## Observations

### Strengths
- Core UX is solid; consistent component library (EmptyState, ErrorBanner, CardTile, etc.)
- Dark mode well-implemented across most pages
- i18n infrastructure is complete — just needs remaining string migration
- Responsive design works well on most pages (grid cols-2/3/4/6 pattern)
- Loading states (skeletons, spinners) present on most data fetches

### Cross-Cutting Patterns Noticed
1. **Error recovery**: Most pages show errors but don't offer retry — pattern should be ErrorBanner with onRetry callback
2. **Async feedback**: Saves/deletes should always show toast (success or error)
3. **Modal roles**: All confirmation modals should use role="alertdialog" + aria-labelledby
4. **Table responsiveness**: All tables need `overflow-x-auto` wrapper for mobile

### Recommended Priority for Next Sprint
1. i18n: hardcoded strings in ImportPurchasesPage, Cards, AdminPanel, DeckBuildWizard (~8h)
2. Admin table horizontal scroll + mobile fixes (~2h)
3. Accessibility: aria-labels on all icon buttons (~3h)
4. ImportPurchasesPage dark mode fix (~1h)
5. Retry buttons on error states (~4h)
6. Success toasts on async operations (~3h)

**Estimated total: 15-20 hours of focused cleanup would bring the grade to A- (90+)**

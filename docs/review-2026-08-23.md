# TCG Market Intelligence — Full Project Review (2026-08-23)

## Executive Summary

53 features shipped (F01-F53), 1756 backend tests (92.52% cov), 938 frontend tests.
Stack: Python 3.14 + FastAPI + SQLite | React 19 + Vite + Tailwind + Recharts.

This review audited **backend**, **frontend**, and **user journeys** in depth.
Findings organized below by priority tier.

---

## TIER 1 — CRITICAL (fix before any new feature)

### T1-01. No 404 catch-all route
- **Where:** Frontend routing (App.tsx)
- **Impact:** Invalid URLs show blank page; app looks broken
- **Fix:** Add `<Route path="*" element={<NotFoundPage />} />`

### T1-02. JWT secret randomly generated per process
- **Where:** `src/auth/jwt.py:19-26`
- **Impact:** All user sessions invalidated on every server restart if `TCG_JWT_SECRET` not set
- **Fix:** Require `TCG_JWT_SECRET` env var; fail fast on startup if missing

### T1-03. Hardcoded CSV path in collection import endpoint
- **Where:** `src/api/routers/collection.py:832`
- **Impact:** Import only works for one specific file; no file upload support
- **Fix:** Accept multipart file upload or configurable path

### T1-04. Default `user_id="eduardo"` in importer
- **Where:** `src/collection/importer.py:17`
- **Impact:** If called without explicit user_id, data goes to wrong user
- **Fix:** Remove default; make user_id required

### T1-05. Destructive collection delete on import (no rollback)
- **Where:** `src/collection/importer.py:71`
- **Impact:** If import fails midway, user loses entire collection with no recovery
- **Fix:** Wrap in transaction; only commit after full success; add backup step

## TIER 2 — HIGH (significant UX/reliability issues)

### T2-01. Scan progress lost on page reload
- **Where:** SSE stream in useCollectionRefresh / ScanProgressBar
- **Impact:** Long scans can't be monitored after navigation; user must keep page open
- **Fix:** Store progress in localStorage; poll /scans/{id} on reconnect

### T2-02. Card refresh fails silently when MYP is down
- **Where:** Collection card detail, refresh button
- **Impact:** User sees error with no fallback; no path to manual entry
- **Fix:** On failure, show "Last known price" + offer manual entry inline

### T2-03. Hardcoded seed user password `"mudar@123"`
- **Where:** `src/cli/main.py:529,531`
- **Impact:** Known default credentials if deployed without change
- **Fix:** Read from env var or generate random password + force reset

### T2-04. CORS `allow_origins=["*"]` with `allow_credentials=True`
- **Where:** `src/api/app.py:90-97`
- **Impact:** Any website can make authenticated cross-origin requests
- **Fix:** Restrict to known frontend origins

### T2-05. Missing null check after link_collection_entry
- **Where:** `src/api/routers/collection.py:557-558`
- **Impact:** Unhandled AttributeError if link fails
- **Fix:** Add `if not entry or entry.card_id is None: raise HTTPException(422)`

### T2-06. Orphan deck cards cause 404
- **Where:** DeckView page
- **Impact:** If a card is deleted from DB, entire deck becomes inaccessible
- **Fix:** Show "Card not found" placeholder instead of crashing

### T2-07. Schedule auto-pause on error is silent
- **Where:** Scheduled Scans
- **Impact:** User thinks scans are running but they stopped silently
- **Fix:** Show pause reason in UI; add "paused" badge on nav item

### T2-08. No "Back" button on detail pages
- **Where:** CardDetail, CollectionCardDetail, DeckView
- **Impact:** Poor mobile UX; browser back might leave the site
- **Fix:** Add back navigation button at top of detail pages

### T2-09. `as any` type assertion on DeckCardTile
- **Where:** `frontend/src/components/DeckCardTile.tsx:17`
- **Impact:** Bypasses TypeScript; hides potential bugs
- **Fix:** Add `name_pt` to DeckCard type definition

### T2-10. Unhandled promise rejection in Cards page
- **Where:** `frontend/src/pages/Cards.tsx:45-49`
- **Impact:** fetchSets() failure silently swallowed
- **Fix:** Add `.catch()` with error state

## TIER 3 — MEDIUM (UX friction, consistency, polish)

### T3-01. No Settings/Preferences page
- Currency/language are in sidebar only; no centralized hub for API keys, data export, notifications

### T3-02. Freshness indicator only on dashboard
- Collection page has no "last synced" info; user doesn't know if prices are stale

### T3-03. No breadcrumbs on detail pages
- Hard to understand page hierarchy; "Back to Collection" is only navigation

### T3-04. Trending → card click doesn't go to price history
- Trending shows gainers/losers but clicking goes to generic CardDetail, not price analysis

### T3-05. Dashboard trending has no "View All" link
- Shows only 10 gainers/losers; no link to full trending page

### T3-06. Market data empty state doesn't explain MYP sync dependency
- "No price data yet" without guidance on how to get data

### T3-07. Deck import format undocumented
- Modal accepts text/file but doesn't show format spec or example

### T3-08. Non-owned card darkening too subtle
- Cards slightly darkened but unclear on small screens; needs "Not Owned" badge

### T3-09. No import summary after CSV import
- Import finishes silently; no count of cards added/failed/canonized

### T3-10. No bulk delete operation on collection
- Can only delete entries individually; tedious for large corrections

### T3-11. Period selector inconsistent across pages
- Dashboard/Market/MarketMovers/TopDecks use different selector styles

### T3-12. Filter persistence missing on Explore Cards page
- Collection persists filters in URL params; Cards page doesn't

### T3-13. Scan result details incomplete
- Scan history shows date/duration but not: cards updated, new prices found, errors

### T3-14. Ban impact analysis incomplete
- Collection shows "3 banned cards" but no monetary impact calculation

### T3-15. Deck page doesn't warn about banned cards
- User can build a deck with banned cards and not know

### T3-16. Decimal rounding mode not specified
- `src/api/routers/collection.py:541` uses default ROUND_HALF_EVEN; financial data should use ROUND_HALF_UP

### T3-17. Database URL pattern repeated ~20 times
- `os.environ.get("TCG_DATABASE_URL", "sqlite:///tcg_market.db")` duplicated everywhere
- Should be a single `get_db_url()` utility

### T3-18. Repository boolean returns silently ignored
- Methods like `delete_deck()` return bool; callers don't check False case

### T3-19. Hardcoded strings missing i18n
- `CollectionCardDetail.tsx:171,176` — "Collection entry not found", "Back to Collection" hardcoded

### T3-20. Network/timeout errors not distinguished
- ErrorBanner checks for "failed to fetch" string; doesn't handle AbortError, TypeError

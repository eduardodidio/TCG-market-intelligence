# F72-T01 — Treasure Sidebar Art Expansion + Click Modal

**Status:** planned
**Wave:** 0
**Depends on:** —

## User Story

As a user, I want to see the treasure token art fully (not squished into a tiny circle) in the sidebar, and when I click it, see a modal with the full-size art and my token count, so I can appreciate the art and know my balance at a glance.

## Dev Notes

### Files to modify

1. **`frontend/src/components/TreasureBalance.tsx`**
   - Replace the `w-8 h-8 rounded-full object-cover border-2 border-yellow-300` img with a larger, rectangular display that shows the art without circular cropping
   - Suggested: `w-12 h-16 rounded object-cover border border-amber-500/50` (card-shaped aspect ratio)
   - Add `cursor-pointer` and onClick handler to open modal
   - Add state: `const [modalOpen, setModalOpen] = useState(false)`
   - Render `TreasureModal` when open

2. **`frontend/src/components/TreasureModal.tsx`** (NEW)
   - Overlay: fixed inset-0 bg-black/60 z-50 flex items-center justify-center
   - Content: the full treasure image (no encapsulation — just the `<img>` rendered large) + count badge
   - Show the `treasureImage` at full resolution (no max constraints beyond viewport)
   - Display token count prominently below or overlaid on the image
   - Close on backdrop click or Escape key
   - Use `useEffect` for Escape key listener (cleanup on unmount)
   - Props: `{ count: number; onClose: () => void }`

### Key decisions
- Do NOT use `TreasureTokenCard` component (which wraps the art in an MTG card frame) — user wants the art exposed directly
- Keep the sidebar widget compact but show art fully (rectangular, not circular)
- Modal shows the raw art image at large size

### i18n
- Reuse existing `credits.balance` key for alt text
- No new i18n keys needed

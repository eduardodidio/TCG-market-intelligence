# F100-T03 -- Admin Job Trigger Endpoints

**Wave:** 1 (parallel with T02, T04)
**Depends on:** T01

## User Story

As an admin, I want to trigger background jobs (Liga collection scan,
catalog sweep) directly from the API so I do not need CLI access to the
server.

## Dev Notes

### New endpoints in `src/api/routers/admin.py`

#### 1. `POST /admin/jobs/liga-scan`

Triggers a Liga scan for all admin users' collections (same logic as
`admin_daily_liga` in `src/collectors/admin_scan.py`).

```python
@router.post("/jobs/liga-scan")
def trigger_liga_scan(
    admin: User = Depends(require_admin),
    repo: Repository = Depends(get_db),
    max_age_days: int = Query(1, ge=1),
):
    """Trigger a Liga scan for all admin collections (no credit cost)."""
    import asyncio, threading, json
    from src.collectors.admin_scan import run_admin_daily_liga_scan
    from src.config import get_db_url
    from src.services.scan_hooks import default_registry

    db_url = get_db_url()
    scan_id = repo.create_scan_run("admin_liga_scan", json.dumps({
        "triggered_by": admin.id,
        "max_age_days": max_age_days,
    }))

    def _run():
        asyncio.run(run_admin_daily_liga_scan(
            db_url=db_url,
            run_id=scan_id,
            max_age_days=max_age_days,
            on_complete=default_registry.notify,
        ))

    thread = threading.Thread(target=_run, daemon=True)
    thread.start()

    return success_response(data={"scan_id": scan_id, "status": "pending"})
```

#### 2. `POST /admin/jobs/catalog-scan`

Triggers a catalog Liga sweep for a specific set code.

```python
@router.post("/jobs/catalog-scan")
def trigger_catalog_scan(
    admin: User = Depends(require_admin),
    repo: Repository = Depends(get_db),
    set_code: str = Query(..., min_length=2, max_length=10),
    delay: float = Query(2.0, ge=0.5, le=10.0),
):
    """Trigger a Liga price sweep for a catalog set (no credit cost)."""
    import asyncio, threading, json
    from src.collectors.liga_sweep import run_liga_sweep
    from src.config import get_db_url

    db_url = get_db_url()
    scan_id = repo.create_scan_run("catalog_sweep", json.dumps({
        "triggered_by": admin.id,
        "set_code": set_code,
    }))

    def _run():
        asyncio.run(run_liga_sweep(
            db_url=db_url,
            set_code=set_code,
            delay=delay,
            run_id=scan_id,
            collection_only=False,
        ))

    thread = threading.Thread(target=_run, daemon=True)
    thread.start()

    return success_response(data={
        "scan_id": scan_id,
        "set_code": set_code,
        "status": "pending",
    })
```

#### 3. `GET /admin/jobs/status`

Returns the most recent scan runs triggered by admin (last 10).

```python
@router.get("/jobs/status")
def get_job_status(
    admin: User = Depends(require_admin),
    repo: Repository = Depends(get_db),
    limit: int = Query(10, ge=1, le=50),
):
    """List recent admin-triggered job runs."""
    runs = repo.list_scan_runs(limit=limit, offset=0)
    return success_response(data=runs)
```

### Key patterns

- Reuse `run_admin_daily_liga_scan` from `src/collectors/admin_scan.py`
  for the Liga scan -- this already handles multi-admin dedup.
- Reuse `run_liga_sweep` from `src/collectors/liga_sweep.py` for catalog
  scans.
- Both launch in daemon threads (same pattern as `scans.py` router).
- No credit deduction -- admin jobs are free (system-level operations).
- The `scan_id` is returned immediately so the frontend can poll
  `GET /scans/{scan_id}` for progress.

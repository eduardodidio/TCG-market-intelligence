# F100-T06 -- AdminOperationsSection (Job Triggers + DB Backup)

**Wave:** 2
**Depends on:** T03, T04

## User Story

As an admin, I want to trigger operational jobs and download DB backups
from the Admin Panel UI so I do not need CLI or API access.

## Dev Notes

### New component: `frontend/src/components/admin/AdminOperationsSection.tsx`

An accordion section in the AdminPanel with three action cards:

#### 1. Liga Collection Scan

- Button: "Run Liga Scan" (indigo)
- Optional input: max_age_days (default 1)
- On click: `POST /api/v1/admin/jobs/liga-scan?max_age_days={n}`
- Shows scan_id and status after trigger
- Links to scan detail (reuse existing scan status polling)

#### 2. Catalog Set Sweep

- Input: set_code (text, required, e.g. "mh3")
- Optional input: delay (number, default 2.0)
- Button: "Sweep Set" (indigo)
- On click: `POST /api/v1/admin/jobs/catalog-scan?set_code={code}&delay={d}`
- Shows scan_id and status after trigger

#### 3. DB Backup Download

- Button: "Download Backup" (green)
- On click: triggers file download via `GET /api/v1/admin/backup`
- Shows loading spinner during download
- Uses `window.open()` or `<a download>` pattern for file download

### API functions in `frontend/src/api/admin.ts`

```typescript
export function triggerLigaScan(maxAgeDays = 1) {
  return apiPost<{ scan_id: number; status: string }>(
    `/api/v1/admin/jobs/liga-scan?max_age_days=${maxAgeDays}`,
    {},
  );
}

export function triggerCatalogScan(setCode: string, delay = 2.0) {
  return apiPost<{ scan_id: number; set_code: string; status: string }>(
    `/api/v1/admin/jobs/catalog-scan?set_code=${setCode}&delay=${delay}`,
    {},
  );
}

export function downloadBackup(): void {
  const token = localStorage.getItem("tcg_access_token");
  const url = new URL("/api/v1/admin/backup", API_BASE_URL || window.location.origin);
  if (token) url.searchParams.set("token", token);
  window.open(url.toString(), "_blank");
}
```

Note: For the backup download, we need to add token-based auth support
to the backup endpoint (query param `?token=<jwt>`) since `window.open`
cannot send Authorization headers. Follow the same pattern as the SSE
stream auth in `scans.py`.

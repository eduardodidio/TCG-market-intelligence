# F100-T04 -- DB Backup Download Endpoint

**Wave:** 1 (parallel with T02, T03)
**Depends on:** T01

## User Story

As an admin, I want to download a backup of the SQLite database from the
admin panel so I can keep local copies without SSH access to the server.

## Dev Notes

### New endpoint in `src/api/routers/admin.py`

#### `GET /admin/backup`

```python
@router.get("/backup")
def download_backup(
    admin: User = Depends(require_admin),
):
    """Download a copy of the SQLite database file (admin only).

    Creates a temporary copy using SQLite's backup API to avoid
    locking issues, then streams it as a file download.
    """
    import shutil
    import sqlite3
    import tempfile
    from datetime import datetime
    from pathlib import Path

    from fastapi.responses import FileResponse
    from src.config import get_db_url

    db_url = get_db_url()
    # Extract file path from sqlite:/// URL
    db_path = db_url.replace("sqlite:///", "")
    if not Path(db_path).exists():
        raise HTTPException(404, "Database file not found")

    # Use SQLite backup API for a consistent copy
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    tmp_dir = tempfile.mkdtemp()
    backup_path = Path(tmp_dir) / f"tcg_market_backup_{timestamp}.db"

    src_conn = sqlite3.connect(db_path)
    dst_conn = sqlite3.connect(str(backup_path))
    src_conn.backup(dst_conn)
    src_conn.close()
    dst_conn.close()

    return FileResponse(
        path=str(backup_path),
        filename=f"tcg_market_backup_{timestamp}.db",
        media_type="application/x-sqlite3",
        background=BackgroundTask(lambda: shutil.rmtree(tmp_dir, ignore_errors=True)),
    )
```

### Implementation notes

- Uses `sqlite3.Connection.backup()` (Python 3.7+) instead of `shutil.copy`
  to get a consistent snapshot even if the DB is being written to.
- The temp file is cleaned up after the response is sent using FastAPI's
  `BackgroundTask`.
- Import `BackgroundTask` from `starlette.background`.
- The backup filename includes a timestamp for easy identification.
- File size is limited by the server's temp disk. For the current DB size
  (~50-100MB) this is fine.

### Security considerations

- Admin-only (enforced by `require_admin` dependency).
- The backup contains all data including password hashes. This is
  acceptable since only admins can download it, and they already have
  full access.

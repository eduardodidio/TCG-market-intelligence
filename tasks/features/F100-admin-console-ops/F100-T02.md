**Wave:** 1 (parallel with T03, T04)

## User Story

As a developer, I need a simple audit logging service so that any admin
endpoint can record actions with a single function call.

## Dev Notes

### Repository methods in `src/database/repository.py`

Add these methods to the existing `Repository` class:

1. **`log_audit(actor_id, actor_email, action, target_type, target_id, details, ip_address)`**
   - Inserts a new AuditLogRow
   - `details` is a Python dict, serialized to JSON before storage
   - Returns the inserted row ID

2. **`list_audit_logs(limit, offset, action, actor_id, date_from, date_to)`**
   - Returns `(list[dict], total_count)` tuple
   - Supports optional filters: action type, actor_id, date range
   - Ordered by timestamp DESC (newest first)
   - Each dict includes: id, timestamp (ISO string), actor_id, actor_email,
     action, target_type, target_id, details_json (raw string)

### Audit service in `src/services/audit.py` (new file)

```python
class AuditService:
    def __init__(self, repo: Repository):
        self._repo = repo

    def log(
        self,
        actor: User,
        action: str,
        target_type: str | None = None,
        target_id: str | None = None,
        details: dict | None = None,
        ip_address: str | None = None,
    ) -> None:
        """Log an admin action. Fire-and-forget -- never raises."""
        try:
            self._repo.log_audit(
                actor_id=actor.id,
                actor_email=actor.email,
                action=action,
                target_type=target_type,
                target_id=str(target_id) if target_id is not None else None,
                details=details,
                ip_address=ip_address,
            )
        except Exception:
            # Best-effort logging -- never block the admin action
            import structlog
            structlog.get_logger().warning("audit_log_failed", action=action)
```

### API endpoint: `GET /admin/audit-log`

Add to `src/api/routers/admin.py`:

```python
@router.get("/audit-log")
def list_audit_log(
    admin: User = Depends(require_admin),
    repo: Repository = Depends(get_db),
    action: str | None = Query(None),
    actor_id: int | None = Query(None),
    date_from: datetime | None = Query(None),
    date_to: datetime | None = Query(None),
    limit: int = Query(50, ge=1, le=200),
    offset: int = Query(0, ge=0),
):
    logs, total = repo.list_audit_logs(
        limit=limit, offset=offset,
        action=action, actor_id=actor_id,
        date_from=date_from, date_to=date_to,
    )
    return success_response(data=logs, total=total, offset=offset)
```

### Action type constants

Define as simple strings (not an enum, for extensibility):
- `"credit_adjust"` -- details: `{amount, reason, new_balance}`
- `"user_create"` -- details: `{email, display_name}`

# F100-T05 -- Retrofit Existing Admin Endpoints with Audit Logging

**Wave:** 1 (after T02 is complete)
**Depends on:** T02

## User Story

As a platform operator, I need existing admin actions (credit adjustments,
user creation, user deletion) to be recorded in the audit log so I have a
complete history of all admin operations.

## Dev Notes

### Endpoints to retrofit in `src/api/routers/admin.py`

Each endpoint gets the `AuditService` dependency and calls `audit.log()`
after the action succeeds.

#### 1. `POST /admin/users` (create_user)

```python
audit.log(
    actor=admin,
    action="user_create",
    target_type="user",
    target_id=str(user.id),
    details={"email": body.email, "display_name": body.display_name},
    ip_address=request.client.host if request.client else None,
)
```

Add `request: Request` parameter to the endpoint signature.

### Pattern

Every retrofitted endpoint follows this pattern:
1. Add `request: Request` and `audit: AuditService = Depends(get_audit_service)`
   to the function signature
2. Perform the action (existing logic -- no changes)
3. Call `audit.log()` after success (fire-and-forget)
4. Return the existing response (no changes to response format)

### Dependency import

Add to `src/api/deps.py`:
```python
from src.services.audit import AuditService

def get_audit_service(repo: Repository = Depends(get_db)) -> AuditService:
    return AuditService(repo)
```

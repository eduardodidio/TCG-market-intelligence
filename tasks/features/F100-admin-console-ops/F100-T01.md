# F100-T01 -- AuditLogRow Model + Migration

**Wave:** 0
**Depends on:** nothing

## User Story

As a platform operator, I need an audit log table so that all admin actions
are recorded with full context for accountability and debugging.

## Dev Notes

### New model: `AuditLogRow` in `src/database/models.py`

```python
class AuditLogRow(Base):
    __tablename__ = "audit_log"

    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    timestamp: Mapped[datetime] = mapped_column(DateTime, default=datetime.now)
    actor_id: Mapped[int] = mapped_column(Integer, nullable=False)  # admin user ID
    actor_email: Mapped[str] = mapped_column(String(320), nullable=False)
    action: Mapped[str] = mapped_column(String(100), nullable=False)
    # e.g. "credit_adjust", "user_create", "user_delete", "job_trigger", "db_backup"
    target_type: Mapped[str | None] = mapped_column(String(50))
    # e.g. "user", "scan", "system"
    target_id: Mapped[str | None] = mapped_column(String(100))
    # e.g. user_id, scan_id
    details_json: Mapped[str | None] = mapped_column(Text)
    # JSON blob with action-specific details
    ip_address: Mapped[str | None] = mapped_column(String(45))

    __table_args__ = (
        Index("ix_audit_log_timestamp", "timestamp"),
        Index("ix_audit_log_actor", "actor_id"),
        Index("ix_audit_log_action", "action"),
    )
```

### Migration

Use the existing pattern: `Base.metadata.create_all(engine)` handles new
tables automatically since SQLite creates missing tables on startup. No
Alembic needed.

Verify the table is created by adding a test that imports all models and
calls `create_all`.

### Design decisions

- `actor_id` + `actor_email` are denormalized (no FK to users). This is
  intentional: the audit log must survive user deletion. The email is
  stored at log-time for human readability.
- `details_json` is a free-form JSON string. Each action type defines its
  own schema (documented in T02).
- `ip_address` is optional -- extracted from the FastAPI Request object
  when available.

## Testing

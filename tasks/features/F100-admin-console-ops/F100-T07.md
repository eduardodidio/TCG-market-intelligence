# F100-T07 -- AdminAuditLogSection (Filterable Table)

**Wave:** 2
**Depends on:** T02, T05

## User Story

As an admin, I want to see a chronological log of all admin actions in the
Admin Panel so I can track who did what and when.

## Dev Notes

### New component: `frontend/src/components/admin/AdminAuditLogSection.tsx`

An accordion section in the AdminPanel showing a filterable, paginated
table of audit log entries.

### Layout

```
+----------------------------------------------------+
| Audit Log                                    [v]   |
+----------------------------------------------------+
| Filters: [Action v] [Actor v] [Date from] [Date to]|
|                                                     |
| Timestamp       | Actor         | Action      | Target | Details |
| 2026-09-07 14:32| admin@...     | credit_adj  | user:5 | +100... |
| 2026-09-07 14:30| admin@...     | user_create | user:6 | edu@... |
| ...                                                 |
|                                                     |
| [< Prev]  1-50 of 123  [Next >]                    |
+----------------------------------------------------+
```

### Features

1. **Action filter dropdown**: all / credit_adjust / user_create /
   user_delete / job_trigger / db_backup
2. **Date range**: from/to date inputs (optional)
3. **Pagination**: 50 per page with prev/next buttons
4. **Details column**: truncated JSON preview, expandable on click
5. **Lazy loading**: only fetches data when accordion is opened

### API function in `frontend/src/api/admin.ts`

```typescript
export interface AuditLogEntry {
  id: number;
  timestamp: string;
  actor_id: number;
  actor_email: string;
  action: string;
  target_type: string | null;
  target_id: string | null;
  details_json: string | null;
}

export function fetchAuditLog(params: {
  action?: string;
  actor_id?: number;
  date_from?: string;
  date_to?: string;
  limit?: number;
  offset?: number;
}) {
  const query: Record<string, string> = {};
  if (params.action) query.action = params.action;
  if (params.actor_id !== undefined) query.actor_id = String(params.actor_id);
  if (params.date_from) query.date_from = params.date_from;
  if (params.date_to) query.date_to = params.date_to;
  if (params.limit !== undefined) query.limit = String(params.limit);
  if (params.offset !== undefined) query.offset = String(params.offset);
  return apiGet<AuditLogEntry[]>("/api/v1/admin/audit-log", query);
}
```

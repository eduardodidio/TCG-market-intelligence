# F127-T01: Stop Click Propagation on CardPreviewModal Backdrop

**Status:** planned
**Wave:** 0
**Depends on:** none

## User Story

As a user, when I click outside the zoomed card to close the preview modal,
I want the modal to simply close without navigating to the card detail page.

## Dev Notes

### Current state (CardPreviewModal.tsx)

The backdrop div:
```tsx
<div
  className={`fixed inset-0 bg-black/60 z-[9999] ...`}
  onClick={onClose}          // ← no stopPropagation, no preventDefault
  ...
>
```

### Changes required

1. **Backdrop onClick**: Change `onClick={onClose}` to a handler that stops
   propagation before closing:
   ```tsx
   onClick={(e: React.MouseEvent) => {
     e.stopPropagation();
     e.preventDefault();
     onClose();
   }}
   ```

2. **Backdrop onMouseDown**: Add `onMouseDown` to prevent the mousedown
   event from leaking through the portal to underlying elements:
   ```tsx
   onMouseDown={(e: React.MouseEvent) => {
     e.stopPropagation();
   }}
   ```

3. **Close button**: Also ensure the X button stops propagation (it
   currently just calls `onClick={onClose}` without propagation control):
   ```tsx
   onClick={(e: React.MouseEvent) => {
     e.stopPropagation();
     e.preventDefault();
     onClose();
   }}
   ```

# F09-T01: Health/status endpoint for collection pipeline

**Wave:** 0
**Status:** planned
**Estimate:** M

## User Story

As an operator monitoring the data pipeline, I want to call
GET `/api/v1/collect/health` and see when the last collection ran, how many
cards have stale data, and whether there are recent errors, so that I can
verify the automated collection is working correctly.

## Dev Notes

### New Repository Methods

Add two new methods to `src/database/repository.py`:

1. **`get_latest_observation_date(source: str | None = None) -> date | None`**
   - Query: `SELECT MAX(observed_at) FROM price_observations [WHERE source = ?]`
   - Returns the most recent observation date across all cards.

2. **`get_stale_cards_count(source: str | None = None, stale_days: int = 14) -> int`**
   - A card is "stale" if its most recent observation is older than `stale_days`.
   - Query approach: subquery gets `MAX(observed_at)` per `(source, external_id)`,
     outer query counts rows where that max is < `date.today() - timedelta(days=stale_days)`.
   - Must also count cards with zero observations (from `source_cards` LEFT JOIN).

3. **`get_recent_errors_count(source: str | None = None, days: int = 7) -> int`**
   - Query: `SELECT COUNT(*) FROM collection_errors WHERE resolved = 0 AND timestamp >= cutoff`

### New Pydantic Schema

Add to `src/api/schemas/collect.py`:

```python
class CollectionHealth(BaseModel):
    last_collection_at: str | None  # ISO date string
    next_expected_at: str | None    # ISO datetime string (last + 24h)
    total_cards: int
    stale_cards_count: int
    recent_errors_count: int
    status: str  # "healthy" | "stale" | "error"
```

Status logic:
- `"error"` if `recent_errors_count > 0`
- `"stale"` if `stale_cards_count > total_cards * 0.5` or `last_collection_at` is None
- `"healthy"` otherwise

## Acceptance Criteria

- [ ] `GET /api/v1/collect/health` returns 200 with `CollectionHealth` payload
- [ ] Response includes `last_collection_at` as ISO date (or null if no data)
- [ ] Response includes `stale_cards_count` (cards with no observation in last 14 days)
- [ ] Response includes `recent_errors_count` (unresolved errors in last 7 days)
- [ ] Response includes `status` field with value "healthy", "stale", or "error"
- [ ] `next_expected_at` is `last_collection_at + 24h` (or null)
- [ ] Health endpoint appears in Swagger docs at `/docs`

# F09-T04: Frontend freshness indicator on Dashboard

**Wave:** 1
**Status:** planned
**Estimate:** S

## User Story

As a dashboard user, I want to see "Last updated: 2 hours ago" on the
Dashboard page, so that I know whether the price data I am viewing is fresh
or stale.

## Dev Notes

### New API Function

Add to `frontend/src/api/market.ts` (or create `frontend/src/api/collect.ts`):

```typescript
export interface CollectionHealth {
  last_collection_at: string | null;
  next_expected_at: string | null;
  total_cards: number;
  stale_cards_count: number;
  recent_errors_count: number;
  status: "healthy" | "stale" | "error";
}

export function fetchCollectionHealth(): Promise<ApiResponse<CollectionHealth>> {
  return apiGet<CollectionHealth>("/api/v1/collect/health");
}
```

Since this is a collect-related type, creating a new file
`frontend/src/api/collect.ts` is cleaner to maintain separation of concerns.

### New Type

Add `CollectionHealth` to `frontend/src/types/api.ts`:

```typescript
export interface CollectionHealth {
  last_collection_at: string | null;
  next_expected_at: string | null;
  total_cards: number;
  stale_cards_count: number;
  recent_errors_count: number;
  status: "healthy" | "stale" | "error";
}
```

### New Component: FreshnessIndicator

Create `frontend/src/components/FreshnessIndicator.tsx`:

- Props: `lastCollectionAt: string | null`, `status: string`
- Renders a small badge/pill showing:
  - "Last updated: X ago" using relative time formatting
  - Green dot for "healthy", yellow for "stale", red for "error"
  - "Unknown" if `lastCollectionAt` is null
- Use a simple relative time formatter (no dependency like `date-fns`):
  - Calculate diff in minutes/hours/days from `new Date(lastCollectionAt)`
  - Format as "X minutes ago", "X hours ago", "X days ago"

### Dashboard Integration

In `frontend/src/pages/Dashboard.tsx`:

1. Import `fetchCollectionHealth` and `FreshnessIndicator`
2. Add a third `useApi` call for health data
3. Render `<FreshnessIndicator />` in the header area, below the "Market
   Overview" heading or alongside it
4. The freshness indicator should NOT block the rest of the dashboard from
   loading -- if the health endpoint fails, the dashboard still works, and
   the indicator shows "Unknown"

### Graceful Degradation

The `useApi` hook already handles errors. If the health endpoint is
unreachable, `health.error` will be set and `health.data` will be null. The
`FreshnessIndicator` component should handle `null` props by showing
"Data freshness: Unknown".

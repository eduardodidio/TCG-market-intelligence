## User Story

As a developer onboarding to the project, I want up-to-date diagrams and
documentation that reflect the scheduled collection pipeline, so that I can
understand how data stays fresh without reading all the source code.

## Dev Notes

### Mermaid Diagrams

Create two diagrams under `docs/diagrams/`:

1. **`F09-architecture.mmd`** -- Component/data-flow diagram showing:
   - External cron trigger (crontab / Task Scheduler)
   - `scripts/cron_update.sh` calling POST `/api/v1/collect/update`
   - API key guard (dependency)
   - FastAPI collect router dispatching to `run_update()`
   - GET `/api/v1/collect/health` returning pipeline status
   - Frontend Dashboard consuming health endpoint
   - SQLite database as the data store

2. **`F09-journey.mmd`** -- BPMN-style user journey showing:
   - Operator: configure API key, set up crontab, verify via health endpoint
   - Cron: trigger fires, script runs, collection executes, data refreshed
   - Dashboard user: opens dashboard, sees freshness indicator, trusts data
   - Error path: collection fails, health endpoint shows "error" status,
     operator checks logs

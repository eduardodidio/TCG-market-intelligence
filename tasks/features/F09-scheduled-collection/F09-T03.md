# F09-T03: Cron trigger script

**Wave:** 1
**Status:** planned
**Estimate:** S

## User Story

As an operator, I want a versionable shell script that I can register in
crontab (or Task Scheduler) to trigger price collection automatically, so
that I do not need to remember to run the update manually.

## Dev Notes

### Script: `scripts/cron_update.sh`

Create a POSIX-compatible bash script that:

1. Reads configuration from environment variables:
   - `TCG_API_URL` (default: `http://localhost:8000`)
   - `TCG_API_KEY` (required)
   - `TCG_LOG_DIR` (default: `logs/cron`)

2. Calls `POST $TCG_API_URL/api/v1/collect/update` with:
   - Header: `X-API-Key: $TCG_API_KEY`
   - Header: `Content-Type: application/json`
   - Body: `{}`

3. Logs the response (timestamp + HTTP status + body) to
   `$TCG_LOG_DIR/cron_update_YYYY-MM-DD.log`

4. Exits with code 0 on HTTP 200, non-zero otherwise.

5. Optionally calls the health endpoint after the update to log the health
   status.

### Script structure (pseudocode)

```bash
#!/usr/bin/env bash
set -euo pipefail

API_URL="${TCG_API_URL:-http://localhost:8000}"
API_KEY="${TCG_API_KEY:?ERROR: TCG_API_KEY must be set}"
LOG_DIR="${TCG_LOG_DIR:-logs/cron}"

mkdir -p "$LOG_DIR"
LOG_FILE="$LOG_DIR/cron_update_$(date +%Y-%m-%d).log"

log() { echo "[$(date -Iseconds)] $*" >> "$LOG_FILE"; }

log "Starting price update..."

HTTP_CODE=$(curl -s -o /tmp/tcg_response.json -w "%{http_code}" \
  -X POST "$API_URL/api/v1/collect/update" \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}')

BODY=$(cat /tmp/tcg_response.json)
log "HTTP $HTTP_CODE — $BODY"

if [ "$HTTP_CODE" -ne 200 ]; then
  log "ERROR: Update failed with HTTP $HTTP_CODE"
  exit 1
fi

# Optional: check health
HEALTH=$(curl -s "$API_URL/api/v1/collect/health")
log "Health: $HEALTH"

log "Done."
exit 0
```

## Testing

- **Manual testing only** (shell script, not unit-testable in pytest):
  1. Start the backend: `make serve`
  2. Set `TCG_API_KEY=test123` in both server and script environments
  3. Run: `TCG_API_KEY=test123 bash scripts/cron_update.sh`
  4. Verify log file created in `logs/cron/`
  5. Verify exit code: `echo $?` shows 0
  6. Stop the backend, run again -- verify exit code is non-zero

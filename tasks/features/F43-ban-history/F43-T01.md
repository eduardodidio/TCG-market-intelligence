# F43-T01: Domain model + API schemas

**Status:** planned
**Wave:** 0

## User Story

As a developer, I need the domain dataclass and API schemas for ban
impact analysis and paginated history responses so all other tasks can
build on them.

## Dev Notes

### Files to modify
- `src/domain/models.py` — add `BanImpactAnalysis` dataclass
- `src/api/schemas/banlist.py` — add new schemas (file created by F41-T04)

### Implementation

1. Add `BanImpactAnalysis` dataclass to `src/domain/models.py`:
   ```python
   @dataclass
   class BanImpactAnalysis:
       card_id: int
       format: str
       old_status: str | None
       new_status: str
       changed_at: datetime
       window_days: int = 7
       price_before: float | None = None
       price_after: float | None = None
       absolute_change: float | None = None
       percent_change: float | None = None
       data_available: bool = False
   ```

2. Add `LegalityHistoryResponse` schema to `src/api/schemas/banlist.py`:
   ```python
   class LegalityHistoryResponse(BaseModel):
       items: list[LegalityHistoryEntry]
       total: int
       limit: int
       offset: int
   ```

3. Add `CardBanHistoryEntry` schema:
   ```python
   class CardBanHistoryEntry(BaseModel):
       id: int
       format: str
       old_status: str | None
       new_status: str
       changed_at: datetime
       source: str
   ```

4. Add `BanImpactSchema` schema:
   ```python
   class BanImpactSchema(BaseModel):
       format: str
       old_status: str | None
       new_status: str
       changed_at: datetime
       window_days: int
       price_before: float | None
       price_after: float | None
       absolute_change: float | None
       percent_change: float | None
       data_available: bool
   ```

5. Add `image_url: str | None` field to existing `LegalityHistoryEntry`
   schema (from F41-T04).

# F43-T05: Frontend — BanHistory timeline page

**Status:** planned
**Wave:** 2

## User Story

As a user, I want a dedicated ban history timeline page where I can
browse all ban/unban events chronologically, filtered by format and
date range, so I can track how the metagame has evolved.

## Dev Notes

### BanHistory page (`frontend/src/pages/BanHistory.tsx`)

1. **Header**: page title "Ban History" with subtitle "Chronological
   timeline of ban list changes"

2. **Filters bar** (top of page):
   - Format dropdown (reuse format list from F41's `fetchFormats`)
     - "All Formats" option as default
   - Date range: two month/year selectors (from / to)
     - Default: last 12 months (or all-time if no data in range)
   - Apply button or auto-apply on change (debounced)

3. **Timeline feed**:
   - Group events by date (month/year headers, e.g. "August 2026")
   - Within each group, list BanEventCard components (from T04)
   - showCardInfo=true (show card thumbnails and names)
   - Vertical timeline line connecting events (left border or similar)
   - Events ordered newest-first within each group

4. **Pagination**:
   - "Load more" button at bottom
   - Show "{loaded} of {total} events"
   - Initial load: 30 events
   - Each "load more": 30 more events (offset-based)

5. **Empty state**: "No ban history events found" with suggestion to
   adjust filters or wait for ban list sync

6. **Loading state**: skeleton cards while fetching

7. **URL param persistence**: store format and date range in URL search
   params so links are shareable (same pattern as other pages)

### Route registration
- Lazy import in `App.tsx`
- Route: `/banlist/history` (public, inside `<Route element={<Layout />}>`)

### Navigation
- Add "History" sub-item under existing "Ban List" nav link

### Styling
- Month/year group headers: text-lg font-semibold text-slate-300
- Timeline line: 2px border-l border-slate-600 on the left
- Events have small circle dot on the timeline line (colored by
  ban=red / unban=green)

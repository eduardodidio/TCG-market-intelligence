# F43-T04: Frontend — BanEventCard + StatusTransition + API client

**Status:** planned
**Wave:** 2

## User Story

As a frontend developer, I need reusable components for rendering ban
events and an API client for the new history endpoints so the timeline
page and card detail section can use them.

### API client extensions (`frontend/src/api/banlist.ts`)

1. `fetchBanHistoryPaginated(params: { format?: string; cardId?: number; dateFrom?: string; dateTo?: string; limit?: number; offset?: number }): Promise<{ items: LegalityHistoryEntry[]; total: number; limit: number; offset: number }>`

### StatusTransition component

1. Props:
   ```typescript
   interface StatusTransitionProps {
     oldStatus: string | null;
     newStatus: string;
     size?: "sm" | "md";
   }
   ```

2. Renders: `[OldBadge] -> [NewBadge]` with an arrow between them
   - Reuse `LegalityBadge` from F41-T07 for each status
   - Arrow: right-pointing chevron or arrow icon
   - If oldStatus is null, show only the new status (initial entry)
   - Color of arrow: red if newStatus is "banned"/"restricted",
     green if newStatus is "legal", gray otherwise

# F43-T06: Frontend — card detail ban history + i18n + tests + diagrams

**Status:** planned
**Wave:** 3

## User Story

As a collector viewing a card's detail page, I want to see the card's
ban history timeline below the legality grid, and as a user I want the
UI translated to my language.

### CollectionCardDetail integration

1. Below the "Format Legality" section (added by F41-T07), add a
   "Ban History" collapsible section:
   - Section header: "Ban History" with clock/history icon
   - Collapsible: collapsed by default, expands on click
   - When expanded, fetch card ban history via
     `fetchCardBanHistory(cardId)`
   - Render list of BanEventCard components (from T04) with
     showCardInfo=false (we are already on the card's page)
   - Vertical timeline layout (similar to BanHistory page but compact)
   - Format badge on each event (since one card can be banned in
     multiple formats)

2. If card has no ban history, show "No ban events recorded for this
   card" inside the collapsed section

3. If card_id is null (unlinked collection entry), hide the section
   entirely (same pattern as legality section from F41-T07)

4. Lazy-load: only fetch ban history when section is expanded (avoid
   unnecessary API calls)

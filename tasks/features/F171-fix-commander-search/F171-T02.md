# F171-T02 — CLI command to audit/backfill cards missing Scryfall metadata

**Wave:** 1
**Depends on:** none
**Files to change:**
- `src/cli/main.py` (add `catalog enrich` or `catalog audit` subcommand)
- `src/catalog/seeder.py` (optional: extract enrichment logic if reusable)

## User Story

As a system operator, I want a CLI command that tells me how many cards are
missing Scryfall metadata (type_line, rarity, etc.) and optionally fixes them
by cross-referencing existing catalog data, so I can diagnose and resolve the
commander search issue without a full re-seed.

## Dev Notes

### Command: `catalog enrich`

Two modes:

1. **Audit mode (default / --dry-run):** Query and report cards where
   `type_line IS NULL AND game = 'magic'`. Show count, sample card names,
   and suggested action ("run `catalog seed` to fix").

2. **Fix mode (--fix):** For each card with missing metadata, look up a
   sibling card with the same `name_en` that HAS metadata (from a different
   printing seeded by the catalog). Copy `type_line`, `rarity`,
   `color_identity`, `mana_cost` from the sibling. This handles the case
   where some printings were seeded and others were not.

### SQL for audit

```sql
SELECT COUNT(*) FROM cards WHERE game = 'magic' AND type_line IS NULL;
```

### SQL for sibling enrichment

```sql
UPDATE cards AS target
SET type_line = (
    SELECT c2.type_line FROM cards c2
    WHERE c2.name_en = target.name_en
      AND c2.type_line IS NOT NULL
    LIMIT 1
), ...
WHERE target.game = 'magic' AND target.type_line IS NULL;
```

In SQLAlchemy, this is a correlated subquery update. Alternatively, do it
in Python: fetch all NULL-metadata cards, group by name_en, find a donor
card, batch-update.

### Output

```
$ python -m src.cli.main catalog enrich --dry-run
Cards missing Scryfall metadata: 1,234 / 105,870
Top 10 affected:
  - Lightning Bolt (m3c #123) — type_line=NULL
  - Sol Ring (cmr #456) — type_line=NULL
  ...
Run with --fix to backfill from sibling printings.
Run 'catalog seed' to fully re-sync from Scryfall bulk data.

$ python -m src.cli.main catalog enrich --fix
Enriched 1,102 cards from sibling printings.
132 cards have no sibling with metadata — run 'catalog seed' to fix.
```

- **Wave:** 1
- **Type:** infra
- **Depends on:** F11-T01

## User Story

As a platform operator, I want to see which collection cards are found on
MYP before running the full sync, so that I can assess coverage and
identify problematic cards.

## Objective

Run the match-report CLI command, capture the output, and generate a JSON
report for review.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/01-operational-pipeline.md`.

- CLI: `python -m src.cli.main match-report`
- This is a **read-only** operation — no DB writes.
- Uses `asyncio.Semaphore(3)` + 1s delay between requests.
- Searches MYP via `/produto/search?marca=magic&term={name_en}`.
- Matching tiers: sku_exact > name_set > name_only.
- Expected runtime: ~10 min for 548 cards.

## Implementation Details

1. Create `reports/` directory if it doesn't exist.
2. Run `python -m src.cli.main match-report --output reports/match-report.json`.
3. Review console output (matched/ambiguous/unmatched counts).
4. Review JSON report for problematic cards.

# F11-T01 — Normalize Set Codes in Production DB

- **Wave:** 0
- **Type:** infra
- **Depends on:** (none)
- **Status:** done

## User Story

As a platform operator, I want all set codes in the database normalized to
lowercase, so that the match report and sync pipeline can match collection
entries correctly.

## Objective

Run `scripts/normalize_set_codes.py` against the production DB and verify
the output.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/01-operational-pipeline.md`.

- Script: `scripts/normalize_set_codes.py` — already has safety checks
  (duplicate conflict detection before UPDATE).
- Default DB: `tcg_market.db` in project root.
- The script updates `cards.set_code` and `source_cards.set_code` via
  `UPDATE ... SET set_code = LOWER(set_code) WHERE set_code != LOWER(set_code)`.
- Back up the DB first using `python -m src.cli.main db-backup`.

## Implementation Details

1. Run `python -m src.cli.main db-backup` to create a safety backup.
2. Run `python scripts/normalize_set_codes.py` (defaults to `tcg_market.db`).
3. Verify output shows rows updated (expected: all uppercase set codes → lowercase).
4. Spot-check with `sqlite3 tcg_market.db "SELECT DISTINCT set_code FROM cards LIMIT 20"`.

## Acceptance Criteria

- [x] DB backup created in `backups/` directory before normalization
- [x] Script runs without errors (no duplicate conflicts)
- [x] All `cards.set_code` values are lowercase
- [x] All `source_cards.set_code` values are lowercase
- [x] Spot-check confirms lowercase set codes

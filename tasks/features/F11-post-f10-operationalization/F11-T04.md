# F11-T04 — Move `collection_summary` SQLAlchemy to Repository

- **Wave:** 1
- **Type:** backend
- **Depends on:** F11-T01

## User Story

As a developer, I want the collection total value calculation in the
Repository layer, so that the API router has no raw SQLAlchemy queries
and follows the project's separation of concerns.

## Objective

Move the inline SQLAlchemy from `collection_summary` endpoint into a new
`Repository.get_collection_total_value()` method.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/02-tech-debt.md`.

- Current: `src/api/routers/collection.py:100-142` has inline imports of
  `select`, `Session`, `UserCollectionRow` inside the function body.
- The logic: query linked collection rows → batch-fetch latest prices →
  sum (median_price * quantity) for each row.
- Target: `Repository.get_collection_total_value(user_id: str) -> Decimal | None`
- The repo already has `get_collection_summary()` and `get_latest_prices_batch()`.
- Convention: Repository methods use `Session(self.engine)` context manager.

## Implementation Details

1. Add to `src/database/repository.py`:
   ```python
   def get_collection_total_value(self, user_id: str) -> Decimal | None:
       with Session(self.engine) as session:
           linked_rows = session.execute(
               select(UserCollectionRow).where(
                   UserCollectionRow.user_id == user_id,
                   UserCollectionRow.card_id.isnot(None),
               )
           ).scalars().all()
           if not linked_rows:
               return None
           card_ids = list({r.card_id for r in linked_rows})
           prices = self.get_latest_prices_batch(card_ids)
           total = Decimal("0")
           for r in linked_rows:
               obs = prices.get(r.card_id)
               if obs and obs.median_price:
                   total += obs.median_price * r.quantity
           return total if total > 0 else None
   ```

2. Simplify `src/api/routers/collection.py` `collection_summary` endpoint:
   ```python
   @router.get("/summary", response_model=ApiResponse[CollectionSummary])
   def collection_summary(repo: Repository = Depends(get_db)):
       summary = repo.get_collection_summary(FAKE_USER_ID)
       total_value = repo.get_collection_total_value(FAKE_USER_ID)
       data = CollectionSummary(
           total_unique=summary["total_unique"],
           total_cards=summary["total_cards"],
           total_value=total_value,
           linked_count=summary["linked_count"],
           sets_count=summary["sets_count"],
       )
       return success_response(data=data)
   ```

3. Remove inline imports (`from decimal import Decimal`, `from sqlalchemy import select`, etc.)

4. Run tests: `python -m pytest tests/ -x -q`

# F11-T03 — Extract Shared `_row_to_entry` Helper

- **Wave:** 1
- **Type:** backend
- **Depends on:** F11-T01
- **Status:** done

## User Story

As a developer, I want the `_row_to_entry` conversion function in a single
shared module, so that changes to the mapping are reflected in both the
match report and the sync pipeline.

## Objective

Extract the duplicated `_row_to_entry` function from `match_report.py` and
`sync_collection.py` into a shared `src/collection/converter.py`.

## Implementation Details

1. Create `src/collection/converter.py` with:
   ```python
   from src.collection.matcher import CollectionEntry
   from src.database.models import UserCollectionRow

   def row_to_collection_entry(row: UserCollectionRow) -> CollectionEntry:
       return CollectionEntry(
           set_code=row.set_code,
           collector_number=row.collector_number,
           name_en=row.name_en,
       )
   ```
2. Update `src/collectors/match_report.py`:
   - Remove `_row_to_entry` function (lines 40-46)
   - Add `from src.collection.converter import row_to_collection_entry`
   - Replace `_row_to_entry(row)` → `row_to_collection_entry(row)` (line 106)
3. Update `src/collectors/sync_collection.py`:
   - Remove `_row_to_entry` function (lines 22-28)
   - Add `from src.collection.converter import row_to_collection_entry`
   - Replace `_row_to_entry(row)` → `row_to_collection_entry(row)` (line 89)
4. Run tests: `python -m pytest tests/ -x -q`

# F29-T04: Refresh button on CollectionCardTile

**Status:** planned
**Wave:** 2
**Depends:** T01, T02

## User Story

As a user browsing my collection grid, I want a small refresh icon on each card
tile to quickly update its price.

## Dev Notes

### Files to modify
- `frontend/src/pages/MyCollection.tsx` (CollectionCardTile component)

### Implementation
1. Add a small refresh icon button in the card tile overlay area
2. Position: bottom-right corner of the card image, visible on hover
3. Only show if `card.card_id != null`
4. On click: prevent Link navigation (stopPropagation), call `refreshCardPrice`
5. While loading: show spinning icon
6. On success: update the card's `latest_price` in the parent `cards` state
7. Need to pass an `onRefresh(cardId, newPrice)` callback from MyCollection

### State management
- `MyCollection` needs a callback `handleCardRefresh(entryId, updatedCard)`
- Updates the `cards` array state with new price for the refreshed card

### UX
- Small icon (w-6 h-6), absolute positioned, shown on hover (group-hover)
- Semi-transparent dark background for visibility over card image
- `stopPropagation` to prevent navigating to detail page

## Testing

- Render test: refresh icon visible on hover for linked cards
- Render test: no refresh icon for unlinked cards
- Click test: calls API without navigating
- State update test: price updates in grid after refresh

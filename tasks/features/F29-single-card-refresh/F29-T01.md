# F29-T01: Backend refresh endpoint

**Status:** planned
**Wave:** 1

## User Story

As a backend developer, I need to create a `POST /api/v1/collection/{entry_id}/refresh`
endpoint that fetches the current price from MYP for a single card and stores it.

## Dev Notes

### Files to modify
- `src/api/routers/collection.py` — new endpoint

### Implementation
1. Add `POST /{entry_id}/refresh` route (auth required via `require_auth_or_api_key`)
2. Load the collection entry via `repo.get_collection_entry(entry_id)`
3. Verify `entry.user_id == user_id` (IDOR protection)
4. If `entry.card_id is None`, return 422 ("Card not linked to a source")
5. Get source cards via `repo.get_source_cards_for_card(entry.card_id)`
6. Filter for `source == "myp"` — if none, return 422
7. Instantiate `MypCardsProvider`, call `fetch_current_price(external_id, slug)`
8. If price returned, insert `HistoricalPrice` observation via `repo.insert_price_observations()`
9. Return updated card detail (reuse `get_collection_entry` logic)
10. Close provider after use

### Response schema
Reuse existing `CollectionCardDetail` schema wrapped in `ApiResponse`.

### Error cases
- 404: entry not found or not owned by user
- 422: card not linked or no MYP source

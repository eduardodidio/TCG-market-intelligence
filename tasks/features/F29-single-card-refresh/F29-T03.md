# F29-T03: Refresh button on CollectionCardDetail

**Status:** planned
**Wave:** 2
**Depends:** T01, T02

## User Story

As a user viewing a card's detail page, I want a refresh button next to the
price that fetches the latest price from MYP.

## Dev Notes

### Files to modify
- `frontend/src/pages/CollectionCardDetail.tsx`

### Implementation
1. Add a refresh icon button next to the "Latest Price" display
2. Only show if `entry.card_id != null` (linked card)
3. On click: call `refreshCardPrice(entryId, { currency })`
4. While loading: show spinning icon, disable button
5. On success: update `entry` state with returned data (new price)
6. On error: show inline error text briefly (auto-dismiss after 3s)
7. Use a small circular button with a refresh SVG icon

### UX
- Button: small (w-8 h-8), rounded, slate-700 bg, hover slate-600
- Icon: 16px refresh/sync SVG, cyan-400 color
- Loading: same icon with `animate-spin`
- Success: brief green flash on price text

## Testing

- Render test: button visible when card_id present
- Render test: button hidden when card_id null
- Click test: calls API and updates price
- Loading state test: spinner shown during fetch

# F29-T05: Refresh button on DeckCardTile

**Status:** planned
**Wave:** 2
**Depends:** T01, T02

## User Story

As a user viewing a deck, I want to refresh individual card prices from the
deck view.

## Dev Notes

### Files to modify
- `frontend/src/components/DeckCardTile.tsx`

### Implementation
1. Check if the DeckCardTile has a `collection_entry_id` (linked to collection)
2. If yes, add a small refresh icon (same pattern as CollectionCardTile)
3. On click: call `refreshCardPrice(collection_entry_id)`
4. While loading: spinning icon
5. On success: update the card's price in deck state via callback

### Considerations
- Deck cards may not all be in the user's collection
- Only cards with a `collection_entry_id` can be refreshed
- Check the DeckDetail type to confirm available fields

## Testing

- Render test: refresh icon for cards with collection link
- Render test: no refresh icon for non-collection cards
- Click test: calls API and updates displayed price

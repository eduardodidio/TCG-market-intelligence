**Status:** planned
**Wave:** 1 (depends on T01 — RoutePrefixContext must be deleted first)
**Type:** frontend

## User Story

As a user, I want all navigation links and breadcrumbs to work correctly
with hardcoded paths (no route prefix), now that V2 has been removed.

## Dev Notes

### What to change (21 page files)

For each file, apply these mechanical transformations:

1. **Remove import**: Delete `import { useRoutePrefix } from "../contexts/RoutePrefixContext";`
2. **Remove hook call**: Delete `const prefix = useRoutePrefix();`
3. **Revert template literals**: Change `` `${prefix}/path` `` back to `"/path"`
4. **Revert navigate calls**: Change `navigate(\`${prefix}/path\`)` to `navigate("/path")`
5. **Revert Link `to` props**: Change `` to={`${prefix}/path`} `` to `to="/path"`
6. **Revert Breadcrumb `to` props**: Change `` to: `${prefix}/` `` to `to: "/"`

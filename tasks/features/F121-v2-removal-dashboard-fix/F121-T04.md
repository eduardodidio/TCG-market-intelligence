# F121-T04: Verify classic layout — build + tests

**Status:** planned
**Wave:** 1
**Type:** frontend + backend

## User Story

As a developer, I want to verify that the classic layout is fully functional
after removing V2 code and that all existing tests pass.

## Dev Notes

### Verification steps

1. **Frontend build**: `cd frontend && npm run build` — must succeed with zero errors
2. **Frontend tests**: `cd frontend && npm test` — all tests must pass
   - V2-specific test files were already deleted in T01
   - Any test that imported V2 components or RoutePrefixContext will fail
     and needs fixing (likely just removing V2-related test cases)
3. **Backend tests**: `pytest tests/ --cov=src` — all tests must pass
4. **Grep audit**: Confirm no V2 references remain:
   ```bash
   grep -r "LayoutV2\|DashboardV2\|CollectionV2\|RoutePrefixContext\|useRoutePrefix\|/v2" frontend/src/
   ```
   (Should return zero hits, excluding comments/docs)

### Expected test fixes

- Tests that mock or import `RoutePrefixContext` will need the mock removed
- Tests that render components with `RoutePrefixProvider` wrapper will need
  the wrapper removed
- Any snapshot tests referencing V2 will need snapshot updates

## Testing

- [ ] `npm run build` succeeds

- [ ] `pytest tests/` — all tests pass

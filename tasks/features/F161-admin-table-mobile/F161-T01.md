# F161-T01: Wrap admin tables in overflow-x-auto

**Feature:** F161 — Admin Table Mobile Overflow
**Wave:** 0
**Status:** planned

## User Story

As an admin on mobile/tablet, I want to scroll admin tables horizontally
instead of having content clipped.

## Dev Notes

### Current State

4 admin tables have parent containers with `overflow-hidden` (clips)
instead of `overflow-x-auto` (scrolls). The correct pattern already
exists in AdminPriceRequestsSection, ScheduleTable, ScanHistoryTable.

### Implementation

For each table, wrap it in `<div className="overflow-x-auto">`:

1. **AdminPanel.tsx** (users table, line ~535):
   Change the parent `overflow-hidden` to include `overflow-x-auto` on
   the table wrapper, or add an inner wrapper.

2. **AdminAuditLogSection.tsx** (line ~134):
   Wrap `<table>` in `<div className="overflow-x-auto">`

3. **AdminErrorsSection.tsx** (line ~284):
   Wrap `<table>` in `<div className="overflow-x-auto">`

4. **AdminLigaSection.tsx** (line ~246):
   Wrap `<table>` in `<div className="overflow-x-auto">`

### Files
- `frontend/src/pages/AdminPanel.tsx`
- `frontend/src/components/admin/AdminAuditLogSection.tsx`
- `frontend/src/components/admin/AdminErrorsSection.tsx`
- `frontend/src/components/admin/AdminLigaSection.tsx`

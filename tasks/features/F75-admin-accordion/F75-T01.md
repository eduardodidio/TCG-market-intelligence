# F75-T01 — AccordionSection Component + AdminPanel Refactor

**Status:** planned
**Wave:** 2
**Depends on:** F74

## User Story

As an admin, I want the admin panel organized in collapsible accordion sections so I can focus on one area at a time without navigating between pages.

## Dev Notes

### Files to create/modify

1. **`frontend/src/components/AccordionSection.tsx`** (NEW)
   ```typescript
   interface AccordionSectionProps {
     title: string;
     icon?: React.ReactNode;  // optional icon before title
     defaultOpen?: boolean;
     isOpen: boolean;
     onToggle: () => void;
     children: React.ReactNode;
   }
   ```
   - Header: clickable bar with title + chevron icon (rotates when open)
   - Styling: `bg-slate-800 border border-slate-700 rounded-lg mb-2`
   - Header: `px-4 py-3 flex justify-between items-center cursor-pointer hover:bg-slate-700/50`
   - Content: conditionally rendered with smooth transition (or simple show/hide)
   - Chevron: `transition-transform duration-200` rotate-180 when open

2. **`frontend/src/pages/AdminPanel.tsx`** (MAJOR REFACTOR)
   - Replace tab-based layout with accordion layout
   - State: `const [openSection, setOpenSection] = useState<string | null>("users")`
   - Toggle handler: `const toggle = (id) => setOpenSection(prev => prev === id ? null : id)`
   - Render 5 AccordionSection components (initially just Users + Dashboard, T02 adds the rest)
   - Extract Users section content into `AdminUsersSection` component
   - Extract Dashboard section content into `AdminDashboardSection` component

### Key decisions
- Single-open accordion (only one section visible at a time) — cleaner, prevents page from being too long
- Default open: "users" section
- Each section manages its own data loading (lazy — only fetch when opened)

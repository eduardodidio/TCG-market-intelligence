# F75-T03 — Nav Cleanup + Route Consolidation

**Status:** planned
**Wave:** 2
**Depends on:** F75-T02

## User Story

As a user, I don't want to see admin-only navigation items (Scans, Schedules, Liga Status) as separate nav entries — they should only appear inside the admin panel.

## Dev Notes

### Files to modify

1. **`frontend/src/components/Layout.tsx`** — Update NAV_ITEMS:
   - Remove standalone entries for `/scans`, `/schedules`, `/admin/liga-status`
   - Keep `/admin` as the single admin nav item
   - Ensure `/admin` has `requiresAdmin: true`

2. **`frontend/src/App.tsx`** — Route changes:
   - Remove or redirect old routes:
     - `/admin/liga-status` → redirect to `/admin` (or remove entirely)
     - `/schedules` → redirect to `/admin`
     - `/scans` → redirect to `/admin`
   - Keep `/admin` route pointing to AdminPanel
   - Option: keep old routes as redirects for bookmarks (`<Navigate to="/admin" />`)

3. **Cleanup** — Delete or keep as dead code (prefer delete):
   - `frontend/src/pages/AdminLigaStatus.tsx` → content moved to AdminLigaSection
   - `frontend/src/pages/Schedules.tsx` → content moved to AdminSchedulesSection
   - `frontend/src/pages/Scans.tsx` → content moved to AdminScansSection

### Key decisions
- Old routes redirect to /admin (graceful for bookmarks)
- Only `/admin` appears in nav sidebar for admin users
- Non-admin users see no admin nav items at all
- BanList stays as its own nav item (per user request)

## Testing

- Nav shows single "Admin" item for admin users
- Nav does not show Scans/Schedules/Liga Status as separate items
- Old routes redirect to /admin
- Non-admin users don't see Admin in nav
- BanList still accessible as standalone page

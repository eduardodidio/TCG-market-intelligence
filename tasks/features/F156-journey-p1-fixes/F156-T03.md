# F156-T03: Admin scan confirmation + loading feedback

**Feature:** F156c — Add confirmation modal and progress to admin operations
**Wave:** 0
**Status:** planned

## User Story

As an admin, I want a confirmation before triggering scans and visible
progress feedback, so I don't accidentally start long operations.

## Dev Notes

### Current State

`AdminOperationsSection.tsx`:
- `handleLigaScan()` (line 28): fires immediately on click, shows "Please Wait"
  text on button, then result/error. No confirmation, no progress.
- `handleCatalogScan()` (line 41): same pattern.
- Backend returns `scan_id` but no progress polling exists.

### Implementation

1. **Confirmation step**: Before `handleLigaScan` and `handleCatalogScan`,
   show a simple `window.confirm()` or inline confirmation panel:
   ```tsx
   const handleLigaScanClick = () => {
     if (!window.confirm(t("admin.ops.confirmLigaScan"))) return;
     handleLigaScan();
   };
   ```

2. **Enhanced loading state**: Replace "Please Wait" with animated spinner
   + descriptive text:
   ```tsx
   {ligaLoading && (
     <div className="flex items-center gap-2 mt-2 text-sm text-cyan-400">
       <div className="h-4 w-4 border-2 border-cyan-400 border-t-transparent rounded-full animate-spin" />
       {t("admin.ops.scanRunning")}
     </div>
   )}
   ```

3. **i18n keys**: Add `admin.ops.confirmLigaScan`, `admin.ops.confirmCatalogScan`,
   `admin.ops.scanRunning`.

### Files
- `frontend/src/components/admin/AdminOperationsSection.tsx` — confirmation + spinner
- `frontend/src/i18n/locales/en.json` — new keys
- `frontend/src/i18n/locales/pt-BR.json` — new keys

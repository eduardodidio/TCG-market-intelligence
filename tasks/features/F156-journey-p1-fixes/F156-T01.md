# F156-T01: Web search "Added" → link to collection

**Feature:** F156a — Add navigation after web search add-to-collection
**Wave:** 0
**Status:** planned

## User Story

As a user who just added a card via web search, I want a clear link
to view it in my collection, so I don't have to navigate manually.

## Dev Notes

### Current State

`Cards.tsx` line 277: `handleAddToCollection()` calls `POST /collection/batch`,
on success sets `addedIdxs` which changes button text to hardcoded "Added".
No toast, no link, no navigation.

### Implementation

1. After successful add, show a brief inline link under the "Added" button:
   ```tsx
   {addedIdxs.has(idx) && (
     <Link to="/collection" className="text-xs text-cyan-400 hover:underline">
       {t("cards.viewInCollection")}
     </Link>
   )}
   ```

2. Also fix the hardcoded "Added" text → `t("cards.added")`.

### Files
- `frontend/src/pages/Cards.tsx` — add Link + fix i18n
- `frontend/src/i18n/locales/en.json` — add `cards.added`, `cards.viewInCollection`
- `frontend/src/i18n/locales/pt-BR.json` — same

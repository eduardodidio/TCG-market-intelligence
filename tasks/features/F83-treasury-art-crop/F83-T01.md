# F83-T01 — Crop treasure image to art-only in TreasureTokenCard

**Wave:** 0
**Status:** done

## User Story

As a user, when I see the "Gastar Fichas de Tesouro" confirmation modal, I want to see only the treasure artwork (not the full MTG card frame with header/footer text bars) so the visual is clean and focused on the art.

## Dev Notes

### Problem
`TreasureTokenCard.tsx` line 27 uses `object-contain` which shows the full card image including:
- Top: "TREASURE" / "TESOURO" name bar (part of the image file, not HTML)
- Bottom: "Token Artifact — Treasure" type line (part of the image file, not HTML)

The HTML-rendered card frame (lines 19-20 name bar, lines 40-42 type line, lines 44-46 text box) are separate from the image — those are fine. The issue is the **image itself** contains card frame elements.

### Solution
Use `object-cover` with `object-position` to crop the image to the art-only area (center portion). The treasure art sits roughly in the center 60% of the card image vertically.

**File:** `frontend/src/components/TreasureTokenCard.tsx`
- Line 27: Change `className="w-full object-contain"` to `className="w-full h-36 object-cover object-center"`
- The `h-36` constrains height and `object-cover` + `object-center` crops the top/bottom card frame portions, showing only the central art area
- Fine-tune the `object-position` if needed (e.g., `object-[center_45%]`) to better frame the treasure pile art

### Files to modify
- `frontend/src/components/TreasureTokenCard.tsx` — image className change

### Files NOT to modify
- `TreasureModal.tsx` — full-screen modal should still show full card
- `TreasureBalance.tsx` — sidebar already uses `object-cover` with `h-16`
- `CreditConfirmModal.tsx` — no changes needed (just renders TreasureTokenCard)

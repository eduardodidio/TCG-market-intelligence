# F163-T01: MyCollection action buttons → mobile dropdown

**Feature:** F163 — Mobile Filter Drawer
**Wave:** 0
**Status:** planned

## User Story

As a mobile user on MyCollection, I want the filter bar to take less
vertical space so I can see more of my cards.

## Dev Notes

### Current State

MyCollection has ~12 inline filter controls taking 180-250px on mobile:
- Row 1: Search + Sort (~44px)
- Row 2: SetIconFilter (~48px)
- Row 3: Acquisition filter (~40px)
- Row 4: Action buttons (select, import, add, canonize, refresh) (~44-88px)

### Implementation

Collapse action buttons into a "More" dropdown on mobile:

1. Wrap action buttons in `hidden sm:flex` (hidden on mobile)
2. Add a mobile-only dropdown button (`sm:hidden`):
   ```tsx
   <div className="sm:hidden relative">
     <button onClick={() => setActionsOpen(!actionsOpen)} className="...">
       <EllipsisIcon /> {t("common.actions")}
     </button>
     {actionsOpen && (
       <div className="absolute right-0 top-full mt-1 bg-slate-800 border border-slate-600 rounded-lg shadow-lg z-20 p-2 min-w-48">
         {/* Same action buttons, stacked vertically */}
       </div>
     )}
   </div>
   ```

This removes ~44-88px from the mobile filter bar (saves 1-2 rows).
Desktop layout unchanged.

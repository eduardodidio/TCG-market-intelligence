## Implementation details
Architecture stub:
```mermaid
flowchart LR
  subgraph Local["Windows local machine"]
    BAT["bats/fetch-news.bat"] --> CLI["src/cli/news_cmd.py\nfetch-news"]
    CLI --> SVC["news_fetcher.fetch_news\nhttpx + ElementTree"]
  end
  FEEDS[("RSS/Atom feeds\nWizards, Scryfall, MTGGoldfish, EDHREC, HotC")] -->|GET| SVC
  SVC -->|upsert_news_item| NEON[("Neon PostgreSQL\nnews_items / user_news_reads")]
  subgraph Render["Render (read-only)"]
    API["routers/news.py\nGET /news, /news/status, /unread-count"] --> REPO["Repository"]
  end
  REPO --> NEON
  UI["NewsPage.tsx"] -->|fetchNews / fetchNewsStatus| API
```
Journey: two swimlanes — **Owner (local)**: run `.bat` → sources ok? (all fail → `[FAIL]`, check `--check-sources`) → items stored. **Reader (web)**: open /news → loading → error? (banner + retry) → total 0? (no-data state) → unread empty? (all-read → show all) → grid → click → opens source + mark read; stale hint if >72 h.

## User Story
As a reader, I want the News page to tell me clearly whether nothing has been collected, whether I've read everything, or whether something failed, so that an empty page never looks broken.

## Objective
Add `fetchNewsStatus` to the API client and implement the state matrix + freshness line in `NewsPage.tsx`.

## Implementation details
- `frontend/src/api/news.ts`: `NewsStatus` interface + `fetchNewsStatus()`.
- `NewsPage.tsx`: state priority loading → error → no-data (`total_items === 0`, hide tabs/chips) → filter-empty (unread: all-read + "show all"; else filter-empty + "clear filters") → grid. Freshness line under `<h1>`, stale if `last_fetched_at` older than 72 h (`STALE_HOURS = 72`).
- Keep `formatRelativeDate` and all existing `data-testid`s.

## Test scenarios
- No data: status `total_items: 0`, list empty → `news-no-data`, tabs hidden.
- All read: status `total_items: 5`, unread list empty → `news-all-read`; click `news-show-all` → `fetchNews` called with `filter: "all"`.
- Filter empty: category `ban` empty with total > 0 → `news-filter-empty`; clear → category `""`, filter `all`.
- Error: `fetchNews` rejects → `ErrorBanner` shown, retry calls again.
- Status error: `fetchNewsStatus` rejects, list has items → grid shown, no freshness line.
- Stale boundary: `last_fetched_at` 71 h ago → no `news-stale`; 73 h ago → `news-stale`.
- Regression: existing grid/pagination/mark-unread tests still pass.

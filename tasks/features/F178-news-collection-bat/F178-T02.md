# F178-T02 — Rewrite news fetcher with httpx + stdlib XML

- **Wave:** 1
- **Type:** backend
- **Depends on:** F178-T01
- **Status:** planned

## User Story
As the site owner, I want the news collector to run without undeclared dependencies and report per-source health, so that I can collect news reliably and see which feeds are broken.

## Objective
Replace `feedparser` in `src/services/news_fetcher.py` with `httpx` + `xml.etree.ElementTree`, add `parse_feed`, `fetch_feed`, `load_sources`, `dry_run`, and a per-source report.

## Dev Notes
Veja `_brief/00-overview.md`, `_brief/01-diagnosis.md` e `_brief/02-fetcher.md`.
- Keep `_clean_summary`, `_categorize` untouched (existing tests).
- `_extract_image` / `_parse_date` currently take feedparser entries; replace them with ElementTree-based helpers and update/remove their tests accordingly (they are private).

## Implementation details
- `class FeedParseError(Exception)`
- `@dataclass(frozen=True) class FeedEntry: title: str; link: str; summary: str | None; image_url: str | None; published_at: datetime | None`
- `def parse_feed(xml_bytes: bytes) -> list[FeedEntry]` — RSS 2.0 + Atom (see shard). Entries with a missing title or link ARE returned (with `""`), and `fetch_news` counts them as `skipped`. This keeps the existing stats semantics.
- `def fetch_feed(url: str, *, client: httpx.Client) -> bytes`
- `def load_sources() -> list[dict[str, str]]` — `NEWS_FEED_SOURCES` env or `SOURCES`.
- `def fetch_news(repo, *, max_per_source=20, sources=None, dry_run=False, client=None) -> dict` — returns shape in shard, includes `sources` list.

## Testing
- Framework: pytest. Command: `pytest tests/services/test_news_fetcher.py --cov=src.services.news_fetcher --cov-report=term-missing`.
- Mock HTTP with `httpx.Client(transport=httpx.MockTransport(handler))` — no network, no new deps. Load fixtures from `tests/fixtures/news/`.
- Repository: real SQLite `Repository(db_url="sqlite:///" + str(tmp_path / "t.db"))` as the existing tests do.

## Test scenarios
- Happy: RSS fixture → 3 stored (D skipped), categories (`ban` for item A), images from enclosure / media:content / media:thumbnail; Atom fixture → 3 stored, alternate link preferred.
- Idempotency: running twice → second run `new == 0`, `skipped == N`.
- Dates: `+0000` and `-0300` both stored as naive UTC; bad date → `None`; Atom `updated` fallback.
- Error: 403 → source `ok=False, http_status=403`; `httpx.TimeoutException` → `ok=False, http_status=None, error` set; invalid XML → `FeedParseError` captured as source error; other sources still processed.
- Boundary: `max_per_source=1`; payload > 5 MB; empty channel (0 items) → `ok=True, entries=0`.
- `load_sources`: env with 2 valid pairs; malformed pair skipped; empty env → defaults.
- `dry_run`: `repo=None`, `sources[*].entries` filled, DB untouched.

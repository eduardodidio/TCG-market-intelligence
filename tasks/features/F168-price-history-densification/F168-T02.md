## User Story

As an admin, I want a CLI command and an API endpoint to trigger the
daily price snapshot, so that I can run it manually or schedule it via
Task Scheduler / cron.

## Objective

Add `snapshot-prices` CLI command and `POST /api/v1/admin/jobs/snapshot-prices`
endpoint that both call `run_daily_snapshot()` from T01.

## Dev Notes

### CLI command

Add to `src/cli/main.py`:

```python
@cli.command("snapshot-prices")
@click.option("--db", default=None, callback=_resolve_db, ...)
def snapshot_prices(db):
    """Record daily price snapshot for all priced cards."""
    from src.collectors.price_snapshot import run_daily_snapshot
    from src.database.repository import Repository

    repo = Repository(db)
    count = run_daily_snapshot(repo)
    click.echo(f"Snapshot complete: {count} new observations recorded.")
```

Follow the existing CLI patterns in `main.py`:
- Use `_resolve_db` callback for `--db` option
- Use structlog for logging
- Print summary to stdout

### Admin API endpoint

Add to `src/api/routers/admin.py`:

```python
@router.post("/jobs/snapshot-prices")
def trigger_snapshot(repo=Depends(get_db), user=Depends(require_admin)):
    from src.collectors.price_snapshot import run_daily_snapshot
    count = run_daily_snapshot(repo)
    return success_response(data={"observations_created": count})
```

Follow the existing pattern from `POST /admin/jobs/process-price-requests`
which is already in the admin router.

### Important

- No credit cost -- this is an internal operation
- Admin-only endpoint (use `require_admin` dependency)
- The endpoint should be fast (< 30s for ~5000 cards) since it only
  reads existing data and bulk-inserts

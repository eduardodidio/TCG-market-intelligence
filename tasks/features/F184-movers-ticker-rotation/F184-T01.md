**Type:** frontend

## User Story

As a user viewing the Dashboard, I want to see my collection's top movers
scrolling automatically at the top of the page, so that I can spot price
movements at a glance without interacting.

## Objective

Create a `MoversTicker` component that fetches collection movers and renders
them as a continuously scrolling horizontal ticker bar, reusing the existing
`animate-ticker` CSS animation pattern from `MarketTicker`.

## Dev Notes

- Pattern to follow: `frontend/src/components/MarketTicker.tsx` (lines 20-44)
  - Uses `animate-ticker` CSS class with `--ticker-duration` CSS variable
  - Duplicates items `[...items, ...items]` for seamless infinite loop
  - `motion-reduce:animate-none motion-reduce:overflow-x-auto` for a11y
  - Pauses on hover via CSS `:hover { animation-play-state: paused }`
- Data source: reuse `fetchCollectionMovers(7, 10, true)` from
  `frontend/src/api/collection.ts:170-181`
- Response shape: `CollectionMoversData.gainers` + `.losers` arrays of
  `CollectionMoverData` (card_id, card_name, set_code, change_pct, change_abs)
- Interleave gainers and losers for visual variety:
  `[gainer1, loser1, gainer2, loser2, ...]`
- Each ticker item shows: card name (truncated), change_pct with sign,
  colored green (gainers) or red (losers), small arrow indicator
- Existing `animate-ticker` keyframe in `frontend/src/index.css` — reuse as-is
- i18n: add `movers.tickerAriaLabel` key
- Component should return `null` when loading or data is empty (same as MarketTicker)

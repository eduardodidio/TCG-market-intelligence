# F184-T02 — Dashboard Integration

**Wave:** 1
**Type:** frontend
**Depends on:** F184-T01
**Status:** done

## User Story

As a user, I want the movers ticker to appear at the top of my Dashboard
automatically, so that I see market highlights as soon as the page loads.

## Objective

Integrate the `MoversTicker` component into `Dashboard.tsx`, positioned above
the hero header and KPI cards.

## Dev Notes

- File to edit: `frontend/src/pages/Dashboard.tsx`
- Place `<MoversTicker />` right after the `{showWelcome && <WelcomeBanner />}`
  block (line 105), before the hero header `<div className="mb-8">` (line 108)
- The ticker should be outside the loading gate — it fetches its own data
  independently (same pattern as `MarketTicker` in the Layout)
- Import: `import { MoversTicker } from "../components/MoversTicker";`
- No props needed — component self-fetches with defaults (days=7, limit=10,
  investmentOnly=true)
- Add `mb-4` wrapper for spacing between ticker and hero

## Implementation Details

### Edit: `frontend/src/pages/Dashboard.tsx`

```tsx
// After WelcomeBanner, before hero header:
<div className="mb-4">
  <MoversTicker />
</div>
```

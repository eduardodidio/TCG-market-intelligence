# F22-T07: Frontend AuthContext + Auth API Client

- **Wave:** 4
- **Status:** done
- **Depends on:** F22-T05
- **Type:** frontend

## Description

Create the React authentication context and API client functions that
the rest of the frontend will consume.

### `frontend/src/api/auth.ts`

- `login(email: string, password: string): Promise<AuthResponse>`
  - `POST /api/v1/auth/login`
- `register(email: string, password: string, displayName?: string): Promise<AuthResponse>`
  - `POST /api/v1/auth/register`
- `refreshToken(): Promise<AuthResponse>`
  - `POST /api/v1/auth/refresh` (sends refresh token from cookie)
- `logout(): Promise<void>`
  - `POST /api/v1/auth/logout`
- `fetchMe(): Promise<UserProfile>`
  - `GET /api/v1/auth/me`
- `getOAuthUrl(provider: string): string`
  - Returns `/api/v1/auth/{provider}` URL for redirect

### `frontend/src/types/api.ts`

Add types:
- `UserProfile { id, email, display_name, avatar_url, auth_provider }`
- `AuthResponse { access_token, refresh_token, token_type, expires_in, user }`

### `frontend/src/contexts/AuthContext.tsx`

- `AuthProvider` component wrapping the app
- State: `user: UserProfile | null`, `isAuthenticated: boolean`,
  `isLoading: boolean`
- On mount: attempt `fetchMe()` to restore session from cookie
- `login(email, password)`: calls API, sets user state
- `logout()`: calls API, clears user state
- `loginWithProvider(provider)`: redirects to OAuth URL
- Context value: `{ user, isAuthenticated, isLoading, login, logout, loginWithProvider }`

### `frontend/src/hooks/useAuth.ts`

- `useAuth()` hook: `useContext(AuthContext)` with error if outside provider

### `frontend/src/api/client.ts` Changes

- Add `Authorization: Bearer <token>` header if token available
- On 401 response: attempt token refresh; if refresh fails, clear auth
  state and redirect to `/login`

## Acceptance Criteria

- [ ] `AuthProvider` wraps the app and provides auth state
- [ ] `useAuth()` hook returns user, isAuthenticated, isLoading
- [ ] Login function calls API and updates state
- [ ] Logout function clears state and cookies
- [ ] OAuth login redirects to provider URL
- [ ] API client attaches auth token to requests
- [ ] 401 responses trigger token refresh or redirect to login
- [ ] All existing frontend tests pass

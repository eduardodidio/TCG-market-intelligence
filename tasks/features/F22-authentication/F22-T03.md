# F22-T03: Repository User CRUD Methods

- **Wave:** 1
- **Status:** done
- **Depends on:** F22-T01
- **Type:** backend

## Description

Add user CRUD methods to `src/database/repository.py` so that auth
endpoints can create, find, and update user records.

### Methods to Add

- `create_user(email: str, display_name: str | None, auth_provider: str, provider_id: str | None, password_hash: str | None) -> UserRow`
  - Inserts a new user; raises if email already exists
- `get_user_by_id(user_id: int) -> UserRow | None`
- `get_user_by_email(email: str) -> UserRow | None`
- `get_user_by_provider(provider: str, provider_id: str) -> UserRow | None`
  - Finds user by OAuth provider + external ID
- `update_user(user_id: int, **kwargs) -> UserRow | None`
  - Updates display_name, avatar_url, etc.
- `link_provider(user_id: int, provider: str, provider_id: str) -> None`
  - If a user registered via email and later logs in via Google with
    the same email, link the provider_id (update the existing row)
- `migrate_collection_user(old_user_id: str, new_user_id: str) -> int`
  - Updates `user_collection.user_id` from old to new; returns count

## Acceptance Criteria

- [ ] `create_user` inserts row and returns it with populated `id`
- [ ] `create_user` with duplicate email raises or returns error
- [ ] `get_user_by_email` returns None for missing user
- [ ] `get_user_by_provider` matches on (provider, provider_id)
- [ ] `migrate_collection_user` updates all matching rows
- [ ] All existing tests pass

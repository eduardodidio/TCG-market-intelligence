# F22-T04: FastAPI Auth Dependencies

- **Wave:** 2
- **Status:** done

- **Type:** backend

## Description

Create FastAPI dependency functions that extract and validate the
authenticated user from incoming requests. These dependencies will be
injected into protected endpoints.

### `src/auth/dependencies.py`

- `get_current_user(request: Request, repo: Repository = Depends(get_db)) -> User`
  - Extracts JWT from:
    1. `Authorization: Bearer <token>` header (API clients), or
    2. `access_token` httpOnly cookie (browser)
  - Decodes token via `decode_token()`
  - Looks up user in DB via `repo.get_user_by_id()`
  - Raises `HTTPException(401)` if token missing, invalid, expired, or
    user not found / inactive
  - Returns `User` domain object

- `get_optional_user(request: Request, repo: Repository = Depends(get_db)) -> User | None`
  - Same as above but returns `None` instead of raising 401
  - Useful for endpoints that behave differently for logged-in users

- `get_current_user_id(user: User = Depends(get_current_user)) -> str`
  - Convenience: returns `str(user.id)` for use in collection queries

### Update `src/api/deps.py`

- Re-export `get_current_user`, `get_optional_user` from
  `src/auth.dependencies` so existing import patterns work

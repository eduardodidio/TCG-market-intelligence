# F22-T02: Auth Utility Modules (Password Hashing + JWT + OAuth Config)

- **Wave:** 0
- **Status:** done
- **Depends on:** none
- **Type:** backend

## Description

Create the `src/auth/` package with three modules that encapsulate
authentication primitives. These are pure utility modules with no
FastAPI or database dependencies, making them easy to test in isolation.

### `src/auth/__init__.py`

Empty init.

### `src/auth/passwords.py`

- `hash_password(plain: str) -> str` -- bcrypt hash with cost factor 12
- `verify_password(plain: str, hashed: str) -> bool` -- bcrypt verify
- Uses `passlib.context.CryptContext(schemes=["bcrypt"])`

### `src/auth/jwt.py`

- `create_access_token(user_id: int, email: str, extra: dict | None = None) -> str`
  - Payload: `sub` (user_id as str), `email`, `exp` (30 min), `iat`, `type: "access"`
  - Signs with `TCG_JWT_SECRET` env var (fallback to random UUID in dev)
  - Algorithm: HS256
- `create_refresh_token(user_id: int) -> str`
  - Payload: `sub`, `exp` (7 days), `iat`, `type: "refresh"`
- `decode_token(token: str) -> dict`
  - Validates signature + expiry; raises `JWTError` on failure
- Constants: `ACCESS_TOKEN_EXPIRE_MINUTES = 30`, `REFRESH_TOKEN_EXPIRE_DAYS = 7`

### `src/auth/oauth.py`

- `get_oauth_client(provider: str) -> authlib.integrations.starlette_client.OAuth`
- Configuration from env vars: `TCG_{PROVIDER}_CLIENT_ID`, `TCG_{PROVIDER}_CLIENT_SECRET`
- Provider configs for Google, Microsoft, Apple with correct endpoints
- Each provider's `server_metadata_url` for auto-discovery

### New dependencies in `pyproject.toml`

- `authlib>=1.3`
- `passlib[bcrypt]>=1.7`
- `python-jose[cryptography]>=3.3`

## Acceptance Criteria

- [ ] `hash_password` / `verify_password` round-trip works
- [ ] `create_access_token` produces a valid JWT decodable by `decode_token`
- [ ] `create_refresh_token` produces token with `type: "refresh"`
- [ ] Expired token raises error in `decode_token`
- [ ] `get_oauth_client` returns configured OAuth instance

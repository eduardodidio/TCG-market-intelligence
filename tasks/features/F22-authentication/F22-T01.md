# F22-T01: User Database Model + Domain Models

- **Wave:** 0
- **Status:** done
- **Depends on:** none
- **Type:** backend

## Description

Create the `UserRow` SQLAlchemy model and corresponding domain models.
This is the foundation for all authentication work.

### Database: `UserRow` table (`users`)

| Column            | Type         | Notes                                    |
|-------------------|--------------|------------------------------------------|
| id                | Integer PK   | autoincrement                            |
| email             | String(320)  | unique, not null                         |
| display_name      | String(200)  | nullable                                 |
| avatar_url        | String(1000) | nullable                                 |
| auth_provider     | String(20)   | "email", "google", "microsoft", "apple"  |
| provider_id       | String(200)  | external ID from OAuth provider, nullable|
| password_hash     | String(200)  | nullable (null for OAuth-only users)     |
| is_active         | Integer      | default 1 (boolean flag)                 |
| created_at        | DateTime     | default now                              |
| updated_at        | DateTime     | default now, onupdate now                |

Indexes:
- Unique on `email`
- Index on `auth_provider`
- Unique on `(auth_provider, provider_id)` where provider_id is not null

### Domain: `src/domain/models.py`

Add `AuthProvider` enum and `User` dataclass:
- `AuthProvider(str, Enum)`: EMAIL, GOOGLE, MICROSOFT, APPLE
- `User` dataclass: id, email, display_name, avatar_url, auth_provider, is_active

# F22-T09: Frontend Route Guards + Layout Updates

- **Wave:** 5
- **Status:** done
- **Depends on:** F22-T07, F22-T08
- **Type:** frontend

## Description

Add route protection and update the Layout component to reflect real
authentication state.

### `frontend/src/components/ProtectedRoute.tsx`

- Wraps `<Outlet />` (or children)
- If `isLoading`: show `<LoadingSpinner />`
- If `!isAuthenticated`: redirect to `/login?returnTo={currentPath}`
- If authenticated: render children

### `frontend/src/App.tsx` Changes

- Wrap app with `<AuthProvider>`
- Group protected routes under a `<ProtectedRoute>` wrapper:
  - `/collection`
  - `/collection/:id`
  - `/scans`
- Public routes remain unwrapped:
  - `/` (Dashboard)
  - `/cards`, `/cards/:id`
  - `/market/movers`
  - `/login`

### `frontend/src/components/Layout.tsx` Changes

- Remove `FAKE_USER` constant
- Use `useAuth()` to get real user data
- If authenticated:
  - Show user avatar (from `avatar_url` or initials from `display_name`)
  - Show user name
  - Show "Sign Out" button/link
  - Show all nav items including protected ones
- If not authenticated:
  - Show "Sign In" button in place of user section
  - Hide "My Collection" and "Price Scans" from nav (or show them
    greyed out with a lock icon -- developer's choice)

### Nav Item Visibility

Update `NAV_ITEMS` to include an `authRequired` flag:

```typescript
const NAV_ITEMS = [
  { to: "/", label: "Dashboard", authRequired: false },
  { to: "/collection", label: "My Collection", authRequired: true },
  { to: "/cards", label: "Explore Cards", authRequired: false },
  { to: "/market/movers", label: "Market Movers", authRequired: false },
  { to: "/scans", label: "Price Scans", authRequired: true },
];
```

Filter or style nav items based on auth state.

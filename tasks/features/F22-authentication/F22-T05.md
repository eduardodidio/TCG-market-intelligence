# F22-T05: Auth API Router (Login, Register, OAuth, Refresh, Logout)

- **Wave:** 2
- **Status:** done

- **Type:** backend

## Description

Create the `/api/v1/auth` router with all authentication endpoints.

### Endpoints

#### `POST /api/v1/auth/register`
- Body: `{ email, password, display_name? }`
- Creates user with `auth_provider="email"`, hashed password
- Returns JWT tokens (access + refresh) in response body and sets
  httpOnly cookies
- Returns 409 if email already exists

#### `POST /api/v1/auth/login`
- Body: `{ email, password }`
- Verifies credentials
- Returns JWT tokens
- Returns 401 for invalid credentials

#### `GET /api/v1/auth/{provider}` (provider = google|microsoft|apple)
- Redirects to OAuth provider's authorization URL
- Stores `state` and optional `returnTo` in session/query

#### `GET /api/v1/auth/{provider}/callback`
- Handles OAuth callback
- Exchanges code for tokens, fetches user profile
- Creates or links user account (match by email)
- Issues JWT tokens
- Redirects to frontend with tokens set as cookies

#### `POST /api/v1/auth/refresh`
- Body or cookie: refresh token
- Validates refresh token, issues new access token
- Returns 401 if refresh token invalid/expired

#### `POST /api/v1/auth/logout`
- Clears auth cookies
- Returns success

#### `GET /api/v1/auth/me`
- Requires auth (uses `get_current_user`)
- Returns current user profile

### Pydantic Schemas (`src/api/schemas/auth.py`)

- `RegisterRequest(email, password, display_name?)`
- `LoginRequest(email, password)`
- `AuthTokenResponse(access_token, refresh_token, token_type, expires_in, user)`
- `UserProfile(id, email, display_name, avatar_url, auth_provider)`
- `RefreshRequest(refresh_token)`

### Register in `src/api/app.py`

- Import and include auth router with prefix `/api/v1`

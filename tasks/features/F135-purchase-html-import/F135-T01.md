## User Story

As a developer, I need a service that can parse saved HTML files from Nerdz
Cards order pages and Liga Magic "Meus Pedidos" pages to extract structured
card purchase data, so that downstream services can match and import this data
into the user's collection.

## Dev Notes

### Data model (output)

```python
@dataclass
class ParsedPurchaseItem:
    card_name_pt: str | None       # Portuguese name (if bilingual)
    card_name_en: str | None       # English name (if bilingual)
    set_name: str | None           # Full set name from edition icon title
    set_code: str | None           # 3-4 letter set code (e.g. "AFR", "DTK")
    collector_number: str | None   # e.g. "139", "390"
    language: str | None           # "PT" or "EN"
    quality: str | None            # "NM", "SP", "MP", "HP", "D", "L" (Lacrado)
    quantity: int                  # Number of copies purchased
    unit_price: Decimal            # Price per unit in BRL
    is_foil: bool                  # True if extras mention "Foil"
    extras: list[str]              # Raw extras (e.g. ["Promo", "Foil"])
    order_number: str              # e.g. "#9117259", "#MP1247013"
    order_date: date | None        # Parsed from order header
    store_name: str                # "Nerdz Cards" or store name from Liga
    source_file: str               # Filename for traceability

@dataclass
class ParsedOrder:
    order_number: str
    order_date: date | None
    store_name: str
    items: list[ParsedPurchaseItem]
    source_file: str
```

### Nerdz Cards parser (`parse_nerdz_order`)

1. **Detect format**: Check `<title>` contains "Nerdz Cards".
2. **Extract order metadata**:
   - Order number: `h3` inside `div.panel-body.panel-order--number` -- text
     like `#9117259`.
   - Order date: `div.panel-order--number` contains a `div > i` with date
     text like `25/08/2025 17:01`. Parse with `datetime.strptime` using
     format `%d/%m/%Y %H:%M`.
3. **Extract card items**: Iterate over `article.panel-order--content` that
   have class `layout-standard` (this excludes the summary article).
   - **Quantity**: First `span.bold` in the article text (e.g. `4x`). Parse
     int from the digits before `x`.
   - **Card name**: `a.link-produto` contains:
     - `span.bold` = PT name (e.g. "Fogo do Dragao")
     - After the closing `</span>`, text ` / English Name` (e.g.
       ` / Dragon's Fire`). If no ` / `, the card is monolingual.
     - If the bold text IS the English name (no PT), treat it as name_en.
   - **Set code + collector number**: `font.input-infoaux` contains text
     like `(Codigo: AFR139)` where `AFR` = set code and `139` (inside
     `<b>`) = collector number. Regex:
     `\(C[oó]digo:\s*([A-Z0-9]+)<b>(\d+[a-z]?)</b>\)` or parse the text
     splitting letters from trailing digits.
   - **Set name**: `img.icon-edicao` `title` attribute.
   - **Unit price**: `p` containing `R$ X,XX (unid.)`. Parse with
     `Decimal(text.replace("R$ ", "").replace(".", "").replace(",", "."))`.
   - **Language**: `img[alt]` where alt is "Portugues" or "Ingles", with
     sibling text "PT" or "EN".
   - **Quality**: `div.icon_qualid` `title` attribute (e.g.
     "Praticamente Nova (NM)"). Extract the code inside parentheses.
   - **Extras**: `span.extras-pedido` text (e.g. "Promo", "Foil").
4. **Skip sealed products**: If no `font.input-infoaux` with `(Codigo: ...)`
   pattern exists, the item is a sealed product -- skip it. Also skip if
   quality is "Lacrado" / "L".

### Liga Magic parser (`parse_liga_orders`)

1. **Detect format**: Check `<title>` contains "LigaMagic" or
   "Meus Pedidos".
2. **Extract order groups**: Each `div.boxshadow.conteudo.box-interna` is an
   order container.
   - **Order date**: `font.titledate` text. Extract date from pattern
     `DD/MM/YYYY HH:MM` using regex
     `(\d{2}/\d{2}/\d{4}\s+\d{2}:\d{2})`.
   - **Order number**: `font.titleorder` text (strip `#`).
3. **Find expanded orders**: Look for `div#meucarrinho` inside each order
   container. If absent (only `loading-itens` div present), skip.
4. **Extract store name**: `div.venda-store label.title` text (first text
   node, before any child elements).
5. **Extract card items**: Inside `div.itens`, each `div.row` (direct
   children with class `row`) is a card item.
   - **Card name**: `p.cardtitle a` or `p[cardtitle] a` text. May be
     bilingual "PT Name / EN Name" or monolingual.
   - **Set code**: `td[editioncard] a` href contains `ed=XXX`. Extract with
     regex `ed=([A-Za-z0-9]+)`. Uppercase it.
   - **Set name**: `img.icon-edicao` `title` attribute, or
     `td.label.hidden-md a` text.
   - **Language**: `td[languagecard] img` `alt` attribute, plus sibling
     `td.label` text for the code.
   - **Quality**: `td[qualitycard]` text content (e.g. "NM").
   - **Quantity**: `div.item-estoque` text (e.g. "1 unid."). Parse int.
   - **Unit price**: `div.item-subpreco` text (e.g. "R$ 9,75"). Parse
     Decimal.

### Bilingual name parsing

Both formats use `"PT Name / EN Name"` or just `"EN Name"`. Logic:
1. Split on ` / ` (space-slash-space).
2. If two parts: first = PT, second = EN.
3. If one part: could be PT or EN. Use heuristic -- if text contains
   accented characters (e.g. `a`, `e`, `i`, `o`, `u` with diacritics), treat
   as PT and leave EN as None. Otherwise treat as EN.
4. Store both when available; the matcher (T02) will try both.

### Price parsing utility

```python
def parse_brl_price(text: str) -> Decimal:
    """Parse 'R$ 1.234,56' into Decimal('1234.56')."""
    cleaned = text.replace("R$", "").strip()
    cleaned = cleaned.split("(")[0].strip()  # remove "(unid.)" suffix
    cleaned = cleaned.replace(".", "").replace(",", ".")
    return Decimal(cleaned)
```

### Auto-detection entry point

```python
def parse_purchase_html(html_content: str, filename: str) -> list[ParsedOrder]:
    """Auto-detect format and parse. Returns list of orders."""
    soup = BeautifulSoup(html_content, "html.parser")
    title = soup.title.string if soup.title else ""
    if "Nerdz Cards" in title or "nerdzcards" in html_content[:2000]:
        return [parse_nerdz_order(soup, filename)]
    elif "LigaMagic" in title or "Meus Pedidos" in title:
        return parse_liga_orders(soup, filename)
    else:
        raise ValueError(f"Unrecognized HTML format in {filename}")
```

## Edge Cases

- Sealed products in Nerdz orders (no set code) -- must be skipped
- Cards with only EN name (e.g. "Belladonna Took") -- no PT name
- Cards with only PT name (unlikely but handle)
- Liga orders not expanded (no card data in HTML) -- skip silently
- Liga file has multiple orders from different stores in the same
  MP order group -- each store sub-order has its own items
- Price text with thousands separator: "R$ 1.234,56"
- Collector number with letter suffix: e.g. "139a"
- Multiple items of the same card at different prices in one order (Nerdz:
  `3x Dragon's Fire @ R$ 0,20` + `1x Dragon's Fire @ R$ 1,00`)
- HTML encoding: `&amp;`, `&#39;`, entity references in card names

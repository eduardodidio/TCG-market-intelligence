## User Story

As a user, I want a page where I can upload my purchase HTML files, see a
preview of which cards were matched and at what confidence level, selectively
edit or skip individual cards, and then apply the import, so that my
acquisition prices are populated accurately.

### Page flow (3 states)

**State 1: Upload**
- Large drag-and-drop zone (dashed border, icon, "Drop HTML files here or
  click to browse")
- Accept `.html` and `.htm` files only
- Checkbox: "Overwrite existing acquisition prices" (default unchecked)
- "Upload & Preview" button (disabled until files selected)
- Show selected file names + sizes in a list with remove buttons
- Loading spinner during upload/parsing

**State 2: Preview**
- Summary bar at top:
  - `{total_items_parsed} items parsed from {total_orders} orders`
  - `{total_items_matched} matched | {total_items_unmatched} unmatched | {total_sealed_skipped} sealed products skipped`
- Warnings section (if any): collapsible, yellow background
- **Matched cards table**:
  - Columns: Select (checkbox), Card Name (parsed), Matched To (collection
    name), Set, Price (editable input), Date, Order #, Store, Confidence
  - Confidence indicator:
    - 1.0: green circle / "Exact"
    - 0.85-0.99: yellow circle / "High"
    - 0.7-0.84: orange circle / "Partial"
  - Already-has-price warning: yellow triangle icon + tooltip "This card
    already has acquisition price R$ X.XX"
  - Row highlight: green for exact, yellow for partial, orange for low
    confidence
  - Each row has a checkbox (pre-checked for confidence >= 0.85, unchecked
    for lower)
  - Price field is editable (user can correct)
  - Select All / Deselect All buttons
  - Filter: show only unconfirmed, show only with existing price
- **Unmatched cards section** (collapsible):
  - Simple list with card name, price, order, and skip reason
  - No action needed -- informational only
- **Action buttons**:
  - "Apply Selected ({count})" -- primary button
  - "Back to Upload" -- secondary button
  - "Export Preview as CSV" -- tertiary (optional, nice to have)

**State 3: Result**
- Success banner: `{total_applied} acquisition prices updated`
- If any skipped: list of skipped cards with reasons
- "Import More" button to go back to State 1
- "Go to Collection" link

### Confidence badge component

```tsx
function ConfidenceBadge({ confidence, method }: { confidence: number; method: string }) {
  const color = confidence >= 0.95 ? "green" : confidence >= 0.85 ? "yellow" : "orange";
  const label = confidence >= 0.95 ? "Exact" : confidence >= 0.85 ? "High" : "Partial";
  return <span className={`badge badge-${color}`}>{label} ({(confidence * 100).toFixed(0)}%)</span>;
}
```

### Drag and drop implementation

Use native HTML5 drag-and-drop API with `onDragOver`, `onDrop` handlers.
Prevent default to allow drop. Read files via `FileReader` or pass to
`FormData` directly.

```tsx
const handleDrop = (e: React.DragEvent) => {
  e.preventDefault();
  const droppedFiles = Array.from(e.dataTransfer.files).filter(
    f => f.name.endsWith(".html") || f.name.endsWith(".htm")
  );
  setFiles(prev => [...prev, ...droppedFiles]);
};
```

## Edge Cases

- User drops non-HTML files -- show error toast, ignore invalid files
- User drops 0 valid files -- "Upload & Preview" stays disabled
- Empty preview (no matches at all) -- show EmptyState with "No matching
  cards found in your collection"
- Very large preview (100+ matches) -- paginate or virtualize the table
- User edits price to invalid value -- validate before apply
- Network error during upload -- show error toast, keep files selected for
  retry
- Session expires during preview -- redirect to login (existing AuthContext
  handles this)

# F41-T03: Scryfall sync orchestrator

**Status:** planned
**Wave:** 1

## User Story

As an operator, I need a sync process that fetches legality data from Scryfall
and updates the local database, detecting and recording status changes.

## Dev Notes

### Files to create
- `src/collectors/banlist_sync.py`

### Implementation

1. `async def run_banlist_sync(db_url: str, bulk: bool = True, limit: int | None = None) -> BanlistSyncSummary`

2. **Bulk mode** (default, recommended for full sync):
   - Fetch Scryfall bulk data catalog: `GET https://api.scryfall.com/bulk-data`
   - Find the `default_cards` entry, download the NDJSON file
   - Stream-parse line by line (do NOT load entire file into memory)
   - For each card line, extract `set`, `collector_number`, `legalities` dict
   - Match against local CardRow by (set_code, collector_number)
   - Skip cards not in local DB

3. **Per-card mode** (for small updates):
   - Iterate local CardRow entries
   - `GET https://api.scryfall.com/cards/{set}/{number}`
   - Rate limit: 100ms between requests (10 req/s)
   - Extract `legalities` dict from response

4. **Diff logic** (shared by both modes):
   - For each (card_id, format, new_status):
     - Look up existing status from DB
     - If no existing row or status differs: mark as changed
   - Batch upsert all CardLegality records
   - Batch insert LegalityChange records for diffs only
   - Set `effective_date = datetime.now().date()` for changed entries

5. **BanlistSyncSummary** dataclass (add to `src/domain/models.py`):
   - `cards_processed: int`
   - `legalities_upserted: int`
   - `changes_detected: int`
   - `errors: int`
   - `started_at: datetime`
   - `finished_at: datetime | None`

6. Use structlog for progress logging.

### Dependencies
- `httpx` or `curl_cffi` for Scryfall API (Scryfall is not Cloudflare-protected,
  httpx is fine here)
- Repository methods from T02

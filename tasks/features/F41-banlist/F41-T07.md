# F41-T07: Frontend — LegalityBadge + CollectionCardDetail integration

**Status:** planned
**Wave:** 3

## User Story

As a collector, I want to see the legality status of my cards on the card
detail page so I know which formats they are legal in.

## Dev Notes

### Files to create
- `frontend/src/components/LegalityBadge.tsx`

### Files to modify
- `frontend/src/pages/CollectionCardDetail.tsx` — add legality section

### LegalityBadge component

1. Props: `status: string`, `format?: string`, `size?: "sm" | "md"`
2. Color mapping:
   - `legal` -> green (bg-green-900/30 text-green-400 border-green-700)
   - `banned` -> red (bg-red-900/30 text-red-400 border-red-700)
   - `restricted` -> yellow (bg-yellow-900/30 text-yellow-400 border-yellow-700)
   - `not_legal` -> gray (bg-slate-700/50 text-slate-400 border-slate-600)
3. Display format name (capitalized) + status text
4. Small variant for inline use, medium for detail page

### CollectionCardDetail integration

1. When card_id is available, fetch legalities via `fetchCardLegalities(cardId)`
2. Add a "Legality" section below price history
3. Show a grid of LegalityBadge components (one per format)
4. Group by status: show banned/restricted first, then legal, then not_legal
5. Collapsible: show top 6 formats by default, "Show all" expander for rest
6. Loading state while fetching legalities
7. If no card_id (unlinked card), show "Legality data not available" message

### Styling
- Follow existing dark theme: slate-800 surface, slate-700 borders
- Section header: "Format Legality" with scale icon or similar

## Testing

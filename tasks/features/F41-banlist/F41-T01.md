# F41-T01: Data model — DB + domain models

**Status:** planned
**Wave:** 0

## User Story

As a developer, I need the database tables and domain dataclasses for card
legalities and legality history so all other tasks can build on them.

## Dev Notes

### Files to modify
- `src/database/models.py` — add `CardLegalityRow`, `LegalityHistoryRow`
- `src/domain/models.py` — add `CardLegality`, `LegalityChange`, `LegalityStatus` enum

### Implementation

1. Add `LegalityStatus` enum to `src/domain/models.py`:
   - Values: `LEGAL`, `NOT_LEGAL`, `BANNED`, `RESTRICTED` (matching Scryfall)

2. Add `CardLegality` dataclass:
   - `card_id: int`
   - `format: str`
   - `status: str`
   - `effective_date: date | None = None`

3. Add `LegalityChange` dataclass:
   - `card_id: int`
   - `format: str`
   - `old_status: str | None`
   - `new_status: str`
   - `changed_at: datetime`
   - `source: str = "scryfall_sync"`

4. Add `CardLegalityRow` SQLAlchemy model:
   - PK: `id` (autoincrement)
   - `card_id` INTEGER NOT NULL
   - `format` VARCHAR(50) NOT NULL
   - `status` VARCHAR(20) NOT NULL
   - `effective_date` DATE nullable
   - `updated_at` DATETIME (auto-update)
   - UniqueConstraint on (card_id, format)
   - Index on (format, status) for filtered queries

5. Add `LegalityHistoryRow` SQLAlchemy model:
   - PK: `id` (autoincrement)
   - `card_id` INTEGER NOT NULL
   - `format` VARCHAR(50) NOT NULL
   - `old_status` VARCHAR(20) nullable
   - `new_status` VARCHAR(20) NOT NULL
   - `changed_at` DATETIME NOT NULL
   - `source` VARCHAR(50) DEFAULT "scryfall_sync"
   - Index on (card_id, format, changed_at)

6. Verify `Base.metadata.create_all()` picks up new tables (existing pattern).

## Testing

- Unit test: verify both Row classes can be instantiated
- Unit test: verify unique constraint name exists on CardLegalityRow
- Unit test: verify LegalityStatus enum values match Scryfall strings

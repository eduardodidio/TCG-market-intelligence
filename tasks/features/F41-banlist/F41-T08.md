### Diagrams

1. `docs/diagrams/F41-architecture.mmd` — component/data-flow diagram:
   - Scryfall API -> banlist_sync.py -> Repository -> SQLite (card_legalities, legality_history)
   - API router -> Repository -> JSON response
   - Frontend BanList page -> API -> display

2. `docs/diagrams/F41-journey.mmd` — user journey:
   - User opens /banlist -> selects format -> sees banned cards
   - User searches for card -> sees legality status
   - User clicks card -> navigates to detail -> sees legality section
   - Admin triggers sync -> backend fetches from Scryfall -> updates DB

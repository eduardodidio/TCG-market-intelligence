# F41-T05: CLI — banlist-sync command

**Status:** planned
**Wave:** 2

## User Story

As an operator, I need a CLI command to trigger ban list sync from the terminal,
for cron jobs or manual updates.

## Dev Notes

### Files to modify
- `src/cli/main.py` — add `banlist-sync` command

### Implementation

1. Add Click command `banlist_sync`:
   ```
   tcg banlist-sync [--bulk/--no-bulk] [--limit N] [--db-url URL]
   ```

2. Default: `--bulk` (use Scryfall bulk data download)
3. `--no-bulk`: per-card mode (slower, for incremental updates)
4. `--limit N`: process only N cards (for testing)
5. `--db-url`: override database URL (default from env `TCG_DATABASE_URL`)

6. Call `run_banlist_sync()` from `src/collectors/banlist_sync.py`
7. Print summary at end:
   ```
   Banlist sync complete:
     Cards processed: 1234
     Legalities upserted: 15000
     Changes detected: 42
     Errors: 0
     Duration: 2m 30s
   ```

8. Use `asyncio.run()` to call the async sync function (same pattern as
   existing CLI commands).

## Testing

- Unit test: CLI command exists and has expected options
- Unit test: mock sync function, verify it is called with correct args

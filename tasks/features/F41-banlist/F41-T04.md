### Schemas (`src/api/schemas/banlist.py`)

```python
class BanListEntry(BaseModel):
    card_id: int
    name_en: str | None
    name_pt: str | None
    set_code: str | None
    collector_number: str | None
    format: str
    status: str
    effective_date: date | None
    image_url: str | None

class CardLegalitySchema(BaseModel):
    format: str
    status: str
    effective_date: date | None

class LegalityHistoryEntry(BaseModel):
    card_id: int
    name_en: str | None
    format: str
    old_status: str | None
    new_status: str
    changed_at: datetime

class SyncTriggerRequest(BaseModel):
    bulk: bool = True
    limit: int | None = None
```

### Endpoints (`src/api/routers/banlist.py`)

1. `GET /banlist` — list banned/restricted cards
   - Query params: `format` (required), `status` (optional, default shows
     banned+restricted), `limit`, `offset`, `search` (card name)
   - Returns paginated list of `BanListEntry`
   - Public (no auth required)

2. `GET /banlist/formats` — list known formats
   - Returns `list[str]`
   - Public

3. `GET /banlist/card/{card_id}` — all legalities for a card
   - Returns `list[CardLegalitySchema]`
   - Public

4. `GET /banlist/history` — legality change history
   - Query params: `format` (optional), `card_id` (optional), `limit`
   - Returns `list[LegalityHistoryEntry]`
   - Public

5. `POST /banlist/sync` — trigger Scryfall sync
   - Auth required (`require_auth_or_api_key`)
   - Body: `SyncTriggerRequest`
   - Runs sync as background task (same pattern as collection sync)
   - Returns `JobStatus`

### App registration
- Add `from src.api.routers.banlist import router as banlist_router`
- Add `app.include_router(banlist_router, prefix="/api/v1")`

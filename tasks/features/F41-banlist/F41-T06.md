# F41-T06: Frontend — API client + BanList page

**Status:** planned
**Wave:** 3

## User Story

As a user, I want a Ban List page where I can select a format and see which
cards are banned or restricted, with search and status filtering.

## Dev Notes

### Files to create
- `frontend/src/api/banlist.ts` — API client functions
- `frontend/src/pages/BanList.tsx` — ban list page

### Files to modify
- `frontend/src/App.tsx` — add `/banlist` route (public, inside Layout)
- Navigation component — add "Ban List" link

### API client (`frontend/src/api/banlist.ts`)

1. `fetchFormats(): Promise<string[]>` — GET /api/v1/banlist/formats
2. `fetchBanList(params: { format: string; status?: string; search?: string; limit?: number; offset?: number }): Promise<BanListEntry[]>` — GET /api/v1/banlist
3. `fetchCardLegalities(cardId: number): Promise<CardLegality[]>` — GET /api/v1/banlist/card/{id}
4. `fetchLegalityHistory(params: { format?: string; cardId?: number; limit?: number }): Promise<LegalityHistoryEntry[]>` — GET /api/v1/banlist/history
5. Use `apiGet` from `client.ts` (no auth needed for reads)

### BanList page (`frontend/src/pages/BanList.tsx`)

1. Format selector dropdown at top (fetch from `/banlist/formats`)
   - Default to first format in list (or "standard" if available)
2. Status filter: "All" | "Banned" | "Restricted" toggle buttons
3. Search bar: filter by card name (debounced, 300ms)
4. Card list: table or card grid showing:
   - Card image (small, Scryfall URL)
   - Card name (language-aware via `useCardName` pattern)
   - Set code + collector number
   - Status badge (color-coded)
   - Effective date (if available)
5. Click on a card: navigate to `/collection/:id` if in collection, or
   open Scryfall link
6. Pagination: offset-based with "Load more" or page buttons
7. Empty state: "No banned cards in this format" message

### Route registration
- Lazy import in `App.tsx`
- Route: `/banlist` (public, inside `<Route element={<Layout />}>`)
- No ProtectedRoute wrapper (ban list is public info)

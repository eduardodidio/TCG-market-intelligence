# F166-T03 — Frontend: top 5 default + expandable view (top 10 / top 100)

**Status:** planned
**Wave:** 1
**Depends on:** T01 (sanity filters), T02 (limit raised to 100)

## User Story

As a user viewing my collection movers on the Dashboard, I want to see the top 5
by default (instead of top 3), and have buttons to expand to top 10 and top 100
to explore deeper market movements.

## Dev Notes

### Problem
1. `Dashboard.tsx:169` passes `limit={3}` — user wants 5.
2. `CollectionMovers.tsx` has no expand/collapse mechanism — it renders exactly
   what the API returns with no UI to request more.

### Solution

#### Dashboard.tsx
Change line 169:
```tsx
<CollectionMovers days={7} limit={3} investmentOnly />
```
to:
```tsx
<CollectionMovers days={7} limit={5} investmentOnly />
```

#### CollectionMovers.tsx
Add progressive expand with state management:

1. Add state: `const [currentLimit, setCurrentLimit] = useState(limit)` where
   `limit` is the prop (default 5).
2. When `currentLimit` changes, re-fetch from API with new limit.
3. After the movers grid, render expand buttons:
   - If showing 5: show "Ver Top 10" button
   - If showing 10: show "Ver Top 100" button
   - If showing 10 or 100: show "Recolher" (collapse) button to go back to 5
4. Buttons styled as subtle text links (`text-indigo-400 hover:text-indigo-300 text-xs`)
   centered below the grid.

#### API Client
`fetchCollectionMovers()` already accepts `limit` param — no changes needed.

### Implementation Detail

```tsx
// New state
const [currentLimit, setCurrentLimit] = useState(limit);

// Update fetchData to use currentLimit
fetchCollectionMovers(days, currentLimit, investmentOnly)

// Add useEffect dependency on currentLimit
useEffect(() => { fetchData(); }, [fetchData]);
// fetchData already depends on currentLimit via useCallback deps

// Expand buttons after the grid
<div className="flex justify-center gap-3 mt-3">
  {currentLimit < 10 && (
    <button onClick={() => setCurrentLimit(10)} className="text-xs text-indigo-400 hover:text-indigo-300">
      {t("movers.showTop10")}
    </button>
  )}
  {currentLimit >= 10 && currentLimit < 100 && (
    <button onClick={() => setCurrentLimit(100)} className="text-xs text-indigo-400 hover:text-indigo-300">
      {t("movers.showTop100")}
    </button>
  )}
  {currentLimit > limit && (
    <button onClick={() => setCurrentLimit(limit)} className="text-xs text-slate-500 hover:text-slate-400">
      {t("movers.collapse")}
    </button>
  )}
</div>
```

### i18n Keys (pt-BR + en)
- `movers.showTop10`: "Ver Top 10" / "Show Top 10"
- `movers.showTop100`: "Ver Top 100" / "Show Top 100"
- `movers.collapse`: "Recolher" / "Collapse"

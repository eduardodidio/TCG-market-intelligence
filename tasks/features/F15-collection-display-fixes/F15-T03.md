# F15-T03: Add BRL Currency Indicator to Sidebar
- **Wave:** 1
- **Type:** frontend
- **Depends on:** none
- **Status:** planned

## User Story
As a user, I want to see a clear currency indicator (BRL with Brazilian
flag) in the navigation so I always know what currency the displayed
prices are in.

## Objective
Add a currency badge to the sidebar showing "BRL" with the Brazilian flag
emoji. This is a small cosmetic addition to the `Layout.tsx` component.

## Dev Notes

### Current state
- `Layout.tsx` has a sidebar with: app title, user avatar section, nav items.
- All prices use `formatBRL()` which outputs `R$ X.XXX,XX` -- the R$ symbol
  is already present on every price value. No formatting bugs found.
- There is no currency indicator in the sidebar or header.

### Implementation
Add a currency badge below the user section (or at the bottom of the sidebar)
showing the Brazilian flag and "BRL":

```tsx
<div className="flex items-center gap-2 px-6 py-3 border-b border-slate-700">
  <span role="img" aria-label="Brazilian flag">&#127463;&#127479;</span>
  <span className="text-sm font-medium text-slate-300">BRL</span>
</div>
```

Place it in the sidebar after the user avatar section, before the nav items.
This keeps it visible at all times without cluttering the UI.

### Files to change
- `frontend/src/components/Layout.tsx`

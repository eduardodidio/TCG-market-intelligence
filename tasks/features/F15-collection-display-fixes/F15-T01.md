# F15-T01: MYP Variant Set Code Mapping Utility
- **Wave:** 0
- **Type:** frontend + backend
- **Depends on:** none
- **Status:** planned

## User Story
As a developer, I need a mapping from MYP variant set codes to Scryfall-
compatible set codes so that image URLs and other Scryfall integrations
work for borderless, extended art, showcase, and Secret Lair variants.

## Objective
Create a shared mapping utility (frontend + backend) that translates
MYP-specific set codes to standard Scryfall set codes. This is a
foundational piece used by T02 (images) and T04 (detail links).

## Dev Notes

### Known MYP variant set codes (from collection CSV)
These are the non-standard codes found in the CSV `Edicao (Sigla)` column.
Pattern analysis:

| Prefix | Meaning | Examples | Scryfall base |
|--------|---------|----------|---------------|
| `bl*`  | Borderless | `bldmr`, `blfdn`, `bl2x2`, `bltr`, `blltr`, `blb` | Remove `bl` prefix |
| `ex*`  | Extended Art | `exdmu` | Remove `ex` prefix |
| `ea*`  | Extended Art (alt) | `eafic`, `eahoc` | Remove `ea` prefix |
| `sr*`  | Showcase Ring | `srltr` | Remove `sr` prefix |
| `sk*`  | Showcase | `skmh2` | Remove `sk` prefix |
| `fe*`  | Full-art / Etched | `feclb`, `fesnc` | Remove `fe` prefix |
| `sm*`  | Special/Misc | `smbro` | Remove `sm` prefix |
| `cb*`  | Commander Borderless | `cbznr` | Remove `cb` prefix |
| `c*`   | Commander variant | `cthb` | May need `thb` |
| `bb*`  | Bundle/Box promo | `bbfdn` | Remove `bb` prefix |
| `dh*`  | Draft/Hobby | `dhhob` | Remove `dh` prefix |
| `df*`  | Draft variant | `dftdm`, `dft` | Context-dependent |
| `gf*`  | Gift variant | `gftdm` | Remove `gf` prefix |
| `pl*`  | Promo/Prerelease | `pl24`, `pltr` | Context-dependent |
| `vv*`  | Vault/Visual | `vvow` | Remove first `v` |
| `sld*` | Secret Lair Drop | `sld158` | `sld` (keep as-is) |
| `sc*`  | Special Commander | `schob`, `schoc`, `sc9` | Context-dependent |
| `ash*` | Art Series | `ashob` | Context-dependent |

### Approach
1. Build a static lookup table for the ~40 known variant codes
2. For codes not in the table, apply a heuristic: try stripping common
   prefixes (`bl`, `ex`, `ea`, `sr`, `sk`, `fe`, `sm`, `cb`, `bb`, `dh`,
   `gf`, `pl`, `vv`) and check if the remainder is a valid 3-letter set code
3. Return both the mapped set code AND the original collector number
   (Scryfall may use different collector numbers for variants, but the
   same number often works for the base set; the name-based fallback in
   T02 handles cases where it doesn't)

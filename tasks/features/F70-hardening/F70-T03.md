## User Story

As a platform operator, I need CORS to allow only necessary HTTP methods
and MYP refresh to always deduct credits, so that the API surface is
minimal and credit deduction is consistent.

## Problem 1: CORS too permissive

`src/api/app.py:152-153` uses `allow_methods=["*"]`, `allow_headers=["*"]`.
Should whitelist specific methods.

## Problem 2: MYP refresh skips credit deduction

`src/api/routers/collection.py:892-894` only deducts if `price_saved=True`.
Users get unlimited free MYP refresh attempts. Liga always deducts.

## Dev Notes

### CORS fix

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=[o.strip() for o in cors_origins],
    allow_credentials=True,
    allow_methods=["GET", "POST", "PATCH", "DELETE", "OPTIONS"],
    allow_headers=["Authorization", "Content-Type", "X-API-Key", "Accept"],
)
```

### MYP refresh credit fix

Move deduction to AFTER the guard check but BEFORE the fetch attempt,
matching Liga's pattern. Remove the `price_saved` condition:

```python
# Before: deduct only if price_saved (line 892-894)
# After: deduct unconditionally after guard (like Liga)
if not user.is_admin:
    credit_svc.deduct(user.id, CARD_REFRESH_COST, "card_refresh",
                      reference_id=str(entry_id))
```

Also add missing "message" field to MYP 402 response (matching Liga).

## User Story

As a developer, I need reproducible builds and a clean git status
so that `npm install` on different dates yields identical results.

## Problem

1. `node_modules/` not in `.gitignore` — accidentally trackable.
2. `frontend/dist/`, `frontend/.vite/`, `frontend/coverage/` also missing.
3. No `package-lock.json` committed — builds are non-deterministic.
4. `.claude/worktrees/` may pollute git status.

## Dev Notes

### .gitignore additions

Append to existing `.gitignore`:

```
# Frontend
node_modules/
frontend/dist/
frontend/.vite/
frontend/coverage/

# Claude Code
.claude/worktrees/
```

### Lock file

```bash
cd frontend && npm install --package-lock-only
```

Then `git add frontend/package-lock.json`.

### Files to modify

- `.gitignore` — add frontend + Claude entries
- `frontend/package-lock.json` — generate and commit

## Testing

- Manual: `git status` should not show `node_modules/` as untracked
- Manual: `rm -rf frontend/node_modules && npm ci` should succeed with lock file

## Acceptance Criteria

- [ ] `node_modules/` in .gitignore
- [ ] `frontend/dist/`, `frontend/.vite/`, `frontend/coverage/` in .gitignore
- [ ] `.claude/worktrees/` in .gitignore
- [ ] `frontend/package-lock.json` committed
- [ ] `npm ci` works in frontend directory

# F70-T04 — Frontend 401 Handler + Token Security

**Status:** done
**Wave:** 1
**Priority:** P0 (BLOCKING)
**Estimated effort:** Medium
**Review ref:** B04, B05 from full-review-20260827.md

## User Story

As a user, when my session expires I should be automatically redirected
to the login page instead of seeing broken data or error states.

## Problem

1. `frontend/src/api/client.ts` sends JWT on every request but never
   handles 401/403 responses. Expired tokens leave users stuck.
2. JWT stored in `localStorage` is accessible to XSS. While moving to
   httpOnly cookies requires backend changes (out of scope), we can
   mitigate by using `sessionStorage` (cleared on tab close).

## Dev Notes

### 401 Interceptor

Add to each API function (apiGet, apiPost, apiPatch, apiDelete):

```typescript
if (response.status === 401) {
  // Token expired or invalid — force logout
  localStorage.removeItem("tcg_access_token");
  localStorage.removeItem("tcg_refresh_token");
  sessionStorage.removeItem("tcg_access_token");
  window.location.href = "/login";
  return { data: null as T, errors: ["Session expired"] };
}
```

Better: extract to a shared `handleAuthError()` function to avoid duplication.

### Token storage migration

Change from `localStorage` to `sessionStorage` for access token:
- `sessionStorage.setItem("tcg_access_token", token)`
- Keep refresh token in localStorage (survives tab close, needed for re-auth)
- Update all `localStorage.getItem("tcg_access_token")` references

### Refresh attempt before logout

Before redirecting to login, attempt ONE token refresh:

```typescript
async function handleAuthError(): Promise<boolean> {
  const refresh = localStorage.getItem("tcg_refresh_token");
  if (!refresh) {
    clearTokens();
    window.location.href = "/login";
    return false;
  }
  try {
    const res = await fetch(`${API_BASE_URL}/auth/refresh`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ refresh_token: refresh }),
    });
    if (res.ok) {
      const data = await res.json();
      sessionStorage.setItem("tcg_access_token", data.access_token);
      return true; // Retry original request
    }
  } catch { /* fallthrough */ }
  clearTokens();
  window.location.href = "/login";
  return false;
}
```

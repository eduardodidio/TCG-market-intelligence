## User Story

As a user, if an unexpected error occurs in the UI, I should see a
friendly error page instead of a blank screen.

## Problem

1. No React Error Boundary — runtime render errors crash entire app.
2. `useCollectionRefresh.ts:172` has `eslint-disable-line react-hooks/exhaustive-deps`
   on empty dependency array, causing potential scan resume failures.

## Dev Notes

### Error Boundary

Create `frontend/src/components/ErrorBoundary.tsx`:

```tsx
import { Component, type ReactNode } from "react";

interface Props { children: ReactNode; }
interface State { hasError: boolean; error?: Error; }

export class ErrorBoundary extends Component<Props, State> {
  state: State = { hasError: false };

  static getDerivedStateFromError(error: Error): State {
    return { hasError: true, error };
  }

  render() {
    if (this.state.hasError) {
      return (
        <div className="flex flex-col items-center justify-center min-h-screen bg-slate-900 text-slate-200 p-8">
          <h1 className="text-2xl font-bold mb-4">Something went wrong</h1>
          <p className="text-slate-400 mb-6">{this.state.error?.message}</p>
          <button
            onClick={() => window.location.reload()}
            className="px-4 py-2 bg-cyan-600 hover:bg-cyan-500 rounded"
          >
            Reload page
          </button>
        </div>
      );
    }
    return this.props.children;
  }
}
```

Wrap `<App />` in `main.tsx`:

```tsx
<ErrorBoundary>
  <App />
</ErrorBoundary>
```

### useCollectionRefresh fix

Remove `eslint-disable-line` and fix dependency array:

```typescript
// Use a ref instead of state in the effect
const isRefreshingRef = useRef(isRefreshing);
isRefreshingRef.current = isRefreshing;

useEffect(() => {
  // Use isRefreshingRef.current instead of isRefreshing
  // This avoids adding isRefreshing to deps which would cause re-subscription
}, []); // Now genuinely correct: ref doesn't need to be in deps
```

## User Story

As a platform operator, I need trade confirmation to be race-condition-free
so that users are never double-charged when both parties confirm simultaneously.

## Problem

`MarketplaceService.confirm_agreement()` has a TOCTOU vulnerability:

1. Buyer and seller confirm simultaneously
2. Both reach line 189, re-fetch agreement, see both_confirmed=True
3. Both call `_complete_trade()` concurrently
4. Both deduct credits from both parties -> double fee

Additionally, `_complete_trade()` makes 5 separate DB writes (2x credit
deduction, agreement update, interest status update, email lookup) without
a transaction wrapper. Partial failure leaves inconsistent state.

## Dev Notes

### Approach A: Atomic UPDATE with conditional (preferred for SQLite)

Replace the read-check-update pattern with an atomic conditional UPDATE:

```python
def confirm_agreement(self, interest_id: int, user_id: int) -> dict:
    # ... validation unchanged ...

    # Atomic: UPDATE ... SET buyer_confirmed=1 WHERE buyer_confirmed=0
    # Returns rows_affected — if 0, someone else confirmed already
    field = "buyer_confirmed" if is_buyer else "seller_confirmed"
    updated = self.repo.atomic_confirm_agreement(agreement.id, field)
    if not updated:
        raise ValueError("You have already confirmed")

    # Re-fetch and check
    agreement = self.repo.get_trade_agreement(agreement.id)
    if agreement.buyer_confirmed and agreement.seller_confirmed:
        return self._complete_trade(interest, agreement)
    ...
```

### Approach B: Wrap _complete_trade in transaction

```python
def _complete_trade(self, interest, agreement) -> dict:
    with self.repo.transaction() as session:
        # Re-check both_confirmed inside transaction (prevents race)
        fresh = session.get(TradeAgreementRow, agreement.id)
        if fresh.completed_at is not None:
            raise ValueError("Trade already completed")

        fee = interest.estimated_fee
        # Deduct both (will raise ValueError if insufficient)
        self.credit_svc.deduct(interest.buyer_user_id, fee, ...)
        self.credit_svc.deduct(interest.seller_user_id, fee, ...)

        # Update agreement + interest atomically
        fresh.buyer_fee_charged = fee
        fresh.seller_fee_charged = fee
        fresh.completed_at = datetime.now()
        session.commit()

    self.repo.update_trade_interest_status(interest.id, "completed")
    ...
```

### Implementation plan

1. Add `atomic_confirm_agreement(agreement_id, field)` to repository
   - Uses `UPDATE ... WHERE {field}=0` returning rows_affected
2. Add `completed_at IS NOT NULL` guard in `_complete_trade` (idempotency)
3. Wrap credit deduction + agreement update in single session
4. Add `InsufficientCreditsError` catch around `deduct()` ValueError
5. Update `confirm_agreement()` to use atomic confirm

## User Story

As a developer, I need end-to-end integration tests for the full trade
flow so that regressions in the marketplace are caught before deployment.

## Problem

`tests/marketplace/test_router.py` has only 11 stub tests (mostly
negative/error cases). No happy-path integration test covers the full flow:
share -> browse -> interest -> accept -> confirm -> email reveal.

Service-layer tests (27 tests) are excellent but don't exercise the
HTTP layer, auth middleware, or credit integration.

## Dev Notes

### Test scenarios to add

All tests use the FastAPI TestClient with real DB (in-memory SQLite).

1. **Full trade happy path:**
   - User A: share collection (POST /marketplace/share)
   - User B: browse listings (GET /marketplace/listings)
   - User B: express interest (POST /marketplace/interest)
   - User A: accept interest (POST /marketplace/respond/{id})
   - User A: confirm agreement (POST /marketplace/agree/{id})
   - User B: confirm agreement (POST /marketplace/agree/{id})
   - Assert: both emails revealed, credits deducted from both

2. **Insufficient credits (402):**
   - Set user balance to 1 credit
   - Attempt trade on card worth >R$10 (fee=2+)
   - Assert: 402 response with INSUFFICIENT_CREDITS detail

3. **Self-trade prevention:**
   - User A tries to express interest on own shared card
   - Assert: 400 response

4. **Auth required:**
   - All marketplace endpoints without JWT
   - Assert: 401 response

5. **IDOR prevention:**
   - User B tries to accept User A's received interest
   - Assert: 403 or 400 response

6. **Double confirm idempotency:**
   - User A confirms twice
   - Assert: second call returns error, no double charge

- Dry-run mode: query and display count of unlinked entries, exit
- Normal mode: call `bulk_canonize()` from F49-T01, print progress + summary
- Use `asyncio.run()` to run the async bulk canonize function
- Print summary table at end (total/canonized/failed/rate_limited)

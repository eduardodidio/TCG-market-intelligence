# F49-T02: Auto-Canonize Hook on CSV Import

**Status:** done
**Wave:** 1
**Depends on:** F49-T01
**Maps to AC:** AC2

## User Story

As a collector, I want my cards to be automatically linked to MYP price tracking when I import them via CSV, so I don't have to manually canonize each new card.

## Dev Notes

### Modify CSV Import Flow (`src/collection/importer.py`)

Current flow: CSV parse -> create CardRow (name/set/number only) -> create UserCollectionRow -> done.

New flow: CSV parse -> create CardRow -> create UserCollectionRow -> **trigger async canonize for newly created entries**.

Implementation:
1. `import_collection_csv` already returns `ImportResult` with `imported` count
2. After import completes, collect IDs of newly created `UserCollectionRow` entries
3. Return these IDs in an extended result: `ImportResult.new_entry_ids: list[int]`
4. In the API endpoint (`POST /collection/import`), after import, schedule background canonization for `new_entry_ids`

### API Integration (`src/api/routers/collection.py`)

In the import endpoint handler:
- After `import_collection_csv()` returns, launch background task to canonize new entries
- Use `asyncio.create_task()` or `BackgroundTasks` from FastAPI
- Don't block the import response — return immediately with import stats
- Add field to `ImportResult`: `canonize_scheduled: bool = False`

### Sync Collection (`src/collectors/sync_collection.py`)

Already auto-canonizes — no changes needed. Just verify it handles the case where CSV import already created a CardRow (should upsert, not duplicate).

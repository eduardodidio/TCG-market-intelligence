**Status:** done

## User Story

As a collector, I want to canonize all my unlinked cards at once so that I can track prices for my entire collection without clicking each card individually.

## Dev Notes

### Backend Service (`src/collectors/bulk_canonize.py`)

Create `bulk_canonize(engine, user_id, provider, concurrency=3)`:
- Query all `UserCollectionRow` where `card_id IS NULL` for user
- Also include orphans: entries with `card_id` but no matching `SourceCardRow`
- For each entry, reuse the canonize logic from `collection.py:canonize_card`:
  - Extract into a shared function `canonize_single_entry(session, entry, provider)` in a new module or refactor inline
  - Search MYP, match, create CardRow+SourceCardRow, link, fetch price
- Use `asyncio.Semaphore(concurrency)` to limit parallel MYP calls
- Return summary: `{total, canonized, failed, skipped, rate_limited}`
- Log progress via structlog

### API Endpoint (`src/api/routers/collection.py`)

`POST /api/v1/collection/canonize-all`
- Auth required (current user)
- Query params: `limit: int | None = None` (cap for safety)
- Runs bulk canonize as background task (like sync-collection)
- Returns `202 Accepted` with job summary
- Reuse existing background task pattern from sync/scan endpoints

### Schema (`src/api/schemas/collection.py`)

```python
class BulkCanonizeResult(BaseModel):
    total: int
    canonized: int
    failed: int
    skipped: int
    rate_limited: int
```

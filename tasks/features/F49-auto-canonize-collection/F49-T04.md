## User Story

As a collector, I want a "Canonize All" button on my collection page to link all unlinked cards to price tracking at once, with progress feedback.

## Dev Notes

### API Client (`frontend/src/api/collection.ts`)

Add `canonizeAll()`:
- `POST /api/v1/collection/canonize-all`
- Returns `BulkCanonizeResult`

### Collection Page (`frontend/src/pages/MyCollection.tsx`)

Add "Canonize All" button:
- Show only when `summary.linked_count < summary.total_unique` (i.e., unlinked cards exist)
- Button style: amber/yellow (similar to warning — "X cards unlinked")
- On click: call `canonizeAll()`, show loading spinner
- On completion: show toast/banner with results (X canonized, Y failed)
- Refresh collection data after completion

### Unlinked Indicator

- In `CollectionSummary` section, show "X unlinked" count when > 0
- Each unlinked card tile shows subtle indicator (e.g., small unlink icon or dashed border)

### Components

- `BulkCanonizeButton` — button + loading state + result toast
- Reuse existing pattern from `useCollectionRefresh` for progress tracking

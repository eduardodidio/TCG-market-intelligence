# F140-T01 — Fix white corners on card images (CSS)

**Status:** planned
**Wave:** 0
**Depends on:** --

## User Story

As a user, I want card images to have smooth rounded corners without visible
white/dark background bleeding through, so the UI looks polished.

## Dev Notes

### Root Cause

Container elements have `rounded-lg` but their `<img>` children don't,
causing the container's `bg-white` (light mode) or `bg-slate-800` (dark mode)
to show through the rounded corner gap.

### Files to fix

**1. CardImage.tsx** (`frontend/src/components/CardImage.tsx`, line ~40)

Current:
```tsx
className={`w-full h-full object-cover transition-opacity duration-200 ${
  loaded ? "opacity-100" : "opacity-0"
}`}
```

Fix — add `rounded-lg`:
```tsx
className={`w-full h-full object-cover rounded-lg transition-opacity duration-200 ${
  loaded ? "opacity-100" : "opacity-0"
}`}
```

Also fix skeleton (line ~30): change `rounded` to `rounded-lg` to match.

**2. CardTile.tsx** (`frontend/src/components/CardTile.tsx`, line ~251)

Current img:
```tsx
className="w-full h-full object-cover"
```

Fix — add `rounded-t-lg` (only top corners rounded since card info is below):
```tsx
className="w-full h-full object-cover rounded-t-lg"
```

Note: Check if CardTile uses CardImage component or its own img element.
If it uses CardImage, the fix in CardImage.tsx may suffice. If it has its
own img, fix it directly.

**3. DeckCardTile.tsx** (`frontend/src/components/DeckCardTile.tsx`, line ~42)

Current img:
```tsx
className={`w-full h-full object-cover ${!card.in_collection ? "opacity-50" : ""}`}
```

Fix:
```tsx
className={`w-full h-full object-cover rounded-t-lg ${!card.in_collection ? "opacity-50" : ""}`}
```

**4. CatalogPage.tsx** (`frontend/src/pages/CatalogPage.tsx`, line ~210)

Check if CatalogPage uses CardImage component. If so, fix in CardImage
is sufficient. If it has custom img rendering, fix there too.

### Guidance

- Use `rounded-t-lg` if the image is at the TOP of a card with info below
  (so only top corners are rounded, bottom stays square to meet the info section).
- Use `rounded-lg` if the image fills the entire card or is standalone.
- Read each file to confirm the exact structure before applying the fix.

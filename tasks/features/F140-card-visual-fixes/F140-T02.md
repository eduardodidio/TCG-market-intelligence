# F140-T02 — Art card image fallback (Scryfall URL construction)

**Status:** planned
**Wave:** 0
**Depends on:** --

## User Story

As a user viewing "The Arkenstone" art card in my collection, I want to see
the card's artwork instead of a placeholder icon, so I can identify the card
visually.

## Dev Notes

### Root Cause

Art series cards (like `ashob/44a`) are not in Scryfall's bulk data, so
`image_uri` is NULL in the database. The CardImage component shows a
placeholder SVG when `src` is null.

### Investigation Findings

- Card: "The Arkenstone // Seek the Heart (Art Card with Signature)"
- DB: `set_code='ashob'`, `collector_number='44a'`, `image_uri=NULL`
- Scryfall has the regular version at `set_code='hob'`
- `src/utils/set_code_map.py` line 59: `"ashob": "hob"` mapping exists
- Art series set codes follow pattern: `as` + base_set_code (e.g. `ashob` = art series of `hob`)

### Fix approach — Frontend fallback URL

In the components that display card images (CardTile, CatalogPage, or at
the API level), when `image_uri` is NULL, construct a Scryfall fallback URL.

**Option A — API level** (preferred, benefits all consumers):

In `src/api/routers/catalog.py`, when building the response, if a card's
`image_uri` is NULL, construct a fallback:

```python
def _fallback_image_url(set_code: str, collector_number: str) -> str | None:
    from src.utils.set_code_map import LIGA_TO_SCRYFALL
    # Map art series codes to base set
    scryfall_set = LIGA_TO_SCRYFALL.get(set_code, set_code)
    # Strip letter suffix from collector number (44a -> 44)
    base_number = ''.join(c for c in collector_number if c.isdigit())
    if not base_number:
        return None
    return f"https://cards.scryfall.io/normal/front/{base_number[0]}/{base_number[-1] if len(base_number) > 1 else '0'}/..."
```

Actually, Scryfall's direct image URL format is not predictable (uses hashes).
Better to use the API redirect:

```python
def _fallback_image_url(set_code: str, collector_number: str) -> str | None:
    from src.utils.set_code_map import LIGA_TO_SCRYFALL
    scryfall_set = LIGA_TO_SCRYFALL.get(set_code, set_code)
    # Strip letter suffix for art cards
    base_number = collector_number.rstrip('abcdefghijklmnopqrstuvwxyz')
    if not base_number:
        return None
    return f"https://api.scryfall.com/cards/{scryfall_set}/{base_number}?format=image&version=normal"
```

This URL redirects to the actual image. Scryfall allows this for reasonable
usage (browser caching handles rate limits).

**Option B — Frontend level**:

In CardImage.tsx, accept `setCode` and `collectorNumber` props. When `src`
is null, construct the fallback URL client-side.

### Recommendation

**Option A** is cleaner — the API populates `image_uri` with the fallback
so the frontend doesn't need to know about Scryfall URL construction.

Apply the fallback in:
- `src/api/routers/catalog.py` — catalog card responses
- `src/api/routers/collection.py` — collection card responses (if applicable)
- Or better: apply in the CardRow → response mapping wherever `image_uri` is used

### Files to modify

| File | Change |
|------|--------|
| `src/api/routers/catalog.py` | Add fallback image_uri in response mapping |
| `src/utils/set_code_map.py` | Verify `LIGA_TO_SCRYFALL` map has `ashob→hob` (already exists) |

OR (if frontend approach):

| File | Change |
|------|--------|
| `frontend/src/components/CardImage.tsx` | Accept setCode/collectorNumber, construct fallback |
| `frontend/src/components/CardTile.tsx` | Pass set_code/collector_number to CardImage |

### Important

- The Scryfall API redirect URL (`?format=image`) is lightweight and cached
- Do NOT call Scryfall API from the backend at request time — just construct
  the redirect URL and let the browser fetch the image
- `collector_number='44a'` needs stripping to `'44'` for the base card

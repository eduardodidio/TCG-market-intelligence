# F166-T03: API router — list news, mark read/unread

**Status:** planned
**Wave:** 0

## User Story

As a frontend, I need API endpoints to list news items (with read/unread filter) and to mark items as read or unread.

## Dev Notes

### Files to create/modify
- New: `src/api/routers/news.py`
- Modify: `src/api/app.py` (register router)

### Endpoints

1. **`GET /api/v1/news`**
   - Query params: `filter` (all|unread|read, default="unread"), `limit` (default=20), `offset` (default=0), `category` (optional)
   - Response: `{ items: NewsItem[], total: int, unread_count: int }`
   - Each item includes `is_read: bool` based on current user
   - Sorted by `published_at DESC` (newest first)
   - Requires auth (to track read status per user)

2. **`POST /api/v1/news/{id}/mark-read`**
   - Marks a news item as read for the current user
   - Idempotent (no error if already read)
   - Returns `{ success: true }`

3. **`POST /api/v1/news/{id}/mark-unread`**
   - Removes the read marker for the current user
   - Returns `{ success: true }`

4. **`GET /api/v1/news/unread-count`**
   - Returns `{ count: int }` — for sidebar badge
   - Lightweight endpoint, no pagination

### Response schema

```python
class NewsItemResponse(BaseModel):
    id: int
    title: str
    summary: str | None
    source_url: str
    source_name: str
    category: str
    image_url: str | None
    published_at: str | None
    fetched_at: str
    is_read: bool
```

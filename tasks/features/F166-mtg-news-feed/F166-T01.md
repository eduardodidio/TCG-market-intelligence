# F166-T01: DB models — news_items + user_news_reads tables

**Status:** planned
**Wave:** 0

## User Story

As a system, I need database tables to store MTG news items and track which users have read them.

## Dev Notes

### Files to modify
- `src/database/models.py`

### Changes

1. **`NewsItemRow` model**:
   ```python
   class NewsItemRow(Base):
       __tablename__ = "news_items"
       id = Column(Integer, primary_key=True, autoincrement=True)
       title = Column(String, nullable=False)
       summary = Column(Text, nullable=True)
       source_url = Column(String, nullable=False, unique=True)  # dedup key
       source_name = Column(String, nullable=False)  # "mtg_official", "scryfall", etc.
       category = Column(String, nullable=False, default="other")  # release, reprint, ban, event, other
       image_url = Column(String, nullable=True)
       published_at = Column(DateTime, nullable=True)
       fetched_at = Column(DateTime, nullable=False, default=func.now())
   ```

2. **`UserNewsReadRow` model**:
   ```python
   class UserNewsReadRow(Base):
       __tablename__ = "user_news_reads"
       id = Column(Integer, primary_key=True, autoincrement=True)
       user_id = Column(String, nullable=False)
       news_item_id = Column(Integer, ForeignKey("news_items.id", ondelete="CASCADE"), nullable=False)
       read_at = Column(DateTime, nullable=False, default=func.now())
       __table_args__ = (UniqueConstraint("user_id", "news_item_id"),)
   ```

3. Add FK constraint on `news_item_id` with CASCADE delete

### Repository methods (in `src/database/repository.py`):
- `list_news_items(limit, offset, user_id=None, filter="all")` — returns news with `is_read` flag per user
- `mark_news_read(user_id, news_item_id)`
- `mark_news_unread(user_id, news_item_id)`
- `upsert_news_item(item_data)` — insert or skip if source_url exists
- `count_unread_news(user_id)` — for badge count

# F166-T04: Frontend — NewsPage with read/unread filter

**Status:** planned
**Wave:** 0

## User Story

As a user, I want to see a news feed of MTG updates (releases, bans, events) where unread items are prominent, and I can filter between unread, read, and all items. Once I click on a news item, it's marked as read.

## Dev Notes

### Files to create
- New: `frontend/src/pages/NewsPage.tsx`
- New: `frontend/src/api/news.ts`

### `frontend/src/api/news.ts`

```typescript
export interface NewsItem {
  id: number;
  title: string;
  summary: string | null;
  source_url: string;
  source_name: string;
  category: string;
  image_url: string | null;
  published_at: string | null;
  fetched_at: string;
  is_read: boolean;
}

export interface NewsListResponse {
  items: NewsItem[];
  total: number;
  unread_count: number;
}

export function fetchNews(filter, limit, offset, category?): Promise<ApiResponse<NewsListResponse>>
export function markNewsRead(id: number): Promise<void>
export function markNewsUnread(id: number): Promise<void>
export function fetchUnreadCount(): Promise<ApiResponse<{ count: number }>>
```

### `frontend/src/pages/NewsPage.tsx`

1. **Filter tabs**: "Nao lidas" (default) | "Lidas" | "Todas"
2. **Optional category filter**: dropdown for release/ban/event/other/all
3. **News cards layout**: responsive grid (1 col mobile, 2 cols tablet, 3 cols desktop)
4. **Each news card**:
   - Title (bold if unread, normal if read)
   - Summary (truncated to 2-3 lines)
   - Source badge (e.g., "MTG Official", "Scryfall")
   - Category badge (colored: green=release, red=ban, blue=event, gray=other)
   - Published date (relative: "2 days ago")
   - Image thumbnail if available
   - Click opens `source_url` in new tab AND marks as read
   - "Mark as unread" button (eye icon) to restore
5. **Empty state**: "No news items" with hint to run fetch
6. **Pagination**: "Load more" button or infinite scroll

### Styling
- Unread cards: slightly brighter border/bg (e.g., `border-cyan-400/30`)
- Read cards: dimmer (e.g., `opacity-75` or `border-slate-700`)
- Dark mode compatible (use existing dark: classes)

# F166-T05: Sidebar nav + route + i18n

**Status:** planned
**Wave:** 0

## User Story

As a user with beta access, I want to see a "News" item in the sidebar navigation that takes me to the news feed page.

## Dev Notes

### Files to modify
- `frontend/src/components/Layout.tsx` — add to BETA_NAV_ITEMS
- `frontend/src/App.tsx` — add route with BetaRoute wrapper
- `frontend/src/i18n/locales/en.json` — English translations
- `frontend/src/i18n/locales/pt.json` — Portuguese translations

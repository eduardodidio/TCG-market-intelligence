## User Story

As the operator, I want a CLI command that processes pending deck suggestions, so that a scheduled .bat can run it daily.

## Objective

Create `src/cli/deck_suggestions.py` with a standalone click command. Registration in `src/cli/main.py` happens in T17.

## Dev Notes

See `_brief/00-overview.md` and `_brief/03-claude-processor.md` (sections "CLI" and "processor.py").

- The CLI uses **click** (`src/cli/main.py`). Mirror the `process-price-requests` output (`src/cli/main.py:1216–1250`): summary block with `"=" * 60`.
- **Do not import from `src.cli.main`** (circular once T17 registers the command). Resolve the DB with `from src.config import get_db_url` when `--db` is None.
- Build `Repository(db_url=db)` (`src/database/repository.py`) and `runner = get_runner(provider)`.
- A `ClaudeRunnerError(transient=False)` raised by `get_runner`, or an early check (missing binary/key), → `click.echo` the message and `sys.exit(2)`
  **before** claiming any request (use a `runner.check()` method if you add one to T05's classes. Otherwise attempt `shutil.which` / the env check here).
  Coordinate by reading `src/deck_suggestions/claude_runner.py`. If you add `check()`, add a test for it in `tests/unit/deck_suggestions/test_claude_runner.py`.
- Exit code: 0 when all processed (even if some failed), 2 on config error.

```python
def process_deck_suggestions(db, limit, provider, dry_run): ...
```

Output: `No pending deck suggestions.` when total is 0. Otherwise it prints `DECK SUGGESTION PROCESSING SUMMARY` with Total / Done / Failed / Retried / Provider / Model.

## Testing

`pytest tests/cli/test_deck_suggestions_cli.py -q`. Use `click.testing.CliRunner`. Patch `src.cli.deck_suggestions.get_runner` to return a fake runner.
Use a tmp_path SQLite file URL (`sqlite:///{tmp_path}/t.db`) with seeded rows.

## Test scenarios

- Happy: 2 pending → exit 0, summary Done 2.
- Edge: no pending → "No pending deck suggestions."; `--limit 1` → 1 done, 1 still pending; `--provider api` passed through to `get_runner`.
- Error: `get_runner` raises a non-transient `ClaudeRunnerError` → exit 2 and the message printed; the fake runner fails → exit 0, Failed 1.
- Boundary: `--limit 0` → nothing processed; `--db` omitted → `get_db_url` is used (patch it).

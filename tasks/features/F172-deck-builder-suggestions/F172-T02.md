- **Wave:** 1
- **Type:** backend
- **Depends on:** F172-T01
- **Status:** planned

## User Story

As a Commander player, I want to find my commander by typing its English or Portuguese name, so that I can build a deck
around it even when the ban-list data hasn't been synced.

## Objective

Make `get_commander_candidates` and `_query_candidates` robust (soft legality filter, PT names, dedupe, filter before limit),
wire real prices into `generate_deck`, and expose `is_commander_eligible`.

## Implementation details

1. `is_commander_eligible(type_line: str | None) -> bool`: pure. `"Legendary" in tl and "Creature" in tl`.
2. `_excluded_by_legality(format_name)`: returns the subquery `select(CardLegalityRow.card_id).where(format == f, status.in_(("banned","not_legal")))`.
   Use `~CardRow.id.in_(subq)` in both `get_commander_candidates` and `_query_candidates` (replacing the hard `IN legal` filter).
3. `get_commander_candidates(repo, colors=None, search=None, limit=50)`:
   - `search = (search or "").strip()`. If `search` is given but shorter than 2 chars, return `[]`.
   - Name filter: `or_(CardRow.name_en.ilike(p), CardRow.name_pt.ilike(p))`.
   - Fetch `min(limit * 10, 500)` rows, post-filter colors, dedupe by `name_en.lower()` (prefer `image_uri` not null, then higher id),
     sort (exact match on en/pt → 0, prefix → 1, else 2; then name_en), and slice `[:limit]`.
   - Add `"name_pt": r.name_pt` to the dict.
4. `CommanderCandidate` schema: `name_pt: str | None = None`.
5. `decks.py` `generate_deck_endpoint`: replace the inline check with `is_commander_eligible(commander.type_line)` (same 400 message).
6. `generate_deck`: fill `prices` for the candidate pool + commander + staples before selection (only the non-None `median_price`).
   The budget logic in `_select_cards` then works. `total_value` becomes non-None when prices exist.

## Acceptance criteria

- [ ] With **no** `card_legalities` rows, the search "atraxa" returns Atraxa.

- [ ] A PT query matches `name_pt`. Results show `name_pt`.
- [ ] 5 printings of the same commander → 1 result.
- [ ] Color filter + limit: a WU filter with limit 2 returns 2 WU-compatible commanders even if the first 2 alphabetically are red.
- [ ] `generate_deck` returns non-land cards with no legality rows, and it respects `budget_limit` when prices exist.
- [ ] Existing tests are still green after updating them.

## Test scenarios

- Happy: EN partial ("atra"), PT partial ("voz dos"), exact match sorted first.
- Edge: empty legality table; mixed (some banned); duplicates across sets; `type_line` NULL excluded; DFC `"Legendary Creature — X // Y"` included.
- Error: search `"%"` / `"_"` doesn't match everything (escaped); 1-char search → `[]`.
- Boundary: `limit=1`; `limit=50` with 600 candidates (the cap of 500 is respected); colorless commander (`color_identity` "" or None) with a colors filter.
- `generate_deck`: budget 0.01 → only zero/unknown-priced cards plus a warning; prices present → `total_value` > 0.

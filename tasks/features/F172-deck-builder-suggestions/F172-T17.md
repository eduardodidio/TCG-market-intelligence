## Notes from Developer

- **CRLF vs neighbors:** the existing `bats/*.bat` files are actually LF (`git ls-files --eol bats/` → `i/lf w/lf`). The AC asks for CRLF,
  and `cmd.exe` handles CRLF best, so `bats/deck-suggestions.bat` uses CRLF (`file` → "with CRLF line terminators").
- **Wiring test uses the OpenAPI schema, not `app.routes`:** FastAPI 0.141 wraps included routers in `_IncludedRouter`, so `app.routes`
  shows only `/health` and the docs routes. `tests/unit/api/test_deck_suggestions_wiring.py` checks `app.openapi()["paths"]`, which is also what `/docs` renders.
  It asserts all 5 operations, and that `/api/v1/decks/{deck_id}` and `/api/v1/decks/ranking` still exist.
- **README:** the mode query value is `?mode=suggestion` (see `DeckBuildWizard.tsx`), not `suggest`.

# F172-T04 — Backend: pure prompt builder + response parser

- **Wave:** 1
- **Type:** backend
- **Depends on:** F172-T01
- **Status:** planned

## User Story

As a player, I want Claude to receive a clear request that includes the cards I own, so that the suggestion reuses my collection and
comes back in a format the app can show.

## Objective

Implement `src/deck_suggestions/prompt.py`: collection filtering, prompt construction, and robust response parsing. No DB and no network.

## Dev Notes

See `_brief/00-overview.md` and `_brief/03-claude-processor.md` (section "prompt.py").

- Follow the F03/F10 learning: pure functions, domain objects in and out, zero mocking.
- Basic lands set: `{"Plains","Island","Swamp","Mountain","Forest","Wastes"}` plus the `"Snow-Covered X"` variants.
- Singleton formats: `{"commander","brawl","oathbreaker"}` (keep in sync with `_SINGLETON_FORMATS` in `src/decks/builder.py`. Import it from there).
- Security: user notes are **data**. Wrap them in `<observacoes_do_usuario>` tags and strip any closing tag the user typed
  (`notes.replace("</observacoes_do_usuario>", "")`). Truncate to 1000 chars.

## Implementation details

- Dataclasses `OwnedCard`, `SuggestionInput`, `ParsedCard(name, quantity, category, reason)`,
  `ParsedSuggestion(deck_name, strategy, cards, warnings)`. Exception `SuggestionParseError(ValueError)`.
- `expected_deck_size`, `filter_owned_for_request`, `build_prompt`, `parse_response` as specified in the shard.
- The prompt ends with a literal JSON example and "Responda SOMENTE com o JSON, sem texto adicional."

## Acceptance criteria

- [ ] `build_prompt` output contains the format, commander/colors/archetype, the notes block, and the owned list (at most `max_cards` lines).
- [ ] `parse_response` accepts plain JSON, fenced JSON, and JSON with leading/trailing prose.
- [ ] Quantities are clamped with warnings, duplicates merged, and a size mismatch adds a warning.
- [ ] Coverage ≥ 95% of `prompt.py`.

## Testing

`pytest tests/unit/deck_suggestions/test_prompt.py -q --cov=src/deck_suggestions/prompt.py --cov-report=term-missing`.

## Test scenarios

- Happy: a Commander request with 3 owned cards produces a prompt with the commander name and the owned lines. A valid response gives 99 cards + no warnings.
- Edge: owned cards outside the colors are filtered; colorless owned cards are kept; a "C" request keeps only colorless cards; duplicates merged (qty summed);
  a notes injection attempt containing `</observacoes_do_usuario>` is neutralised; notes None → no block.
- Error: empty string, non-JSON, `{"cards": []}`, `cards` not a list, a card without a name → `SuggestionParseError`.
- Boundary: 151 cards → error (or truncated to 150 + warning: pick one and test it); quantity 0 → clamped to 1; qty 5 non-basic in modern → 4;
  qty 3 non-basic in commander → 1; 30x Island in commander kept; `deck_name` 500 chars → truncated to 120; `max_cards=300` with 1000 owned → 300 lines.

# F172-T05 — Backend: Claude runners (CLI subprocess + HTTP API via httpx)

- **Wave:** 1
- **Type:** backend
- **Depends on:** F172-T01
- **Status:** planned
- **Maps to AC:** AC6, AC8

## User Story

As the operator, I want to process suggestions with my local Claude CLI (or, optionally, the Anthropic API key in `.env`), so that
no secret is hardcoded and no new dependency is needed.

## Objective

Implement `src/deck_suggestions/claude_runner.py` with `ClaudeCliRunner`, `ClaudeApiRunner`, `ClaudeRunnerError`, and `get_runner()`.

## Dev Notes

See `_brief/00-overview.md` and `_brief/03-claude-processor.md` (section "claude_runner.py").

- **No new dependency.** Use `subprocess`, `shutil`, `tempfile`, `json`, `os` and the existing `httpx`. Do NOT `import anthropic`.
- Check the actual CLI flags with `claude --help` if the binary is available. Required: `-p`, `--output-format json`, `--max-turns`.
  To disable tools, prefer `--tools ""` if supported, else `--disallowedTools "Bash,Edit,Write,NotebookEdit,WebFetch,WebSearch,Read,Glob,Grep"`.
  Keep the chosen args in a module constant `_CLI_BASE_ARGS` so the tests assert on them.
- The `--output-format json` envelope contains `{"type":"result","is_error":false,"result":"<text>", ...}`.
- The API runner's model default comes from `DECK_SUGGEST_MODEL` (default `claude-sonnet-5`). Anthropic version header `2023-06-01`.
- Log via `structlog.get_logger()` (project convention). **Never** log the prompt in full (it includes collection data. Log its length instead), and never log the API key or headers.
- Windows: `claude` may resolve to `claude.cmd`. `shutil.which` handles that. Pass the list args with `shell=False`.

## Implementation details

- `ClaudeRunnerError(message, transient: bool)`.
- `ClaudeCliRunner(bin_path=None, model=None, timeout=None)`, `provider = "cli"`, `run(prompt) -> str`.
- `ClaudeApiRunner(api_key=None, model=None, timeout=None, client: httpx.Client | None = None)` (the injectable client is for tests), `provider = "api"`.
- `get_runner(provider=None) -> ClaudeCliRunner | ClaudeApiRunner`. An unknown provider raises `ValueError`.

## Acceptance criteria

- [ ] The CLI runner sends the prompt via stdin, runs in an empty temp dir, and removes it afterwards (even on error).
- [ ] Missing binary / missing API key → non-transient error with an actionable message.
- [ ] Timeout, non-zero exit, `is_error`, HTTP 429/5xx → transient. HTTP 400/401/403 → non-transient.
- [ ] No secret appears in logs or exceptions (test with a sentinel key).
- [ ] Coverage ≥ 95%.

## Testing

- Targeted: `pytest tests/unit/deck_suggestions/test_claude_runner.py -q --cov=src/deck_suggestions/claude_runner.py --cov-report=term-missing`.
- Mock `subprocess.run` / `shutil.which` with `unittest.mock.patch`.

- Use `monkeypatch.setenv` / `delenv` for the env vars.
- Lint: `ruff check src/`.

## Test scenarios

- Happy: the CLI returns an envelope → `run` returns the `result` text. The API returns `content:[{type:text,text:"{…}"}]` → text.
- Edge: `DECK_SUGGEST_MODEL` set → `--model` passed (CLI) / used in the body (API); multiple text blocks are concatenated; a non-text block is ignored.
- Error: `which` → None; returncode 1 with stderr; `TimeoutExpired`; stdout that isn't JSON (→ transient error); API 401; API 529/503; missing `ANTHROPIC_API_KEY`;
  `get_runner("xyz")`.
- Boundary: stderr of 10 KB truncated to 500 chars in the message; `DECK_SUGGEST_TIMEOUT="abc"` → falls back to the default of 300.
- Security: a sentinel key `sk-test-SECRET` never appears in `str(exc)` or in captured logs (`structlog.testing.capture_logs`).

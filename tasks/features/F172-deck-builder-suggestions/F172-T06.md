## User Story

As a Commander player, I want the commander search to tell me when it's searching, found nothing, or failed, so that I'm never
left staring at an empty screen.

## Objective

Extract the commander search out of `DeckBuildWizard.tsx` into `components/decks/CommanderSearch.tsx` with robust states and a stale-response guard.
Add Pioneer/Vintage to the wizard formats.

## Implementation details

- `CommanderSearch({ selected, onSelect, onClear })`: internal `query`, `results`, `status: "idle"|"loading"|"done"|"error"`,
  `errorMsg`, and `reqSeq = useRef(0)`. Debounce 300 ms. The effect increments the seq, awaits, and ignores the response if `seq !== reqSeq.current`.
  `try/catch/finally`.
- Render: the input (`commander-search`), the loading text (`commander-search-loading`), the error (`commander-search-error`),
  the empty state (`commander-search-empty`, only when status is done, there are 0 results, and the query is ≥ 2 chars), the selected chip (`selected-commander`), and the grid options (`commander-option-{id}`) showing `name_en` plus `name_pt` when it differs.
- `frontend/src/types/api.ts`: add `name_pt?: string | null;` to `CommanderSearchResult`.
- `DeckBuildWizard.tsx`: replace the inline search with `<CommanderSearch selected={selectedCommander} onSelect={setSelectedCommander} onClear={() => { setSelectedCommander(null); setSelectedColors([]); }} />`.
  Remove the unused state. Add `pioneer` and `vintage` to `FORMAT_INFO` (60 cards).

## Test scenarios

- Happy: typing "atr" → one call after 300 ms → the options render → a click calls `onSelect`.
- Edge: 1 char → no call; typing fast ("a","at","atr") → a single call; `name_pt` shown; the selected chip + clear calls `onClear`.
- Error: `{ data: null, errors: [{message:"boom"}] }` → error text; a rejected promise → error text, loading gone.
- Boundary: 0 results → empty state; out-of-order responses (the first resolves after the second) → only the second shown.
- Wizard: the pioneer option renders and selecting it goes to the colors step (a non-commander format).

## User Story

As a player, I want to see the suggested deck, which cards I already own, and what the missing ones cost, and then save it as a deck,
so that I can act on the suggestion.

## Objective

Render a suggestion detail for every status. For `done`, show the strategy, summary tiles, the grouped card list with owned/missing plus prices, unresolved names,
warnings, and the "Salvar como deck" action.

## Dev Notes

See `_brief/00-overview.md`, `_brief/02-suggestion-persistence-api.md` (result contract) and `_brief/04-frontend-flow.md` (component "SuggestionResultView").

- Props: `{ suggestion: DeckSuggestion; onSaved?: (deckId: number) => void }`. After saving, `navigate(`/decks/${deck_id}`)` (`useNavigate`).
- Currency: `value.toLocaleString("pt-BR", { style: "currency", currency: "BRL" })`. Check `frontend/src/components/CurrencyIndicator.tsx` / any
  currency context (the project supports BRL/USD/Pila, F18/F19). If a `formatPrice` helper / context exists, use it. Otherwise use BRL.
- Card image thumbnails: `image_uri` or the Scryfall fallback (`https://api.scryfall.com/cards/{set}/{num}?format=image&version=small`), as in the wizard.
  Keep the list compact: a row per card (qty, name, category badge, owned or missing + price). Optional hover preview via `CardHoverPreview.tsx` if it is trivial to use.
- Group by `category` in a stable order: commander first, then alphabetical categories, with "Land" last.

## Acceptance criteria

- [ ] pending/processing show the "Na fila – será gerado na próxima execução diária" info. failed shows `error_message`.
- [ ] done shows the strategy, 4 summary tiles, grouped cards, owned badges, and the missing price per card.
- [ ] Save calls `saveDeckSuggestion(id, name)`, then navigates. A save error is shown inline. The button is disabled while saving.
- [ ] If `saved_deck_id` is set, a "Ver deck salvo" link to `/decks/{id}` is shown instead of save.

## Testing

- Targeted: `cd frontend && npx vitest run src/components/decks/__tests__/SuggestionResultView.test.tsx`.
- Mock `react-router-dom`'s `useNavigate` like the wizard test, and mock the API module.
- Then `cd frontend && npm test` and `npm run build`.

## Test scenarios

- Happy: a done fixture (3 cards: owned, missing priced, missing unpriced) → totals rendered, and the save flow navigates to `/decks/42`.
- Edge: `missing_cost_brl` null → "—"; empty `unresolved` → the section is hidden; warnings are listed; no commander (modern).
- Error: save returns errors → the message is shown and there is no navigation.
- Boundary: 100 cards render (perf sanity, no crash); a deck name that is empty → falls back to `result.deck_name`.

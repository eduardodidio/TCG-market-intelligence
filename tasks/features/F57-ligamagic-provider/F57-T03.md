# F57-T03 — LigaMagic Price Parser + Snapshot Integration

**Status:** done
**Wave:** 1
**Depends on:** F57-T01 (go decision)
**Estimate:** medium

## User Story

As the system, I want to extract current prices from LigaMagic card pages
and store them as PriceSnapshot records, so we have a second price source.

## Dev Notes

### Parser (`src/providers/liga/parser.py`)

Extract from card page HTML:
- Card name (PT and EN if available)
- Set / edition
- Price(s) in BRL — LigaMagic shows marketplace prices
- Availability / stock status
- Product ID for URL construction

Handle CSS obfuscation: use Playwright's `page.evaluate()` to extract
rendered text content rather than parsing raw HTML. This bypasses CSS-based
obfuscation.

### Price Snapshot Mapping

Map LigaMagic price data to existing `PriceSnapshot` domain model:
- `source`: `"liga"`
- `price_brl`: extracted price
- `currency`: `"BRL"`
- `timestamp`: current datetime

### Integration with Database

Use existing `upsert_price_snapshot` repo method with `source="liga"`.
No schema changes needed — PriceSnapshot already supports multiple sources.

## Testing

- Unit tests: parser with fixture HTML (3+ variants)
- Unit tests: price mapping to PriceSnapshot
- Edge cases: card with no price, card out of stock, multiple editions

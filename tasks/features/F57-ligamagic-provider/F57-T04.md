# F57-T04 — Provider Registry + Fallback Chain

**Status:** planned
**Wave:** 2
**Depends on:** F57-T02, F57-T03
**Estimate:** medium

## User Story

As the system, I want a provider registry that tries LigaMagic first and
falls back to MYP, so we get the best available price data automatically.

## Dev Notes

### New Module: `src/providers/registry.py`

```python
class ProviderRegistry:
    def __init__(self, providers: list[CardSourceProvider]):
        self.providers = providers  # ordered by priority

    async def get_current_price(self, card) -> PriceSnapshot | None:
        for provider in self.providers:
            try:
                price = await provider.get_current_price(card)
                if price:
                    return price
            except Exception:
                continue  # try next provider
        return None
```

### Provider Order

1. **LigaMagic** (primary) — more accurate Brazilian market prices
2. **MYP** (fallback) — existing provider, lower friction

### Configuration

Environment variable `TCG_PROVIDER_ORDER` (optional):
- Default: `"liga,myp"`
- Can be overridden to `"myp,liga"` or `"myp"` (disable liga)

### Integration Points

- `src/collectors/scan.py` — use registry instead of direct MYP provider
- `src/collectors/sync_collection.py` — use registry for price fetching
- `src/api/deps.py` — registry singleton in FastAPI lifespan

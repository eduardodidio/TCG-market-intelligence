# F57-T01 — Feasibility Spike: Validate LigaMagic Scraping

**Status:** done
**Wave:** 0
**Estimate:** medium

## User Story

As a developer, I want to validate that we can reliably extract price data
from LigaMagic using browser automation, so we can decide whether to
proceed with a full provider implementation.

## Dev Notes

### Approach

Write a standalone spike script (`scripts/ligamagic_spike.py`) that:

1. Installs Playwright (`pip install playwright && playwright install chromium`)
2. Opens a LigaMagic card page in headless Chromium
3. Extracts: card name, set, price(s), availability
4. Handles the anti-bot measures (wait for JS render, realistic viewport)
5. Tests 3-5 different cards to validate consistency

### URL Pattern to Test

```
https://www.ligamagic.com.br/?view=cards/card&card=Lightning+Bolt&show=1
https://www.ligamagic.com.br/?view=cards/card&card=Counterspell&show=1
https://www.ligamagic.com.br/?view=cards/card&card=Sol+Ring&show=1
```

### Success Criteria

- Can load page without 403
- Can extract at least: card name, one price value, set/edition
- Consistent across 3+ cards
- Execution time < 15s per card (acceptable for batch)

### Output

- `scripts/ligamagic_spike.py` — runnable spike
- `docs/adr/NNNN-ligamagic-provider.md` — ADR documenting findings and go/no-go decision
- If no-go: document why and close F57


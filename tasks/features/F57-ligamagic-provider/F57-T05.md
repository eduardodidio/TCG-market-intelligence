# F57-T05 — CLI + API Integration

**Status:** done
**Wave:** 2
**Depends on:** F57-T04
**Estimate:** small

## User Story

As a user, I want CLI commands and API endpoints to use the provider
registry (LigaMagic + MYP fallback), so price scans automatically
use the best available source.

## Dev Notes

### CLI Changes (`src/cli/main.py`)

- `scan` command: inject ProviderRegistry instead of MypProvider
- Add `--provider` flag: `liga`, `myp`, or `auto` (default: `auto` = registry)
- `snapshot-prices`: support `--provider` flag

### API Changes

- `src/api/deps.py`: create ProviderRegistry in lifespan, inject as dependency
- Scan endpoints: use registry from deps
- Collection refresh: use registry from deps

### No Frontend Changes

Provider selection is transparent to the frontend — it just sees prices
with a `source` field ("liga" or "myp").

## Testing

- CLI test: `--provider auto` uses registry
- CLI test: `--provider myp` uses MYP directly
- API test: scan endpoint uses registry
- Integration: verify price source field shows "liga" or "myp"

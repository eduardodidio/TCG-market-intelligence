# F57-T02 — LigaMagic Provider Skeleton + Card Search

**Status:** planned
**Wave:** 1
**Depends on:** F57-T01 (go decision)
**Estimate:** medium

## User Story

As the system, I want a LigaMagic provider that implements
CardSourceProvider, so I can search for cards and discover sets from
LigaMagic.

## Dev Notes

### New Files

```
src/providers/liga/
  __init__.py
  provider.py      — LigaMagicProvider(CardSourceProvider)
  parser.py         — HTML parsing (card page, search results)
  config.py         — LigaConfig dataclass
  exceptions.py     — LigaError hierarchy (mirrors MYP pattern)
```

### Provider Class

```python
@dataclass
class LigaConfig:
    delay_seconds: float = 4.0   # conservative rate limit
    timeout_seconds: float = 30.0
    headless: bool = True

class LigaMagicProvider(CardSourceProvider):
    source_name = "liga"

    async def discover_sets(self) -> list[str]: ...
    async def discover_cards(self, set_id=None) -> list[SourceCard]: ...
    async def get_current_price(self, card: SourceCard) -> PriceSnapshot | None: ...
    async def get_price_history(self, card, days=1095) -> list[HistoricalPrice]:
        return []  # LigaMagic has no public history — return empty
```

### Browser Session Management

- Use Playwright async API with persistent browser context
- Reuse a single browser instance across multiple calls
- Close browser on provider shutdown (context manager)
- Headless mode by default, configurable for debugging

### Card Search

- URL: `?view=cards/card&card={name}&show=1`
- Parse search results page for: card name, set, product ID, price
- Map to SourceCard domain model

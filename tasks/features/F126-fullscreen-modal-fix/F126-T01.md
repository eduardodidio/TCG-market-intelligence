# F126-T01: CardPreviewModal — Portal + Fullscreen Sizing

**Status:** planned
**Wave:** 0
**Depends on:** none

## User Story

As a user, when I click on a card image to zoom in, I want the 3D preview to
appear centered on the full screen (viewport overlay), not confined inside the
card tile or page section.

## Dev Notes

### Current state
- `CardPreviewModal.tsx` renders a `<div className="fixed inset-0 ... z-50">`
  inline wherever it is placed in the React tree.
- When rendered inside `Card3DTilt` (which applies CSS `transform` via
  react-parallax-tilt) or inside the Layout sidebar (which has
  `transform transition-all`), `position: fixed` becomes relative to the
  transformed ancestor — NOT the viewport.
- Image container uses `max-w-sm` (384px) which is small.

### Changes required

1. **Add `createPortal`**: Import `createPortal` from `react-dom`. Wrap the
   entire modal JSX in `createPortal(modal, document.body)` — same pattern
   already used by `TreasureModal` (line 231) and `CardHoverPreview` (line 18).

2. **Increase z-index**: Change `z-50` to `z-[9999]` to match TreasureModal
   and ensure it renders above everything (sidebar z-30, other overlays).

3. **Increase card size**: Change inner container from `max-w-sm mx-4` to
   `max-w-md mx-4` and add `max-h-[80vh]` on the image for comfortable
   viewport-scale viewing.

4. **Add smooth entrance**: Add a subtle scale-in transition (opacity 0→1,
   scale 0.9→1) for polish, matching the TreasureModal's animation pattern.

### Files
- `frontend/src/components/CardPreviewModal.tsx`

### Acceptance Criteria
- [ ] Modal renders as a direct child of `document.body` via portal
- [ ] Modal covers full viewport (`fixed inset-0`) regardless of parent transforms
- [ ] Card image is larger than before (max-w-md, max-h-[80vh])
- [ ] z-index is `z-[9999]` (above sidebar, other modals)
- [ ] Escape key and backdrop click still close the modal
- [ ] Foil shimmer still works when `isFoil=true`

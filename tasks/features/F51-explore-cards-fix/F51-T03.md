# F51-T03 — Add Refresh Button on CardDetail

**Status:** done
**Wave:** 1
**Estimate:** medium

## User Story

As a user viewing a card in explore that is also in my collection, I want
a refresh button that fetches the latest price from MYP, so I can update
stale or missing price data without leaving the page.

## Dev Notes

### What to change

**Backend — `src/api/routers/cards.py`:**
- Add `GET /api/v1/cards/{card_id}/collection-entry` endpoint that returns
  the user's collection entry ID for a given card_id (if it exists).
  Returns 404 if not in collection. Requires auth.
- OR: extend `CardDetail` schema to include `collection_entry_id: int | None`
  when authenticated — populated by checking if the card_id exists in the
  user's collection entries. This is simpler (single endpoint).

**Frontend — `frontend/src/pages/CardDetail.tsx`:**
- If `collection_entry_id` is present in the card detail response:
  - Show a refresh button (reuse the pattern from `CollectionCardDetail.tsx`)
  - On click, call `POST /collection/{entry_id}/refresh`
  - Show loading spinner during fetch, update price on success
  - Show error toast on failure
- If not in collection, don't show the button

**Backend — `src/api/routers/cards.py` or `src/api/schemas/cards.py`:**
- Add `collection_entry_id: int | None = None` to `CardDetail` schema
- In the GET `/cards/{id}` endpoint, if user is authenticated, query
  `collection_entries` for matching `card_id` and populate the field

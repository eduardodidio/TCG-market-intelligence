# F159-T03: Other pages — replace inline error with ErrorBanner

**Feature:** F159 — Error Retry Pattern
**Wave:** 0
**Status:** planned

## User Story

As a user seeing an error on any page, I want consistent error display
with retry capability.

## Dev Notes

### Current State

- `TopDecksPage.tsx` lines ~123-129: inline error div
- `Evaluations.tsx` lines ~109-116: inline error div
- `AchievementsPage.tsx` lines ~86-91: inline error div

All have a fetch/load function available for retry.

### Implementation

Replace inline error divs with `<ErrorBanner message={error} onRetry={...} />`.

For each page:
1. Import `ErrorBanner` from `../components/ErrorBanner`
2. Replace `{error && <div className="...text-red-...">{error}</div>}`
   with `{error && <ErrorBanner message={error} variant="full" onRetry={loadFn} />}`

### Files
- `frontend/src/pages/TopDecksPage.tsx` — ErrorBanner + retry
- `frontend/src/pages/Evaluations.tsx` — ErrorBanner + retry
- `frontend/src/pages/AchievementsPage.tsx` — ErrorBanner + retry

# F159-T01: Add onRetry to existing ErrorBanner uses

**Feature:** F159 — Error Retry Pattern
**Wave:** 0
**Status:** planned

## User Story

As a user seeing an error on Cards or Catalog page, I want a "Retry"
button so I can recover without reloading the page.

## Dev Notes

### Current State

- `Cards.tsx` line ~458: `<ErrorBanner message={error} variant="inline" />` — missing `onRetry`
- `CatalogPage.tsx` line ~810: `<ErrorBanner message={error} variant="inline" />` — missing `onRetry`

Both pages have a `refetch` or reload function available in scope.

### Implementation

Add `onRetry` prop to the existing ErrorBanner in each page:

**Cards.tsx:**
```tsx
<ErrorBanner message={error} variant="inline" onRetry={refetch} />
```

**CatalogPage.tsx:**
```tsx
<ErrorBanner message={error} variant="inline" onRetry={() => loadCards()} />
```

### Files
- `frontend/src/pages/Cards.tsx` — add onRetry prop
- `frontend/src/pages/CatalogPage.tsx` — add onRetry prop

## Testing

- Unit: ErrorBanner renders with retry button on CatalogPage error state

# F159-T02: Deck pages — replace inline error with ErrorBanner

**Feature:** F159 — Error Retry Pattern
**Wave:** 0
**Status:** planned

## User Story

As a user seeing an error on deck pages, I want a consistent error
display with retry capability.

## Dev Notes

### Current State

- `DeckList.tsx` lines ~66-72: inline `<div className="text-red-400">` with no retry
- `DeckView.tsx` lines ~101-111: inline error div with no retry
- `DeckBuildWizard.tsx` line ~108: `setError()` with limited display

### Implementation

Replace inline error divs with `<ErrorBanner message={error} onRetry={...} />`.
Import ErrorBanner component. Use the existing load/fetch function for retry.

**DeckList.tsx:**
```tsx
import { ErrorBanner } from "../components/ErrorBanner";
// Replace inline error div:
{error && <ErrorBanner message={error} variant="full" onRetry={loadDecks} />}
```

**DeckView.tsx:**
```tsx
import { ErrorBanner } from "../components/ErrorBanner";
// Replace inline error div:
{error && <ErrorBanner message={error} variant="full" onRetry={loadDeck} />}
```

**DeckBuildWizard.tsx:** Keep inline error for form validation (step-specific),
only add ErrorBanner if there's a page-level fetch error.

### Files
- `frontend/src/pages/DeckList.tsx` — ErrorBanner + retry
- `frontend/src/pages/DeckView.tsx` — ErrorBanner + retry

## User Story

As a platform owner, I need the admin page protected by a frontend guard that
redirects non-admin users, a route registered in App.tsx, and a sidebar link
visible only to admins, so the admin panel is properly integrated into the
application shell.

### 2. AdminRoute component: `frontend/src/components/AdminRoute.tsx`

```typescript
import { Navigate } from "react-router-dom";
import { useAuth } from "../hooks/useAuth";
import { LoadingSpinner } from "./LoadingSpinner";

export function AdminRoute({ children }: { children: React.ReactNode }) {
  const { user, isAuthenticated, loading } = useAuth();

  if (loading) {
    return <LoadingSpinner message="Checking access..." />;
  }

  if (!isAuthenticated) {
    return <Navigate to="/login" replace />;
  }

  if (!user?.is_admin) {
    return <Navigate to="/" replace />;
  }

  return <>{children}</>;
}
```

### 3. Route registration in `frontend/src/App.tsx`

Add lazy import:
```typescript
const AdminPanel = lazy(() =>
  import("./pages/AdminPanel").then((m) => ({ default: m.AdminPanel })),
);
```

Add route inside the Layout routes, near the existing `/admin/liga-status`:
```tsx
<Route
  path="/admin"
  element={
    <Suspense fallback={<LoadingSpinner message="Loading page..." />}>
      <AdminRoute><AdminPanel /></AdminRoute>
    </Suspense>
  }
/>
```

Also wrap the existing `/admin/liga-status` route with `AdminRoute` instead
of `ProtectedRoute` (it should be admin-only too).

### 4. Nav conditional in `frontend/src/components/Layout.tsx`

Add `requiresAdmin` flag to NAV_ITEMS type and items:

```typescript
const NAV_ITEMS = [
  ...existing items...,
  { to: "/admin", labelKey: "nav.adminPanel", requiresAuth: true, requiresAdmin: true },
  { to: "/admin/liga-status", labelKey: "nav.ligaStatus", requiresAuth: true, requiresAdmin: true },
] as const;
```

Update the nav filtering logic:
```typescript
const visibleNavItems = NAV_ITEMS.filter((item) => {
  if (item.requiresAuth && !isAuthenticated) return false;
  if (item.requiresAdmin && !user?.is_admin) return false;
  return true;
});
```

This requires adding `requiresAdmin?: boolean` to all items (default false
for non-admin items). The cleanest approach is to change NAV_ITEMS from
`as const` to a typed array, or add `requiresAdmin: false` to every existing
item.

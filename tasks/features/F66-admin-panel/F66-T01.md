**Status:** planned

## User Story

As an admin, I want API endpoints to list all users with their credit
balances and grant/revoke treasure tokens to any user (including myself),
so I can manage the platform economy.

## Dev Notes

### New dependency: `src/api/deps.py`

```python
def require_admin(user: User = Depends(get_current_user)) -> User:
    """Require the current user to be an admin."""
    if not getattr(user, 'is_admin', False):
        raise HTTPException(status_code=403, detail="Admin access required")
    return user
```

# F96-T03: Inline Cost Badge on Single Refresh Buttons

**Wave:** 1
**Depends on:** T01, T06

## User Story

As a user viewing a card, I want to see the credit cost (e.g., "1 token")
directly on the refresh button, so I know the cost before clicking.

## Dev Notes

### Files to modify

1. **`frontend/src/pages/CollectionCardDetail.tsx`**
   - Liga refresh button (line ~438): append a small badge after the
     button text showing `(1)` with a treasure-token icon or just
     `(1 token)` text.
   - MYP refresh button (line ~463): same treatment.
   - Use i18n key `credits.costBadge` with `{{cost}}` interpolation.
   - When balance < 1, add `text-red-400` to the badge to signal
     insufficient funds visually.

2. **`CollectionCardTile` in `frontend/src/pages/MyCollection.tsx`**
   - The hover overlay refresh button (circular, line ~148-173) is small.
     Instead of inline text, add a `title` attribute with cost info:
     `title={t("credits.refreshCostTooltip", { cost: 1 })}`.
   - This avoids cluttering the compact circular button.

3. **`frontend/src/components/DeckCardTile.tsx`** (if it has a refresh
   button) — apply the same tooltip pattern.

### New component (optional, recommended)

Create `frontend/src/components/CostBadge.tsx`:
```
interface CostBadgeProps {
  cost: number;
  balance: number | null;
}
```
- Renders: `(1 token)` in `text-xs text-slate-400` inline.
- When `balance !== null && balance < cost`: `text-red-400`.
- Reusable across all button placements.

### Styling
- Badge: `text-xs text-slate-400 ml-1` (or `text-red-400` when insufficient)
- Compact enough to fit inside existing button padding without layout shift.

# F96-T02: Bonus Claim Success Feedback in TreasureBalance

**Wave:** 0
**Depends on:** T06 (i18n keys)

## User Story

As a user who claims a bonus via the sidebar TreasureBalance widget, I want
to see a brief success message confirming how many tokens were credited, so
I have confidence the action worked.

## Dev Notes

### File: `frontend/src/components/TreasureBalance.tsx`

1. The existing `handleClaim` already sets `claimed=true` for 1.5s, which
   turns the balance text emerald. Enhance this:
   - Store the `credited` amount from `claimBonus` response (the
     `ClaimBonusResponse` already includes a `credited` field).
   - While `claimed` is true, show a small text below the balance:
     `"+5 tokens!"` (using i18n key `credits.bonusClaimed` with
     `{{amount}}` interpolation).
   - Animate with `animate-fade-in-up` (already exists in tailwind config).

2. **Modify `useCredits.claimBonus`** to return the `credited` amount:
   - Change return type from `Promise<void>` to `Promise<number>` (the
     credited amount, or 0 on failure).
   - In `TreasureBalance.handleClaim`, capture the return value.

### Styling
- Success text: `text-xs text-emerald-400 font-medium animate-fade-in-up`
- Positioned below the "Treasure Tokens" label, above the claim button area.

## Testing

- Test: after calling `handleClaim`, the "+N tokens!" message appears.
- Test: message disappears after 1.5s timeout.
- Test: when `claimBonus` returns 0, no success message shown.
- Update existing TreasureBalance tests for the new text element.

# F96-T05: Admin Scheduled Scan Credit-Pause Indicator

**Wave:** 2
**Depends on:** T06

## User Story

As an admin viewing the Schedules page, I want the
`paused_insufficient_credits` status to be visually distinct from a normal
pause (with an icon and recovery guidance), so I can quickly identify and
fix credit-related scan failures.

# F96-T01: Enhance CreditConfirmModal (Claim Bonus + Earn Info)

**Wave:** 0
**Depends on:** T06 (i18n keys)

## User Story

As a user who sees "Insufficient tokens!" in the confirmation modal, I want
a "Claim Bonus" button (when eligible) and guidance on how to earn more
tokens, so I can recover without leaving the modal flow.

## Dev Notes

### File: `frontend/src/components/CreditConfirmModal.tsx`

1. **Add new props** to `CreditConfirmModalProps`:
   - `bonusEligible?: boolean` — whether the user can claim a bonus right now.
   - `onClaimBonus?: () => Promise<void>` — callback that calls the credit
     claim API and triggers a balance refetch.

2. **Insufficient state enhancement** (render when `insufficient` is true):
   - Below the existing red "Insufficient tokens!" text, add:
     - A "Claim Bonus" button (emerald, small) when `bonusEligible` is true.
       On click, call `onClaimBonus`, then the parent refetches balance.
       Show a brief "Claimed!" flash (1.5s, emerald text) next to the button.
     - A static "earn info" paragraph with i18n key `credits.earnInfo` that
       explains: "Earn 5 tokens every 12 hours by claiming your bonus. Run
       scans and refreshes to spend tokens."

3. **Callers must pass the new props.** Update all three call sites:
   - `CollectionCardDetail.tsx` — pass `bonusEligible` and `onClaimBonus`
     from `useCredits()`.
   - `CollectionCardTile` in `MyCollection.tsx` — same.
   - Bulk refresh `CreditConfirmModal` in `MyCollection.tsx` — same.

4. **Keep the confirm button disabled** when insufficient, even after
   claiming bonus. The parent refetches balance, which re-renders the modal
   with updated `balance` prop. If balance is now sufficient, the button
   enables automatically.

### Styling
- "Claim Bonus" button: `bg-emerald-600 hover:bg-emerald-500 text-white
  text-xs px-3 py-1 rounded-md`
- "Earn info" text: `text-xs text-slate-400 mt-2`

## Testing

- Test: modal shows "Claim Bonus" button when `insufficient && bonusEligible`.
- Test: modal does NOT show "Claim Bonus" when `bonusEligible` is false.

- Test: clicking "Claim Bonus" calls `onClaimBonus`.

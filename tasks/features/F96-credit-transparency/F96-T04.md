# F96-T04: Inline Cost Badge on Bulk Refresh Button

**Wave:** 1
**Depends on:** T01, T06

## User Story

As a user viewing my collection, I want to see the estimated token cost on
the "Refresh All" button before clicking it, so I can decide whether to
proceed without opening the modal first.

## Dev Notes

### File: `frontend/src/pages/MyCollection.tsx`

1. **Enhance the "Refresh All" button** (line ~807-821):
   - Show the user's current balance and estimated cost inline on the button
     or as a subtitle beneath it.
   - The exact cost is only known after `fetchScanPreview`, which runs on
     modal open. Instead, show the balance as a hint:
     `"Refresh All ({{balance}} tokens)"` using `creditBalance` from
     `useCredits()` (already available in scope at line 318).
   - This gives users a sense of their budget before clicking.

2. **Alternative approach** (preferred if scan count is cached): if the
   collection summary already includes `total_unique` or `linked_count`,
   show an approximate cost: `"~{{count}} tokens"` using `summary.total_unique`
   as the upper bound. The exact cost (after `max_age_days` filtering) is
   shown in the modal.

3. **Use the CostBadge component** from T03 beneath the button text:
   - `<CostBadge cost={summary?.total_unique ?? 0} balance={creditBalance} />`
   - Or a simpler static approach: render a `text-xs text-slate-400` span
     inside the button showing the approximate cost.

4. **When balance is insufficient** for even a rough estimate
   (`creditBalance < summary.total_unique`), tint the badge red to signal
   the user may not have enough tokens.

### Styling
- Badge text inside button: `text-xs opacity-75 ml-1`
- Keep the button's existing emerald styling; the badge is supplementary.

# F77-T01: Debug Liga HTML + Fix Parser/Fetch

**Status:** planned
**Wave:** 0

## User Story
As a user, I want the Liga refresh button to successfully fetch and display the current price from LigaMagic, so I can see up-to-date Brazilian market prices for my cards.

## Dev Notes

### Root Cause Investigation (confirmed by code analysis)
**Most likely cause: Playwright timing.** The `_fetch_page` method (provider.py:259) does:
```python
page.goto(url, wait_until="networkidle", timeout=30000)
await page.wait_for_timeout(2000)  # Fixed 2s wait
return await page.content()
```
Liga renders prices via JavaScript AFTER `networkidle`. The 2s buffer is insufficient — prices may not be in the DOM when `page.content()` captures HTML.

**Secondary causes to check:**
1. **No wait-for-selector guard** — no `page.wait_for_selector('[class*="preco"]')` before capture
2. **Parser regex** (`src/providers/liga/parser.py:65`) `R\$\s*[\d.,]+` may miss variants (no space, `&nbsp;`, etc.)
3. **Silent error swallowing** (`provider.py:409`) — `LigaError` caught and returns empty `parse_card_prices("", card_name)` (all None)
4. **Card name encoding** — `_build_card_url` uses `quote_plus(card_name)`. If name has special chars, Liga URL may not resolve.

### Files to Modify
- `src/providers/liga/parser.py` — update regex patterns / extraction strategy to match current Liga HTML
- `src/providers/liga/provider.py` — improve error handling in `_search_card_unlocked` (re-raise instead of swallowing errors, or log the actual HTML received)
- `src/api/routers/collection.py:930-1008` — consider using `name_en` with fallback to `name_pt` for Liga search

### Approach
1. **Add `page.wait_for_selector`** for price elements before `page.content()` — e.g., wait for `[class*="preco"]` or any element containing "R$"
2. **Increase wait timeout** or replace fixed 2s with dynamic wait (poll for price presence)
3. **Add HTML dump logging** at debug level to diagnose empty-price cases
4. **Fix parser regex** if needed (test against current Liga HTML)
5. If the issue is card name mismatch, add EN→PT fallback like F47 did for MYP

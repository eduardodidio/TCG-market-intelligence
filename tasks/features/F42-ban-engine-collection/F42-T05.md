**Status:** planned

## User Story

As a collector, I want a clear visual warning when I own banned cards, and
I want to spot them at a glance in my card grid.

## Dev Notes

### Files to create
- `frontend/src/components/BanAlertBanner.tsx`
- `frontend/src/components/BanBadge.tsx`

### BanAlertBanner component

A dismissible warning banner that appears above the collection grid when
the user owns banned or restricted cards.

Props:
```typescript
interface BanAlertBannerProps {
  bannedCount: number;
  restrictedCount: number;
  recentlyChangedCount: number;
  onDismiss: () => void;
}
```

Behavior:
- Only renders when `bannedCount > 0 || restrictedCount > 0`
- Shows red/amber background for severity
- Text: "X cards banned, Y restricted across your collection"
- If `recentlyChangedCount > 0`, append: "Z changed in the last 30 days"
- Dismiss button (X icon) — dismissed state stored in `sessionStorage`
  (reappears on next session so user doesn't permanently miss alerts)
- Click on banner body links to `/collection?filter=banned` (future) or
  scrolls to first banned card
- Uses `useTranslation()` for all text

Styling:
- `bg-red-900/30 border border-red-700 text-red-200` for banned
- `bg-amber-900/30 border border-amber-700 text-amber-200` if only restricted
- Rounded corners, padding, flex layout with icon + text + dismiss button
- Alert/warning SVG icon on the left

### BanBadge component

A small overlay badge for `CollectionCardTile`.

Props:
```typescript
interface BanBadgeProps {
  status: "banned" | "restricted";
  recentlyChanged?: boolean;
}
```

Rendering:
- Absolutely positioned top-left corner (after extras badge if present)
- `status === "banned"`: red pill badge with text "BANNED"
- `status === "restricted"`: yellow pill badge with text "RESTRICTED"
- If `recentlyChanged`, add a pulsing ring animation
  (`animate-pulse ring-2 ring-red-400/50`)
- Small size: `text-[10px] font-bold px-1.5 py-0.5`
- Uses i18n keys for badge text

### Design decisions
- BanBadge shows the "worst" status for the card (banned > restricted).
  If a card is banned in Standard but legal in Modern, show "BANNED".
- BanAlertBanner data comes from `CollectionSummary.banned_count` which is
  already fetched on mount — no extra API call needed for the banner.
- Recently-changed highlight: cards with changes in last 7 days get
  `ring-2 ring-red-400/60` on the tile container div.

# F42-T06: Frontend — LegalityPanel on CollectionCardDetail

**Status:** planned

## User Story

As a collector viewing a card's detail page, I want to see its legality
status across all formats, with highlights on recently changed statuses.

### LegalityPanel component

A panel that displays a card's legality across all formats.

Props:
```typescript
interface LegalityPanelProps {
  entryId: number;
  cardId: number | null;
}
```

Behavior:
1. If `cardId` is null, show a muted message: "Legality data not available
   for unlinked cards"
2. On mount, call `fetchCardLegalities(entryId)` from `banEngine.ts`
3. Show loading skeleton while fetching
4. Display results in a responsive grid (2 columns on mobile, 3 on desktop)
5. Each cell is a `LegalityBadge` (from F41) showing format name + status
6. Sort order: banned first, restricted, legal, not_legal
7. Recently changed items get a "NEW" chip next to them (small cyan badge)
   and a tooltip showing "Changed from {old_status} on {date}"
8. Collapsible: show first 8 formats by default, "Show all N formats"
   expander for the rest
9. Handle empty response gracefully (no legality data synced yet)

### CollectionCardDetail integration

Add the LegalityPanel below the existing "External Links" section:


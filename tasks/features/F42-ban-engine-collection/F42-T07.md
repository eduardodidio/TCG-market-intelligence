# F42-T07: Frontend — wire banner + badges into MyCollection

**Status:** planned
**Wave:** 3

## User Story

As a collector, I want the collection page to show a ban alert banner and
per-card ban indicators so I can see at a glance which cards are affected.

## Dev Notes

### Files to modify
- `frontend/src/pages/MyCollection.tsx`

### Integration steps

1. **Fetch banned card data on mount**:
   - After the existing `fetchCollectionSummary` call, also call
     `fetchCollectionBanned()` from `banEngine.ts`
   - Store result in state: `bannedCards: BannedCollectionCard[]`
   - Build a lookup map: `bannedCardMap: Map<number, { status: string,
     recentlyChanged: boolean }>` keyed by `card_id`
   - This allows O(1) lookup per card tile

2. **Add BanAlertBanner**:
   - Place `<BanAlertBanner>` between the KPI cards and the search/filter bar
   - Feed it `summary.banned_count`, `summary.recently_changed_count`
   - Pass dismiss handler

3. **Add BanBadge to CollectionCardTile**:
   - Modify the `CollectionCardTile` component (defined inline in
     MyCollection.tsx) to accept optional `banStatus` prop
   - If `card.card_id` is in `bannedCardMap`, pass the status to BanBadge
   - Render `<BanBadge>` inside the card image container, positioned
     after the existing extras badge
   - Add `recentlyChanged` ring to tile container when flagged

4. **Pass ban data through the grid render**:
   ```tsx
   {sortedCards.map((card) => {
     const banInfo = card.card_id ? bannedCardMap.get(card.card_id) : undefined;
     return (
       <CollectionCardTile
         key={card.id}
         card={card}
         banStatus={banInfo?.status}
         recentlyChanged={banInfo?.recentlyChanged}
         // ...existing props
       />
     );
   })}
   ```

5. **Refresh ban data with collection**:
   - Include `refreshKey` in the dependency array for the banned cards
     fetch, so it refreshes when the user triggers "Refresh All"

### Performance considerations
- `fetchCollectionBanned()` is called once on mount + refreshKey change
- The bannedCardMap is built once and shared across all tiles via props
- No per-tile API calls

### Edge cases
- If F41 tables don't exist yet (F41 not deployed), the
  `/collection/banned` endpoint returns empty list — banner stays hidden
- If user has no banned cards, banner doesn't render (bannedCount === 0)

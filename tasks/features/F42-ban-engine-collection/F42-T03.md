# F42-T03: API — /collection/banned endpoint + summary extension

**Status:** planned
**Wave:** 1

## User Story

As a frontend developer, I need an API endpoint to fetch banned cards in
my collection and see ban counts in the collection summary.

## Dev Notes

### Files to modify
- `src/api/routers/collection.py` — add new endpoint, extend summary
- `src/api/schemas/collection.py` — add optional fields to CollectionSummary

### New endpoint: `GET /collection/banned`

Add to `src/api/routers/collection.py`:

```python
@router.get("/banned", response_model=ApiResponse[list[BannedCollectionCard]])
def list_banned_cards(
    format: str | None = Query(None),
    days: int = Query(default=30, ge=1, le=365),
    repo: Repository = Depends(get_db),
    user_id: str = Depends(require_auth_or_api_key),
):
```

- Auth required (uses `require_auth_or_api_key`)
- Query params:
  - `format` (optional) — filter to a specific format
  - `days` (default 30) — lookback window for "recently changed" flag
- Calls `ban_analyzer.get_banned_collection_cards(repo, user_id, format, days)`
- Returns paginated response with `BannedCollectionCard` list

### Extend collection summary

Modify `collection_summary` endpoint to include ban counts:

1. Add optional fields to `CollectionSummary` schema:
   ```python
   banned_count: int = 0
   recently_changed_count: int = 0
   ```

2. In the `collection_summary` handler, call
   `ban_analyzer.get_ban_summary(repo, user_id)` and merge into response.
   Wrap in try/except so it degrades gracefully if F41 tables don't exist yet.

### New endpoint: `GET /collection/{entry_id}/legality`

Add to `src/api/routers/collection.py`:

```python
@router.get("/{entry_id}/legality",
            response_model=ApiResponse[list[CardLegalityWithChange]])
def get_entry_legality(
    entry_id: int,
    days: int = Query(default=30, ge=1, le=365),
    repo: Repository = Depends(get_db),
    user_id: str = Depends(require_auth_or_api_key),
):
```

- Fetches the collection entry, verifies ownership
- If `card_id` is None, returns empty list
- Calls `ban_analyzer.get_card_legalities_with_changes(repo, card_id, days)`
- Returns list of `CardLegalityWithChange`

### Route ordering

Place `/collection/banned` BEFORE `/{entry_id}` to avoid path parameter
conflict. Follow existing pattern where `/collection/summary` and
`/collection/sets` are placed before the `/{entry_id}` catch-all.

# F82-T01: Liga Lowest Price Priority

**Status:** done
**Wave:** 0

## User Story

As a collector, I want the system to always store the lowest Liga marketplace price so that my portfolio valuation reflects the best available buy price, not the median.

## Dev Notes

Four files need the same logical change -- swap `mid` to first priority to `low` to first priority in the fallback chain.

### 1. `src/collectors/scan.py` -- `_fetch_price_liga()` (line 54)

**Current:**
```python
price: Decimal | None = normal.get("mid") or normal.get("low") or normal.get("high")
```

**Change to:**
```python
price: Decimal | None = normal.get("low") or normal.get("mid") or normal.get("high")
```

### 2. `src/collectors/liga_sweep.py` -- `_fetch_liga_price()` (line 44)

**Current:**
```python
price: Decimal | None = normal.get("mid") or normal.get("low") or normal.get("high")
```

**Change to:**
```python
price: Decimal | None = normal.get("low") or normal.get("mid") or normal.get("high")
```

### 3. `src/api/routers/collection.py` -- `refresh_card_price_liga` endpoint (line 1059)

**Current:**
```python
price = normal.get("mid") or normal.get("low") or normal.get("high")
```

**Change to:**
```python
price = normal.get("low") or normal.get("mid") or normal.get("high")
```

### 4. `src/providers/liga/provider.py` -- `get_current_price()` (lines 368-379)

**Current:**
```python
min_price = prices["normal"]["low"]
avg_price = prices["normal"]["mid"]

if min_price is None and avg_price is None:
    high = prices["normal"]["high"]
    if high is None:
        ...
        return None
    avg_price = high
```

**Change to:**
```python
low = prices["normal"]["low"]
mid = prices["normal"]["mid"]
high = prices["normal"]["high"]

# Primary price = lowest available
avg_price = low or mid or high
min_price = low  # keep separate min_price for PriceSnapshot

if avg_price is None:
    log.info("liga_no_prices_found", card=card_name, url=url)
    return None
```

This ensures `avg_price` (the primary field stored in price_observations.median_price) always holds the lowest available Liga price.

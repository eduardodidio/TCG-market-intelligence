# F82-T02: CLI reset-prices Command

**Status:** done
**Wave:** 0

## User Story

As an operator, I want a CLI command to wipe all price observations (or only those from a specific source like "liga") so I can reset stale data collected with the wrong pricing strategy and re-scan from scratch.

## Dev Notes

### Why not reuse `db-clear-prices`?

The existing `db-clear-prices` command calls `clear_prices_by_source()` from `src/database/cleanup.py`, which has `PROTECTED_SOURCES = {"liga", "manual"}` and raises `ValueError` when trying to clear Liga prices. This protection was intentional for day-to-day operations but blocks the one-time reset we need now.

Rather than removing the protection (which is useful ongoing), create a new `reset-prices` command that bypasses it.

### 1. New repository method: `delete_all_price_observations()`

**File:** `src/database/repository.py`

Add a method:
```python
def delete_all_price_observations(self, source: str | None = None) -> int:
    """Delete price observations, optionally filtered by source.

    Args:
        source: If provided, only delete rows with this source value.
                If None, delete ALL price observations.

    Returns:
        Number of rows deleted.
    """
```

Implementation:
- Use SQLAlchemy `delete(PriceObservationRow)` with optional `.where(source == ...)` filter
- Single transaction, return `result.rowcount`
- No PROTECTED_SOURCES check -- caller is responsible for safety gates

### 2. New CLI command: `reset-prices`

**File:** `src/cli/main.py`

```
tcg reset-prices [--source liga|myp|manual|jsonld_snapshot] [--confirm] [--db URL]
```

Options:
- `--source` (optional): filter by source. If omitted, deletes ALL price observations from ALL sources.
- `--confirm` (required flag): safety gate. Without it, runs as dry-run showing count only.
- `--db` (optional): database URL, defaults to `get_db_url()`.

Flow:
1. Count rows that would be deleted (dry-run query)
2. Print count and source filter to stdout
3. If `--confirm` not passed: print "Pass --confirm to actually delete." and exit
4. Call `backup_database()` from `src/database/backup.py`
5. Call `repo.delete_all_price_observations(source=source)`
6. Run `VACUUM` to reclaim space
7. Print deleted count and backup path

### 3. VACUUM after delete

Follow the pattern from `cleanup.py`:
```python
with repo.engine.connect() as conn:
    conn.execute(text("VACUUM"))
    conn.commit()
```

# F116-T03: Holographic Foil Shimmer Effect

**Status:** planned
**Wave:** 1 (parallel with T02, depends on T01)

## User Story

As a user viewing foil cards, I want a holographic shimmer effect that makes
foils visually distinct and premium, like inspecting a real foil card.

## Dev Notes

### 1. CSS holographic effect

Create `frontend/src/styles/foil-shimmer.css`:

```css
.foil-shimmer {
  position: relative;
  overflow: hidden;
}

.foil-shimmer::after {
  content: '';
  position: absolute;
  inset: 0;
  background: linear-gradient(
    115deg,
    transparent 20%,
    rgba(255, 255, 255, 0.1) 30%,
    rgba(100, 200, 255, 0.15) 40%,
    rgba(200, 100, 255, 0.15) 50%,
    rgba(255, 200, 100, 0.15) 60%,
    rgba(255, 255, 255, 0.1) 70%,
    transparent 80%
  );
  mix-blend-mode: color-dodge;
  pointer-events: none;
  opacity: 0;
  transition: opacity 0.3s;
  /* Move gradient with mouse via CSS custom properties */
  transform: translateX(var(--shimmer-x, 0%)) translateY(var(--shimmer-y, 0%));
}

.foil-shimmer:hover::after {
  opacity: 1;
}

@media (prefers-reduced-motion: reduce) {
  .foil-shimmer::after {
    display: none;
  }
}
```

### 2. Update Card3DTilt for foil mode

When `foil={true}`:
- Enable glare: `glareEnable={true}`, `glareMaxOpacity={0.15}`
- Add `foil-shimmer` class to container
- Optionally track mouse position via onMove callback to update
  CSS custom properties for shimmer position

```typescript
<Tilt
  // ... base props
  glareEnable={foil}
  glareMaxOpacity={foil ? 0.15 : 0}
  glareColor="rgba(200, 180, 255, 0.3)"
  glarePosition="all"
  onMove={foil ? handleShimmerMove : undefined}
>
  <div className={foil ? "foil-shimmer" : ""}>
    {children}
  </div>
</Tilt>
```

### 3. Foil detection

Cards with `is_foil = true` or `extras` containing foil markers get the
shimmer. The `is_foil` flag exists on collection entries. For catalog cards
without foil info, default to no shimmer.

## Acceptance Criteria

1. Foil cards show rainbow shimmer gradient on hover
2. Shimmer follows mouse position (gradient moves with pointer)
3. Non-foil cards have NO shimmer (clean tilt only)
4. Shimmer respects `prefers-reduced-motion`
5. Shimmer works with dark and light themes

# F116-T01: Card3DTilt Wrapper Component

**Status:** planned
**Wave:** 0

## User Story

As a user viewing cards, I want them to tilt in 3D when I hover with my
mouse, creating a premium card-inspection feel like deckcheck.co.

## Dev Notes

### 1. Install dependency

```bash
cd frontend && npm install react-parallax-tilt
```

`react-parallax-tilt` provides: tiltMaxAngle, glareEnable, scale,
perspective, gyroscope support, and respects `prefers-reduced-motion`.

### 2. Create Card3DTilt component

**File:** `frontend/src/components/Card3DTilt.tsx`

```typescript
import Tilt from "react-parallax-tilt";
import { ReactNode } from "react";

interface Card3DTiltProps {
  children: ReactNode;
  disabled?: boolean;    // for grid performance (disable in large lists)
  foil?: boolean;        // enable holographic effect (T03)
  className?: string;
}

export function Card3DTilt({ children, disabled, foil, className }: Card3DTiltProps) {
  if (disabled) return <div className={className}>{children}</div>;

  return (
    <Tilt
      tiltMaxAngleX={12}
      tiltMaxAngleY={12}
      scale={1.05}
      perspective={1000}
      transitionSpeed={300}
      glareEnable={false}       // enable in T03 for foils
      className={className}
    >
      {children}
    </Tilt>
  );
}
```

### 3. Performance considerations

- `tiltMaxAngleX/Y: 12` — subtle, not distracting in grids
- `scale: 1.05` — replaces existing `hover:scale-[1.02]` on CardTile
- Disable on mobile (no mouse hover) — check via media query or `matchMedia`
- For grids >50 cards, consider IntersectionObserver to only enable for
  visible cards, or disable entirely and only enable on detail/preview views
- Respect `prefers-reduced-motion` — library does this natively

### 4. Remove existing hover scale

When integrating (T02), remove `hover:scale-[1.02]` from CardTile since
Card3DTilt handles scale via `scale={1.05}`.

## Acceptance Criteria

1. `react-parallax-tilt` installed and builds successfully
2. Card3DTilt component renders children with 3D tilt on hover
3. Tilt is subtle (12 degrees max) with smooth 300ms transition
4. Component has `disabled` prop for performance opt-out
5. Component has `foil` prop placeholder for T03

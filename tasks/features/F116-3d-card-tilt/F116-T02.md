# F116-T02: Integrate 3D Tilt in All Card Views

**Status:** planned
**Wave:** 1 (depends on T01)

## User Story

As a user, I want the 3D tilt effect on every card across all pages
(collection, catalog, decks, explore) for a consistent premium experience.

## Dev Notes

### Components to wrap with Card3DTilt

1. **CardTile.tsx** — main card grid component (Collection, Cards pages)
   - Wrap the card image container (not the whole card with text)
   - Remove `hover:scale-[1.02]` and `hover:shadow-lg` (Card3DTilt handles it)
   - Pass `foil={card.is_foil}` if available

2. **CatalogCardTile.tsx** — catalog grid (CatalogPage)
   - Same treatment as CardTile
   - Consider `disabled` for large catalog results (>100 cards)

3. **DeckCardTile.tsx** — deck view cards
   - Wrap image container
   - Keep ownership overlay logic intact

4. **CardHoverPreview.tsx** — floating enlarged card on hover
   - Wrap the enlarged image with Card3DTilt
   - Use larger tiltMaxAngle (18-20) since it's a focused preview

5. **CardImage.tsx** — consider wrapping here instead of each tile
   - PRO: single integration point
   - CON: not all CardImage uses want 3D (e.g., small icons, thumbnails)
   - DECISION: wrap at tile level, not at CardImage level

### Integration pattern

```tsx
// In CardTile.tsx, wrap the image section:
<Card3DTilt foil={card.is_foil} className="aspect-[5/7]">
  <CardImage src={card.image_uri} alt={card.name} />
</Card3DTilt>
```

### Performance guard

For grids with >50 visible cards, add a prop or context to batch-disable:
```tsx
const disableTilt = cardCount > 100; // or use a user setting
<Card3DTilt disabled={disableTilt} ...>
```

## Acceptance Criteria

1. CardTile shows 3D tilt effect on hover
2. CatalogCardTile shows 3D tilt effect on hover
3. DeckCardTile shows 3D tilt effect on hover
4. CardHoverPreview shows enhanced 3D tilt
5. No performance degradation with 50+ card grids
6. Mobile: no jank (tilt disabled or via gyroscope)

- Unit test: CatalogCardTile renders Card3DTilt wrapper

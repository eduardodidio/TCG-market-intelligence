# F62-T02: Provider lifecycle in FastAPI lifespan (open/close)

**Status:** done
**Wave:** 0
**Parallel with:** T01

## User Story

As a system operator, I want the Liga browser to start once at server boot
and close cleanly on shutdown, so that refresh-liga requests don't pay the
~5s Playwright startup cost and don't hit lazy-init edge cases in the
uvicorn event loop.

## Dev Notes

### Problem

`create_registry_from_env()` creates `LigaMagicProvider()` but never calls
`open()`. The browser starts lazily on first `_ensure_page()` call inside a
request handler. In the uvicorn async context, this lazy init can hit edge
cases (subprocess spawning, event loop state) that cause `NotImplementedError`.

The lifespan also never calls `close()` — the browser process leaks on
server shutdown.

### Changes needed

1. **Open Liga provider in lifespan** — after creating the registry in
   `src/api/app.py:lifespan()`, iterate providers and call `open()` on any
   `LigaMagicProvider` instance:
   ```python
   from src.providers.liga.provider import LigaMagicProvider

   for provider in registry.providers:
       if isinstance(provider, LigaMagicProvider):
           await provider.open()
   ```

2. **Close Liga provider on shutdown** — in the lifespan's `yield` teardown:
   ```python
   # After yield (shutdown)
   registry = getattr(app.state, "provider_registry", None)
   if registry:
       for provider in registry.providers:
           if isinstance(provider, LigaMagicProvider):
               await provider.close()
   ```

3. **Wrap open() in try/except** — browser startup failure should not crash
   the server. Log warning and let `_ensure_page` retry lazily as fallback:
   ```python
   try:
       await provider.open()
   except Exception:
       log.warning("liga_browser_startup_failed", exc_info=True)
   ```

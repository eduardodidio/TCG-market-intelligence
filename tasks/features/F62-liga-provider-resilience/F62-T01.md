# F62-T01: Broaden _fetch_page exception handler + add concurrency lock

**Status:** done
**Wave:** 0
**Parallel with:** T02

## User Story

As a collector, when I click Liga refresh on a card, I want the system to
handle ANY Playwright failure gracefully (retry or clear error) instead of
crashing with an opaque "NotImplementedError (no message)".

## Dev Notes

### Problem

`_fetch_page()` at `src/providers/liga/provider.py:241` catches only:
```python
except (TimeoutError, OSError, PlaywrightError) as e:
```

`NotImplementedError` is a subclass of `RuntimeError`, not any of those three.
It escapes to `search_card()`'s generic handler which wraps it as `LigaError`
but the damage is done — the retry logic in `_fetch_page` never fires.

Additionally, the singleton provider shares a single `Page` object with no
concurrency guard. Two concurrent requests navigating the same page can cause
Playwright internal errors.

### Changes needed

1. **Broaden `_fetch_page` except clause** — replace the specific tuple with
   `except Exception as e:`, then categorize inside the handler:
   ```python
   except Exception as e:
       # Playwright-specific or transient — log and retry
       log.warning(
           "liga_request_error",
           url=url,
           attempt=attempt,
           error=str(e) or "(no message)",
           exc_type=type(e).__name__,
       )
       # Reset browser on non-timeout errors
       if not isinstance(e, TimeoutError):
           await self._reset_browser()
       if attempt == self.config.max_retries:
           etype = type(e).__name__
           msg = (
               f"Request failed ({etype}): {e}"
               if str(e)
               else f"Request failed ({etype}, no details) after {attempt} attempts: {url}"
           )
           raise LigaError(msg, url=url, status_code=0, attempts=attempt) from e
       await asyncio.sleep(2 ** attempt)
   ```

2. **Add `asyncio.Lock` to serialize page access**:
   - Add `self._lock = asyncio.Lock()` in `__init__`
   - Wrap `_fetch_page` body (or `search_card` / `get_current_price`) with
     `async with self._lock:`
   - This prevents two concurrent requests from navigating the same page

3. **Improve `_reset_browser` reliability** — add a small `asyncio.sleep(0.5)`
   after closing to let the subprocess fully exit before re-open.

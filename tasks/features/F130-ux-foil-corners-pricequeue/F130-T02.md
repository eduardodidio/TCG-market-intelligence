# F130-T02: Propagate isFoil from Data to CardPreviewModal

**Wave:** 0 (Frontend Visual)
**Parallel with:** T01, T03
**Files to modify:** `frontend/src/components/CardTile.tsx`, `frontend/src/pages/CatalogPage.tsx` (CatalogCardTile), `frontend/src/components/DeckCardTile.tsx`
**Files to create:** (none)

## User Story

As a collector, I want foil cards in my collection to automatically show the
foil visual effect when I open the 3D preview, without needing any manual
toggle, so that my foil cards feel special.

## Problem

All three tile components hardcode `foil={false}` on Card3DTilt and do not
pass `isFoil` to CardPreviewModal:

1. **CardTile.tsx** (line 69): `<Card3DTilt foil={false}>` -- never shows foil.
   Opens `<CardPreviewModal>` without `isFoil` prop.
2. **CatalogCardTile** (CatalogPage.tsx): `<Card3DTilt foil={false}>` -- catalog
   cards don't have foil info, so this stays `false`. But it still doesn't pass
   `isFoil` to CardPreviewModal.
3. **DeckCardTile.tsx** (line 200): `<Card3DTilt foil={false}>` -- deck view.

### Data availability
- `CollectionCard` type already has `is_foil: boolean` (from backend, line 127
  of `api.ts`). The backend computes it via `is_foil_entry(extras)`.
- `CardSummary` (used by CardTile) does NOT have `is_foil`. CardTile receives
  `CardSummary` via props.
- `CatalogCard` does NOT have `is_foil`.

### Strategy
- **CardTile**: Add optional `isFoil?: boolean` prop to `CardTileProps`.
  The parent component (MyCollectionPage) already has `CollectionCard` data
  with `is_foil` -- pass it down.
- **CatalogCardTile**: No foil data available from catalog. Keep `foil={false}`.
  No change needed.
- **DeckCardTile**: Check if deck card data includes foil info. If not, keep
  `foil={false}`. The deck view may link to collection entries that have foil
  info -- check the data flow.

## Dev Notes

### CardTile changes
1. Add `isFoil?: boolean` to `CardTileProps` interface.
2. Replace `<Card3DTilt foil={false}>` with `<Card3DTilt foil={isFoil ?? false}>`.
3. Pass `isFoil={isFoil}` to `<CardPreviewModal>`.
4. In the parent that renders CardTile for collection views, pass
   `isFoil={card.is_foil}`.

### DeckCardTile changes
1. Check if DeckCardTile receives foil info from its data source.
2. If the deck card data includes `is_foil` or `extras`, propagate to
   Card3DTilt and CardPreviewModal.
3. If not available, keep `foil={false}` -- no change.

### CatalogCardTile
- No change. Catalog data doesn't include foil status.

### Parent components to update
- `MyCollectionPage.tsx` or wherever CardTile is rendered with collection data:
  find the mapping and add `isFoil={entry.is_foil}`.
- Search for all `<CardTile` usages and verify each one passes isFoil when
  the data is available.

## Edge Cases

- Cards in collection that have `extras=null` -- `is_foil` should be `false`
- Cards viewed from non-collection contexts (search, trending) -- no foil info,
  default to non-foil
- CardTile used in DeckView with collection entries that are foil

## User Story

As an admin, I want to see pending and processed price update requests in the
admin panel, so I can monitor the queue health and manually trigger processing
if needed.

## Problem

There is no visibility into the price update request queue from the admin UI.
The admin needs to:
1. See how many requests are pending/processing/completed/failed
2. See request details (card name, user, timestamps)
3. Trigger processing from the admin panel (calls the local machine)

## Dev Notes

### Backend: Admin endpoints (admin.py)

1. **GET /admin/price-requests**: List requests with filters
```python
@admin_router.get("/price-requests")
async def list_price_requests(
    status: str | None = None,
    limit: int = 50,
    offset: int = 0,
    repo = Depends(get_db),
    user = Depends(require_admin),
):
    rows, total = repo.get_price_requests(status=status, limit=limit, offset=offset)
    # Join card name for display
    items = []
    for r in rows:
        card = repo.get_card_by_id(r.card_id)
        items.append({
            "id": r.id,
            "card_id": r.card_id,
            "card_name": card.name_en if card else "Unknown",
            "user_id": r.user_id,
            "status": r.status,
            "requested_at": r.requested_at.isoformat(),
            "processed_at": r.processed_at.isoformat() if r.processed_at else None,
            "result_price": float(r.result_price) if r.result_price else None,
            "error_message": r.error_message,
            "attempts": r.attempts,
        })
    return success_response(data={"items": items, "total": total})
```

- No pending requests: show empty state with message
- Very long error messages: truncate with tooltip/expand
- Admin triggers process but local machine is off: show info that processing
  happens locally

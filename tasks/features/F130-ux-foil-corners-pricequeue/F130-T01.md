# F130-T01: Enhanced Foil Shimmer CSS + Card3DTilt Improvements

**Wave:** 0 (Frontend Visual)
**Parallel with:** T02, T03
**Files to modify:** `frontend/src/styles/foil-shimmer.css`, `frontend/src/components/Card3DTilt.tsx`
**Files to create:** (none)

## User Story

As a collector inspecting a foil card in the 3D preview, I want to see a vivid
holographic/rainbow shimmer effect that reacts to the mouse tilt angle, so that
the card feels like a real foil.

## Problem

The current foil effect is barely noticeable:
- `foil-shimmer.css` uses `opacity: 0` by default, only showing on `:hover`
  with `opacity: 1` -- in the modal the user is always hovering, so it's
  static and subtle.
- `glareMaxOpacity` in Card3DTilt is only `0.15` (very faint).
- The shimmer gradient is a single fixed angle (115deg) and doesn't react
  to the tilt position.
- Colors are muted (`rgba` at 10-15% opacity).

## Dev Notes

### foil-shimmer.css enhancements
1. **Always-on for modal context**: Add a `.foil-shimmer--active` variant
   (or use `.foil-shimmer` directly when `foil=true`) that starts with
   `opacity: 1` instead of requiring hover.
2. **Animated gradient**: Use CSS `@keyframes` to slowly shift the gradient
   angle or position, creating a "moving light" effect even without tilt.
   Example: `background-position` animation over 3-4s cycle.
3. **Richer colors**: Increase color stop opacities from 10-15% to 20-35%.
   Add more color stops for a rainbow spectrum: red, orange, yellow, green,
   cyan, blue, violet. Use `color-dodge` or `screen` blend mode.
4. **Multiple layers**: Consider a second `::before` pseudo-element with a
   different gradient angle for depth (optional, only if performance is ok).
5. **Respect `prefers-reduced-motion`**: Keep the existing media query guard.

### Card3DTilt.tsx enhancements
1. **Increase glare for foil**: `glareMaxOpacity` from `0.15` to `0.35-0.4`
   when `foil=true`.
2. **Glare color**: Change from `rgba(200, 180, 255, 0.3)` to a warmer
   holographic white `rgba(255, 255, 255, 0.4)` for more realism.
3. **Consider `glareBorderRadius`**: If react-parallax-tilt supports it,
   match the card's border radius so glare doesn't overflow corners.

### Performance
- CSS animations are GPU-accelerated (`transform`, `opacity`) -- no JS needed.
- Avoid `filter: blur()` or heavy `box-shadow` animations on mobile.
- Test on low-end devices -- the animation should be smooth or gracefully
  degrade.

## Edge Cases

- Cards where the image fails to load (skeleton placeholder) -- shimmer
  should still render over the placeholder gradient
- Very dark card art -- shimmer should still be visible
- Very bright/white card art -- shimmer should not wash out the image

## Testing

- Unit test: Card3DTilt renders with `foil-shimmer` class when `foil={true}`
- Unit test: Card3DTilt renders WITHOUT `foil-shimmer` when `foil={false}`
- Unit test: glareMaxOpacity is 0.35+ when foil=true, 0 when foil=false
- Visual test (manual): open CardPreviewModal for a foil card, verify
  holographic effect is vivid and animates
- Visual test (manual): open CardPreviewModal for a non-foil card, verify
  NO shimmer or glare
- Accessibility: verify `prefers-reduced-motion` disables animation

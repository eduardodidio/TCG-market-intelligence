# F130-T03: Fix Card Corner Rounding in 3D Preview

**Wave:** 0 (Frontend Visual)
**Parallel with:** T01, T02
**Files to modify:** `frontend/src/components/Card3DTilt.tsx`, `frontend/src/components/CardPreviewModal.tsx`, `frontend/src/styles/foil-shimmer.css`
**Files to create:** (none)

## User Story

As a user inspecting a card in the 3D preview, I want the card corners to be
smoothly rounded like a real Magic card, without white/square corners showing
through, so the preview looks realistic.

## Problem

When viewing cards in CardPreviewModal (3D tilt), white corners are visible.
The issue is in the wrapper chain:

1. **CardPreviewModal** `<img>` has `className="rounded-lg"` (~8px) -- this
   rounds the image itself.
2. **Card3DTilt** wraps with `<Tilt>` from react-parallax-tilt -- this renders
   a `<div>` that does NOT have `overflow: hidden` or `border-radius`.
3. **foil-shimmer** `<div>` (when foil=true) has `overflow: hidden` but no
   `border-radius`, so the shimmer overlay clips but the tilt wrapper doesn't.
4. **react-parallax-tilt** internally renders perspective transforms that can
   expose the underlying background at corners during tilt rotation.

### Root cause
The Tilt component's outer div has no `overflow: hidden` and no border-radius.
During tilt, the 3D perspective transform reveals the parent background (white
or transparent) at the corners. The `rounded-lg` on the image creates rounded
corners on the image, but the rectangular tilt wrapper extends beyond.

## Dev Notes

### Fix strategy
Apply `overflow-hidden` and matching `border-radius` at EVERY level of the
wrapper chain:

1. **Card3DTilt.tsx**: Add `style={{ borderRadius: '12px', overflow: 'hidden' }}`
   to the `<Tilt>` component. react-parallax-tilt accepts a `style` prop.
   Use `12px` (~rounded-xl) for realistic Magic card corners.

2. **foil-shimmer.css**: Add `border-radius: inherit` to `.foil-shimmer` so
   it inherits from the parent Tilt wrapper. The existing `overflow: hidden`
   is already correct.

3. **CardPreviewModal.tsx**: Change `<img className="rounded-lg ...">` to
   `rounded-xl` (12px) to match the tilt wrapper radius. Or remove the
   img border-radius entirely since the parent clips.

4. **Card3DTilt inner wrapper**: If the Tilt renders an inner div, ensure
   it also has overflow hidden. Check react-parallax-tilt docs for
   `style` and `innerStyle` props.

### Thumbnail tiles (CardTile, CatalogCardTile, DeckCardTile)
These use Card3DTilt with smaller images in the grid. Check if they also
show corner issues:
- The image container has `overflow-hidden` via the aspect-[5/7] div.
- The Card3DTilt wrapper in tiles may also need the same fix.
- Test visually -- if tiles don't tilt enough to expose corners, may not
  need fixing (default tiltMaxAngle=12 vs modal's 18).

### Border radius value
Real Magic cards have ~3.5mm corner radius on a 63x88mm card = ~3.98%.
For a 400px wide preview image, that's ~16px. Use `rounded-xl` (12px) or
a custom `rounded-[16px]` for maximum realism.

## Edge Cases

- Cards with transparent/dark backgrounds (e.g. full-art lands) -- no white
  showing but corners should still be rounded
- Very small viewport (mobile) -- modal shrinks, radius should scale or
  stay proportional
- Foil cards: the foil-shimmer overlay must also be clipped to the same radius

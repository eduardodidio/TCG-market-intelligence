# F113-T06: Set Completion UX — Collapse, Icons, Navigate

**Status:** planned
**Wave:** 1
**Request:** R6

## User Story

As a collector on My Collection page, I want the set completion section to
be minimized by default (showing just a summary), display set icons instead
of just text codes, and let me click a set to see only that set's cards
in my collection.

## Dev Notes

### Existing Icon Infrastructure

The project already has set icon support via:
- **`frontend/src/utils/scryfall.ts`** — `scryfallSetIconUrl(setCode)` returns
  `https://svgs.scryfall.io/sets/{mapped}.svg` with MYP-to-Scryfall code mapping
- **`frontend/src/components/SetIconFilter.tsx`** — Horizontal scrollable set
  icon filter (used in MyCollection). Uses `invert brightness-200` CSS for dark
  backgrounds. Has fallback to uppercase text on image error. 26 tests.

### File: `frontend/src/components/SetCompletionBar.tsx`

Current behavior: Shows a list of sets with completion bars, always expanded.
Currently does NOT use set icons — only text badges (`w-12 monospace`).

#### Change 1: Collapsed by default

- Wrap the set list in a collapsible section (like the Beta nav in Layout.tsx)
- Default state: `collapsed = true`
- Show a summary line when collapsed: e.g. "Set Completion (5 sets)" with
  a chevron toggle
- Store expand/collapse preference in `localStorage` key `tcg_set_completion_open`

#### Change 2: Set icons

- Reuse `scryfallSetIconUrl()` from `frontend/src/utils/scryfall.ts`
- Render a small (16x16) `<img>` with same styling as SetIconFilter:
  `className="w-4 h-4 invert brightness-200"`
- Add `onError` fallback to show text code if SVG fails to load

#### Change 3: Click to navigate

- Wrap each set row in a `<Link>` or clickable `<button>` that navigates to
  `/collection?set={set_code}`
- This uses the existing set filter on MyCollection page
- The MyCollection page already reads `set` from `searchParams`
- Add cursor-pointer and hover effect to indicate clickability

### File: `frontend/src/pages/MyCollection.tsx`

- Ensure the `set` search param is read and applied to the filter on mount
- The `SetIconFilter` component already handles set selection

### Acceptance Criteria

1. Set completion section is collapsed by default
2. Expanding shows set list with SVG icons + completion bars
3. Clicking a set navigates to `/collection?set=<code>`
4. Collapse state persists via localStorage

# F113-T09: Cards Page — Scroll Reset, Set Icons, Price Refresh

**Status:** done
**Wave:** 2
**Request:** R5 + R9 (consolidated to avoid Cards.tsx conflicts)

## User Story

As a user browsing the Explore Cards page, I want:
1. The list to scroll back to top when I change sort order
2. Set icons to appear next to set codes in the filter chips
3. An "Update Price" button on each card to refresh from Liga
4. A "Refresh All Prices" action to batch-refresh visible cards

## Dev Notes

### Part A: Scroll Reset on Sort (R5)

**File: `frontend/src/pages/Cards.tsx`**

When `sortBy` or `sortDir` changes, the page fetches new data but the scroll
position stays wherever the user was. Fix:

1. In the `useEffect` that fetches cards on filter change (line ~100), add
   `window.scrollTo({ top: 0, behavior: 'smooth' })` after setting loading state
2. This already happens implicitly since `setCards([])` clears the grid,
   but the scroll position remains. Explicitly scroll to top.

**Also apply to**: `frontend/src/pages/MyCollection.tsx` (same pattern)

### Part B: Set Icons in FilterChips (R9)

**Existing infrastructure:** `scryfallSetIconUrl(setCode)` in
`frontend/src/utils/scryfall.ts` returns the correct Scryfall SVG URL with
MYP-to-Scryfall code mapping. `SetIconFilter.tsx` already renders icon buttons
with `invert brightness-200` styling and fallback text.

**File: `frontend/src/components/FilterChips.tsx`**

Currently shows text-only chips for set codes. Add set icon support:

1. Add an optional `icon` property to chip options interface
2. Render icon img before label: `<img src={icon} className="w-4 h-4 invert brightness-200 inline mr-1" />`
3. Add `onError` fallback to hide img on failure

**File: `frontend/src/pages/Cards.tsx`**

Update `setOptions` mapping (line ~177) to include icon URLs:
```typescript
import { scryfallSetIconUrl } from "../utils/scryfall";
const setOptions = sets.map((s) => ({
  label: s.set_code,
  value: s.set_code,
  icon: scryfallSetIconUrl(s.set_code),
}));
```

### Part C: Update Price Button per Card (R9)

**File: `frontend/src/components/CardTile.tsx`**

Add a small refresh icon button on each card tile:
1. On click, call the existing refresh-liga endpoint:
   `POST /api/v1/collection/{entry_id}/refresh-liga`

   BUT: Cards page shows `CardSummary` (not collection entries). The card
   may not be in the user's collection. Need a different approach.

**Alternative**: Create a new endpoint `POST /api/v1/cards/{card_id}/refresh-price`
that triggers a Liga price lookup for any card (not just collection entries).
This endpoint:
- Costs 1 credit
- Calls Liga provider with the card's `name_en`
- Stores the new price observation
- Returns the updated price

**File: `src/api/routers/cards.py`** — Add the new endpoint

**File: `frontend/src/api/cards.ts`** — Add `refreshCardPrice(cardId)` function

**File: `frontend/src/components/CardTile.tsx`** — Add refresh button with
loading state, only visible to authenticated users

### Part D: Refresh All Prices (R9)

**File: `frontend/src/pages/Cards.tsx`**

Add a "Refresh All" button in the sticky filter bar:
1. When clicked, iterates visible cards and calls `refreshCardPrice` for each
2. Shows progress (e.g. "Refreshing 3/12...")
3. Rate-limited: 1 request at a time with 1s delay between
4. Only visible to authenticated users
5. Costs 1 credit per card (show total cost before confirming)

Use a `CreditConfirmModal` before starting the batch refresh.

### Acceptance Criteria

1. Changing sort resets scroll to top on Cards and MyCollection pages
2. Set filter chips show SVG icons
3. Each card tile has a refresh price button (authenticated only)
4. "Refresh All" button in filter bar with credit confirmation
5. Prices update in real-time after refresh

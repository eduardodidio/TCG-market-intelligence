# F113-T04: Web Search PT/EN Name Fallback

**Status:** planned
**Wave:** 0
**Request:** R10

## User Story

As a user searching for "Mox de Ambar" (Portuguese name) on the web search,
I want the system to find the card even if Liga only indexes the English name
"Mox Amber", so I get results regardless of the language I search in.

## Dev Notes

### Current Behavior

`src/api/routers/card_search.py` sends the user query directly to
`liga_provider.search_card(q.strip())`. If Liga doesn't match the name
(e.g. Portuguese vs English), it returns empty results.

### Solution: Local Catalog Name Lookup

Before searching Liga, or as a fallback when Liga returns empty:

1. **Lookup in local DB**: query `cards` table for `name_pt LIKE :q` or
   `name_en LIKE :q` (case-insensitive)
2. If a match is found, extract BOTH `name_en` and `name_pt`
3. If the original query was in Portuguese (matched `name_pt`), retry Liga
   search with `name_en`
4. If the original query was in English (matched `name_en`), retry Liga
   search with `name_pt`

### Implementation

**File: `src/api/routers/card_search.py`**

Add a helper function:

```python
def _find_alternate_name(repo: Repository, query: str) -> str | None:
    """Find alternate language name for a card.

    If query matches name_pt, return name_en (and vice versa).
    Uses the local card catalog (Scryfall-seeded data).
    """
    from sqlalchemy import text
    from sqlalchemy.orm import Session

    sql = """
        SELECT name_en, name_pt FROM cards
        WHERE name_en LIKE :q OR name_pt LIKE :q
        LIMIT 1
    """
    with Session(repo.engine) as session:
        row = session.execute(text(sql), {"q": f"%{query}%"}).fetchone()

    if not row:
        return None

    # If query matches PT name, return EN; if EN, return PT
    if row.name_pt and query.lower() in row.name_pt.lower():
        return row.name_en
    if row.name_en and query.lower() in row.name_en.lower():
        return row.name_pt
    return None
```

Modify `_search_via_liga()`:
- After getting empty results, call `_find_alternate_name(repo, q)`
- If an alternate name is found, retry `liga_provider.search_card(alternate_name)`
- Return the retry results (or empty if still nothing)

### Edge Cases

- Query matches multiple cards: use first match (LIMIT 1)
- Alternate name is None (card has no PT translation): skip retry
- Both searches fail: return empty (current behavior)
- Don't deduct a second credit for the retry (it's part of the same search)

# Task F145-T04 — Compact/collapsible rarity + color filters on mobile

**Feature:** F145
**Wave:** 2
**Type:** frontend
**Depends on:** F145-T02
**Status:** planned

## User Story

As a mobile user browsing the catalog, I want the rarity and color filter
chips to stay accessible without taking up too much vertical space, so that
I can see more card results on my screen.

## Objective

Reorganize the collapsible filter panel so rarity chips, color chips, price
toggle, and owned filter fit comfortably on small screens. Remove the sort
section from the panel (it moved to the sticky bar in T02). Ensure the
filter panel is compact and the toggle button shows a badge count of active
filters.

## Dev Notes

### Current collapsible panel contents (after T02 + T03)

After T02 removes the sort selects and T03 adds the owned filter, the
collapsible panel will contain:
1. Set filter (removed — now in sticky bar via SetIconFilter from T02)
2. Rarity chips
3. Color identity chips
4. Has price toggle
5. Owned filter chips (from T03)
6. Clear filters button

Items 1 and sort were the bulkiest sections. After T02 moves them out, the
panel is already lighter. This task focuses on:

### Layout changes

1. **Remove set filter from collapsible panel** — it is now in the sticky
   bar as SetIconFilter (from T02). The collapsible panel should NOT
   duplicate it.

2. **Horizontal layout on desktop** — arrange rarity + color + price +
   owned in a 2x2 or single-row grid on wider screens:
   ```
   desktop:  [Rarity chips] [Color chips] [Has Price] [Owned] [Clear]
   mobile:   [Rarity chips     ]
             [Color chips      ]
             [Has Price] [Owned]
             [Clear]
   ```
   Use Tailwind responsive classes: `flex flex-col sm:flex-row sm:flex-wrap gap-4`.

3. **Compact chip sizing on mobile** — reduce padding on filter chips for
   `sm:` breakpoint. Use `px-2 py-1 text-xs` on mobile, `px-3 py-1.5 text-sm`
   on desktop.

4. **Filter badge count** — the Filters toggle button already shows a count
   badge (lines 479-486). After T02/T03, update the count to include:
   - `selectedSet !== null` (now via SetIconFilter, but still counts)
   - `selectedRarities.size > 0`
   - `selectedColors.size > 0`
   - `hasPrice !== ""`
   - `ownedFilter !== "all"`
   Exclude sort from the count (sort is always active, not a "filter").

5. **Mobile: auto-close filter panel** when a filter is applied (optional
   nice-to-have — reduces taps). If implemented, do it via an effect that
   watches filter changes and closes after a 300ms delay on mobile widths.

## Acceptance criteria

- [ ] Collapsible filter panel does NOT contain set dropdown or sort selects
- [ ] Rarity + color chips render on a single row on desktop, stacked on mobile
- [ ] Filter chips have compact sizing on small screens
- [ ] Filter badge count reflects all active filters (rarity, color, price, owned, set)
- [ ] Clear Filters button resets all filters including owned and set
- [ ] Panel opens/closes smoothly via the Filters toggle button
- [ ] No horizontal overflow on mobile (320px viewport)

## Test scenarios

- **Happy path:** Open filters on mobile -> all chips visible without overflow
- **Happy path:** Badge shows "3" when rarity + color + has_price are active
- **Edge case:** All filters active -> badge shows correct total count
- **Edge case:** Clear filters resets badge to 0 and hides badge element
- **Boundary:** 320px viewport width -> no horizontal scroll in filter panel

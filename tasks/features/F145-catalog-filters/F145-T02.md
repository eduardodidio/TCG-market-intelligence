# Task F145-T02 — Replace set dropdown + sort selects with SetIconFilter + SortSelect

**Feature:** F145
**Wave:** 1
**Type:** frontend
**Depends on:** F145-T01
**Status:** planned

## User Story

As a user browsing the catalog, I want the same visual set filter (icon
buttons) and unified sort dropdown I use in My Collection, so that the
experience is consistent across pages.

## Objective

Replace the plain `<select>` set dropdown and the dual sort_by/sort_dir
selects in CatalogPage with the existing `SetIconFilter` and `SortSelect`
components. Define `CATALOG_SORT_OPTIONS` in `SortSelect.tsx`.

## Dev Notes

### SetIconFilter integration

- File: `frontend/src/pages/CatalogPage.tsx`
- Current set filter (lines 498-516): a `<select>` element with `setOptions`
  built from `useCatalogSets()` as `{ value: set_code, label: "set_code (count)" }`.
- Replace with `<SetIconFilter>` component (already used in MyCollection).
- `SetIconFilter` expects `options: { label: string; value: string }[]`,
  `selected: string | null`, `onSelect: (value: string | null) => void`.
- Build options from `useCatalogSets()`:
  ```tsx
  const setIconOptions = sets.map((s) => ({
    label: s.set_code,
    value: s.set_code,
  }));
  ```
- Change `selectedSet` state from `string` to `string | null` (SetIconFilter
  uses `null` for "all", not empty string). Update all references:
  - `filters.set_code` should use `selectedSet ?? ""`
  - URL param sync: write `set_code` only when `selectedSet !== null`
  - `handleClearFilters`: set to `null` instead of `""`
  - `hasActiveFilters`: check `selectedSet !== null` instead of `!== ""`
- Place `SetIconFilter` inside the sticky bar, below the search row (same
  position as MyCollection — line 777-778 of MyCollection).

### SortSelect integration

- Current sort UI (lines 596-621): two separate `<select>` elements for
  sort_by and sort_dir inside the collapsible filter panel.
- Replace with single `<SortSelect>` in the sticky bar (top row, next to
  SearchBar and GridSizeToggle), matching MyCollection layout.
- Add `CATALOG_SORT_OPTIONS` to `frontend/src/components/SortSelect.tsx`:
  ```ts
  export const CATALOG_SORT_OPTIONS: SortOption[] = [
    { labelKey: "sort.nameAZ", sortBy: "name", sortDir: "asc" },
    { labelKey: "sort.nameZA", sortBy: "name", sortDir: "desc" },
    { labelKey: "sort.set", sortBy: "set_code", sortDir: "asc" },
    { labelKey: "sort.priceHighLow", sortBy: "price", sortDir: "desc" },
    { labelKey: "sort.priceLowHigh", sortBy: "price", sortDir: "asc" },
    { labelKey: "sort.rarityMythicFirst", sortBy: "rarity", sortDir: "asc" },
    { labelKey: "sort.rarityCommonFirst", sortBy: "rarity", sortDir: "desc" },
    { labelKey: "sort.cardNumber", sortBy: "collector_number", sortDir: "asc" },
  ];
  ```
- Add i18n keys for new sort labels (`sort.rarityMythicFirst`,
  `sort.rarityCommonFirst`) to `frontend/src/i18n/` locale files (en + pt).
- Remove the old sort_by and sort_dir `<select>` elements from the
  collapsible filter section.
- The `SortSelect` value format is `"sortBy-sortDir"`. The `onChange`
  callback gives `(sortBy, sortDir)` — map these to existing state setters.

### Sticky bar layout (target)

```
Row 1: [SearchBar (flex-1)] [SortSelect] [GridSizeToggle]
Row 2: [SetIconFilter — full width, horizontally scrollable]
```

This matches MyCollection's layout exactly (lines 766-779).

## Acceptance criteria

- [ ] Set filter renders as `SetIconFilter` with Scryfall set icons
- [ ] Clicking a set icon filters the catalog to that set
- [ ] Clicking the active set icon (or "All") clears the set filter
- [ ] SortSelect renders in the sticky bar with all 8 CATALOG_SORT_OPTIONS
- [ ] Changing sort updates URL params and re-fetches cards
- [ ] GridSizeToggle still present and functional

- [ ] Layout matches MyCollection's sticky bar structure
- [ ] URL search params persist set_code, sort_by, sort_dir correctly

## Test scenarios

- **Happy path:** Select set icon -> cards filter to that set -> URL updates
- **Happy path:** Change sort to "Price: High to Low" -> cards re-order
- **Edge case:** Page loads with `?set_code=mh3` in URL -> SetIconFilter
  shows mh3 as selected, scrolled into view
- **Edge case:** No sets available -> SetIconFilter not rendered (empty guard)
- **Error scenario:** Invalid sort value in URL -> fallback to name-asc

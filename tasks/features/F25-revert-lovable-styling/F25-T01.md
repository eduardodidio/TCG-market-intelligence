## User Story

As a developer, I want to remove the Lovable design system infrastructure
so the project uses plain Tailwind classes without custom CSS properties.

## Dev Notes

### 1. Revert `frontend/tailwind.config.ts`

Restore to pre-F24 state:

```ts
import type { Config } from 'tailwindcss';

export default {
  darkMode: 'class',
  content: ['./index.html', './src/**/*.{ts,tsx}'],
  theme: {
    extend: {
      colors: {
        surface: {
          DEFAULT: '#1e293b', // slate-800
        },
      },
    },
  },
  plugins: [],
} satisfies Config;
```

### 2. Revert `frontend/src/index.css`

Remove the `@import './styles/design-tokens.css'` line. Restore body to:

```css
@layer base {
  body {
    @apply bg-slate-900 text-slate-100 antialiased;
  }
}
```

Remove `html { color-scheme: dark; }` if not needed, or keep if it was
pre-F24.

### 3. Delete files

- `frontend/src/styles/design-tokens.css`
- `docs/lovable/LOVABLE_PROMPT.md`
- `docs/design/lovable-tokens.md`

### 4. Verify

After these changes, the app will have broken styling (components still
reference tcg-* classes). This is expected — T02-T04 fix the components.

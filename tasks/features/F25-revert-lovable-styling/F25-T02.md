# F25-T02: Revert Layout & Navigation Components

- **Wave:** 1
- **Status:** planned
- **Depends on:** F25-T01
- **Type:** frontend

## User Story

As a user, I want the layout, sidebar, and shared UI components to use the
original slate dark theme instead of the Lovable design tokens.

## Dev Notes

Replace all `tcg-*` Tailwind classes with their slate equivalents in these
shared/structural components:

### Components to update:

1. **`Layout.tsx`** — sidebar, topbar, nav items, user menu
2. **`SearchBar.tsx`** — input styling
3. **`SortSelect.tsx`** — select dropdown
4. **`GridSizeToggle.tsx`** — toggle buttons
5. **`CurrencyToggle.tsx`** — currency selector
6. **`LanguageSelector.tsx`** — language toggle
7. **`LoadingSpinner.tsx`** — spinner styling
8. **`Skeleton.tsx`** — skeleton loaders

### Mapping cheat sheet:

- `bg-tcg-bg` → `bg-slate-900`
- `bg-tcg-surface` / `bg-tcg-card` → `bg-slate-800`
- `bg-tcg-card-alt` → `bg-slate-700`
- `border-tcg-border` → `border-slate-600`
- `text-tcg-text` → `text-slate-100`
- `text-tcg-muted` → `text-slate-400`
- `text-tcg-primary` → `text-indigo-400` or `text-cyan-400`
- `hover:bg-tcg-primary-hover` → `hover:bg-indigo-400`
- `shadow-tcg-*` → `shadow-md` or `shadow-lg`
- `rounded-tcg-*` → `rounded-md` or `rounded-lg`
- `font-tcg-sans` → remove (default)
- `font-tcg-mono` → `font-mono`
- `ring-tcg-*` → `ring-slate-500` or `ring-indigo-400`

### Important:

- Keep ALL functionality (click handlers, state, i18n translations)
- Only change class names / styling
- Use `git show dbb7b37^:<file>` to reference pre-F24 styling when unsure

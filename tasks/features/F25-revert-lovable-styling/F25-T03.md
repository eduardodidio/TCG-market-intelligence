# F25-T03: Revert Card & Data Display Components

- **Wave:** 1
- **Status:** planned
- **Depends on:** F25-T01
- **Type:** frontend

## User Story

As a user, I want the card tiles, charts, tables, and data display
components to use the original slate dark theme.

## Dev Notes

Replace all `tcg-*` Tailwind classes with slate equivalents in data display
components:

### Components to update:

1. **`CardTile.tsx`** — card grid items
2. **`DeckCardTile.tsx`** — deck card display
3. **`KpiCard.tsx`** — KPI stat cards
4. **`PriceChart.tsx`** — chart container and Recharts config
5. **`MoversPreview.tsx`** — movers preview section
6. **`MoversTable.tsx`** — movers full table
7. **`ScanForm.tsx`** — scan trigger forms
8. **`ScanHistoryTable.tsx`** — scan history table
9. **`FilterChips.tsx`** — set filter chips
10. **`SetIconFilter.tsx`** — set icon filter
11. **`ErrorBanner.tsx`** — error display
12. **`EmptyState.tsx`** — empty state display
13. **`FreshnessIndicator.tsx`** — data freshness
14. **`CurrencyIndicator.tsx`** — currency display
15. **`DeckImportModal.tsx`** — import modal

### Same mapping as T02. Key considerations:

- PriceChart uses tcg colors for Recharts config (stroke, fill, grid) —
  replace with hex values directly (e.g., `#0f172a` for slate-900,
  `#22d3ee` for cyan-400)
- CardTile hover effects: replace `hover:border-tcg-primary` with
  `hover:border-cyan-400` or `hover:border-indigo-400`
- Error/empty states: `text-tcg-loss` → `text-red-400`,
  `text-tcg-warning` → `text-amber-400`

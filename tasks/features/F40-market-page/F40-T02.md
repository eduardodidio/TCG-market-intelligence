# F40-T02 -- Frontend: PeriodSelector Extraction + MarketSummary Section

**Wave:** 1
**Depends on:** T01 (backend endpoints must exist)
**Produces:** Reusable PeriodSelector component, MarketSummaryKpis section.

## Objective

Extract the period selector pattern (7d/30d/90d button group) already
duplicated in `MarketMovers.tsx` into a shared reusable component. Build
the Market Summary KPI row that displays aggregated market statistics.

## Deliverables

### 1. PeriodSelector Component (`frontend/src/components/PeriodSelector.tsx`)

Extract the period button group pattern from `MarketMovers.tsx` into a
standalone component.

Props:
```typescript
interface PeriodSelectorProps {
  value: string;
  onChange: (period: string) => void;
  periods?: string[];  // default: ["7d", "30d", "90d"]
  className?: string;
}
```

Styling: reuse the exact button group pattern from `MarketMovers.tsx`
(indigo-500 active, slate-800 inactive, focus ring).

### 2. Refactor MarketMovers.tsx

Replace the inline period button group in `MarketMovers.tsx` with the
new `PeriodSelector` component. Behavior must be identical -- this is a
pure extraction refactor with no visual changes.

### 3. MarketSummaryKpis Component (`frontend/src/components/MarketSummaryKpis.tsx`)

A row of `KpiCard` components displaying market summary data.

Props:
```typescript
interface MarketSummaryKpisProps {
  data: MarketSummaryResponse | null;
  loading: boolean;
  currency: string;
}
```

Cards displayed:
1. **Cards Tracked** -- `total_cards_tracked`, number format.
2. **Avg Price** -- `avg_price` with `CurrencyIndicator` and
   `formatCurrency`.
3. **Avg Change** -- `avg_price_change_pct` with green/red arrow and
   color. Format as "+X.XX%" or "-X.XX%".
4. **Market Sentiment** -- `market_direction` as a badge:
   - "up" -> green badge "Bullish" (or i18n key)
   - "down" -> red badge "Bearish"
   - "flat" -> gray badge "Flat"
5. **Gainers Ratio** -- `gainers_count / (gainers_count + losers_count)`
   as percentage, e.g., "67% up".

Loading state: render 5x `SkeletonKpi` when `loading=true`.
Empty state: show dashes ("--") when `data` is null.

### 4. MarketSummary TypeScript Type

Add to `frontend/src/types/api.ts`:

```typescript
export interface MarketSummaryResponse {
  total_cards_tracked: number;
  total_observations: number;
  avg_price: number | null;
  avg_price_change_pct: number | null;
  gainers_count: number;
  losers_count: number;
  unchanged_count: number;
  market_direction: string;
  period: string;
  currency: string;
  computed_at: string;
}
```

## Constraints

- PeriodSelector must be a pure presentational component (no API calls).
- MarketSummaryKpis receives data as props -- does NOT fetch data itself.
- Reuse `KpiCard` for each stat card -- do NOT create new card components.
- MarketMovers behavior must be pixel-identical after refactor.
- i18n keys for KPI labels deferred to T04 (use literal strings with
  `t()` calls pointing to keys that T04 will add).

## Acceptance Criteria

- [ ] PeriodSelector renders button group with configurable periods
- [ ] PeriodSelector calls onChange with selected period string
- [ ] MarketMovers.tsx uses PeriodSelector with no visual change
- [ ] MarketSummaryKpis renders 5 KPI cards from summary data
- [ ] Loading state shows 5 skeleton cards
- [ ] Null data shows dash placeholders
- [ ] Market direction badge is color-coded (green/red/gray)
- [ ] Avg change shows directional arrow with color

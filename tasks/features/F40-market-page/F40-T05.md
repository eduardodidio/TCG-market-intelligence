# F40-T05 -- Tests: Backend + Frontend Comprehensive Coverage

**Wave:** 3
**Depends on:** T01, T02, T03, T04 (all code complete)
**Produces:** Full test coverage for all F40 code.

## Objective

Write comprehensive unit and integration tests for all new backend
endpoints and frontend components introduced in F40.

## Deliverables

### 1. Backend Tests

#### `tests/unit/api/test_market_summary.py`

Test the two new endpoints in `market.py`:

**`GET /market/summary` tests:**
- Returns correct schema with all fields populated
- Period parameter validation (valid: 7d/30d/90d, invalid: 1d -> 422)
- Currency conversion applies to avg_price
- Currency fallback to BRL when exchange rate unavailable
- Market direction: "up" when gainers > losers
- Market direction: "down" when losers > gainers
- Market direction: "flat" when equal
- Empty database returns zeros/null gracefully
- Cache hit returns same result within TTL
- PILA currency works (1:1 BRL)

**`GET /market/volatile` tests:**
- Returns cards sorted by volatility (high change * low consistency)
- Limit parameter respected
- Period parameter validation
- Currency conversion applies to price fields
- Empty result returns empty list (not error)
- Graceful fallback when F36 trending service not available
- Cache hit returns same result within TTL

### 2. Frontend Tests

#### `frontend/tests/components/PeriodSelector.test.tsx`

- Renders all default periods (7d, 30d, 90d)
- Renders custom periods when provided
- Active period has active styling class
- Click calls onChange with correct period string
- Keyboard accessibility (focus ring)

#### `frontend/tests/components/MarketSummaryKpis.test.tsx`

- Renders 5 KPI cards with data
- Loading state shows 5 skeletons
- Null data shows dash placeholders
- Market direction badge colors: green for "up", red for "down",
  gray for "flat"
- Avg change shows correct arrow direction
- Currency formatting applied

#### `frontend/tests/components/TopDecksPreview.test.tsx`

- Renders top 5 deck rows with rank numbers
- Shows deck name, value, change badge
- "View All" link points to /decks/ranking
- Returns null on API error (graceful hide)
- Returns null on empty data
- Loading state shows skeleton

#### `frontend/tests/pages/MarketPage.test.tsx`

- Renders page title
- Renders PeriodSelector
- Renders MarketSummaryKpis section
- Period change triggers re-fetch of summary
- Currency from useCurrency applied to all sections
- Page does not crash when section API calls fail
- document.title set correctly
- Sections render in correct order
- Loading states shown while data loads

### 3. Test Patterns

- Backend: use `TestClient` with mocked Repository. Mock
  `repo.get_market_stats()` and `repo.get_movers()` return values.
- Frontend: use Vitest + React Testing Library. Mock API calls via
  `vi.mock("../api/market")`. Mock `useCurrency` to return test currency.
- Use `@testing-library/react` `screen`, `waitFor`, `within`.
- Follow existing test patterns in the codebase (check
  `frontend/tests/pages/` for page test examples).

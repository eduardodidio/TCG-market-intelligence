# F40-T04 -- Frontend: Navigation Update + i18n + Integration

**Wave:** 2
**Depends on:** T02 (PeriodSelector, MarketSummaryKpis), T03 (MarketPage)
**Produces:** Fully wired and translatable market page.

## Objective

Wire the MarketPage into the application routing, update navigation,
and add all i18n keys for the market page and its sections.

## Deliverables

### 1. Route Registration (`frontend/src/App.tsx`)

Add lazy import and route for MarketPage:

```typescript
const MarketPage = lazy(() =>
  import("./pages/MarketPage").then((m) => ({ default: m.MarketPage })),
);
```

Add route inside the Layout routes (public, no ProtectedRoute):

```tsx
<Route
  path="/market"
  element={
    <Suspense fallback={<LoadingSpinner message="Loading page..." />}>
      <MarketPage />
    </Suspense>
  }
/>
```

The existing `/market/movers` route remains unchanged.

### 2. Navigation Update (`frontend/src/components/Layout.tsx`)

Update `NAV_ITEMS` array:

Change:
```typescript
{ to: "/market/movers", labelKey: "nav.marketMovers", requiresAuth: false },
```

To:
```typescript
{ to: "/market", labelKey: "nav.market", requiresAuth: false },
```

The `/market/movers` page remains accessible via direct URL and "View
All" links but is no longer a primary nav item.

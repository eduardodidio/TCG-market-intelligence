# Task F85-T04 — Admin Error API Endpoints

**Feature:** F85
**Wave:** 1
**Type:** backend
**Depends on:** F85-T01 (DB model + repo), F85-T02 (error logger service)
**Status:** done

## User Story

As an admin, I want API endpoints to list and inspect application errors,
so that I can monitor system health from the admin panel.

## Objective

Add two endpoints to the admin router: `GET /admin/errors` (list with
filters + pagination) and `GET /admin/errors/{error_id}` (detail view).
Add corresponding Pydantic schemas.

## Dev Notes

- Relevant files:
  - `src/api/routers/admin.py` — add two new endpoints
  - `src/api/schemas/admin.py` — add error schemas
  - `src/api/deps.py` — `require_admin` already exists, reuse it
- Schemas:
  ```python
  class ErrorLogEntry(BaseModel):
      id: str
      timestamp: datetime
      level: str
      error_type: str
      message: str
      module: str | None
      function: str | None

  class ErrorLogDetail(ErrorLogEntry):
      traceback: str | None
      line: int | None
      request_method: str | None
      request_path: str | None
      request_user_id: int | None
      request_id: str | None
      request_params: dict | None  # parsed from JSON string
      extra: dict | None           # parsed from JSON string

  class ErrorLogFilters(BaseModel):
      level: str | None = None
      module: str | None = None
      date_from: datetime | None = None
      date_to: datetime | None = None
  ```
- `GET /admin/errors`:
  - Query params: `level`, `module`, `date_from`, `date_to`, `limit` (default 50, max 200), `offset` (default 0)
  - Returns `success_response(data=list[ErrorLogEntry], total=total, offset=offset)`
  - Requires admin auth
- `GET /admin/errors/{error_id}`:
  - Returns `success_response(data=ErrorLogDetail)` or 404
  - Parse `request_params` and `extra` from JSON strings to dicts
  - Requires admin auth

## Acceptance criteria

- [ ] `GET /admin/errors` returns paginated error list
- [ ] `GET /admin/errors` supports level, module, date_from, date_to filters
- [ ] `GET /admin/errors/{id}` returns full error detail with parsed JSON fields

- [ ] Response follows project envelope format (data/meta/errors)

## Test scenarios

- **Happy path:** List errors returns correct data shape
- **Pagination:** Verify limit/offset/total in response
- **Filters:** level=CRITICAL returns only critical errors
- **Detail view:** Get single error includes traceback, request context
- **404:** Unknown error_id returns 404
- **Auth:** Non-admin user gets 403
- **Unauthenticated:** No token gets 401

# Task F85-T01 — ErrorLog SQLAlchemy Model + Repository Methods

**Feature:** F85
**Wave:** 0
**Type:** backend
**Depends on:** (none)
**Status:** done

## User Story

As an admin, I want application errors persisted in the database, so that
I can query and filter them through the API.

## Objective

Create the `error_log` SQLAlchemy table and add repository methods for
inserting errors and querying them with filters + pagination.

## Dev Notes

- Relevant files:
  - `src/database/models.py` — add `ErrorLogRow` model
  - `src/database/repository.py` — add error log repo methods
- Follow existing model patterns (see `ScanRunRow`, `CreditTransactionRow`)
- Table name: `error_log`
- Columns:
  - `id` TEXT PRIMARY KEY (UUID string)
  - `timestamp` DATETIME NOT NULL (indexed)
  - `level` TEXT NOT NULL (ERROR, CRITICAL, WARNING)
  - `error_type` TEXT NOT NULL (exception class name)
  - `message` TEXT NOT NULL
  - `traceback` TEXT (nullable — warnings may not have one)
  - `module` TEXT (file/module path)
  - `function` TEXT (function name)
  - `line` INTEGER (line number)
  - `request_method` TEXT (nullable)
  - `request_path` TEXT (nullable)
  - `request_user_id` INTEGER (nullable)
  - `request_id` TEXT (nullable)
  - `request_params` TEXT (nullable — JSON string)
  - `extra` TEXT (nullable — JSON string for arbitrary context)
- Repository methods:
  - `insert_error_log(row_dict: dict) -> None` — single insert
  - `list_error_logs(level, module, date_from, date_to, limit, offset) -> tuple[list[dict], int]`
  - `get_error_log(error_id: str) -> dict | None`
  - `delete_error_logs_before(before: datetime) -> int`
  - `delete_error_logs_excess(max_entries: int) -> int`
- Use `INSERT` (not upsert) — errors are append-only
- Index on `(timestamp DESC)` and `(level)` for query performance

## Test scenarios

- **Happy path:** Insert 5 errors, list returns all 5 with correct total
- **Filter by level:** Insert ERROR + WARNING, filter level=ERROR returns only errors
- **Filter by date:** Insert errors at different times, date_from/date_to filters correctly
- **Filter by module:** Insert errors from different modules, module filter matches substring
- **Pagination:** Insert 10, request limit=3 offset=0 returns 3 items with total=10
- **Get by ID:** Insert one, get by its ID returns full record
- **Delete before:** Insert old + new, delete before cutoff removes only old ones
- **Delete excess:** Insert 15, delete excess(10) keeps 10 newest

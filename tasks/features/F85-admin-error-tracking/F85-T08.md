## User Story

As a developer, I want integration tests verifying the full error capture
pipeline, and updated documentation reflecting the new feature.

## Objective

Write integration tests covering the end-to-end flow (exception -> DB +
JSONL -> API query -> frontend display), create architecture and journey
diagrams, and update README.md.

## Dev Notes

- Integration test files:
  - `tests/integration/test_error_pipeline.py` — full pipeline test
    1. Start TestClient
    2. Hit an endpoint that raises an unhandled exception
    3. Query `GET /admin/errors` and verify the error appears
    4. Query `GET /admin/errors/{id}` and verify full detail
    5. Verify JSONL file was written
    6. Run cleanup and verify entries removed
  - `tests/integration/test_error_filters.py` — filter combinations
    1. Insert errors at different levels/modules/dates
    2. Test each filter independently and in combination
- Diagrams:
  - `docs/diagrams/F85-architecture.mmd`:
    - Components: FastAPI Exception Handlers -> ErrorLogger -> [DB Sink, JSONL Sink]
    - Admin API -> Repository -> error_log table
    - CLI -> Retention -> [DB, JSONL]
  - `docs/diagrams/F85-journey.mmd`:
    - Admin opens error panel -> filters -> clicks error -> sees detail
    - Operator shares JSONL with Claude -> gets fix plan
- README.md: add F85 entry describing error tracking, admin errors page,
  CLI error-cleanup command

## Testing

- Framework: pytest (backend), Vitest (frontend)
- Command: `python -m pytest tests/integration/test_error_pipeline.py tests/integration/test_error_filters.py -v`

- [ ] Integration test: cleanup removes old entries from both DB and JSONL

## Test scenarios

- **End-to-end capture:** Raise in endpoint -> appears in /admin/errors list
- **Detail includes traceback:** Error detail has non-empty traceback
- **Request context:** Error detail includes correct method, path, request_id
- **JSONL verification:** File contains valid JSON with matching error_id
- **Cleanup pipeline:** Insert old errors, run cleanup, verify removed from both stores
- **Filter accuracy:** Multiple errors, filter by each dimension, verify correct subset

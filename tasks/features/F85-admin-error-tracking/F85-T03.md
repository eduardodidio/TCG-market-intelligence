## User Story

As a developer using Claude for debugging, I want error logs written to a
structured JSONL file, so that I can share the file directly with Claude
for diagnosis.

## Objective

Set up the `logs/errors/` directory structure, ensure it is gitignored,
and implement the JSONL rotation/management utilities.

## Dev Notes

- Relevant files:
  - `.gitignore` — add `logs/errors/` entry
  - `src/errors/retention.py` — NEW: retention cleanup functions
  - `src/config.py` — add `get_error_log_dir()`, `get_error_max_age_days()`, `get_error_max_entries()` helpers
- `get_error_log_dir()`: returns `os.environ.get("TCG_ERROR_LOG_DIR", "logs/errors")`
- `get_error_max_age_days()`: returns `int(os.environ.get("TCG_ERROR_MAX_AGE_DAYS", "30"))`
- `get_error_max_entries()`: returns `int(os.environ.get("TCG_ERROR_MAX_ENTRIES", "10000"))`
- `src/errors/retention.py`:
  - `cleanup_jsonl(file_path: str, max_age_days: int, max_entries: int) -> int`
    - Reads the JSONL file, filters out entries older than max_age_days, keeps only max_entries newest
    - Writes back atomically (write to tmp, then rename)
    - Returns number of entries removed
  - `cleanup_db(repo: Repository, max_age_days: int, max_entries: int) -> int`
    - Calls `repo.delete_error_logs_before()` and `repo.delete_error_logs_excess()`
    - Returns total entries removed
- Ensure `logs/errors/` directory is created on first write (mkdir -p equivalent in Python)

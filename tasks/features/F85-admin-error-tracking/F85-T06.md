# Task F85-T06 — Frontend Admin Errors Section

**Feature:** F85
**Wave:** 2
**Type:** frontend
**Depends on:** F85-T04 (API endpoints)
**Status:** done

## User Story

As an admin, I want to see recent application errors in the admin panel,
so that I can monitor and diagnose issues without checking log files.

## Objective

Create an `AdminErrorsSection` component and integrate it into the admin
panel as a new accordion section. Include error list with severity badges,
filters, pagination, and an expandable detail view.

  ```typescript
  interface ErrorLogEntry {
    id: string;
    timestamp: string;
    level: string;
    error_type: string;
    message: string;
    module: string | null;
    function: string | null;
  }
  interface ErrorLogDetail extends ErrorLogEntry {
    traceback: string | null;
    line: number | null;
    request_method: string | null;
    request_path: string | null;
    request_user_id: number | null;
    request_id: string | null;
    request_params: Record<string, unknown> | null;
    extra: Record<string, unknown> | null;
  }
  function fetchAdminErrors(params: {
    level?: string; module?: string;
    date_from?: string; date_to?: string;
    limit?: number; offset?: number;
  }): Promise<ApiResponse<ErrorLogEntry[]>>
  function fetchAdminErrorDetail(errorId: string): Promise<ApiResponse<ErrorLogDetail>>
  ```
- Component design (`AdminErrorsSection`):
  - **Filter bar** (top): severity dropdown (All/ERROR/CRITICAL/WARNING), module text input, date range (from/to date inputs)
  - **Error list**: table with columns: Timestamp, Level (color-coded badge), Type, Message (truncated), Module
  - **Level badges**: CRITICAL = red bg, ERROR = amber bg, WARNING = yellow bg
  - **Row click**: expands inline detail view (no separate route)
  - **Detail view**: shows full traceback in `<pre>` block (monospace, scrollable), request context (method, path, user, params), extra data as formatted JSON
  - **Pagination**: same pattern as users table (prev/next buttons, offset info)
  - Lazy-load on accordion open (same pattern as existing admin sections)
  - Follow existing Tailwind slate dark theme patterns
- AdminPanel integration:
  - Add new AccordionSection after "Scans" section
  - Title: `t("admin.section.errors")`
  - Pass `isOpen={openSection === "errors"}`

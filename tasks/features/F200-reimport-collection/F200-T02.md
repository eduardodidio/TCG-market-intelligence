# F200-T02: Post-import verification & cleanup

**Status:** planned
**Wave:** 1
**Depends on:** T01

## User Story

As the collection owner, I want to verify that the import completed
correctly — all 986 entries are linked, no orphaned data was left behind,
and the snapshot backup exists — so I can trust the system reflects my
real collection.

## Dev Notes

Run verification queries:

```bash
# 1. Verify collection count
python -m src.cli.main collection-stats

# 2. Check for unlinked entries (card_id IS NULL)
python3 -c "
from src.database.repository import Repository
import os
repo = Repository(os.environ.get('DATABASE_URL'))
with repo.transaction() as s:
    from src.database.models import UserCollectionRow
    from sqlalchemy import select, func
    total = s.scalar(select(func.count()).select_from(UserCollectionRow).where(UserCollectionRow.user_id == '3'))
    unlinked = s.scalar(select(func.count()).select_from(UserCollectionRow).where(UserCollectionRow.user_id == '3', UserCollectionRow.card_id == None))
    print(f'Total: {total}, Unlinked: {unlinked}')
"

# 3. Verify snapshot exists
python3 -c "
from src.database.repository import Repository
import os
repo = Repository(os.environ.get('DATABASE_URL'))
with repo.transaction() as s:
    from src.database.models import CollectionSnapshotRow
    from sqlalchemy import select
    snap = s.execute(select(CollectionSnapshotRow).order_by(CollectionSnapshotRow.id.desc()).limit(1)).scalar_one_or_none()
    if snap:
        print(f'Snapshot #{snap.id}: reason={snap.reason}, rows={snap.row_count}')
"

# 4. Optional: orphan cleanup dry-run
python -m src.cli.main cleanup-orphans --dry-run
```

Expected results:
- Total collection entries: 986
- Unlinked entries: 0 (all auto-canonized)
- Snapshot: reason=import_replace, row_count=549
- Orphan cleanup: no action needed (cards table shared with catalog)

## Testing

- All verification queries return expected values
- No errors in application logs
- Frontend `/collection` page shows updated card count

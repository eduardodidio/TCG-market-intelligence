# F200-T01: Execute collection import (replace)

**Status:** planned
**Wave:** 0
**Depends on:** none

## User Story

As the collection owner, I want my card database updated to match my
current physical collection (986 cards from the updated CSV), replacing
the stale 549-entry collection, so that all dashboards, portfolio, and
price tracking reflect reality.

## Dev Notes

Run the existing `import-csv` CLI command against the Neon production
database (via `DATABASE_URL` in `.env`):

```bash
python -m src.cli.main import-csv \
  --file docs/colecaoMtgAtualizada.csv \
  --user-id 3 \
  --currency auto
```

What the importer does automatically:
1. Snapshots existing 549 rows into `collection_snapshots` table
2. Deletes all `user_collection` rows for user_id=3
3. Parses 986 CSV rows (Liga format, auto-detected)
4. For each row: looks up `cards` by (game, set_code, collector_number)
   - If found: links to existing card_id
   - If not found: creates new `CardRow` (auto-canonize)
5. Inserts `UserCollectionRow` with card_id link
6. All in a single transaction (atomic)

No code changes required. No new dependencies.

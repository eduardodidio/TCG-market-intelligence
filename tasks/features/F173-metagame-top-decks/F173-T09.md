# F173-T09 — Collector service `collect_metagame`

- **Wave:** 2
- **Type:** backend
- **Depends on:** F173-T03, F173-T04
- **Status:** planned

## User Story
As the operator, I want one service that pulls every format from its source, resolves
cards and stores a dated snapshot, so that the CLI/.bat just calls it.

## Objective
Orquestração pura-ish em `src/metagame/collector.py` (composição sobre sources +
repository — lição F13).

## Dev Notes
Veja `_brief/00-overview.md`, `_brief/01-sources-and-collection.md` (assinatura) e
`_brief/02-persistence.md`.
- Recebe `sources: dict[str, MetaSource]` (mapa formato→source) já montado — não importa
  adapters concretos (T07/T08 rodam em paralelo). Testes usam `FakeSource`.
- `snapshot_date` default `date.today()`.
- `dry_run=True`: busca e resolve, NÃO grava; stats preenchidos.
- `unresolved_cards` = cartas sem `card_id` (métrica do PRD: ≥90% resolvidas).
- Um formato falhando (`FetchError`, `RobotsDisallowed`, qualquer `Exception`) → `stats.errors.append(f"{fmt}: {e}")`, `log.error`, segue.

## Implementation details
- `CollectStats` dataclass + `collect_metagame(repo, sources, formats, *, limit=20, snapshot_date=None, dry_run=False, resolver=None) -> CollectStats`.
- Formato sem source no mapa → erro em `stats.errors` ("no source for <fmt>").
- Resolver default: `repo.resolve_card_id` com cache dict por coleta (chave nome.lower()).

## Acceptance criteria
- [ ] Grava via `repo.replace_snapshot` por formato; idempotente no mesmo dia.
- [ ] Erro isolado por formato; stats corretos.
- [ ] Cobertura ≥ 90%.

## Testing
- pytest, `tests/unit/metagame/test_collector.py`; `FakeSource`; `MetagameRepository` real
  em SQLite em memória (depende de T03) ou mock com `MagicMock(spec=...)` para cenários de erro.
- `pytest tests/unit/metagame/test_collector.py --cov=src/metagame/collector.py`

## Test scenarios
- Happy: 2 formatos, 3 decks cada → 6 decks gravados, stats ok.
- Edge: dry_run → nada gravado, stats preenchidos.
- Edge: mesma carta em vários decks → resolver chamado 1x (cache).
- Error: source de um formato lança → outro formato gravado; `errors` tem 1 item.
- Error: formato sem source → erro registrado.
- Boundary: `formats=[]` → stats zerados; `limit=1`.

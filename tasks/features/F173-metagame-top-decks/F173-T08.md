## User Story
As a constructed player, I want the top archetypes of Standard, Pioneer, Modern, Legacy,
Vintage and Pauper with meta share and a representative list, so that I can compare the
meta and its cost in BRL.

## Objective
Adapter `MetaSource` para formatos construídos (default `Mtgtop8Source` em
`src/metagame/sources/mtgtop8.py`).

## Notes from Developer
- Implemented `src/metagame/sources/mtgtop8.py` (`Mtgtop8Source`, `FORMAT_CODES`,
  pure `_parse_meta_page` / `_parse_archetype_page` / `_parse_decklist` / `_parse_share`).
  Selectors live in constants at the top of the module.
- `rank` is the archetype's position on the meta page, sorted by meta share (descending, a
  missing share goes last). A skipped archetype, such as one with a failed or empty decklist
  or an archetype page with no decks, leaves a gap in the ranks. Ranks are **not** renumbered.
- `limit` counts only decks that were built successfully. `limit <= 0` returns `[]` with no fetch.
- A meta-page fetch error propagates, and the collector (T09) handles errors per format.
  Errors on the archetype page or decklist (`FetchError`, `RobotsDisallowed`, `httpx.HTTPError`)
  skip that archetype and log a warning.
- `parse_deck_text` treats `1x Card` as the name "1x Card", so lines are normalized
  (`^(\d+)x\s` → `\1 `) before it runs. The `Sideboard` (or `Sideboard:`) header splits main from side.
- Decklists are fetched with `ttl_hours=168` (7 days, per the ADR). Meta and archetype pages use the fetcher default of 24 h.
- `source_url` = `event?e=&d=&f=`. It falls back to the archetype URL when the deck link has no `e=`.
- `ruff check src/metagame/sources` currently reports E501 only in `edhrec.py` (T07, parallel);
  `mtgtop8.py` is clean.

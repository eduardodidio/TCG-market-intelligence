# F173-T08 — Adapter formatos construídos (MTGTop8, ou fonte escolhida no ADR)

- **Wave:** 2
- **Type:** backend
- **Depends on:** F173-T01, F173-T04
- **Status:** planned

## User Story
As a constructed player, I want the top archetypes of Standard, Pioneer, Modern, Legacy,
Vintage and Pauper with meta share and a representative list, so that I can compare the
meta and its cost in BRL.

## Objective
Adapter `MetaSource` para formatos construídos (default `Mtgtop8Source` em
`src/metagame/sources/mtgtop8.py`).

## Dev Notes
Veja `_brief/00-overview.md` e `_brief/01-sources-and-collection.md`.
- **Fonte, URLs e códigos de formato: ADR de T01** + fixtures `tests/fixtures/metagame/<fonte>/`.
  Hipótese MTGTop8: página de formato `https://www.mtgtop8.com/format?f=MO` (códigos
  ST, PI, MO, LE, VI, PAU) lista arquétipos com % do meta; cada arquétipo aponta para decks;
  decklist exportável em texto (`4 Card Name` / `Sideboard`). Se o ADR escolheu outra fonte,
  renomeie arquivo/classe para ela.
- Deck representativo por arquétipo: o mais recente/top-finish listado (regra do ADR).
- `rank` = ordem por meta share; `meta_share_pct` Decimal; `event_date` se disponível;
  `external_id` estável = id do arquétipo na fonte (não do deck, para histórico de rank).
- Parse de decklist em texto: reusar `src/decks/parser.py::parse_deck_text` se o formato
  bater (retorna `list[dict]`; verifique chaves) e mapear para `MetaCardEntry`; sideboard → `board="side"`.
- HTML com `BeautifulSoup(html, "html.parser")`; seletores concentrados em constantes no topo
  (facilita manutenção quando o site mudar — lição F11).
- NÃO editar `src/metagame/sources/__init__.py` (T12 registra).

## Implementation details
- `class Mtgtop8Source: name="mtgtop8"; formats=("standard","pioneer","modern","legacy","vintage","pauper")`
  (apenas os suportados pelo ADR); `FORMAT_CODES: dict[str,str]`.
- Funções puras `_parse_meta_page(html) -> list[dict]`, `_parse_decklist(text) -> tuple[MetaCardEntry,...]`.

## Acceptance criteria
- [ ] Com fixtures, retorna arquétipos ordenados com `meta_share_pct` e decklist main (60) + side.
- [ ] Formato não suportado → `ValueError`.
- [ ] Sem rede nos testes; cobertura ≥ 90%.

## Testing
- pytest, `tests/unit/metagame/test_source_<fonte>.py`; FakeFetcher com fixtures.
- `pytest tests/unit/metagame/test_source_mtgtop8.py --cov=src/metagame/sources`

## Test scenarios
- Happy: página de meta Modern → N arquétipos, rank 1 com maior %.
- Edge: meta share "12.5 %" / "12,5%" → Decimal("12.5"); ausente → None.
- Edge: decklist com sideboard, linhas em branco, "1x Card" vs "1 Card".
- Error: decklist falha → arquétipo pulado; página sem tabela → [] + warning.
- Boundary: `limit=0` → []; `limit` > arquétipos → todos.

## User Story
As a player, I want each metagame deck valued in BRL with how much of it I already own,
so that I know what it costs to build and how much I still need to spend.

## Objective
Função pura `value_meta_deck` em `src/metagame/valuation.py`, sem imports de DB.

## Dev Notes
Veja `_brief/00-overview.md` e `_brief/03-valuation-api.md` (regras exatas).
- Padrão a seguir: `src/decks/valuation.py::compute_deck_value` (pure, `getattr` em
  `card_id`/`quantity`). Aqui também `board` (default "main" se ausente) e `card_name`
  (para detectar terrenos básicos).
- `Decimal` sempre; `quantize(Decimal("0.01"), ROUND_HALF_UP)` p/ BRL e `Decimal("0.1")` p/ %.
- Terrenos básicos: `BASIC_LANDS = frozenset({"Plains","Island","Swamp","Mountain","Forest","Wastes"} | {f"Snow-Covered {x}" ...})`.

## Implementation details
- `MetaDeckValuation` dataclass frozen + `value_meta_deck(cards, prices, owned, include_sideboard=False)`.
- `total_copies` = soma das quantidades consideradas (inclui básicos).
- `priced_pct` = cópias com preço conhecido (básicos contam como precificados a 0) / total.
- `owned_pct` = cópias possuídas `min(qty, owned[card_id])` (básicos = possuídos) / total; `None` se `owned is None`.
- `missing_value_brl` = soma `price * (qty - owned_copies)` para cartas com preço; `None` se `owned is None` ou nenhuma carta com preço.
- Deck vazio → total None, pcts 0, copies 0 (sem ZeroDivision).

## Test scenarios
- Happy: 4x A (R$10) + 2x B (R$5) → total 50.00; owned {A:4} → owned_pct 66.7, missing 10.00.
- Edge: owned maior que deck (A:10 possuídas, deck pede 4) → conta 4.
- Edge: card_id None → não precificada, não possuída.
- Edge: básicos (20 Island) → valor 0, possuídos, precificados.
- Edge: sideboard ignorado por default; incluído com flag. Board "commander" incluído.
- Error: price None para todas → total None, priced_pct 0 (exceto básicos).
- Boundary: deck vazio; owned=None (anônimo) → owned_pct None e missing None; arredondamento 2/3 → 66.7.

## User Story
As the SPA, I want endpoints listing metagame decks per format with BRL value and my
owned %, so that the Top Decks "Mercado" tab can render them.

## Objective
Novo router `src/api/routers/meta_decks.py` (NÃO registrar em `app.py` — isso é T15).

## Dev Notes
Veja `_brief/00-overview.md`, `_brief/02-persistence.md` e `_brief/03-valuation-api.md`
(contrato completo).
- Padrões: `src/api/routers/news.py` (schemas pydantic no próprio arquivo, envelope
  `ApiResponse`/`success_response`), `src/api/routers/decks.py::get_deck_ranking`

- Detail: `image_url` opcional — incluir só se `CardRow` já tiver campo de imagem;
  senão omitir.

## Implementation details
- `router = APIRouter(prefix="/meta-decks", tags=["meta-decks"])`.
- `def get_meta_repo(repo: Repository = Depends(get_db)) -> MetagameRepository`.
- Rotas: `/formats`, `""` (lista), `/{deck_id}` (detail). Declarar `/formats` antes de `/{deck_id}`.
- Batch: 1 `get_deck_cards(ids)`, 1 `get_latest_prices_batch(all_card_ids)`, 1 `owned_quantities` (se logado).

## Test scenarios
- Happy: seed 3 decks modern + preços + coleção → lista ordenada por rank, valores corretos.
- Happy: `/formats` lista formatos com contagem e data.
- Happy: detail com cartas, `price_brl`, `owned_qty`.
- Edge: anônimo → owned_pct null. Carta sem card_id → price null, owned 0.
- Edge: `snapshot_date` explícito retorna snapshot antigo.
- Error: `format=foo` → 422; `/meta-decks/9999` → 404.
- Boundary: `limit=50` ok, `limit=51` → 422; `offset` além do total → lista vazia com `total` correto.

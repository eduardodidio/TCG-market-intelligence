## Implementation details
- `MetaFormatPills({ value, formats, onChange })` — `formats: MetaFormatInfo[]`; formato sem
  snapshot fica `disabled` com tooltip.
- `MetaDeckRow({ deck, expanded, onToggle })` — mostra rank, nome, cores, meta share/nº decks,
  valor BRL, barra owned % (`data-testid="meta-owned-bar"`), "faltam R$", link fonte.
  Expandido → `MetaDeckCardList` carregado via `fetchMetaDeck(deck.id)` (loading/erro locais).
- `MetaDeckCardList({ cards })` — agrupado por board (commander, main, side), link `/cards/:id`.
- `MetaDecksPanel({ format, onFormatChange })` — carrega `/formats` 1x e `/meta-decks?format=`
  a cada troca; paginação "carregar mais" (PAGE_SIZE 20) como TopDecksPage; rodapé fonte/data.

## Test scenarios
- Happy: 3 decks renderizados na ordem de rank com `R$` formatado.
- Happy: clicar num deck expande e mostra cartas agrupadas; segundo clique recolhe.
- Edge: `owned_pct: null` → CTA; `total_value_brl: null` → "—".
- Edge: Commander sem meta share → mostra nº de decks.
- Edge: formato desabilitado (sem snapshot) não dispara onChange.
- Error: API retorna errors → ErrorBanner; retry refaz fetch.
- Error: detail falha → mensagem inline, lista continua.
- Boundary: lista vazia → EmptyState; "carregar mais" some quando `decks.length >= total`.

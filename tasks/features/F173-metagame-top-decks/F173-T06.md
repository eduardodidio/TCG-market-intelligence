## User Story
As a frontend developer, I want typed API functions for `/api/v1/meta-decks*`, so that
the UI components can be built and tested against a stable contract.

## Objective
Criar `frontend/src/types/metaDecks.ts` e `frontend/src/api/metaDecks.ts` + testes.

## Dev Notes
Veja `_brief/00-overview.md`, `_brief/03-valuation-api.md` (contrato) e `_brief/04-frontend.md`.

  `Promise<ApiResponse<T>>`); testes existentes em `frontend/src/api/__tests__/*.test.ts`
  mostram como mockar `apiGet`/`fetch`.

## Implementation details
- `types/metaDecks.ts`: `export const META_FORMATS = ["commander","standard","pioneer","modern","legacy","pauper","vintage"] as const; export type MetaFormat = typeof META_FORMATS[number];`
  + interfaces `MetaFormatInfo`, `MetaDeckSummary`, `MetaDeckListResponse`, `MetaDeckCard`, `MetaDeckDetail`.
- `api/metaDecks.ts`: `fetchMetaFormats()`, `fetchMetaDecks({ format, limit?, offset?, snapshot_date? })`
  (converte números para string nos params), `fetchMetaDeck(id: number)`.

## Acceptance criteria
- [ ] Funções chamam as URLs corretas com params corretos.
- [ ] `npm test` e `npx tsc --noEmit` (via `npm run build`) sem erros.

## Testing
- Vitest, `frontend/src/api/__tests__/metaDecks.test.ts`; mock de `../client`.
- `cd frontend && npx vitest run src/api/__tests__/metaDecks.test.ts`

## Test scenarios
- Happy: `fetchMetaDecks({format:"modern"})` → `apiGet("/api/v1/meta-decks", {format:"modern"})`.
- Edge: `limit`/`offset` numéricos viram string; `undefined` omitidos.
- Edge: `fetchMetaDeck(42)` → `/api/v1/meta-decks/42`.
- Error: envelope com `errors` é repassado sem throw.
- Boundary: `offset: 0` é enviado (não confundir com falsy).

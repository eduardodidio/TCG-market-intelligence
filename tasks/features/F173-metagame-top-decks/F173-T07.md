# F173-T07 — Adapter EDHREC (Commander)

- **Wave:** 2
- **Type:** backend
- **Depends on:** F173-T01, F173-T04
- **Status:** planned
- **Maps to AC:** AC2, AC8

## User Story
As a Commander player, I want the most popular commanders and their typical decklists,
so that I can see the Commander "meta" priced in BRL.

## Objective
`EdhrecSource` implementando `MetaSource` para `commander`, usando `PoliteFetcher`.

## Dev Notes
Veja `_brief/00-overview.md` e `_brief/01-sources-and-collection.md`.
- **URLs, campos e política exatos: ADR de T01** (`docs/adr/0016-metagame-deck-sources.md`)
  e fixtures em `tests/fixtures/metagame/edhrec/`. Hipótese: lista de top commanders
  (JSON) + "average deck" por comandante (JSON/texto). Se o ADR descartou EDHREC, implemente
  a fonte Commander escolhida no ADR com o mesmo nome de classe genérico `CommanderSource`
  e ajuste o nome do arquivo (registrar no README da feature).
- Mapear: `rank` = posição na lista; `deck_count` = nº de decks; `meta_share_pct` = None
  (ou % se a fonte fornecer); `archetype` = nome do comandante; `commander_name` idem;
  `external_id` = slug do comandante; `cards` inclui o comandante com `board="commander"`.
- Resiliência (lição F11): campo ausente → `log.warning` e pular a carta/deck; nunca
  derrubar o formato inteiro. Nomes: normalizar espaços; manter `//` para cartas duplas.
- Limitar requests: `limit` decks → 1 request de lista + `limit` requests de decklist
  (cache 7d para decklists, conforme ADR).

## Implementation details
- `src/metagame/sources/edhrec.py`: `class EdhrecSource: name="edhrec"; formats=("commander",)`,
  `__init__(self, fetcher: PoliteFetcher)`, `fetch_top_decks(fmt, *, limit=20)`,
  funções privadas puras `_parse_top_list(payload) -> list[dict]` e
  `_parse_decklist(payload) -> tuple[MetaCardEntry, ...]` (testáveis isoladas).
- `fmt` diferente de commander → `ValueError`.
- NÃO editar `src/metagame/sources/__init__.py` (T12 registra).

## Test scenarios
- Happy: fixture → N decks, rank 1 = primeiro da lista, comandante em board "commander".
- Edge: `limit` maior que a lista → retorna o que existe; `limit=1` → 1 request de decklist.
- Edge: carta dupla "A // B" preservada; quantidade ausente → 1.
- Error: decklist de um comandante lança `FetchError` → deck pulado, demais retornados.
- Error: payload sem a chave esperada → lista vazia + warning (sem exceção).
- Boundary: `fmt="modern"` → ValueError.

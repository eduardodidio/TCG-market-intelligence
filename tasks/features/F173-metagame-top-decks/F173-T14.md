```mermaid
  subgraph Local["Windows local"]
    BAT[bats/collect-metagame.bat] --> CLI[src/cli/metagame.py collect-metagame]

  subgraph Metagame["src/metagame"]
    CLI --> COL[collector.collect_metagame]

  MREPO --> DB[(Neon PG / SQLite: meta_decks, meta_deck_cards, cards, user_collection, price_observations)]
  subgraph API["FastAPI"]
    R[routers/meta_decks.py] --> MREPO
    R --> VAL[valuation.value_meta_deck]
    R --> PR[Repository.get_latest_prices_batch]
  end
  subgraph SPA["React"]
    P[TopDecksPage ?view=meta] --> PANEL[components/meta/MetaDecksPanel] --> CLIENT[api/metaDecks.ts] --> R
  end
```
Jornada: `flowchart LR` com swimlanes Usuário / SPA / API / Coleta semanal: abrir Top Decks →
aba Mercado → escolher formato → (sem snapshot? → EmptyState) → lista com valor BRL →
(logado? owned % : CTA login) → expandir deck → ver cartas faltantes → abrir carta / fonte
externa; caminho de erro (API erro → ErrorBanner → retry).

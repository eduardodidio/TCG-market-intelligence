## Notes from Developer
- Existing `.bat` files use LF line endings (`file bats/process-queue.bat` reports no CRLF;
  `grep -c $'\r'` = 0), so `bats/collect-metagame.bat` also uses LF to match the repo.
  Stage it with `git add -f bats/collect-metagame.bat` (`bats/` is gitignored).
- `--no-cache`: the adapters call `fetcher.get_text`/`get_json` without `use_cache`, so the CLI
  wraps `PoliteFetcher` in a subclass that forces `use_cache=False` (reads skip the cache, writes
  still refresh it). `http.py` is unchanged.
- The T04 placeholder test `test_registry_empty` in `tests/unit/metagame/test_http.py` now
  checks for a populated registry (`test_registry_populated`).
- The status line for each format marks FAIL from `CollectStats.errors` (`"<fmt>: ..."` or
  `"no source for <fmt>"`).

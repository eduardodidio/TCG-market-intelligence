**Wave:** 1
**Status:** planned

## User Story

As an API consumer, I want to list available card sets and view market movers/statistics so that I can understand the overall market landscape and find trending cards.

## Dev Notes

- Create `src/api/routers/sets.py` with an `APIRouter(prefix="/sets", tags=["sets"])`.
- Create `src/api/routers/market.py` with an `APIRouter(prefix="/market", tags=["market"])`.

### `GET /sets`

- Query param: `game` (optional filter).
- Query distinct `(game, set_code)` from `CardRow`, with `COUNT(*)` as `card_count`.
- Requires new repository method: `Repository.list_sets(game) -> list[tuple[str, str, int]]` returning `(game, set_code, card_count)`.
- Map to `list[SetSummary]` schema. No pagination needed (sets are few).

### `GET /market/movers`

- Query params: `period` (default `30d`, options: `7d`, `30d`, `90d`), `limit` (default 10).
- Map period string to days: `7d->7`, `30d->30`, `90d->90`.
- Logic: For each card, get the price N days ago and the latest price. Compute `change_pct = (latest - past) / past * 100`. Sort by `change_pct` DESC for gainers, ASC for losers. Return top `limit` of each.
- Requires new repository method: `Repository.get_movers(days, limit) -> tuple[list[MoverData], list[MoverData]]` where `MoverData` is a named tuple or dataclass with `card_id, name_en, set_code, price_start, price_end, change_pct`.
  - Implementation: subquery to get the earliest price within the period window and the latest price for each card, then compute change. Use SQL for efficiency rather than loading all observations into Python.
- Map to `MoversResponse` schema.

### `GET /market/stats`

- Query param: `game` (optional).
- Aggregate stats: total cards, total observations, average latest price, min/max observation dates.
- Requires new repository method: `Repository.get_market_stats(game) -> MarketStatsData` with fields matching the `MarketStats` schema.
  - `total_cards`: `COUNT(*)` from `CardRow` (filtered by game if provided)
  - `total_observations`: `COUNT(*)` from `PriceObservationRow`
  - `avg_price`: average of the most recent `median_price` per card
  - `date_range_start/end`: `MIN/MAX(observed_at)` from `PriceObservationRow`
- Map to `MarketStats` schema.

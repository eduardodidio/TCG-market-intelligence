## Dev Notes

### Integration tests

- Create `tests/api/test_integration.py` with end-to-end tests using `httpx.AsyncClient` + FastAPI `TestClient`.
- Seed a test SQLite database with known data (cards, source_cards, price_observations) using the existing `Repository`.
- Test the full request-response cycle for every endpoint:
  - `GET /cards` — verify pagination, filters, response shape
  - `GET /cards/{id}` — verify detail with source cards, 404 case
  - `GET /cards/{id}/history` — verify time filtering, empty history
  - `GET /sets` — verify grouping
  - `GET /market/movers` — verify gainers/losers with seeded price data
  - `GET /market/stats` — verify aggregation
  - `POST /collect/backfill` — verify job creation (mock the actual backfill to avoid network calls)
  - `POST /collect/update` — verify job creation (mock the actual update)
- Use `pytest` fixtures for app creation and test data seeding.
- Mock `run_backfill` and `run_update` in collect endpoint tests to avoid real network calls.

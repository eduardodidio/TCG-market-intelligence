# F06-T03: Cards endpoints (list, detail, history)

**Wave:** 1
**Status:** planned
**Estimate:** L

## User Story

As an API consumer, I want to list cards with filters, view card details, and retrieve price history so that I can browse and analyze TCG price data programmatically.

## Dev Notes

- Create `src/api/routers/cards.py` with an `APIRouter(prefix="/cards", tags=["cards"])`.

- **`GET /cards`** — list with filters:
  - Query params: `game`, `set` (set_code), `name` (partial match LIKE), `cursor` (base64-encoded card ID), `limit` (default 50, max 200).
  - Cursor-based pagination: decode cursor to get the last seen `card.id`, query `WHERE id > cursor_id ORDER BY id ASC LIMIT limit+1`. If result has `limit+1` rows, there is a next page — encode the last row's ID as cursor.
  - Requires new repository method: `Repository.list_cards(game, set_code, name, cursor_id, limit)` returning `list[CardRow]`. Add to `src/database/repository.py`.
  - Also need `Repository.get_latest_price(card_id)` to attach latest price to each card summary. Query `PriceObservationRow` joined through `SourceCardRow.card_id` ordered by `observed_at DESC LIMIT 1`.
  - Alternatively, for performance, add a `Repository.get_latest_prices_batch(card_ids)` that fetches latest prices for multiple cards in one query.
  - Map `CardRow` + latest price to `CardSummary` schema.

- **`GET /cards/{id}`** — card detail:
  - Path param: `id: int`.
  - Fetch `CardRow` by ID. If not found, return 404 with `CARD_NOT_FOUND` error.
  - Fetch associated `SourceCardRow` records via `card_id` foreign key.
  - Requires new repository method: `Repository.get_card_by_id(card_id)` and `Repository.get_source_cards_for_card(card_id)`.
  - Map to `CardDetail` schema.

- **`GET /cards/{id}/history`** — price history:
  - Path param: `id: int`. Query param: `period` (default `90d`).
  - Map period string to days: `30d->30`, `90d->90`, `180d->180`, `1y->365`, `3y->1095`.
  - Look up `SourceCardRow` for the card, then use existing `Repository.get_price_series(source, external_id, days)`.
  - If card not found, return 404. If no history, return empty array.
  - Map `HistoricalPrice` domain objects to `PriceObservation` schema.

- New repository methods to add in `src/database/repository.py`:
  - `list_cards(game, set_code, name_search, after_id, limit) -> list[CardRow]`
  - `count_cards(game, set_code, name_search) -> int`
  - `get_card_by_id(card_id) -> CardRow | None`
  - `get_source_cards_for_card(card_id) -> list[SourceCardRow]`
  - `get_latest_prices_batch(card_ids) -> dict[int, PriceObservationRow | None]`

## Acceptance Criteria

- [ ] `GET /cards` returns paginated list with cursor in meta
- [ ] `GET /cards?game=magic&set=dmr` filters correctly
- [ ] `GET /cards?name=sol` partial matches on `name_en` (case-insensitive)
- [ ] `GET /cards?limit=201` returns 422 validation error
- [ ] Cursor pagination works: following cursor returns next page, last page has `cursor: null`
- [ ] `GET /cards/{id}` returns full card detail with source cards
- [ ] `GET /cards/{id}` returns 404 for nonexistent ID
- [ ] `GET /cards/{id}/history` returns price observations ordered by date ASC
- [ ] `GET /cards/{id}/history?period=30d` filters to last 30 days
- [ ] All responses use the standard `{data, meta, errors}` envelope

**Wave:** 2
**Status:** planned
**Estimate:** M

## User Story

As a developer, I want a properly configured FastAPI application with all routers mounted, error handling, CORS, and a runnable server so that the API is ready for local use and testing.

## Dev Notes

- Implement `src/api/app.py`:
  - `create_app() -> FastAPI` factory function.
  - Configure FastAPI with `title="TCG Market Intelligence API"`, `version="0.1.0"`, `docs_url="/docs"`, `redoc_url="/redoc"`.
  - Set `root_path="/api/v1"` to match the API spec base URL.
  - Include all routers from `src/api/routers/` (cards, sets, market, collect).
  - Add CORS middleware: allow all origins for local dev (`allow_origins=["*"]`). This is appropriate because auth is out of scope and the API is for local use.

- Add global exception handlers in `src/api/app.py`:
  - `RequestValidationError` -> 422 with structured errors in envelope format
  - `HTTPException` -> appropriate status with envelope format
  - Generic `Exception` -> 500 with envelope format (log the traceback, return safe message)
  - 404 handler for unknown routes

- Add a request ID middleware:
  - Generate a UUID per request, attach to `request.state.request_id`.
  - Include in all `Meta.request_id` responses.

- Add a health check endpoint: `GET /health` returning `{"status": "ok"}` (outside the `/api/v1` prefix).

- Implement `run_server()` function:
  ```python
  def run_server(host="0.0.0.0", port=8000):
      import uvicorn
      uvicorn.run("src.api.app:create_app", factory=True, host=host, port=port, reload=True)
  ```
- Update the `project.scripts` entry in `pyproject.toml`: `api = "src.api.app:run_server"`.

- Add a CLI command to `src/cli/main.py`: `@cli.command("serve")` that starts the API server with configurable `--host` and `--port`.

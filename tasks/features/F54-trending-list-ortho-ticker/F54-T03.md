# F54-T03 — Market Ticker Auto-Scroll Fix

**Wave:** 1 | **Status:** done | **Parallel:** yes

## User Story

As a user, I want the market ticker bar at the top to continuously scroll like a stock exchange display, showing card price movements automatically.

## Acceptance Criteria

- [ ] Ticker scrolls continuously left-to-right without user interaction
- [ ] Animation is smooth and consistent (stock-exchange feel)
- [ ] Hovering pauses the animation (already implemented)
- [ ] `prefers-reduced-motion` disables animation (already implemented)
- [ ] Ticker is visible and populated with data when trending data exists

## Dev Notes

### Analysis of current state

The CSS animation IS already defined and looks correct:
- `index.css`: `@keyframes ticker-scroll` with `translateX(0) → translateX(-50%)`, `linear infinite`
- `MarketTicker.tsx`: duplicates items (`[...items, ...items]`) for seamless loop
- Duration: `(items.length * 80) / 60` seconds, min 20s

**Likely issue:** The ticker may appear "stuck" because:
1. **No trending data** — if `useTickerData` returns empty, ticker returns `null`
2. **Duration too long** — with few items, animation may be imperceptibly slow
3. **CSS not applied** — the `animate-ticker` class uses a CSS custom property `--ticker-duration` which may not be picked up correctly

### Fix approach

1. **Speed tuning** — Reduce the per-item factor and minimum duration for a more dynamic feel:
   - Change from `(items.length * 80) / 60` to `(items.length * 60) / 60` (= items.length seconds)
   - Lower minimum from 20s to 10s
   - This makes the ticker visibly move at ~60px/s regardless of item count

2. **Ensure seamless loop** — Current implementation already duplicates items. Verify the container width calculation works.

3. **Add `will-change: transform`** to the animation CSS for GPU acceleration and smoother rendering.

4. **Fallback content** — If items are empty after loading, show nothing (current behavior is fine).

### Files to modify
- `frontend/src/components/MarketTicker.tsx` (speed constants)
- `frontend/src/index.css` (add `will-change: transform` to `.animate-ticker`)

### Files NOT to modify
- `useTickerData.ts` — data fetching logic is fine
- `TickerItem.tsx` — rendering is fine
- Backend — no changes

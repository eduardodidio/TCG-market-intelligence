# F54-T01 — Trending List Layout (Side-by-Side Grids)

**Wave:** 1 | **Status:** done | **Parallel:** yes

## User Story

As a user viewing trending cards, I want to see gainers and losers as two side-by-side lists (not horizontal card scrolls with images) so I can quickly scan price movements and click through to card details.

## Acceptance Criteria

- [ ] Trending page shows gainers and losers as two columns on desktop (grid-cols-2), stacked on mobile
- [ ] Each item is a compact list row: card name, set code, % change (colored), current price
- [ ] No card images in this view — text-only for density
- [ ] Clicking a row navigates to `/cards/:card_id`
- [ ] Existing controls (period selector, limit selector) still work
- [ ] TrendingSection accepts a `layout` prop or the Trending page overrides the rendering
- [ ] Accessible: keyboard navigable, proper aria labels

## Dev Notes

### Approach: New `TrendingListItem` component + Trending page layout change

1. **Create `frontend/src/components/TrendingListItem.tsx`**
   - Receives a `TrendingCardEntry` prop
   - Renders a single row: `<Link to={/cards/${card_id}}>` with flex layout
   - Left: card name (truncated) + set code badge
   - Right: % change (green/red) + current price
   - Hover: subtle bg highlight (`hover:bg-slate-700/50`)
   - Use `useCardName` hook for language-aware names

2. **Modify `frontend/src/pages/Trending.tsx`**
   - Replace the `space-y-8` stacked layout with `grid grid-cols-1 md:grid-cols-2 gap-6`
   - Both TrendingSections render side by side on desktop

3. **Modify `frontend/src/components/TrendingSection.tsx`**
   - Add optional `variant?: "cards" | "list"` prop (default: `"cards"` for backward compat)
   - When `variant="list"`: render `TrendingListItem` in a vertical list instead of horizontal scroll of `TrendingCard`
   - Trending page passes `variant="list"`
   - Dashboard/MarketPage keep using default `"cards"` variant (no changes needed)

### Files to modify
- `frontend/src/components/TrendingListItem.tsx` (new)
- `frontend/src/components/TrendingSection.tsx` (add variant prop)
- `frontend/src/pages/Trending.tsx` (grid layout)

### Files NOT to modify
- `TrendingCard.tsx` — still used by Dashboard/MarketPage in card mode
- Backend — no changes needed

# F80-T02: Snapshot Service + CLI Command

**Status:** planned
**Wave:** 1

## User Story
As an operator, I want a CLI command (`snapshot-portfolio`) that I can run daily via cron to capture each user's portfolio value, so I have historical data for performance tracking.

## Dev Notes

### Files to Create/Modify
- `src/collectors/portfolio_snapshot.py` — `take_snapshot(user_id, repo) -> PortfolioSnapshot` — reuses `get_collection_total_value` and `get_collection_summary`
- `src/cli/main.py` — add `snapshot-portfolio` command (runs for all users, or a specific user_id)

### Approach
1. Query all active users
2. For each user, call `get_collection_total_value(user_id)` and `get_collection_summary(user_id)`
3. Upsert into `portfolio_snapshots` with today's date
4. CLI outputs summary: "Snapshotted N users, total portfolio value: R$ X"

### Cron Integration
```bash
# Add to start.sh or crontab
# Daily at 23:59 after price scans complete
python -m src.cli.main snapshot-portfolio
```

## Testing
- Unit test: snapshot creates correct row with BRL value
- Unit test: re-running same day upserts (doesn't duplicate)
- Unit test: handles users with no priced cards (value=0)

# F80-T04: Frontend — % Change Display

**Status:** planned
**Wave:** 1

## User Story
As a collector, I want to see the daily/weekly percentage change of my collection's total value on the dashboard and collection pages, so I know if my portfolio is appreciating or depreciating.

## Dev Notes

### Files to Create/Modify
- `frontend/src/api/collection.ts` — add `fetchValuation(days, currency)` API call
- `frontend/src/hooks/useValuation.ts` — hook wrapping the API call with loading/error state
- `frontend/src/components/ValuationBadge.tsx` — displays % change with green (up) / red (down) colors and arrow icon
- `frontend/src/pages/Dashboard.tsx` — add ValuationBadge near portfolio total
- `frontend/src/pages/MyCollection.tsx` — add ValuationBadge near collection summary total_value
- `frontend/src/i18n/locales/en.json` + `pt-BR.json` — add keys: `valuation.change`, `valuation.noHistory`, `valuation.since`

### Display Pattern
```
R$ 1.234,56  +2.88%    (green arrow up)
R$ 1.234,56  -1.50%    (red arrow down)
R$ 1.234,56  --        (no previous data)
```

### Approach
1. Call `/collection/valuation?days=7` on mount
2. Display `change_pct` with appropriate color/icon
3. Tooltip shows absolute change and comparison date

## Testing

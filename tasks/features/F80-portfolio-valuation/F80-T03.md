# F80-T03: API Endpoint — GET /collection/valuation

**Status:** planned
**Wave:** 1

## User Story
As a frontend, I need an endpoint that returns portfolio value history and computed change percentages so I can display appreciation/depreciation.

## Dev Notes

### Endpoint
```
GET /collection/valuation?days=30&currency=BRL
```

### Response
```json
{
  "current_value": 1234.56,
  "previous_value": 1200.00,
  "change_pct": 2.88,
  "change_abs": 34.56,
  "currency": "BRL",
  "snapshots": [
    {"date": "2026-08-27", "value": 1234.56, "priced_count": 300, "total_count": 349},
    {"date": "2026-08-26", "value": 1200.00, "priced_count": 298, "total_count": 349}
  ]
}
```

### Files to Create/Modify
- `src/api/schemas/collection.py` — add `ValuationResponse`, `ValuationSnapshot` schemas
- `src/api/routers/collection.py` — add `GET /collection/valuation` endpoint
- Uses `get_portfolio_snapshots` from repo, computes % change between latest and previous

### Key Logic
- `change_pct = ((current - previous) / previous) * 100` when previous > 0
- If no previous snapshot, `change_pct = None`
- Currency conversion applied to all values if `currency != BRL`

## Testing
- Unit test: endpoint returns correct change_pct
- Unit test: handles no snapshots (empty history)
- Unit test: handles single snapshot (no previous, change_pct=None)

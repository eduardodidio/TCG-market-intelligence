# F80-T01: DB Model — portfolio_snapshots Table

**Status:** planned
**Wave:** 1

## User Story
As a system, I need a table to store daily portfolio value snapshots per user so the application can calculate appreciation/depreciation over time.

## Dev Notes

### Schema
```sql
CREATE TABLE portfolio_snapshots (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT NOT NULL,
    snapshot_date DATE NOT NULL,
    total_value_brl DECIMAL(12,2) NOT NULL,
    priced_card_count INTEGER NOT NULL DEFAULT 0,
    total_card_count INTEGER NOT NULL DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(user_id, snapshot_date)
);
CREATE INDEX idx_portfolio_snapshots_user_date ON portfolio_snapshots(user_id, snapshot_date);
```

### Files to Modify
- `src/database/models.py` — add `PortfolioSnapshotRow` SQLAlchemy model
- `src/database/repository.py` — add `upsert_portfolio_snapshot` and `get_portfolio_snapshots` methods

### Key Decisions
- Store value in BRL (base currency) — convert on display
- `UNIQUE(user_id, snapshot_date)` — one snapshot per user per day (upsert on re-run)
- Track `priced_card_count` vs `total_card_count` for coverage %

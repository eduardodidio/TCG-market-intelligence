# F115-T01: Backend Price Sort Support

**Status:** planned
**Wave:** 0

## User Story

As a user viewing my collection, I want the API to return cards sorted by
price so that my most valuable cards appear first by default.

## Root Cause Analysis

**Current state:**
- `collection.py:100-113` — `sort_by` pattern `^(name|set|number|added)$` explicitly excludes "price"
- `repository.py:1427-1470` — `_COLLECTION_SORT_COLUMNS` maps to UserCollectionRow columns only
- `cards.py` — list_cards has NO sort params, always `ORDER BY CardRow.id ASC`
- Prices live in `price_observations` table (separate from collection/cards)
- Catalog endpoint already supports price sort (catalog.py:182-186) — use as reference

## Dev Notes

### 1. Repository: Add price sort to list_collection()

Add a LEFT JOIN to get latest price per card, then ORDER BY it:

```python
_COLLECTION_SORT_COLUMNS = {
    "name": "name_en",
    "set": "set_code",
    "number": "collector_number",
    "added": "created_at",
    # "price" handled specially via subquery
}

def list_collection(self, ..., sort_by="name", sort_dir="asc", ...):
    if sort_by == "price":
        # Subquery: latest price per card
        latest_price = (
            select(
                PriceObservationRow.card_id,
                func.max(PriceObservationRow.price_mid).label("price_mid")
            )
            .group_by(PriceObservationRow.card_id)
            .subquery()
        )
        stmt = stmt.outerjoin(latest_price, UserCollectionRow.card_id == latest_price.c.card_id)
        sort_expr = latest_price.c.price_mid.desc() if sort_dir == "desc" else latest_price.c.price_mid.asc()
        # NULLs at end
        sort_expr = sort_expr.nulls_last() if sort_dir == "desc" else sort_expr.nulls_first()
    else:
        # existing logic
```

Reference the catalog.py implementation (lines 182-186) which already handles
price sort with nulls.

## Acceptance Criteria

1. `GET /api/v1/collection?sort_by=price&sort_dir=desc` returns cards sorted by price (highest first)
2. `GET /api/v1/collection?sort_by=price&sort_dir=asc` returns cheapest first
3. Cards with no price appear at the end (nulls last for desc, nulls first for asc)
4. Default sort is `price desc` (when no params specified)
5. Existing sort options (name, set, number, added) still work
6. `GET /api/v1/cards?sort_by=price` also works

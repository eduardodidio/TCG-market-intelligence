# F162-T01: Add focus-visible rings to modal buttons

**Feature:** F162 — Accessibility Gaps
**Wave:** 0
**Status:** planned

## User Story

As a keyboard user, I want to see which button is focused in modals,
so I can navigate the UI without a mouse.

## Dev Notes

### Current State

6 buttons across 3 components are missing `focus-visible` rings:
- SetAlertModal.tsx: direction below (line ~140), direction above (~152),
  submit (~207), delete (~234)
- BatchAddModal.tsx: cancel (~165), preview (~174)
- TreasureBalance.tsx: claim bonus (~96)

Good examples already exist in CreditConfirmModal, ThemeToggle, AlertBell.

### Implementation

Add `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-cyan-400`
to each button's className. This is the standard pattern used throughout
the app.

### Files
- `frontend/src/components/SetAlertModal.tsx` — 4 buttons
- `frontend/src/components/BatchAddModal.tsx` — 2 buttons
- `frontend/src/components/TreasureBalance.tsx` — 1 button

## Testing

- Unit: focused buttons show cyan ring

## Acceptance Criteria

- [ ] All modal buttons have visible focus ring on keyboard navigation
- [ ] Consistent with existing focus ring pattern (cyan-400)

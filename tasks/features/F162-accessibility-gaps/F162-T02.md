# F162-T02: Add sr-only text for collapsed sidebar nav

**Feature:** F162 — Accessibility Gaps
**Wave:** 0
**Status:** planned

## User Story

As a screen reader user with the sidebar collapsed, I want to hear
navigation item labels so I know where each link goes.

## Dev Notes

### Current State

`Layout.tsx` lines ~294-390: nav items show icon + label when expanded,
but when collapsed (`collapsed === true`), only the icon is visible.
The `title` attribute provides tooltip but is not announced by most
screen readers.

### Implementation

Add sr-only text when sidebar is collapsed:

```tsx
{collapsed && <span className="sr-only">{label}</span>}
```

This pattern keeps the visual layout unchanged while ensuring screen
readers announce the navigation item name.

### Files
- `frontend/src/components/Layout.tsx` — sr-only text on collapsed nav items

## Testing

- Unit: collapsed nav items have sr-only text
- Unit: expanded nav items render normally (no duplicate text)

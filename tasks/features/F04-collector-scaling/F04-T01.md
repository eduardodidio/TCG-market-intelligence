## User Story

As a data collector operator, I want price observations to be inserted in
batch with conflict handling, so that full-catalog backfills complete in
minutes instead of hours.

## Objective

Replace the current per-row SELECT + INSERT pattern in
`Repository.insert_price_observations` with SQLAlchemy's
`insert().on_conflict_do_nothing()` using the existing unique constraint
`uq_price_observation (source, external_id, observed_at)`.

## Dev Notes

- File: `src/database/repository.py`, method `insert_price_observations`
  (lines 93-123)
- Current problem: for each price in the list, the code does a SELECT to
  check for duplicates, then INSERTs individually. With 1889 observations
  this works fine, but with 10k+ cards x 150 observations = 1.5M+ rows
  this will be extremely slow.
- SQLite supports `INSERT OR IGNORE` via SQLAlchemy's
  `insert().on_conflict_do_nothing()` — this is the simplest fix.
- The unique constraint `uq_price_observation` on
  `(source, external_id, observed_at)` already exists in
  `src/database/models.py` line 83-85.
- Use `from sqlalchemy.dialects.sqlite import insert` for SQLite-specific
  `on_conflict_do_nothing()`. Note: if we later migrate to PostgreSQL,
  `from sqlalchemy.dialects.postgresql import insert` works identically.
- To get accurate inserted count: use `session.execute(stmt)` and check
  `result.rowcount`. With SQLite + ON CONFLICT DO NOTHING, `rowcount`
  returns only the actually inserted rows.
- Keep the method signature identical: `insert_price_observations(self, prices: list[HistoricalPrice]) -> int`
- Process in chunks of 500 to avoid SQLite's variable limit
  (SQLITE_MAX_VARIABLE_NUMBER defaults to 999, each row has ~9 columns =
  ~111 rows per statement, but 500 per batch with individual statements
  in a single transaction is safe and simple).
- Convention: use `from __future__ import annotations` (already present).
- Existing tests: `tests/unit/test_repository.py` has tests for this method
  that must still pass.

## Implementation Details

```python
# In repository.py, replace insert_price_observations:
from sqlalchemy.dialects.sqlite import insert as sqlite_insert

def insert_price_observations(self, prices: list[HistoricalPrice]) -> int:
    if not prices:
        return 0
    inserted = 0
    with Session(self.engine) as session:
        for batch_start in range(0, len(prices), 500):
            batch = prices[batch_start:batch_start + 500]
            for p in batch:
                stmt = sqlite_insert(PriceObservationRow).values(
                    source=p.source,
                    external_id=p.external_id,
                    observed_at=p.observed_at,
                    median_price=p.median_price,
                    tcg_price=p.tcg_price,
                    last_sold_price=p.last_sold_price,
                    quantity_available=p.quantity_available,
                    last_sold_meta=p.last_sold_meta,
                    currency=p.currency,
                ).on_conflict_do_nothing(
                    index_elements=["source", "external_id", "observed_at"]
                )
                result = session.execute(stmt)
                inserted += result.rowcount
        session.commit()
    return inserted
```

Alternative (bulk approach if rowcount is unreliable): count rows before
and after the batch insert, then `inserted = after - before`. But try
`rowcount` first — it's cleaner.

# F148-T05 — Import card via Liga link

**Status:** planned
**Wave:** 1
**Estimated effort:** M

## User Story

As a user, I want to paste a Liga Magic card URL and have the system
automatically load the card into the catalog with its price. If the price
can't be fetched immediately, I want to see a message that it was queued.

## Dev Notes

### Liga URL Format
```
https://www.ligamagic.com.br/?view=cards/card&card={encoded_name}
https://www.ligamagic.com.br/?view=cards/card&card={encoded_name}&ed={set_code}
```

### Backend
- **New endpoint:** `POST /api/v1/catalog/import-liga`
- Request body: `{ url: string }`
- Auth required, credit cost: 1
- Logic:
  1. Parse the Liga URL → extract card name (and optional set_code from `&ed=`)
  2. URL-decode the card name
  3. Search existing catalog cards by name (+ set_code if provided)
  4. If card found in catalog:
     - Create a `PriceUpdateRequestRow` for that card_id
     - Return: `{ status: "queued", card_id, card_name, message: "Solicitacao enfileirada" }`
  5. If card NOT found in catalog:
     - Search Liga via the existing provider to get card details
     - Create a new `CardRow` with available info (name, set_code)
     - Create a `PriceUpdateRequestRow` for the new card
     - Return: `{ status: "queued", card_id, card_name, message: "Card adicionado e preco enfileirado" }`
  6. On any error (invalid URL, Liga unreachable):
     - Return appropriate error message
- **File:** `src/api/routers/catalog.py`
- **URL parsing helper:** new function in `src/providers/liga/url.py`

### Frontend
- **New component:** `ImportLigaLink` — input field + submit button
- Location: catalog page header/toolbar area (near search bar)
- UI flow:
  1. User pastes Liga URL in input field
  2. Click "Importar" button
  3. Loading state while API processes
  4. Success: show toast "Card adicionado! Preco sera atualizado em breve"
  5. Error: show inline error (URL invalida, etc.)
- Input validation: check URL starts with `ligamagic.com.br` before submitting
- **File:** `frontend/src/pages/CatalogPage.tsx` (inline) or new component

### URL Parsing
- **File:** `src/providers/liga/url.py`
- New function: `parse_liga_card_url(url: str) -> tuple[str, str | None]`
  - Returns: (card_name, set_code_or_none)
  - Raises ValueError for invalid URLs
- Extract `card` param from query string → URL-decode
- Extract optional `ed` param

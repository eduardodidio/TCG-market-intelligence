# F148-T01 — Default sort by price desc (NULLS LAST)

**Status:** planned
**Wave:** 0
**Estimated effort:** XS

## User Story

As a user browsing the catalog, I want cards to be sorted by price
(highest first) by default, so I can immediately see the most valuable cards.
Cards without a price should appear at the bottom.

## Dev Notes

### Frontend
- **File:** `frontend/src/pages/CatalogPage.tsx` ~line 319
- Change default `sort_by` from `"name"` to `"price"` and `sort_dir` from `"asc"` to `"desc"`
- The URL param restoration already handles persisting user-chosen sorts

### Backend
- **File:** `src/api/routers/catalog.py`
- The `GET /catalog/cards` endpoint already supports `sort_by=price` + `sort_dir=desc`
- Verify NULLS LAST behavior in the SQL ORDER BY for price sort
- Current price sort uses `COALESCE(latest_price.median_price, 0)` — change to push NULLs to bottom:
  - For DESC: `ORDER BY CASE WHEN median_price IS NULL THEN 1 ELSE 0 END, median_price DESC`
  - Or use `NULLS LAST` if PostgreSQL (Neon supports it)

### Files to modify

2. `src/api/routers/catalog.py` — NULLS LAST for price sort

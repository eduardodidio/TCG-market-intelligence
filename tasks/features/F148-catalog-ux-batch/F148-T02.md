# F148-T02 — Duplicate card disambiguation

**Status:** planned
**Wave:** 0
**Estimated effort:** S

## User Story

As a user browsing the catalog, when I see multiple cards with the same name
in the same set, I want to see what differentiates them (collector number,
type line, variant) so I can tell them apart.

## Dev Notes

### Root Cause
Scryfall bulk data includes multiple entries for the same card name within a
set — these are different printings (e.g., alternate art, borderless, extended
art, showcase, different collector numbers). The current CatalogCardTile only
shows name + set_code + rarity + price, so duplicates look identical.

### Frontend
- **File:** `frontend/src/pages/CatalogPage.tsx` — `CatalogCardTile` component
- Add `collector_number` display as a small badge next to set_code (e.g., `#354`)
- Add `type_line` as a subtle secondary text line below the name (truncated)
- The data is already in the `CatalogCard` interface (`collector_number`, `type_line`)
  and returned by the API — just not rendered

### Layout (non-compact mode)
```
  Card Name
  [SET] [R] #354
  Creature — Human Wizard
  R$ 12.50
```

# F148-T04 — Bulk refresh collection prices

**Status:** planned
**Wave:** 1
**Estimated effort:** M

## User Story

As a user with a card collection, I want to refresh prices for all my
collection cards at once, so I don't have to refresh them one by one.

## Dev Notes

### Backend
- **New endpoint:** `POST /api/v1/collection/refresh-all-prices`
- Auth required
- Logic:
  1. Fetch all card_ids from `user_collection` for the authenticated user
  2. Deduplicate (user may have multiple entries for same card_id)
  3. Skip cards that already have a pending `PriceUpdateRequestRow` (created < 24h ago)
  4. Check credit balance: 1 credit per card to enqueue
  5. Deduct credits
  6. Create `PriceUpdateRequestRow` entries (status="pending") for each card
  7. Return: `{ status: "queued", card_count: N, total_cost: N, skipped: N }`
- Safety limit: cap at 500 cards per request (same as daily-scan)
- **File:** `src/api/routers/collection.py` or new endpoint in `cards.py`

### Frontend
- **File:** `frontend/src/pages/MyCollection.tsx`
- Add "Atualizar Todos os Precos" button in the toolbar/header area
- On click: show `CreditConfirmModal` with cost (card_count * 1 credit)
- On confirm: call the new endpoint
- Show toast/feedback: "X cards queued for price update"
- Disable button while request is in flight

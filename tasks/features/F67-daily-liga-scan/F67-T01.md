# F67-T01: Scan Preview Endpoint + Per-Card Credit Cost

**Status:** done
**Wave:** 0

## Summary

Replace the flat `BULK_SCAN_COST=5` with per-card pricing (1 credit per
card). Add a preview endpoint so the frontend can display exact cost.
Thread `max_age_days` through `POST /scans` so users can skip
recently-scanned cards.

## Acceptance Criteria

1. `GET /scans/preview?max_age_days=N` returns JSON:
   `{card_count, credit_cost, skipped_count}`.
   - `card_count` = number of cards that WILL be scanned.
   - `skipped_count` = cards excluded by `max_age_days`.
   - `credit_cost` = `card_count * CARD_REFRESH_COST` (0 for admin).
   - Requires auth (JWT or API key).
2. `POST /scans` accepts optional `max_age_days` in `ScanRequest`.
   - Threaded into `run_liga_scan(..., max_age_days=N)`.
   - Stored in `filters_json` for traceability.
3. Non-admin bulk scan cost = `card_count * CARD_REFRESH_COST`.
   - Deducted upfront (before launching background thread).
   - Uses the same `max_age_days` to count eligible cards.
4. Admin bypass unchanged (no credit check/deduction).
5. `BULK_SCAN_COST` constant removed or deprecated.
6. All existing scan tests updated; new tests for preview + per-card cost.

### Router: preview endpoint
```
# src/api/routers/scans.py

@router.get("/preview", response_model=ScanPreviewResponse)
async def preview_scan(
    max_age_days: int | None = Query(None, ge=1),
    user: User = Depends(get_current_user),
    credit_svc: CreditService = Depends(get_credit_service),
):
    repo = Repository(_get_db_url())
    scan_filter = ScanFilter()
    all_entries = repo.get_cards_for_liga_scan(scan_filter, max_age_days=None)
    eligible = repo.get_cards_for_liga_scan(scan_filter, max_age_days=max_age_days)
    card_count = len(eligible)
    skipped = len(all_entries) - card_count
    cost = 0 if user.is_admin else card_count * CARD_REFRESH_COST
    return ScanPreviewResponse(
        card_count=card_count,
        skipped_count=skipped,
        credit_cost=cost,
    )
```

### Router: trigger_scan update
In `trigger_scan`, replace flat `BULK_SCAN_COST` deduction:
1. Parse `max_age_days` from request.
2. Count eligible cards via `repo.get_cards_for_liga_scan(filter, max_age_days)`.
3. `cost = len(eligible) * CARD_REFRESH_COST`.
4. Check + deduct upfront (non-admin only).
5. Pass `max_age_days` to `run_liga_scan` in the background thread.

### Constants cleanup
- Keep `CARD_REFRESH_COST = 1` (already exists).
- Remove or comment out `BULK_SCAN_COST = 5`.
- Add `PER_CARD_SCAN_COST = CARD_REFRESH_COST` alias if needed for clarity.

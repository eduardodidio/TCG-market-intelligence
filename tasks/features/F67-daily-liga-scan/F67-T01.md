# F67-T01: Scheduled admin_daily_liga job + admin credit exemption

**Status:** planned
**Wave:** 0

## User Story

As an admin, I want my collection prices to be automatically refreshed daily
via Liga without spending treasure tokens, so I always have fresh price data
for market analysis.

### Admin exemption in scan flow

Add a `skip_credits: bool = False` parameter to `run_scan` or create a wrapper:
```python
async def run_admin_daily_liga_scan(db_url: str, **kwargs):
    """Daily Liga scan for all admin collections. No credit cost."""
    repo = Repository(db_url)
    admin_users = repo.get_admin_users()  # new repo method
    for admin in admin_users:
        scan_filter = ScanFilter(user_id=str(admin.id))
        await run_liga_scan(
            db_url=db_url,
            scan_filter=scan_filter,
            max_age_days=kwargs.get("max_age_days", 1),
            **kwargs,
        )
```

### Scheduler integration

In `src/scheduler/service.py`, add handler for `admin_daily_liga` scan type

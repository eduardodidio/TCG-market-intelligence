# F67-T02: Per-card credit cost for non-admin bulk "Refresh All"

**Status:** planned
**Wave:** 1
**Depends on:** T01

## User Story

As a non-admin user with treasure tokens, when I click "Refresh All" on my
collection page, I want to be informed of the total credit cost (1 token per
card) and have it deducted as cards are scanned, so I can decide if I want
to spend my tokens on a full refresh.

## Dev Notes

### Bulk scan credit flow

When `POST /scans` is triggered by a non-admin user for collection scan:

1. **Pre-check**: Count collection entries, calculate total cost
2. **Confirm**: Return cost estimate in response (frontend shows confirmation)
3. **Per-card deduction**: During scan, deduct 1 credit per successful card scan
4. **Insufficient mid-scan**: If credits run out during scan, pause and mark
   scan as "paused_insufficient_credits"
5. **Admin bypass**: If user `is_admin=1`, skip all credit checks

### API changes

Update `POST /scans` (or add new endpoint) to include cost preview:
```python
@router.post("/scans")
def trigger_scan(body, user = Depends(require_auth_or_api_key), ...):
    # If not admin, calculate cost
    if not user.is_admin:
        total_cards = repo.count_collection_entries(user_id=str(user.id))
        if not credit_svc.check_sufficient(user.id, total_cards):
            raise HTTPException(402, detail={
                "code": "INSUFFICIENT_CREDITS",
                "balance": balance,
                "cost": total_cards,
            })
    # Start scan with credit callback
```

### Scan callback for per-card deduction

Pass a callback to `run_scan` that deducts 1 credit per card:
```python
async def on_card_scanned(card_name: str, entry_id: int):
    if not is_admin:
        credit_svc.deduct(user_id, 1, "card_refresh", reference_id=str(entry_id))
```

### Frontend update

Update `useCollectionRefresh.startRefresh` to show CreditConfirmModal with
total cost before triggering scan.

# F67-T02: Admin Daily Liga Scan Job

**Status:** done
**Wave:** 0

## Summary

Add a system-level scheduled job (`admin_daily_liga`) that runs at 6 AM
daily, scanning all admin users' collections via Liga with
`max_age_days=1`. No credit cost. Hardcoded in scheduler startup via
`seed_default_liga_schedules`.

## Acceptance Criteria

1. New repo method `get_admin_user_ids()` returns list of user IDs where
   `is_admin=1`.
2. New async function `run_admin_daily_liga_scan(db_url, max_age_days=1)`
   in `src/collectors/admin_scan.py`:
   - Queries admin user IDs.
   - Gathers all their collection entries (deduplicated by `card_id`).
   - Runs a single `run_liga_scan` with those entries and `max_age_days`.
   - No credit deduction (system job, not user-initiated).
3. `seed_default_liga_schedules` adds a third schedule:
   - Name: `"Admin Daily Liga"`
   - Cron: `"0 6 * * *"` (6 AM daily)
   - Scan type: `"admin_daily_liga"`
   - `filters_json`: `{"provider": "liga", "max_age_days": 1}`
   - Idempotent: does not duplicate if already exists.
4. `ScanScheduler._execute_scheduled_scan` handles `admin_daily_liga`
   scan type by calling `run_admin_daily_liga_scan`.
5. Existing Liga schedules (Daily Partial, Weekly Full) unchanged.
6. Job auto-pauses on repeated failures (existing F37 behavior preserved).

## Implementation Notes

### Repository: `get_admin_user_ids`
```python
# src/database/repository.py
def get_admin_user_ids(self) -> list[int]:
    """Return IDs of all users with is_admin=1."""
    with Session(self.engine) as session:
        stmt = select(UserRow.id).where(UserRow.is_admin == 1)
        return list(session.execute(stmt).scalars().all())
```

### Admin scan orchestrator
```python
# src/collectors/admin_scan.py
async def run_admin_daily_liga_scan(
    db_url: str,
    run_id: int | None = None,
    max_age_days: int = 1,
    on_complete: Callable | None = None,
) -> ScanRun:
    repo = Repository(db_url)
    admin_ids = repo.get_admin_user_ids()
    if not admin_ids:
        # No admins: mark scan complete with 0 cards
        ...

    # Build scan filter for all admin collection entries
    # get_cards_for_liga_scan already supports user_id filter
    # For multiple admins, run once per admin or collect all card_ids
    all_card_ids = set()
    for uid in admin_ids:
        entries = repo.get_cards_for_liga_scan(
            ScanFilter(), user_id=str(uid), max_age_days=max_age_days
        )
        all_card_ids.update(e["card_id"] for e in entries)

    if not all_card_ids:
        # All cards recently scanned
        ...

    scan_filter = ScanFilter(card_ids=list(all_card_ids))
    return await run_liga_scan(
        db_url=db_url,
        scan_filter=scan_filter,
        run_id=run_id,
        max_age_days=max_age_days,
        on_complete=on_complete,
    )
```

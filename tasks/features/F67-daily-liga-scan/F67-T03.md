# F67-T03: Frontend Per-Card Cost + max_age_days Selector

**Status:** done
**Wave:** 1
**Depends on:** T01

## Summary

Update the "Refresh All" flow on MyCollection to show per-card cost from
the preview endpoint and let the user choose a `max_age_days` freshness
threshold before confirming.

## Acceptance Criteria

1. New API client function `fetchScanPreview(maxAgeDays?: number)` calls
   `GET /scans/preview?max_age_days=N`.
2. When user clicks "Refresh All", the `CreditConfirmModal` opens with:
   - Card count and per-card cost from preview (not hardcoded `5`).
   - Skipped count shown as helper text ("N cards skipped, scanned recently").
   - A dropdown/select to change `max_age_days` (options: 1, 3, 7, or
     "All" = no filter). Changing the value re-fetches the preview.
3. `useCollectionRefresh.startRefresh` accepts optional `maxAgeDays`
   parameter, passed to `triggerScanAuth`.
4. `triggerScanAuth` sends `max_age_days` in the request body.
5. Admin users see "0 credits (admin)" in the modal (existing behavior
   preserved).
6. i18n keys added for new strings (both EN and PT-BR).
7. Tests for preview fetch, modal with dynamic cost, and max_age_days
   passthrough.

## Implementation Notes

### API client
```typescript
// frontend/src/api/scans.ts
export async function fetchScanPreview(
  maxAgeDays?: number,
): Promise<ApiResponse<ScanPreviewResponse>> {
  const params = maxAgeDays ? `?max_age_days=${maxAgeDays}` : "";
  return apiGet<ScanPreviewResponse>(`/api/v1/scans/preview${params}`);
}
```

### ScanRequest update
```typescript
// triggerScanAuth in scans.ts
export function triggerScanAuth(
  request: { scan_type: string; provider?: string; max_age_days?: number },
): Promise<ApiResponse<ScanTriggerResponse>> {
  return apiPost<ScanTriggerResponse>("/api/v1/scans", { ... });
}
```

### useCollectionRefresh update
- `startRefresh(maxAgeDays?: number)` passes `max_age_days` to
  `triggerScanAuth`.

### MyCollection page update
- Replace `setBulkCreditModalOpen(true)` with a flow that:
  1. Fetches preview (default `max_age_days=1`).
  2. Opens modal with preview data.
  3. Dropdown changes re-fetch preview.
  4. Confirm calls `startRefresh(selectedMaxAgeDays)`.
- `CreditConfirmModal` props extended: `cardCount`, `skippedCount`
  (optional display fields). Cost is now dynamic from preview, not
  hardcoded.

### MaxAgeDaysSelect component
Small select/dropdown component with options:
- "Last 24h" (1), "Last 3 days" (3), "Last 7 days" (7), "Scan all" (undefined)

### i18n keys
```

"collection.maxAgeDaysOption1": "Last 24 hours"

```

# F31-T01: SetIconFilter constrained width + scroll styling

**Status:** planned
**Wave:** 1

## User Story

As a user, I want the set filter to show ~10 icons at a time with a smooth
horizontal scroll, so it doesn't overwhelm the interface.

## Dev Notes

### Files to modify
- `frontend/src/components/SetIconFilter.tsx`

### Implementation
1. Add `max-w-full` on the outer container (it already has `overflow-x-auto`)
2. Add a fixed/max-width wrapper or use CSS `max-width` so only ~10 icons
   (10 * 40px + 10 * 8px gap = ~480px) show without overflow on desktop
3. Actually, better approach: keep `overflow-x-auto` but add a gradient fade
   on the right edge to indicate more content
4. Add custom scrollbar styling via Tailwind classes:
   - `scrollbar-thin scrollbar-track-slate-800 scrollbar-thumb-slate-600`
   - Or use `::-webkit-scrollbar` CSS
5. Wrap the icon list in a `relative` container, add gradient overlay `div`
   on the right side (`pointer-events-none`, gradient from transparent to
   slate-900)

### Scroll container sizing
- Use `max-w-[520px]` or similar to constrain to ~10 icons
- On mobile: `max-w-full` (uses available width, fewer icons visible)
- The "All" button takes ~60px, so effective space = ~460px for icons

### Gradient fade indicator
```tsx
<div className="absolute right-0 top-0 bottom-0 w-8 bg-gradient-to-l from-slate-900 to-transparent pointer-events-none" />
```

## Testing

- Render test: container has constrained max-width
- Render test: scroll is functional with 20+ options
- Render test: gradient overlay present
- Visual regression: icons are properly sized and scrollable

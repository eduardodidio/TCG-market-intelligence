# F31-T02: Scroll arrow buttons

**Status:** planned
**Wave:** 1

## User Story

As a user, I want arrow buttons on the sides of the set filter to scroll
through sets without needing to use the scrollbar.

## Dev Notes

### Files to modify
- `frontend/src/components/SetIconFilter.tsx`

### Implementation
1. Add left/right arrow buttons flanking the icon scroll container
2. Left arrow: hidden when scrolled to start, visible otherwise
3. Right arrow: hidden when scrolled to end, visible otherwise
4. On click: scroll the container by ~200px (smooth scroll)
5. Use `useRef` for the scroll container to control `scrollLeft`
6. Track scroll position via `onScroll` event to show/hide arrows

### Arrow button design
- Small circular buttons (w-7 h-7), `bg-slate-700 hover:bg-slate-600`
- Chevron left/right SVG icons
- `z-10` to appear above the gradient fade
- Positioned with `absolute` at the edges of the container

### Layout
```
[<] [All] [icon] [icon] ... [icon] [>]
```
- Outer wrapper: `relative flex items-center gap-1`
- Inner scroll area: `overflow-x-auto flex-1`
- Arrows: `absolute left-0 / right-0`

### Scroll behavior
```typescript
const scrollBy = (delta: number) => {
  scrollRef.current?.scrollBy({ left: delta, behavior: "smooth" });
};
```

## Testing

- Render test: arrows present when icons overflow
- Render test: left arrow hidden at scroll start
- Click test: right arrow scrolls container
- Click test: left arrow scrolls back

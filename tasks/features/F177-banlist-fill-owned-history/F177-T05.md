## User Story
As a player browsing the ban list, I want to click a card and see its legality in every format plus when it was banned or unbanned, so that I don't need a separate history page.

## Objective
Build `frontend/src/components/BanCardDetailModal.tsx`, a self-contained modal that fetches legalities + ban history for one card.

## Implementation details
- `export function BanCardDetailModal({ entry, onClose }: { entry: ModalEntry | null; onClose: () => void })`
- Esc key listener (`useEffect` on keydown), backdrop click closes, click inside doesn't close (stopPropagation), and focus moves to the close button on open.
- Sections render independently with their own loading/error states.
- Sort legalities: banned, restricted, legal, not_legal; then alphabetical.
- History grouped by format: `entry.format` first, then alphabetical. Within a format, newest first.
- `Link` to `/cards/${entry.card_id}` ("Open card page").

## Acceptance criteria
- [ ] `entry=null` → renders nothing
- [ ] Shows the name, set/#, current status badge, and owned qty when > 0
- [ ] Legalities grid sorted by severity
- [ ] History grouped by format with `StatusTransition`; the baseline label appears for `scryfall_baseline`
- [ ] Empty history → `ban-card-history-empty`
- [ ] Esc / backdrop / close button call `onClose`
- [ ] Accessible: `role="dialog"`, `aria-modal`, `aria-labelledby`

## Test scenarios
- Happy: legalities (commander banned, legacy legal) + history (2 events in commander, 1 in legacy) → grouped, commander first
- Happy: the owned badge shows "2x" when `owned_quantity=2`
- Edge: `entry=null` → container empty
- Edge: history empty → empty message; legalities empty → "unavailable" (`legality.unavailable` key)
- Edge: a baseline event shows the baseline label, not a date
- Error: fetchCardBanHistory rejects → history error text while legalities still render
- Interaction: Esc → onClose called once; backdrop click → onClose; click inside the dialog → not called
- Boundary: 20+ formats render without crashing (scrollable container)

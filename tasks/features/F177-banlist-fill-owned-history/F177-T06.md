## Implementation details
- Pure helpers: `_select_download_url(catalog: dict) -> str | None`, `_parse_bulk_line(line: bytes) -> dict | None`, `_build_index_keys(set_code, cn) -> set[tuple[str,str]]`, `_classify(...)`.
- An async generator `_iter_bulk_lines(resp, gzipped)` yields complete lines (gzip via `zlib.decompressobj(16 + zlib.MAX_WBITS)`; detect via the URL suffix or the magic bytes of the first chunk).
- Flush writes every ~5000 pending legalities.
- `_sync_per_card`: `map_to_scryfall_set_code` in the URL, `follow_redirects=True`, and the same `_classify` policy.

## Acceptance criteria
- [ ] JSONL, JSONL.gz, and JSON-array (`[`, `{..},`, `]`) fixtures all populate `card_legalities`

- [ ] `scope="full"` stores every format for every matched card
- [ ] `pytest tests/banlist -v` green; `ruff check src/collectors/banlist_sync.py` clean; module coverage ≥ 90%

## Test scenarios
- Happy: JSONL 3 cards (1 banned in commander, 1 restricted in vintage, 1 all legal) → the correct compact rows
- Happy: the gzip variant produces identical results to plain
- Edge: JSON-array lines with trailing commas, `[`/`]`, blank lines, and a CRLF line ending
- Edge: a line split across two chunks is reassembled (chunk size 7 bytes in the mock)
- Edge: collector number "007" locally vs "7" in Scryfall → matches
- Edge: two local card ids map to the same Scryfall key → both are written
- Error: a malformed JSON line → `summary.errors += 1`, the rest processed
- Error: catalog without a default_cards entry → `summary.errors == 1`, no raise (existing behavior)
- Error: 0 matches → RuntimeError message contains "matched 0 cards"
- Boundary: `limit=1` → exactly 1 card processed
- Unit: `_parse_bulk_line`, `_build_index_keys`, `_classify` truth table (first_sync × existing × status × owned × scope)

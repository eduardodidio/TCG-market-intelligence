# F93-T02 — Auth State Sync Across Tabs

**Wave:** 0
**Status:** planned
**Estimate:** S (small)

## User Story

As a user with multiple tabs open, when I logout on one tab, I want the other tabs to also redirect to login so I don't interact with a stale session.

## Dev Notes

### Current behavior
- AuthContext reads tokens from localStorage on mount only
- No `storage` event listener — logout/login on Tab A has zero effect on Tab B
- Tab B continues using stale in-memory token until next page refresh

### Implementation

1. **Update `frontend/src/contexts/AuthContext.tsx`**:
   - Add `useEffect` with `window.addEventListener('storage', handler)`
   - Handler listens for changes to `tcg_access_token` key:
     - If token was **removed** (logout on another tab): clear auth state, navigate to `/login`
     - If token was **added/changed** (login on another tab): call `fetchMe()` with new token to update user state
   - Cleanup: `removeEventListener` on unmount

2. **Key detail**: `storage` event only fires on **other** tabs (not the originating tab), which is exactly what we want — the originating tab already handles its own state via `login()`/`logout()`

### Files

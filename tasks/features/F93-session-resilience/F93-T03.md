# F93-T03 — Refetch Data on Window Focus

**Wave:** 1
**Status:** planned
**Estimate:** S (small)

## User Story

As a user returning to the app tab after a push-db or background data update, I want the displayed data to automatically refresh so I always see the latest collection without needing to logout/login.

## Dev Notes

### Current behavior
- `useApi` hook fetches data once on mount (or when deps change)
- No refetch mechanism on window focus/visibility change
- After push-db, user must logout+login to see updated collection

### Implementation

1. **Update `frontend/src/hooks/useApi.ts`**:
   - Add optional `refetchOnFocus` parameter (default: `false`)
   - When enabled, add `useEffect` with `document.addEventListener('visibilitychange', handler)`
   - Handler: if `document.visibilityState === 'visible'`, call `refetch()`
   - Add debounce: skip refetch if last fetch was < 30 seconds ago (avoid hammering API on rapid tab switches)
   - Cleanup: remove listener on unmount

2. **Enable `refetchOnFocus` on key pages**:
   - `MyCollection.tsx` — collection list (main use case for push-db staleness)
   - `CollectionCardDetail.tsx` — card detail
   - `DeckList.tsx` — deck list
   - Dashboard — landing page

3. **Keep it opt-in**: not all pages need this (admin, settings, etc.)

### Files
- `frontend/src/hooks/useApi.ts` — add refetchOnFocus option + visibility listener
- `frontend/src/pages/MyCollection.tsx` — enable refetchOnFocus
- `frontend/src/pages/CollectionCardDetail.tsx` — enable refetchOnFocus
- `frontend/src/pages/DeckList.tsx` — enable refetchOnFocus
- `frontend/src/pages/Dashboard.tsx` — enable refetchOnFocus

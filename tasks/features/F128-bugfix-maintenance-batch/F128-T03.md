## User Story

As a user, I want to be able to reset my collection and re-import from
a CSV file via CLI, so I can test the full import flow or migrate data.

## Dev Notes

### Implementation

Add a `import-csv` Click command to `src/cli/main.py`:

```python
@cli.command("import-csv")
@click.option("--file", "csv_file", required=True, type=click.Path(exists=True),
              help="Path to the CSV file to import")
@click.option("--user-id", required=True, help="User ID to import into")
@click.option("--dry-run", is_flag=True, help="Parse CSV and show stats without importing")
def import_csv_cmd(csv_file: str, user_id: str, dry_run: bool):
    """Import collection from CSV file (clears existing collection first)."""
    from src.collection.importer import import_collection_csv

    if dry_run:

        return

    result = import_collection_csv(engine, csv_file, user_id)
    click.echo(f"Imported: {result['imported']}")
    click.echo(f"Skipped: {result['skipped']}")

```

### Usage

```bash
# Dry run first
python -m src.cli.main import-csv --file docs/exportColeacao.csv --user-id <uid> --dry-run

# Actual import (clears existing collection!)
python -m src.cli.main import-csv --file docs/exportColeacao.csv --user-id <uid>
```

### Acceptance Criteria

- [ ] `import-csv --dry-run` shows row count without modifying DB
- [ ] `import-csv` clears existing collection and imports all rows
- [ ] Reports imported/skipped/linked counts
- [ ] Works with both UTF-8 and cp1252 encoded CSVs
- [ ] Error on missing file or invalid user-id

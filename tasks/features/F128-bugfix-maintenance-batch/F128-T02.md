# F128-T02: Fix CardPreviewModal Backdrop Click Navigation in MyCollection

**Status:** planned
**Wave:** 0
**Depends on:** none

## User Story

As a user browsing My Collection, when I click a card image to zoom in
and then click outside the preview to close it, I want to stay on the
collection page — not navigate to the card detail page.

## Dev Notes

### Root Cause

In `frontend/src/pages/MyCollection.tsx`, `CollectionCardTile` builds:

```tsx
const inner = (
  <Card3DTilt>
    <div>...card content...</div>
    {previewOpen && <CardPreviewModal ... />}   // ← INSIDE inner
  </Card3DTilt>
);

return (
  <>
    <Link to={`/collection/${card.id}`}>{inner}</Link>  // ← inner (with modal) INSIDE Link
    ...
  </>
);
```

React portal synthetic events bubble through the **React component tree**:
`CardPreviewModal → Card3DTilt → inner → Link`. The Link intercepts the
click and navigates.

### Fix

Move the `CardPreviewModal` render block OUT of `inner`, placing it as a
sibling to `<Link>` in the return statement:

```tsx
const inner = (
  <Card3DTilt>
    <div>...card content...</div>
    {/* modal REMOVED from here */}
  </Card3DTilt>
);

return (
  <>
    <Link to={`/collection/${card.id}`}>{inner}</Link>
    <CreditConfirmModal ... />
    {previewOpen && primaryUrl && (
      <CardPreviewModal
        imageUrl={primaryUrl}
        cardName={displayName}
        isFoil={card.is_foil}
        onClose={() => setPreviewOpen(false)}
      />
    )}
  </>
);
```

### Other components — already OK

Verified that the modal is NOT inside a Link in:
- `CardTile.tsx` — sibling to Link, inside Card3DTilt (no Link parent)
- `CatalogPage.tsx` — sibling to Link, inside Card3DTilt
- `DeckCardTile.tsx` — outside both Card3DTilt and Link
- `SharedCollectionPage.tsx` — no Link wrapper on tile
- `Marketplace.tsx` — no Link wrapper on tile
- `WishlistPage.tsx` — no Link wrapper on tile
- `DuplicatesList.tsx` — no Link wrapper on tile

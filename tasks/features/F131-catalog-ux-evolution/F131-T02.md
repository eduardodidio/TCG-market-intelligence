# F131-T02 — Per-Card Liga Refresh Button on Catalog Tiles

## User Story

As a catalog browser, I want to request a Liga price refresh for any
individual card so that I can get up-to-date pricing without running a
full set scan.

## Dev Notes

### Context

The collection page's `CardTile.tsx` already has a per-card refresh
button that calls `POST /api/v1/cards/{card_id}/refresh-price`. This
endpoint queues a `price_update_requests` row (F130) and deducts 1
credit. The endpoint works for ANY card in the `cards` table (not just
collection cards), so it already supports catalog cards. The frontend
API function `refreshCardPrice(cardId)` in `frontend/src/api/cards.ts`
is also ready to use.

The `CatalogCardTile` component currently has no refresh button.

### Implementation Steps

**File: `frontend/src/pages/CatalogPage.tsx` (CatalogCardTile)**

1. Import `refreshCardPrice` from `../api/cards`.
2. Import `useAuth` from the auth context to check `isAuthenticated`.
3. Add local state: `const [refreshing, setRefreshing] = useState(false);`
   and `const [queued, setQueued] = useState(false);`.
4. Add a `handleRefresh` handler (pattern from `CardTile.tsx`):
   - Prevent event propagation (the tile is wrapped in a `<Link>`).
   - Call `refreshCardPrice(card.id)`.
   - On success, set `queued = true`.
   - On error, optionally show a toast or log.
5. Render the refresh button in the card image area (top-right corner),
   matching the `CardTile` styling: a circular button with a refresh
   icon, conditionally showing a checkmark when queued.
6. Only show the button when `isAuthenticated` is true.
7. Show a `CostBadge` or tooltip indicating the 1-credit cost.

### Files to Modify

### Key Decisions

- Reuse the existing `refreshCardPrice` API function and the existing
  backend endpoint; no backend changes needed.
- The button uses the same visual pattern as `CardTile.tsx` for
  consistency (circular, top-right, refresh icon).
- No credit confirmation modal for single-card refresh (consistent with
  the collection page behavior).

# F131-T01 — Grid Size Toggle on Catalog Page

## User Story

As a catalog browser, I want to switch between small, medium, and large
card grids so that I can see more cards at once (small) or examine
individual cards in detail (large).

## Dev Notes

### Context

The collection page (`MyCollection.tsx`) already uses `GridSizeToggle`
and `useGridSize` with `GRID_SIZE_CONFIG` from `constants.ts`. The
catalog page uses a hardcoded 5-column grid
(`grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 xl:grid-cols-5 gap-4`).

### Implementation Steps

**File: `frontend/src/pages/CatalogPage.tsx`**

1. Import `GridSizeToggle` from `../components/GridSizeToggle` and
   `useGridSize` from `../hooks/useGridSize`.
2. Import `GRID_SIZE_CONFIG` from `../utils/constants`.
3. Call `const { gridSize, setGridSize } = useGridSize();` at the top of
   the `CatalogPage` component.
4. Place the `<GridSizeToggle value={gridSize} onChange={setGridSize} />`
   in the sticky filter bar, next to the Filters button (right side).
5. Replace the hardcoded grid classes on both the skeleton grid
   (`data-testid="skeleton-grid"`) and the card grid
   (`data-testid="catalog-grid"`) with
   `grid ${GRID_SIZE_CONFIG[gridSize].gridClasses}`.
6. Optionally pass `compact={GRID_SIZE_CONFIG[gridSize].compact}` to
   `CatalogCardTile` so it can hide the info section when the grid is
   small (matching the collection tile behavior). If `CatalogCardTile`
   does not accept `compact`, add the prop and conditionally hide the
   `p-3` info section.

### Files to Modify

- `frontend/src/pages/CatalogPage.tsx` — add hook, toggle component,
  dynamic grid classes
- `frontend/src/pages/CatalogPage.tsx` (`CatalogCardTile`) — optional
  compact mode support

### Key Decisions

- Reuse the same `useGridSize` hook (shared localStorage key
  `tcg:grid-size`), so switching on the collection page also applies to
  the catalog and vice versa. This is intentional for UX consistency.
- The `GridSizeToggle` component is already styled and
  internationalized; no changes needed to it.

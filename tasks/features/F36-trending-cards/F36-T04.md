# F36-T04 — Frontend: TrendingCard + TrendingSection Components

**Wave:** 3 (parallel with T05)
**Depends on:** T03 (API contract)
**Creates:** `frontend/src/components/TrendingCard.tsx`,
`frontend/src/components/TrendingSection.tsx`,
`frontend/src/api/trending.ts`
**Modifies:** `frontend/src/types/api.ts`

## Objective

Build reusable frontend components for displaying trending cards: a
single card tile with price change indicators, and a scrollable section
that fetches and displays a list of trending cards.

## Steps

### 1. Add TypeScript types (`frontend/src/types/api.ts`)

```typescript
export interface TrendingCardEntry {
  card_id: number;
  name_en: string;
  name_pt: string | null;
  set_code: string | null;
  collector_number: string | null;
  image_url: string | null;
  price_start: number;
  price_end: number;
  change_pct: number;
  change_abs: number;
  consistency: number;
  composite_score: number;
  observation_count: number;
  currency: string;
}

export interface TrendingResponse {
  cards: TrendingCardEntry[];
  period: string;
  direction: "up" | "down";
  computed_at: string;
  cached: boolean;
}
```

### 2. Create API client (`frontend/src/api/trending.ts`)

```typescript
import { apiGet } from "./client";
import type { ApiResponse, TrendingResponse } from "../types/api";

export function fetchTrending(
  direction: "gainers" | "losers",
  params: { period?: string; limit?: string; currency?: string },
): Promise<ApiResponse<TrendingResponse>> {
  return apiGet<TrendingResponse>(`/market/trending/${direction}`, params);
}
```

### 3. Create `TrendingCard` component

File: `frontend/src/components/TrendingCard.tsx`

Props:
```typescript
interface TrendingCardProps {
  entry: TrendingCardEntry;
}
```

Renders:
- Card image thumbnail (64x90px, Scryfall URL, lazy loading, fallback
  placeholder on error).
- Card name (use `useCardName` hook for language-aware display).
- Set code badge (small, muted text).
- Price change line:
  - Arrow icon: up-arrow (green) or down-arrow (red) based on
    `change_pct` sign.
  - `change_pct` formatted as "+12.3%" or "-5.2%", colored green/red.
  - `change_abs` in parentheses, e.g. "(+R$3.50)".
- Composite score: thin horizontal bar (0-100), gradient from red (low)
  through amber (mid) to green (high). Show numeric value on hover
  (title attribute).
- Clickable: links to `/cards/${card_id}` (card detail page).

Styling: Tailwind slate-800 card with rounded corners, subtle border,
hover:ring effect. Compact width (~180px) for horizontal scroll layout.

### 4. Create `TrendingSection` component

File: `frontend/src/components/TrendingSection.tsx`

Props:
```typescript
interface TrendingSectionProps {
  direction: "gainers" | "losers";
  period: string;
  currency: string;
  limit?: number;
}
```

Behavior:
- Fetches trending data via `fetchTrending()` using `useApi` hook.
- Displays a section header: icon + title (e.g., "Trending Up",
  "Trending Down"), i18n-aware.
- Renders a horizontal scrollable container of `TrendingCard` tiles.
- Uses the same scroll pattern as `SetIconFilter` (left/right arrow
  buttons, overflow-x-auto, gradient fade).
- Shows `SkeletonCard` placeholders (3-4 cards) during loading.
- Shows `EmptyState` when no trending cards found.
- Shows `ErrorBanner` on fetch error with retry.
- Shows a muted "cached" badge with relative time if `cached` is true
  (e.g., "cached 5 min ago").

### 5. Currency formatting

Use the existing currency formatting patterns from the codebase. For
PILA currency, use the pila extenso format if applicable, or just the
numeric value with the Pila symbol.

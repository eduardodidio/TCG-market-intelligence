## Objective

Create pure trending score functions that compute a composite score for
a card's price movement, factoring in percentage change, consistency of
direction, observation density, and recency. Include anti-false-trending
filtering and ranking.

## Steps

### 1. Add domain dataclass to `src/domain/models.py`

Add after the existing analytics models:

```python
@dataclass
class TrendingScore:
    """Composite trending score for a single card over a period."""
    card_id: int
    change_pct: Decimal        # raw % change (positive or negative)
    change_abs: Decimal         # absolute price change
    consistency: Decimal        # 0-1, fraction of daily deltas in same direction
    observation_count: int      # data points in the period window
    observation_density: Decimal # observation_count / period_days (0-1, capped)
    composite_score: Decimal    # weighted score 0-100
    direction: str              # "up" | "down"
    price_start: Decimal
    price_end: Decimal
    latest_date: date           # date of most recent observation
```

### 2. Create `src/analytics/trending.py`

New file with two public functions. All imports from `src/domain/models`
only. No database imports. All arithmetic in Decimal.

#### 2a. `compute_trending_score()`

```python
def compute_trending_score(
    card_id: int,
    prices: list[tuple[date, Decimal]],
    period_days: int,
) -> TrendingScore | None:
```

Logic:
1. Sort prices by date ascending. Deduplicate by date (keep last).
2. If fewer than 2 data points, return None.
3. `price_start` = first price, `price_end` = last price.
4. `change_abs` = price_end - price_start.
5. `change_pct` = (change_abs / price_start) * 100. If price_start == 0,
   return None.
6. `direction` = "up" if change_abs > 0, "down" if change_abs < 0. If
   exactly 0, return None (no movement).
7. **Consistency**: compute daily deltas between consecutive observations.
   Count how many deltas go in the same direction as `direction`.
   `consistency` = matching_deltas / total_deltas. Value is 0-1.
   If only 1 delta exists, consistency = 1 if it matches direction, else 0.
8. `observation_count` = number of prices.
9. `observation_density` = min(observation_count / period_days, 1.0).
10. `latest_date` = date of last observation.
11. **Recency bonus**: 1.0 if latest_date is within 2 days of today,
    0.5 if within 7 days, 0.0 otherwise. (Pass `reference_date` as
    param with default `date.today()` for testability.)
12. **Composite score**:
    - change_component = min(abs(change_pct), 100) * 0.40
    - consistency_component = consistency * 100 * 0.30
    - density_component = observation_density * 100 * 0.20
    - recency_component = recency_bonus * 100 * 0.10
    - composite_score = sum of components, clamped to [0, 100]

Add `reference_date: date | None = None` parameter (defaults to
`date.today()`) for testing without time-dependency.

#### 2b. `rank_trending()`

```python
def rank_trending(
    scores: list[TrendingScore],
    direction: str,  # "up" | "down"
    min_observations: int = 3,
    min_price: Decimal = Decimal("1.00"),
    min_consistency: Decimal = Decimal("0.50"),
    limit: int = 20,
) -> list[TrendingScore]:
```

Logic:
1. Filter to only scores matching `direction`.
2. Exclude scores where `observation_count < min_observations`.
3. Exclude scores where `price_start < min_price` (for "up") or
   `price_end < min_price` (for "down"). This prevents penny-card noise.
4. Exclude scores where `consistency < min_consistency`.
5. Sort remaining by `composite_score` descending.
6. Return top `limit` entries.

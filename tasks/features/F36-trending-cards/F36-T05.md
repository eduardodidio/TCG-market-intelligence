# F36-T05 — Frontend: Trending Page + Routing + i18n

**Wave:** 3 (parallel with T04)
**Depends on:** T03 (API contract)
**Creates:** `frontend/src/pages/Trending.tsx`
**Modifies:** `frontend/src/App.tsx`, navigation component,
`frontend/src/i18n/locales/en.json`,
`frontend/src/i18n/locales/pt-BR.json`

## Objective

Create the full trending page at `/market/trending` with gainers and
losers sections, period selector, and navigation link. Add all i18n
keys for trending labels.

## Steps

### 1. Create `Trending` page (`frontend/src/pages/Trending.tsx`)

Layout (similar to `MarketMovers.tsx` pattern):
- Page title: "Trending Cards" (i18n).
- Controls row:
  - Period selector buttons: 7d / 30d / 90d (same style as MarketMovers).
  - Limit selector dropdown: 10 / 20 / 50.
- Two sections stacked vertically:
  - "Trending Up" section with `TrendingSection` component
    (direction="gainers").
  - "Trending Down" section with `TrendingSection` component
    (direction="losers").
- Pass period, currency (from `useCurrency`), and limit as props to
  each `TrendingSection`.

State management:
- `period` state with URL search param persistence (same pattern as
  existing pages).
- `limit` state.
- `currency` from `useCurrency()` hook.

Document title: `useEffect` to set `document.title` with page name.

### 2. Add route to `App.tsx`

Add inside the `<Route element={<Layout />}>` block:

```tsx
<Route
  path="/market/trending"
  element={
    <Suspense fallback={<PageSkeleton />}>
      <Trending />
    </Suspense>
  }
/>
```

Use lazy import: `const Trending = lazy(() => import("./pages/Trending"))`.
Follow existing patterns in App.tsx.

### 3. Add navigation link

Add "Trending" link to the sidebar/nav component, near the existing
"Market Movers" link. Use a trending-up icon (e.g., arrow-trending-up
or chart-bar-up from Heroicons, or a simple SVG arrow).

Order in nav: Dashboard > Cards > Market Movers > Trending > Collection
> Decks > Scans.

`/market/trending?period=30d`. Default to "30d" when no param present.

# F36-T03 — Backend: Trending Service + API Endpoints + Schemas

**Wave:** 2 (after T01 and T02)
**Depends on:** T01 (trending score functions), T02 (batch price query)
**Creates:** `src/services/trending.py`, `src/api/schemas/trending.py`
**Modifies:** `src/api/routers/market.py`

## Objective

Build the trending service that orchestrates batch price loading, score
computation, and in-memory caching. Expose via two new API endpoints on
the existing market router.

## Steps

### 1. Create Pydantic schemas (`src/api/schemas/trending.py`)

```python
from datetime import datetime
from pydantic import BaseModel


class TrendingCardEntry(BaseModel):
    card_id: int
    name_en: str
    name_pt: str | None = None
    set_code: str | None = None
    collector_number: str | None = None
    image_url: str | None = None
    price_start: float
    price_end: float
    change_pct: float
    change_abs: float
    consistency: float      # 0.0-1.0
    composite_score: float  # 0-100
    observation_count: int
    currency: str = "BRL"


class TrendingResponse(BaseModel):
    cards: list[TrendingCardEntry] = []
    period: str             # "7d" | "30d" | "90d"
    direction: str          # "up" | "down"
    computed_at: datetime
    cached: bool = False
```

### 2. Create trending service (`src/services/trending.py`)

```python
class TrendingService:
    def __init__(self, repo: Repository):
        self._repo = repo
        self._cache: dict[str, tuple[datetime, TrendingResponse]] = {}
        self._cache_ttl = timedelta(minutes=30)
```

#### Method: `get_trending()`

```python
def get_trending(
    self,
    direction: str,
    period_days: int,
    limit: int,
    converter: CurrencyConverter,
    currency: str,
) -> TrendingResponse:
```

Flow:
1. Build cache key: `f"{direction}:{period_days}"`.
2. If cache hit and not expired, return cached response (set
   `cached=True`). Currency conversion is applied fresh even on cache
   hit since the user might request a different currency.
3. On cache miss:
   a. Call `repo.get_trending_price_data(period_days)`.
   b. For each card_id's price series, call
      `compute_trending_score(card_id, prices, period_days)`.
   c. Collect all non-None scores.
   d. Call `rank_trending(scores, direction, limit=limit)` for the
      requested direction.
   e. Load card metadata via `repo.get_card_info_batch(card_ids)`.
   f. Build `TrendingCardEntry` list with image URLs (Scryfall format).
   g. Apply currency conversion to `price_start`, `price_end`,
      `change_abs`.
   h. Cache the raw (pre-conversion) result.
4. Return `TrendingResponse`.

**Important**: cache stores the BRL-denominated result. Currency
conversion is applied on read from cache, not on write.

#### Method: `invalidate_cache()`

```python
def invalidate_cache(self) -> None:
    """Clear all cached trending data."""
    self._cache.clear()
```

### 3. Add dependency injection

Add to `src/api/deps.py` (or inline in router):

```python
def get_trending_service(repo: Repository = Depends(get_db)) -> TrendingService:
    return TrendingService(repo)
```

Note: since TrendingService holds an in-memory cache, consider using a
module-level singleton or FastAPI's app state so the cache persists
across requests. The simplest approach: store a module-level
`_trending_service: TrendingService | None = None` in deps.py and
create on first use (lazy singleton).

### 4. Add API endpoints to `src/api/routers/market.py`

```python
TRENDING_PERIOD_MAP = {"7d": 7, "30d": 30, "90d": 90}

@router.get("/trending/gainers", response_model=ApiResponse[TrendingResponse])
def get_trending_gainers(
    period: str = Query(default="30d"),
    limit: int = Query(default=20, ge=1, le=50),
    currency: str = Query(default="BRL", pattern="^(BRL|USD|PILA)$"),
    service: TrendingService = Depends(get_trending_service),
    converter: CurrencyConverter = Depends(get_currency_converter_dep),
):
    if period not in TRENDING_PERIOD_MAP:
        raise HTTPException(422, f"Invalid period. Must be: {', '.join(TRENDING_PERIOD_MAP)}")
    days = TRENDING_PERIOD_MAP[period]
    data = service.get_trending("up", days, limit, converter, currency)
    data.period = period
    return success_response(data=data)

@router.get("/trending/losers", response_model=ApiResponse[TrendingResponse])
def get_trending_losers(
    period: str = Query(default="30d"),
    limit: int = Query(default=20, ge=1, le=50),
    currency: str = Query(default="BRL", pattern="^(BRL|USD|PILA)$"),
    service: TrendingService = Depends(get_trending_service),
    converter: CurrencyConverter = Depends(get_currency_converter_dep),
):
    if period not in TRENDING_PERIOD_MAP:
        raise HTTPException(422, f"Invalid period. Must be: {', '.join(TRENDING_PERIOD_MAP)}")
    days = TRENDING_PERIOD_MAP[period]
    data = service.get_trending("down", days, limit, converter, currency)
    data.period = period
    return success_response(data=data)
```

- [ ] `TrendingService` computes trending scores via batch price data
- [ ] Cache stores BRL-denominated results with 30-min TTL

- [ ] `GET /market/trending/gainers?period=30d` returns trending-up cards

- [ ] Each card entry includes `image_url` (Scryfall format)

# F151-T03: Fix art card image in collection list

**Feature:** F151 — Art card image fix
**Wave:** 0
**Status:** planned
**Type:** bugfix (investigation complete, root cause found)

## User Story

As a user, I want to see the image for "The Arkenstone // Seek the Heart
(Art Card with Signature)" in my collection, which currently shows broken.

## Root Cause (confirmed via DB + URL testing)

**Card:** id=105871, set=`hob`, collector_number=`44a` (Art Card with Signature)
**Collection entry:** uc_id=1084, user_id=3

The collection list endpoint (line 192 of `collection.py`) uses
`_scryfall_image_url(r.set_code, r.collector_number)` which always
constructs a URL from set_code + collector_number, **ignoring** the
`image_uri` stored in the DB.

For collector_number `44a`:
- Generated URL: `https://api.scryfall.com/cards/hob/44a?format=image` → **404**
- DB `image_uri`: `https://cards.scryfall.io/normal/front/b/a/ba3ff39b-...` → **valid**
- `fallback_image_uri('hob', '44a')` strips suffix → `hob/44` → **302 OK**

The `_scryfall_image_url` function doesn't strip letter suffixes like
`fallback_image_uri` does. And it doesn't check the DB `image_uri` first.

## Dev Notes

### File: `src/api/routers/collection.py`

**Option A (minimal, preferred):** At line 192, prefer DB `image_uri` when
available, then fallback:

```python
image_url=r.image_uri or fallback_image_uri(r.set_code, r.collector_number) or _scryfall_image_url(r.set_code, r.collector_number),
```

Need to verify that `r` (the collection row) actually has `image_uri`
accessible. Check the JOIN/query in `list_collection`.

**Option B:** Fix `_scryfall_image_url` to strip letter suffixes like
`fallback_image_uri` does:

```python
def _scryfall_image_url(set_code: str, collector_number: str) -> str:
    mapped = map_to_scryfall_set_code(set_code)
    base_number = re.sub(r"[a-zA-Z]+$", "", collector_number) or collector_number
    return f"https://api.scryfall.com/cards/{mapped}/{base_number}?format=image&version=normal"
```

**Recommended: Both A + B.** Use DB image_uri first, and fix the fallback
URL generation for art cards.

### Also check these endpoints for the same bug:

# F154-T07: Add typeable set/collection filter to Cards page

**Feature:** F154 — Typeable set filter on Cards page
**Wave:** 2 (after F153 lands)
**Status:** done

## User Story

As a user exploring cards, I want to type a set name to quickly filter
by collection/set, instead of scrolling through a long icon grid.

## Dev Notes

### Current State

`Cards.tsx` uses a `selectedSet` state with `fetchSets()` to get all sets,
but the UI uses basic search + set icon filter components. The CatalogPage
has `SetIconFilter` (visual set icons) + `SortSelect`.

### Implementation

Add a searchable text input that filters the set list. Two approaches:

**Option A (simpler):** Add a text input above/beside the existing set filter
that filters the `sets` array client-side by name match:

```tsx
const [setSearch, setSetSearch] = useState("");
const filteredSets = useMemo(() => {
  if (!setSearch.trim()) return sets;
  const q = setSearch.toLowerCase();
  return sets.filter(s =>
    s.name.toLowerCase().includes(q) || s.code.toLowerCase().includes(q)
  );
}, [sets, setSearch]);
```

**Option B (dropdown with search):** Create a `SetSearchFilter` component
that shows a filter icon button → opens a dropdown with a text input +
scrollable list of matching sets. Clicking a set selects it.

### Recommended: Option B

Create `frontend/src/components/SetSearchFilter.tsx`:
- Filter icon button (funnel icon) that toggles a dropdown
- Text input for typing set name
- Scrollable list of matching sets (max-h with overflow-y-auto)
- Each set shows icon (via scryfallSetIconUrl) + name + card count
- Click to select, click again to deselect
- Close on outside click

### File: `frontend/src/pages/Cards.tsx`

Add `SetSearchFilter` next to existing filters:
```tsx
<SetSearchFilter
  sets={sets}
  selectedSet={selectedSet}
  onSelect={setSelectedSet}
/>
```

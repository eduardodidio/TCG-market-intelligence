### Journeys to test

1. New user registration → first scan → view prices
2. Guest user login → browse collection → view card detail
3. Add card → set acquisition price → view portfolio
4. Set price alert → trigger → view notification
5. Build deck → evaluate → view suggestions
6. Import purchases (Nerdz + Liga) → verify cards added
7. Dark mode toggle → verify all pages
8. Mobile viewport → verify responsive layout
9. Offline mode → verify PWA behavior
10. Admin: trigger scan → view results → manage users

### What to look for

- Broken links or dead routes
- Missing i18n keys (untranslated text)
- Inconsistent styling (colors, spacing, typography)
- Missing loading states or error handling
- Accessibility issues (contrast, focus, aria labels)
- Mobile layout breaks
- Dark mode visual issues
- Performance issues (slow renders, unnecessary re-renders)
- Missing empty states
- Confusing UX flows

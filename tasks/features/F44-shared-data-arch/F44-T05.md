# F44-T05 — Refactor market.py Router to Use MarketDataService

**Wave:** 2 (parallel with T04)
**Depends on:** T02 (shared schemas), T03 (MarketDataService)
**Modifies:** `src/api/routers/market.py`

## Objective

Refactor the existing `market.py` router to delegate to
`MarketDataService` instead of calling `Repository` and
`CurrencyConverter` directly. This is the proof-of-concept for the
shared data architecture: verify that the service layer produces
identical API responses.

## Steps

### 1. Replace direct Repository calls

**Before (current `get_movers`):**
```python
@router.get("/movers")
def get_movers(
    repo: Repository = Depends(get_db),
    converter: CurrencyConverter = Depends(get_currency_converter_dep),
):
    gainers_raw, losers_raw = repo.get_movers(days=days, limit=limit)
    # ... manual conversion and MoverEntry construction
```

**After:**
```python
@router.get("/movers")
def get_movers(
    service: MarketDataService = Depends(get_market_data_service),
):
    result = service.get_top_movers(period=period, limit=limit, currency=currency)
    # Map MoversResult -> existing MoversResponse for backward compat
```

### 2. Replace `get_stats` similarly

**After:**
```python
@router.get("/stats")
def get_stats(
    service: MarketDataService = Depends(get_market_data_service),
):
    summary = service.get_market_summary(currency=currency)
    # Map MarketSummary -> existing MarketStats for backward compat
```

### 3. Preserve Backward Compatibility

The existing response schemas (`MoversResponse`, `MarketStats`,
`MoverEntry`) remain in `src/api/schemas/market.py`. The refactored
router maps from the new shared types to the old response types.

This ensures:
- Frontend code does not need changes.
- Existing tests validate the same response shape.
- The transition is invisible to API consumers.

Later, when consumer features are built, they can use the shared
schemas directly.

### 4. Temporary Dependency Shim

Until T06 wires the proper singleton, use a temporary inline
dependency in the router:

```python
def _get_service():
    """Temporary: will be replaced by get_market_data_service in T06."""
    db_url = os.environ.get("TCG_DATABASE_URL", "sqlite:///tcg_market.db")
    repo = Repository(db_url=db_url)
    converter = CurrencyConverter(repo)
    return MarketDataService(repo, converter)
```

T06 replaces this with the proper singleton dependency.

### 5. Remove Direct Imports

After refactoring, `market.py` should no longer import:
- `Repository` (access via service)
- `CurrencyConverter` (access via service)
- `get_db`, `get_currency_converter_dep` (replaced by service dep)

It should import:
- `MarketDataService` (from T03)
- `get_market_data_service` (from deps, or temp shim)
- Existing response schemas (for backward compat mapping)

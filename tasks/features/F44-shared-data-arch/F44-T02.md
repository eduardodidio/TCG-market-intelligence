# F44-T02 — Shared API Schemas

**Wave:** 1 (parallel with T03)
**Depends on:** none
**Creates:** `src/api/schemas/market_data.py`

## Objective

Define shared Pydantic response schemas for market data that multiple
routers and future features can import. This eliminates the current
pattern where each router defines its own "card with price" shape.

## Steps

### 1. Create `src/api/schemas/market_data.py`

```python
from __future__ import annotations

from datetime import date, datetime
from decimal import Decimal

from pydantic import BaseModel


class CardPriceInfo(BaseModel):
    """Price info that can be embedded in any card representation."""
    card_id: int
    latest_price: Decimal | None = None
    price_date: date | None = None
    currency: str = "BRL"


class MarketCardSummary(BaseModel):
    """Card summary with market data -- shared base for consumer features."""
    card_id: int
    name_en: str
    name_pt: str | None = None
    set_code: str | None = None
    collector_number: str | None = None
    image_url: str | None = None
    price: CardPriceInfo | None = None


class MoverInfo(BaseModel):
    """Price movement data for a card over a period."""
    card_id: int
    name_en: str
    name_pt: str | None = None
    set_code: str | None = None
    price_start: Decimal | None = None
    price_end: Decimal | None = None
    change_pct: Decimal | None = None
    currency: str = "BRL"


class MarketSummary(BaseModel):
    """Pre-computed daily market summary."""
    total_cards: int
    total_observations: int
    avg_price: Decimal | None = None
    date_range_start: date | None = None
    date_range_end: date | None = None
    currency: str = "BRL"
    computed_at: datetime | None = None


class MoversResult(BaseModel):
    """Top movers response."""
    gainers: list[MoverInfo] = []
    losers: list[MoverInfo] = []
    period: str = "30d"
    currency: str = "BRL"
    computed_at: datetime | None = None
```

### 2. Design Notes

- `CardPriceInfo` is intentionally minimal. It carries the price +
  currency + date. Consumer features can embed it or use it as-is.
- `MarketCardSummary` is the "standard card shape" that landing pages,
  trending lists, deck views, and ban engine results can all use.
- `MoverInfo` replaces `MoverEntry` from `src/api/schemas/market.py`.
  The old schema remains for backward compatibility during the
  transition (T05 will switch market.py to use `MoverInfo`).
- `computed_at` on `MarketSummary` and `MoversResult` communicates
  cache freshness to the frontend.
- All price fields use `Decimal` (Pydantic v2 serializes as string
  by default; consistent with existing schemas).

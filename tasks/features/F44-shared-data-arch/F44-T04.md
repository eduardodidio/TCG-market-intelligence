# F44-T04 — Scan Completion Hook + Wiring

**Wave:** 2 (parallel with T05)
**Depends on:** T01 (AggregateCache), T03 (MarketDataService)
**Creates:** `src/services/scan_hooks.py`
**Modifies:** `src/collectors/scan.py`

## Objective

Add an event-driven mechanism so that scan completion automatically
invalidates stale cached aggregates. The scan orchestrator calls a
hook after finishing; the hook tells MarketDataService to drop affected
cache entries.

## Steps

### 1. Create `src/services/scan_hooks.py`

```python
from __future__ import annotations

from collections.abc import Callable
from typing import Any

import structlog

from src.domain.models import ScanRun

log = structlog.get_logger()

# Type alias for hook functions
ScanHook = Callable[[ScanRun, list[str]], None]


class ScanHookRegistry:
    """Registry of callbacks invoked after a scan completes.

    Each hook receives the ScanRun and a list of external_ids that
    were processed.
    """

    def __init__(self) -> None:
        self._hooks: list[ScanHook] = []

    def register(self, hook: ScanHook) -> None:
        """Register a callback."""
        self._hooks.append(hook)

    def notify(self, scan_run: ScanRun, external_ids: list[str]) -> None:
        """Invoke all registered hooks. Errors are logged, not raised."""
        for hook in self._hooks:
            try:
                hook(scan_run, external_ids)
            except Exception:
                log.exception("scan_hook_error", hook=hook.__name__)


# Module-level default registry (singleton pattern)
default_registry = ScanHookRegistry()
```

### 2. Add cache-invalidation hook function

In the same file, add a factory:

```python
def make_cache_invalidation_hook(
    service: "MarketDataService",
) -> ScanHook:
    """Create a hook that invalidates cached data for scanned cards."""

    def _hook(scan_run: ScanRun, external_ids: list[str]) -> None:
        if not external_ids:
            return
        # Resolve external_ids -> card_ids via the service's repo
        card_ids = service._repo.resolve_external_ids_to_card_ids(external_ids)
        if card_ids:
            service.invalidate_cards(card_ids)
            log.info(
                "cache_invalidated_after_scan",
                scan_id=scan_run.id,
                cards_invalidated=len(card_ids),
            )

    return _hook
```

### 3. Add `resolve_external_ids_to_card_ids()` to Repository

Add a new method to `src/database/repository.py`:

```python
def resolve_external_ids_to_card_ids(self, external_ids: list[str]) -> list[int]:
    """Map source card external_ids to canonical card_ids."""
    with Session(self.engine) as session:
        rows = session.execute(
            select(SourceCardRow.card_id)
            .where(
                SourceCardRow.external_id.in_(external_ids),
                SourceCardRow.card_id.isnot(None),
            )
            .distinct()
        ).scalars().all()
        return list(rows)
```

### 4. Modify `run_scan()` in `src/collectors/scan.py`

Add an optional `on_complete` callback parameter:

```python
async def run_scan(
    db_url: str = "sqlite:///tcg_market.db",
    scan_filter: ScanFilter | None = None,
    dry_run: bool = False,
    delay: float = 1.0,
    concurrency: int = 3,
    run_id: int | None = None,
    on_complete: Callable[[ScanRun, list[str]], None] | None = None,

```

At the end of a successful scan (after updating the scan run row),
collect the list of external_ids that were processed and call:

```python
if on_complete is not None:
    on_complete(scan_run, processed_external_ids)
```

Track `processed_external_ids` by appending to a list inside
`process_entry()` when `jsonld_price` is successfully fetched.

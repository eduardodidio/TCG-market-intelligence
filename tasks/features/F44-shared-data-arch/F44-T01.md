# F44-T01 — AggregateCache: TTL-Based In-Memory Cache

**Wave:** 0 (no dependencies)
**Creates:** `src/services/aggregate_cache.py`

## Objective

Build a generic, thread-safe, TTL-based in-memory cache that the
MarketDataService will use to store pre-computed aggregates (market
summary, top movers, latest price maps). No external dependencies.

## Steps

### 1. Create `src/services/aggregate_cache.py`

```python
class CacheEntry:
    """A cached value with expiry metadata."""
    value: Any
    computed_at: datetime
    ttl_seconds: int
    tags: frozenset[str]  # for tag-based invalidation

class AggregateCache:
    """Thread-safe in-memory cache with TTL and tag-based invalidation."""

    def __init__(self, default_ttl: int = 900):
        ...

    def get(self, key: str) -> Any | None:
        """Return cached value if present and not expired, else None."""

    def set(
        self,
        key: str,
        value: Any,
        ttl: int | None = None,
        tags: set[str] | None = None,
    ) -> None:
        """Store a value with optional custom TTL and tags."""

    def invalidate(self, key: str) -> None:
        """Remove a specific key."""

    def invalidate_by_tags(self, tags: set[str]) -> int:
        """Remove all entries tagged with any of the given tags.
        Returns count of entries removed."""

    def clear(self) -> None:
        """Remove all entries."""

    def stats(self) -> dict:
        """Return cache statistics: size, hits, misses, evictions."""
```

### 2. Implementation Details

- Use `threading.Lock` to protect `_store: dict[str, CacheEntry]`.
- `get()` checks expiry: if `now - computed_at > ttl_seconds`, delete
  and return None (lazy eviction). Increment hit/miss counters.
- `set()` overwrites existing entries. Tags are stored as
  `frozenset[str]` for hashability.
- `invalidate_by_tags()` iterates all entries and removes those whose
  tags intersect with the provided set. This is O(n) but the cache
  will hold < 100 entries, so acceptable.
- Tag convention for card-specific data:
  `tags={"card:123", "card:456"}`. For global data:
  `tags={"market_summary"}`, `tags={"movers:7d"}`.
- `stats()` returns `{"size": int, "hits": int, "misses": int}`.

### 3. TTL Constants

Define module-level constants:

```python
TTL_MARKET_SUMMARY = 3600    # 1 hour
TTL_TOP_MOVERS = 1800        # 30 minutes
TTL_LATEST_PRICES = 900      # 15 minutes

```

## Acceptance Criteria

- [ ] `AggregateCache` is thread-safe (uses `threading.Lock`)
- [ ] `get()` returns None for expired entries (lazy eviction)
- [ ] `set()` stores values with TTL and optional tags
- [ ] `invalidate_by_tags()` removes matching entries
- [ ] `clear()` removes all entries
- [ ] `stats()` returns size, hits, misses
- [ ] No external dependencies (stdlib only)
- [ ] No database imports

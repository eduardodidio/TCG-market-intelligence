# F44-T06 — FastAPI Dependency + Singleton Lifecycle

**Wave:** 3
**Depends on:** T03 (MarketDataService), T04 (scan hooks), T05 (market router)
**Modifies:** `src/api/deps.py`, `src/api/app.py` (or app factory)

## Objective

Wire the MarketDataService as a proper FastAPI singleton so that all
requests share one instance (preserving the AggregateCache and
CurrencyConverter rate cache across requests). Register the scan
completion hook at app startup.

## Steps

### 1. Add `get_market_data_service()` to `src/api/deps.py`

```python
from functools import lru_cache

from src.services.aggregate_cache import AggregateCache
from src.services.market_data import MarketDataService


@lru_cache(maxsize=1)
def _create_market_data_service() -> MarketDataService:
    """Create a singleton MarketDataService."""
    db_url = os.environ.get("TCG_DATABASE_URL", "sqlite:///tcg_market.db")
    repo = Repository(db_url=db_url)
    converter = CurrencyConverter(repo)
    cache = AggregateCache()
    return MarketDataService(repo, converter, cache)


def get_market_data_service() -> MarketDataService:
    """FastAPI dependency for MarketDataService."""
    return _create_market_data_service()
```

### 2. Register scan hook at app startup

In the app factory (`src/api/app.py` or wherever `create_app()` lives),
add a startup event or lifespan handler:

```python
from contextlib import asynccontextmanager

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup: register scan completion hook
    from src.api.deps import _create_market_data_service
    from src.services.scan_hooks import default_registry, make_cache_invalidation_hook

    service = _create_market_data_service()
    hook = make_cache_invalidation_hook(service)
    default_registry.register(hook)

    yield

    # Shutdown: clear cache
    service._cache.clear()
```

If the app already uses a lifespan context manager, add the hook
registration to the existing startup section.

### 3. Wire scan trigger to use the registry

In `src/api/routers/scans.py`, update the `_run()` function inside
`trigger_scan()` to pass the registry's `notify` as `on_complete`:

```python
from src.services.scan_hooks import default_registry

def _run() -> None:
    result = asyncio.run(
        run_scan(
            db_url=db_url,
            scan_filter=scan_filter,
            dry_run=request.dry_run,
            run_id=scan_id,
            on_complete=default_registry.notify,
        )
    )
```

### 4. Remove temporary shim from market.py

Replace the temporary `_get_service()` function added in T05 with
the proper `get_market_data_service` dependency:

```python
from src.api.deps import get_market_data_service
```

### 5. Verify singleton behavior

The `@lru_cache(maxsize=1)` ensures one instance. Verify that:
- Cache hits accumulate across requests.
- CurrencyConverter rate cache persists across requests.
- The service instance is the same object for all endpoints.

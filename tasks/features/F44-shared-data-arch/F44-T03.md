# F44-T03 — MarketDataService Facade

**Wave:** 1 (parallel with T02)
**Depends on:** T01 (AggregateCache)
**Creates:** `src/services/market_data.py`

## Objective

Create the central `MarketDataService` class that wraps Repository,
CurrencyConverter, and AggregateCache into a single facade. All
consumer features will eventually use this service instead of calling
Repository directly.

## Steps

### 1. Create `src/services/market_data.py`

```python
class MarketDataService:
    """Unified facade for all market data access.

    Combines Repository (data), CurrencyConverter (currency), and
    AggregateCache (performance) into a single entry point.
    """

    def __init__(
        self,
        repo: Repository,
        converter: CurrencyConverter,
        cache: AggregateCache | None = None,
    ):
        self._repo = repo
        self._converter = converter
        self._cache = cache or AggregateCache()
```

### 2. Implement Core Methods

#### `get_latest_price(card_id, currency) -> CardPriceInfo | None`

1. Check cache (key: `f"latest_price:{card_id}"`).
2. If miss: call `repo.get_latest_prices_batch([card_id])`.
3. Convert price via `converter.convert()`.
4. Cache the raw (BRL) result with tag `{"card:{card_id}"}` and
   TTL `TTL_LATEST_PRICES`.
5. Return `CardPriceInfo`.

#### `get_cards_with_prices(card_ids, currency) -> dict[int, CardPriceInfo]`

1. Batch version of `get_latest_price`.
2. Split into cache hits and misses.
3. For misses: call `repo.get_latest_prices_batch(miss_ids)`.
4. Cache each result individually.
5. Apply currency conversion to all results.
6. Return dict keyed by card_id.

#### `get_top_movers(period, limit, currency) -> MoversResult`

1. Check cache (key: `f"movers:{period}:{limit}"`).
2. If miss: call `repo.get_movers(days, limit)`.
3. Build `MoverInfo` list with currency conversion.
4. Cache with tags `{"movers:{period}"}` and TTL `TTL_TOP_MOVERS`.
5. Return `MoversResult` with `computed_at`.

#### `get_market_summary(currency) -> MarketSummary`

1. Check cache (key: `"market_summary"`).
2. If miss: call `repo.get_market_stats()`.
3. Convert avg_price.
4. Cache with tag `{"market_summary"}` and TTL `TTL_MARKET_SUMMARY`.
5. Return `MarketSummary` with `computed_at`.

#### `invalidate_cards(card_ids: list[int]) -> None`

1. Build tag set: `{f"card:{cid}" for cid in card_ids}`.
2. Add `"market_summary"` and all `"movers:*"` tags.
3. Call `self._cache.invalidate_by_tags(tags)`.

### 3. Period Map

Define `PERIOD_MAP` as a class-level constant (reuse the same mapping
from `cards.py`):

```python
PERIOD_MAP = {"24h": 1, "7d": 7, "30d": 30, "90d": 90, "180d": 180, "1y": 365, "3y": 1095}
```

This centralizes the period -> days mapping that is currently duplicated
between `cards.py` and `market.py`.

### 4. Design Decisions

- The service does NOT own the Repository or CurrencyConverter lifecycle.
  Both are injected.
- Currency conversion happens at the service boundary (callers get
  converted values). The cache stores BRL values to avoid cache
  fragmentation by currency.
- The cache is optional (defaults to a new instance). For testing,
  pass `AggregateCache(default_ttl=0)` to disable caching.
- Methods return the shared schemas from T02 (`CardPriceInfo`,
  `MoverInfo`, etc.), not raw tuples or dicts.

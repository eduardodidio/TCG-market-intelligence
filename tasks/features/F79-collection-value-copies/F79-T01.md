# F79-T01: Frontend — Unit Price x Qty = Line Total

**Status:** planned
**Wave:** 0

## User Story
As a collector, when I have multiple copies of a card (quantity > 1), I want to see the unit price, the multiplier, and the total line value (unit x qty), so I understand exactly how each card contributes to my collection's total value.

## Dev Notes

### Current State
- `CollectionCardTile` shows price but doesn't multiply by quantity
- `CollectionCardDetail` shows quantity and price separately
- The API already returns `quantity` and `latest_price` per card
- `get_collection_total_value` in repo already does `median_price * quantity`

### Files to Modify
- `frontend/src/components/CollectionCardTile.tsx` — when qty > 1, show: `R$ X x N = R$ Y` below the unit price
- `frontend/src/pages/CollectionCardDetail.tsx` — show line total when qty > 1
- `frontend/src/pages/MyCollection.tsx` — ensure summary total_value reflects qty-weighted sum (already does via API)

### Display Pattern
```
R$ 12,50          (qty=1, show as-is)
R$ 12,50 x 3 = R$ 37,50   (qty>1, show breakdown)
```

### Approach
1. Compute `lineTotal = price * quantity` client-side (price already available)
2. Only show the `x N = total` suffix when `quantity > 1`
3. Use CurrencyIndicator for all formatted values
4. Add i18n key for the multiplication pattern

## Testing
- Unit test: CollectionCardTile renders "x N = total" when qty > 1
- Unit test: CollectionCardTile does NOT show multiplier when qty = 1
- Unit test: correct arithmetic (handles decimals)
- Unit test: CurrencyIndicator used for both unit and total

- **Status:** done

## User Story

As a collector, I want to set the paid price on each card right in my
collection grid and see the valuation panel update, so that tracking my
investment is quick.

## Objective

Mount `PaidPriceQuickEdit` in `CollectionCardTile`, update local state and refresh `PortfolioDashboard` after save.

## Implementation details

1. `CollectionCardTile` new optional props `onPaidPriceSaved?: (entryId: number, price: number | null) => void; showPaidPrice?: boolean`.
   Render under the price row: `{showPaidPrice && onPaidPriceSaved && <PaidPriceQuickEdit ... compact={compact} />}`.
2. Parent: `const [portfolioRefreshKey, setPortfolioRefreshKey] = useState(0);`
   `handlePaidPriceSaved = useCallback((id, price) => { setCards(prev => prev.map(c => c.id === id ? { ...c, acquisition_price: price } : c)); setPortfolioRefreshKey(k => k + 1); }, [])`.
3. Pass `showPaidPrice={!selectionMode}` and `onPaidPriceSaved={handlePaidPriceSaved}`; `<PortfolioDashboard refreshKey={portfolioRefreshKey} />`.

## Test scenarios

- Grid with 2 cards (one with `acquisition_price: 10`, one null) → both editors rendered with right state.
- Save on card 2 → `patchCollectionEntry` called; tile shows new value; `fetchPortfolioSummary` called again (count +1).
- Clear on card 1 → tile shows "set paid price".
- Selection mode on → editors hidden.
- Clicking editor does not change route (MemoryRouter location stays `/collection`).
- PortfolioDashboard: changing `refreshKey` refetches; same key does not.

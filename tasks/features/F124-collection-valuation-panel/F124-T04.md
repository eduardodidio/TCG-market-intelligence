## User Story

As a collector, I want the dashboard to show how much I invested, what it is
worth now and how many cards have a paid price, so that I can follow my
collection's appreciation at a glance.

## Objective

Standalone component rendering investment KPIs + progress, or a CTA when no paid prices exist.

## Implementation details

`frontend/src/components/DashboardInvestmentSummary.tsx`:
```tsx
export function DashboardInvestmentSummary({ totalUnique }: { totalUnique: number }) { ... }
```
- root testid `dashboard-investment`; empty testid `dashboard-investment-empty`; error testid `dashboard-investment-error`;
  progress bar testid `dashboard-investment-progress` with `role="progressbar"` `aria-valuenow` (0-100, clamped) `aria-valuemin=0` `aria-valuemax=100`;
  unpriced hint testid `dashboard-investment-unpriced`.
- pct = `totalUnique > 0 ? Math.min(100, Math.round(invested_card_count / totalUnique * 100)) : 0`.
- P&L % shows `—` when `total_pnl_pct == null`.

## Acceptance criteria

- [ ] Loading → 4 skeleton KPIs; success with data → 4 KPIs + progress; `invested_card_count === 0` → CTA linking to `/collection`; API error → inline error, no throw.
- [ ] Positive P&L green, negative red, zero neutral.
- [ ] Unpriced hint only when `unpriced_card_count > 0`.
- [ ] i18n keys in both locales (i18n key-parity test, if present in `frontend/src/i18n/__tests__`, passes).
- [ ] `npm test` + `npm run build` green.

## Test scenarios

- Happy: invested 100, current 150, pnl 50, pct 50, count 5, totalUnique 10 → KPIs formatted, progress `aria-valuenow=50`, green P&L.
- Negative P&L → red class; `total_pnl_pct: null` → "—".
- Empty: count 0 → CTA visible, link href `/collection`, no KPIs.
- Error: `{data: null, errors:[...]}` and rejected promise → error testid, no crash.
- Boundaries: totalUnique 0 → progress 0; count > totalUnique → clamped 100; `unpriced_card_count` undefined → no hint; 3 → hint with count.

# F124-T01: Liga URL helpers + provider page_url capture

- **Type:** backend
- **Depends on:** —
- **Status:** planned

## User Story

As a collector, I want every Liga price fetch to remember the exact page it
came from, so that the "Ver na LigaMagic" link can open that same page.

## Objective

Create a single source of truth for Liga card URLs and make
`LigaMagicProvider.search_card` return the URL of the page actually loaded.

## Implementation details

1. New `src/providers/liga/urls.py` (pure, no Playwright import):
   - `LIGA_BASE_URL = "https://www.ligamagic.com.br"`
   - `build_liga_card_url(card_name: str) -> str` (exact same output as today's `_build_card_url`).
   - `is_valid_liga_card_url(url: str | None) -> bool`: `urlsplit`; scheme `https`;
     netloc in `{"www.ligamagic.com.br", "ligamagic.com.br"}`; `parse_qs(query).get("view") == ["cards/card"]`;
     len ≤ 1000 (column size); returns False for None/empty/garbage.
   - `liga_external_id(card_id: int, is_foil: bool) -> str`.
2. `provider.py`: `_build_card_url = build_liga_card_url` alias (keep the name so
   existing imports/tests keep working); `self._last_page_url: str | None = None` in `__init__`;
   reset to `None` at the start of `_fetch_page` / `_fetch_page_sync`; after a successful goto
   (status OK path, right before returning HTML) set `self._last_page_url = page.url or url`.
3. `_search_card_unlocked`: after `prices = parse_card_prices(...)`, set
   `prices["page_url"] = self._last_page_url if is_valid_liga_card_url(self._last_page_url) else url`.
4. Do NOT touch `src/catalog/seeder.py` (catalog URLs are never served as the link).

## Test scenarios

- Happy: build URL for simple name; name with comma/apostrophe/slash/accents (`"Dain, Dwarven King"`, `"Jötun Grunt"`, `"Fire // Ice"`) is `quote_plus`-encoded; leading/trailing spaces stripped.
- `is_valid_liga_card_url`: valid www host; valid bare host; `http://` rejected; `https://evil.com/?view=cards/card` rejected; `https://www.ligamagic.com.br/?view=cards/search` rejected; `None`, `""`, `"not a url"` rejected; 1001-char URL rejected (boundary 1000 accepted).
- `liga_external_id(42, False) == "liga_42"`, `(42, True) == "liga_42_foil"`, `card_id=0` boundary.
- Provider: `page_url` equals redirected URL when valid; equals requested URL when `_last_page_url` is None or foreign; LigaError path still raises and does not leak previous `_last_page_url` (reset at start).

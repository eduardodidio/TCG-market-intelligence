## User Story

As a collector, I want the paid price I saved to come back in the collection
list and detail, and to be counted correctly in my P&L, so that the valuation
panel reflects my real investment.

## Objective

Return `acquisition_price`/`acquired_at` from list + detail endpoints; make
`portfolio-summary` foil-aware and exclude unpriced entries from P&L.

## Implementation details

1. List + detail constructors: `acquisition_price=float(r.acquisition_price) if r.acquisition_price is not None else None`, `acquired_at=str(r.acquired_at) if r.acquired_at is not None else None`. Guard MagicMock rows in tests by using real values in fixtures.
2. `portfolio_summary`:
   - `foil_ids = {e.card_id for e in entries if e.card_id is not None and is_foil_entry(e.extras)}`;
     fetch foil and non-foil maps the same way `list_collection` does, pick per entry.
   - For each entry with price: `current += price*qty`, `invested_priced += acquisition_price*qty`; else `unpriced += 1`.
   - `total_pnl = current - invested_priced`; `total_pnl_pct = round(total_pnl / invested_priced * 100, 2)` if `invested_priced > 0` else None.
   - `total_invested` stays from `get_portfolio_invested_total`. Early-return branch sets `unpriced_card_count=0`.
3. PATCH: no change needed (explicit `null` already clears) — add a regression test proving it.

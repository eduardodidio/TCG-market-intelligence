# F124-T06: Record fetched Liga URL in all Liga price writers

- **Wave:** 1
- **Type:** backend
- **Depends on:** F124-T01, F124-T02, F124-T03
- **Status:** planned
- **Maps to AC:** AC5

## User Story

As a collector, I want every Liga price update (sweep, scan, refresh, CLI) to
save the page URL it read, so that the link always matches the price I see.

## Objective

After each Liga observation is inserted, upsert `liga_card_urls[external_id] = prices["page_url"]`.

## Implementation details

Prefer a tiny shared helper to avoid 5 copies, e.g. in `src/providers/liga/urls.py` is NOT allowed (pure module, no repo). Put it in `src/collectors/liga_url_recorder.py`:

```python
def record_liga_url(repo, external_id: str, page_url: str | None) -> bool:
    """Persist the Liga page URL for a price external_id. Never raises."""
```
Returns True when stored. Use it in all 5 writers.

## Acceptance criteria

- [ ] All 5 writers call `record_liga_url` right after a successful observation insert (foil writes use the `_foil` key).
- [ ] No URL recorded when no price is found or fetch fails.
- [ ] Recorder exceptions are swallowed + logged; price still stored; sweep result counts unchanged.
- [ ] `pytest tests/collectors tests/api tests/unit tests/providers -q` green; ruff clean.

## Test scenarios

- Recorder: valid URL → upsert called once, returns True; invalid/None URL → not called, False; repo raises → returns False, logs warning, no exception.
- Sweep normal card → upsert(`liga_{id}`, url); foil card → upsert(`liga_{id}_foil`, url); no price → no upsert; provider raises → error counter +1, no upsert.
- Refresh-liga: success → upsert with reloaded card_id (also when card was auto-created); `price is None` branch → no upsert; LigaNotFoundError → no upsert; recorder failure → response still 200 with updated price.
- Cards refresh + scan + CLI: happy path upsert called with correct key.

## User Story

As a collector, I want to type the price I paid directly on a collection card
(and clear it if I made a mistake), so that I don't have to open each card's
detail page to track my investment.

## Objective

Compact inline paid-price editor for grid tiles; fix `AcquisitionPriceInput` so clearing sends `null`.

## Implementation details

- New `frontend/src/components/PaidPriceQuickEdit.tsx` with props from `_brief/01-paid-price.md`.
- Parse with `parseFloat`; accept comma decimal (`"12,50"` → 12.5) since users are BR: `draft.replace(",", ".")`. Input `type="text" inputMode="decimal"` to allow comma (instead of `type="number"`).
- Validation: empty → null (clear); NaN / ≤ 0 / > 99999.99 → `portfolio.invalidPrice`, no request.
- While saving: disable input/buttons. Success: exit edit mode, call `onSaved(entryId, value)`.
- P&L chip: only when both prices non-null, `currency === "BRL"`, paid > 0.

## Test scenarios

- Happy: null price → "set paid price" button → type `12,50` → Enter → PATCH `{acquisition_price: 12.5}` → `onSaved(1, 12.5)`.
- Existing price 10 displays formatted BRL; latest 15 BRL → chip `+50.0%` green; latest 5 → `-50.0%` red.
- Currency USD → no chip.
- Clear: empty + save → PATCH `{acquisition_price: null}`.
- Validation: `0`, `-1`, `abc`, `100000` → error, PATCH not called; `99999.99` and `0.01` accepted (boundaries).
- API failure (`{data:null}` and rejection) → `paid-price-error`, stays in edit mode.
- Escape restores previous value without request.
- Parent Link: click edit/save/cancel/input → parent click spy not called / location unchanged.
- Compact: icon-only button with `title`.
- AcquisitionPriceInput: empty price save → `{acquisition_price: null}`; empty date save → `{acquired_at: null}`.

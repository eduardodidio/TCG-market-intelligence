# F124-T07: Serve stored Liga URL (collection detail, card detail, web search)

- **Wave:** 2
- **Type:** backend + frontend
- **Depends on:** F124-T01, F124-T02, F124-T06
- **Status:** planned
- **Maps to AC:** AC5

## User Story

As a collector, I want "Ver na LigaMagic" to open exactly the card whose price
is shown, so that I can trust the link like I trust the MYP link.

## Objective

Detail endpoints return the stored fetched URL; fallback uses the same name as the price fetch.

## Implementation details

1. `collection.py` `_build_collection_detail`:
   ```python
   ligamagic_url = None
   if entry.card_id is not None:
       keys = [liga_external_id(entry.card_id, True), liga_external_id(entry.card_id, False)] if is_foil \
              else [liga_external_id(entry.card_id, False)]
       for key in keys:
           stored = repo.get_liga_card_url(key)
           if is_valid_liga_card_url(stored):
               ligamagic_url = stored
               break
   if ligamagic_url is None:
       fetch_name = entry.name_en or entry.name_pt or ""
       ligamagic_url = build_liga_card_url(fetch_name) if fetch_name else None
   ```
   Remove the now-unused canonical-name lookup for Liga (keep `get_card_by_id` only if used elsewhere in the function).
2. `schemas/cards.py` `CardDetail`: `ligamagic_url: str | None = None`. `cards.py`: stored `liga_{card_id}` if valid else `build_liga_card_url(card.name_en)`.
3. `card_search.py`: `liga_url = page_url if is_valid_liga_card_url(page_url := prices.get("page_url")) else build_liga_card_url(card_name)`
   (note: current web-search URL has no `&show=1`; switching to the shared builder adds it — acceptable, same card page).
4. Frontend: `types/api.ts` `CardDetail` add `ligamagic_url?: string | null`; `CardDetail.tsx` href =
   `card.ligamagic_url ?? \`https://www.ligamagic.com.br/?view=cards/card&card=${encodeURIComponent(card.name_en)}\``.

## Acceptance criteria

- [ ] Stored invalid/foreign URL is never served.

## Test scenarios

- Stored URL present (non-foil) → exact URL.
- Foil entry: `_foil` stored → foil URL; only non-foil stored → non-foil URL; none → name fallback.
- Stored value `"https://evil.com/?view=cards/card"` → fallback.
- Drifted entry name vs CardRow name → fallback uses entry name.
- `entry.card_id is None` → name fallback, repo URL lookup not called.
- No names at all → `ligamagic_url is None`.
- Special chars encoded (`"Dain, Dwarven King"` → `Dain%2C+Dwarven+King`).
- Card detail: stored → stored; none → name URL. Card search: valid `page_url` used; missing → builder.
- Frontend: link uses `ligamagic_url` when present; falls back to encoded name when null/undefined.

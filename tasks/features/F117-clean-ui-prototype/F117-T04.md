# F117-T04: V2 Dashboard Page

**Status:** planned

## User Story

As a user testing the v2 prototype, I want a dashboard that immediately
shows my portfolio value, trending cards, and collection highlights in
a clean, data-rich layout.

## Dev Notes

### 1. Create DashboardV2.tsx

**File:** `frontend/src/pages/DashboardV2.tsx`

Structure:
```
<div class="font-figtree space-y-fluid-lg">
  +-- Hero Section
  |   +-- Portfolio value (large, bold, animated counter)
  |   +-- Change since yesterday (green/red, with arrow)
  |   +-- Mini sparkline (30-day portfolio value)
  |
  +-- Quick Stats Row (3-4 cards, horizontal scroll on mobile)
  |   +-- Total Cards
  |   +-- Sets Owned
  |   +-- Price Alerts Active
  |   +-- Credits Remaining
  |
  +-- Two-Column Layout (desktop)
  |   +-- Left: Top Gainers (cards going up in price)
  |   |   +-- Card image mini + name + % change (green)
  |   |   +-- Link to collection detail
  |   |
  |   +-- Right: Top Losers (cards going down)
  |       +-- Card image mini + name + % change (red)
  |       +-- Link to collection detail
  |
  +-- Recent Activity
  |   +-- Last scan results
  |   +-- Recent price alerts triggered
  |
  +-- Set Completion Preview (top 3 sets, progress bars)
</div>
```

### 2. API endpoints used

- `GET /api/v1/collection/summary` — total cards, value, sets
- `GET /api/v1/collection/movers` — top gainers/losers
- `GET /api/v1/collection/portfolio-summary` — portfolio value + history
- `GET /api/v1/collection/set-completion` — set progress
- `GET /api/v1/alerts/notifications` — recent alerts
- `GET /api/v1/market/stats` — market overview

### 3. Key design elements

**Portfolio Hero:**
- Full-width card with gradient background (v2-accent-soft)
- Large number: "R$ 12,450.00" with animated count-up
- Sparkline: 30-day trend using Recharts AreaChart (accent color fill)

**Stats Cards:**
- v2-card surface with icon + number + label
- Hover: v2-glow shadow
- Horizontal scroll on mobile

**Movers Section:**
- Card mini-image (48px) + name + price + % change
- Green accent for gainers, red for losers
- Max 5 items per column

### 4. Reuse from v1

- `PriceSparkline` — for portfolio trend
- `TrendBadge` — for % change display
- `SetCompletionBar` — for set progress
- `CardImage` — for mini card images
- All hooks: useApi, usePriceTrends, etc.

## Acceptance Criteria

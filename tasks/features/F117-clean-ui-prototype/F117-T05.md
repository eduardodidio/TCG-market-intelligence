# F117-T05: V2 Route Prefix + Navigation Toggle

**Status:** planned
**Wave:** 2 (depends on T01-T04)

## User Story

As a user, I want to access the v2 prototype at `/v2/` URLs while keeping
the current UI at the default routes, so I can compare both versions.

## Dev Notes

### 1. Add /v2 routes in App.tsx

```tsx
// Lazy-load v2 pages
const LayoutV2 = lazy(() => import("./components/LayoutV2"));
const DashboardV2 = lazy(() => import("./pages/DashboardV2"));
const CollectionV2 = lazy(() => import("./pages/CollectionV2"));

// Inside BrowserRouter, add v2 route group:
<Route element={<ProtectedRoute><LayoutV2 /></ProtectedRoute>}>
  <Route path="/v2" element={<DashboardV2 />} />
  <Route path="/v2/collection" element={<CollectionV2 />} />
  {/* More v2 pages added later */}
</Route>
```

### 2. Version toggle in both layouts

Add a small floating button to switch between v1 and v2:

```tsx
// In Layout.tsx (v1), bottom-right corner:
<Link to="/v2" className="fixed bottom-4 right-4 v2-card px-3 py-2 text-sm">
  Try New UI
</Link>

// In LayoutV2.tsx, same position:
<Link to="/" className="fixed bottom-4 right-4 v2-card px-3 py-2 text-sm">
  Back to Classic
</Link>
```

### 3. Render deployment

Both v1 and v2 share the same SPA build. No separate deploy needed.
The /v2 routes are just additional React Router entries.

### 4. Pages available in v2 (initial prototype)

| Route | Page | Status |
|-------|------|--------|
| /v2 | DashboardV2 | T04 |
| /v2/collection | CollectionV2 | T03 |

Pages NOT in v2 yet — clicking nav links for them should redirect to v1
equivalents (e.g., `/v2/cards` → `/cards` with a subtle banner "This page
is not yet available in the new UI").

### 5. Feature flag (optional)

Store v2 preference in localStorage:
```typescript
const [preferV2, setPreferV2] = useState(
  localStorage.getItem("tcg_prefer_v2") === "true"
);
```

If user has opted into v2, redirect `/` → `/v2` automatically.

## Acceptance Criteria

1. `/v2` renders DashboardV2 in LayoutV2
2. `/v2/collection` renders CollectionV2 in LayoutV2
3. Floating toggle button visible on both layouts
4. Nav links to unimplemented v2 pages redirect to v1 gracefully
5. Build size increase <50KB (lazy-loaded, code-split)
6. Existing v1 routes completely unchanged

## Testing

- Unit test: /v2/collection route renders CollectionV2
- Unit test: toggle button renders correct link
- Build: verify code splitting (v2 pages in separate chunks)

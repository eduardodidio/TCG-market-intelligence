# F117-T02: Design Tokens + Typography

**Status:** planned
**Wave:** 0 (parallel with T01)

## User Story

As a developer building the v2 UI, I want shared design tokens (colors,
spacing, fonts) so that all v2 pages have a consistent premium look.

## Dev Notes

### 1. Add Figtree font

In `frontend/index.html`:
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Figtree:wght@400;500;600;700&display=swap" rel="stylesheet">
```

### 2. Extend tailwind.config.ts

```typescript
theme: {
  extend: {
    fontFamily: {
      figtree: ['Figtree', 'system-ui', 'sans-serif'],
    },
    colors: {
      v2: {
        bg: '#0a0e1a',
        surface: '#111827',         // cards, panels
        'surface-hover': '#1a2332',
        border: 'rgba(255,255,255,0.06)',
        accent: '#06b6d4',          // cyan-500
        'accent-soft': 'rgba(6,182,212,0.15)',
        muted: '#94a3b8',           // slate-400
      }
    },
    spacing: {
      'fluid-sm': 'clamp(0.5rem, 1.5vw, 1rem)',
      'fluid-md': 'clamp(1rem, 3vw, 2rem)',
      'fluid-lg': 'clamp(2rem, 5vw, 4rem)',
    },
    borderRadius: {
      'v2': '0.75rem',             // slightly more rounded than default
    },
    boxShadow: {
      'v2-card': '0 4px 24px rgba(0,0,0,0.3)',
      'v2-glow': '0 0 20px rgba(6,182,212,0.15)',
    },
  }
}
```

### 3. V2 utility classes in index.css

```css
/* V2 card surface */
.v2-card {
  @apply bg-v2-surface border border-v2-border rounded-v2 shadow-v2-card;
  @apply transition-all duration-200;
}
.v2-card:hover {
  @apply bg-v2-surface-hover shadow-v2-glow;
}

/* V2 text hierarchy */
.v2-heading {
  @apply font-figtree font-semibold text-white tracking-tight;
}
.v2-body {
  @apply font-figtree text-v2-muted;
}
.v2-accent {
  @apply text-v2-accent font-medium;
}
```

### 4. Color palette rationale

| Token | Hex | Usage |
|-------|-----|-------|
| bg | #0a0e1a | Page background (near-black with blue tint) |
| surface | #111827 | Cards, panels, modals |
| surface-hover | #1a2332 | Hover state for surfaces |
| border | rgba(255,255,255,0.06) | Subtle dividers |
| accent | #06b6d4 | CTAs, links, highlights (cyan) |
| muted | #94a3b8 | Secondary text, labels |

## Acceptance Criteria

1. Figtree font loads and renders correctly
2. v2- color tokens available in Tailwind
3. v2-card, v2-heading, v2-body utility classes work
4. Fluid spacing tokens (fluid-sm/md/lg) responsive
5. No impact on existing v1 styles (additive only)

## Testing

- Build: `npm run build` succeeds with new tokens
- Visual: create a test component using v2 tokens — renders correctly
- Performance: Figtree font load <100ms (preconnect)

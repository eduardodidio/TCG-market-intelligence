# F117-T01: V2 Layout Shell (DeckCheck-inspired)

**Status:** planned
**Wave:** 0

## User Story

As a user, I want a clean, premium dark-themed layout with frosted-glass
navigation, generous spacing, and card-centric design inspired by deckcheck.co.

## Dev Notes

### 1. Create LayoutV2.tsx

**File:** `frontend/src/components/LayoutV2.tsx`

Structure:
```
<LayoutV2>
  +-- TopBar (frosted glass, h-16)
  |   +-- Logo ("TEDHC Market" — gradient text)
  |   +-- NavLinks (horizontal, compact)
  |   +-- UserMenu (avatar + dropdown)
  |   +-- ThemeToggle
  |
  +-- Main Content (centered, max-w-7xl, fluid padding)
  |   +-- <Outlet />
  |
  +-- (optional) Bottom Nav (mobile only, 5 icons)
```

### 2. TopBar design

```css
.topbar-v2 {
  position: sticky;
  top: 0;
  z-index: 50;
  backdrop-filter: blur(12px);
  background: rgba(15, 23, 42, 0.8); /* slate-900 with opacity */
  border-bottom: 1px solid rgba(255, 255, 255, 0.06);
}
```

Navigation items: Dashboard, Collection, Explore, Catalog, Alerts
(reduced from current 16+ items — only core pages in primary nav).

### 3. Main content area

```css
.main-v2 {
  max-width: 1400px;
  margin: 0 auto;
  padding: clamp(1rem, 3vw, 3rem);
  min-height: calc(100vh - 4rem);
}
```

### 4. Key differences from current Layout

| Aspect | Current (v1) | New (v2) |
|--------|-------------|----------|
| Nav | Fixed sidebar 256px | Sticky topbar, horizontal links |
| Background | Flat slate-900 | Layered gradient (slate-950 base + radial accents) |
| Typography | System fonts | Figtree (Google Fonts) |
| Spacing | Tight padding | Generous, fluid clamp() |
| Nav items | 16+ links in sidebar | 5-6 in topbar, rest in dropdown |
| Content width | Full width minus sidebar | Centered max-w-7xl |
| Mobile | Hamburger → full sidebar | Bottom tab bar |

### 5. Background gradients (deckcheck style)

```css
body.v2-theme {
  background: #0a0e1a; /* near-black base */
  background-image:
    radial-gradient(ellipse at 20% 50%, rgba(99, 102, 241, 0.08) 0%, transparent 50%),
    radial-gradient(ellipse at 80% 20%, rgba(6, 182, 212, 0.06) 0%, transparent 50%);
}
```

## Acceptance Criteria

1. LayoutV2 renders topbar + centered content area
2. Topbar has frosted glass effect (backdrop-filter: blur)
3. 5-6 core nav items in topbar, responsive
4. Mobile: bottom tab bar replaces topbar nav
5. Background: layered gradients (indigo + cyan accents)
6. Content area: max-w-7xl, fluid padding

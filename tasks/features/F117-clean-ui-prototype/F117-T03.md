# F117-T03: V2 Collection Page

**Status:** planned
**Wave:** 1 (depends on T01 layout + T02 design tokens)

## User Story

As a user testing the v2 prototype, I want to see my collection in the
new clean layout with large card images, minimal chrome, and smooth
filtering — like browsing cards on deckcheck.co.

## Dev Notes

### 1. Create CollectionV2.tsx

**File:** `frontend/src/pages/CollectionV2.tsx`

Structure:
```
<div class="font-figtree">
  +-- Page Header
  |   +-- "My Collection" (v2-heading, large)
  |   +-- Stats bar: {total} cards | R$ {value} total | {sets} sets
  |
  +-- Filter Bar (sticky, frosted glass)
  |   +-- Search input (large, rounded, accent border on focus)
  |   +-- Sort dropdown (price high→low default)
  |   +-- Filter chips (set, rarity, color)
  |   +-- Grid size toggle
  |
  +-- Card Grid (responsive, gap-fluid-md)
  |   +-- Card3DTilt > CardImage (large, hero-sized)
  |   +-- Card name (below image, clean)
  |   +-- Price + trend (small, accent color)
  |
  +-- Pagination / Infinite scroll
</div>
```

### 2. Key design differences from v1

| Aspect | v1 (MyCollection) | v2 (CollectionV2) |
|--------|-------------------|-------------------|
| Card size | Small grid tiles | Large hero cards (min 200px) |
| Info density | Name + set + price + sparkline | Just name + price (hover for more) |
| Filters | Inline dropdowns | Sticky bar with search prominent |
| Background | Flat slate-800 cards | v2-card surfaces with glow on hover |
| Typography | Default sans | Figtree, larger sizes |
| Spacing | Compact 4px gaps | Fluid 16-32px gaps |

### 3. Reuse from v1

- `useApi` hook — same API calls
- `CardImage` component — for image loading
- `Card3DTilt` (F116) — 3D hover effect
- `SortSelect` component — sort options
- `FilterChips` component — filter UI
- All backend endpoints unchanged

### 4. API calls

Same as MyCollection.tsx:
- `GET /api/v1/collection` (with sort_by, sort_dir, search, filters)
- `GET /api/v1/collection/summary` (for stats)

### 5. Card hover detail

On hover (desktop), show a floating detail panel:
- Enlarged card image (3D tilt)
- Full name + set + collector number
- Price history sparkline
- Liga/MYP links
- "View Details" button

This replaces the current CardHoverPreview with a richer panel.

## Acceptance Criteria

1. CollectionV2 page renders in LayoutV2 shell
2. Cards display as large hero images with minimal text
3. Filter bar is sticky with frosted glass background
4. Default sort: price descending
5. Card hover shows detail panel (desktop)
6. Responsive: 1 col mobile, 2 col tablet, 3-4 col desktop
7. Uses v2 design tokens throughout

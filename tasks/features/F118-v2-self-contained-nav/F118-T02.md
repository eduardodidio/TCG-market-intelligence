# F118-T02: Register All V2 Routes + Wire Provider + Expand LayoutV2 Nav

**Status:** planned
**Wave:** 1 (depends on T01)

## User Story

As a user browsing the V2 UI, I want all pages available under `/v2/*`
routes so I never get redirected to the classic layout when navigating.

### 2. App.tsx — Wire RoutePrefixProvider

Wrap the classic Layout route group:
```tsx
<Route element={
  <ProtectedRoute>
    <RoutePrefixProvider prefix="">
      <Layout />
    </RoutePrefixProvider>
  </ProtectedRoute>
}>
```

Wrap the V2 route group:
```tsx
<Route element={
  <ProtectedRoute>
    <RoutePrefixProvider prefix="/v2">
      <Suspense ...><LayoutV2 /></Suspense>
    </RoutePrefixProvider>
  </ProtectedRoute>
}>
```

### 3. LayoutV2.tsx — Expand NAV_ITEMS to full navigation

Replace the current 5-item nav with full sections matching classic Layout:

**Primary nav:**
- Dashboard → /v2

- Ban History → /v2/banlist/history

Use auth/admin filtering logic similar to classic Layout.

### 4. Layout.tsx — Wire RoutePrefixProvider

Wrap the Layout's returned JSX with `<RoutePrefixProvider prefix="">`.
This ensures pages rendered in classic layout get prefix="" from the hook.

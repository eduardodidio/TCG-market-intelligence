# F118-T04: Tests for V2 Self-Contained Navigation

**Status:** planned
**Wave:** 2 (depends on T02, T03)

## User Story

As a developer, I want comprehensive tests verifying that the V2 layout
is fully self-contained — no navigation action escapes to the classic layout.

## Dev Notes

### 1. RoutePrefixContext tests

File: `frontend/src/contexts/__tests__/RoutePrefixContext.test.tsx`

- Default value is ""
- Provider with "/v2" returns "/v2"
- Provider with "" returns ""
- Nested providers use innermost value

### 2. V2 Route rendering tests

File: `frontend/src/pages/__tests__/V2FullRoutes.test.tsx`

Test that each `/v2/*` route renders the correct page component inside
LayoutV2 (not classic Layout):

- `/v2` → DashboardV2 + LayoutV2 topbar visible
- `/v2/collection` → CollectionV2 + LayoutV2
- `/v2/cards` → Cards + LayoutV2
- `/v2/catalog` → CatalogPage + LayoutV2
- `/v2/alerts` → AlertsPage + LayoutV2
- `/v2/settings` → Settings + LayoutV2
- `/v2/cards/:id` → CardDetail + LayoutV2
- `/v2/collection/:id` → CollectionCardDetail + LayoutV2
- `/v2/admin` → AdminPanel + LayoutV2 (admin user)
- Sample of beta routes: `/v2/market`, `/v2/decks`, `/v2/marketplace`

### 3. Navigation self-containment tests

File: `frontend/src/components/__tests__/V2NavContainment.test.tsx`

- All LayoutV2 nav links have href starting with "/v2"
- No LayoutV2 nav link points to a classic route (no href without /v2 prefix)
- "Back to Classic" link points to "/" (only allowed exit)
- Mobile bottom tabs all point to /v2/* routes

### 4. Page link prefix tests

Spot-check critical pages render prefixed links when inside V2 context:

- CollectionV2: card links start with "/v2/collection/"
- CardDetail: breadcrumb back link starts with "/v2/cards"
- CatalogPage: card links start with "/v2/cards/"
- Dashboard: trending link starts with "/v2/market"

### Files

## Acceptance Criteria

1. All RoutePrefixContext unit tests pass
2. All V2 route rendering tests pass (pages load in V2 layout)
3. Nav containment tests verify no escape links exist
4. Page link prefix tests verify critical pages stay in V2
5. All existing tests still pass (no regression)

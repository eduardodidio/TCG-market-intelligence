# F118-T01: RoutePrefixContext + useRoutePrefix Hook

**Status:** planned
**Wave:** 0

## User Story

As a developer, I need a React context that provides the current route
prefix ("" for classic, "/v2" for V2 layout) so that page components can
build internal links that stay within the active layout.

## Dev Notes

### 1. Create `frontend/src/contexts/RoutePrefixContext.tsx`

```tsx
import { createContext, useContext, type ReactNode } from "react";

const RoutePrefixContext = createContext<string>("");

export function RoutePrefixProvider({
  prefix,
  children,
}: {
  prefix: string;
  children: ReactNode;
}) {
  return (
    <RoutePrefixContext.Provider value={prefix}>
      {children}
    </RoutePrefixContext.Provider>
  );
}

export function useRoutePrefix(): string {
  return useContext(RoutePrefixContext);
}
```

### 2. Usage pattern for pages

```tsx
const prefix = useRoutePrefix();
// Classic: prefix = "" → to="/collection/5"
// V2:      prefix = "/v2" → to="/v2/collection/5"
<Link to={`${prefix}/collection/${card.id}`}>...</Link>
```

## Acceptance Criteria

1. `RoutePrefixProvider` exported and accepts `prefix` string prop
2. `useRoutePrefix()` returns empty string by default (no provider = classic)
3. When wrapped in `<RoutePrefixProvider prefix="/v2">`, hook returns "/v2"
4. Zero impact on existing code (new file only)

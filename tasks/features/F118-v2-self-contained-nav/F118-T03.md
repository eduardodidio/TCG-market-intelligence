# F118-T03: Migrate Page Internal Links to useRoutePrefix

**Status:** planned
**Wave:** 1 (depends on T01, parallel with T02)

## User Story

As a user in the V2 layout, when I click a link inside a page (e.g.,
a card in my collection → card detail), I want to stay in the V2 layout
instead of being redirected to the classic UI.

## Dev Notes

### Strategy

Each page that has hardcoded internal `<Link to="...">` or
`navigate("...")` calls needs to:
1. Import `useRoutePrefix` from `contexts/RoutePrefixContext`
2. Call `const prefix = useRoutePrefix();` in the component
3. Prepend `${prefix}` to internal route paths

### Pages to migrate (with their hardcoded links)

| Page | Current link | Updated link |
|------|-------------|--------------|
| CollectionV2.tsx | `/collection/${card.id}` | `${prefix}/collection/${card.id}` |
| CollectionCardDetail.tsx | `/collection` (x2) | `${prefix}/collection` |
| CardDetail.tsx | `/cards` (x2) | `${prefix}/cards` |
| CatalogPage.tsx | `/cards/${card.id}` | `${prefix}/cards/${card.id}` |
| Dashboard.tsx | `/market/trending` | `${prefix}/market/trending` |
| DeckList.tsx | `/decks/${deck.id}` | `${prefix}/decks/${deck.id}` |
| MarketPage.tsx | `/market/trending` | `${prefix}/market/trending` |
| Marketplace.tsx | `/marketplace/my-trades` | `${prefix}/marketplace/my-trades` |
| MyCollection.tsx | `/collection/${card.id}` | `${prefix}/collection/${card.id}` |
| TopDecksPage.tsx | `/decks/${deck.id}` | `${prefix}/decks/${deck.id}` |
| TradeMatchesPage.tsx | `/marketplace`, `/cards/${card.card_id}` | prefixed |
| Trending.tsx | `/market` | `${prefix}/market` |

### Pages NOT migrated (intentional)

- **SharedCollectionPage** — public route, not inside V2 layout
- **Login / ChangePassword** — outside both layouts
- **NotFoundPage** — standalone
- **DashboardV2** — no internal links (only data display)

### Pattern

```tsx
// Before:
import { Link } from "react-router-dom";
// ...
<Link to={`/collection/${card.id}`}>

// After:
import { Link } from "react-router-dom";
import { useRoutePrefix } from "../contexts/RoutePrefixContext";
// ...
const prefix = useRoutePrefix();
<Link to={`${prefix}/collection/${card.id}`}>
```

For `navigate()` calls, same pattern:
```tsx
navigate(`${prefix}/collection`);
```

### Files changed

- 12 page files in `frontend/src/pages/` (see table above)
- No layout or App.tsx changes (those are in T02)

## Acceptance Criteria

1. All 12 pages use `useRoutePrefix()` for internal links
2. In classic layout (prefix=""), behavior is identical to before
3. In V2 layout (prefix="/v2"), all links stay within /v2/*
4. No link goes to an external route outside the current layout
5. SharedCollectionPage and standalone pages unaffected

## Testing

- Unit test: CollectionV2 card links include "/v2" prefix when in V2 context
- Unit test: CardDetail breadcrumb links include prefix
- Unit test: In classic context (prefix=""), links remain unchanged
- Integration test: navigate from /v2/collection → card detail → back stays in V2

# F34-T04 — Frontend: CollectionCardDetail Integration + i18n

**Wave:** 2 (parallel with T03)
**Depends on:** T03 (MetricsPanel component exists)
**Modifies:** `frontend/src/pages/CollectionCardDetail.tsx`,
`frontend/src/i18n/locales/en.json`, `frontend/src/i18n/locales/pt-BR.json`

## Objective

Wire the MetricsPanel into the collection card detail page and add all
necessary i18n translation keys.

## Steps

### 1. Add period state to CollectionCardDetail

The PriceChart component currently manages its own period state
internally. To share the period with MetricsPanel, lift the period state
up to `CollectionCardDetail`:

- Add `const [period, setPeriod] = useState("30d")` to the page.
- Pass `period` and `onPeriodChange={setPeriod}` as props to PriceChart.
- Pass `period` to MetricsPanel.

**Note:** This requires a small change to `PriceChart.tsx` to accept
an external `period` prop and `onPeriodChange` callback. If the period
is provided externally, PriceChart uses it instead of its own state.
Make the prop optional to avoid breaking other usages of PriceChart.

### 2. Integrate MetricsPanel in page layout

Add MetricsPanel below the PriceChart in the right column:

```tsx
{/* Right panel: Price chart + Metrics */}
<div>
    {entry.card_id != null ? (
        <>
            <PriceChart
                cardId={entry.card_id}
                currency={currency}
                period={period}
                onPeriodChange={setPeriod}
            />
            <div className="mt-4">
                <MetricsPanel
                    entryId={entry.id}
                    period={period}
                    currency={currency}
                />
            </div>
        </>
    ) : (
        <div data-testid="no-price-chart" ...>
            ...
        </div>
    )}
</div>
```

### 3. Update PriceChart to accept external period (minor change)

In `frontend/src/components/PriceChart.tsx`:

```typescript
interface PriceChartProps {
    cardId: number;
    currency?: string;
    period?: string;           // NEW: external period control
    onPeriodChange?: (p: string) => void;  // NEW: callback
}
```

If `period` prop is provided, use it instead of internal state. When a
period button is clicked, call `onPeriodChange` if provided, otherwise
update internal state (backward compatible).

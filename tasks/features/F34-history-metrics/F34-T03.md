# F34-T03 — Frontend: MetricsPanel Component + API Client

**Wave:** 2 (parallel with T04)
**Depends on:** T02 (API endpoint exists)
**Creates:** `frontend/src/components/MetricsPanel.tsx`, `frontend/src/api/metrics.ts`

## Objective

Build the MetricsPanel component that displays analytics metrics as a
grid of stat cards, and the API client function to fetch them.

## Steps

### 1. Create API client `frontend/src/api/metrics.ts`

```typescript
export async function fetchCardMetrics(
    entryId: number,
    period: string,
    currency: string
): Promise<CardMetricsResponse> { ... }
```

Uses `apiGet` from `frontend/src/api/client.ts` (auth-aware).
Endpoint: `GET /collection/${entryId}/metrics?period=${period}&currency=${currency}`.

### 2. Add TypeScript types to `frontend/src/types/api.ts`

```typescript
interface MovingAverageEntry {
    period: number;
    value: number;
}

interface PriceExtremes {
    ath_price: number;
    ath_date: string;
    atl_price: number;
    atl_date: string;
}

interface VolatilityData {
    period_days: number;
    std_dev: number;
    coefficient_of_variation: number;
}

interface MomentumData {
    period_days: number;
    rate_of_change: number;
    trend_direction: "up" | "down" | "flat";
}

interface PerformanceScoreData {
    score: number;
    label: "strong" | "moderate" | "weak" | "declining";
    period_days: number;
}

interface PeriodComparisonData {
    current_avg: number;
    previous_avg: number;
    delta: number;
    delta_pct: number;
    period_days: number;
}

interface CardMetricsResponse {
    entry_id: number;
    card_id: number;
    period: string;
    currency: string;
    moving_averages: MovingAverageEntry[];
    extremes: PriceExtremes | null;
    volatility: VolatilityData | null;
    momentum: MomentumData | null;
    performance: PerformanceScoreData | null;
    period_comparison: PeriodComparisonData | null;
    data_points: number;
}
```

### 3. Create `MetricsPanel` component

`frontend/src/components/MetricsPanel.tsx`

Props:
```typescript
interface MetricsPanelProps {
    entryId: number;
    period: string;
    currency: string;
}
```

The component:
1. Calls `fetchCardMetrics(entryId, period, currency)` via `useApi` hook.
2. Renders a responsive grid (2 cols on mobile, 3 cols on lg) of metric
   cards.
3. Shows skeleton loading state (reuse `SkeletonKpi` pattern).
4. Handles null metrics gracefully (hide card or show "N/A").

Metric cards to render:

**Trend Card**:
- Arrow icon: up (green, `text-green-400`), down (red, `text-red-400`),
  flat (gray, `text-slate-400`).
- Rate of change as percentage with sign.
- Period label (e.g., "7d momentum").

**Moving Averages Card**:
- Two values side by side: MA-7 and MA-30 (from `moving_averages` array).
- Formatted as currency.
- If only one MA available, show just that one.

**ATH / ATL Card**:
- All-time high: price + date.
- All-time low: price + date.
- Both formatted as currency with short date (DD/MM/YY).

**Volatility Card**:
- Coefficient of variation as percentage.
- Visual indicator bar: low (<0.1 green), medium (0.1-0.3 amber),
  high (>0.3 red).
- Period label.

**Performance Card**:
- Score displayed large (0-100).
- Label badge: "strong" (green bg), "moderate" (amber bg), "weak"
  (slate bg), "declining" (red bg).

**Period Comparison Card**:
- Current avg vs previous avg.
- Delta with arrow and color.
- "vs previous {period}" label.

### 4. Styling

Use existing Tailwind patterns from the codebase:
- `bg-slate-800 border border-slate-600 rounded-lg p-4` for card containers.
- `text-white` for values, `text-slate-400` for labels.
- Green/red/amber for positive/negative/neutral indicators.
- Consistent with `KpiCard` component on Dashboard.

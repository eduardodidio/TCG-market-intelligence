## Steps

### 1. Add domain dataclasses to `src/domain/models.py`

Add after the existing `CardAnalytics` class:

```python
@dataclass
class PerformanceScore:
    """Composite performance indicator for a price series."""
    score: int  # 0-100
    label: str  # "strong" | "moderate" | "weak" | "declining"
    period_days: int
    price_field: str

@dataclass
class PeriodComparison:
    """Current period vs previous period of equal length."""
    current_avg: Decimal
    previous_avg: Decimal
    delta: Decimal
    delta_pct: Decimal
    period_days: int
    price_field: str
```

### 3. Add `compute_performance_score()` to `src/analytics/indicators.py`

```python
def compute_performance_score(
    prices: list[HistoricalPrice],
    period_days: int = 30,
    price_field: str = "median_price",
) -> PerformanceScore | None:
```

Logic:
1. Extract valid prices for the period window (last N days).
2. If fewer than 3 data points, return None.
3. Compute three sub-scores (each 0-100):
   - **Momentum score**: map rate_of_change from [-50, +50] to [0, 100],
     clamped.
   - **Trend consistency**: count positive daily deltas / total deltas
     * 100. A card that goes up every day scores 100.
   - **ATH proximity**: (current_price / ath_price) * 100. At ATH = 100.
4. Weighted average: momentum 40%, consistency 30%, ATH proximity 30%.
5. Round to int. Label: >= 70 "strong", >= 45 "moderate", >= 25 "weak",
   < 25 "declining".

### 4. Add `compute_period_comparison()` to `src/analytics/indicators.py`

```python
def compute_period_comparison(
    prices: list[HistoricalPrice],
    period_days: int = 30,
    price_field: str = "median_price",
) -> PeriodComparison | None:
```

Logic:
1. Extract valid prices.
2. Determine current period: last `period_days` days of data.
3. Previous period: the `period_days` days immediately before that.
4. If either period has < 1 data point, return None.
5. Compute average price for each period.
6. Delta = current_avg - previous_avg.
7. Delta_pct = (delta / previous_avg) * 100.

### 5. Update `compute_card_analytics()` orchestrator

Add optional `period_days: int | None = None` parameter.

When `period_days` is set:
- Pass it to `compute_volatility()` (already supports `period_days`).
- Pass it to `compute_momentum()`.
- Call `compute_performance_score(prices, period_days)`.
- Call `compute_period_comparison(prices, period_days)`.
- Extremes still computed over the full dataset (not period-filtered).

When `period_days` is None, use existing defaults (30d volatility, 7d
momentum, no performance/comparison).

Update the `CardAnalytics` construction to include the new fields.

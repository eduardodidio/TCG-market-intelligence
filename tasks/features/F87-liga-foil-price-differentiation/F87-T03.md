# F87-T03 — get_latest_prices_batch Foil-Aware Lookup

**Status:** planned
**Wave:** 0 (parallel with T01, T02)
**Estimate:** medium

## User Story

As a collector, when I view my collection, I want foil cards to show
their foil price (not the normal price) so that my portfolio valuation
is accurate.

## Dev Notes

### What to do

1. **Update `get_latest_prices_batch`** (`src/database/repository.py`):
   - Accept a mapping of `entry_id → is_foil` (or a set of foil entry IDs)
   - For foil entries, look up `external_id = f"liga_{card_id}_foil"`
     in addition to the normal external_id
   - Priority: foil-specific observation > normal observation (for foil entries)
   - For non-foil entries, behavior unchanged

   Current logic builds external_id keys like:
   ```python
   f"liga_{card_id}"  # for Liga source cards
   ```

   For foil entries, also check:
   ```python
   f"liga_{card_id}_foil"
   ```

2. **Update callers** that call `get_latest_prices_batch`:
   - Collection list endpoint — pass foil info from extras field
   - Collection detail endpoint — pass foil info
   - Portfolio valuation — pass foil info
   - Deck valuation — cards in decks are typically non-foil (no change)

3. **Ensure manual prices still win** — the SOURCE_PRIORITY should still
   apply. Manual price (priority 0) beats foil Liga price (priority 1).

### Key files

- `src/database/repository.py` — `get_latest_prices_batch()`
- `src/api/routers/collection.py` — callers that pass entry data
- `src/api/schemas/collection.py` — may need `foil_price` vs `normal_price`
  fields if we want to show both

### Design decision

**Option A (recommended):** Single `latest_price` field — foil entries get
foil price, normal entries get normal price. Simpler, matches current UX.

**Option B:** Dual fields (`normal_price` + `foil_price`). More informative
but adds complexity. Defer to a future feature if needed.

→ Go with Option A for now.

## Testing

- Unit: foil entry gets foil price from `liga_{card_id}_foil` external_id
- Unit: non-foil entry gets normal price from `liga_{card_id}` external_id
- Unit: manual price still wins over foil Liga price
- Unit: entry with no foil observation falls back gracefully (shows None)
- Integration: collection list returns correct prices for mixed foil/non-foil
- Integration: portfolio valuation uses foil prices for foil entries

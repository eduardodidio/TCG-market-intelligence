# F87-T04 — Frontend Foil Badge + Foil Price Display

**Status:** done
**Wave:** 1 (depends on T01, T02, T03)
**Estimate:** medium

## User Story

As a collector, I want to see a visual indicator on foil cards and
their correct foil price so that I can distinguish them from normal
cards and trust the displayed valuation.

## Dev Notes

### What to do

1. **FoilBadge component** (`frontend/src/components/FoilBadge.tsx`):
   - Small badge with a sparkle/shine icon and "Foil" text
   - Use a gradient or shimmer effect (CSS only, subtle)
   - Compact variant for tiles, full variant for detail page

2. **Update CollectionCardTile** (`frontend/src/components/CollectionCardTile.tsx`):
   - Show `<FoilBadge />` when `card.is_foil === true`
   - Position: top-right corner overlay or below card name

3. **Update CollectionCardDetail** (`frontend/src/pages/CollectionCardDetail.tsx`):
   - Show `<FoilBadge />` next to card name/title
   - In price section, label as "Foil price" when `is_foil`

4. **Update API types** (`frontend/src/api/types.ts` or equivalent):
   - Add `is_foil: boolean` to the CollectionCard type

5. **i18n keys** (`frontend/src/i18n/locales/en.json`, `pt-BR.json`):
   - `"card.foil"`: "Foil" / "Foil"
   - `"card.foilPrice"`: "Foil price" / "Preco Foil"

### Visual design

- FoilBadge: small pill shape, subtle gradient background
  (e.g., `bg-gradient-to-r from-amber-500/20 to-yellow-500/20`),
  amber text, sparkle emoji or SVG icon
- Should be visually distinct but not overwhelming
- Dark theme compatible (slate-800 surface)

### What NOT to do

- Do NOT show both normal and foil prices side by side (defer to future)
- Do NOT add foil toggle/filter to collection page (defer to future)

## Testing

- Unit: CollectionCardTile shows FoilBadge when is_foil=true

- Snapshot: FoilBadge compact and full variants

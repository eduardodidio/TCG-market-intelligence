# F87-T01 — Foil Detection from Collection Extras Field

**Status:** planned
**Wave:** 0 (parallel with T02, T03)
**Estimate:** small

## User Story

As a collector, I want the system to know which of my cards are foil so
that it can fetch the correct (foil) price from Liga instead of the
non-foil price.

## Dev Notes

### What to do

1. **Add `is_foil` helper** to `src/collection/converter.py` (or a new
   `src/collection/foil.py` utility):
   ```python
   def is_foil_entry(extras: str | None) -> bool:
       """Check if a collection entry's extras field indicates foil."""
       if not extras:
           return False
       return "foil" in extras.lower()
   ```

2. **Add `is_foil` property** to the `CollectionEntry` domain model
   (`src/domain/models.py`) if it has an extras field, or compute it
   from the extras string wherever needed.

3. **Add `is_foil` to CollectionCard schema** (`src/api/schemas/collection.py`):
   - Computed from the `extras` field during serialization
   - `is_foil: bool = False`

4. **Update CSV importer** (`src/collection/importer.py`): ensure the
   `extras` field preserves "Foil" text from CSV import. Currently it
   does — just verify with a test.

### Key files

- `src/collection/converter.py` — add `is_foil_entry()` helper
- `src/domain/models.py` — check `CollectionEntry` dataclass
- `src/api/schemas/collection.py` — add `is_foil` field
- `src/api/routers/collection.py` — populate `is_foil` during serialization

### What NOT to do

- Do NOT add a new database column yet (keep it computed from extras)
- Do NOT modify the Liga parser (already works)

## Testing

- Unit test: `is_foil_entry("Foil")` → True
- Unit test: `is_foil_entry("foil")` → True
- Unit test: `is_foil_entry(None)` → False
- Unit test: `is_foil_entry("Signed")` → False

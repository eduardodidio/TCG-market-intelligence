# F55-T02 -- Refresh Auto-Canonize for Orphan Entries

**Status:** planned
**Wave:** 0

## User Story

As a collector, I want the "Refresh" button to automatically link my card to
a MYP source when one is missing, so that I do not have to manually canonize
before refreshing.

## Context

`POST /collection/{entry_id}/refresh` (line 705 in
`src/api/routers/collection.py`) returns HTTP 422 "No MYP source card linked"
when an entry has `card_id` but no MYP SourceCard. The canonize endpoint
(line 584) already handles this exact orphan case -- it re-runs MYP
search+match and creates the SourceCard. But refresh does not delegate to
this logic, forcing the user to manually canonize first.

## Dev Notes

### File: `src/api/routers/collection.py`

Modify `refresh_card_price()` (starts at line 705). Replace the early 422


With an inline auto-canonize attempt that reuses the same pattern from
`canonize_card()`:

```python
if not myp_sources:
    # Auto-canonize: search MYP and create source card before refresh
    from src.collection.converter import row_to_collection_entry
    from src.collection.matcher import match_collection_card
    from src.domain.models import SourceCard

    provider = MypCardsProvider()
    try:
        ce = row_to_collection_entry(entry)
        search_results: list = []
        if ce.name_en:
            search_results = await provider.search_card(ce.name_en)
        if not search_results and ce.name_pt:
            search_results = await provider.search_card(ce.name_pt)

        match = match_collection_card(ce, search_results)

        if match.status != "matched" or not match.myp_result:
            raise HTTPException(
                status_code=422,
                detail="No MYP source card linked and auto-match failed",
            )

        myp = match.myp_result
        source_card = SourceCard(
            source="myp",
            external_id=myp.external_id,
            url=myp.url,
            sku=myp.sku,
        )

        detailed = await provider.get_card_details(source_card)
        if detailed:
            repo.upsert_card(detailed)
            repo.upsert_source_card(detailed, card_id=entry.card_id)

        # Re-fetch source cards after canonize
        source_cards = repo.get_source_cards_for_card(entry.card_id)
        myp_sources = [sc for sc in source_cards if sc.source == "myp"]
        if not myp_sources:
            raise HTTPException(
                status_code=422,
                detail="No MYP source card linked and auto-canonize failed",
            )

        log.info(
            "refresh_auto_canonized",
            entry_id=entry_id,
            card_id=entry.card_id,
            external_id=myp.external_id,
        )
    except HTTPException:
        raise
    except Exception as exc:
        log.warning(
            "refresh_auto_canonize_failed",
            entry_id=entry_id,
            error=str(exc),
        )
        raise HTTPException(
            status_code=422,
            detail=f"No MYP source card linked and auto-canonize failed: {exc}",
        )
    finally:
        await provider.close()
```

After this block, execution continues to the existing price-fetch logic
(line 729+) which now has a valid `myp_sources[0]`.

**Important**: the existing code on line 733 creates `provider = MypCardsProvider()`
again for the price fetch. Since we already created and closed a provider in the
auto-canonize block, the existing code is fine -- it creates a fresh provider for
the price fetch. No need to restructure the existing flow.

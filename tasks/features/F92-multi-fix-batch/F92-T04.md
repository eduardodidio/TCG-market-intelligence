# F92-T04: Simplify CreditConfirmModal Art

**Status:** planned
**Wave:** 1
**Type:** improvement (frontend-only)

## User Story
As a user, when I see the treasure token spending confirmation modal, I want
to see just the clean card art image (identical to the sidebar treasure card),
without the MTG-style card frame (header bar, type line, rules text, border).

## Dev Notes

### Changes

1. **`frontend/src/components/CreditConfirmModal.tsx`**:
   - Remove `import { TreasureTokenCard }`
   - Add `import { useTreasureImage }` from hooks
   - Replace `<TreasureTokenCard count={balance} />` (line 55) with a
     simple image + count overlay:
     ```tsx
     <div className="relative w-32">
       <img
         src={treasureImage}
         alt={t("credits.balance")}
         className="w-full rounded-lg object-cover shadow-lg"
         data-testid="treasure-image"
       />
       <div
         className="absolute bottom-1 right-1 bg-black/70 text-amber-400
                     rounded-full w-8 h-8 flex items-center justify-center
                     text-sm font-bold border border-amber-500"
         data-testid="treasure-count"
       >
         {balance}
       </div>
     </div>
     ```
   - This matches the sidebar TreasureBalance style: just the art with
     a small count badge overlay

### Scope
- Single component change
- TreasureTokenCard component is NOT deleted (may be used elsewhere)
- No i18n changes

## Testing
- Verify modal shows clean card art without card frame elements
- Verify count badge overlay shows correct balance
- Existing CreditConfirmModal tests should pass (update selectors if needed)

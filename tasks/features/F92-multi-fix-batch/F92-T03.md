# F92-T03: Credit Balance Stale on Card Navigation

**Status:** planned
**Wave:** 1
**Type:** fix (frontend-only)

## User Story
As a user, when I navigate from one card detail page to another (e.g. via
browser back/forward or direct link), I want the credit balance to refresh
so I don't see a false "insufficient credits" error.

## Dev Notes

### Root Cause
`useCredits()` in `CollectionCardDetail.tsx` (line 94) fetches balance only
on mount via `useEffect(() => { fetchBalance(); }, [fetchBalance])`. When
React Router navigates from `/collection/1` to `/collection/2`, the component
re-renders with new `entryId` but `useCredits` doesn't re-fetch because
`fetchBalance` is a stable `useCallback` reference.

### Changes

1. **`frontend/src/pages/CollectionCardDetail.tsx`**:
   - Add a `useEffect` after the existing `useCredits()` call (~line 95):
     ```tsx
     useEffect(() => { refetchCredits(); }, [entryId]);
     ```
   - This ensures balance is re-fetched whenever the route param changes

### Scope
- Single file change, frontend only
- No changes to useCredits hook itself (avoids breaking other consumers)

## Testing
- Test: render CollectionCardDetail, change id param, verify refetchCredits
  is called
- Manual: navigate between two card details, verify balance shown is current

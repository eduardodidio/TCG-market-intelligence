# F114-T01: Card Links Fix (Liga URL + CardTile Navigation)

**Status:** planned
**Wave:** 0

## User Story

As a user browsing my collection, I want card links to open the correct card
and Liga Magic links to show the right card page, so I can trust the
navigation.

## Root Cause Analysis

### Bug 1: Liga URL sem encoding
**File:** `src/api/routers/collection.py:1638`
```python
ligamagic_url = f"https://www.ligamagic.com.br/?view=cards/card&card={name}"
```
Uses raw card name without URL encoding. Cards with spaces/special chars
(e.g. "Esgaroth, Lost Lord of Laimar") produce malformed URLs. Liga's search
then returns the first result (wrong card like "Walking Ballista").

**Fix:** Use `urllib.parse.quote_plus` (already used correctly in
`src/providers/liga/provider.py:43-46` via `_build_card_url`).

### Bug 2: CardTile always links to /cards/{id}
**File:** `frontend/src/components/CardTile.tsx:65`
```typescript
<Link to={`/cards/${card.id}`} ... >
```
CardTile is used in both the Cards page (catalog view) and Collection page.
In collection context, clicking should navigate to `/collection/{entry_id}`
(the user's collection entry), not `/cards/{card_id}` (the generic card).

**Fix:** Accept an optional `linkPrefix` prop (default `/cards`) so the
Collection page can pass `linkPrefix="/collection"` with the entry_id.

## Dev Notes

```python
from urllib.parse import quote_plus

# Line ~1638 — replace raw name with encoded
ligamagic_url = f"https://www.ligamagic.com.br/?view=cards/card&card={quote_plus(name)}&show=1"
```

### Frontend change (CardTile.tsx)
Add optional `href` or `linkTo` prop:
```typescript
interface CardTileProps {
  card: CardSummary;
  linkTo?: string;  // override navigation target
  // ... existing props
}

// In render:
<Link to={linkTo ?? `/cards/${card.id}`} ... >
```

Then in MyCollection.tsx, pass `linkTo={`/collection/${entry.id}`}`.

### General link audit
Grep all `<Link to=` and `href=` in frontend for card-related links.
Verify each uses the correct ID (card_id vs entry_id vs external_id).

## Acceptance Criteria

1. Liga Magic links open the correct card (URL-encoded names)
2. Clicking a card in Collection navigates to `/collection/{entry_id}`
3. Clicking a card in Cards/Catalog navigates to `/cards/{card_id}` (unchanged)
4. No broken links across the 27 pages

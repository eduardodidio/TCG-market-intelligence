# F114-T03: Dashboard Collection Summary Resilience

**Status:** planned
**Wave:** 0

## User Story

As a user with an imported collection, I want the Dashboard to show my
collection stats and trending cards instead of asking me to import, so that
the home page reflects my actual portfolio.

## Root Cause Analysis

**File:** `frontend/src/pages/Dashboard.tsx:158-212`

The Dashboard conditionally renders:
```typescript
{!collectionSummary.loading && !collectionSummary.error && summaryData ? (
  // Show KPIs
) : !collectionSummary.loading ? (
  // Show "import your collection" EmptyState
) : null}
```

The empty state shows when:
1. `collectionSummary.error` is truthy (API failure), OR
2. `summaryData` is null/undefined (response parsing issue)

**Likely trigger:** After `push-db`, user's JWT has stale user_id (e.g., 1
instead of 3). API returns 401 or empty data. Even after re-login, React
Query cache may serve stale error state.

**Additional issue:** Dashboard doesn't show "cards trending up/down" from
the user's actual collection — it only shows market-wide stats.

## Dev Notes

### Fix 1: Resilient summary fetch

In Dashboard.tsx, add retry + cache invalidation:
```typescript
// If summary fails, show partial dashboard (market stats) instead of full empty state
// Only show "import" CTA if total_unique === 0 AND no error
```

Change the conditional to:
```typescript
const hasCollection = summaryData && summaryData.total_unique > 0;
const isError = collectionSummary.error && !summaryData;

{hasCollection ? (
  // Full KPI dashboard
) : isError ? (
  // Error state with retry button (not "import your collection")
) : !collectionSummary.loading ? (
  // Genuine empty state — user has no cards
) : null}
```

### Fix 2: Show collection movers on dashboard

The `/api/v1/collection/movers` endpoint already exists (F112). Add a
section to the Dashboard that shows the user's top gainers/losers:

```typescript
// Fetch movers alongside existing stats
const movers = useApi<CollectionMovers>('/api/v1/collection/movers');
```

Display a compact "Your Cards" section with:
- Top 3 gainers (green, % change)
- Top 3 losers (red, % change)
- Link to full portfolio page

### Fix 3: Force refetch on auth change

In the useApi hook or Dashboard, invalidate cache when user changes:
```typescript
// Key the query by user_id to prevent stale cross-user cache
const cacheKey = `/api/v1/collection/summary?_uid=${user?.id}`;
```

## Acceptance Criteria

1. Dashboard shows KPIs when collection exists (even after push-db + re-login)
2. API errors show retry button, NOT "import your collection"
3. "Import" CTA only appears when user truly has 0 cards
4. Dashboard shows top gainers/losers from user's collection (movers)

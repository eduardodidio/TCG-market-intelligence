## User Story

As a new contributor, I want to run `make setup && make test` on a fresh clone
so that I can start working on the project within minutes without guessing
which commands to run.

## Objective

Create a Makefile with standard targets, a `.env.example` documenting all
environment variables, and complete the `pyproject.toml` with build-system
metadata, project URLs, and classifiers.

## Dev Notes

- The project uses Python 3.14 (requires-python currently says >=3.11, keep
  that for compatibility but add a Python 3.14 classifier).
- Entry point is already defined: `collector = "src.cli.main:cli"`.
- No secrets are needed for the collector itself -- the only env var is the
  database URL (defaults to `sqlite:///tcg_market.db`).
- Use `[build-system]` with setuptools.

## Implementation Details

### Makefile

Create `Makefile` at project root with these targets:

```makefile
.PHONY: setup test lint format clean run-backfill run-update help

help:            ## Show this help
setup:           ## Create venv, install deps (dev + prod)
test:            ## Run pytest with verbose output
lint:            ## Run ruff check
format:          ## Run ruff format
clean:           ## Remove __pycache__, .pytest_cache, *.egg-info, dist, build
run-backfill:    ## Run backfill (use SET= and LIMIT= to customize)
run-update:      ## Run incremental update
```

- `setup` target: `python -m venv .venv && .venv/bin/pip install -e ".[dev]"`
- `test` target: `.venv/bin/python -m pytest tests/ -v`
- `lint` target: `.venv/bin/ruff check src/ tests/`
- `format` target: `.venv/bin/ruff format src/ tests/`
- `clean` target: remove `__pycache__`, `.pytest_cache`, `*.egg-info`, `dist/`, `build/`, `tcg_market.db`
- `run-backfill`: `.venv/bin/python -m src.cli.main backfill $(if $(SET),--set $(SET)) $(if $(LIMIT),--limit $(LIMIT))`
- `run-update`: `.venv/bin/python -m src.cli.main update`
- `help` as default target, using the `##` comment convention

### .env.example

Create `.env.example` at project root:

```
# TCG Market Intelligence - Environment Variables
# Copy this file to .env and adjust values as needed.

# Database connection string (SQLAlchemy format)
# Default: sqlite:///tcg_market.db (file in project root)
DATABASE_URL=sqlite:///tcg_market.db

# Request delay between HTTP calls (seconds) - be respectful to sources
REQUEST_DELAY=1.0

# Maximum days of price history to fetch (max 1095 = ~3 years)
HISTORY_DAYS=1095

# Log level (DEBUG, INFO, WARNING, ERROR)
LOG_LEVEL=INFO
```

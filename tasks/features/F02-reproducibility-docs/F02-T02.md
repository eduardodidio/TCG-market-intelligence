# F02-T02: Bootstrap scripts for Mac and Linux

**Type:** setup
**Depends on:** none

## User Story

As a developer setting up the project on a new Mac or Linux machine, I want to
run a single bootstrap script that installs system dependencies (Python, SQLite)
and sets up the project so that I do not need to manually figure out
prerequisites.

## Objective

Create platform-specific bootstrap scripts under `bin/` that detect the OS,
install system-level prerequisites, then delegate to `make setup`.

## Dev Notes

- Mac is the primary development environment (Homebrew).
- Linux script should support Debian/Ubuntu (apt) as the primary target.
- Both scripts must be idempotent (safe to re-run).
- Python 3.14 may not be in default repos yet -- scripts should check for
  Python >= 3.11 and suggest pyenv if needed.
- SQLite is bundled with Python, no separate install needed.
- Scripts should NOT run as root; use `sudo` only for package manager calls.

## Implementation Details

### bin/bootstrap-mac.sh

```bash
#!/usr/bin/env bash
set -euo pipefail

# 1. Check for Homebrew, install if missing
# 2. brew install python@3.14 (or python@3.13 / python@3.12 / python@3.11)
#    - Detect highest available Python >= 3.11
# 3. Check for make (xcode-select --install if missing)
# 4. Copy .env.example to .env if .env does not exist
# 5. Run make setup
# 6. Print success message with next steps
```

### bin/bootstrap-linux.sh

```bash
#!/usr/bin/env bash
set -euo pipefail

# 1. Detect distro (Debian/Ubuntu vs other)
# 2. sudo apt update && sudo apt install -y python3 python3-venv python3-pip make
#    - For non-Debian: print manual instructions
# 3. Check Python version >= 3.11, warn if older and suggest pyenv
# 4. Copy .env.example to .env if .env does not exist
# 5. Run make setup
# 6. Print success message with next steps
```

### Common requirements

- Both scripts must:
  - Print a banner with project name at start
  - Use colored output (green for success, yellow for warnings, red for errors)
  - Be executable (`chmod +x`)
  - Exit with clear error message if a critical dependency cannot be installed
  - Be idempotent: skip steps that are already satisfied
  - Print "Next steps" at the end (run `make test`, try `make run-backfill`)

## Acceptance Criteria

## Testing

Test on available platform. Verify:
1. Script detects existing Python installation
2. Script skips already-installed dependencies
3. Script creates `.env` from `.env.example`
4. Script runs `make setup` successfully
5. Re-running the script completes without errors

## Test Scenarios

1. Mac with Homebrew already installed, Python present: script skips installs
2. Linux (Debian) with Python present: script skips apt install
3. Missing Python: script installs or prints clear guidance
4. `.env` already exists: script does not overwrite it
5. Re-run after successful first run: no errors, no side effects

# F61-T01: Harden search_card Playwright exception handling

**Status:** done
**Wave:** 0
**Parallel with:** T02

## User Story

As a developer, I want `LigaMagicProvider.search_card()` to catch Playwright-
specific exceptions and convert them to `LigaError` with descriptive messages,
so that callers always get typed, meaningful errors instead of bare exceptions
with empty messages.

## Dev Notes

### Current state
- `src/providers/liga/provider.py` — `search_card()` (line 323-344) only
  catches `LigaError` from `_fetch_page()`
- `_fetch_page()` (line 128-246) catches `TimeoutError` and `OSError` but NOT
  `playwright._impl._errors.Error` or `playwright._impl._errors.TimeoutError`
- Playwright can raise its own `Error` class with empty messages (e.g. when
  browser crashes, page disconnects, or navigation fails mid-way)

### Changes needed

1. **In `_fetch_page()`** — expand the exception catch to include Playwright errors:
   ```python
   except (TimeoutError, OSError) as e:
   ```
   becomes:
   ```python
   except (TimeoutError, OSError, PlaywrightError) as e:
   ```
   where `PlaywrightError` is imported lazily inside the method:
   ```python
   from playwright._impl._errors import Error as PlaywrightError
   ```
   The error message should include `type(e).__name__` to disambiguate.

2. **In `search_card()`** — add a catch-all that wraps unexpected exceptions:
   ```python
   except LigaError as e:
       ...
   except Exception as e:
       log.warning(
           "liga_search_unexpected_error",
           card=card_name,
           error=repr(e),
           exc_type=type(e).__name__,
       )
       raise LigaError(
           f"Unexpected {type(e).__name__}: {e}" if str(e) else f"Unexpected {type(e).__name__} (no message)",
           url=url,
       ) from e
   ```
   This ensures callers ALWAYS get a `LigaError` with a non-empty message.

3. **In `_fetch_page()`** — improve the error message for empty-message exceptions:
   ```python
   raise LigaError(
       f"Request failed ({type(e).__name__}): {e}" if str(e) else f"Request failed ({type(e).__name__}, no details) after {attempt} attempts: {url}",
       url=url,
       status_code=0,
       attempts=attempt,
   ) from e
   ```

# F61-T02: Fix refresh-liga endpoint — reuse singleton + better errors

**Status:** done
**Wave:** 0

## User Story

As a collector, when Liga refresh fails, I want a clear error message that
tells me what went wrong (not just "Unexpected error: ") so I can decide
whether to retry or use the MYP fallback.

## Dev Notes

### Current state
- `src/api/routers/collection.py:898` creates `LigaMagicProvider()` per request
- This creates a NEW Playwright browser instance each time (~5s startup)
- Meanwhile `app.state.provider_registry` already holds a singleton instance
- Multiple concurrent Playwright instances may conflict in the server context
- Error handler at line 920-924 logs only `str(exc)` — no type, no traceback

### Changes needed

1. **Reuse the singleton provider from the registry**:
   ```python
   # Instead of: provider = LigaMagicProvider()
   # Use the registry's Liga provider:
   from src.providers.liga.provider import LigaMagicProvider

   registry = request.app.state.provider_registry
   provider = next(
       (p for p in registry.providers if isinstance(p, LigaMagicProvider)),
       None,
   )
   if provider is None:
       raise HTTPException(status_code=503, detail="Liga provider not available")
   ```
   Remove the `finally: await provider.close()` block — the singleton
   provider is managed by the app lifecycle, not per-request.

2. **Add `request: Request` to the endpoint signature** (FastAPI dependency
   to access `app.state`).

3. **Improve the catch-all error handler** (line 920-924):
   ```python
   except Exception as exc:
       import traceback as _tb
       log.warning(
           "liga_refresh_unexpected_error",
           entry_id=entry_id,
           error=str(exc),
           exc_type=type(exc).__name__,
           traceback=_tb.format_exc(),
       )
       msg = f"{type(exc).__name__}: {exc}" if str(exc) else f"{type(exc).__name__} (no details)"
       response = _build_collection_detail(entry_id, currency, repo, converter, user_id)
       response.errors.append(
           ErrorDetail(code="liga_warning", message=f"LigaMagic error: {msg}")
       )
       return response
   ```

4. **Improve the `LigaError` handler** (line 916-918) to include traceback
   in logs as well:
   ```python
   except LigaError as exc:
       log.warning("liga_refresh_error", entry_id=entry_id, error=str(exc), exc_type=type(exc).__name__)
       ...
   ```

# F61-T03: Frontend error message display improvement

**Status:** done
**Wave:** 1
**Depends on:** T02

## User Story

As a collector, when Liga refresh fails I want to see a meaningful error
message (not just "Unexpected error: ") with a clear suggestion to try
the MYP fallback button.

## Dev Notes

### Current state
- `CollectionCardDetail.tsx` line 99-100: when `res.errors` present with
  `res.data`, shows `res.errors[0].message` as a warning toast
- The current message is `"Unexpected error: "` — blank and confusing
- After T02, the backend will return messages like `"LigaMagic error: Error (no details)"` or `"LigaMagic error: TimeoutError: page.goto timed out"`

### Changes needed

1. **Improve the warning display for Liga errors**:
   - If the error code is `"liga_warning"`, show a user-friendly prefix
   - Add an i18n key for the fallback hint: `collection.ligaErrorHint`
     → "Try the MYP refresh button as fallback."
   - Display pattern:
     ```
     [warning] Liga: {error message}. Try the MYP refresh button as fallback.
     ```

2. **Extend the warning toast timeout** from 3s to 5s for Liga warnings
   (the message is longer and needs more reading time).

3. **Add i18n keys** (both locales):
   - `collection.ligaErrorHint`: "Try the MYP refresh button as fallback."
   - `collection.ligaErrorHint` (pt-BR): "Tente o botao MYP como alternativa."

### Files to modify
- `frontend/src/pages/CollectionCardDetail.tsx` — `handleRefreshLiga` callback
- `frontend/src/i18n/locales/en.json` — add 1 key
- `frontend/src/i18n/locales/pt-BR.json` — add 1 key

### Files NOT to modify
- `frontend/src/api/collection.ts` — no changes needed

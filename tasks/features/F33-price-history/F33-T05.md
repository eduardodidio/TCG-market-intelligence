## Objective

Write comprehensive unit and integration tests for all F33 code. Target:
maintain backend coverage >= 94%, frontend coverage in line with existing
standards.

## Backend Tests

### File: `tests/unit/analytics/test_aggregation.py`

Test `src/analytics/aggregation.py`:

1. **`test_determine_resolution`** — verify "daily" for 24h/7d/30d/90d,
   "weekly" for 180d/1y.

2. **`test_aggregate_weekly_groups_by_iso_week`** — provide 14 daily
   observations spanning 2 ISO weeks, verify output has 2 data points
   with correct averaged prices.

3. **`test_aggregate_weekly_handles_none_prices`** — observations with
   some None median_price values are averaged only over non-None values.

4. **`test_aggregate_weekly_empty_input`** — returns empty list.

5. **`test_aggregate_weekly_single_observation`** — returns 1 data point.

6. **`test_aggregate_weekly_preserves_currency`** — output currency
   matches input.

7. **`test_aggregate_series_daily_passthrough`** — period="30d" returns
   input unchanged, resolution="daily".

8. **`test_aggregate_series_weekly_for_long_period`** — period="180d"
   triggers weekly aggregation.

9. **`test_compute_price_change_summary_positive`** — start < end, verify
   positive absolute_change and percent_change.

10. **`test_compute_price_change_summary_negative`** — start > end.

11. **`test_compute_price_change_summary_no_data`** — empty observations,
    verify all fields are None/0.

12. **`test_compute_price_change_summary_single_point`** — 1 observation,
    start == end, change == 0.

### File: `tests/unit/api/test_cards_history_periods.py`

Test the extended periods in `src/api/routers/cards.py`:

1. **`test_24h_period_accepted`** — GET with period=24h returns 200.
2. **`test_7d_period_accepted`** — GET with period=7d returns 200.
3. **`test_3y_period_rejected`** — GET with period=3y returns 422.
4. **`test_history_response_includes_summary`** — verify response has
   `observations` and `summary` keys.

### File: `tests/unit/api/test_collection_history.py`

Test `GET /collection/{id}/history`:

1. **`test_collection_history_requires_auth`** — 401 without token.
2. **`test_collection_history_returns_404_for_other_user`** — entry
   belongs to different user.
3. **`test_collection_history_returns_observations`** — happy path with
   linked card and price data.
4. **`test_collection_history_empty_for_unlinked`** — card_id is None,
   returns empty observations.
5. **`test_collection_history_applies_period_filter`** — verify day
   filtering works.
6. **`test_collection_history_applies_currency_conversion`** — USD
   currency param converts prices.
7. **`test_collection_history_invalid_period`** — returns 422.

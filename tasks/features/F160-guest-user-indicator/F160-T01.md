# F160-T01: Show guest indicator in sidebar

**Feature:** F160 — Guest User Visual Indicator
**Wave:** 0
**Status:** planned

## User Story

As a guest user, I want to know that I'm viewing someone else's
collection, so I understand the data I see isn't mine.

## Dev Notes

### Current State

`Layout.tsx` shows `user.display_name` in the sidebar. `AuthContext.tsx`
exposes `user.role` which is `"guest"` for guest users. No visual
indicator exists.

### Implementation

Below the display name in the sidebar, when `user.role === "guest"`,
show a subtle subtitle:

```tsx
{user?.role === "guest" && (
  <p className="text-xs text-amber-400/80 mt-0.5" data-testid="guest-indicator">
    {t("auth.guestViewing")}
  </p>
)}
```

### i18n keys
- `auth.guestViewing`: "Viewing shared collection" / "Visualizando colecao compartilhada"

### Files
- `frontend/src/components/Layout.tsx` — guest indicator below display name
- `frontend/src/i18n/locales/en.json` — new key
- `frontend/src/i18n/locales/pt-BR.json` — new key

## Testing

- Unit: guest indicator renders when user.role === "guest"
- Unit: guest indicator does not render for admin/regular users

## Acceptance Criteria

- [ ] Guest users see "Viewing shared collection" in sidebar
- [ ] Admin users do not see the indicator
- [ ] Text is translated (en + pt-BR)

# F38-T02 -- i18n Keys for Landing Page Sections (EN + PT-BR)

**Wave:** 1 (parallel with T01)
**Depends on:** None (standalone)
**Modifies:** `frontend/src/i18n/locales/en.json`,
`frontend/src/i18n/locales/pt-BR.json`

## Objective

Add i18n keys for the new landing page sections introduced by F38: hero
header, compact market summary strip, and any landing-specific labels.
Trending section labels already exist from F36.

## Steps

### 1. Add English keys (`frontend/src/i18n/locales/en.json`)

Add under a `landing` namespace (or merge into existing `dashboard`
namespace -- follow the pattern already in use):

```json
{
  "landing.heroTitle": "TCG Market Intelligence",
  "landing.heroSubtitle": "Track prices, spot trends, manage your collection",
  "landing.cardsTracked": "Cards tracked",
  "landing.observations": "Price observations",
  "landing.avgPrice": "Avg. price"
}
```

### 2. Add Portuguese keys (`frontend/src/i18n/locales/pt-BR.json`)

```json
{
  "landing.heroTitle": "TCG Market Intelligence",
  "landing.heroSubtitle": "Acompanhe precos, identifique tendencias, gerencie sua colecao",
  "landing.cardsTracked": "Cards rastreados",
  "landing.observations": "Observacoes de preco",
  "landing.avgPrice": "Preco medio"
}
```

### 3. Verify no key collisions

Check existing keys in both locale files. The `landing.*` namespace
should not conflict with existing `dashboard.*` keys. Existing dashboard
keys (`dashboard.totalCards`, `dashboard.totalObservations`,
`dashboard.averagePrice`) remain available for the Market Overview page
if it exists separately. The new `landing.*` keys are shorter labels
designed for the compact summary strip.

## Notes

- F36 already added trending-specific i18n keys (`trending.trendingUp`,
  `trending.trendingDown`, `trending.noTrending`, etc.). Do NOT duplicate
  those here.
- The `common.viewAll` key already exists and is used by the "Ver mais"
  links.
- If additional keys are needed during T01 implementation (e.g., for
  skeleton aria-labels), add them in this task's scope.

## Acceptance Criteria

- [ ] `landing.heroTitle` key exists in both EN and PT-BR locales
- [ ] `landing.heroSubtitle` key exists in both EN and PT-BR locales
- [ ] `landing.cardsTracked` key exists in both EN and PT-BR locales
- [ ] `landing.observations` key exists in both EN and PT-BR locales
- [ ] `landing.avgPrice` key exists in both EN and PT-BR locales
- [ ] No duplicate or conflicting keys with existing namespaces
- [ ] JSON files remain valid (no syntax errors)

# F89-T06 — i18n Keys + Integration Tests

**Status:** planned
**Wave:** 2
**Depends:** T03, T04, T05

## User Story

As a user, I want all batch collection management UI to be fully translated in English and Portuguese, and I want confidence that the end-to-end flows work correctly.

## Acceptance Criteria

- All new UI strings have i18n keys in both `en.json` and `pt-BR.json`
- No hardcoded strings in any new component
- Integration tests cover full flows: batch add (parse → preview → add), batch edit (select → update), single edit, delete
- Backend integration tests cover PATCH/DELETE/POST endpoints with real DB

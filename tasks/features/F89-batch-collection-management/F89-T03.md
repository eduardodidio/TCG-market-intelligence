# F89-T03 — Frontend: Single Card Inline Edit

**Status:** planned
**Wave:** 1
**Depends:** T01

## User Story

As a collector, I want to edit a card's quantity, condition, language, and extras directly from the card detail page, so that I can quickly fix metadata without navigating away.

## Acceptance Criteria

- CollectionCardDetail page shows editable fields for: quantity, quality, language, extras
- Each field has an edit mode (click pencil icon → inline input/select → save/cancel)
- Quantity: number input with +/- stepper buttons (min 1)
- Quality: dropdown select with options: M, NM, SP, MP, HP, D
- Language: dropdown select with options: BR, EN, DE, ES, FR, IT, JP, KO, RU, TW
- Extras: text input (free-form, comma-separated like "Foil, Promo")
- Save calls `PATCH /collection/{id}` with changed fields only
- On success: UI updates inline, shows brief success indicator (green check)
- On error: shows error message, reverts to previous value
- CollectionCardTile: quick qty edit via +/- overlay buttons (no modal)
- Delete button on CollectionCardDetail with confirmation dialog
- All new strings in i18n (EN + PT-BR)

### InlineEditField component
- Props: `value`, `onChange`, `type: "text" | "number" | "select"`, `options?`, `label`

- Escape key cancels, Enter saves

- Props: `value`, `onChange`, `min=1`, `compact?`

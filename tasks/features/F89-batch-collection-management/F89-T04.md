# F89-T04 — Frontend: Batch Add Modal (Text Paste + Preview)

**Status:** planned
**Wave:** 1
**Depends:** T02

## User Story

As a collector, I want to paste a list of cards in text format into a modal, preview the parsed results, fix any errors, and add them all at once, so that I can quickly grow my collection.

## Acceptance Criteria

- "Add Cards" button on MyCollection page opens BatchAddModal
- Modal has a textarea for pasting card lines (placeholder with format example)
- "Preview" button calls `POST /collection/batch/parse` and displays results in a table
- Preview table columns: Status (valid/error icon), Qty, Card Name, Set, Condition, Language, Extras
- Error rows highlighted red with error message tooltip
- Valid rows can be individually removed from the batch (X button)
- Editable fields in preview: qty (stepper), quality (dropdown), language (dropdown), extras (text)
- "Add N Cards" button calls `POST /collection/batch` with valid entries only
- On success: modal closes, collection page refreshes, toast shows "N cards added"
- On partial error: shows summary "Added X, failed Y" with error details
- Format help section (collapsible) shows supported syntax examples
- Max 500 lines enforced client-side with warning
- All strings in i18n (EN + PT-BR)

### BatchAddModal flow
1. User opens modal → sees textarea + format help
2. Pastes text → clicks "Preview"
3. API returns parsed lines → BatchPreviewTable renders
4. User reviews/edits → clicks "Add N Cards"
5. API creates entries → modal closes + toast + page refresh

### BatchPreviewTable
- Each row: status icon, qty (editable stepper), name (read-only), set (read-only), quality (dropdown), language (dropdown), extras (text)
- Error rows: red bg, error message in a tooltip on the status icon
- Remove button (X) per row to exclude from batch
- Header shows count: "N valid / M errors"

# F89-T05 — Frontend: Multi-Select + Bulk Actions Toolbar

**Status:** planned
**Wave:** 1
**Depends:** T01

## User Story

As a collector, I want to select multiple cards in my collection grid and apply bulk actions (change condition, language, extras, or delete), so that I can manage large collections efficiently.

## Acceptance Criteria

- "Select" toggle button on MyCollection page enables selection mode
- In selection mode: each CollectionCardTile shows a checkbox overlay
- "Select All" / "Deselect All" buttons in the toolbar
- Floating bulk actions toolbar appears when >= 1 card selected
- Toolbar shows: selected count, bulk actions dropdown, Cancel button
- Bulk actions:
  - **Set Condition**: dropdown → applies to all selected
  - **Set Language**: dropdown → applies to all selected
  - **Set Extras**: text input → applies to all selected
  - **Delete**: confirmation dialog → deletes all selected
- Bulk update calls `PATCH /collection/bulk` with selected IDs + updates
- Bulk delete calls `DELETE /collection/bulk` with selected IDs
- On success: exits selection mode, refreshes grid, toast shows result
- On error: shows error message, selection preserved
- Toolbar is sticky at bottom of viewport (fixed position)
- All strings in i18n (EN + PT-BR)

### BulkActionsToolbar
- Fixed bottom bar, dark bg, slides up when selection count > 0
- Left: "N selected" count
- Center: action buttons (Condition, Language, Extras, Delete)
- Right: Cancel button (exits selection mode)
- Delete action shows confirmation modal with count
- Each action (except delete) opens a small popover with the input/dropdown

### SelectableCardTile
- Wraps CollectionCardTile
- Adds checkbox overlay (top-left corner)
- Click on checkbox toggles selection (click on card still navigates to detail)
- Selected state: subtle border highlight (cyan-400)

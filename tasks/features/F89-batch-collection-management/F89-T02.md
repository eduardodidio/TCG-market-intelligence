## User Story

As a collector, I want to paste a list of cards in text format (like LigaMagic) and have them added to my collection, so that I can quickly add multiple cards without creating a CSV file.

## Acceptance Criteria

- `POST /api/v1/collection/batch` accepts `{entries: [{name_en, set_code?, collector_number?, quantity?, quality?, language?, extras?}, ...]}`
- `POST /api/v1/collection/batch/parse` accepts `{text: str}` and returns parsed entries (preview mode, no DB writes)
- Text parser handles formats:
  - `2 Lightning Bolt` (qty + name)
  - `Lightning Bolt` (qty defaults to 1)
  - `2 Lightning Bolt [m15]` (qty + name + set)
  - `2 Lightning Bolt [m15] NM EN Foil` (full format)
  - `2x Lightning Bolt` (qty with 'x' suffix)
  - Lines starting with `#` or empty lines are ignored (comments)
- Parser returns structured entries with validation status per line (valid/error + message)
- Batch add auto-links to existing CardRow by (game="magic", set_code, collector_number) when set_code + collector_number are provided
- Batch add auto-creates minimal CardRow when no match found (same as CSV import)
- Max 500 entries per request
- JWT auth required, entries created with authenticated user_id
- Returns `{added: int, errors: [{line: int, text: str, error: str}]}`

### Parser implementation (`batch_parser.py`)
```python
def parse_batch_text(text: str) -> list[ParsedLine]:
    """Parse multi-line text into structured card entries.

    Format: [Qty[x]] CardName [[set_code]] [Quality] [Language] [Extras...]
    Examples:
        2 Lightning Bolt
        2x Lightning Bolt [m15] NM EN Foil
        # this is a comment
    """
```

Regex approach:
1. Strip line, skip empty/comments
2. Match optional leading `(\d+)x?\s+` for quantity
3. Match optional trailing `\[([\w]+)\]` for set code
4. Match optional quality codes: `\b(M|NM|SP|MP|HP|D)\b`
5. Match optional language codes: `\b(BR|EN|DE|ES|FR|IT|JP|KO|RU|TW)\b`
6. Match optional extras: `\b(Foil|Promo|Pre Release|Etched|Extended Art)\b` (case-insensitive)
7. Remaining text = card name

### Batch add orchestrator (`batch_add.py`)
- For each parsed entry:
  1. If set_code + collector_number → try match to CardRow
  2. If name_en only → create minimal CardRow (game="magic", name_en, set_code if provided)
  3. Insert UserCollectionRow
- Use a single DB session/transaction for atomicity
- Return summary with per-line error details

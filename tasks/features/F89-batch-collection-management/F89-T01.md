## User Story

As a collector, I want to update card metadata (quantity, condition, language, extras) and delete entries from my collection via API, so that I can manage my collection without re-importing the entire CSV.

## Acceptance Criteria

- `PATCH /api/v1/collection/{entry_id}` accepts partial update of `{quantity, quality, language, extras}`
- `PATCH /api/v1/collection/bulk` accepts `{ids: [int], updates: {quantity?, quality?, language?, extras?}}` for batch edit
- `DELETE /api/v1/collection/{entry_id}` removes a single entry
- `DELETE /api/v1/collection/bulk` accepts `{ids: [int]}` to remove multiple entries
- All endpoints require JWT auth
- IDOR protection: entries must belong to the authenticated user
- Validation: quantity >= 1, quality in (M, NM, SP, MP, HP, D) or null, language in (BR, EN, DE, ES, FR, IT, JP, KO, RU, TW) or null
- If `extras` changes and affects foil status, the response includes updated `is_foil` field
- Returns 404 for non-existent entries, 403 for wrong user
- Bulk operations are atomic (all-or-nothing within a single DB transaction)
- Bulk limit: max 200 entries per request

### Implementation details
- PATCH single: load entry by id + user_id, apply partial fields, commit
- PATCH bulk: `UPDATE user_collection SET ... WHERE id IN (:ids) AND user_id = :user_id`, verify affected rows == len(ids)
- DELETE single: `DELETE FROM user_collection WHERE id = :id AND user_id = :user_id`
- DELETE bulk: same pattern with IN clause
- Use `is_foil_entry(extras)` from `src/collection/converter.py` to compute `is_foil` in response
- Invalidate AggregateCache tags if quantity/extras change (affects portfolio valuation)

### Pydantic schemas
```python
class CollectionUpdateRequest(BaseModel):
    quantity: int | None = None
    quality: str | None = Field(None, pattern="^(M|NM|SP|MP|HP|D)$")
    language: str | None = Field(None, pattern="^(BR|EN|DE|ES|FR|IT|JP|KO|RU|TW)$")
    extras: str | None = None

class BulkUpdateRequest(BaseModel):
    ids: list[int]  # max 200
    updates: CollectionUpdateRequest

class BulkDeleteRequest(BaseModel):
    ids: list[int]  # max 200
```

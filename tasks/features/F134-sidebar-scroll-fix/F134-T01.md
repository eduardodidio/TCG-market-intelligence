# F134-T01 — Sidebar flex layout + scrollable nav + scrollbar styling

**Wave:** 0
**Status:** pending
**File(s):** `frontend/src/components/Layout.tsx`, `frontend/tailwind.config.ts`, `frontend/package.json`, `frontend/src/components/__tests__/Layout.test.tsx`

## Objective

Restructure the sidebar aside element to use flex column layout so that the
navigation section scrolls when content exceeds viewport height, while the
header zone (logo, user, controls) stays fixed and InstallPrompt pins to the
bottom.

## Implementation Steps

### 1. Install tailwind-scrollbar plugin

```bash
cd frontend && npm install -D tailwind-scrollbar
```

Update `frontend/tailwind.config.ts`:
- Import: `import scrollbar from 'tailwind-scrollbar'`
- Add to plugins array: `scrollbar({ nocompatible: true })`

### 2. Restructure aside element in Layout.tsx (line ~174)

Add `flex flex-col` to the aside element className. The aside currently has
`fixed inset-y-0` on mobile which gives it full viewport height, and
`md:relative` on desktop where the parent `flex min-h-screen` gives it full
height. Adding `flex flex-col` enables the internal flex structure.

**Current aside className (line 175-181):**
```
fixed inset-y-0 left-0 z-30 bg-white dark:bg-slate-800 border-r ...
md:relative md:translate-x-0
${sidebarOpen ? ...} ${!sidebarOpen ? ...}
```

**Add to this:** `flex flex-col`

### 3. Identify the two zones inside the aside

**Zone A -- Fixed header (lines 184-269):** Logo header, user section,
TreasureBalance, AlertBell, CurrencyToggle, LanguageSelector, ThemeToggle.
These elements should NOT scroll. Wrap them in a `<div>` with
`flex-shrink-0` to prevent compression:

```tsx
{/* Fixed header zone */}
<div className="flex-shrink-0">
  {/* Logo header (lines 184-202) */}
  {/* User section (lines 204-244) */}
  {/* TreasureBalance (lines 246-250) */}
  {/* AlertBell (lines 252-257) */}
  {/* CurrencyToggle (lines 259-261) */}
  {/* LanguageSelector (lines 263-265) */}
  {/* ThemeToggle (lines 267-269) */}
</div>
```

**Zone B -- Scrollable nav (lines 270-346):** Wrap the `<nav>` element in a
scrollable container:

```tsx
{/* Scrollable nav zone */}
<div className="flex-1 overflow-y-auto scrollbar-thin scrollbar-thumb-slate-600 dark:scrollbar-thumb-slate-500 scrollbar-track-transparent">
  <nav className={`mt-4 ${collapsed ? "px-1" : "px-3"}`} data-testid="sidebar-nav">
    {/* ... existing nav content unchanged ... */}
  </nav>
</div>
```

Key classes:
- `flex-1` -- take all remaining vertical space after header zone
- `overflow-y-auto` -- scroll only when content overflows
- `scrollbar-thin` -- thin scrollbar (from tailwind-scrollbar plugin)
- `scrollbar-thumb-slate-600` / `dark:scrollbar-thumb-slate-500` -- subtle thumb color
- `scrollbar-track-transparent` -- invisible track

### 4. InstallPrompt (lines 348-352)

The InstallPrompt `<div className="mt-auto">` is already correct. With the
aside now being `flex flex-col`, `mt-auto` will push it to the bottom as
intended. No changes needed to this element, but move it OUTSIDE the
scrollable container (it should be a direct child of the aside flex column,
after the scrollable nav div).

Final aside structure:
```
<aside class="... flex flex-col">
  <div class="flex-shrink-0">       <!-- Zone A: fixed header -->
    Logo | User | Controls
  </div>
  <div class="flex-1 overflow-y-auto scrollbar-...">  <!-- Zone B: scrollable -->
    <nav>Primary items + Beta Test</nav>
  </div>
  <div class="mt-auto">             <!-- Zone C: bottom-pinned -->
    <InstallPrompt />
  </div>
</aside>
```

### 5. Tests

Add tests to `frontend/src/components/__tests__/Layout.test.tsx`:

- **Sidebar has flex layout:** assert the aside (`[data-testid="sidebar"]`)
  has classes `flex` and `flex-col`.
- **Nav container is scrollable:** assert the parent of `[data-testid="sidebar-nav"]`
  has `overflow-y-auto` in its className.
- **Fixed header does not scroll:** assert the wrapper around the user section
  and controls has `flex-shrink-0`.
- **Scrollbar styling present:** assert the scrollable container has
  `scrollbar-thin` class.

## Notes

- Do NOT change the aside's positioning classes (`fixed inset-y-0 left-0`,
  `md:relative`). These are correct and ensure proper mobile/desktop behavior.
- The `h-screen` or `min-h-screen` is not needed on the aside because
  `fixed inset-y-0` already makes it full viewport height on mobile, and on
  desktop the parent flex container handles it.
- The scrollbar classes require `tailwind-scrollbar` plugin. Without the
  plugin, Tailwind will silently ignore them (no build error, just no styling).
  The plugin MUST be installed.

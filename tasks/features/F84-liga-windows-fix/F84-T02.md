# F84-T02 — Backend tests for Windows sync provider path

**Wave:** 0
**Status:** done

## User Story

As a developer, I want tests covering the Windows sync Playwright path so regressions are caught automatically.

## Dev Notes

### Tests to add in `tests/providers/liga/test_provider_windows.py`:

1. **test_open_windows_uses_sync_playwright** — mock `sys.platform` to `"win32"`, mock `playwright.sync_api`, verify sync_playwright is started via `to_thread`
2. **test_fetch_page_windows_delegates_to_sync** — verify `_fetch_page` calls sync path when `_use_sync=True`
3. **test_close_windows_cleans_sync_resources** — verify browser/playwright cleanup in sync mode
4. **test_search_card_windows** — end-to-end mock test of `search_card` on Windows path
5. **test_open_linux_uses_async_playwright** — verify async path still used when `sys.platform != "win32"`
6. **test_unavailable_flag_not_set_on_windows** — verify `_unavailable` stays `False` (the old behavior was to set it `True`)

### Approach
- Use `unittest.mock.patch("sys.platform", "win32")` to simulate Windows
- Mock `playwright.sync_api.sync_playwright` to avoid requiring actual browser
- Use `pytest.mark.asyncio` for async test functions

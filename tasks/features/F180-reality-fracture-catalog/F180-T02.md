# T02 -- Create catalog-seed-fra.bat

**Status:** done
**Wave:** 1

## User Story

As a user, I want a single bat script that seeds the Scryfall catalog
(picking up FRA and related sets) and then scans FRA + FRC prices via
Liga Magic, so I can populate my database with Reality Fracture cards in
one step.

## Dev Notes

**File:** `bats/catalog-seed-fra.bat` (new)

Follow the pattern established by `bats/daily-scan.bat`:

```bat
@echo off
REM ============================================================
REM  catalog-seed-fra.bat — Seed Scryfall catalog + scan FRA via Liga
REM  Run once after Reality Fracture (FRA) data is available on Scryfall
REM ============================================================

cd /d "%~dp0\.."

echo ============================================================
echo  TEDHC Catalog Seed - Reality Fracture (FRA) - %date% %time%
echo ============================================================

echo  [%time%] Seeding Scryfall catalog (includes FRA, FRC, TFRA, TFRC)...
python -m src.cli.main catalog seed || echo  [WARN] catalog seed failed

echo  [%time%] Scanning FRA prices via Liga...
python -m src.cli.main catalog scan --set fra || echo  [WARN] FRA scan failed

echo  [%time%] Scanning FRC (Commander) prices via Liga...
python -m src.cli.main catalog scan --set frc || echo  [WARN] FRC scan failed

echo.
echo  [DONE] %date% %time%
echo  Note: TFRA and TFRC are token sets (no Liga prices expected).
echo ============================================================
```

### Key decisions

- Only scan `fra` and `frc` (the main set and Commander). Token sets
  (`tfra`, `tfrc`) are seeded by the catalog but not scanned because
  Liga does not list token cards.
- Uses `||` fallback pattern (same as `daily-scan.bat`) so a failure in
  one step does not abort the rest.
- Script is idempotent -- re-running just updates existing data.

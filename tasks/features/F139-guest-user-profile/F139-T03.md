# F139-T03 — Frontend: beta access control

**Status:** planned
**Wave:** 1
**Depends on:** T01

## User Story

As a guest user, I can see the Beta Test section in the sidebar but all
items appear disabled (greyed out, not clickable). When I try to click a
disabled beta item, a toast shows: **"Esta funcao nao esta habilitada para
o perfil atual"**. If I navigate directly to a beta route via URL, I see
a centered message card with the same text instead of the page content.

### 3. BetaRoute guard component

Create: `frontend/src/components/BetaRoute.tsx`

```typescript
export function BetaRoute({ children }: { children: React.ReactNode }) {
  const { isAuthenticated, loading, hasBetaAccess } = useAuth();
  const { t } = useTranslation();

  if (loading) return <LoadingSpinner message="..." />;
  if (!isAuthenticated) return <Navigate to="/login" replace />;

  if (!hasBetaAccess) {
    return (
      <div className="flex items-center justify-center h-full">
        <div className="text-center p-8 bg-white dark:bg-slate-800 rounded-lg shadow max-w-md">
          <p className="text-gray-600 dark:text-slate-400 text-lg">
            {t("beta.blocked")}
          </p>
        </div>
      </div>
    );
  }

  return <>{children}</>;
}
```

### 4. App.tsx — wrap beta routes

File: `frontend/src/App.tsx`

Wrap all beta route elements with `<BetaRoute>`:

```tsx
// Before:
<Route path="/decks" element={<ProtectedRoute><DecksPage /></ProtectedRoute>} />

// After:
<Route path="/decks" element={<BetaRoute><DecksPage /></BetaRoute>} />
```

Apply to all 12 beta routes: `/market`, `/market/trending`, `/banlist`,
`/banlist/history`, `/decks`, `/decks/ranking`, `/decks/build`,
`/decks/evaluate`, `/marketplace`, `/trade-matches`, `/achievements`,
`/evaluations`.

Note: BetaRoute should also handle unauthenticated users for routes that
currently require auth (embed ProtectedRoute logic or wrap both).
For public beta routes (market, trending, banlist), only block guest
users — anonymous users can still view.

# F124-T01: Centralize Liga URL utility + fix split/DFC names

**Status:** planned
**Wave:** 0

## User Story

As a developer, I want a single canonical function for building Liga Magic URLs
so that all parts of the codebase produce correct, consistent links — especially
for split/DFC cards whose full Scryfall names (e.g. "Front // Back") break Liga search.

## Dev Notes

### What to change

1. **Create `src/providers/liga/url.py`** with:
   ```python
   from urllib.parse import quote_plus

   BASE_URL = "https://www.ligamagic.com.br"

   def liga_url_for_card_name(card_name: str) -> str:
       """Build a Liga Magic search URL from a card name.

       Handles split/DFC cards by using only the front face name.
       """
       # Strip back face for split/DFC cards
       front_face = card_name.split(" // ")[0].strip()
       encoded = quote_plus(front_face)
       return f"{BASE_URL}/?view=cards/card&card={encoded}&show=1"
   ```

2. **Refactor `src/providers/liga/provider.py`**:
   - Remove `_build_card_url` function
   - Import and use `liga_url_for_card_name` from `url.py`
   - Update `BASE_URL` reference

3. **Update `src/catalog/seeder.py`**:
   - Change import from `_build_card_url` to `liga_url_for_card_name`

4. **Update all backend URL construction sites**:
   - `src/api/routers/collection.py` — use `liga_url_for_card_name(canonical_name)`
   - `src/api/routers/card_search.py` — use `liga_url_for_card_name(card_name)` (fixes missing `&show=1`)

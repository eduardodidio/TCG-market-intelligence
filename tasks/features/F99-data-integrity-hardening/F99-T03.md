# F99-T03 -- PRAGMA foreign_keys=ON in Engine Config

**Wave:** 1 (parallel with T04, T05)
**Depends on:** T01 (orphans must be cleaned first)

## User Story

As a developer, I want SQLite to enforce foreign key constraints at
runtime so that invalid references are rejected immediately rather than
silently corrupting the database.

## Problem

SQLite does NOT enforce foreign keys by default. The `PRAGMA foreign_keys`
setting must be enabled per connection. Without this, adding FK constraints
to the schema (T04) would have no runtime effect -- inserts with invalid
card_id values would still succeed silently.

## Dev Notes

### Implementation

In `src/database/repository.py`, after creating the engine, register a
SQLAlchemy event listener:

```python
from sqlalchemy import event

engine = create_engine(db_url, echo=False)

@event.listens_for(engine, "connect")
def _set_sqlite_pragma(dbapi_connection, connection_record):
    cursor = dbapi_connection.cursor()
    cursor.execute("PRAGMA foreign_keys=ON")
    cursor.close()
```

This ensures every new connection from the pool has FK enforcement enabled.

### Important considerations

- This MUST be done in the `Repository.__init__` method, right after
  `create_engine` and BEFORE `Base.metadata.create_all` (so that
  `create_all` itself respects FK constraints).
- Only apply when the engine URL starts with `sqlite` (guard for future
  PostgreSQL migration).
- The `cleanup.py` module also creates its own `Repository` instances,
  so it inherits this behavior automatically.
- Test fixtures that create in-memory SQLite databases (`sqlite://`)
  will also get FK enforcement -- this is intentional and may surface
  latent test bugs where tests insert invalid foreign keys.

### Verify it works

After the change, inserting a `SourceCardRow` with `card_id=99999` (where
no such card exists) should raise an `IntegrityError` instead of succeeding
silently.

## Testing

- Unit test: verify PRAGMA foreign_keys is ON after engine creation
  (execute `PRAGMA foreign_keys` and assert result is 1)
- Unit test: verify inserting a row with invalid FK raises IntegrityError
- Unit test: verify the pragma is set on every new connection (close and
  reopen, check again)
- Unit test: guard clause -- if engine URL is not sqlite, pragma is not set

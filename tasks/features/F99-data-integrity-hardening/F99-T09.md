# F99-T09 -- Integration Tests for FK Constraints and Cascade Behavior

**Wave:** 3 (parallel with T08)
**Depends on:** T03, T04, T05, T06, T07

## User Story

As a developer, I want comprehensive integration tests covering all FK
constraints and cascade behaviors so that future schema changes do not
silently break referential integrity.

## Problem

The existing test suite does not test FK enforcement (because it was never
enabled). After T03 enables `PRAGMA foreign_keys=ON` and T04 adds FK
constraints, we need tests that verify:

1. FK constraints reject invalid references
2. CASCADE DELETE propagates correctly
3. SET NULL works on collection/card deletion
4. The orphan cleanup (T01) and link_orphan (T05) work with FK enforcement
5. The atomic sync transaction (T06) rolls back cleanly
6. The exchange rate fallback (T07) handles edge cases

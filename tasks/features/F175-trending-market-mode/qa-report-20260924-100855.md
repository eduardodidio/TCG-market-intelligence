## Finding fixed during QA

**Architecture diagram didn't match the implementation.** `docs/diagrams/F175-architecture.mmd` labeled Path 2's exclusion regex as
`^(?:liga|manual)_(\d+)(?:_foil)?$` (an *optional* foil group), which reads as "foil IDs also match." The actual implementation in
`src/database/trending_queries.py:26` is `^(?:liga|manual)_(\d+)$` — no foil group at all, so `liga_{id}_foil` never matches and is
correctly excluded. The Tech Lead review asserted the diagram "accurately reflects the actual code," which was not the case for this
detail. Fixed the diagram label to show the real regex and note explicitly that `_foil` and `liga_catalog_*` are rejected. No code
changes were needed — this was a documentation-only defect caught by QA's "diagrams reflect reality" check.

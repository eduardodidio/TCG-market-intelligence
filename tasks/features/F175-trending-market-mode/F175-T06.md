## Implementation details
- architecture: `flowchart TD` with Frontend (Trending.tsx, TrendingSection, api/trending.ts) → API
  (`market.py` gainers/losers, `collection_only`) → TrendingService (cache: success 30 min, empty 2 min,
  error = no cache) → Repository → `trending_queries.load_market_trending_prices` [source_cards ∪ liga_/manual_]
  or `get_trending_price_data_for_user` → `analytics.compute_trending_score/rank_trending`. Also the Dashboard ticker → market mode.
- journey: `flowchart LR` with subgraphs Usuário / Frontend / API+DB; decisions: authenticated?, toggle
  on?, query ok?, ranked empty?; error paths.

## User Story

As a trader, I want my trades and matches to filter and sort instantly, so that I navigate them like my collection.

## Objective

Create `utils/cardListFilter.ts` (filterCardList, sortCardList, buildSetOptions) and `utils/tradeSortOptions.ts`.

  **Do not edit `SortSelect.tsx`.**

## Acceptance criteria

- [ ] All functions are exported with the documented signatures. `npm run build` type-checks.
- [ ] Search is case- and accent-insensitive over name + namePt.
- [ ] Sorting is stable, puts nulls last in both directions, and uses natural sort for collector numbers ('2' < '10' < '10a').
- [ ] `buildSetOptions` is de-duplicated, returns lowercase values and uppercase labels, and is sorted.
- [ ] No sort option `sortBy` contains '-'.
- [ ] 100% line coverage for `cardListFilter.ts`.

## Testing

- Vitest: `cd frontend && npx vitest run src/utils/__tests__/cardListFilter.test.ts`.
- Then `cd frontend && npm test` (no new failing files versus the baseline).
- Use plain object fixtures, with no mocks needed.

## Test scenarios

- Happy: filter by 'bolt' + set 'M11' on mixed items, then sort by price desc.
- Edge: 'Relâmpago' matches the search 'relampago'. set/number/price null. Empty array. Input array identity unchanged after sort.
- Error: unknown sortBy → copy in the original order. The `status` filter with an accessor missing → ignored.
- Boundary: a single item. All-equal keys keep the input order (stability). Numbers '1','2','10','10a','★'.

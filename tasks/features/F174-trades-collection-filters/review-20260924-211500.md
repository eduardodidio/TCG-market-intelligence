**Required fix before re-review:** T06's `TradeCard.tsx` broke
`frontend/tests/components/TradeCard.test.tsx` (a pre-existing test file
this feature does not own) by switching the status badge from a raw
lowercase string to a translated, capitalized label. This is a real,
reproducible new test-file failure that the AC7 gate ("no new failing
test file") exists specifically to catch — it just wasn't caught because
the wave summaries compared failure *counts*, not failure *file names*, and
the total happened to stay at 13 by coincidence (an unrelated flaky file
flipped from failing to passing in the same run). Fix the test or the
component's DOM output, re-run `cd frontend && npm test`, and diff the
failing-file names (not just the count) against the pre-F174 baseline
before resubmitting.

Everything else in the feature — the backend query module, the two new
endpoints, the shared `CardFilterBar`/`useCardListFilters` kit, the three
trade pages, the MyCollection adoption, and the docs — is solid and ready
to ship once this one regression is closed.

## Retrospective Seeds

- **Pattern:** Wave summaries validated the AC7-style "no new failing test
  file" gate by comparing the *count* of failing files, not the *list of
  names*. A regression can hide behind an unrelated flaky test flipping in
  the opposite direction in the same run, keeping the count stable while a
  real regression slips through.
  **Role(s) affected:** developer, techlead
  **Lesson:** whenever an AC defines a "no new failures" gate, diff the
  actual sorted list of failing file names against a clean baseline run
  (e.g. a throwaway git worktree at the pre-feature commit), not just the
  reported count.
- **Pattern:** A component rewrite (T06) that changes rendered text (raw
  value → i18n-translated label) can silently break duplicate/legacy test
  files that live in a different test directory (`frontend/tests/` vs
  `frontend/src/**/__tests__/`) and therefore aren't discovered by grepping
  for the component's "owned" test file.
  **Role(s) affected:** developer
  **Lesson:** before rewriting a shared component's rendered output, grep
  the whole test tree (both `frontend/tests/` and `frontend/src/**/__tests__/`)
  for the component's name/testids, not just the test file the task
  explicitly lists as touched.

# F143-T01 — Increase useApi debounce + add debounce to useOwnedCardIds

**Status:** pending
**Wave:** 0
**Depends on:** --

## Objective

Prevent quick alt-tab from triggering API re-fetches by increasing the
staleness threshold from 30 seconds to 120 seconds across all visibility
change handlers.

## Changes

### 1. `frontend/src/hooks/useApi.ts`

- Change `REFETCH_DEBOUNCE_MS` from `30_000` to `120_000` (line 17).
- That single constant change propagates to all `refetchOnFocus: true`
  consumers (Dashboard health, Dashboard summary, CollectionCardDetail).

### 2. `frontend/src/hooks/useOwnedCardIds.ts`

- Add a `lastFetchedAtRef = useRef(0)` (similar to useApi pattern).
- Set `lastFetchedAtRef.current = Date.now()` after successful fetch.
- In the `visibilitychange` handler, check elapsed time against 120_000ms
  before calling `load()`.
- This prevents the hook from fetching 9999 cards on every single alt-tab.

## Acceptance Criteria

- [ ] `REFETCH_DEBOUNCE_MS` is 120000 in useApi.ts.
- [ ] `useOwnedCardIds` only re-fetches if >120s have elapsed since last fetch.
- [ ] Existing tests pass (`cd frontend && npm test`).
- [ ] Add/update unit tests for the debounce behavior in both hooks.

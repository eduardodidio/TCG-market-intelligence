# F71-T04 — i18n Type Line + Card Text

**Status:** planned
**Wave:** 1
**Depends on:** T01

## User Story

As a user viewing the treasure token card in Portuguese, I want the card's type line and rules text to be in Portuguese ("Token Artefato — Tesouro"), matching the card language, so the experience is fully localized.

## Dev Notes

1. **Add i18n keys to `frontend/src/i18n/locales/en.json`** under `credits`:
   ```json
   "tokenTypeLine": "Token Artifact — Treasure",
   "tokenRulesText": "Tap, Sacrifice this artifact: Add one mana of any color."
   ```

2. **Add i18n keys to `frontend/src/i18n/locales/pt-BR.json`** under `credits`:
   ```json
   "tokenTypeLine": "Token Artefato — Tesouro",
   "tokenRulesText": "Tap, sacrifique este artefato: Adicione um mana de qualquer cor."
   ```

3. **Update `TreasureTokenCard.tsx`** (coordinated with T02):
   - Type line div: replace `"Token Artifact — Treasure"` with `{t("credits.tokenTypeLine")}`
   - Text box div: replace the hardcoded English quote with `{t("credits.tokenRulesText")}`

## Testing

# F71-T01 — Asset Setup + Image Utility Hook

**Status:** planned
**Wave:** 0
**Depends on:** —

## User Story

As a developer, I need the treasure token images available as Vite-importable assets and a reusable hook to select the correct image based on the current language, so that all treasure components can use real card art.

## Dev Notes

1. **Copy images** from `images/` to `frontend/src/assets/`:
   - `images/treasure.jpg` -> `frontend/src/assets/treasure.jpg`
   - `images/tesouro.png` -> `frontend/src/assets/tesouro.png`

2. **Create `frontend/src/hooks/useTreasureImage.ts`**:
   ```typescript
   import { useContext } from 'react';
   import { LanguageContext } from '../contexts/LanguageContext';
   import treasureEn from '../assets/treasure.jpg';
   import tesouroPt from '../assets/tesouro.png';

   export function useTreasureImage(): string {
     const ctx = useContext(LanguageContext);
     const lang = ctx?.language ?? 'en';
     return lang === 'en' ? treasureEn : tesouroPt;
   }
   ```

3. **Vite asset handling**: Vite automatically resolves `import` of image files to hashed URLs. No config changes needed.

4. If `frontend/src/assets/` doesn't have a Vite asset declaration file, ensure `*.jpg` and `*.png` are covered by `vite-env.d.ts` or a custom `assets.d.ts`:
   ```typescript
   declare module '*.jpg' { const src: string; export default src; }
   declare module '*.png' { const src: string; export default src; }
   ```

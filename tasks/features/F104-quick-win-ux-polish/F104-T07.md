# F104-T07: Skeleton Loading for Card Images

**Wave:** 1
**Depends on:** none
**Estimated effort:** small

## User Story

As a user scrolling through card grids, I want to see a pulsing
placeholder animation while card images load, so that the layout
doesn't jump and the experience feels polished.

## Dev Notes

### Approach

Replace the current blank gradient placeholder (shown while images
load) with a skeleton animation that matches the card's aspect ratio.

### Changes to `CardTile.tsx`

Currently: image has `loading="lazy"` and falls back to a static SVG
icon on error. While loading, the gradient background is visible but
static.

New behavior:
1. Add `useState<boolean>(false)` for `imageLoaded`
2. Show a pulsing skeleton overlay (`animate-pulse bg-slate-700`)
   positioned absolutely over the image area
3. On `<img onLoad>`, set `imageLoaded = true` and hide the skeleton
4. On error, show the existing SVG fallback (no skeleton)
5. Smooth fade-in transition when image appears (opacity 0→1, 200ms)

### Changes to `CatalogCardTile` (in CatalogPage.tsx)

Same pattern as CardTile.

### Changes to `CollectionCardTile` (in MyCollection.tsx)

Same pattern as CardTile.

### Shared helper (optional)

Consider extracting a `CardImage` wrapper component that encapsulates:
- Image src with error fallback
- Skeleton overlay while loading
- Fade-in transition
- `loading="lazy"` attribute

This avoids duplicating the loading state logic in 3 tile components.

### Files to create (optional)

- `frontend/src/components/CardImage.tsx` — shared image wrapper

### Files to modify

- `frontend/src/components/CardTile.tsx` — add skeleton loading state
- `frontend/src/pages/CatalogPage.tsx` — add skeleton to CatalogCardTile
- `frontend/src/pages/MyCollection.tsx` — add skeleton to CollectionCardTile

### CSS

- Use existing `animate-pulse` from Tailwind (already used in Skeleton.tsx)
- Fade-in: `transition-opacity duration-200`

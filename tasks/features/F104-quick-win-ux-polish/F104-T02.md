# F104-T02: PriceSparkline Component + Integration

**Wave:** 1
**Depends on:** T01 (batch price trends endpoint)
**Estimated effort:** medium

## User Story

As a user browsing my collection or the catalog, I want to see a tiny
inline price trend chart next to each card's price, so I can quickly
identify cards that are rising or falling in value without clicking
into each one.

## Dev Notes

### Component: `PriceSparkline`

Reuse the existing `DeckSparkline` component pattern (Recharts
`LineChart` in a `ResponsiveContainer`). Create a thin wrapper
`PriceSparkline` that:

1. Accepts `cardId: number` and optional `prices: number[]`
2. If `prices` not provided, fetches from the batch trends hook
3. Renders a 60x24px sparkline (green if up, red if down, gray if flat)
4. Shows nothing gracefully if no data (empty div, same dimensions)

### Hook: `usePriceTrends`

- Batch-fetches price trends for visible card IDs
- Caches results in a React context or simple Map to avoid re-fetching
- Accepts array of card_ids, calls `fetchPriceTrends` from T01
- Debounced to avoid rapid calls during scroll

### Integration points

- `CardTile.tsx` — add sparkline below the price
- `CatalogCardTile` (in `CatalogPage.tsx`) — add sparkline below price
- `CollectionCardTile` (in `MyCollection.tsx`) — add sparkline below price
- Only render when card has a `latest_price` (no sparkline for unpriced)

# F104-T05: Set Completion Progress Bar

**Wave:** 1
**Depends on:** none
**Estimated effort:** small

## User Story

As a collector, I want to see a progress bar showing how many cards
I own from each set versus the total cards in that set, so I can
track my collection completion at a glance.

## Dev Notes

### Component: `SetCompletionBar`

```tsx
interface SetCompletionBarProps {
  setCode: string;
  setName: string;
  owned: number;
  total: number;
}
```

- Horizontal progress bar with `owned/total` label
- Color: gradient from slate to cyan as completion increases
- Full completion (100%) gets a gold/amber highlight
- Compact design: fits in a single row

### Data source

The MyCollection page already fetches `fetchCollectionSets()` which
returns set info. We need to cross-reference with catalog data to
get total cards per set.

**Approach:** Add a new lightweight endpoint or extend existing:
- `GET /api/collection/set-completion` — returns array of
  `{ set_code, set_name, owned_count, total_in_set }` where
  `total_in_set` comes from the catalog (cards table COUNT by set_code)
- Only return sets where user owns at least 1 card

### Integration

- `MyCollection.tsx` — add a collapsible "Set Completion" section
  above the card grid, showing `SetCompletionBar` for each set
- Sort by completion percentage (highest first) or alphabetically
- Toggle to show/hide this section (persist in localStorage)

# F104-T03: TrendBadge Component (Arrow + % Change)

**Wave:** 1
**Depends on:** T01 (batch price trends endpoint)
**Estimated effort:** small

## User Story

As a user viewing card prices, I want to see a small arrow indicator
(up/down) with the percentage change next to the price, so I can
instantly tell if a card's value is trending up or down.

## Dev Notes

### Component: `TrendBadge`

```tsx
interface TrendBadgeProps {
  changePct: number | null;
  size?: "sm" | "md";
}
```

- `changePct > 0`: green up-arrow + `+X.X%`
- `changePct < 0`: red down-arrow + `-X.X%`
- `changePct === 0`: gray dash + `0.0%`
- `changePct === null`: render nothing (no data)
- Sizes: `sm` (text-xs, for card tiles), `md` (text-sm, for detail pages)
- Use inline SVG arrows (no icon library dependency)
- Color-blind safe: use shape (arrow direction) as primary indicator,
  color as secondary

### Integration points

- `CardTile.tsx` — next to price, inline with `PriceSparkline`
- `CatalogCardTile` — next to price
- `CollectionCardTile` — next to price
- `CardDetail.tsx` — next to main price display
- Data source: `change_pct` from the `usePriceTrends` hook (T02)

# F104-T08: Sticky Filter Bar + Scroll Position Retention

**Wave:** 1
**Depends on:** none
**Estimated effort:** small

## User Story

As a user scrolling through large card grids, I want the filter/search
bar to stay visible at the top of the viewport, so I can adjust filters
without scrolling back up. Additionally, when I navigate to a card
detail page and press Back, I want to return to my previous scroll
position.

## Dev Notes

### Sticky Filter Bar

**Pages affected:** CatalogPage, MyCollection, Cards (explore)

**Approach:**
- Wrap the search + filter section in a `<div>` with:
  ```
  className="sticky top-0 z-10 bg-slate-900/95 backdrop-blur-sm
             pb-4 -mx-6 px-6 pt-2 border-b border-slate-700/50"
  ```
- The `bg-slate-900/95 backdrop-blur-sm` creates a frosted glass effect
  so content scrolling behind is subtly visible
- `-mx-6 px-6` extends the background to full width (compensating for
  parent padding)
- `z-10` ensures it stays above card grid content

**MyCollection specifics:**
- The search bar, sort select, grid size toggle, and set filter are all
  in the sticky zone
- KPI cards and scan summary stay above (scroll away)

**CatalogPage specifics:**
- Search bar + filter toggle button are sticky
- The collapsible filter panel expands below the sticky bar

### Scroll Position Retention

**Approach:** Custom hook `useScrollRestoration`

```tsx
function useScrollRestoration(key: string) {
  // On mount: restore scroll position from sessionStorage
  // On unmount/navigation: save current scroll position
}
```

- Use `sessionStorage` (not localStorage) — cleared on tab close
- Key format: `scroll_${pathname}` (e.g., `scroll_/collection`)
- Save scroll position on the `<main>` element (from Layout.tsx),
  not window (since main is the scrolling container)
- Restore after content has rendered (use `requestAnimationFrame`
  or small delay to wait for DOM paint)
- Only restore on browser back/forward navigation (not on fresh
  navigation to the page). Detect via `window.history.state` or
  a navigation type check.

# F104-T04: CardHoverPreview Component

**Wave:** 1
**Depends on:** none
**Estimated effort:** medium

## User Story

As a user browsing card lists, I want to hover over a card name (desktop)
or long-press a card tile (mobile) to see an enlarged preview of the
card image, so I can identify cards visually without navigating away
from the list.

## Dev Notes

### Component: `CardHoverPreview`

A floating overlay that shows the full card image when triggered:

**Desktop behavior:**
- On `mouseenter` of a card tile/row, show a floating panel with the
  card image at ~300px width, positioned near the cursor
- On `mouseleave`, hide the panel
- Delay: 200ms before showing (avoid flicker on quick mouse movements)
- Position: right of cursor if space allows, left if near right edge

**Mobile behavior:**
- On `touchstart` with 500ms hold (long-press), show the preview
- On `touchend` or `touchmove` (>10px), dismiss
- Must NOT interfere with normal tap (navigation) or scroll
- Show a semi-transparent backdrop on mobile

### Hook: `useCardHoverPreview`

```tsx
const { previewProps, PreviewOverlay } = useCardHoverPreview();
// previewProps = { onMouseEnter, onMouseLeave, onTouchStart, onTouchEnd, ... }
```

Returns event handlers to spread on the trigger element, plus a portal
component for the overlay.

### Integration

- Wrap `CardTile`, `CatalogCardTile`, and `CollectionCardTile` image
  areas with hover/long-press handlers
- The overlay renders via React portal (appended to body) to avoid
  z-index/overflow issues
- Image URL: reuse the same Scryfall URL already computed in each tile

- Dismiss on scroll (mobile)

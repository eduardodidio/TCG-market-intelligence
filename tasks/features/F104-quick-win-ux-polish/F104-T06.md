# F104-T06: ArbitrageBadge Component

**Wave:** 1
**Depends on:** none
**Estimated effort:** small

## User Story

As a user comparing prices, I want to see a visual indicator showing
which price source (Liga or TCG) is cheapest and the percentage
difference, so I can make informed purchasing decisions.

## Dev Notes

### Component: `ArbitrageBadge`

```tsx
interface ArbitrageBadgeProps {
  ligaPrice: number | null;
  tcgPrice: number | null;
  currency?: string;
}
```

**Rendering logic:**

- If both prices exist:
  - Show "Best: Liga -X%" or "Best: TCG -X%" (whichever is lower)
  - Green badge for the cheaper source
  - Tooltip with both prices displayed
- If only one price: show "Liga only" or "TCG only" in neutral gray
- If no prices: render nothing

**Gap calculation:**
- `gap_pct = ((higher - lower) / higher) * 100`
- Display with 1 decimal: e.g., "-15.3%"

### Data source

The `CollectionCardDetail` interface already has `price_history` with
`median_price` (Liga) and `tcg_price` fields on each observation.
The `CardDetail` type also exposes `latest_price`.

For card tiles in list views, we need the tcg_price. Options:
1. Extend `CardSummary` / `CollectionCard` types to include `tcg_price`
   (requires backend change to include tcg_price in list endpoints)
2. Use the price trends batch endpoint (T01) to also return latest
   tcg_price — lighter touch

**Recommended:** Option 1, extend collection/cards list responses to
include `tcg_price` field (nullable). This is a simple JOIN that's
already done for the detail view.

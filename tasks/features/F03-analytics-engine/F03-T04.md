## User Story

As a CLI user, I want to run `python -m src.cli.main analyze <card_id>`
to see market indicators for a card, so that I can make informed decisions.

## Objective

Add an `analyze` command group to the Click CLI with subcommands for
single-card analysis and listing analyzable cards.

## Dev Notes

- File: `src/cli/main.py`
- Follow existing CLI pattern: `@cli.command()` with `@click.option()`.
- Lazy imports inside the command function (same pattern as `backfill`).
- The flow is: CLI -> Repository.get_price_series() -> analytics functions -> print results.

### Commands to add

1. **`analyze card <external_id>`**
   - `--db` option (default: `sqlite:///tcg_market.db`)
   - `--source` option (default: `myp`)
   - `--price-field` option (default: `median_price`)
   - Fetches price series, computes all analytics, prints formatted output
   - Output format: plain text table, one section per indicator type

2. **`analyze list`**
   - `--db` option
   - `--source` option (default: `myp`)
   - Lists all cards with observation counts (from `get_cards_with_observations`)

### Output format example

### F03-architecture.mmd

Component / data-flow diagram showing:
- CLI layer (`src/cli/main.py`) receives `analyze` command
- Repository layer (`src/database/repository.py`) fetches price series
- Analytics engine (`src/analytics/indicators.py`) computes indicators
- Domain models (`src/domain/models.py`) carry results
- Data flows: CLI -> Repository -> HistoricalPrice[] -> Analytics -> CardAnalytics -> CLI (print)

### F03-journey.mmd

User journey (BPMN-style flowchart LR) showing:
1. User runs `analyze list` to see available cards
2. User picks a card external_id
3. User runs `analyze card <id>`
4. System fetches data from SQLite
5. Decision: enough data? No -> show "insufficient data" message
6. Yes -> compute all indicators
7. Print formatted results

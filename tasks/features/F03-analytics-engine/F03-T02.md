# Task F03-T02 — Repository Price Series Queries

**Feature:** F03
**Wave:** 0
**Type:** backend
**Depends on:** (none)
**Maps to AC:** AC4
**Status:** planned

## User Story

As an analytics engine, I want to fetch ordered price time-series from
the database for a given card, so that I can compute indicators over them.

## Objective

Add query methods to `src/database/repository.py` that return price
observations as a list of `HistoricalPrice` domain objects, ordered by date.

## Dev Notes

- File: `src/database/repository.py`
- Follow existing pattern: methods on the `Repository` class, using
  `Session(self.engine)` context managers.
- Return domain objects (`HistoricalPrice`), not ORM rows -- keep the
  analytics engine decoupled from SQLAlchemy.
- The `PriceObservationRow` table has columns: source, external_id,
  observed_at, median_price, tcg_price, last_sold_price, quantity_available.
- `HistoricalPrice` dataclass is already defined in `src/domain/models.py`.

### Methods to add

1. **`get_price_series(source: str, external_id: str, days: int | None = None) -> list[HistoricalPrice]`**
   - Returns observations ordered by `observed_at ASC`
   - If `days` is set, filter to last N days from today
   - Maps `PriceObservationRow` fields to `HistoricalPrice`

2. **`get_cards_with_observations(source: str) -> list[tuple[str, int]]`**
   - Returns list of (external_id, observation_count) for cards that have data
   - Useful for the CLI to list analyzable cards

## User Story

As a market analyst, I want to see moving averages, ATH/ATL, volatility,
and momentum indicators for a card, so that I can understand price trends,
assess risk, and predict short-term direction.

## Objective

Implement all pure analytics functions in a single `src/analytics/indicators.py`:
moving averages, price extremes, volatility, momentum, and the orchestrator.

## Dev Notes

- File: `src/analytics/indicators.py` (new, in scaffolded package from T01)
- Pure functions -- take `list[HistoricalPrice]` as input, return domain
  model objects from F03-T01.
- Use `Decimal` arithmetic throughout -- no floats for price math.
- The `HistoricalPrice` dataclass has: median_price, tcg_price,
  last_sold_price -- analytics should work on any of these fields
  via a `price_field` parameter (default: `"median_price"`).
- Handle None values in price fields gracefully (skip them).
- For standard deviation: use the population formula (not sample).
- For `Decimal` sqrt: use `value.sqrt()` with proper decimal context.

### Functions to implement

1. **`compute_moving_average(prices, period, price_field) -> MovingAverage | None`**
   - Simple moving average of the last `period` observations
   - Returns None if fewer than `period` non-None values exist

2. **`compute_all_moving_averages(prices, periods=[7,30,90], price_field) -> list[MovingAverage]`**
   - Convenience: computes MAs for standard periods, skips insufficient data

3. **`compute_price_extremes(prices, price_field) -> PriceExtremes | None`**
   - Finds ATH and ATL with their dates
   - Returns None if no valid price data

4. **`compute_volatility(prices, period_days=None, price_field) -> Volatility | None`**
   - Standard deviation + coefficient of variation (std_dev / mean)
   - Returns None if fewer than 2 valid prices

5. **`compute_momentum(prices, period_days=7, price_field) -> Momentum | None`**
   - Rate of change = (current - past) / past as percentage
   - Trend direction: "up" if RoC > 1%, "down" if RoC < -1%, "flat" otherwise

6. **`compute_card_analytics(prices, source, external_id) -> CardAnalytics`**
   - Orchestrator: calls all functions, assembles CardAnalytics
   - Default periods: MA [7, 30, 90], volatility 30d, momentum 7d

## Test Scenarios

- **Happy path:** 30 daily prices, compute MA(7), MA(30) -- verify values
- **Happy path:** 30 prices with known std_dev, verify volatility
- **Happy path:** Price went from 10 to 12 over 7 days -- RoC = 20%, trend = "up"
- **Edge case:** All prices are the same -- MA equals that price, ATH == ATL, std_dev = 0, RoC = 0%, trend = "flat"
- **Edge case:** Some prices are None -- skipped correctly
- **Edge case:** Empty price list -- returns None
- **Edge case:** Only 1 valid price -- volatility returns None
- **Boundary values:** Exactly `period` data points (MA computable)
- **Boundary values:** `period - 1` data points (MA returns None)
- **Boundary values:** RoC exactly 1% -- trend = "flat" (threshold is exclusive)
- **Boundary values:** RoC exactly -1% -- trend = "flat"
- **Error scenario:** All prices None -- returns None

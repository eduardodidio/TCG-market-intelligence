## User Story

As a developer, I want well-defined dataclasses for analytics results,
so that computation outputs have a clear contract and are easy to serialize.

## Objective

Add analytics result dataclasses to `src/domain/models.py` and scaffold
the `src/analytics/` package directory for Wave 1.

## Dev Notes

- File: `src/domain/models.py`
- Scaffold: create `src/analytics/__init__.py` (empty, for Wave 1)
- Follow existing pattern: plain `@dataclass` with type hints, `Decimal`
  for prices, `date` for timestamps.
- No imports from database or analytics modules -- these are pure domain objects.
- Use `from __future__ import annotations` (already present in file).

### Models to add

1. **`MovingAverage`** -- period (int), value (Decimal), price_field (str),
   calculated_at (date)
2. **`PriceExtremes`** -- ath_price (Decimal), ath_date (date),
   atl_price (Decimal), atl_date (date), price_field (str)
3. **`Volatility`** -- period_days (int), std_dev (Decimal),
   coefficient_of_variation (Decimal), price_field (str)
4. **`Momentum`** -- period_days (int), rate_of_change (Decimal),
   trend_direction (str: "up"/"down"/"flat"), price_field (str)
5. **`CardAnalytics`** -- composite: external_id (str), source (str),
   moving_averages (list[MovingAverage]), extremes (PriceExtremes | None),
   volatility (Volatility | None), momentum (Momentum | None),
   computed_at (datetime)

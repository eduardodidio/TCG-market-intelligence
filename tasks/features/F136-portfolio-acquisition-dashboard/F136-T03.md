**Wave:** 1 (Frontend Dashboard & Collection)

**Depends on:** T01, T02 (backend filters and summary fields must exist)
**Status:** planned

## User Story

As an investor, when I open the main Dashboard I want to see my portfolio
performance at a glance -- total invested, current value, P&L, P&L% -- along
with a mini sparkline of portfolio value over time, and a clear alert telling me
how many cards still need acquisition prices, so I can act on it immediately.

## Dev Notes

### Existing Components

The `DashboardInvestmentSummary` component (`frontend/src/components/
DashboardInvestmentSummary.tsx`) already shows the 4 KPI cards (invested,
current, P&L, P&L%) plus a progress bar. This task extends it with:

1. **P&L sparkline** -- a mini Recharts LineChart showing portfolio value over
   the last 90 days, rendered below the KPI row.
2. **Missing-price alert** -- an amber banner below the sparkline showing
   "X cards without acquisition price" with a link to the filtered collection.

### DashboardInvestmentSummary changes

**Add portfolio history fetch**: call `fetchPortfolioHistory(90)` alongside the
existing `fetchPortfolioSummary()` in a `Promise.all`.

**P&L sparkline**: render a compact `LineChart` (height ~80px, no axes labels,
minimal grid) using `history` data. Use cyan stroke for the line, no dots. Only
render when `history.length > 1`. This is deliberately smaller and simpler than
the full chart in `PortfolioDashboard` -- it is a "glanceable" sparkline.

```tsx
<ResponsiveContainer width="100%" height={80}>
  <LineChart data={history}>
    <Line type="monotone" dataKey="value" stroke="#22d3ee" strokeWidth={1.5} dot={false} />
  </LineChart>
</ResponsiveContainer>
```

**Missing-price alert**: use the new `cards_without_acquisition` field from
`PortfolioSummary`. When > 0, render an amber alert:

```tsx
{data.cards_without_acquisition > 0 && (
  <Link
    to="/collection?has_acquisition_price=false"
    className="..."
  >
    <WarningIcon />
    {t("dashboard.cardsWithoutAcquisition", { count: data.cards_without_acquisition })}
    <ChevronRight />
  </Link>
)}
```

### Types: `frontend/src/types/api.ts`

Update `PortfolioSummary` type to include:
```ts
cards_without_acquisition: number;
```

### i18n keys (en.json, pt.json)

- `dashboard.cardsWithoutAcquisition`: "{{count}} cards without acquisition price"
- `dashboard.cardsWithoutAcquisitionDesc`: "Add purchase prices to track your investment performance"

### Dashboard.tsx

No changes needed -- `DashboardInvestmentSummary` is already rendered on the
Dashboard page. The sparkline and alert will appear inside the existing component.

## Edge Cases

- No portfolio history (< 2 points): hide the sparkline entirely.
- `cards_without_acquisition=0`: hide the alert.
- All cards lack acquisition price: show alert but with appropriate wording
  (the component already handles `invested_card_count=0` with an empty state).
- Loading state: show skeleton for sparkline area too.
- Error fetching history: sparkline section gracefully hidden (do not break the
  KPI cards).

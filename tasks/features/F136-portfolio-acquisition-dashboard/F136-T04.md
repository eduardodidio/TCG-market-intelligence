# F136-T04: Frontend -- Collection Filter: Acquisition-Price Filter Chips + Deep Link

**Wave:** 1 (Frontend Dashboard & Collection)
**Parallel with:** T03
**Depends on:** T01 (backend `has_acquisition_price` filter must exist)
**Status:** planned

## User Story

As a collector, I want to filter my collection view to show only cards with or
without acquisition prices, so I can quickly find cards that need cost basis data
and update them. When I click the alert on the Dashboard, it should navigate
directly to the collection with the "without price" filter pre-applied.

## Dev Notes

### MyCollection.tsx changes

**State**: add `acquisitionFilter` state, initialized from URL search param:

```tsx
const [acquisitionFilter, setAcquisitionFilter] = useState<"all" | "with" | "without">(
  () => {
    const param = searchParams.get("has_acquisition_price");
    if (param === "true") return "with";
    if (param === "false") return "without";
    return "all";
  }
);
```

**URL sync**: update the `useEffect` that syncs URL params to include
`has_acquisition_price` when filter is active:

```tsx
if (acquisitionFilter === "with") params.has_acquisition_price = "true";
if (acquisitionFilter === "without") params.has_acquisition_price = "false";
```

**API params**: update `buildParams()` to pass the filter:

```tsx
if (acquisitionFilter === "with") params.has_acquisition_price = "true";
if (acquisitionFilter === "without") params.has_acquisition_price = "false";
```

**Filter chip UI**: add a 3-state toggle chip group below (or alongside) the
existing set filter. Use the same visual style as existing filter chips:

```
[All] [With acquisition price] [Without acquisition price]
```

Keep it compact -- on mobile the labels can be shortened:
- "All" / "With price" / "Without price"

Place the filter chips after the set icon filter and before the action buttons
row (or in the same sticky filter bar area). Use a subtle separator or label
`Investment filter:` to distinguish from the set filter.

**Reset**: `handleClearFilters()` should also reset `acquisitionFilter` to "all".

**Deep link**: when user clicks the Dashboard alert (`/collection?has_acquisition_price=false`),
the URL param is read on mount and sets `acquisitionFilter="without"`, which
triggers the fetch with the backend filter.

### Refresh on filter change

Add `acquisitionFilter` to the dependency array of the `useEffect` that fetches
collection cards (the one at line ~597 that watches `debouncedSearch`,
`selectedSet`, etc.). This ensures the list re-fetches when the filter changes.

### i18n keys (en.json, pt.json)

- `collection.filterAcquisitionAll`: "All"
- `collection.filterAcquisitionWith`: "With price"
- `collection.filterAcquisitionWithout`: "Without price"
- `collection.filterAcquisitionLabel`: "Investment"

### Edge Cases

- Deep link from Dashboard with `has_acquisition_price=false`: filter chip
  should be visually active on "Without price".
- Changing set filter while acquisition filter is active: both filters stack.
- Clearing all filters resets acquisition filter to "All".
- No cards match "Without price": show existing empty state with clear-filters
  action.
- Browser back/forward: URL params correctly restore the filter state.

## Testing

### Frontend unit tests (`frontend/src/pages/MyCollectionAcquisitionFilter.test.tsx`)

1. Filter chips render with "All" active by default.
2. Clicking "Without price" updates URL to `?has_acquisition_price=false`.
3. Clicking "With price" updates URL to `?has_acquisition_price=true`.
4. Clicking "All" removes `has_acquisition_price` from URL.
5. Initializing with `?has_acquisition_price=false` in URL sets "Without price"
   as active.
6. Clear filters resets acquisition filter to "All".
7. `buildParams()` includes `has_acquisition_price` when filter is active.
8. `buildParams()` omits `has_acquisition_price` when filter is "All".

### Integration (manual)

1. Navigate to `/collection?has_acquisition_price=false` -- only cards without
   acquisition price are shown.
2. Click "With price" chip -- list updates to show only investment-tracked cards.
3. Click "All" -- full collection shown again.
4. Dashboard missing-price alert -> collection with correct filter.
5. Filter persists through infinite scroll (load more pages).
6. Filter works combined with search term and set filter.

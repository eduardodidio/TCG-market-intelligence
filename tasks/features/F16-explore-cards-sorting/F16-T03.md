# Task F16-T03 — Frontend SortSelect component

**Feature:** F16
**Wave:** 2
**Type:** frontend
**Depends on:** none
**Status:** planned

## User Story

As a user, I want a dropdown to choose how my collection cards are sorted,
so I can find cards more easily.

## Objective

Create a reusable `SortSelect` component that renders a styled dropdown
with predefined sort options and emits `(sortBy, sortDir)` on change.

## Dev Notes

- Relevant files:
  - `frontend/src/components/` — existing components (SearchBar, FilterChips)
  - `frontend/src/pages/MyCollection.tsx` — will consume this component (T04)

- Component: `SortSelect`
- Props:
  ```typescript
  interface SortOption {
    label: string;      // e.g. "Name (A-Z)"
    sortBy: string;     // e.g. "name"
    sortDir: "asc" | "desc";
  }

  interface SortSelectProps {
    options: SortOption[];
    value: string;       // composite key like "name-asc"
    onChange: (sortBy: string, sortDir: "asc" | "desc") => void;
  }
  ```

- Predefined sort options (defined as a constant, exported for reuse):
  ```typescript
  export const COLLECTION_SORT_OPTIONS: SortOption[] = [
    { label: "Name (A-Z)", sortBy: "name", sortDir: "asc" },
    { label: "Name (Z-A)", sortBy: "name", sortDir: "desc" },
    { label: "Set", sortBy: "set", sortDir: "asc" },
    { label: "Card Number", sortBy: "number", sortDir: "asc" },
    { label: "Date Added (Newest)", sortBy: "added", sortDir: "desc" },
    { label: "Date Added (Oldest)", sortBy: "added", sortDir: "asc" },
    { label: "Price (High-Low)", sortBy: "price", sortDir: "desc" },
    { label: "Price (Low-High)", sortBy: "price", sortDir: "asc" },
  ];
  ```

- Styling: match existing Tailwind dark theme (slate-800 bg, cyan accents).
  Use a native `<select>` element styled with Tailwind for simplicity.
  Add an icon (sort arrows) before the select if desired.

- The composite value (e.g. `"name-asc"`) is used as the `<option>` value
  to avoid two-select complexity.

## Implementation details

- On change, parse the composite value back to `(sortBy, sortDir)` and
  call `onChange`

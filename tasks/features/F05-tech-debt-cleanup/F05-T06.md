## Dev Notes

### 1. `docs/diagrams/F04-architecture.mmd`

Mermaid flowchart showing:
- `backfill.py` orchestrator with `asyncio.Semaphore` concurrency
- `repository.py` batch upsert (INSERT ON CONFLICT DO NOTHING)
- Resume flow: DB check -> skip already-collected cards
- Connection to provider and database layers

### 2. `docs/diagrams/F04-journey.mmd`

BPMN-style user journey:
1. User runs `backfill --set <slug> --concurrency N`
2. System discovers cards
3. System checks DB for already-collected (resume)
4. System processes remaining cards concurrently (semaphore)
5. Each card: fetch details + history -> batch upsert
6. On error: log + continue (error isolation)
7. Summary with counts (collected, skipped, failed)

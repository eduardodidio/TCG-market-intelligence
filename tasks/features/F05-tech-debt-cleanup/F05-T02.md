## Dev Notes

### Current gaps (63% coverage, 43 lines missed)

### Approach

Create `tests/unit/test_provider.py`:

1. **Mock `AsyncSession`** — patch `curl_cffi.requests.AsyncSession` to return
   canned HTML responses. Do NOT make real HTTP calls.
2. **Use `pytest-asyncio`** for async test functions.
3. **Set `delay_seconds=0`** in `MypConfig` to avoid sleeps in tests.
4. **Test `_fetch`**:
   - Happy path: returns `resp.text` on 200
   - 429 retry: returns 429 then 200
   - 403 retry: returns 403 then 200
   - Generic 4xx/5xx: raises `RuntimeError` after max retries
   - Timeout/OSError: raises after max retries
   - Exhausted retries (final `raise RuntimeError`)
5. **Test `discover_sets`**: mock _fetch to return HTML with set links +
   pagination, verify returned slugs
6. **Test `discover_cards`**: mock _fetch for set page with card links,
   verify `SourceCard` list
7. **Test `_discover_cards_in_set`**: multi-page with dedup
8. **Test `get_card_details`**: mock _fetch, verify parse_card_page called
9. **Test `get_current_price`**: mock _fetch, verify parse_price_snapshot called
10. **Test `get_price_history`**: mock _fetch, verify parse_price_history called
11. **Test `close`**: verify session closed and set to None
12. **Test `source_name`**: returns "myp"

### Key patterns

```python
from unittest.mock import AsyncMock, patch, MagicMock

@pytest.fixture
def provider():
    config = MypConfig(delay_seconds=0, max_retries=2, timeout_seconds=1)
```

Use real HTML fixtures from `tests/fixtures/` if they exist, or create
minimal HTML that the parsers can handle.

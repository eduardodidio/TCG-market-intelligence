# F27-T03: Audit & fix currency param passing in all frontend API calls

**Status:** planned
**Wave:** 1
**Depends on:** none

## User Story

As a user, when I switch currency, all displayed prices should actually
convert to the selected currency, not just change the symbol.

## Dev Notes

### Audit results (pre-planning)

The frontend DOES pass `currency` in most API calls:
- `Cards.tsx` line 71: passes `currency` to `fetchCards()` -- OK
- `Dashboard.tsx` line 34: passes `currency` to `fetchMovers()` -- OK
- `Dashboard.tsx` line 39: passes `currency` to `fetchCollectionSummary()` -- OK
- `MarketMovers.tsx` line 29: passes `currency` to `fetchMovers()` -- OK
- `MyCollection.tsx` line 186: passes `currency` to `fetchCollectionSummary()` -- OK
- `CollectionCardDetail.tsx` line 37: passes `currency` to `fetchCollectionEntry()` -- OK

**Potential issue**: `fetchCards()` in `cards.ts` takes `params?: Record<string, string>`,
so currency IS passed. But the `CardTile` component formats with local `currency`
from context, which should match the API-returned currency. This is correct.

### Real root cause

The actual issue is likely that **no exchange rates are seeded in the DB**.
When `CurrencyConverter.convert()` can't find a rate, it returns `None`.

In `market.py` line 47: `converter.convert(g[3], today, currency) or g[3]`
- If convert returns `None`, the `or g[3]` fallback shows the BRL value
- This means USD shows BRL values with "$" symbol — looks like "only mask changes"

In `cards.py` line 77: `converter.convert(raw_price, ...) if raw_price else None`
- If convert returns `None`, the card shows no price at all

### Fix: ensure exchange rates are seeded on startup

**File:** `frontend/src/pages/Dashboard.tsx` (or App.tsx)
- No frontend fix needed per se — the issue is backend data

**File:** `src/api/app.py` (or startup hook)
- Option A: Auto-seed exchange rate on API startup (call BCB on boot)
- Option B: Add a note/warning in the dashboard when no rate available
- Option C: CLI `seed-exchange-rate` must be run as part of setup

**Recommended**: Option B + ensure `start.sh` includes `seed-exchange-rate`.

**File:** `start.sh`
- Add `python -m src.cli.main seed-exchange-rate --backfill-days 90` before server start

### Fix: converter fallback should not silently show wrong currency

**File:** `src/api/routers/market.py` lines 47-48
- When `converter.convert()` returns `None`, the fallback `or g[3]` is misleading
  because it shows BRL value under USD label
- Change to: if currency != "BRL" and convert returns None, set a flag or skip

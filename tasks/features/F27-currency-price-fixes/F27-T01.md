# F27-T01: Country flags for BRL/USD + PILA uppercase

**Status:** planned
**Wave:** 1
**Depends on:** none

## User Story

As a user, I want to see country flags (Brazil for BRL, US for USD) next to
currency indicators so I can visually distinguish currencies at a glance.
I also want PILA displayed in uppercase consistently.

## Dev Notes

### CurrencyIndicator — add flags

**File:** `frontend/src/components/CurrencyIndicator.tsx`

Currently BRL renders `<span>R$</span>` and USD renders `<span>$</span>`.
Add inline SVG flags (or emoji flags) alongside the symbol:

```tsx
// BRL: Brazil flag emoji + "R$"
// USD: US flag emoji + "$"
// PILA: RS flag SVG (already done)
```

**Approach**: Use emoji flags (most reliable cross-platform):
- BRL: render a small Brazil flag emoji or inline SVG before "R$"
- USD: render a small US flag emoji or inline SVG before "$"

Alternatively, create `br-flag.svg` and `us-flag.svg` in `frontend/src/assets/`
matching the pattern of `rs-flag.svg`. Use whichever approach is simpler and
consistent with the existing RS flag pattern (SVG imports).

# F27-T02: Exchange rate banner when USD selected

**Status:** planned
**Wave:** 1
**Depends on:** none

## User Story

As a user, when I select USD currency, I want to see the current exchange
rate at the top of the page (e.g., "USD 1 = BRL 5.42") so I know the
conversion basis. The base data is always stored in BRL.

## Dev Notes

### Backend — endpoint already exists

`GET /api/v1/exchange-rates/current` returns the latest PTAX rate.
No backend changes needed.

### Frontend — new ExchangeRateBanner component

**New file:** `frontend/src/components/ExchangeRateBanner.tsx`

- Only visible when `currency === "USD"` (from CurrencyContext)
- On mount/currency change: fetch `/api/v1/exchange-rates/current`
- Display: slim banner below the top nav or above page content
  - Format: "USD 1 = R$ {rate}" with date info
  - If no rate available: "Exchange rate unavailable"
- Style: `bg-slate-700/50 text-slate-300 text-xs py-1 px-4` — subtle, non-intrusive

### Frontend — add API helper

**New function in:** `frontend/src/api/market.ts` (or new `exchangeRates.ts`)

```typescript
export function fetchCurrentRate(): Promise<ApiResponse<ExchangeRateSchema>> {
  return apiGet("/api/v1/exchange-rates/current");
}
```

### Frontend — integrate banner in layout

**File:** `frontend/src/App.tsx` or layout wrapper

Add `<ExchangeRateBanner />` in the main layout, below the sidebar/nav.
It self-manages visibility based on currency context.

### Files to modify/create

1. `frontend/src/components/ExchangeRateBanner.tsx` — new component
2. `frontend/src/api/market.ts` (or `exchangeRates.ts`) — fetchCurrentRate
3. `frontend/src/types/api.ts` — ExchangeRateSchema type
4. `frontend/src/App.tsx` — include banner in layout

## Testing

- Unit: ExchangeRateBanner renders rate when currency=USD
- Unit: ExchangeRateBanner hidden when currency=BRL or PILA
- Unit: shows fallback message when no rate available
- Integration: verify API call is made on currency change to USD

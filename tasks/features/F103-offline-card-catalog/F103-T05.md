# F103-T05 — Adapt liga_sweep for catalog-mode

**Status:** planned
**Wave:** 1
**Depends on:** T01, T03

## User Story

Como operador, quero poder escanear preços Liga para cartas do catálogo
(que não estão na minha coleção), usando a mesma infraestrutura de sweep
existente.

## Acceptance Criteria

- [ ] `run_liga_sweep()` aceita novo parâmetro `collection_only=True` (default,
  mantém comportamento atual)
- [ ] Quando `collection_only=False`, busca cards da tabela `cards` + `source_cards`
  ao invés de `user_collection`
- [ ] Novo método no Repository: `get_catalog_cards_for_liga_scan(set_codes, max_age_days, limit)`
  que retorna cards do catálogo sem preço Liga recente
- [ ] A query filtra:
  - `cards.game = 'magic'`
  - `source_cards.source = 'liga'`
  - LEFT JOIN com `price_observations` para encontrar cards sem preço ou preço velho
  - `set_codes` filter (obrigatório para catalog mode)
- [ ] O retorno tem o mesmo formato dict que `get_cards_for_liga_scan` usa
  (name_en, card_id, set_code, collector_number, extras=None)

## Dev Notes

- O `run_liga_sweep` em `src/collectors/liga_sweep.py` atualmente chama
  `repo.get_cards_for_liga_scan()` — adicionar branch para catalog mode
- A query de catalog cards deve usar JOIN entre `cards` e `source_cards`
  em vez de `user_collection`
- `_fetch_liga_price` já funciona com dict genérico — não precisa mudar
- O external_id para catalog cards é `liga_catalog_{set}_{cn}` (vs
  `liga_{card_id}` para collection) — garantir que não conflita

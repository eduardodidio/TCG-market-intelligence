# F103-T04 — CLI `catalog` command group

**Status:** planned
**Wave:** 1
**Depends on:** T02, T03

## User Story

Como operador, quero comandos CLI para gerenciar o catálogo offline:
baixar dados do Scryfall, popular o banco, escanear preços Liga por set,
e ver estatísticas do catálogo.

## Acceptance Criteria

- [ ] `python -m src.cli.main catalog seed` — baixa bulk data + roda seeder
  - `--skip-download` — usa arquivo existente
  - `--batch-size N` — tamanho do batch de insert (default 500)
  - `--dry-run` — mostra contagem sem inserir
- [ ] `python -m src.cli.main catalog scan` — roda Liga sweep para catalog cards
  - `--set CODE` — scan apenas este set (obrigatório na v1)
  - `--limit N` — máx cards a escanear
  - `--delay N` — segundos entre requests (default 5.0)
  - `--batch-size N` — cards por batch (default 20)
  - `--batch-pause N` — pausa entre batches (default 60)
  - `--max-age-days N` — skip cards com preço recente (default 7)
  - `--dry-run` — mostra elegíveis sem escanear
- [ ] `python -m src.cli.main catalog stats` — mostra contagens:
  - Total cards no catálogo
  - Cards com preço Liga (e sem preço)
  - Breakdown por set (top 10 por contagem)
  - Último seed date
- [ ] Output é formatado com click.echo + tabela simples

## Dev Notes

- Adicionar `@cli.group() def catalog():` ao `src/cli/main.py`
- `catalog seed` chama `download_bulk_data()` + `seed_catalog()`
- `catalog scan` cria um `ScanFilter(collection_only=False, set_codes=[code])`
  e chama `run_liga_sweep()` adaptado (ver T05)
- `catalog stats` faz queries diretas no repo:
  - `SELECT COUNT(*) FROM cards WHERE game='magic'`
  - `SELECT COUNT(DISTINCT sc.external_id) FROM source_cards sc JOIN price_observations po ON ...`
  - `SELECT set_code, COUNT(*) FROM cards GROUP BY set_code ORDER BY COUNT(*) DESC LIMIT 10`

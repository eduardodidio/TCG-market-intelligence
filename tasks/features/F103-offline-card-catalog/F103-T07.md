# F103-T07 — Frontend Catalog page

**Status:** planned
**Wave:** 2
**Depends on:** T06

## User Story

Como usuário, quero uma página `/catalog` onde posso navegar o catálogo
completo de cartas de Magic com filtros por set, cor, raridade e faixa de
preço, vendo o preço Liga quando disponível, para descobrir cartas e
comparar preços antes de comprar.

## Acceptance Criteria

- [ ] Nova rota `/catalog` no React Router
- [ ] Componente `CatalogPage` com:
  - Search bar (busca por nome, debounced 300ms)
  - Filter sidebar/collapsible:
    - Set dropdown (carregado de `/catalog/sets`)
    - Rarity chips (C, U, R, M)
    - Color identity chips (W, U, B, R, G, Colorless)
    - Price range slider (min/max, ou "has price" toggle)
  - Card grid (reusa pattern existente do ExploreCards)
  - Cada card mostra: nome, set, raridade, imagem (thumbnail), preço Liga
  - Cards sem preço mostram "—" ou badge "Sem preço"
  - Paginação (Load More ou infinite scroll)
- [ ] Stats summary no topo: "X cards • Y sets • Z com preço"
- [ ] Click em card navega para `/cards/{id}` (página existente de detalhes)
- [ ] CTA "Add to Collection" nos cards (reusa hook `useCollectionRefresh`)
- [ ] Link no nav menu (breadcrumb: Home > Catalog)
- [ ] Empty state quando nenhum resultado ou catálogo vazio
- [ ] Responsive: grid adapta de 1 col (mobile) a 4–5 cols (desktop)

## Dev Notes

- Criar `frontend/src/pages/CatalogPage.tsx`
- Criar `frontend/src/hooks/useCatalogCards.ts` — React Query hook para
  `/catalog/cards` com filtros como query params
- Criar `frontend/src/hooks/useCatalogSets.ts` — React Query hook para
  `/catalog/sets`
- Reusar componentes existentes:
  - `EmptyState` para catálogo vazio
  - `Breadcrumb` para navigation
  - `CostBadge` se quiser mostrar custo de refresh
- Card grid: pode reusar o layout do `ExploreCards` ou criar `CatalogCardGrid`
- Imagem: usar `image_uri` do card (Scryfall small ~150px wide) com lazy loading
- Filtros: managed via URL search params para deep linking
- i18n: adicionar keys para "Catalog", "All Cards", filtro labels

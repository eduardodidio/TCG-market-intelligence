# F103-T01 — Extend cards table schema

**Status:** planned
**Wave:** 0
**Depends on:** none

## User Story

Como desenvolvedor, quero que a tabela `cards` tenha colunas adicionais
(rarity, color_identity, mana_cost, type_line, image_uri) para que o
catálogo offline contenha metadados suficientes para browsing e filtros
sem depender de API externa.

## Acceptance Criteria

- [ ] `cards` table ganha 5 novas colunas (todas nullable para backward compat):
  - `rarity` VARCHAR(5) — "C", "U", "R", "M", "S", "B"
  - `color_identity` VARCHAR(20) — ex: "WU", "BRG", "" (colorless)
  - `mana_cost` VARCHAR(50) — ex: "{2}{W}{U}"
  - `type_line` VARCHAR(200) — ex: "Legendary Creature — Human Wizard"
  - `image_uri` VARCHAR(500) — Scryfall image URL (small/normal)
- [ ] Migration é safe: colunas nullable, sem default, sem breaking change
- [ ] Testes existentes continuam passando sem alteração
- [ ] Index em `cards.rarity` e `cards.color_identity` para filtros

## Dev Notes

- Editar `src/database/models.py` — adicionar colunas ao `CardRow`
- Criar migration function em `src/database/migrations.py` (ou inline no
  repository init) que faz `ALTER TABLE cards ADD COLUMN ... IF NOT EXISTS`
- SQLite suporta `ALTER TABLE ADD COLUMN` mas não suporta `IF NOT EXISTS` —
  usar try/except OperationalError para cada coluna
- Adicionar os 2 indexes via `CREATE INDEX IF NOT EXISTS`

## Testing

- [ ] Integration: migration é idempotente (rodar 2x sem erro)

# F103-T02 — Scryfall bulk data downloader + parser

**Status:** planned
**Wave:** 0
**Depends on:** none

## User Story

Como desenvolvedor, quero um módulo que baixe o bulk data do Scryfall
(default_cards) e parse o JSON em objetos de domínio, para que o seeder
(T03) possa inserir no banco.

## Acceptance Criteria

- [ ] Módulo `src/catalog/scryfall.py` com:
  - `download_bulk_data(dest_dir) -> Path` — baixa o arquivo JSON (~150MB)
    via Scryfall Bulk Data API, com progress logging, retry (3x), e
    verificação de integridade (file size > 0)
  - `parse_bulk_cards(path) -> Iterator[CatalogCard]` — streaming parser
    (ijson ou json line-by-line) que yield objetos sem carregar tudo em RAM
  - `CatalogCard` dataclass com: name_en, set_code, collector_number,
    rarity, color_identity, mana_cost, type_line, image_uri, name_pt (nullable)
- [ ] Filtra apenas `game == "paper"` e `lang == "en"` (evita digital-only e duplicatas)
- [ ] Extrai nome PT do campo `printed_name` quando `lang == "pt"` (segundo pass ou
  lookup no mesmo bulk, ver Dev Notes)
- [ ] Não depende de Playwright/browser — usa httpx ou urllib puro
- [ ] Funciona offline se o arquivo JSON já existir no dest_dir (skip download)

## Dev Notes

### Scryfall Bulk Data API
- `GET https://api.scryfall.com/bulk-data` retorna lista de bulk datasets
- Usar o tipo `default_cards` — contém todas as printings em inglês
- O response tem `download_uri` com URL direta para o JSON
- O JSON é um array de objetos card (um por printing)
- Cada card tem `game` (paper/arena/mtgo), `lang`, `set`, `collector_number`,
  `name`, `printed_name`, `rarity`, `color_identity`, `mana_cost`,
  `type_line`, `image_uris.normal`

### Nomes em PT
- O bulk `default_cards` só tem cards em inglês
- Para nomes PT, usar o bulk `all_cards` que inclui todas as langs, mas é
  muito maior (~1.5GB). Alternativa: fazer um segundo pass com
  `GET https://api.scryfall.com/cards/search?q=lang:pt+set:{code}` por set
- **Decisão recomendada**: seed inicial só com inglês, nome PT fica como
  enhancement futuro (campo nullable já existe)

### Streaming parser
- O JSON é um array `[{...}, {...}, ...]` — usar `ijson` para streaming
- Se `ijson` não estiver instalado, fallback para `json.load()` com warning
  de que vai usar mais RAM (~500MB)
- Adicionar `ijson` ao requirements.txt como optional dependency

### File management
- Salvar em `data/catalog/` (gitignored)
- Filename: `scryfall-default-cards-{date}.json`
- Limpar downloads antigos automaticamente (keep last 2)

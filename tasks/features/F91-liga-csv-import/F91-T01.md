# F91-T01: Schema — add `set_name_pt` + `notes` to UserCollectionRow

**Status:** planned
**Wave:** 0

## User Story

As a collector importing from LigaMagic, I want the Portuguese edition name
and any comments preserved in the database, so that I don't lose data from
my Liga export.

## Dev Notes

### Changes

1. **`src/database/models.py`** — Add two columns to `UserCollectionRow`:
   - `set_name_pt: Mapped[str | None] = mapped_column(String(200))`
   - `notes: Mapped[str | None] = mapped_column(String(500))`

2. SQLAlchemy `Base.metadata.create_all()` handles schema creation for new
   databases. For existing databases, SQLite `ALTER TABLE` is needed:
   ```sql
   ALTER TABLE user_collection ADD COLUMN set_name_pt VARCHAR(200);
   ALTER TABLE user_collection ADD COLUMN notes VARCHAR(500);
   ```
   Add this to the importer's `Base.metadata.create_all()` call or use a
   startup migration check.

3. **`src/api/schemas/collection.py`** — Add `set_name_pt` and `notes` to
   `CollectionCard` and `CollectionCardDetail` schemas so they appear in API
   responses.

### Constraints

- No new dependencies
- SQLite ALTER TABLE ADD COLUMN is safe (nullable columns only)
- Existing data gets NULL for new columns — acceptable

## Testing

- Unit: verify UserCollectionRow accepts set_name_pt and notes
- Unit: verify CollectionCard schema includes new fields
- Integration: create_all on fresh DB includes new columns
- Integration: existing rows survive schema addition (NULL values)

# F91-T03: Frontend — CSV import modal on MyCollection page

**Status:** planned
**Wave:** 1
**Depends on:** T01

## User Story

As a collector, I want to import my LigaMagic CSV directly from the
collection page UI, so I don't need CLI access to load my cards.

## Dev Notes

### New Components

1. **`frontend/src/components/CsvImportModal.tsx`** — Modal with:
   - File input (`<input type="file" accept=".csv">`)
   - Preview: file name, size, encoding hint
   - Warning: "This will replace your entire collection"
   - Import button → `POST /collection/import` (multipart/form-data)
   - Progress states: idle → uploading → success/error
   - Success: show ImportResult stats (imported, skipped, linked)

2. **`frontend/src/api/collection.ts`** — Add `importCollectionCsv`:
   ```typescript
   export async function importCollectionCsv(
     file: File,
   ): Promise<ApiResponse<ImportResult>> {
     const form = new FormData();
     form.append("file", file);
     const res = await fetch("/api/v1/collection/import", {
       method: "POST",
       headers: { Authorization: `Bearer ${getToken()}` },
       body: form,
     });
     return res.json();
   }
   ```

3. **MyCollection page** — Add "Import CSV" button in the toolbar area
   (near BatchAdd, BulkCanonize, Refresh All). Opens CsvImportModal.
   On success, refresh collection data.

### i18n Keys (~8)

- `collection.importCsv` / `collection.importCsvTitle`
- `collection.importCsvWarning` (destructive re-import warning)
- `collection.importCsvSuccess` / `collection.importCsvError`
- `collection.importing` (loading state)
- `collection.importStats` (imported/skipped/linked summary)
- `collection.selectCsvFile`

### Constraints

- Auth required (existing `require_auth_or_api_key` on endpoint)
- No new API endpoints — reuses existing `POST /collection/import`
- Multipart/form-data (not JSON) — can't use `apiPost` helper, need raw fetch
- Max file size: no frontend limit (server can handle typical Liga exports)

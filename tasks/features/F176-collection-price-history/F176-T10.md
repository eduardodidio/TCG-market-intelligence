# F176-T10 — UI: `PriceHistoryMeta`, estado vazio explicativo, tooltip de snapshot

**Wave:** 2
**Type:** frontend
**Depends on:** F176-T04
**Status:** planned

## User Story
As a colecionador, I want ver no gráfico qual versão do card (foil/normal) está sendo mostrada, de quais fontes vêm os preços e desde quando há histórico, so that eu confie no gráfico e entenda quando ele está vazio.

## Objective
Novo componente `PriceHistoryMeta.tsx` renderizado dentro de `PriceChart.tsx`, com estados vazios distintos baseados em `meta`, e tooltip que sinaliza pontos `daily_snapshot`.

## Test scenarios
- Happy: meta foil com sources `["liga","daily_snapshot"]` → badge "Foil", fontes "Liga" e "Snapshot diário", "Histórico desde 10/09".
- Normal: badge "Normal".
- `first_observed_at=null` + observations vazias → `empty-history-never` com variante no texto.
- `first_observed_at` definido + observations vazias → `empty-history-period` com data.
- Sem `meta` → nenhum `price-history-meta`; `empty-history` com texto antigo.
- Source desconhecida (`"foo"`) → exibida crua, sem crash.
- Tooltip: ponto `daily_snapshot` → texto de snapshot; ponto `liga` → sem texto.
- Erro de fetch → `ErrorBanner` inalterado.
- Boundary: `sources=[]` → seção de fontes oculta; `real_points=0` exibido corretamente.
- i18n: toda chave `priceHistory.*` existe em en.json e pt-BR.json (teste que carrega os dois JSON e compara as chaves do bloco).

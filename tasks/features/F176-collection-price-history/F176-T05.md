# F176-T05 — Snapshot diário com carry-forward limitado + backfill forward-fill

**Wave:** 1
**Type:** backend
**Depends on:** F176-T01
**Status:** planned
**Maps to AC:** AC7, AC8, AC14

## User Story
As a colecionador, I want que cada card com preço ganhe um ponto por dia e que o backfill preencha lacunas só com preços realmente coletados, so that o gráfico seja contínuo sem mostrar história inventada.

## Objective
Reescrever `src/collectors/price_snapshot.py`: `run_daily_snapshot` com limite de carry-forward de 30 dias desde a última observação real; `backfill_snapshots` como forward-fill a partir de observações reais, com `dry_run`.

- `date.today()` — permitir injeção para teste: parâmetro opcional `today: date | None = None` nas funções internas (não mudar a assinatura pública além de kwargs opcionais).
- Log com `logging` (já usado no módulo).

## Implementation details
- `MAX_CARRY_FORWARD_DAYS = 30`.
- `_latest_real_prices(repo) -> list[tuple[str, date, Decimal]]` (external_id, data, preço).
- `run_daily_snapshot(repo, today=None) -> int`: só ids cuja última real tem `today - data <= MAX_CARRY_FORWARD_DAYS`; e não cria snapshot se já existe observação real hoje (evita ponto redundante — o merge já priorizaria a real, mas economiza linhas).
- `backfill_snapshots(repo, days=1, dry_run=False, today=None) -> int` conforme shard 03; `days < 1` → `ValueError`; `days > 90` → cap com warning (comportamento existente).

## Acceptance criteria
- [ ] `run_daily_snapshot` não gera snapshot para id cuja última real tem >30 dias.
- [ ] `run_daily_snapshot` 2× no mesmo dia → segunda chamada retorna 0.
- [ ] Backfill nunca cria ponto antes da 1ª observação real do id.
- [ ] Backfill usa o preço da última real ≤ d (não o preço atual).
- [ ] Backfill idempotente; `dry_run=True` não escreve e retorna a mesma contagem que a execução real.

## Test scenarios
- Happy daily: liga_7 real há 3 dias → 1 snapshot hoje com esse preço.
- Carry-forward limit: real há 31 dias → 0 snapshots; exatamente 30 dias → 1 (boundary).
- Snapshot anterior não conta como real: só `daily_snapshot` há 1 dia e real há 40 dias → 0.
- Real hoje → sem snapshot hoje para esse id.
- Backfill: reais em D-10 (R$10) e D-4 (R$20), `days=15`, today=D → snapshots em D-9..D-5 = 10, D-3..D = 20; nada em D-14..D-11.
- Backfill: id com `daily_snapshot` antigo continua sendo preenchido nos dias faltantes (regressão H6).
- Backfill 2× → segunda retorna 0. `dry_run` → contagem igual e 0 linhas escritas.
- Backfill respeita carry-forward: real em D-60 e `days=90` → preenche só até D-30.
- Error: `days=0` → `ValueError`; `days=120` → cap 90 + warning (caplog).
- Empty DB → 0 em ambos.
- `median_price=None` real → ignorada como fonte de preço.

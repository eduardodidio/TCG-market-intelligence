# F17-T01: Scryfall set icon URL utility

- **Wave:** 0
- **Status:** done

- **Description:**

  existing `frontend/src/utils/scryfall.ts` module. The function takes an
  MYP set code (e.g. "bldmr", "DMR"), runs it through
  `mapToScryfallSetCode()` to get the canonical Scryfall code, and

  covering: standard codes, MYP variant codes, case insensitivity.

# F17-T02: SetIconFilter component

- **Wave:** 1
- **Status:** done
- **Depends on:** F17-T01
- **Description:**
  Create a new `SetIconFilter` component at
  `frontend/src/components/SetIconFilter.tsx`. This component replaces
  the text-based `FilterChips` specifically for the set filter on the
  collection page.

  **Props interface** (same shape as FilterChips for easy swap):
  ```ts
  interface SetIconFilterProps {
    options: { label: string; value: string }[];
    selected: string | null;
    onSelect: (value: string | null) => void;
  }
  ```

  **Rendering:**
  - "All" button identical to FilterChips (text, pill shape).
  - Each set option renders as a compact square/rounded button containing:
    - An `<img>` tag with `src={scryfallSetIconUrl(option.value)}`,
      `alt={option.label}`, sized ~24x24px, with `filter: invert(1)` or
      similar to make the black SVGs visible on the dark theme.
    - A CSS tooltip (via `title` attribute or a custom tooltip `<span>`)
      showing `option.label` on hover.
  - Selected icon gets a highlight (e.g. `ring-2 ring-cyan-500` or
    `bg-cyan-500/20`).
  - On `<img>` error, replace with a text fallback showing the set code
    (first 3-5 chars).

  **Layout:** Same horizontal scrollable flex row as FilterChips, with
  `data-testid="set-icon-filter"` on the container and
  `data-testid="set-icon-{value}"` on each icon button.

- **Acceptance Criteria:**
  - [ ] Component renders "All" button plus one icon button per option
  - [ ] Each icon button loads the Scryfall SVG via `scryfallSetIconUrl`
  - [ ] Hovering an icon shows tooltip with the set's label (full name)
  - [ ] Clicking an icon calls `onSelect(value)`, clicking again calls `onSelect(null)`
  - [ ] Clicking "All" calls `onSelect(null)`
  - [ ] Selected icon has visual highlight (distinguishable from unselected)
  - [ ] SVG load error falls back to set code text
  - [ ] `data-testid` attributes present for testing
  - [ ] Component test file created with at least 6 tests covering:
    render, selection, deselection, "All" click, tooltip presence,
    fallback on error

### Associate existing collection

The existing collection data in `user_collection` table may have `user_id`
pointing to the old user (created from `eduardo.didio` email) or to a
hardcoded/default user ID.

Add a step after user creation to associate orphaned collection entries:

```python
# After creating/finding the main user:
repo.associate_collection_to_user(user_id=main_user.id)
```

This requires checking:
1. What `user_id` existing collection entries have
2. If they reference the old seed user, update to new user's ID
3. If entries have `user_id=NULL` or a default, assign to new user

**Implementation**: Add a `--associate-collection` flag to `seed-users` that
updates all `user_collection` rows with `user_id` = old_user_id to the new
user's id. Or simpler: update all collection entries to belong to the first
seeded user.

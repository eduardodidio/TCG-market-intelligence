# F28-T02: Add name_pt to MoverEntry schema & query

**Status:** planned
**Wave:** 1
**Depends on:** none

## User Story

As a user viewing market movers, I want card names to switch to Portuguese
when I select PT-BR language, just like on other pages.

## Dev Notes

**File:** `src/api/schemas/market.py` (line 9-16)

Add `name_pt` field to `MoverEntry`:


`(card_id, name_en, name_pt, set_code, price_start, price_end, change_pct)`

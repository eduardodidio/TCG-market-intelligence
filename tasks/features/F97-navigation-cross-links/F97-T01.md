## User Story

As a user navigating the app, I want consistent breadcrumbs on every
secondary page so I always know where I am and can navigate back to the
parent section.

## Dev Notes

- Import `Breadcrumb` from `../components/Breadcrumb`.
- Follow the exact pattern used in `CollectionCardDetail.tsx` (line 273-278):
  ```tsx
  <Breadcrumb items={[
    { label: t("...parent"), to: "/parent" },
    { label: t("...current") },
  ]} />
  ```
- Place the `<Breadcrumb>` as the first child inside the page's root `<div>`,
  before the `<h1>` or header section.
- Use existing i18n keys for page titles where available (e.g., `nav.market`,
  `nav.trending`). New breadcrumb-specific keys will be added in T06.
- `Dashboard` link should point to `/`.

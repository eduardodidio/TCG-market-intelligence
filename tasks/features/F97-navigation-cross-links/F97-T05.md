# F97-T05: "Add Missing Cards" on DeckView

**Wave:** 2
**Depends on:** --

## User Story

As a user viewing a deck that I do not fully own, I want a button to batch-add
all missing cards to my collection, so I can quickly fill gaps without manually
typing each card name.

## Current State

- `DeckView.tsx` already displays ownership stats: `owned_cards`,
  `ownership_pct`, and each `DeckCard` has `in_collection: boolean` and
  `owned_quantity: number`.
- The deck header already shows a `deck.ownership_pct` badge that changes
  color based on completion.
- `BatchAddModal` exists and accepts text in `1 CardName [SET]` format.

## Dev Notes

### Implementation

1. In `DeckView.tsx`, when `deck.ownership_pct < 100`, show an "Add Missing
   Cards" button in the header area (next to the delete button or in the
   stats row).

2. On click, compute the missing cards text:
   ```ts
   const missingText = deck.cards
     .filter(c => !c.in_collection && c.name_en)
     .map(c => {
       const qty = c.quantity - c.owned_quantity;
       const set = c.set_code ? ` [${c.set_code}]` : "";
       return `${qty > 0 ? qty : 1} ${c.name_en}${set}`;
     })
     .join("\n");
   ```

3. Open `BatchAddModal` with `initialText={missingText}`. (Reuse the
   `initialText` prop added in T04.)

4. After successful batch add, call `loadDeck()` to refresh ownership data.

5. When `ownership_pct === 100`, the button should not appear (deck is
   complete).

### Button Design

Place it in the stats row or next to the delete button:
```tsx
<button
  data-testid="add-missing-cards-btn"
  className="inline-flex items-center gap-2 rounded-md bg-indigo-500 px-3 py-1.5 text-sm font-medium text-white hover:bg-indigo-400 transition-colors"
>
  + {t("decks.addMissingCards")}
</button>
```

## Testing

- Render DeckView with `ownership_pct: 60`, 2 of 5 cards not in collection:
  assert "add-missing-cards-btn" is present.
- Render DeckView with `ownership_pct: 100`: assert button is NOT present.
- Click button: assert BatchAddModal opens. Verify pre-filled text contains
  the missing card names with correct quantities.
- After successful add + reload: verify ownership stats update.

## Acceptance Criteria

- [ ] "Add Missing Cards" button visible when `ownership_pct < 100`
- [ ] Button not shown when deck is 100% owned
- [ ] BatchAddModal opens pre-filled with missing cards in correct format
- [ ] Quantities reflect the difference (needed minus owned)
- [ ] After adding, deck view refreshes and ownership stats update

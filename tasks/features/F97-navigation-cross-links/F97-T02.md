# F97-T02: Market-Trending Cross-Links

**Wave:** 1
**Depends on:** T01

## User Story

As a user on the Market page, I want a "View All Trending" link that takes me
to the full Trending page. As a user on the Trending page, I want a "Back to
Market Overview" link that takes me to the Market page. These two pages are
related but currently disconnected.

## Dev Notes

### MarketPage.tsx

Add a `Link` component after the TrendingSection blocks (or within each
section header). Suggested placement: a small link-row between the trending
sections and the volatile section.

```tsx
<div className="mb-8 flex justify-end">
  <Link
    to="/market/trending"
    className="text-sm text-cyan-400 hover:text-cyan-300 transition-colors"
    data-testid="view-all-trending-link"
  >
    {t("marketPage.viewAllTrending")} ->
  </Link>
</div>
```

### Trending.tsx

Add a link near the page title or below the breadcrumb, pointing back to
`/market`.

```tsx
<Link
  to="/market"
  className="text-sm text-cyan-400 hover:text-cyan-300 transition-colors"
  data-testid="back-to-market-link"
>
  <- {t("trending.backToMarket")}
</Link>
```

### Breadcrumb update

With T01 done, Trending already has a breadcrumb `Dashboard > Trending`.
Consider whether the breadcrumb should instead be `Market > Trending` given
the navigation hierarchy. If so, update the Trending breadcrumb parent to
point to `/market` instead of `/`.

## Testing

- MarketPage: assert `screen.getByTestId("view-all-trending-link")` has
  `href="/market/trending"`.
- Trending: assert `screen.getByTestId("back-to-market-link")` has
  `href="/market"`.

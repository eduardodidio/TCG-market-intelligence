# F97-T06: i18n Keys (EN + PT-BR)

**Wave:** 2
**Depends on:** T01, T02, T03, T04, T05

## User Story

As a user in either English or Portuguese, I want all new navigation labels,
breadcrumbs, buttons, and tooltips to be properly translated.

## Dev Notes

This task consolidates all i18n keys introduced by T01-T05. The developer
should audit all new strings added by prior tasks and ensure they exist in
both `en.json` and `pt-BR.json`.

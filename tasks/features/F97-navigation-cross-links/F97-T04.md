# F97-T04: "Add to Collection" CTA on CardDetail

**Wave:** 2
**Depends on:** --

## User Story

As a user viewing a card on the Explore Cards detail page (`/cards/:id`) that
is not in my collection, I want an "Add to Collection" button so I can quickly
add it without navigating to the collection page and using batch add.

## Current State

- `CardDetail.tsx` already checks `card.collection_entry_id != null` to
  conditionally show the refresh button (line 201).
- When `collection_entry_id` is null, the card is not in the user's collection.
- `BatchAddModal` exists at `frontend/src/components/BatchAddModal.tsx` and
  accepts `isOpen`, `onClose`, `onSuccess`.
- The batch add text format is: `1 Card Name [SET]` (one per line).

## Dev Notes

### Implementation

1. In `CardDetail.tsx`, when `card.collection_entry_id == null` AND user is
   authenticated, show an "Add to Collection" button below the price section
   (or alongside the external links).

2. On click, open a `BatchAddModal` pre-filled with the card's name and set:
   ```
   1 {card.name_en} [{card.set_code}]
   ```

3. The `BatchAddModal` currently does not support an `initialText` prop.
   Add an optional `initialText?: string` prop that pre-fills the textarea
   and automatically triggers the preview step.

4. After successful add, refetch the card detail to update
   `collection_entry_id` (the refresh button should now appear).

5. If user is not authenticated, show a "Sign in to add" link to `/login`
   instead.

### Button Design

```tsx
<button
  data-testid="add-to-collection-btn"
  className="inline-flex items-center gap-2 rounded-md bg-indigo-500 px-4 py-2 text-sm font-medium text-white hover:bg-indigo-400 transition-colors"
>
  + {t("cardDetail.addToCollection")}
</button>
```

## Testing

- Render CardDetail with `collection_entry_id: null` + authenticated user:
  assert "add-to-collection-btn" is present.
- Render CardDetail with `collection_entry_id: 42`: assert button is NOT
  present (refresh button shown instead).
- Render CardDetail unauthenticated: assert neither add button nor refresh
  button shown (or "sign in to add" link shown).
- Click add button: assert BatchAddModal opens with pre-filled text.
- After successful add + refetch: assert add button disappears.

## Acceptance Criteria

- [ ] "Add to Collection" button visible on CardDetail when card is not owned
- [ ] Button opens BatchAddModal pre-filled with card name + set
- [ ] Button not shown when card is already in collection
- [ ] Button not shown (or replaced by sign-in link) for unauthenticated users
- [ ] After adding, the page updates to show the card as owned

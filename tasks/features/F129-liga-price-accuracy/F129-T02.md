# F129-T02: Enhance Debug Script for Batch Investigation

**Wave:** 0 (Tooling)
**Parallel with:** T01
**Files to modify:** `scripts/liga_debug.py`
**Files to create:** (none)

## User Story

As a developer investigating price mismatches, I want the debug script to
accept a set_code parameter and support batch mode (process multiple cards
from a CSV), so that I can efficiently investigate groups of mismatched
cards and confirm whether the data-sigla fix resolves them.

## Problem

The current `liga_debug.py` only accepts a single card name and optionally
a collector number. To investigate the 273 BIG_MISMATCH cards, the developer
needs to:

1. Pass `--set-code` to trigger edition selection with sigla matching (the
   key fix from commit 1686d03). Currently the debug script does not call
   `_select_edition` with set_code -- it only passes collector_number.

2. Batch mode: read from a CSV (e.g. `mismatches.csv`) and run debug for
   each card, outputting a summary row. This avoids manual card-by-card
   investigation.

## Dev Notes

### set_code support
- Add `--set-code` / `-sc` argument to the CLI.
- When selecting edition, update the matching logic to use both
  collector_number AND data-sigla (same logic as provider._select_edition).
- The `parse_edition_options` already returns 3-tuples `(value, cn, sigla)`.
- Update the edition display to show sigla: `value=X cn=Y sigla=Z`.
- Note: the existing code at line 76 uses 2-tuples `for val, cn in editions`
  -- this is outdated and needs to be updated to 3-tuples.

### Batch mode
- Add `--batch` / `-b` argument that accepts a CSV file path.
- Read name_en, collector_number, set_code, card_id from the CSV.
- For each card, run the debug flow (navigate, select edition, parse prices).
- Output a summary CSV with columns:
  `card_name, collector_number, set_code, edition_matched, our_mid, liga_buy,
   diff_pct, status`
- Rate limit between cards (use existing delay pattern).
- Add `--limit N` to cap how many cards to process in batch mode.
- Save batch results to `scripts/debug_output/batch_debug.csv`.

### Summary output
After batch mode completes, print:
- Total cards processed
- Edition matched / not matched counts
- Price found / not found counts
- Cards with >50% deviation (potential issues)

## Edge Cases

- Card not found on Liga (404) -- log and continue in batch mode
- Edition selection fails -- log warning, record "edition_matched=false"
- Rate limiting (429) -- respect backoff in batch mode
- CSV with missing columns -- graceful error message

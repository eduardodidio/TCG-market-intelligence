## User Story

As a price collector, I want foil cards and variant editions (Borderless,
Extended Art, Etched, Gilded) to correctly resolve to their Liga edition,
so that foil/variant prices are not confused with regular prices and vice
versa.

## Problem

The pre-fix comparison shows foil-specific mismatches in both directions:

**Our price LOWER than Liga's lowest buy (genuine bugs):**
- Exemplar of Light (Borderless, Foil): -81% (our R$12.14 vs Liga R$64.95)
- Thundermaw Hellkite (Iconic Masters, Foil): -73% (our R$5.89 vs Liga R$21.61)
- Snort (Extended Art, Foil): -53% (our R$4.40 vs Liga R$9.29)
- Frodo Baggins (Promo, Foil Pre Release): -71% (our R$0.88 vs Liga R$3.00)

**Our price MUCH HIGHER than Liga's (possible wrong edition):**
- Arcane Signet (Commander Legends Variantes, Foil): +325%
- The Book of Exalted Deeds (AFR, Foil Pre Release): +976%
- Sarkhan Dragonsoul (M19, Foil): +144%
- Smoldering Egg (MID, Foil): +253%

Root causes:
1. **Foil price stored as normal**: When edition selection fails for a foil
   card, the sweep stores the default edition's NORMAL price instead of
   skipping. But the current code already returns None on edition mismatch.

2. **Variant edition not matching**: Cards from variant sub-sets (Borderless,
   Extended Art, Variantes) have different edition IDs on Liga. The sigla
   may differ from the base set sigla.

3. **No foil fallback**: When a card is foil but the selected edition has no
   foil prices, the sweep currently returns None. It should NOT fall back
   to normal prices (this would store wrong data).

### Scope gate

may resolve many of these by selecting the correct edition in the first

## Dev Notes

### Investigation first
Before implementing fixes, the developer should:
1. Use the debug script on 3-5 foil mismatch cards
2. Check if the Liga page shows the correct edition for the foil card
3. Check if foil prices are available on that edition
4. Identify whether the issue is edition selection or foil price extraction

### Potential fix 1: Variant sigla awareness
Variant sub-sets on Liga often have sigla patterns like:
- Base set: `afr` (Adventures in the Forgotten Realms)
- Promo: `pafr` or `ampafr`
- Borderless: same sigla but different collector_number range

When sigla matching fails, try common variant prefixes/suffixes:
- `p{set}` (promo)
- `amp{set}` (Ampersand promo)
- `{set}` without prefix (if we have a prefixed code)

### Potential fix 2: Foil edition logging
When a foil card's edition is selected but no foil prices are found,
log the card + edition details so we can investigate. Currently the
sweep just returns None silently for foil-no-prices.

Add structured log:
```python
log.info(
    "liga_sweep_foil_no_prices_for_edition",
    card=card_name,
    card_id=card_id,
    edition_value=edition_value,
    set_code=set_code,
)
```

### Potential fix 3: Pre-release / promo collector number
Pre-release promos often have collector numbers in a different range
(e.g. 400+ for M19 promos). Liga may store these under the promo sub-set.
The edition dropdown may have the promo as a separate entry with a
different collector_number than what Scryfall reports.

### What NOT to do
- Do NOT fall back from foil to normal prices -- this stores wrong data.
- Do NOT store the "default" edition price when edition selection fails --
  the current behavior (skip/return None) is correct.
- Do NOT try to match foil prices from a different edition than the one
  in the user's collection.

## Edge Cases

- Cards that exist only as foil (e.g. some promos) -- no normal prices
  at all, foil prices should be found
- Cards with "Foil Etched" or "Gilded Foil" -- different from regular foil
  on Liga? Check if Liga has separate editions for these.
- Cards in "(Foil Etched / Gilded Foil)" variant sets -- these have their
  own collector numbers and edition IDs
- "Foil, Pre Release" extras -- dual-tagged cards

# F179-T03 — Frontend contracts: types, i18n, credits refresh event

**Wave:** 0
**Type:** frontend
**Depends on:** —
**Status:** planned

## User Story

As a frontend developer, I want the reward types, translations and a
credits-changed event in place, so that the page and toast tasks can run in
parallel without touching shared files.

## Objective

Extend achievement types, add i18n keys (en + pt-BR), add
`utils/creditsEvents.ts`, and make `useCredits` refetch on that event.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/04-frontend.md`.

- Types: `frontend/src/types/achievements.ts` (currently 2 interfaces).
- i18n: add keys only INSIDE the existing `"achievements"` object in
  `frontend/src/i18n/locales/en.json` and `pt-BR.json` (object starts ~line 1220).
  Keep JSON valid; there is an i18n test in `frontend/src/i18n/__tests__` that

## Implementation details

- `types/achievements.ts`: `AchievementTier`, extended `AchievementItem`
  (`reward`, `tier`, `reward_credited`), `AchievementReward`, extended
  `AchievementCheckResponse` (optional `rewards`, `total_reward`, `backfilled`, `balance`).
- `utils/creditsEvents.ts`: `CREDITS_CHANGED_EVENT`, `notifyCreditsChanged()`.
- i18n keys: `reward`, `rewardEarned`, `treasureProgress`, `toastReward`,
  `backfillReward`, `tier.{common,uncommon,rare,mythic,legendary}`.
- Existing test mocks of `AchievementItem` in other tests will fail type-check
  only when T06/T07 touch them; to keep `npm run build` green now, make sure
  no existing non-test code constructs `AchievementItem` literals (grep). If a
  test file constructs them, TypeScript in Vitest won't fail at runtime; leave to T06/T07.

## Test scenarios

- Happy: `notifyCreditsChanged()` dispatches an `Event` of type `credits:changed` on window.
- Happy: hook mounted → event fired → `fetchCreditBalance` called twice total.
- Edge: after unmount, firing the event does not call fetch again.
- Edge: multiple rapid events → each triggers a fetch (no crash).
- i18n: `t("achievements.reward", {amount: 50})` → "+50 Tesouros" (pt-BR) / "+50 Treasures" (en).
- Boundary: tier labels exist for all 5 tiers in both locales.

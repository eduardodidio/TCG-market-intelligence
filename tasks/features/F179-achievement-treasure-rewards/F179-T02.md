## User Story

As a player, I want each achievement to be worth a Treasure amount matching its
difficulty and to be paid exactly once, so that achievements feel rewarding and
the economy stays fair.

## Objective

Create `src/services/achievement_rewards.py` (tiers, mapping, in-session credit,
backfill) with full unit tests. New files only.

## Implementation details

Public API of `src/services/achievement_rewards.py`:

```python
ACHIEVEMENT_REWARD_REASON = "achievement_reward"
REWARD_TIERS: dict[str, int] = {"common": 50, "uncommon": 100, "rare": 250, "mythic": 500, "legendary": 1000}
ACHIEVEMENT_TIERS: dict[str, str] = {...}  # 11 keys, see _brief/01
def get_tier(key: str) -> str | None
def get_reward(key: str) -> int                      # 0 for unknown
def reference_id_for(key: str) -> str                # "achievement:<key>"
def credited_keys(session, user_id) -> set[str]      # keys with an existing ledger row
def credit_reward_in_session(session, user_id, key) -> int   # 0 if unknown/already credited; caller commits
def backfill_user_rewards_in_session(session, user_id) -> int
def backfill_all_rewards(repo, *, dry_run=False, user_id=None) -> dict
```

## Acceptance criteria

- [ ] Tiers exactly 50/100/250/500/1000; mapping per `_brief/01`
- [ ] `credit_reward_in_session` credits once; 2nd call returns 0, balance unchanged, 1 ledger row
- [ ] Creates `CreditBalanceRow` when missing
- [ ] Backfill credits every unlocked achievement once; re-run = 0
- [ ] `dry_run=True` returns same totals but DB unchanged
- [ ] Per-user failure in `backfill_all_rewards` counted in `errors`, others still processed

## Test scenarios

- Happy: `first_card` → +50, ledger row reason/ref correct, balance 50.
- Happy: existing balance 7 → 7 + 250 for `collector_50`.
- Edge: every key of `ACHIEVEMENT_DEFINITIONS` has a tier (coverage test).
- Edge: unknown key → 0, no rows written.
- Edge: pre-existing ledger row for `achievement:first_card` → no credit.
- Edge: other reasons with same reference_id (e.g. `bonus_claim`) don't block.
- Boundary: `legendary` = 1000; a user holding all 11 achievements is backfilled
  3400 Tesouros (4×50 + 2×100 + 2×250 + 500 + 2×1000); assert against
  `sum(get_reward(k) for k in ACHIEVEMENT_TIERS)` and the literal 3400.
- Backfill: 2 users, one already credited → only other credited; re-run → all zeros.
- Backfill `user_id=` filter only touches that user.
- Dry-run: returned totals > 0, balances/ledger untouched.
- Error: one user raises (monkeypatch) → `errors == 1`, other user credited.

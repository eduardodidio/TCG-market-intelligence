# F179-T06 — AchievementsPage: reward chips + treasure totals

**Wave:** 1
**Type:** frontend
**Depends on:** F179-T03
**Status:** done

## User Story

As a player, I want to see how many Tesouros each achievement is worth and how
many I've earned, so that I know what to go after next.

## Objective

Render a reward/tier chip on every achievement card and an earned/total
Tesouros line under the progress bar.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/04-frontend.md`.

- File: `frontend/src/pages/AchievementsPage.tsx` (187 lines; dark theme,
  amber accents). Use `t("achievements.reward", {amount})`,
  `t(\`achievements.tier.${tier}\`)`, `t("achievements.treasureProgress", ...)`,
  `t("achievements.rewardEarned")` — keys added by T03.
- Backend fields (T04) may be absent while Wave 1 runs in parallel: treat
  `reward ?? 0`, `tier ?? null`, and hide the chip if `reward` is 0.
- Only this task edits the page and its test.

## Implementation details

- Tier → classes map (`common: text-slate-300 border-slate-500`, `uncommon:
  emerald`, `rare: sky`, `mythic: orange`, `legendary: amber`).
- Chip `data-testid="achievement-reward-<key>"`; earned marker
  `data-testid="achievement-reward-earned-<key>"` when `unlocked && reward_credited`.
- Totals `data-testid="achievements-treasure-progress"`.

## Acceptance criteria

- [ ] Every card with reward > 0 shows "+N Tesouros" and tier label
- [ ] Locked cards show muted chip; unlocked+credited show earned marker
- [ ] Totals line correct (earned = sum of unlocked rewards)
- [ ] Existing page tests still pass

## Test scenarios

- Happy: fixture with 3 items (50 common unlocked+credited, 250 rare locked,
  1000 legendary locked) → chips "+50", "+250", "+1000"; totals "50 / 1300".
- Edge: item without `reward` field (older API) → no chip, no crash, totals 0.
- Edge: `tier` null with reward > 0 → chip without tier label.
- Edge: unlocked but `reward_credited=false` → no earned marker.
- Boundary: all unlocked → earned == total; empty list → "0 / 0".
- Error: API error still renders ErrorBanner (existing behavior).

## User Story

As a player, I want a toast telling me "+N Tesouros" when I unlock an achievement
and my Treasure balance to update right away, so that the reward feels immediate.

## Objective

Add the reward line to `AchievementToast`, propagate rewards/backfill in
`useAchievementNotifier`, and create `AchievementNotifierHost` (mounted by T09).

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/04-frontend.md`.

- Today neither the toast nor the hook are mounted anywhere — the host is what
  makes them visible. Do NOT edit `Layout.tsx` or `App.tsx` (T09 does it).
- Hook currently returns early when `newly_unlocked.length === 0`; must still
  handle `backfilled > 0`.
- Use `notifyCreditsChanged()` from `../utils/creditsEvents` (T03).
- Auth: `useAuth()` from `../hooks/useAuth` → `{ user, isAuthenticated }`;
  skip for guests (`user?.role === "guest"`).
- Throttle: `useRef<number>(0)`; skip if `Date.now() - last < 30_000`.

## Implementation details

- `AchievementToast.tsx`: optional prop `reward?: number`; `useTranslation`;
  render reward line `data-testid="achievement-toast-reward"` when > 0.
- `useAchievementNotifier.ts`: `PendingToast` gains `reward?: number`; map
  from `resp.data.rewards`; backfill toast (icon `treasure`); call
  `notifyCreditsChanged()` when `(total_reward ?? 0) + (backfilled ?? 0) > 0`.
- `AchievementNotifierHost.tsx` (new): `useLocation()` + effect on
  `pathname` → throttled `checkAchievements()`; renders toasts stacked
  (wrapper `fixed top-4 left-1/2 -translate-x-1/2 z-[60] flex flex-col gap-2`;
  if the toast's own `fixed` positioning conflicts, add an optional
  `inline?: boolean` prop that drops the fixed classes). `data-testid="achievement-notifier-host"`.

## Acceptance criteria

- [ ] Toast shows "+50 Tesouros adicionados!" when `reward=50`; nothing when absent/0
- [ ] Hook attaches correct reward per key; emits credits event only when something was credited
- [ ] Backfill-only response produces a single backfill toast
- [ ] Host: calls check on mount, again on route change after 30 s, not before; nothing for guests/anonymous
- [ ] Multiple toasts don't overlap

## Test scenarios

- Happy: check returns `first_card` + reward 50 → toast with title + "+50".
- Happy: two unlocks → two toasts with their own rewards; credits event dispatched once.
- Edge: `rewards` missing (old backend) → toast without reward line, no event.
- Edge: `newly_unlocked=[]`, `backfilled=300` → one backfill toast + event.
- Edge: nothing new → no toast, no event.
- Throttle: mount → 1 call; navigate at +10 s → still 1; at +31 s → 2.
- Auth: guest → 0 calls; anonymous → 0 calls.
- Error: `checkAchievements` rejects → no toast, no throw, `checkingRef` released (next call works).
- Boundary: dismiss removes only that toast.

## User Story

As an operator, I want a one-off command to credit rewards for achievements
unlocked before F179, so that every existing user is paid without waiting for
them to log in.

## Objective

Create `src/cli/achievement_rewards.py` with a standalone click command wrapping
`backfill_all_rewards`. Registration in `main.py` is T09's job.

## Implementation details

- `@click.command("backfill-achievement-rewards")` with `--db`, `--dry-run`, `--user-id`.
- `Repository(db_url=db)`; call `backfill_all_rewards(repo, dry_run=..., user_id=...)`.
- Output: `Backfill complete: {users} users, {credited_rows} rewards, {total_tokens} Tesouros credited (dry-run: yes|no)`; if `errors` > 0 print a warning line and exit code 1.

## Test scenarios

- Happy: 2 users with achievements → output counts, balances updated.
- Idempotent: run twice → second reports 0 rewards.
- Dry-run: output > 0 but DB ledger unchanged.
- `--user-id` of user without achievements → 0 rewards, exit 0.
- Error: monkeypatch `backfill_all_rewards` to return `errors=1` → exit 1.
- Boundary: empty DB → "0 users", exit 0.

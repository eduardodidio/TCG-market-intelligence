## User Story

As a platform operator, I need database tables to track user credit balances
and transaction history, plus an admin flag on users, so the credit economy
has persistent storage and audit capabilities.

## Dev Notes

### New models in `src/database/models.py`

```python
class CreditBalanceRow(Base):
    __tablename__ = "credit_balances"

    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    user_id: Mapped[int] = mapped_column(Integer, nullable=False, unique=True)
    balance: Mapped[int] = mapped_column(Integer, nullable=False, default=0)
    last_bonus_at: Mapped[datetime | None] = mapped_column(DateTime)
    updated_at: Mapped[datetime] = mapped_column(
        DateTime, default=datetime.utcnow, onupdate=datetime.utcnow
    )

    __table_args__ = (Index("ix_credit_balance_user", "user_id"),)


class CreditTransactionRow(Base):
    __tablename__ = "credit_transactions"

    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    user_id: Mapped[int] = mapped_column(Integer, nullable=False)
    amount: Mapped[int] = mapped_column(Integer, nullable=False)  # positive=credit, negative=debit
    reason: Mapped[str] = mapped_column(String(50), nullable=False)
    # Reason values: "card_refresh", "bulk_scan", "bonus_claim",
    #                "admin_grant", "initial_credits"
    reference_id: Mapped[str | None] = mapped_column(String(200))
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)

    __table_args__ = (
        Index("ix_credit_tx_user", "user_id"),
        Index("ix_credit_tx_user_date", "user_id", "created_at"),
    )
```

### Repository methods (in `src/database/repository.py`)

```python
def get_credit_balance(self, user_id: int) -> CreditBalanceRow | None
def ensure_credit_balance(self, user_id: int) -> CreditBalanceRow  # create if missing, default balance=0
def update_credit_balance(self, user_id: int, delta: int, reason: str, reference_id: str | None = None) -> CreditBalanceRow
def get_credit_transactions(self, user_id: int, limit: int = 50, offset: int = 0) -> list[CreditTransactionRow]
```

`update_credit_balance` must:
1. Call `ensure_credit_balance` to get/create the row
2. Check that `balance + delta >= 0` (raise ValueError if not)
3. Update `balance += delta`
4. Insert a `CreditTransactionRow` with the given reason
5. Commit and return the updated balance row

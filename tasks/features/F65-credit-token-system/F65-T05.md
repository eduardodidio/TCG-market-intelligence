# F65-T05: Frontend sidebar credit balance + treasure token icon

**Status:** planned
**Wave:** 2
**Depends on:** T03

## User Story

As a logged-in user, I want to see my treasure token balance in the sidebar
at all times, displayed as a gold token icon with a count, so I know how many
refreshes I can afford.

## Dev Notes

### New component: `frontend/src/components/TreasureBalance.tsx`

Display a treasure token icon with the balance count:
```tsx
function TreasureBalance() {
  const { balance, bonusEligible, claimBonus, loading } = useCredits();

  return (
    <div className="flex items-center gap-2 px-6 py-3">
      {/* Gold coin/token icon - MTG Treasure Token style */}
      <div className="w-8 h-8 rounded-full bg-gradient-to-br from-yellow-400 via-amber-500 to-yellow-600
                      border-2 border-yellow-300 shadow-lg flex items-center justify-center">
        <span className="text-yellow-900 text-xs font-bold">T</span>
      </div>
      <div className="flex flex-col">
        <span className="text-amber-400 font-semibold text-sm">
          {balance ?? "..."}
        </span>
        {bonusEligible && (
          <button onClick={claimBonus}
                  className="text-xs text-emerald-400 hover:text-emerald-300">
            {t("credits.claimBonus")}
          </button>
        )}
      </div>
    </div>
  );
}
```

### Bonus claim button

If `bonusEligible` is true, show a small "Claim" button below the balance
that triggers `POST /credits/claim-bonus`. After claim, refetch balance
and show brief success feedback (balance number animates or flashes green).

### Admin indicator

If `isAdmin` is true, show a small infinity symbol or "Admin" badge next
to the balance to indicate unlimited access.

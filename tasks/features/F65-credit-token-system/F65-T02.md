# F65-T02: Credit service — check/deduct/grant/claim_bonus

**Status:** planned
**Wave:** 0
**Parallel with:** T01

## User Story

As a developer integrating credits into endpoints, I want a clean service
layer that encapsulates all credit logic (checking balance, deducting,
granting, claiming bonuses) so routers stay thin and business rules are
centralized.

## Dev Notes

### New module: `src/credits/service.py`

```python
class CreditService:
    def __init__(self, repo: Repository):
        self.repo = repo

    def get_balance(self, user_id: int) -> CreditBalance:
        """Get current balance, creating row if needed."""

    def check_sufficient(self, user_id: int, cost: int) -> bool:
        """Return True if user has >= cost credits."""

    def deduct(self, user_id: int, cost: int, reason: str, reference_id: str | None = None) -> CreditBalance:
        """Deduct credits. Raises InsufficientCreditsError if balance < cost."""

    def grant(self, user_id: int, amount: int, reason: str, reference_id: str | None = None) -> CreditBalance:
        """Add credits to user (admin grant, bonus, etc.)."""

    def claim_bonus(self, user_id: int) -> tuple[CreditBalance, bool]:
        """Claim 12h bonus (5 credits). Returns (balance, was_claimed).
        Returns False if <12h since last claim."""

    def get_bonus_eligibility(self, user_id: int) -> dict:
        """Return {eligible: bool, next_eligible_at: datetime | None, amount: 5}"""

    def get_transactions(self, user_id: int, limit: int = 50, offset: int = 0) -> list[CreditTransaction]:
        """Paginated transaction history."""
```

### New exception: `src/credits/exceptions.py`

```python
class InsufficientCreditsError(Exception):
    def __init__(self, balance: int, cost: int):
        self.balance = balance
        self.cost = cost
        super().__init__(f"Insufficient credits: have {balance}, need {cost}")
```

### Business rules encoded

- `claim_bonus`: Check `last_bonus_at`. If None or 12h+ ago, grant 5 credits
  and update `last_bonus_at = utcnow()`. If <12h, return `(balance, False)`.
- `deduct`: Atomic check-and-subtract. If balance < cost, raise
  `InsufficientCreditsError`. Otherwise subtract and log transaction.
- **Admin exemption is NOT in this service** — it is checked at the router
  level in T04. The service always charges regardless of admin status.
  This keeps the service pure and testable.

## Testing

- Unit: `get_balance` returns 0 for new user (auto-creates balance row)
- Unit: `deduct(cost=1)` with balance=5 returns balance=4, transaction logged with reason
- Unit: `deduct(cost=1)` with balance=0 raises InsufficientCreditsError(balance=0, cost=1)
- Unit: `grant(amount=100, reason="admin_grant")` increases balance, transaction logged
- Unit: `claim_bonus` with no prior claim grants 5 credits, sets last_bonus_at
- Unit: `claim_bonus` called twice within 12h — second returns (balance, False)
- Unit: `claim_bonus` after 12h+ grants 5 more credits
- Unit: `get_bonus_eligibility` returns correct next_eligible_at (last_bonus_at + 12h)
- Unit: `get_bonus_eligibility` with no prior claim returns eligible=True
- Unit: `get_transactions` returns most recent first, respects limit/offset
- Unit: `check_sufficient(cost=3)` with balance=5 returns True
- Unit: `check_sufficient(cost=3)` with balance=2 returns False

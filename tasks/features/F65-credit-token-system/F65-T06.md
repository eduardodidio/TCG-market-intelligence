# F65-T06: Frontend credit confirmation modal with treasure token card art

**Status:** planned
**Wave:** 2
**Depends on:** T03, T05
**Parallel with:** T05 (mostly — shares useCredits hook)

## User Story

As a collector, when I click "Refresh Price" on a card, I want to see a
confirmation modal showing a treasure token card (MTG style) with my
current balance and the cost, so I understand the credit economy and can
make an informed decision before spending.

### Admin behavior in modal

Admin users still see the confirmation modal (to prevent accidental clicks)
but the modal text says "Admin — no cost" instead of showing a deduction.
The confirm button is always enabled for admins.

### Integration into refresh flows

1. **CollectionCardDetail.tsx**: Refresh button opens CreditConfirmModal
   (cost=1) instead of immediate API call. On confirm, call refresh endpoint.

2. **CollectionCardTile.tsx**: Hover refresh overlay opens modal (cost=1).

3. **DeckCardTile.tsx**: Refresh button opens modal (cost=1).

4. **useCollectionRefresh.ts** (bulk scan): Before triggering scan, open
   CreditConfirmModal (cost=5). On confirm, proceed with existing scan flow.

### Handle 402 responses

If the backend returns 402 (race condition — balance dropped between modal
display and API call):
```tsx
try {
  await refreshCard(id);
} catch (err) {
  if (err.status === 402) {
    // Re-fetch balance via useCredits.refetch()
    // Show "insufficient" state in modal or toast
  }
}
```

# F20-T02: GridSizeToggle Component
- **Wave:** 1
- **Status:** done
- **Depends on:** F20-T01

## Description

Create a `GridSizeToggle` component that renders three icon buttons
(small/medium/large grid) and calls the `setGridSize` callback when
clicked. The active size is visually highlighted.

### Props

```typescript
interface GridSizeToggleProps {
  value: GridSize;
  onChange: (size: GridSize) => void;
}
```

### Design

- Three buttons in a horizontal button group (rounded corners on ends).
- Each button shows an SVG icon representing grid density:
  - Small: 3x3 grid of small squares
  - Medium: 2x2 grid of medium squares
  - Large: 1x2 grid of large squares
- Active button: `bg-slate-600 text-cyan-400 border-cyan-500/50`
- Inactive button: `bg-slate-800 text-slate-400 hover:text-white`
- Each button has `aria-label` (e.g., "Small grid", "Medium grid",
  "Large grid") and `aria-pressed` for accessibility.
- The group has `role="group"` with `aria-label="Grid size"`.

## Acceptance Criteria

- [ ] Component renders 3 buttons with distinct grid icons
- [ ] Active button is visually distinct
- [ ] Clicking a button calls `onChange` with the correct size value
- [ ] Accessible: `aria-label`, `aria-pressed`, `role="group"`
- [ ] Component is purely presentational (no localStorage logic)

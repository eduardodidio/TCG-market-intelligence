# F20-T03: Integrate Grid Size into MyCollection Page
- **Wave:** 1
- **Status:** done
- **Depends on:** F20-T01

## Description

Wire the `useGridSize` hook and `GridSizeToggle` component into the
`MyCollection` page. The grid classes for both the skeleton grid and the
card grid should change based on the selected size. In "small" mode, the
`CollectionCardTile` should render a compact info section.

### Changes to MyCollection.tsx

1. **Import and use hook**: Call `useGridSize()` at the top of
   `MyCollection`.
2. **Add toggle**: Place `<GridSizeToggle>` in the page header area,
   between the filters section and the grid. Right-align it.
3. **Dynamic grid classes**: Replace the hardcoded grid class strings
   on both the skeleton grid (`data-testid="skeleton-grid"`) and the
   card grid (`data-testid="collection-grid"`) with
   `GRID_SIZE_CONFIG[gridSize].gridClasses`.
4. **Compact card tile**: Pass `compact` prop to `CollectionCardTile`.
   When `compact` is true, hide the set/rarity row and the
   quality/language row. Show only: image, name (truncated), and price.

### Layout

```

[                                    [S] [M] [L] ]   <-- toggle row
[Card grid ...]
```

## Acceptance Criteria

- [ ] Grid columns change when toggling between Small, Medium, Large
- [ ] Skeleton grid matches the selected size
- [ ] Small mode hides set/rarity/quality rows on cards
- [ ] Medium mode matches current behavior exactly (no visual regression)
- [ ] Large mode shows larger cards with full info
- [ ] Toggle position is right-aligned above the grid
- [ ] Size preference survives page reload (localStorage)

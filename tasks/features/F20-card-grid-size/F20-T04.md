# F20-T04: Tests for Grid Size Feature
- **Wave:** 2
- **Status:** done
- **Depends on:** F20-T01, F20-T02, F20-T03

## Description

Write tests for all new code introduced in F20: the `useGridSize` hook,
the `GridSizeToggle` component, and the integration in `MyCollection`.

### Test Suites

**1. useGridSize hook** (`frontend/tests/hooks/useGridSize.test.ts`)
- Returns `"md"` when localStorage is empty
- Returns `"md"` when localStorage has invalid value
- Returns stored value when localStorage has valid `"sm"`, `"md"`, `"lg"`
- `setGridSize` updates both state and localStorage
- Multiple instances stay in sync (same localStorage key)

**2. GridSizeToggle** (`frontend/tests/components/GridSizeToggle.test.tsx`)
- Renders 3 buttons
- Active button has `aria-pressed="true"`
- Inactive buttons have `aria-pressed="false"`
- Click calls `onChange` with correct size
- Accessible group label exists

**3. MyCollection integration** (`frontend/tests/pages/MyCollection.test.tsx`)
- Grid uses medium classes by default
- Extend existing test file with grid-size-specific tests
- Skeleton grid also uses the selected size classes

## Acceptance Criteria

- [ ] Hook tests cover default, invalid, valid, and setter scenarios
- [ ] Component tests cover rendering, active state, click handling
- [ ] Page integration tests verify grid classes change with size
- [ ] All new tests pass with `npm run test`
- [ ] No existing tests broken

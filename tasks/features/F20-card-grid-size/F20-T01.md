# F20-T01: useGridSize Hook and Grid Size Constants
- **Wave:** 0
- **Status:** done
- **Depends on:** none

## Description

Create a custom React hook `useGridSize` that reads/writes the grid size
preference to localStorage and exposes the current value plus a setter.
Also define the grid size configuration constants (Tailwind class
strings per size).

### Hook API

```typescript
type GridSize = "sm" | "md" | "lg";

function useGridSize(): {
  gridSize: GridSize;
  setGridSize: (size: GridSize) => void;
};
```

- localStorage key: `tcg:grid-size`
- Default: `"md"`
- Invalid/missing values fall back to `"md"`

### Grid Size Config

Add to `frontend/src/utils/constants.ts` (or a new dedicated file if
constants.ts is getting large):

```typescript
export const GRID_SIZE_CONFIG: Record<GridSize, {
  gridClasses: string;    // Tailwind grid-cols + gap
  label: string;          // Accessible label
  compact: boolean;       // Whether card info is condensed
}>;
```

| Size | gridClasses | compact |
|------|-------------|---------|
| `sm` | `grid-cols-3 sm:grid-cols-4 md:grid-cols-5 xl:grid-cols-8 gap-3` | true |
| `md` | `grid-cols-2 sm:grid-cols-3 md:grid-cols-4 xl:grid-cols-6 gap-4` | false |
| `lg` | `grid-cols-1 sm:grid-cols-2 md:grid-cols-3 xl:grid-cols-4 gap-5` | false |

## Acceptance Criteria

- [ ] `useGridSize` hook reads from and writes to localStorage
- [ ] Invalid localStorage values fall back to `"md"`
- [ ] `GRID_SIZE_CONFIG` exported with correct Tailwind classes for all 3 sizes
- [ ] Hook triggers re-render on size change
- [ ] No backend changes

# F59-T03 — PriceSourceBadge "liga" support + i18n keys

**Status:** planned
**Wave:** 1
**Depends on:** F59-T01

## User Story

As a collector, I want to see a "LigaMagic" label on prices fetched from
Liga so I know the source of the price data.

## Dev Notes

### PriceSourceBadge

In `frontend/src/components/PriceSourceBadge.tsx`:

- Add `"liga"` to the source label map → "LigaMagic"
- Use violet/purple color for Liga badge (consistent with Liga button)
- Example: `bg-violet-600/20 text-violet-400`

### sourceLabel helper

In `CollectionCardDetail.tsx`, the `sourceLabel()` function maps source
strings to display names. Add:

```ts
liga: "LigaMagic",
```

### i18n keys

Add to both `frontend/src/i18n/locales/en.json` and `pt-BR.json`:

```json
"collection.refreshLiga": "LigaMagic" / "LigaMagic",
"collection.refreshLigaTooltip": "Fetch price from LigaMagic (~10s)" / "Buscar preco na LigaMagic (~10s)",
"collection.refreshLigaSuccess": "Price updated from LigaMagic" / "Preco atualizado via LigaMagic",
"collection.refreshLigaNotFound": "Card not found on LigaMagic" / "Card nao encontrada na LigaMagic",
"collection.refreshLigaError": "LigaMagic fetch failed" / "Falha ao buscar na LigaMagic",
"collection.refreshLigaRateLimit": "LigaMagic rate limited, try later" / "LigaMagic limitou requisicoes, tente depois",
"priceSource.liga": "LigaMagic" / "LigaMagic"
```

### Key files to modify

- `frontend/src/components/PriceSourceBadge.tsx`
- `frontend/src/pages/CollectionCardDetail.tsx` (sourceLabel)
- `frontend/src/i18n/locales/en.json`
- `frontend/src/i18n/locales/pt-BR.json`

## Testing

### Unit tests

- `PriceSourceBadge` renders "LigaMagic" for `source="liga"`
- `PriceSourceBadge` uses violet color variant for liga
- i18n keys resolve correctly in both locales

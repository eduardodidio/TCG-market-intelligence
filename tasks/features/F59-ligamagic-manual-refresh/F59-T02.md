# F59-T02 — Frontend: LigaMagic refresh button on card detail

**Status:** planned
**Wave:** 1
**Depends on:** F59-T01

## User Story

As a collector viewing a card's detail page, I want a distinct "LigaMagic"
button so I can fetch the price from LigaMagic independently of MYP.

## Dev Notes

### API client

Add to `frontend/src/api/collection.ts`:

```ts
export function refreshCardPriceLiga(
  entryId: number,
  params?: Record<string, string>,
): Promise<ApiResponse<CollectionCardDetail>> {
  const query = params ? "?" + new URLSearchParams(params).toString() : "";
  return apiPost<CollectionCardDetail>(
    `/api/v1/collection/${entryId}/refresh-liga${query}`,
    {},
    { timeoutMs: 45000 },  // Liga is slow (~5-10s)
  );
}
```

### CollectionCardDetail changes

In `frontend/src/pages/CollectionCardDetail.tsx`:

1. Add `refreshingLiga` state (separate from `refreshing` which is MYP)
2. Add `handleRefreshLiga` callback:
   - Calls `refreshCardPriceLiga(entryId, { currency })`
   - On success: update entry via `setEntry`, show success message
   - On warning (errors[] present): show amber warning
   - On error: show red error message
3. Render button in the "Latest price" section, below existing refresh button:
   - Purple/violet accent to distinguish from MYP's cyan refresh
   - SVG icon: globe or external link (indicating external source)
   - Text: t("collection.refreshLiga")
   - Disabled when `refreshingLiga` or when no name (name_en + name_pt both null)
   - Show spinner when loading
   - Tooltip: "Fetch price from LigaMagic (~10s)"
4. Auto-dismiss message after 5s (Liga is slower, give user more time to read)

### Button placement

Place after the existing MYP refresh button, in the same flex row:

```
[MYP Refresh ↻] [LigaMagic 🌐]
```

### Visual design

- Background: `bg-violet-600 hover:bg-violet-500` (distinct from MYP cyan)
- Text: `text-white text-xs font-medium`
- Size: compact, same height as MYP refresh button
- Loading: `animate-spin` on icon

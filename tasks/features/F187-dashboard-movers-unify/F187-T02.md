# T02 -- Add Dismiss/Remove to CollectionMovers Rows

- **Wave:** 1
- **Type:** frontend
- **Depends on:** T01
- **Status:** planned

## User Story

As a user viewing the Dashboard collection movers, I want to dismiss individual
cards from the gainers/losers list so I can focus on the movers I care about
during my current session.

## Objective

Add an X (dismiss) button to each `MoverRow` in `CollectionMovers`. Dismissed
rows are hidden for the current browser session only (React state, not persisted
to backend or localStorage).

## Dev Notes

### Step 1: Add `onDismiss` prop to MoverRow

In `CollectionMovers.tsx`, extend the `MoverRowProps` interface:

```typescript
export interface MoverRowProps {
  mover: CollectionMoverData;
  type: "gainer" | "loser";
  onDismiss?: (cardId: number) => void;  // NEW
}
```

When `onDismiss` is provided, render an X button on the right side of the row
(before the price column, or as an overlay on hover):

```tsx
{onDismiss && (
  <button
    onClick={(e) => {
      e.preventDefault();   // prevent Link navigation
      e.stopPropagation();  // prevent event bubbling to Link
      onDismiss(mover.card_id);
    }}
    className="flex-shrink-0 p-1 text-slate-500 hover:text-slate-300
      opacity-0 group-hover:opacity-100 transition-opacity"
    aria-label={t("movers.dismiss")}
    data-testid={`mover-dismiss-${mover.card_id}`}
  >
    <svg className="h-3.5 w-3.5" fill="none" viewBox="0 0 24 24"
      stroke="currentColor" strokeWidth={2}>
      <path strokeLinecap="round" strokeLinejoin="round"
        d="M6 18L18 6M6 6l12 12" />
    </svg>
  </button>
)}
```

Add `group` class to the `MoverRow` root `<Link>` element so `group-hover`
works for the X button visibility.

### Step 2: Add dismiss state to CollectionMovers

In the `CollectionMovers` component:

```typescript
const [dismissed, setDismissed] = useState<Set<number>>(new Set());

const handleDismiss = useCallback((cardId: number) => {
  setDismissed((prev) => new Set(prev).add(cardId));
}, []);
```

Filter out dismissed cards before rendering:

```typescript
const visibleGainers = data.gainers.filter((m) => !dismissed.has(m.card_id));
const visibleLosers = data.losers.filter((m) => !dismissed.has(m.card_id));
```

Use `visibleGainers` / `visibleLosers` in the render. Update the empty check
to use the filtered arrays.

Pass `onDismiss={handleDismiss}` to each `MoverRow` in `CollectionMovers`.

**Do NOT pass `onDismiss` from `DashboardTrendingMovers`** -- the dismiss
feature is only for the collection movers section per the requirement.

### Step 3: Add i18n key

Add to `en.json` under `movers`:
```json
"dismiss": "Dismiss"
```

Add to `pt-BR.json` under `movers`:
```json
"dismiss": "Dispensar"
```

### Step 4: Visual polish

- The X button should be invisible by default and appear on row hover
  (`opacity-0 group-hover:opacity-100`).
- On mobile (touch devices), the button should always be visible since there is
  no hover. Add `md:opacity-0 md:group-hover:opacity-100` pattern (always
  visible on small screens, hover-reveal on desktop).
- When a row is dismissed, it simply disappears (no animation needed per the
  brief: "just hide for the current session").

## Acceptance Criteria

1. Each `MoverRow` in `CollectionMovers` displays an X button on hover (desktop)
   or always visible (mobile).
2. Clicking the X button hides the row immediately without navigating to the
   card detail page.
3. Dismissed rows do not reappear during the current session (until page reload).
4. The dismiss button has `aria-label` for accessibility.
5. `DashboardTrendingMovers` does NOT have dismiss buttons (onDismiss is not
   passed).
6. `npm run build` passes.

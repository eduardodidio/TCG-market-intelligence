## Dev Notes

### File 1: `frontend/src/components/__tests__/DashboardTrendingMovers.test.tsx`

Mock `fetchTrending` from `../../api/trending`. Mock `useCardName` hook.

**Test scenarios:**

1. **Renders gainers with MoverRow style** -- provide API response with 2
   `TrendingCardEntry` items, assert card thumbnails (`img` with `h-10 w-7`
   class or alt text), card names, set codes, and price changes are visible.
   Assert container has `bg-slate-800` class.

2. **Renders losers with red color** -- direction="losers", verify header text
   uses losers title key and red color class.

3. **Shows loading skeleton** -- API returns a pending promise, assert
   `animate-pulse` skeleton is rendered.

4. **Shows error with retry** -- API rejects, assert error message is visible.
   Click retry, assert `fetchTrending` is called again.

5. **Shows empty state** -- API returns `{ cards: [] }`, assert empty message.

6. **Maps image_url to image_uri correctly** -- provide entry with `image_url:
   "https://example.com/img.jpg"`, assert `<img>` has that src. Provide entry
   with `image_url: null`, assert placeholder div is rendered.

7. **Passes collectionOnly param to API** -- assert `fetchTrending` is called
   with `collection_only: "true"` when `collectionOnly={true}`.

8. **Each row links to /cards/{card_id}** -- assert `<a>` elements have correct
   href.

### File 2: `frontend/src/components/__tests__/CollectionMoversDismiss.test.tsx`

Mock `fetchCollectionMovers` from `../../api/collection`.

Provide test data:
```typescript
const mockData = {
  gainers: [
    { card_id: 1, card_name: "Card A", set_code: "SET", image_uri: null,
      price_start: 10, price_end: 15, change_abs: 5, change_pct: 50 },
    { card_id: 2, card_name: "Card B", set_code: "SET", image_uri: null,
      price_start: 20, price_end: 25, change_abs: 5, change_pct: 25 },
  ],
  losers: [
    { card_id: 3, card_name: "Card C", set_code: "SET", image_uri: null,
      price_start: 30, price_end: 25, change_abs: -5, change_pct: -16.7 },
  ],
  period_days: 7,
};
```

**Test scenarios:**

1. **Dismiss button is visible on hover** -- render `CollectionMovers`, assert
   dismiss buttons exist with correct `data-testid` (`mover-dismiss-{card_id}`).

2. **Clicking dismiss hides the row** -- click dismiss on card_id=1, assert
   "Card A" is no longer in the document, "Card B" is still visible.

3. **Dismiss does not navigate** -- after clicking dismiss, assert no navigation
   occurred (the `<Link>` click handler was prevented).

4. **Multiple dismisses work independently** -- dismiss card_id=1 from gainers,
   then card_id=3 from losers, both should be hidden.

5. **Dismissed cards persist within session** -- dismiss card_id=1, trigger a
   re-render (e.g., click "Show Top 10"), assert card_id=1 is still hidden
   after re-fetch.

6. **MoverRow without onDismiss has no dismiss button** -- render `MoverRow`
   without `onDismiss`, assert no dismiss button exists.

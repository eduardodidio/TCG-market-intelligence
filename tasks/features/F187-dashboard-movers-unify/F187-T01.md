- **Wave:** 0
- **Type:** frontend

## User Story

As a user viewing the Dashboard, I want the "Em Alta" and "Em Baixa" sections
to have the same visual style as the "Movimentacao da Colecao" movers panel --
card thumbnails, consistent containers, same price formatting -- so the
Dashboard looks unified and professional.

## Objective

Replace the `TrendingSection variant="list"` usage on Dashboard with a new
`DashboardTrendingMovers` component that fetches trending data but renders using
the same `MoverRow` visual style extracted from `CollectionMovers`.

## Dev Notes

### Step 1: Extract MoverRow from CollectionMovers.tsx

The `MoverRow` component (lines 16-51 of `CollectionMovers.tsx`) is currently a
private function inside the file. Extract it as a **named export** so it can be
reused:

```typescript
// In CollectionMovers.tsx -- change from:
function MoverRow({ mover, type }: MoverRowProps) { ... }

// To:
export function MoverRow({ mover, type }: MoverRowProps) { ... }
```

Also export the `MoverRowProps` interface and `CollectionMoverData` type
re-export (or import it directly from `../api/collection`).

The `MoverRow` internal structure stays identical. No behavior change to
`CollectionMovers`.

### Step 2: Create DashboardTrendingMovers component

New file: `frontend/src/components/DashboardTrendingMovers.tsx`

This component:
1. Accepts props: `direction: "gainers" | "losers"`, `period: string`,
   `currency: string`, `limit?: number`, `collectionOnly?: boolean`
2. Fetches data using `fetchTrending(direction, params)` (same API as
   TrendingSection)
3. Maps `TrendingCardEntry[]` to the shape `MoverRow` expects:
   ```typescript
   const mapped: CollectionMoverData = {
     card_id: entry.card_id,
     card_name: getCardName(entry.name_en, entry.name_pt),
     set_code: entry.set_code,
     image_uri: entry.image_url,   // TrendingCardEntry uses image_url
     price_start: entry.price_start,
     price_end: entry.price_end,
     change_abs: entry.change_abs,
     change_pct: entry.change_pct,
   };
   ```
4. Renders with the exact same container as CollectionMovers:
   - Outer: `bg-slate-800 rounded-lg p-4 border border-slate-600`
   - Header: direction-colored h4 (emerald for gainers, red for losers)
   - Content: `MoverRow` for each mapped entry
   - Uses `useCardName` hook for name resolution (pt vs en)
5. Loading state: `animate-pulse bg-slate-700/50 rounded-lg h-48`
6. Error state: `ErrorBanner` with retry (matching TrendingSection pattern)
7. Empty state: text message in slate-500
8. Has `data-testid="dashboard-trending-{direction}"` on the outer container

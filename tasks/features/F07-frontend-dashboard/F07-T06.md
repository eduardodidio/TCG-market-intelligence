**Wave:** 2

## User Story

As a user, I want to see complete tables of the biggest price gainers and losers over selectable time periods so that I can identify market trends and opportunities.

## Dev Notes

### Movers Table (`src/components/MoversTable.tsx`)

- Reusable table component for both gainers and losers.
- Props: `entries: MoverEntry[]`, `title: string`, `type: 'gainers' | 'losers'`.
- Table columns:
  1. **Rank** — row number (1, 2, 3...).
  2. **Card** — `name_en`, linked to `/cards/:card_id`. Below in muted text: set code.
  3. **Start Price** — `formatBRL(price_start)`.
  4. **End Price** — `formatBRL(price_end)`.
  5. **Change** — `formatPercent(change_pct)`, green for positive, red for negative. Bold.
- Table styling: `bg-slate-800 rounded-xl`, header row `bg-slate-700/50`, alternating row backgrounds `bg-slate-800/bg-slate-850`, hover `bg-slate-700`.
- Mobile responsive: on small screens, hide "Start Price" and "End Price" columns, show only Card + Change.

### Period Selector

- Shared period selector at the top of the page.
- Options: `7d` (7 days), `30d` (30 days), `90d` (90 days).
- Button group: active button `bg-cyan-500 text-white`, inactive `bg-slate-700 text-slate-300`.
- Default period: `7d`.
- Changing period re-fetches `GET /api/v1/market/movers?period={period}&limit=25`.

### Limit Selector (optional)

- Dropdown or button group to select how many results: 10, 25, 50.
- Default: 25.

### Market Movers Page Assembly (`src/pages/MarketMovers.tsx`)

- Page title: "Market Movers".
- Period selector at top.
- Two tables side by side on desktop (grid-cols-2), stacked on mobile.
- Left table: "Top Gainers" with green accent header.
- Right table: "Top Losers" with red accent header.
- Loading spinner while fetching.
- Error banner if API fails.
- Empty state: "No movers data available for this period."

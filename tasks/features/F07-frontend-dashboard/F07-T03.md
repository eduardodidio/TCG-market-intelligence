# F07-T03: Dashboard page — market stats KPIs and movers preview

**Wave:** 1
**Status:** done
**Estimate:** M

## User Story

As a user, I want to see a dashboard with key market statistics and a quick preview of top gainers and losers so that I can get an at-a-glance view of the TCG market.

## Dev Notes

### KPI Cards Section

- Create a `KpiCard` component (`src/components/KpiCard.tsx`):
  - Props: `title: string`, `value: string`, `subtitle?: string`, `icon?: ReactNode`.
  - Dark card style: `bg-slate-800 rounded-xl p-6`, title in `text-slate-400 text-sm`, value in `text-2xl font-bold text-white`.
- Dashboard fetches `GET /api/v1/market/stats` using `useApi` hook.
- Render 4 KPI cards in a responsive grid (2 cols on mobile, 4 cols on desktop):
  1. **Total Cards** — `marketStats.total_cards`, subtitle "cards tracked"
  2. **Total Observations** — `marketStats.total_observations`, subtitle "price points"
  3. **Average Price** — `formatBRL(marketStats.avg_price)`, subtitle "across all cards"
  4. **Data Range** — formatted date range from `date_range_start` to `date_range_end`

### Movers Preview Section

- Dashboard also fetches `GET /api/v1/market/movers?period=7d&limit=5`.
- Create a compact `MoversPreview` component that shows:
  - Two columns side by side: "Top Gainers" and "Top Losers".
  - Each entry: card name, set code badge, percentage change (green for gainers, red for losers).
  - "View all" link at the bottom of each column that navigates to `/market/movers`.
- Use `react-router-dom` `Link` for navigation to card detail (`/cards/:id`) when clicking a card name.

### Dashboard Page Assembly (`src/pages/Dashboard.tsx`)

- Page title: "Dashboard" or "Market Overview" as an `<h1>`.
- KPI cards grid at the top.
- Movers preview below.
- Show `LoadingSpinner` component while data loads.
- Show `ErrorBanner` component if API calls fail.
- Create `LoadingSpinner` (`src/components/LoadingSpinner.tsx`): centered spinner animation with Tailwind.
- Create `ErrorBanner` (`src/components/ErrorBanner.tsx`): red banner with error message and optional retry button.

### Component Design

- All components use Tailwind utility classes.
- Follow the dark theme palette: `bg-slate-900` page background, `bg-slate-800` cards, `text-cyan-400` for accents, `text-green-400` for positive values, `text-red-400` for negative values.

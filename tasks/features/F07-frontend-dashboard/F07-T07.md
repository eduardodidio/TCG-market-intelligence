# F07-T07: Responsive polish, loading/error UX, and accessibility

**Wave:** 3
**Status:** done
**Estimate:** M

## User Story

As a user, I want the application to work well on mobile devices and tablets, handle loading and error states gracefully, and be usable with keyboard navigation so that I have a reliable experience on any device.

## Dev Notes

### Responsive Layout Audit

- Test all pages at 3 breakpoints: mobile (375px), tablet (768px), desktop (1280px).
- Sidebar (`Layout.tsx`):
  - Desktop: fixed sidebar (w-64), main content offset.
  - Mobile/tablet: sidebar hidden by default, hamburger button in top bar toggles sidebar as overlay.
  - Close sidebar on route change (mobile).
  - Close sidebar on click outside (mobile).
- Card grid (`Cards.tsx`): verify 2/3/4/6 column breakpoints.
- Movers tables (`MarketMovers.tsx`): verify stacking and column hiding.
- Chart (`PriceChart.tsx`): verify it reflows on resize.
- KPI cards (`Dashboard.tsx`): verify 2/4 column breakpoints.

### Loading States

- Create a `Skeleton` component (`src/components/Skeleton.tsx`):
  - Pulsing placeholder blocks (Tailwind `animate-pulse bg-slate-700 rounded`).
  - Variants: `SkeletonCard` (card tile shape), `SkeletonTable` (table rows), `SkeletonKpi` (KPI card shape).
- Replace `LoadingSpinner` with contextual skeletons on each page:
  - Dashboard: 4 skeleton KPI cards + skeleton movers rows.
  - Cards: grid of skeleton card tiles.
  - Card Detail: skeleton info panel + skeleton chart area.
  - Market Movers: skeleton table rows.
- Keep `LoadingSpinner` for inline loading indicators (e.g., "Load more" button).

### Error State Improvements

- `ErrorBanner` supports `variant: 'full' | 'inline'`:
  - `full`: centered on page with icon, used for page-level errors.
  - `inline`: small banner, used for section-level errors (e.g., chart fails but card info succeeded).
- Network error detection: if `fetch` fails with `TypeError` (network down), show specific "Unable to connect to the server. Please check your connection." message.
- API error display: show error codes from the envelope `errors` array.

### Empty States

- Create an `EmptyState` component (`src/components/EmptyState.tsx`):
  - Props: `message: string`, `icon?: ReactNode`, `action?: { label: string, onClick: () => void }`.
  - Used when API returns valid response but empty data.
- Apply on Cards page ("No cards found. Try a different search."), Movers page, Dashboard movers preview.

### Accessibility

- All interactive elements are keyboard-focusable (buttons, links, inputs).
- Focus ring visible on keyboard navigation (`focus-visible:ring-2 ring-cyan-400`).
- Sidebar hamburger has `aria-label="Toggle navigation"`.
- Tables have proper `<thead>`, `<th scope="col">`, `<tbody>` structure.
- Images / placeholders have `alt` text.
- Color is not the only indicator for gain/loss (also use +/- sign and up/down arrow icons).
- Page titles set via `document.title` or a custom hook for each route.

### Performance

- Lazy-load route pages with `React.lazy` and `Suspense` in `App.tsx`.
- Recharts should only be imported in the `CardDetail` page (not in the main bundle).

# F07-T05: Card Detail page with interactive price history chart

**Wave:** 2
**Status:** done
**Estimate:** L

## User Story

As a user, I want to view a card's full details and its price history on an interactive chart so that I can understand price trends over time.

## Dev Notes

### Card Info Panel

- Fetch `GET /api/v1/cards/:id` on mount using the route param `id`.
- Display card information in a two-column layout (info + chart):
  - **Left panel** (or top on mobile):
    - Card name (EN), with PT name below in muted text if different.
    - Set code and collector number.
    - Game badge.
    - Latest price in large, bold BRL format.
    - Source links: for each `source_card`, render a link to its `url` (opens in new tab). Label with source name (e.g., "MYP Cards").
    - Timestamps: "First tracked" (`created_at`), "Last updated" (`updated_at`), formatted as dates.
  - **Right panel** (or bottom on mobile): the price chart.

### Price History Chart (`src/components/PriceChart.tsx`)

- Use **Recharts** `LineChart` component.
- Fetch `GET /api/v1/cards/:id/history?period={period}` when period changes.
- Period selector: row of buttons/tabs for `30d`, `90d`, `180d`, `1y`, `3y`. Active button highlighted in cyan.
- Chart configuration:
  - X-axis: `observed_at` dates, formatted as `DD/MM`.
  - Y-axis: price in BRL, auto-scaled.
  - Lines: `median_price` (primary, cyan), `tcg_price` (secondary, dashed, slate-400), `last_sold_price` (tertiary, dotted, green-400).
  - Tooltip: show date, all price values formatted as BRL, and `quantity_available`.
  - Legend: show line labels.
  - Responsive: chart fills its container width.
  - Grid: subtle `stroke="#334155"` (slate-700).
- Dark theme: `bg-slate-800 rounded-xl p-4`, white text for labels.
- Handle empty data: show "No price history available" message.

### Card Detail Page Assembly (`src/pages/CardDetail.tsx`)

- Route: `/cards/:id`, extract `id` from `useParams`.
- Breadcrumb: "Cards > Card Name" with link back to `/cards`.
- Two API calls: card detail + price history (initial period: `90d`).
- Loading and error states for both calls independently.
- 404 handling: if card not found (API returns error), show "Card not found" with link back to cards list.

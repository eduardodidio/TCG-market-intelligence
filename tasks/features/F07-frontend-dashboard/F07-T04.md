# F07-T04: Cards list page — search, filters, and cursor pagination

**Wave:** 1
**Status:** done
**Estimate:** L

## User Story

As a user, I want to browse all tracked cards in a searchable, filterable grid with pagination so that I can find specific cards and see their current prices.

## Dev Notes

### Search Bar (`src/components/SearchBar.tsx`)

- Text input with search icon, debounced (300ms) via `useDebounce` hook.
- Placeholder: "Search cards by name..."
- On value change, update the `name` query parameter for the API call.
- Styled: `bg-slate-800 border border-slate-700 rounded-lg`, focus ring in cyan.

### Filter Chips (`src/components/FilterChips.tsx`)

- Fetch `GET /api/v1/sets` on mount to populate set filter options.
- Render as horizontal scrollable row of chips/pills.
- Props: `options: Array<{ label: string, value: string }>`, `selected: string | null`, `onSelect: (value: string | null) => void`.
- Active chip: `bg-cyan-500 text-white`, inactive: `bg-slate-700 text-slate-300`.
- First chip is "All" (clears filter).
- Game filter: hardcoded chips for "magic" (only game currently).

### Card Tile (`src/components/CardTile.tsx`)

- Props: `card: CardSummary`.
- Display:
  - Placeholder image area (gradient background or card-back icon, ~200x280 aspect ratio).
  - Card name (`name_en`, fallback to `name_pt`).
  - Set code badge (small pill).
  - Collector number in muted text.
  - Latest price formatted as BRL, or "--" if null.
- Entire tile is a `Link` to `/cards/${card.id}`.
- Hover effect: subtle border glow or scale transform.
- Dark card style: `bg-slate-800 rounded-xl overflow-hidden`.

### Pagination (`src/components/Pagination.tsx`)

- Cursor-based: "Load more" button pattern (simpler than page numbers for cursor pagination).
- Props: `cursor: string | null`, `onLoadMore: () => void`, `loading: boolean`.
- Show "Load more" button if `cursor` is not null.
- Alternative: infinite scroll with intersection observer (developer's choice, but "Load more" button is simpler and recommended).

### Cards Page (`src/pages/Cards.tsx`)

- State management:
  - `searchTerm` (string) — debounced before API call.
  - `selectedSet` (string | null) — set filter.
  - `cards` (CardSummary[]) — accumulated cards list.
  - `cursor` (string | null) — for pagination.
- On mount and on filter change: reset cards list and cursor, fetch `GET /api/v1/cards` with params `{ name, set, limit: 24 }`.
- On "Load more": fetch next page with `cursor` param, append results to existing cards.
- Display cards in a responsive grid: 2 cols on mobile, 3 on tablet, 4 on desktop, 6 on wide screens.
- Show `LoadingSpinner` on initial load.
- Show "No cards found" message when results are empty.
- Page title: "Explore Cards".

### URL Sync (optional but recommended)

- Sync search and filter state to URL query params (`?name=...&set=...`) using `useSearchParams` from React Router.
- This allows bookmarking and sharing filtered views.

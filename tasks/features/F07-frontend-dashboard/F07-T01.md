# F07-T01: Vite project scaffolding, dependencies, and Tailwind setup

**Wave:** 0
**Status:** done
**Estimate:** M

## User Story

As a developer, I want a fully configured Vite + React + TypeScript project with Tailwind CSS in the `frontend/` directory so that subsequent tasks can build pages on a stable foundation.

## Dev Notes

- Create `frontend/` at the repository root. All front-end code lives here.
- Initialize with `npm create vite@latest . -- --template react-ts` (run inside `frontend/`), or manually create the equivalent files.
- Install runtime deps: `react`, `react-dom`, `react-router-dom`, `recharts`.
- Install dev deps: `vite`, `@vitejs/plugin-react`, `typescript`, `tailwindcss`, `postcss`, `autoprefixer`, `vitest`, `@testing-library/react`, `@testing-library/jest-dom`, `jsdom`, `@types/react`, `@types/react-dom`.
- Configure Tailwind CSS:
  - `tailwind.config.ts`: set `darkMode: 'class'`, content paths to `./src/**/*.{ts,tsx}`.
  - `postcss.config.js`: include tailwindcss and autoprefixer plugins.
  - Create `src/index.css` with Tailwind directives (`@tailwind base; @tailwind components; @tailwind utilities;`).
  - Define a dark theme color palette: background slate-900, surface slate-800, accent cyan-400/green-400, text slate-100.
- Configure `vite.config.ts`:
  - React plugin.
  - Dev server proxy: `/api` proxied to `http://localhost:8000` (FastAPI backend).
  - `/health` also proxied.
- Configure `tsconfig.json`: strict mode, `baseUrl: "."`, path alias `@/` mapping to `src/`.
- Configure `vitest` in `vite.config.ts`: `test.environment: 'jsdom'`, `test.globals: true`, `test.setupFiles: './tests/setup.ts'`.
- Create `tests/setup.ts` that imports `@testing-library/jest-dom`.
- Create placeholder `src/main.tsx` that renders a `<div>App loading...</div>` (imports App from `./App` — T02 creates `App.tsx`).
- Add `package.json` scripts: `dev`, `build`, `preview`, `test`, `test:coverage`, `lint`.
- Add `.gitignore` inside `frontend/` for `node_modules/`, `dist/`, `coverage/`.
- Verify: `npm run build` succeeds, `npm run test` runs (even with 0 tests), `npm run dev` starts without errors.

## Dev Notes

### ADR: `docs/adr/0003-frontend-stack.md`

Document the front-end technology decisions:
- **Title**: Front-end Stack: Vite + React + TypeScript + Tailwind + Recharts
- **Status**: accepted
- **Context**: Need a web dashboard to visualize TCG price data from the REST API. Requirements are dark theme, responsive, chart-heavy, developer-friendly.
- **Decision**: Vite for build tooling (fast HMR), React 18 with hooks (widely adopted, good ecosystem), TypeScript (type safety), Tailwind CSS (utility-first, dark theme support), Recharts (lightweight React-native charts), Vitest (Vite-native testing).
- **Consequences**: Adds Node.js toolchain to the project. Front-end lives in `frontend/` in the mono-repo. Developers need Node 18+ installed. No SSR needed (SPA is sufficient for internal/data tool).
- **Alternatives considered**: Vue.js (smaller community for charting), plain HTML + Chart.js (less maintainable), Next.js (SSR overkill for this use case).

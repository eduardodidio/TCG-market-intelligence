# F07-T02: API client, TypeScript types, and routing shell

**Wave:** 0
**Status:** done

## User Story

As a developer, I want TypeScript interfaces mirroring the API schemas, a typed fetch wrapper, and a React Router shell so that page tasks can immediately call the API and render within the app layout.

## Dev Notes

### TypeScript Types (`src/types/api.ts`)

Mirror the Pydantic schemas from the backend exactly:

```typescript
// Response envelope
interface ApiResponse<T> {
  data: T | null;
  meta: { cursor: string | null; total: number | null; request_id: string };
  errors: Array<{ code: string; message: string; field?: string }>;
}

// Card types
interface CardSummary {
  id: number;
  game: string;
  name_en: string;
  name_pt: string | null;
  set_code: string | null;
  collector_number: string | null;
  latest_price: number | null;  // Decimal -> number in JS
}

interface SourceCard {
  source: string;
  external_id: string;
  sku: string | null;
  url: string;
}

interface CardDetail extends CardSummary {
  source_cards: SourceCard[];
  created_at: string;  // ISO datetime
  updated_at: string;
}

interface PriceObservation {
  observed_at: string;  // ISO date
  median_price: number | null;
  tcg_price: number | null;
  last_sold_price: number | null;
  quantity_available: number | null;
  currency: string;
}

// Set types
interface SetSummary {
  set_code: string;
  game: string;
  card_count: number;
}

// Market types
interface MoverEntry {
  card_id: number;
  name_en: string;
  set_code: string | null;
  price_start: number;
  price_end: number;
  change_pct: number;
}

interface MoversResponse {
  gainers: MoverEntry[];
  losers: MoverEntry[];
}

interface MarketStats {
  total_cards: number;
  total_observations: number;
  avg_price: number | null;
  date_range_start: string | null;
  date_range_end: string | null;
}
```

### API Client (`src/api/client.ts`)

- Create a thin fetch wrapper: `apiGet<T>(path: string, params?: Record<string, string>): Promise<ApiResponse<T>>`
- Base URL from `import.meta.env.VITE_API_BASE_URL` with fallback to `""` (same-origin, handled by Vite proxy in dev).
- Handle HTTP errors by returning them in the envelope `errors` array.
- Add request timeout (10s default).

### API Functions (`src/api/cards.ts`, `src/api/market.ts`, `src/api/sets.ts`)

- `fetchCards(params)` -> `apiGet<CardSummary[]>('/api/v1/cards', params)`
- `fetchCardDetail(id)` -> `apiGet<CardDetail>('/api/v1/cards/${id}')`
- `fetchCardHistory(id, period)` -> `apiGet<PriceObservation[]>('/api/v1/cards/${id}/history', { period })`
- `fetchSets()` -> `apiGet<SetSummary[]>('/api/v1/sets')`
- `fetchMovers(params)` -> `apiGet<MoversResponse>('/api/v1/market/movers', params)`
- `fetchMarketStats()` -> `apiGet<MarketStats>('/api/v1/market/stats')`

### Custom Hook (`src/hooks/useApi.ts`)

- Generic `useApi<T>(fetcher: () => Promise<ApiResponse<T>>)` hook.
- Returns `{ data: T | null, loading: boolean, error: string | null, refetch: () => void }`.
- Handles loading state, error extraction from envelope, and cleanup on unmount (AbortController).

### Utility Hook (`src/hooks/useDebounce.ts`)

- `useDebounce<T>(value: T, delayMs: number): T` — debounces input for search.

### Routing Shell (`src/App.tsx`)

- Set up React Router with 4 routes:
  - `/` -> `Dashboard` (placeholder)
  - `/cards` -> `Cards` (placeholder)
  - `/cards/:id` -> `CardDetail` (placeholder)
  - `/market/movers` -> `MarketMovers` (placeholder)
- Create a `Layout` component with:
  - Sidebar navigation (Dashboard, Explore Cards, Market Movers).
  - Main content area where routes render via `<Outlet />`.
  - Dark theme applied via `dark` class on `<html>`.
  - Responsive: sidebar collapses to hamburger menu on mobile (< 768px).
- Create placeholder page components in `src/pages/` that render their route name.

### Formatters (`src/utils/format.ts`)

- `formatBRL(value: number | null): string` — formats as `R$ 1.234,56` (Brazilian locale).
- `formatPercent(value: number): string` — formats as `+12,3%` or `-5,7%` with sign and color hint.
- `formatDate(iso: string): string` — formats as `DD/MM/YYYY`.

### Constants (`src/utils/constants.ts`)

- `API_BASE_URL`
- `PERIOD_OPTIONS`: `[{ label: '30 dias', value: '30d' }, ...]`
- `DEFAULT_PAGE_LIMIT`: 24 (card grid)

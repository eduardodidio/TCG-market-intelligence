# F69-T05: Frontend trade flow — interest, negotiation, agreement

**Status:** planned
**Wave:** 3
**Depends on:** T04

## User Story

As a trader, I want a complete flow to express interest in a card, negotiate
with the owner, and confirm a trade agreement — seeing credit fees clearly
before committing — so I can safely trade cards through the platform.

## Dev Notes

### My Trades page: `frontend/src/pages/MyTrades.tsx`

Two tabs:
1. **As Buyer**: Trade interests I expressed (status, card, fee)
2. **As Seller**: Trade interests received on my cards (accept/reject actions)

Each trade shows:
- Card thumbnail + name
- Status badge (pending/accepted/rejected/completed)
- Estimated fee in tokens
- Message from buyer
- Action buttons based on status and role

### Trade interest form (modal)

When clicking "I'm Interested" on marketplace:
```tsx
<TradeInterestModal
  card={card}
  estimatedFee={fee}
  onSubmit={(message) => expressInterest(shareCode, entryId, message)}
/>
```

### Agreement confirmation flow

When seller accepts and both need to confirm:
1. Show fee preview with TreasureTokenCard
2. "Confirm Trade" button
3. On confirm → POST /marketplace/agree/{id}
4. If both confirmed → show revealed email
5. If insufficient credits → show error with balance

### Trade completed view

After both confirm:
```tsx
<div className="bg-green-900/30 border border-green-600 rounded-lg p-4">
  <h3>Trade Completed!</h3>
  <p>Contact: {counterpartyEmail}</p>
  <p>Fee charged: {fee} tokens</p>
</div>
```

### Route in App.tsx

```tsx
<Route path="/marketplace/my-trades" element={<MyTrades />} />
```

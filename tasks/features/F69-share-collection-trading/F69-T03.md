### Trade completion flow

When both parties confirm:
```python
def _complete_trade(interest, agreement, repo, credit_svc):
    fee = calculate_trade_fee(interest.card_price_at_interest)

    # Check both have credits
    if not credit_svc.check_sufficient(interest.buyer_user_id, fee):
        raise HTTPException(402, ...)
    if not credit_svc.check_sufficient(interest.seller_user_id, fee):
        raise HTTPException(402, ...)

    # Deduct from both
    credit_svc.deduct(interest.buyer_user_id, fee, "trade_fee", ref=str(interest.id))
    credit_svc.deduct(interest.seller_user_id, fee, "trade_fee", ref=str(interest.id))

    # Update agreement
    agreement.buyer_fee_charged = fee
    agreement.seller_fee_charged = fee
    agreement.completed_at = datetime.now()

    # Mark interest as completed
    interest.status = "completed"
```

### Security

- Cannot express interest in own cards (self-trade prevention)
- Cannot access non-shared collections
- Email only revealed after both parties confirm
- IDOR prevention: verify user is buyer or seller before allowing actions

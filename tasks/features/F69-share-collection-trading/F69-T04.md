# F69-T04: Frontend marketplace browse page + share toggle

**Status:** done
**Wave:** 2
**Depends on:** T03

## User Story

As a user, I want to browse cards available for trade from other collectors
and toggle whether my own collection is shared, so I can discover trading
opportunities.

## Dev Notes

### Share toggle on MyCollection page

Add a toggle in the collection page header:
```tsx
<label className="flex items-center gap-2">
  <input type="checkbox" checked={isShared} onChange={toggleSharing} />
  <span>{t("marketplace.shareCollection")}</span>
</label>
```

### New page: `frontend/src/pages/Marketplace.tsx`

- Card grid showing available cards from shared collections
- Each card shows: image, name, set, price, estimated fee
- Share code displayed (not user info)
- Search + set filter
- "I'm Interested" button per card → opens interest form

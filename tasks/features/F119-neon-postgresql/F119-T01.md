# F119-T01: Engine Abstraction Layer + Dependencies

**Status:** planned
**Wave:** 0

## User Story

As a developer, I need the application to support both SQLite (local) and
PostgreSQL (Neon production) via environment-based configuration so that
the same codebase works in both environments.

## Dev Notes

### 1. Add psycopg2-binary to requirements.txt

```
psycopg2-binary>=2.9.9
```

This is the PostgreSQL adapter for SQLAlchemy. Binary variant avoids
needing libpq-dev on Render.

### 2. Create `src/database/compat.py`

Thin dialect abstraction:

```python
"""Database dialect compatibility layer."""
from __future__ import annotations

from sqlalchemy import Engine


def is_sqlite(engine: Engine) -> bool:
    """Return True if the engine is SQLite."""
    return engine.dialect.name == "sqlite"


def dialect_insert(engine: Engine, table):
    """Return a dialect-specific insert() for upsert support.

    Both SQLite and PostgreSQL support .on_conflict_do_update() and
    .on_conflict_do_nothing() but require their own dialect insert.
    """
    if is_sqlite(engine):
        from sqlalchemy.dialects.sqlite import insert
    else:
        from sqlalchemy.dialects.postgresql import insert
    return insert(table)
```

### 3. Update `src/config.py`

```python
_DEFAULT_DB_URL = "sqlite:///tcg_market.db"


def get_db_url() -> str:
    """Return the database URL from environment or a smart default.

    Priority:
    1. DATABASE_URL (Neon / standard PG convention)
    2. TCG_DATABASE_URL (legacy)
    3. Auto-detect Render /data dir (SQLite)
    4. Local SQLite default
    """
    for var in ("DATABASE_URL", "TCG_DATABASE_URL"):
        value = os.environ.get(var)
        if value:
            return value
    if os.path.isdir("/data"):
        return "sqlite:////data/tcg_market.db"
    return _DEFAULT_DB_URL
```

### 4. Update `Repository.__init__` engine creation

Add pool settings for PostgreSQL (Neon uses connection pooling):

```python
def __init__(self, db_url: str = "sqlite:///tcg_market.db"):
    kwargs = {"echo": False}
    if not db_url.startswith("sqlite"):
        kwargs.update({
            "pool_size": 5,
            "max_overflow": 10,
            "pool_pre_ping": True,  # handle Neon cold starts
        })
    self.engine = create_engine(db_url, **kwargs)
```

Note: `pool_pre_ping=True` is critical for Neon — the serverless DB
may suspend after 5min idle, and stale connections need to be detected.

## Acceptance Criteria

1. `psycopg2-binary` in requirements.txt
2. `is_sqlite()` and `dialect_insert()` exported from compat.py
3. `get_db_url()` reads `DATABASE_URL` first, then `TCG_DATABASE_URL`
4. Repository engine uses pool_pre_ping for non-SQLite URLs
5. Existing SQLite behavior completely unchanged

# F119-T05: Data Migration Script + Neon Setup Docs

**Status:** planned
**Wave:** 2 (depends on T01-T04)

## User Story

As the project operator, I need a script to migrate my existing SQLite
data to Neon PostgreSQL and documentation for setting up the Neon
database so that the production environment is ready.

## Dev Notes

### 1. Create `scripts/migrate-to-pg.py`

One-time migration script that:
1. Reads all tables from local SQLite DB
2. Connects to Neon PostgreSQL via DATABASE_URL
3. Creates schema (via `Base.metadata.create_all()`)
4. Copies data table by table in dependency order
5. Handles type differences (SQLite's loose typing → PG strict)

```python
"""One-time migration from SQLite to PostgreSQL (Neon).

Usage:
    python scripts/migrate-to-pg.py \
        --source sqlite:///tcg_market.db \
        --target postgresql://user:pass@host/db?sslmode=require
"""
```

**Table migration order** (respecting FK dependencies):
1. users
2. cards
3. source_cards (FK → cards)
4. user_collection (FK → cards)
5. price_observations
6. scan_runs
7. decks
8. deck_cards (FK → decks, cards)
9. card_legalities (FK → cards)
10. legality_history (FK → cards)
11. credit_balances (FK → users)
12. credit_transactions (FK → users)
13. shared_collections (FK → users)
14. exchange_rates
15. evaluation_entries (FK → cards)
16. scheduled_scans
17. error_logs
18. collection_errors
19. audit_logs
20. price_alerts
21. alert_notifications
22. achievements
23. trade_interests
24. trade_agreements (FK → trade_interests)
25. portfolio_snapshots
26. wishlist

**Key considerations:**
- Use `INSERT ... ON CONFLICT DO NOTHING` to make script re-runnable
- Batch inserts (1000 rows at a time) to avoid memory issues
- Handle SQLite NULL vs PG NULL (should be compatible)
- Handle datetime strings (SQLite stores as text, PG as timestamp)
- Set PG sequences to max(id)+1 after migration (SERIAL auto-increment)

### 2. Sequence reset after migration

PostgreSQL SERIAL columns need their sequences synced:
```sql
SELECT setval(pg_get_serial_sequence('users', 'id'),
              COALESCE(MAX(id), 0) + 1, false) FROM users;
-- Repeat for all tables with auto-increment IDs
```

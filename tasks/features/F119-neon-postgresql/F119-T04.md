# F119-T04: Guard SQLite-Only Features (backup, db_sync, push-db, VACUUM)

**Status:** planned
**Wave:** 1 (depends on T01, parallel with T02/T03)

## User Story

As a production operator, I want SQLite-specific utilities (push-db,
backup download, db_sync) to be gracefully disabled when running on
PostgreSQL, and critical operations to show clear messages.

## Dev Notes

### 1. backup.py — Guard sqlite3 usage

The backup module uses `sqlite3.connect()` and `sqlite3.backup()`.
Add a guard at the top of `create_backup()`:

```python
from src.database.compat import is_sqlite

def create_backup(db_url: str, backup_dir: str = "backups") -> str:
    if not db_url.startswith("sqlite"):
        raise ValueError("Backup via sqlite3.backup() only supported for SQLite databases. "
                         "For PostgreSQL, use pg_dump.")
    # ... existing code
```

### 2. admin.py — Guard backup download endpoint

The admin router's backup/download endpoint uses `sqlite3.connect()`.
Add a check and return a clear error:

```python
@router.post("/backup")
async def create_backup_endpoint(...):
    db_url = get_db_url()
    if not db_url.startswith("sqlite"):
        raise HTTPException(400, "Database backup download not available for PostgreSQL. "
                                  "Use Neon dashboard for backups.")
    # ... existing code
```

### 3. db_sync.py — Guard upload/restore endpoints

The `POST /db/upload` and `POST /db/restore` endpoints are SQLite file
operations. Guard them:

```python
if not get_db_url().startswith("sqlite"):
    raise HTTPException(400, "DB sync not needed — using persistent PostgreSQL database.")
```

Keep the endpoints registered (don't remove the router) — they just
return helpful error messages when called against PG.

### 4. cli/main.py — Guard push-db and VACUUM

**push-db command:** Add a guard at the start:
```python
@cli.command("push-db")
def push_db(db, remote, api_key, force):
    if not db.startswith("sqlite"):
        click.echo("push-db is only needed for SQLite deployments. "
                    "Neon PostgreSQL persists data automatically.")
        return
    # ... existing code
```

**VACUUM in cleanup-orphans** (L1314): Guard with is_sqlite check.

**push-prices command:** Keep as-is — it POSTs price data via API, not
SQLite-specific. Works with both backends.

### 5. cli/main.py — Guard pull-db command

Same pattern:
```python
if not db.startswith("sqlite"):
    click.echo("pull-db is only needed for SQLite deployments.")
    return
```

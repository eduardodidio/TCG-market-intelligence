# F95-T01: Enhance shared EmptyState component

**Wave:** 0
**Depends on:** --

## User Story

As a developer, I want a standardized EmptyState component with rich props
(icon, title, description, primary/secondary actions) so that all pages can
present consistent, actionable empty states without duplicating layout code.

## Dev Notes

### File to modify

`frontend/src/components/EmptyState.tsx`

### Current API (to extend, not break)

```ts
interface EmptyStateProps {
  message: string;
  icon?: ReactNode;
  action?: { label: string; onClick: () => void };
}
```

### Target API

```ts
interface EmptyStateAction {
  label: string;
  onClick: () => void;
  variant?: "primary" | "secondary";  // default: "primary"
}

interface EmptyStateProps {
  // Existing (kept for backward compat)
  message?: string;
  icon?: ReactNode;
  action?: EmptyStateAction;

  // New props
  title?: string;           // bold heading above description
  description?: string;     // longer explanatory text (replaces message when both absent)
  actions?: EmptyStateAction[];  // multiple action buttons
  compact?: boolean;        // reduced padding for inline usage (py-6 vs py-12)
}
```

- When `message` is provided (legacy usage), render it as before for backward
  compatibility. When `title`+`description` are provided, render the richer
  layout.
- `actions` array renders buttons in a flex row. If both `action` (singular)
  and `actions` (plural) are provided, `actions` takes precedence.
- `variant="secondary"` renders as a ghost/outline button (border-slate-500,
  text-slate-300, hover:bg-slate-700).
- `compact` reduces vertical padding for contexts like inline cards.
- Keep existing `data-testid="empty-state"` on the root div. Add
  `data-testid="empty-state-title"` and `data-testid="empty-state-description"`.

### Suggested icon set (SVG, inline)

Provide a few named icon helpers (not required in the component itself, but
as a utility or documented pattern):
- Collection icon (stack of cards)
- Chart icon (trending line)
- Deck icon (layered rectangles)
- Search icon (magnifying glass)

These can be simple inline SVGs passed via the `icon` prop by consumers.

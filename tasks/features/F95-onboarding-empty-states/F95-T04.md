# F95-T04: Collection page empty state with import CTA

**Wave:** 1
**Depends on:** T01

## User Story

As a user with no cards in my collection, I want to see a prominent
import wizard CTA instead of a "no cards" message so that I immediately
know how to populate my collection.

## Dev Notes

### File to modify

`frontend/src/pages/MyCollection.tsx`

### Current behavior (lines 859-864)

```tsx
{!loading && !error && cards.length === 0 && (
  <EmptyState
    message={t("collection.emptyCollection")}
    action={{ label: t("common.clearFilters"), onClick: handleClearFilters }}
  />
)}
```

This always shows "Clear filters" as the action, even when the user has
no cards at all (not just no matching cards). The two cases should be
distinguished.

### Target behavior

**Case 1: No cards at all** (no search term, no set filter active):
```tsx
<EmptyState
  icon={/* card stack SVG */}
  title={t("onboarding.collectionEmptyTitle")}
  description={t("onboarding.collectionEmptyDesc")}
  actions={[
    { label: t("collection.importCsv"), onClick: () => setCsvImportOpen(true), variant: "primary" },
    { label: t("batchAdd.addCards"), onClick: () => setBatchAddOpen(true), variant: "secondary" },
  ]}
/>
```

**Case 2: No matching cards** (filters active but no results):
```tsx
<EmptyState
  message={t("collection.noMatchingCards")}
  action={{ label: t("common.clearFilters"), onClick: handleClearFilters }}
/>
```

### Detection logic

```ts
const hasActiveFilters = debouncedSearch !== "" || selectedSet !== null;
```

If `cards.length === 0 && !hasActiveFilters` --> Case 1 (truly empty).
If `cards.length === 0 && hasActiveFilters` --> Case 2 (filtered empty).

### i18n keys needed (placeholder -- final text in T06)

- `onboarding.collectionEmptyTitle`
- `onboarding.collectionEmptyDesc`
- `collection.noMatchingCards` (new, distinct from `collection.emptyCollection`)

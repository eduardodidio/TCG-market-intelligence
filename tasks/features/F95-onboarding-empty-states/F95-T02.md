# F95-T02: Welcome banner on first login

**Wave:** 1
**Depends on:** T01

## User Story

As a new user, I want to see a welcome message with setup guidance on my
first login so that I know what steps to take to get value from the platform.

## Dev Notes

### New file

`frontend/src/components/WelcomeBanner.tsx`

### Component API

```ts
interface WelcomeBannerProps {
  onDismiss: () => void;
}
```

### Behavior

- Renders a full-width banner at the top of the Dashboard page (above hero).
- Contains:
  - Welcome title: "Welcome to TEDHC Market!" (i18n key: `onboarding.welcomeTitle`)
  - Subtitle: "Here are a few steps to get started:" (i18n: `onboarding.welcomeSubtitle`)
  - 3 step cards in a row (responsive, stack on mobile):
    1. "Import your collection" -- links to `/collection` (i18n: `onboarding.step1Title`, `onboarding.step1Desc`)
    2. "Explore the market" -- links to `/market` (i18n: `onboarding.step2Title`, `onboarding.step2Desc`)
    3. "Import a deck" -- links to `/decks` (i18n: `onboarding.step3Title`, `onboarding.step3Desc`)
  - Dismiss button (X icon, top-right corner)
- Styling: bg-slate-800 border border-cyan-500/30, rounded-lg, p-6

### First-login detection

- On successful login (in `AuthContext` or `Login.tsx`), check localStorage
  key `tcg_welcomed`. If absent, set a flag in state (e.g., via a new
  `useWelcome` hook or inline in Dashboard).
- When user dismisses, set `localStorage.setItem("tcg_welcomed", "1")`.
- The banner never appears again after dismissal.

### Files to modify

- `frontend/src/components/WelcomeBanner.tsx` (new)
- `frontend/src/pages/Dashboard.tsx` (integrate banner above hero)
- Optionally: `frontend/src/hooks/useWelcome.ts` (new, encapsulates localStorage logic)

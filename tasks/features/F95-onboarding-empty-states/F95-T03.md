# F95-T03: Dashboard empty states with actionable CTAs

**Wave:** 1
**Depends on:** T01

## User Story

As a user with an empty collection, I want the Dashboard to show me
actionable suggestions instead of bare text so that I know exactly what
to do next.

## Dev Notes

### File to modify

`frontend/src/pages/Dashboard.tsx`

### Current behavior

Lines 190-193: When collection summary fails or is empty, renders:
```tsx
<EmptyState message={t("dashboard.emptyCollection")} />
```

Lines 220-222: When market data is empty, renders:
```tsx
<EmptyState message={t("dashboard.emptyMarket")} />
```

### Target behavior

**Collection empty state** (replaces `data-testid="collection-empty"`):
```tsx
<EmptyState
  icon={/* card stack SVG */}
  title={t("onboarding.dashboardCollectionTitle")}
  description={t("onboarding.dashboardCollectionDesc")}
  actions={[
    { label: t("onboarding.importCollection"), onClick: () => navigate("/collection"), variant: "primary" },
    { label: t("onboarding.exploreCards"), onClick: () => navigate("/cards"), variant: "secondary" },
  ]}
/>
```

**Market empty state** (replaces `data-testid="market-empty"`):
```tsx
<EmptyState
  icon={/* chart SVG */}
  title={t("onboarding.dashboardMarketTitle")}
  description={t("onboarding.dashboardMarketDesc")}
  actions={[
    { label: t("onboarding.runScan"), onClick: () => navigate("/scans"), variant: "primary" },
  ]}
/>
```

### Navigation

Use `useNavigate()` from react-router-dom (already available in the project).

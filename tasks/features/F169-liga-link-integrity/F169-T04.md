# F169-T04 — `liga-relink` CLI command

**Status:** planned

## User Story

As an operator, after running `liga-verify-links` and finding mismatches, I want
to automatically re-fetch the correct Liga URL for those cards, updating the
`liga_card_urls` table.

## Dev Notes

### File: `src/cli/main.py`

Add a new CLI command `liga-relink` to the top-level `cli` group (near the
`liga-verify-links` command added in T03).

### CLI command design

```python
@cli.command("liga-relink")
@click.option("--db", default=None, callback=_resolve_db, is_eager=True, ...)
@click.option("--input", "input_file", default=None, help="JSON file from liga-verify-links --output")
@click.option("--external-ids", default=None, help="Comma-separated external_ids to relink")
@click.option("--all-mismatches", is_flag=True, help="Re-verify and relink all mismatches")
@click.option("--dry-run", is_flag=True, help="Show what would be relinked without writing")
@click.option("--delay", default=3.0, help="Delay between Playwright requests (seconds)")
def liga_relink(db, input_file, external_ids, all_mismatches, dry_run, delay):
    """Re-fetch correct Liga URLs for mismatched cards."""
```

**Input modes** (exactly one required):

1. `--input results.json` — Read the JSON output from `liga-verify-links --output`.
   Filter entries with status `MISMATCH`.
2. `--external-ids liga_123,liga_456` — Explicit list of external_ids to relink.
3. `--all-mismatches` — Run the verification logic from T03 inline, then relink
   all mismatches found.

**Algorithm for each external_id to relink:**

1. Resolve the card name via `repo.get_card_name_by_liga_external_id(external_id)`.
2. If no card found, skip with warning (orphan).
3. Use Playwright to navigate to Liga search for that card name (using
   `liga_url_for_card_name()` from `src/providers/liga/url.py`).
4. Wait for the page to load. Extract the final URL after any redirects
   (Liga search often redirects to the actual card page).
5. Validate the final URL with `is_valid_liga_card_url()`.
6. If `--dry-run`, print what would be updated.
7. Otherwise, call `repo.upsert_liga_card_url(external_id, final_url)` to
   store the correct URL.
8. Sleep `--delay` seconds between requests.

**Alternative approach** (simpler, reuses existing infrastructure):
Instead of implementing custom Playwright logic, reuse `_fetch_liga_price()`
from `liga_sweep.py` which already:
- Navigates to the card page
- Extracts the final page URL
- Handles retries and error cases

This would require extracting the URL-fetching part of the sweep into a
reusable function, or calling `record_liga_url()` with the result.

**Recommended approach**: Use Playwright directly for URL resolution (simpler
than pulling in the full sweep machinery). The sweep fetches prices too, which
is unnecessary overhead for a relink operation.

### Playwright URL resolution helper

Create a small helper in `src/providers/liga/url_resolver.py`:

```python
async def resolve_liga_page_url(card_name: str, page) -> str | None:
    """Navigate to Liga search for card_name and return the final page URL.

    Uses an existing Playwright page object. Returns the final URL after
    redirects, or None if the page could not be loaded.
    """
    from src.providers.liga.url import liga_url_for_card_name

    search_url = liga_url_for_card_name(card_name)
    try:
        await page.goto(search_url, wait_until="domcontentloaded", timeout=30000)
        return page.url
    except Exception:
        return None
```

### Output format

```
[RELINKED] liga_123  "Sol Ring"  old=https://... new=https://...
[SKIPPED]  liga_456  "Lightning Bolt"  dry-run
[ORPHAN]   liga_789  no card found
[ERROR]    liga_012  "Dark Ritual"  playwright timeout
```

Summary at the end: total processed, relinked, skipped, errors, orphans.

## Testing

### New tests in `tests/cli/test_liga_relink.py`

1. **test_relink_dry_run**: Provide `--external-ids liga_123 --dry-run`. Assert
   no DB writes occur and output contains `[SKIPPED]`.

2. **test_relink_from_external_ids**: Provide `--external-ids liga_123`. Mock
   Playwright to return a valid URL. Assert `repo.upsert_liga_card_url` is
   called with the new URL.

3. **test_relink_from_json_input**: Write a temp JSON file with one MISMATCH
   entry. Run with `--input`. Assert the mismatched external_id is processed.

4. **test_relink_orphan_skipped**: Mock `get_card_name_by_liga_external_id`
   returning `None`. Assert output contains `[ORPHAN]` and no DB write.

5. **test_relink_respects_delay**: Mock 2 external_ids. Assert at least
   `delay` seconds elapsed between Playwright calls (or mock `asyncio.sleep`
   and assert it was called with the correct value).

### Unit tests for `resolve_liga_page_url` in `tests/providers/liga/test_url_resolver.py`

1. **test_resolve_returns_final_url**: Mock `page.goto` and `page.url`.
   Assert the returned URL matches `page.url`.

2. **test_resolve_returns_none_on_timeout**: Mock `page.goto` raising
   `TimeoutError`. Assert `None` returned.

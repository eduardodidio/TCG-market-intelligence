# F165-T03 — Optimize get_trending_price_data_for_user query

**Status:** planned
**Wave:** 1
**Depends on:** none

## User Story

As a user with a large collection (500+ cards), I want the trending data to load within a reasonable time, without the query timing out on Neon PostgreSQL.

## Dev Notes

**File:** `src/database/repository.py`

### Problem

`get_trending_price_data_for_user()` (line ~1117) builds direct_patterns dict with 3 entries per card (`liga_{cid}`, `liga_{cid}_foil`, `manual_{cid}`). For 500 cards = 1500 strings in a single `WHERE external_id IN (...)` clause. This is slow for PostgreSQL query planning.

### Solution: Replace Python-side pattern generation with SQL-side pattern matching

Instead of building 1500 patterns in Python and using `IN(...)`, use a SQL approach:

**Option A (recommended): JOIN with generated patterns via CTE**

```python
# Build a CTE from user_card_ids that generates the patterns in SQL
from sqlalchemy import literal_column, union_all

if user_card_ids:
    # Batch into chunks of 200 to avoid huge unions
    CHUNK = 200
    all_direct_obs = []
    for i in range(0, len(user_card_ids), CHUNK):
        chunk = user_card_ids[i:i+CHUNK]
        pattern_unions = []
        for cid in chunk:
            for prefix, suffix in [("liga_", ""), ("liga_", "_foil"), ("manual_", "")]:
                ext_id = f"{prefix}{cid}{suffix}"
                pattern_unions.append(
                    select(
                        literal(ext_id).label("ext_id"),
                        literal(cid).label("card_id"),
                    )
                )
        patterns_cte = union_all(*pattern_unions).cte("direct_patterns")

        chunk_obs = session.execute(
            select(
                patterns_cte.c.card_id,
                PriceObservationRow.observed_at,
                PriceObservationRow.median_price,
            )
            .join(
                PriceObservationRow,
                PriceObservationRow.external_id == patterns_cte.c.ext_id,
            )
            .where(
                PriceObservationRow.observed_at >= cutoff,
                PriceObservationRow.median_price.isnot(None),
            )
            .order_by(PriceObservationRow.observed_at.asc())
        ).all()
        all_direct_obs.extend(chunk_obs)
```

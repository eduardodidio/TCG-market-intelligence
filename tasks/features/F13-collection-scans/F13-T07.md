## Dev Notes

Veja `_brief/00-overview.md` e `_brief/04-cli-api.md`.

Existing patterns in `src/api/routers/`:
- Routers use `APIRouter(prefix="/api/v1/<resource>", tags=["<Resource>"])`
- Auth: `Depends(verify_api_key)` from `src/api/deps.py` for mutation endpoints
- Background jobs: use `threading.Thread` pattern (see `collection.py` snapshot endpoint)
- Read-only endpoints: no auth required
- App registration: `app.include_router(router)` in `src/api/app.py`

## Test Scenarios

1. **POST trigger:** Send valid request, verify 200 with scan_id
2. **POST auth required:** No API key -> 401/403
3. **GET list:** Create 3 scans, GET list, verify 3 items
4. **GET list with filter:** Filter by scan_type, verify filtered results
5. **GET list pagination:** limit=1 offset=1, verify single result
6. **GET detail:** Create scan, GET by id, verify all fields
7. **GET detail 404:** Non-existent id -> 404
8. **POST with filters:** Send set_codes in request, verify scan created with filters

## User Story

As a system operator, I want CLI commands to trigger scans with filters
and view scan history, so that I can manage data collection from the
terminal.

## Objective

Add `scan` and `scan-history` Click commands to `src/cli/main.py`.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/04-cli-api.md`.

Existing patterns in `src/cli/main.py`:
- Commands registered with `@cli.command()` decorator
- Options follow `@click.option("--name", ...)` pattern
- Async commands use `asyncio.run()` to call async functions
- Summary printing uses dedicated `_print_*` helper functions
- Imports are lazy (inside the function body)

Follow the exact same patterns. The `scan` command should accept:
- `--type` (choice: collection, set, format, custom)
- `--set` (string, for set code)
- `--format` (string, for format name)
- `--rarity` (string, for rarity filter)
- `--card-ids` (string, comma-separated)
- Standard options: `--db`, `--limit`, `--dry-run`, `--delay`, `--concurrency`

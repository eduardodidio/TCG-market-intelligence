# F13-T03: Repository Methods (scan CRUD + filtered card queries)

- **Wave:** 1
- **Type:** backend
- **Depends on:** F13-T01, F13-T02
- **Status:** planned

## User Story

As a scan orchestrator, I want repository methods for creating/updating scan
runs and querying cards by filter, so that the scan logic is decoupled from
raw SQL.

## Objective

Add scan-related CRUD and a filtered card query to `src/database/repository.py`.

## Dev Notes

Veja `_brief/00-overview.md` e `_brief/02-database.md`.

Existing patterns in `src/database/repository.py`:
- `Repository` class with `self.db_url` and `self._engine()` / `self._session()` context managers
- Methods return plain dicts or domain objects, not ORM rows
- Uses `sqlalchemy.select()`, `insert()`, `update()` core-style queries
- Existing method `get_linked_collection_with_source()` joins `user_collection` + `source_cards`
  and returns `list[dict]` with `{external_id, slug, card_id, ...}` -- this is the base query
  pattern to extend

Key method: `get_cards_for_scan(scan_filter)` must:
1. Start from `user_collection` JOIN `source_cards` (same as existing)
2. Apply optional WHERE clauses based on filter fields:
   - `set_codes` -> `user_collection.set_code IN (...)`
   - `rarities` -> `user_collection.rarity IN (...)`
   - `card_ids` -> `user_collection.card_id IN (...)`
3. Respect `limit` from filter
4. Return same shape as `get_linked_collection_with_source()`

## Implementation Details

File: `src/database/repository.py`

Add these methods to the `Repository` class:

```python
def create_scan_run(self, scan_type: str, filters_json: str = "{}") -> int:
    """Insert a new scan run row and return its ID."""

def update_scan_run(self, run_id: int, **fields) -> None:
    """Update a scan run with the given fields."""

def get_scan_run(self, run_id: int) -> dict | None:
    """Return a scan run as a dict, or None if not found."""

def list_scan_runs(
    self, limit: int = 20, offset: int = 0,
    scan_type: str | None = None, status: str | None = None,
) -> list[dict]:
    """List scan runs with optional filters, ordered by created_at desc."""

def get_cards_for_scan(self, scan_filter) -> list[dict]:
    """Return cards matching the scan filter.
    Returns list of {external_id, slug, card_id, set_code, name_en}.
    """
```

## Acceptance Criteria

Framework: pytest (`python -m pytest tests/`)

## Test Scenarios

1. **CRUD happy path:** create -> get -> update -> get (verify fields changed)
2. **List with filters:** create 3 runs with different types, list with type filter
3. **List ordering:** runs listed newest-first
4. **Pagination:** create 5 runs, list with limit=2 offset=2
5. **get_cards_for_scan (collection):** returns all linked collection cards
6. **get_cards_for_scan (set filter):** returns only cards from specified set
7. **get_cards_for_scan (rarity filter):** returns only cards with specified rarity
8. **get_cards_for_scan (limit):** respects limit parameter
9. **get_cards_for_scan (empty result):** returns empty list for non-matching filter
10. **get_scan_run (not found):** returns None for non-existent ID

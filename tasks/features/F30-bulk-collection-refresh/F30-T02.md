# F30-T02: useCollectionRefresh hook

**Status:** planned
**Wave:** 1

## User Story

As a frontend developer, I need a hook that manages the scan lifecycle:
trigger, poll progress, detect completion.

## Dev Notes

### Files to create
- `frontend/src/hooks/useCollectionRefresh.ts`

### Implementation
```typescript
interface UseCollectionRefreshReturn {
  isRefreshing: boolean;
  progress: { processed: number; total: number } | null;
  error: string | null;
  startRefresh: () => Promise<void>;
  cancelRefresh: () => void;
}
```

1. `startRefresh()`:
   - Calls `triggerScan({ scan_type: "collection" })`
   - Stores `scan_id` in state
   - Starts polling interval (3s)
2. Poll loop:
   - Calls `getScanStatus(scanId)` every 3s
   - Updates `progress` state with `{ processed: cards_processed, total: cards_total }`
   - On status `completed` or `failed`: stop polling, set `isRefreshing = false`
3. `cancelRefresh()`:
   - Clears polling interval
   - Sets `isRefreshing = false`
   - (Scan continues server-side, just UI stops tracking)
4. Cleanup on unmount: clear interval, abort in-flight requests

### AbortController
- Use AbortController for both trigger and poll requests
- Cancel on unmount via useEffect cleanup

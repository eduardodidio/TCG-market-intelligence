# F30-T01: Frontend scan API client functions

**Status:** planned
**Wave:** 1

## User Story

As a frontend developer, I need API functions to trigger scans and poll their
status.

## Dev Notes

### Files to create/modify
- `frontend/src/api/scans.ts` (new file)

### Implementation
1. `triggerScan(request)` — `apiPost<ScanTriggerResponse>("/api/v1/scans", request)`
2. `getScanStatus(scanId)` — `apiGet<ScanRunResponse>(`/api/v1/scans/${scanId}`)`
3. Type definitions for `ScanTriggerResponse` and `ScanRunResponse`

### Types
```typescript
interface ScanTriggerResponse {
  scan_id: number;
  status: string;
}

interface ScanRunResponse {
  id: number;
  scan_type: string;
  status: string;
  cards_total: number;
  cards_processed: number;
  cards_failed: number;
  observations_saved: number;
  started_at: string | null;
  finished_at: string | null;
}
```

# F30-T03: RefreshAllButton + MyCollection integration

**Status:** planned
**Wave:** 2
**Depends:** T01, T02

## User Story

As a user, I want a "Refresh All Prices" button on my collection page that
shows progress while updating all card prices.

## Dev Notes

### Files to modify
- `frontend/src/pages/MyCollection.tsx` — add button and integrate hook

### Implementation
1. Import and use `useCollectionRefresh` hook in `MyCollection`
2. Add `RefreshAllButton` inline (or as a small component) next to GridSizeToggle
3. Button states:
   - Idle: "Refresh All" with refresh icon
   - Refreshing: progress bar + "42/120" text + cancel button
   - Complete: brief "Done!" flash, then back to idle
   - Error: show error inline, auto-dismiss
4. On completion: trigger re-fetch of collection data and summary
5. Position: in the `flex justify-end` row with GridSizeToggle

### Progress bar
- Thin bar (h-1 or h-2) below the button or inline
- `bg-cyan-400` fill, `bg-slate-700` track
- Width = `(processed / total) * 100%`

### Re-fetch on completion
- Call the existing collection fetch effect by bumping a refresh counter state
- Or add a `refreshKey` dependency to the fetch useEffect

## Testing

- Progress test: bar updates

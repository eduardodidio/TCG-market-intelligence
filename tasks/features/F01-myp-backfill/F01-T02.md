## Dev Notes

### Validation Queries

Run these queries against `tcg_market.db` and report results:

1. **Card count:**
   ```sql
   SELECT count(*) FROM source_cards WHERE source = 'myp';
   SELECT count(*) FROM cards;
   ```

2. **Observation count per card:**
   ```sql
   SELECT sc.name_en, sc.sku, count(po.id) as obs_count
   FROM source_cards sc
   LEFT JOIN price_observations po ON po.external_id = sc.external_id AND po.source = sc.source
   WHERE sc.source = 'myp'
   GROUP BY sc.external_id
   ORDER BY obs_count DESC;
   ```

3. **Cards with zero observations (missing history):**
   ```sql
   SELECT sc.external_id, sc.name_en, sc.sku
   FROM source_cards sc
   LEFT JOIN price_observations po ON po.external_id = sc.external_id AND po.source = sc.source
   WHERE sc.source = 'myp' AND po.id IS NULL;
   ```

4. **Date range coverage:**
   ```sql
   SELECT min(observed_at), max(observed_at), count(DISTINCT observed_at)
   FROM price_observations;
   ```

5. **Sample price data (spot check):**
   ```sql
   SELECT sc.name_en, po.observed_at, po.median_price, po.tcg_price, po.quantity_available
   FROM price_observations po
   JOIN source_cards sc ON sc.external_id = po.external_id AND sc.source = po.source
   ORDER BY po.observed_at DESC
   LIMIT 20;
   ```

6. **Encoding check:**
   ```python
   # Verify UTF-8 names are correct
   for row in cursor.execute("SELECT name_en FROM source_cards"):
       assert all(ord(c) < 65536 for c in row[0])
   ```

7. **Error table:**
   ```sql
   SELECT count(*) FROM collection_errors WHERE resolved = 0;
   ```

### Success Criteria

- All 30 cards have source_card entries
- Most cards have > 0 price observations
- No unresolved errors
- Date range spans at least several months
- Prices are reasonable (> 0, < 100000 BRL)

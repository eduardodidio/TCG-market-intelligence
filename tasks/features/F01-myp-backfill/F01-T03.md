# F01-T03: Fix any issues found

**Status:** done
**Wave:** 1

## User Story

As a developer, I want to fix any data quality issues or bugs discovered
during validation so the collector is reliable for full-scale operation.

## Dev Notes

This task is conditional — only execute if F01-T01 or F01-T02 revealed issues.

### Common issues to look for

1. **Parsing failures:** Cards where JSON-LD was not found or SKU parsing failed
2. **Encoding problems:** Garbled Portuguese characters in the database
3. **Missing history:** Cards that should have history but returned empty
4. **Price anomalies:** Negative prices, absurdly high values, null where not expected
5. **Idempotency bugs:** Duplicate observations for same card+date

### Fix approach

- For parser bugs: fix `src/parsers/myp.py`, add regression test, re-run
- For encoding: check `curl_cffi` response encoding, add `.encode('utf-8')` if needed
- For missing history: check if `window.precoChartConfig` is absent (expected for low-data cards)
- For idempotency: verify unique constraint in `price_observations`

## Testing

- Re-run backfill after fixes to confirm 0 new failures
- Run `python -m pytest tests/ -v` to confirm no regressions

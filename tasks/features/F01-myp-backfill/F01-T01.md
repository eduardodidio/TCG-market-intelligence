2. Run the full backfill:

   python -m src.cli.main backfill --set dominaria-remastered --delay 1.5

3. Capture the full output (summary + any warnings/errors)
4. If any cards fail, analyze the failures and determine if they are
   transient (rate limit, timeout) or structural (parsing error)

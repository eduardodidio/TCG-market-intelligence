# F213-T09: Portfolio API Hardening + Liga Link Resolver

**Wave:** 1 | **Sub-Feature:** F213b-1 (F124) | **Status:** planned

## User Story

As a collector, I want my portfolio summary to accurately reflect only cards
with both acquisition and market prices, and I want Liga links to open the
correct card page.

## Dev Notes

1. Update portfolio endpoints:
   - `GET /api/v1/collection/portfolio-summary`: add `unpriced_card_count`
   - Filter investment metrics to cards with BOTH `acquisition_price` AND current price
   - Add `acquisition_only` param to collection list (cards with acquisition price set)
2. Liga link resolver:
   - When collection entry name differs from CardRow name (drift), resolve via
     Liga sweep's stored `external_id` to find correct Liga URL
   - Add `liga_url` field to collection detail response
3. Add `cards_without_acquisition` count to summary

## Acceptance Criteria

- [ ] Portfolio summary excludes cards without both prices from investment metrics
- [ ] `unpriced_card_count` and `cards_without_acquisition` in response
- [ ] `acquisition_only` filter works on collection list
- [ ] Liga URL resolves correctly even when names drifted

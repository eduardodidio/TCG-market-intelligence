# F213-T20: Price History Backfill Script + Forward-Fill

**Wave:** 3 | **Sub-Feature:** F213c-4 (F176) | **Status:** planned

## User Story

As an admin, I want to backfill price history gaps so charts show continuous
data without missing days.

## Dev Notes

1. Create `bats/daily-snapshot.bat`:
   - Calls `python -m src.cli.main backfill-snapshots --days 1`
   - Add to daily-scan.bat pipeline (after sweep, before snapshot-portfolio)
2. Enhance `backfill-snapshots` CLI:
   - Forward-fill carry: copy previous day's price if no observation exists
   - Cap at 30 days without real data (stop carrying after 30-day gap)
   - `--dry-run` flag: report what would be filled
   - Report: days filled, gaps found, sources used
3. Create `bats/price-history-backfill.bat`:
   - Full backfill for all cards with existing observations
   - `--days 90` default
4. Update `daily-scan.bat` to include daily snapshot step

## Acceptance Criteria

# F213-T17: Accessibility — aria-labels, Keyboard Nav, Dialog Roles

**Wave:** 2 | **Sub-Feature:** F213h-2 (UX P1) | **Status:** planned

## User Story

As a user with assistive technology, I want proper ARIA labels, keyboard
navigation, and dialog roles so I can use the app effectively.

## Dev Notes

Target fixes from UX audit:

1. **aria-labels on filter buttons** (Cards, CatalogPage, Trending):
   - Add `aria-label` to all icon-only filter buttons
   - Add `aria-label` to toggle buttons
2. **Color-only signaling** (DeckList, Trending):
   - Add text alternative for ownership % (e.g., "80% owned" sr-only text)
   - Add pattern/icon alongside color for trend direction
3. **Keyboard navigation on DeckBuildWizard**:
   - Commander grid: Tab through results, Enter to select
   - Arrow keys for grid navigation
4. **ImportPurchasesPage drop zone**:
   - Add `aria-label="Drop files here or click to browse"`
   - Add `role="button"` with keyboard activation
5. **alertdialog role on delete modals**:
   - DeckView delete modal
   - Collection remove modal
   - Alert delete modal
   - Add `role="alertdialog"` + `aria-describedby`

## Acceptance Criteria

- [ ] All filter buttons have aria-labels
- [ ] Ownership % has text alternative
- [ ] Commander grid navigable by keyboard
- [ ] Drop zone accessible via keyboard
- [ ] Delete modals use alertdialog role

# F213-T14: Wishlist Page + Trade Matches Page

**Wave:** 2 | **Sub-Feature:** F213f-2 (F110) | **Status:** planned

## User Story

As a collector, I want a dedicated wishlist page and a trade matches page to
manage my wants and find potential trades.

## Dev Notes

2. Create `DuplicatesSection` (on MyCollection or standalone):

3. Add nav entry for Wishlist in sidebar
4. Add breadcrumbs

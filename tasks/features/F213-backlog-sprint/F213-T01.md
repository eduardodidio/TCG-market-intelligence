# F213-T01: Reality Fracture Catalog Seed Script

**Wave:** 0 | **Sub-Feature:** F213e (F180) | **Status:** planned

## User Story

As a collector, I want Reality Fracture (FRA/FRC) cards seeded into the catalog
so I can browse and track prices for this set.

## Dev Notes

1. Create `bats/catalog-seed-fra.bat`:
   - Run `python -m src.cli.main catalog seed` (picks up FRA, FRC, TFRA, TFRC from latest Scryfall bulk)
   - Run `python -m src.cli.main catalog scan --set fra`
   - Run `python -m src.cli.main catalog scan --set frc`
2. Verify FRA/FRC appear in `GET /api/v1/catalog/sets`
3. Update README.md with delivery note

## Acceptance Criteria

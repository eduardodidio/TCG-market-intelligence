# F213-T07: Price History Endpoints + Daily Snapshot + Backfill CLI

**Wave:** 1 | **Sub-Feature:** F213c-2 (F176) | **Status:** planned

## User Story

As a collector, I want API endpoints to fetch card price history and a CLI
command to backfill historical data from existing observations.

## Dev Notes

1. Add endpoints using `price_history.py` service from T05:
   - `GET /api/v1/collection/{id}/history` — price history for collection entry
   - `GET /api/v1/collection/{id}/metrics` — summary stats (min, max, avg, trend)
   - `GET /api/v1/cards/{id}/history` — price history for any card
   - Response includes: `variant`, `sources[]`, `since`, `real_points`, `snapshot_points`
2. Add `daily_snapshot` as new source value in price_observations:
   - Created by `run_daily_snapshot()` at end of sweep
   - Forward-fill carry: if no real data for a day, carry previous price (cap 30 days)
3. CLI command `price-history-backfill`:
   - `--dry-run` flag
   - Forward-fill from existing observations
   - Report: days filled, gaps found, sources used

## Acceptance Criteria

- [ ] History endpoint returns daily time series with source metadata
- [ ] Metrics endpoint returns min/max/avg/trend
- [ ] Daily snapshot creates `daily_snapshot` source entries
- [ ] Backfill CLI fills gaps up to 30 days with carry-forward
- [ ] `--dry-run` shows what would be filled without writing

# F213-T06: Banlist API — Owned Filter, Status, Manual Sync

**Wave:** 1 | **Sub-Feature:** F213d-2 (F177) | **Status:** planned

## User Story

As a user, I want to filter the ban list to show only cards I own and see
sync status so I know when data was last updated.

## Dev Notes

1. Update `GET /api/v1/banlist`:
   - Add `owned_only` query param (requires auth, 401 without)
   - Group by card name (not by printing) for cleaner display
   - Fix pagination (current impl may skip entries)
2. Add `GET /api/v1/banlist/status`:
   - `last_synced_at`, `card_count`, `banned_count`, `restricted_count`
   - `format_count` (number of formats tracked)
   - `history_entry_count`
3. Add `POST /api/v1/banlist/sync` (admin-only):
   - Trigger sync and return summary
   - Uses fixed sync from T03

## Acceptance Criteria

- [ ] `?owned_only=true` filters to user's collection cards
- [ ] 401 returned for owned_only without auth
- [ ] Status endpoint returns accurate counts
- [ ] Manual sync trigger works for admin

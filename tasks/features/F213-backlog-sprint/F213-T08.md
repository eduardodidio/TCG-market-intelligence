# F213-T08: Wishlist CRUD Hardening + Duplicates Endpoint

**Wave:** 1 | **Sub-Feature:** F213f-1 (F110) | **Status:** planned

## User Story

As a collector, I want to maintain a wishlist of cards I'm looking for and
see which cards in my collection are duplicates (surplus copies).

## Dev Notes

1. Harden existing `src/api/routers/wishlist.py`:
   - Verify CRUD operations (add, remove, list, bulk-add)
   - Add `max_price` optional field (target buy price)
   - Add `any_version` boolean (match any printing)
   - Enforce max 200 items per user
   - Return current_price alongside wishlist entry
2. Add duplicates detection endpoint:
   - `GET /api/v1/collection/duplicates` — cards with quantity > needed
   - "Needed" = max(1, deck_usage) per card
   - Response: card_id, name, owned_qty, needed_qty, surplus, estimated_value
   - Sort by estimated_value DESC (most valuable surplus first)
3. Ensure `wishlists` table has proper indexes (user_id, card_id unique)

## Acceptance Criteria

- [ ] Wishlist CRUD works with max_price and any_version
- [ ] 400 error when exceeding 200 items
- [ ] Duplicates endpoint returns surplus cards sorted by value
- [ ] Current price included in wishlist response

# F213-T13: Price History Chart on Card Detail

**Wave:** 2 | **Sub-Feature:** F213c-3 (F176) | **Status:** planned

## User Story

As a collector, I want to see a price history chart on the card detail page
showing how the card's value has changed over time.

## Dev Notes

1. Create `PriceHistoryChart` component (Recharts):
   - Line chart with date x-axis, price y-axis
   - Tooltip showing date + price + source
   - Period selector: 7d, 30d, 90d, All
   - Responsive (mobile-friendly)
2. Add variant badge next to chart:
   - Shows which variant/source is being displayed
   - e.g., "Liga (mid)" or "MYP"
3. Add sources tooltip:
   - Hover to see all contributing sources
   - Point counts per source
4. Integrate into `CollectionCardDetail.tsx`:
   - Below price section
   - Uses `GET /api/v1/collection/{id}/history` from T07
5. Also integrate into general `CardDetail.tsx`:
   - Uses `GET /api/v1/cards/{id}/history`
   - Empty state if no history available

## Acceptance Criteria

- [ ] Chart renders price history with correct data
- [ ] Period selector filters displayed range
- [ ] Variant badge shows active source
- [ ] Empty state shown when no history
- [ ] Mobile responsive

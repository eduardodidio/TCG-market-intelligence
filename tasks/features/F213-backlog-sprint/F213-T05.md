# F213-T05: Price History Variant Resolution + Aggregation

**Wave:** 0 | **Sub-Feature:** F213c-1 (F176) | **Status:** planned

## User Story

As a collector, I want accurate price history for each card, properly resolving
which price observations belong to each card variant.

## Dev Notes

1. Create `src/services/price_history.py`:
   - Variant resolution: map external_id patterns to card_id
     - `liga_{id}[_foil]` -> direct card_id match
     - `manual_{id}` -> manual entry
     - source_cards path (MYP, catalog)
     - `jsonld_snapshot`, `daily_snapshot` sources
   - Source priority: manual > liga > jsonld > myp > daily
2. 1-point-per-day aggregation:
   - Group observations by date
   - Apply source priority for same-day conflicts
   - Return clean daily time series
3. Diagnostic function for per-entry analysis:
   - Priced vs unpriced breakdown
   - Source distribution
   - Data points count per source

## Acceptance Criteria

- [ ] Variant resolution correctly maps all external_id patterns
- [ ] 1 point per day per card (no duplicates)
- [ ] Source priority applied correctly
- [ ] Diagnostic function returns accurate breakdown

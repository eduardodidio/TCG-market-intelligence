# F213-T15: Collection Grid Inline Edit + Dashboard KPI Refactor

**Wave:** 2 | **Sub-Feature:** F213b-2 (F124) | **Status:** planned

## User Story

As a collector, I want to edit acquisition prices inline on the collection
grid and see only relevant investment KPIs on the dashboard.

## Dev Notes

1. Add inline `AcquisitionPriceInput` to collection grid tiles:
   - Click to edit, Enter to save, Esc to cancel
   - Show current acquisition price or "Set price" placeholder
   - Save via PATCH to collection endpoint
   - Success feedback (checkmark animation)
2. Dashboard KPI refactor:
   - Remove market stats strip (redundant with Trending page)
   - Keep: total collection value, total investment, P&L, unpriced count
   - Add: "cards without acquisition price" count with CTA
   - `DashboardInvestmentSummary` shows only cards with both prices
3. Add Liga link to collection detail:
   - Use `liga_url` from T09 API response
   - Open in new tab

## Acceptance Criteria

- [ ] Inline price edit works on collection grid
- [ ] Dashboard shows investment-only KPIs
- [ ] "Cards without price" count + CTA visible
- [ ] Liga link opens correct card page

# F213-T02: Trending Market Query Union + Cache Fix

**Wave:** 0 | **Sub-Feature:** F213a (F175) | **Status:** planned

## User Story

As a user, I want the "Market" toggle on the Trending page to show prices from
all sources (not just collection cards) so I can see real market trends.

## Dev Notes

1. Create `src/database/trending_queries.py` with `load_market_trending_prices()`:
   - Union path A: `source_cards` join to `price_observations`
   - Union path B: direct `price_observations` with regex `^(?:liga|manual)_(\d+)(?:_foil)?$`
   - Deduplicate by card_id, prefer latest observation
2. Update `TrendingService` to delegate to new function when `collection_only=False`
3. Fix cache: stop caching error results; empty results use 2min TTL (not 30min)
4. Add session-level `statement_timeout = 12s` for Neon market queries
5. Add regression tests for toggle behavior

## Acceptance Criteria

- [ ] Market mode returns prices from all sources, not just collection
- [ ] Empty results cached 2min, errors not cached
- [ ] Query timeout 12s prevents long-running queries from blocking
- [ ] Toggle switches correctly between collection and market mode

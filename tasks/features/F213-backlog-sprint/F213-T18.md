# F213-T18: Trade Matcher Service + Cross-User Matching UI

**Wave:** 3 | **Sub-Feature:** F213f-3 (F110) | **Status:** planned

## User Story

As a collector, I want to see potential trades with other users who have cards
I want and want cards I have surplus of.

## Dev Notes

1. Create `src/services/trade_matcher.py`:
   - `find_matches(user_id)` → cross-user matching:
     - My wishlist items vs other users' duplicates
     - Other users' wishlist items vs my duplicates
   - Match scoring: bilateral matches ranked higher
   - Price delta: estimated value exchanged
   - Respect `any_version` flag on wishlist entries
2. Add `GET /api/v1/trades/matches`:
   - Returns grouped matches by other_user
   - Each match: my_want, their_surplus, their_want, my_surplus
   - Score + estimated value
3. Create `TradeMatchesPage` (`/trades`):
   - Grouped by user (expandable sections)
   - Per-match: card images, names, values
   - "Contact" link (placeholder for future messaging)
   - Empty state: "No matches found — add cards to your wishlist"
4. Add nav entry for Trades

## Acceptance Criteria

- [ ] Matcher finds bilateral trades correctly
- [ ] Matches ranked by score (bilateral > one-sided)
- [ ] TradeMatchesPage displays matches grouped by user
- [ ] Empty state shown when no matches

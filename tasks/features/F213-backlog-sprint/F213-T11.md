# F213-T11: i18n — Wrap 150+ Hardcoded English Strings

**Wave:** 1 | **Sub-Feature:** F213h-1 (UX P1) | **Status:** planned

## User Story

As a Brazilian user, I want all UI text to be in Portuguese so the app feels
consistent and professional.

## Dev Notes

Target pages with hardcoded English strings (from UX audit):

1. `Cards.tsx` (lines 328-352):
   - "Local Search", "Web Search" mode toggle labels
   - "Added" button state
2. `ImportPurchasesPage.tsx` (80+ strings):
   - ConfidenceBadge labels, breadcrumb, drop zone text, state labels
   - Already partially done in F157-T02 — verify what remains
3. `AdminPanel.tsx` (70+ strings):
   - "Create User", form fields, table headers
   - Admin-only but still needs i18n for consistency
4. `DeckBuildWizard.tsx` (lines 21-71):
   - FORMAT_INFO descriptions, ARCHETYPES names/descriptions
5. `CollectionCardDetail.tsx` (line 302):
   - "Remove" button text

Process:
- Add keys to `frontend/src/i18n/locales/pt.json`
- Wrap each string with `t('key')`
- Do NOT change component logic, only string wrapping

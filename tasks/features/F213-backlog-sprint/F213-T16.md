# F213-T16: Admin Dashboard — Job Triggers + Audit Log + DB Stats

**Wave:** 2 | **Sub-Feature:** F213g-3 (F100) | **Status:** planned

## User Story

As an admin, I want a visual dashboard to trigger jobs, view audit logs, and
monitor database health without using the CLI.

## Dev Notes

1. Add "Operations" tab to AdminPanel:
   - Job trigger buttons: MYP Sweep, Snapshot, Catalog Seed, Banlist Sync
   - Each button shows spinner during execution
   - `window.confirm` before triggering
   - Status indicator per job (idle/running/completed/failed + timestamp)
2. Add "Audit Log" tab:
   - Paginated table: timestamp, user, action, target, details
   - Filter by action type dropdown
   - Date range filter
3. Add "DB Stats" tab:
   - Table sizes (cards, collection, prices, etc.)
   - Last sync dates (MYP, banlist, catalog)
   - Neon connection info
   - Auto-refresh every 60s
4. All tabs mobile-responsive (overflow-x-auto on tables)

## Acceptance Criteria

- [ ] Job trigger buttons work with confirmation + spinner
- [ ] Audit log shows paginated, filterable entries
- [ ] DB stats show table sizes and sync dates
- [ ] All tabs mobile-friendly

## Testing

- Frontend: Unit test audit log pagination

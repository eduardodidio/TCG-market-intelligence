# F141-T01: Upgrade foil-shimmer.css with mouse-reactive holographic effect

**Status:** planned
**Wave:** 0

## User Story

As a collector inspecting a foil card, I want to see a realistic
holographic rainbow shimmer that shifts with my mouse position, so the
card feels like a real foil when I tilt/hover over it.

## Dev Notes

### What to change

File: `frontend/src/styles/foil-shimmer.css`

1. **Add CSS custom properties** to `.foil-shimmer`:
   - `--mouse-x: 0.5` and `--mouse-y: 0.5` (defaults to center)
   - These will be set by JS (T02) on mousemove events

2. **Replace the fixed-angle gradient** in `.foil-shimmer::after` with a
   dynamic gradient that uses `calc()` on the custom properties:
   - Gradient angle: `calc(135deg + (var(--mouse-x) - 0.5) * 60deg)` --
     rotates ~30deg each direction from center
   - Background position: driven by `--mouse-x` and `--mouse-y`
   - Keep the same rainbow color stops (red, orange, yellow, green,
     cyan, blue, violet, pink) but tighten them for a more realistic
     iridescent look

3. **Add a secondary overlay** (`.foil-shimmer::before`) for a subtle
   specular highlight (white radial gradient that follows mouse position).
   This adds depth to the holographic look:
   - `radial-gradient(circle at calc(var(--mouse-x)*100%) calc(var(--mouse-y)*100%), rgba(255,255,255,0.25), transparent 60%)`
   - `mix-blend-mode: overlay`
   - `pointer-events: none`

4. **Keep the fallback keyframe animation** (`foil-shift`) as a default
   when JS has not set custom properties (i.e., on initial render or
   when the element is not hovered). Add a `.foil-shimmer--interactive`
   modifier class that disables the keyframe and enables mouse-driven
   positioning. T02 will toggle this class on mousemove.

5. **Add holographic border glow** for CardPreviewModal context:
   - `.foil-shimmer--glow` modifier: adds a subtle rainbow
     `box-shadow` that shifts hue based on `--mouse-x`
   - `box-shadow: 0 0 20px 2px hsl(calc(var(--mouse-x) * 360), 80%, 60%)`

6. **prefers-reduced-motion**: disable both keyframe animation AND
   mouse-reactive positioning. Show a static centered gradient.

### Key constraints

- No new CSS dependencies (no PostCSS plugins, no CSS-in-JS)
- Must not break existing `.foil-shimmer` usage in Card3DTilt grid tiles
- The `::before` specular highlight must have `pointer-events: none` and
  `border-radius: inherit` to stay within card bounds

## Testing

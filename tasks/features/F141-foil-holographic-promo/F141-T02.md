# F141-T02: Wire mouse tracking into Card3DTilt and CardPreviewModal

**Status:** planned
**Wave:** 0

## User Story

As a collector hovering over a foil card, I want the holographic shimmer
to react to my mouse position in real time, giving the impression of
tilting a real foil card under light.

## Dev Notes

### Card3DTilt changes

File: `frontend/src/components/Card3DTilt.tsx`

1. When `foil=true`, add an `onMouseMove` handler to the `.foil-shimmer`
   wrapper div that computes normalized mouse coordinates (0-1) relative
   to the element bounds and sets CSS custom properties:
   ```ts
   const rect = el.getBoundingClientRect();
   const x = (e.clientX - rect.left) / rect.width;
   const y = (e.clientY - rect.top) / rect.height;
   el.style.setProperty('--mouse-x', x.toFixed(3));
   el.style.setProperty('--mouse-y', y.toFixed(3));
   ```

2. On `onMouseEnter`, add the `foil-shimmer--interactive` class to switch
   from keyframe animation to mouse-driven positioning.

3. On `onMouseLeave`, remove `foil-shimmer--interactive` class so the
   fallback keyframe animation resumes.

4. **prefers-reduced-motion**: check `window.matchMedia` at mount time.
   If reduced motion is preferred, skip adding event handlers entirely
   (the CSS already handles the static fallback).

5. Use a `useRef` for the container div to avoid re-renders on every
   mousemove. No state needed -- this is purely imperative DOM mutation.

### CardPreviewModal changes

File: `frontend/src/components/CardPreviewModal.tsx`

1. The modal already wraps the image in `<Card3DTilt foil={isFoil}>`.
   Since Card3DTilt now handles mouse tracking internally (above),
   no additional changes are needed in CardPreviewModal for the foil
   effect itself.

2. Add the `foil-shimmer--glow` modifier class when `isFoil=true` on
   the Card3DTilt wrapper div. This can be done via a new `glowBorder`
   prop on Card3DTilt, or by wrapping Card3DTilt output in a div with
   the class. Prefer a `className` approach:
   ```tsx
   <Card3DTilt ... foil={isFoil} className={isFoil ? "foil-shimmer--glow" : undefined}>
   ```
   Note: Card3DTilt already accepts a `className` prop, so pass it there.
   The glow class needs to be on the outer Tilt wrapper, so it may need
   to go on the Tilt component's `className` or a wrapping div.

### Performance considerations

- `onMouseMove` fires frequently. The handler only sets CSS custom
  properties (no React state, no re-renders), so performance impact is
  negligible.
- `will-change: background-position` is already set in the CSS.
- Consider throttling with `requestAnimationFrame` if needed, but test
  first without it -- CSS property updates are very cheap.

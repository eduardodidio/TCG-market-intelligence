# F141-T04: Thread isPromo through callers

**Status:** planned
**Wave:** 1

## User Story

As a collector viewing my collection, I want promo cards to show the
promo badge when I open the card preview modal or visit the card detail
page, so promo variants are clearly identified throughout the app.

## Dev Notes

### Callers to update

Each caller that renders `<CardPreviewModal>` needs to compute
`isPromo` using the new `isPromoCard(setCode, extras)` utility and
pass it as a prop.

1. **CardTile** (`frontend/src/components/CardTile.tsx`)
   - Already receives a `card` object with `set_code`.
   - CollectionCard has `extras` field. Non-collection cards (CardSummary)
     do not have `extras`.
   - Add optional `extras?: string | null` prop to CardTileProps, or
     compute isPromo from `card.set_code` only (simpler, since the
     `p`-prefix heuristic covers most cases).
   - Pass `isPromo={isPromoCard(card.set_code, extras)}` to
     CardPreviewModal.
   - Do NOT render PromoBadge on the grid tile itself (too small).

2. **CardDetail** (`frontend/src/pages/CardDetail.tsx`)
   - Has `card: CardDetail` with `set_code`.
   - Pass `isPromo={isPromoCard(card.set_code, null)}` to
     CardPreviewModal.

3. **CollectionCardDetail** (`frontend/src/pages/CollectionCardDetail.tsx`)
   - Has `card: CollectionCardDetail` with `set_code` and `extras`.
   - Pass `isPromo={isPromoCard(card.set_code, card.extras)}` to
     CardPreviewModal.

4. **CatalogPage** (`frontend/src/pages/CatalogPage.tsx`)
   - Check if it renders CardPreviewModal. If it uses CardTile, the
     update in (1) covers it. If it has its own preview, update
     similarly.

5. **SharedCollectionPage** (`frontend/src/pages/SharedCollectionPage.tsx`)
   - Uses CardTile. Same as (1).

6. **DeckCardTile** (`frontend/src/components/DeckCardTile.tsx`)
   - Check if it renders CardPreviewModal. If yes, thread isPromo.
     DeckCard type has `set_code` but no `extras`, so use set_code only.

7. **DuplicatesList** (`frontend/src/components/DuplicatesList.tsx`)
   - Check if it renders CardPreviewModal. If yes, thread isPromo.

8. **WishlistPage** (`frontend/src/pages/WishlistPage.tsx`)
   - Check if it renders CardPreviewModal. If yes, thread isPromo.

9. **Marketplace** (`frontend/src/pages/Marketplace.tsx`)
   - Check if it renders CardPreviewModal. If yes, thread isPromo.

### Import the utility

All callers need:
```ts
import { isPromoCard } from "../utils/promo";
```

### What NOT to change

- CardTile grid tiles: no PromoBadge on thumbnails (too small)
- Card3DTilt: no changes needed (foil effect is already handled by T01/T02)
- Backend: no API changes

# F141-T03: Add isPromo prop to CardPreviewModal + PromoBadge component

**Status:** planned
**Wave:** 1

## User Story

As a collector inspecting a promo card, I want to see a silver "PROMO"
stamp on the card image (similar to the real holofoil stamp on MTG cards),
so I can immediately tell the card is a promo variant.

## Dev Notes

### New component: PromoBadge

File: `frontend/src/components/PromoBadge.tsx`

1. A small overlay badge positioned at the bottom-center of the card
   image, mimicking the holofoil stamp location on real MTG cards.

2. Visual design:
   - Rounded pill shape, ~60px wide
   - Silver/platinum gradient background:
     `linear-gradient(135deg, #c0c0c0, #e8e8e8, #a0a0a0)`
   - Text: "PROMO" in small caps, dark gray (`#333`), font-weight 700
   - Subtle metallic border: `1px solid rgba(255,255,255,0.5)`
   - Drop shadow for depth: `0 1px 3px rgba(0,0,0,0.3)`
   - Opacity ~0.85 so the card art shows through slightly

3. Positioning: `absolute bottom-2 left-1/2 -translate-x-1/2`
   The parent must be `relative` (Card3DTilt's foil-shimmer div already
   is, and CardPreviewModal's image container should be too).

4. `pointer-events: none` so clicks pass through to the card.

5. Props: none needed (it is purely visual). Accept optional `className`
   for size overrides if needed.

6. `data-testid="promo-badge"` for test targeting.

### New utility: isPromoCard

File: `frontend/src/utils/promo.ts`

1. Export function `isPromoCard(setCode: string | null, extras: string | null): boolean`
2. Returns true if:
   - `setCode` starts with `p` and the remainder is a known set code
     pattern (2-3 lowercase letters), e.g., `pone`, `pltr`, `pmkm`
   - OR `extras` contains the substring "promo" (case-insensitive)
3. Guard against false positives: set codes like `pip` (Pauper), `pca`
   (Planechase Anthology) are real sets, not promo prefixes. Use a
   simple heuristic: if `setCode` length is 4+ and starts with `p`,
   treat as promo. This is good enough for Liga-sourced data where
   promo set codes follow the `p{base_set}` convention.

### CardPreviewModal changes

File: `frontend/src/components/CardPreviewModal.tsx`

1. Add `isPromo?: boolean` prop (default `false`).
2. When `isPromo=true`, render `<PromoBadge />` as an overlay on the
   card image, positioned inside the Card3DTilt children:
   ```tsx
   <Card3DTilt foil={isFoil} ...>
     <div className="relative">
       <img ... />
       {isPromo && <PromoBadge />}
     </div>
   </Card3DTilt>
   ```
3. The `relative` wrapper ensures PromoBadge positions correctly even
   when Card3DTilt applies transforms.

### Card3DTilt changes (minor)

Optionally, Card3DTilt could accept a `promoBadge?: boolean` prop and
render PromoBadge internally. However, keeping PromoBadge in the caller
is simpler and more flexible. Prefer the CardPreviewModal approach above.

For CardTile grid tiles, the promo badge should NOT be shown (too small
to be useful on thumbnails). Only show in CardPreviewModal and detail
pages.

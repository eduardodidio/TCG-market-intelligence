# T01 — Fix catalog stats "cards with price" counter

## User Story
As a user running `catalog stats`, I want to see the correct count of cards that have prices, so I know scan coverage.

## Bug Analysis
The query in `src/cli/main.py` (lines ~1914-1928) uses an IN subquery matching `source_cards.external_id` against `price_observations.external_id`. But:
- Seeder creates `external_id = f"liga_catalog_{set_code}_{collector_number}"`
- Liga sweep stores prices as `external_id = f"liga_{card_id}"`
- These never match → count is always 0.

## Dev Notes
**File:** `src/cli/main.py` (catalog stats command, ~line 1914)

**Fix:** Replace the external_id IN subquery with a card_id-based JOIN:
```python
with_price = (
    session.execute(
        select(func.count(func.distinct(SourceCardRow.card_id)))
        .where(
            SourceCardRow.source == "liga",
            SourceCardRow.external_id.like("liga_catalog_%"),
            SourceCardRow.card_id.in_(
                select(func.distinct(PriceObservationRow.card_id)).where(
                    PriceObservationRow.source == "liga",
                    PriceObservationRow.card_id.isnot(None),
                )
            ),
        )
    ).scalar()
    or 0
)
```
If `PriceObservationRow` doesn't have `card_id`, use a subquery that extracts card_id from the external_id pattern `liga_{card_id}` via source_cards JOIN.

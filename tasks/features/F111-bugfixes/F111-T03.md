# T03 — Fix disappeared collection (My Collection empty)

## User Story
As a user, my collection should always be visible after login, without data loss.

## Bug Analysis
User reports collection disappeared. Possible causes:
1. push-db replaced DB with one that doesn't have the user's collection data
2. `/db/restore` invalidated caches but user_collection FK references broke
3. Auth token references old user_id that doesn't exist in restored DB
4. Frontend filtering/query returning empty due to stale state

## Dev Notes
**Investigation steps (in order):**

1. Check if the data exists in the DB:
   ```sql
   SELECT COUNT(*) FROM user_collection;
   SELECT COUNT(*) FROM users;
   ```

2. Check if the user_id in the JWT matches a user in the current DB:
   - `src/api/routers/collection.py` — how user_id is resolved
   - If user was ID=1 in old DB but ID=5 in restored DB → collection query returns empty

3. If data loss from push-db:
   - Ensure push-db scripts copy the FULL database (including user_collection table)
   - Verify `.bat` scripts don't exclude tables

4. If auth mismatch:
   - This ties to T02 — forcing re-auth after DB restore would fix user_id mismatch
   - Additionally: `/db/restore` should verify user table integrity

**Possible fixes:**
- If data is in DB but user_id mismatch: T02 fix (force re-auth) resolves this
- If data was lost: check push-db pipeline, ensure atomic DB copy
- Add a safeguard: before `/db/restore`, backup current DB to `tcg_market.db.bak`

## Testing
- Integration test: restore DB, verify collection data persists
- Test: user_id consistency after DB restore

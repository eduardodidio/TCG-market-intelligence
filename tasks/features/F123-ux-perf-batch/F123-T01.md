# F123-T01: Collapsible Sidebar with Icon Navigation

**Status:** planned
**Wave:** 0

## User Story

As a user, I want to collapse the sidebar to icon-only mode so I have more
screen space for card grids, especially on smaller laptop screens.

## Acceptance Criteria

1. A toggle button (chevron or hamburger) at the top of the sidebar collapses
   it from `w-64` to `w-16`.
2. In collapsed mode, each nav item shows only its icon with a tooltip on hover
   showing the label text.
3. Sidebar state persists in localStorage (key: `sidebar-collapsed`).
4. Logo section shrinks to a small icon/initials in collapsed mode.
5. User avatar, TreasureBalance, AlertBell, CurrencyToggle, LanguageSelector,
   and ThemeToggle remain visible in collapsed mode (icon-only, stacked).
6. InstallPrompt hides in collapsed mode (or shows icon-only).
7. Width transition is smooth (CSS transition, ~200ms).
8. Mobile sidebar overlay behavior is unchanged (still full-width slide-in).
9. Dark mode styling works correctly in both states.

## Dev Notes

### Files to change

- `frontend/src/components/Layout.tsx` (only file)

### Implementation hints

1. **New state:** `const [collapsed, setCollapsed] = useState(() => localStorage.getItem('sidebar-collapsed') === 'true')`.
   Sync to localStorage in a `useEffect`.

2. **Icons:** Add an icon for each nav item in `PRIMARY_NAV_ITEMS` and
   `BETA_NAV_ITEMS`. Use inline SVGs or a lightweight icon set already in
   the project. Each nav item object gets an `icon` field (React element or
   component).

   Suggested icon mapping (use simple SVG paths or Heroicons-style):
   - Dashboard: grid/home icon
   - Collection: stack/layers icon
   - Cards: search/magnifier icon
   - Catalog: book icon
   - Decks: cards-fan icon
   - Alerts: bell icon
   - Marketplace: shopping-bag icon
   - Achievements: trophy icon
   - Admin: shield icon
   - Trending: chart-up icon

3. **Toggle button:** Place a small chevron-left/chevron-right button at the
   bottom of the sidebar (or top-right corner). In collapsed mode the chevron
   points right (expand); in expanded mode it points left (collapse).

4. **Tooltips:** Use the `title` attribute on the nav link `<a>` or `<Link>`
   element in collapsed mode. No tooltip library needed.

5. **Width classes:** Sidebar: `collapsed ? 'w-16' : 'w-64'` with
   `transition-all duration-200`. Main content margin: adjust `ml-64` to
   `ml-16` accordingly.

6. **Collapsed layout:**
   - Logo: show first letter or small icon only
   - Nav items: center the icon, hide text (`overflow-hidden` + `whitespace-nowrap`)
   - Bottom controls (theme, currency, language): show icon only, hide labels
   - TreasureBalance: show coin icon + number only
   - AlertBell: already icon-only, no change needed

7. **Do NOT change mobile behavior.** The `sidebarOpen` state for mobile
   overlay is separate from `collapsed`. Mobile always shows full sidebar
   content in the overlay.

## Testing

### Unit tests (Vitest + RTL)

- Sidebar renders expanded by default (no localStorage value).
- Clicking toggle button collapses sidebar (width changes, text hidden).
- Clicking toggle again expands sidebar.
- localStorage is updated on toggle.
- Sidebar initializes collapsed when localStorage has `sidebar-collapsed=true`.
- Nav item tooltips appear in collapsed mode (title attribute present).
- Mobile overlay is unaffected by collapsed state.

### Visual verification

- Smooth width transition on collapse/expand.
- Icons are centered and legible at w-16.
- Dark mode renders correctly in both states.
- No layout shift in main content area during transition.

# F123-T03: CardPreviewModal Component

**Status:** planned
**Wave:** 0

## User Story

As a user, I want to click a card image to open a large modal with a 3D tilt
effect (like deckcheck.co), letting me inspect the card art like a physical
card. Foil cards should show the holographic shimmer.

## Acceptance Criteria

1. `CardPreviewModal` opens a centered overlay with a large card image
   wrapped in the existing `Card3DTilt` component.
2. Modal has close button (X) top-right and click-outside-to-close.
3. Escape key closes the modal.
4. Foil cards show holographic shimmer (via `Card3DTilt foil={true}`).
5. Card name displayed below the image.
6. Modal uses higher tilt angle (18 deg) and larger scale for dramatic effect.
7. Works in dark and light themes.
8. Respects `prefers-reduced-motion` (Card3DTilt already handles this).

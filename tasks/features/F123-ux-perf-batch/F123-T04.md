# F123-T04: Integrate CardPreviewModal in Card Tiles

**Status:** planned
**Wave:** 1 (depends on T03)

## User Story

As a user browsing cards in any grid (collection, catalog, decks), I want to
click a card image to open the 3D tilt preview modal so I can inspect the art.

## Acceptance Criteria

1. Clicking a card image in CardTile opens CardPreviewModal.
2. Clicking a card image in CatalogCardTile opens CardPreviewModal.
3. Clicking a card image in DeckCardTile opens CardPreviewModal.
4. The rest of the card tile (name, price, badges) remains clickable for
   navigation to card detail --- only the image area opens the modal.
5. Cards without `image_uri` do not open modal (no click handler).
6. Modal works in dark and light themes.
7. On mobile, tapping card image opens modal (Card3DTilt auto-disables
   tilt on no-hover devices, but click still works).

## Dev Notes

### Files to change

1. **`frontend/src/components/CardTile.tsx`**
   - Add `onClick` handler on the CardImage wrapper to open CardPreviewModal.
   - Use local state: `const [previewOpen, setPreviewOpen] = useState(false)`.
   - Stop propagation on image click so it does not navigate to detail page.
   - Pass `foil={card.is_foil}` to CardPreviewModal's `isFoil` prop.

2. **`frontend/src/components/CatalogCardTile.tsx`**
   - Same pattern as CardTile.

3. **`frontend/src/components/DeckCardTile.tsx`**
   - Same pattern. Keep existing ownership overlay logic intact.

### Integration pattern

```tsx
import { CardPreviewModal } from './CardPreviewModal';

// Inside the tile component:
const [previewOpen, setPreviewOpen] = useState(false);

// In JSX, on the image area:
<div onClick={(e) => { e.stopPropagation(); setPreviewOpen(true); }}
     className="cursor-zoom-in">
  {/* existing Card3DTilt + CardImage code */}
</div>

{previewOpen && (
  <CardPreviewModal
    imageUrl={card.image_uri}
    cardName={card.name}
    isFoil={card.is_foil}
    onClose={() => setPreviewOpen(false)}
  />
)}
```

### Edge cases

- Cards without `image_uri`: do not add click handler, no preview.
- Mobile: Card3DTilt already auto-disables tilt, but click still opens modal.

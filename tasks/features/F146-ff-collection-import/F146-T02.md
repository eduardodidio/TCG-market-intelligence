# F146-T02: Re-seed catalog if needed + scan FF sets for Liga prices

**Status:** planned
**Wave:** 1
**Depends on:** T01

## User Story

As a user, I want Final Fantasy cards (including Tifa Lockhart) to appear in
my catalog with Liga prices, so I can track their market value.

## Dev Notes

### Step 1: Re-seed catalog (conditional on T01 findings)

If T01 found that "Tifa Lockhart" is missing from the DB, run a fresh
catalog seed to pull the latest Scryfall bulk data:

```bash
python -m src.cli.main catalog seed
```

This downloads the latest `default_cards` JSONL.gz from Scryfall (~300MB)
and upserts all paper English cards. The operation is idempotent — existing
cards are skipped, new cards are inserted.

**Expected time:** ~10 minutes (download + parse + upsert).

After seeding, verify Tifa exists:

```sql
SELECT id, name, set_code, collector_number
FROM cards
WHERE LOWER(name) LIKE '%tifa%';
```

### Step 2: Scan Liga prices for FF sets

Run `catalog scan` for each FF set code. Priority order:

```bash
# Main set first (largest, most likely to have user's cards)
python -m src.cli.main catalog scan --set fin --delay 5 --batch-size 20 --batch-pause 60

# Commander set (if it exists in DB after seed)
python -m src.cli.main catalog scan --set fic --delay 5 --batch-size 20 --batch-pause 60

# Promo variants (lower priority, smaller sets)
python -m src.cli.main catalog scan --set pfin --delay 5 --batch-size 20 --batch-pause 60
python -m src.cli.main catalog scan --set afin --delay 5 --batch-size 20 --batch-pause 60
```

**Rate limiting notes:**
- `--delay 5` = 5 seconds between individual card requests
- `--batch-size 20` = 20 cards per batch before pausing
- `--batch-pause 60` = 60 seconds pause between batches
- `--max-age-days 7` (default) = skip cards priced within last 7 days
- For `fin` with 288/601 already priced, ~313 cards remain = ~2 hours
- For `fic` (if fully unscanned), time depends on card count

**Important:** Liga sweep runs from the user's local machine (residential
IP required — Liga blocks datacenter IPs). Do NOT attempt to run this from
CI or cloud environments.

### Step 3: Verify results

After scanning, check coverage:

```bash
python -m src.cli.main catalog missing --user-id 3 --min-cards 1 | grep -i "fin\|fic"
```

And verify Tifa specifically has a price:

```sql
SELECT c.name, c.set_code, po.price_mid, po.observed_at
FROM cards c
JOIN price_observations po ON po.external_id = 'liga_' || CAST(c.id AS TEXT)
WHERE LOWER(c.name) LIKE '%tifa%'
ORDER BY po.observed_at DESC;
```

### Expected Outcome

- `fin` set: >90% Liga price coverage (up from 48%)
- `fic` set: scanned (coverage depends on Liga availability)
- "Tifa Lockhart" has a Liga price observation
- User can find Tifa in the catalog page search

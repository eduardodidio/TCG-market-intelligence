# F146 — Final Fantasy Collection Import + Missing Sets Discovery

**Status:** planned
**Created:** 2026-09-18
**Priority:** P1

## Summary

Operational feature: discover which Scryfall set codes contain Final Fantasy
crossover cards (Tifa Lockhart, Cloud Strife, etc.), ensure they are seeded
in the catalog, scan Liga prices for them, and generate a comprehensive
missing-sets batch script using the existing `catalog missing` CLI from F138.

## Context

- Scryfall bulk data was seeded with 994 sets. Final Fantasy cards live in
  set codes `fin` (Final Fantasy, 601 cards) and `fic` (Final Fantasy
  Commander, unknown count in DB). The set code map already handles MYP
  variant `eafic` -> `fic` (added in F131).
- The `scan-missing-collection.sh` script (generated by F138) already lists
  `fin` with 288/601 priced and `fic` is likely in the unscanned list or
  already partially covered.
- The user cannot find "Tifa Lockhart" — this is either because the card is
  not yet seeded (stale Scryfall bulk data) or because the Liga scan has not
  covered it yet (288/601 = 48% coverage on `fin`).
- Related sets: `pfin` (promo Final Fantasy, 94 cards) and `afin` (art
  series Final Fantasy, 53 cards) also appear in the missing script.

## Architecture

This is purely operational — no code changes expected. The Developer agent
will run existing CLI commands and generate documentation.

### Key Commands

```bash
# 1. Check if FF cards exist in DB
python -m src.cli.main catalog stats

# 2. Re-seed if needed (downloads latest Scryfall bulk data)
python -m src.cli.main catalog seed

# 3. Scan FF sets
python -m src.cli.main catalog scan --set fin --delay 5 --batch-size 20 --batch-pause 60
python -m src.cli.main catalog scan --set fic --delay 5 --batch-size 20 --batch-pause 60
python -m src.cli.main catalog scan --set pfin --delay 5 --batch-size 20 --batch-pause 60

# 4. Generate missing-sets script
python -m src.cli.main catalog missing --user-id 3 --format script > scripts/scan-missing-collection.sh
```

## Risks

- Liga may not have listings for all FF cards (new set, limited Brazilian
  market availability). Expect some `not_found` results.
- Re-seeding catalog takes ~10 minutes (downloads ~300MB from Scryfall).
- Liga rate limits: scanning 300+ remaining `fin` cards at 5s delay with
  20-card batches and 60s pauses will take approximately 2-3 hours.
- The `fic` set may not exist on Liga at all if Commander precons are not
  yet released in Brazil.

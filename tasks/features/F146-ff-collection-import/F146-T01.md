# F146-T01: Investigate FF set codes in Scryfall + verify DB state

**Status:** planned
**Wave:** 0
**Depends on:** none

## User Story

As a user, I want to understand which Scryfall set codes contain Final
Fantasy cards and whether they are already in my database, so I can decide
what needs scanning.

## Dev Notes

### Step 1: Query DB for FF-related sets

Run a SQL query against the catalog to find all sets with "final fantasy" or
FF-related set codes:

```bash
# Check which FF set codes exist in the DB
python -m src.cli.main catalog stats
```

Then use a direct DB query (via Python one-liner or psql) to check:

```sql
SELECT set_code, COUNT(*) as total
FROM cards
WHERE set_code IN ('fin', 'fic', 'pfin', 'afin')
GROUP BY set_code
ORDER BY total DESC;
```

### Step 2: Search for "Tifa Lockhart" specifically

```sql
SELECT id, name, set_code, collector_number, rarity
FROM cards
WHERE LOWER(name) LIKE '%tifa%'
ORDER BY set_code, collector_number;
```

If zero results: the Scryfall bulk data is stale and needs re-seeding (T02).
If results exist but no prices: the Liga scan has not covered that card yet.

### Step 3: Check current price coverage for fin/fic

```sql
SELECT c.set_code, COUNT(DISTINCT c.id) as priced
FROM cards c
JOIN price_observations po ON po.external_id = 'liga_' || CAST(c.id AS TEXT)
WHERE c.set_code IN ('fin', 'fic', 'pfin', 'afin')
GROUP BY c.set_code;
```

### Step 4: Verify set_code_map.py coverage

Confirm that the set code map in `src/utils/set_code_map.py` handles MYP
variants for FF sets. Currently known: `eafic` -> `fic`. Check if there are
MYP variants for `fin` that need mapping (e.g., `blfin`, `exfin`, `skfin`).

### Expected Outcome

A clear picture of:
1. Which FF sets are seeded (fin, fic, pfin, afin) with card counts
2. Whether "Tifa Lockhart" exists in the DB
3. Current Liga price coverage per FF set
4. Whether a catalog re-seed is needed
5. Any missing set_code_map entries for MYP FF variants

### Decision Gate

- If Tifa is NOT in DB -> proceed to T02 with re-seed
- If Tifa IS in DB but no price -> proceed to T02 scan-only (skip seed)
- If all FF sets already >90% priced -> T02 can be skipped

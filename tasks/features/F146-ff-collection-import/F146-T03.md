# F146-T03: Generate comprehensive missing-sets batch script + docs

**Status:** planned
**Wave:** 1
**Depends on:** T01

## User Story

As a user, I want a prioritized batch script covering all my unscanned
collection sets, so I can run it overnight and fill price gaps across my
entire collection — not just Final Fantasy.

## Dev Notes

### Step 1: Regenerate the missing-sets script

After T01 investigation (and optionally after T02 seed), regenerate the
comprehensive missing-sets script using the F138 CLI:

```bash
python -m src.cli.main catalog missing --user-id 3 --format script > scripts/scan-missing-collection.sh
```

This overwrites the existing script with fresh data reflecting any new
seeds or scans completed.

### Step 2: Review and prioritize the output

The generated script groups sets into:
1. **Collection priority** — sets the user owns cards from (marked `*COLL*`)
2. **Unscanned sets** — sets with zero price data
3. **Partially scanned** — sets with <50% coverage

Manual review checklist:
- Are all FF sets (`fin`, `fic`, `pfin`, `afin`) covered?
- Are high-value collection sets near the top?
- Is the `scan_set` function definition included at the top?

### Step 3: Add scan_set function header

The generated script only outputs `scan_set` calls. Ensure the script has
the proper header with the function definition. The header should match
the existing `catalog-scan-batch.sh` format:

```bash
#!/usr/bin/env bash
set -e
cd "$(dirname "$0")/.."

CLI="python -m src.cli.main"

scan_set() {
  local code=$1
  echo ""
  echo "--- Scanning set: $code ($(date)) ---"
  $CLI catalog scan --set "$code" --delay 5 --batch-size 20 --batch-pause 60
  echo "--- Done: $code ($(date)) ---"
}
```

### Step 4: Document FF set codes

Add a brief reference section to the script header or as a comment block
documenting the FF set code mapping:

```bash
# Final Fantasy set codes (Scryfall):
#   fin  — Final Fantasy (main set, ~601 cards)
#   fic  — Final Fantasy Commander (~TBD cards)
#   pfin — Promo Final Fantasy (~94 cards)
#   afin — Art Series Final Fantasy (~53 cards)
# MYP variant mapping: eafic -> fic (in src/utils/set_code_map.py)
```

### Step 5: Estimate total scan time

Calculate approximate run time for the full batch:
- Formula: `(cards / batch_size) * (delay * batch_size + batch_pause) / 3600` hours
- Example for collection-priority sets: sum total unpriced cards across all
  `*COLL*` entries, apply formula
- Document the estimate in the script header so the user knows how long an
  overnight run will take

### Expected Outcome

- Updated `scripts/scan-missing-collection.sh` with:

  - FF set codes documented in comments
  - Collection-priority sets first
  - Estimated run time in header comments
- User can run `bash scripts/scan-missing-collection.sh` and walk away

# F185-T04 — Diagnostic CLI + Diagrams

**Wave:** 1
**Type:** backend + docs
**Depends on:** F185-T01
**Status:** done

## User Story

As a system operator, I want a CLI command to identify price data outliers, so
that I can audit and clean dirty data when needed.

## Objective

Add a `diagnose-prices` CLI subcommand that reports price observation outliers
(penny cards, extreme swings) without modifying data, plus the two mandatory
Mermaid diagrams.

## Dev Notes

- CLI file: `src/cli/main.py` — add `diagnose-prices` command to existing Click group
- Query: find price_observations where `median_price < 0.5` or
  where the same card has observations with `max/min ratio > 20x`
- Output: table with card_id, name, external_id, source, median_price, observed_at
- Read-only — no mutations
- Use existing `get_repo()` pattern from other CLI commands
- Limit output to top 50 outliers by default, with `--limit` option
- Diagram templates: `docs/diagrams/templates/`

## Test Scenarios

1. **Penny prices found**: seed DB with penny price, verify it appears in output
2. **Extreme ratios found**: seed card with 0.50 and 100.00 prices, verify flagged
3. **Clean data**: seed only valid data, verify empty/clean output

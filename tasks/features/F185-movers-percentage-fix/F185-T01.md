## User Story

As a user viewing market movers, I want percentages to be realistic and not
show absurd values like 49900%, so that I can trust the data.

## Objective

Align `get_movers()` filtering with `get_collection_movers_optimized()` by
adding the R$0.50 minimum price floor and +/-1000% percentage cap.

# F185-T03 — Price Observation Insertion Validation

**Wave:** 1
**Type:** backend
**Depends on:** F185-T01
**Status:** done

## User Story

As a system operator, I want price observations to be validated before
insertion, so that dirty data (zero/negative prices) never enters the database.

## Objective

Add validation to `insert_price_observations()` to reject price observations
with `median_price <= 0` before they reach the database, preventing future
dirty data from accumulating.

## Dev Notes

- File: `src/database/repository.py`
- `insert_price_observations()` at lines 386-430
- Currently: no validation on price values — passes everything through
- Liga provider already rejects negatives at parser level (`src/parsers/liga.py:31-78`)
- MYP JSON-LD rejects zeros (`src/parsers/myp.py:209-242`)
- But MYP history parser does NOT filter zeros (`src/parsers/myp.py:308-317`)
- Defense in depth: validate at repository level as last line of defense
- Filter strategy: skip observations where ALL price fields are None or <= 0
  (don't reject the whole batch — just skip individual bad records)
- Log filtered records with structlog warning for visibility
- Do NOT reject records where median_price is None but other fields have
  valid values (that's legitimate — e.g., tcg_price only)

## Implementation Details

### Edit: `src/database/repository.py` — `insert_price_observations()`

```python
# Before the bulk insert, filter out bad records:
valid_prices = []
for p in prices:
    # Skip if median_price is explicitly zero or negative
    if p.median_price is not None and p.median_price <= 0:
        logger.warning("skipping_invalid_price", external_id=p.external_id,
                       median_price=float(p.median_price))
        continue
    valid_prices.append(p)
# Use valid_prices for the insert
```

## Acceptance Criteria

- [ ] Observations with `median_price = 0` are skipped (not inserted)
- [ ] Observations with `median_price < 0` are skipped
- [ ] Observations with `median_price = None` are still inserted (legitimate)
- [ ] Observations with valid `median_price > 0` are inserted normally
- [ ] Skipped records are logged with structlog warning
- [ ] Batch insert count reflects only valid records

return detailed value history for a single deck.

### Modified file: `src/api/routers/decks.py`

#### `GET /ranking` (must be defined BEFORE `/{deck_id}` to avoid route conflict)

Query params: `sort_by`, `sort_order`, `period`, `min_value`, `max_value`,
`currency`, `limit`, `offset`.

Implementation flow:
1. Load all user decks via `repo.list_decks(user_id)`
2. Collect all unique card_ids across all decks
3. Batch-fetch latest prices via `repo.get_latest_prices_batch(all_card_ids)`
4. For each deck:
   a. Get deck cards via `repo.get_deck_cards(deck.id)`
   b. Compute `DeckValuation` via `compute_deck_value()`
   c. If period-based sorting needed, load price series via
      `repo.get_price_series_batch()` and compute value change
   d. Compute sparkline from value series (list of floats)
   e. Get deck summary for ownership stats
5. Apply `min_value`/`max_value` filters
6. Sort by requested field
7. Paginate with offset/limit
8. Return `DeckRankingResponse` wrapped in `ApiResponse`

Currency conversion: apply converter to all value fields.

#### `GET /{deck_id}/value`

Query params: `period` (default `30d`), `currency`.

Implementation:
1. Load deck, verify ownership
2. Load deck cards
3. Batch-load price series for linked cards
4. Compute full value series via `compute_deck_value_series()`
5. Compute value change via `compute_deck_value_change()`
6. Apply currency conversion
7. Return `DeckValueDetailSchema`

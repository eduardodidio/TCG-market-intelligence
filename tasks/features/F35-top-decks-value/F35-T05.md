# F35-T05: DeckList value badges + DeckView value panel

**Status:** planned
**Wave:** 2

## User Story

As a collector, I want to see each deck's value on the deck list page
and a value trend chart on the deck detail page, so I can assess my
collection's worth without navigating to a separate ranking page.

## Dev Notes

### Modified file: `frontend/src/pages/DeckList.tsx`

Update each deck card in the grid to show:
1. **Total value badge**: below the ownership stats row, show
   `total_value` formatted with `CurrencyIndicator`. Show "N/A" if null.
2. **Value change indicator**: small colored text next to value showing
   `value_change_pct` (e.g., "+5.2%" in green, "-3.1%" in red).
   Only show if `value_change_pct` is not null.

The existing `DeckSummary` type needs `total_value` and
`value_change_pct` fields (added in T03's schema extension). Update
the TypeScript `DeckSummary` interface in `types/api.ts` to include:
- `total_value: number | null`
- `value_change_pct: number | null`

### Modified file: `frontend/src/pages/DeckView.tsx`

Add a value summary panel between the stats row and the card grid:

1. **Value summary bar**: horizontal panel with:
   - Total deck value (large text with currency)
   - Value change badge (delta + percent, colored)
   - "X of Y cards priced" data coverage indicator
2. **Value trend chart**: Recharts `AreaChart` below the summary bar
   showing deck value over time. Uses `fetchDeckValue(deckId, period)`
   from `deckRanking.ts`. Period selector (7d/30d/90d) controls the
   chart range.
3. Collapsible: chart hidden by default, "Show value history" toggle
   to expand (keeps the card grid as primary focus).

Implementation:
- Call `fetchDeckValue(deckId, period)` on mount
- Render AreaChart with gradient fill (cyan for up, red for down)
- Show loading skeleton while fetching
- Handle case where value_series is empty (no price data)

# F35-T02: Valuation service + repository helper

**Status:** planned
**Wave:** 1

## User Story

As a backend developer, I need pure functions to compute a deck's total
value and value history from card price data, and a repository method to
batch-load price series for multiple cards efficiently.

## Dev Notes

### New file: `src/decks/valuation.py`

Pure functions (no DB imports):

#### `compute_deck_value(card_prices, deck_cards) -> DeckValuation`
- `card_prices: dict[int, Decimal | None]` — card_id -> latest price
- `deck_cards: list` — objects with `card_id` and `quantity` attributes
- Sum `price * quantity` for each card where `card_id` is not None and
  price is not None
- Track priced vs unpriced counts
- Return `DeckValuation(total_value, priced_cards, unpriced_cards)`
- If no cards have prices, `total_value = None`

#### `compute_deck_value_series(deck_cards, price_series_by_card, days) -> list[DeckValuePoint]`
- `price_series_by_card: dict[int, list[HistoricalPrice]]` — card_id -> sorted price list
- Build a date-indexed matrix: for each date in the union of all series,
  sum all card prices at that date (carry-forward last known price)
- Return chronologically sorted `list[DeckValuePoint]`
- Downsample to max 30 points if series is longer (evenly spaced selection)

#### `compute_deck_value_change(value_series, period_days) -> DeckValueChange | None`
- Compare last point's value to the value `period_days` ago (nearest available)
- Return `DeckValueChange(current, previous, delta, delta_pct)`
- Return None if fewer than 2 data points

### Modified file: `src/database/repository.py`

#### `get_price_series_batch(self, card_ids, days=90) -> dict[int, list[HistoricalPrice]]`
- Single query: JOIN source_cards (card_id IN card_ids) with
  price_observations (observed_at >= cutoff)
- Group results by card_id
- Convert to `HistoricalPrice` domain objects
- Return dict keyed by card_id

This avoids N+1 queries when valuing a deck with many cards.

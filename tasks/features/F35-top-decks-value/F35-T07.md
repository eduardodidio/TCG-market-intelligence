## Dev Notes

### Backend tests

#### `tests/unit/decks/test_valuation.py` (new)

Test `compute_deck_value`:
- Basic: 3 cards with prices, correct sum accounting for quantity
- Mixed: some cards priced, some not — correct priced/unpriced counts
- All unpriced: total_value is None
- Empty deck: total_value is None, priced=0, unpriced=0
- Card with card_id=None (unlinked): counted as unpriced

Test `compute_deck_value_series`:
- Single card: series matches card's price series
- Multiple cards: values summed per date
- Carry-forward: gaps in one card's series use last known price
- Downsampling: 60-point series reduced to 30 points
- Empty input: returns empty list

Test `compute_deck_value_change`:
- Normal: current > previous, positive delta/delta_pct
- Decline: current < previous, negative values
- Insufficient data (<2 points): returns None
- Period exceeds data range: uses earliest available as "previous"

#### `tests/unit/api/test_deck_ranking.py` (new)

Test ranking endpoint:
- Returns decks sorted by total_value descending (default)
- sort_by=value_change_pct works correctly
- sort_order=asc reverses order
- min_value filter excludes cheap decks
- max_value filter excludes expensive decks
- min_value + max_value combined range
- Pagination: offset=0 limit=2 returns first 2, offset=2 returns next
- Auth required: 401 without token
- Only returns authenticated user's decks (IDOR protection)
- Empty deck list: returns empty array, total=0

Test value detail endpoint:
- Returns value series for valid deck
- 404 for nonexistent deck
- 404 for other user's deck
- Period parameter affects series length
- Currency conversion applied

#### `tests/unit/database/test_repository_price_batch.py` (new)

Test `get_price_series_batch`:
- Returns grouped price series for multiple card_ids
- Empty card_ids returns empty dict
- Card with no source_cards returns empty series
- Days parameter limits date range

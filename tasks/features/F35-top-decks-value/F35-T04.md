# F35-T04: TopDecksPage + DeckSparkline + API client

**Status:** shipped
**Wave:** 2

## User Story

As a collector, I want a dedicated Top Decks page that ranks my decks
by total value with sparkline trends, so I can see which decks are
most valuable at a glance.

## Dev Notes

### New file: `frontend/src/pages/TopDecksPage.tsx`

Page at route `/decks/ranking`. Layout:

1. **Header row**: title "Top Decks" + sort dropdown + period selector
2. **Ranked list**: each row is a horizontal card showing:
   - Rank number (1, 2, 3...)
   - Deck name (link to `/decks/{id}`)
   - Total value (large, bold, with currency indicator)
   - Value change badge: colored arrow + delta_pct (green positive,
     red negative, gray zero/null)
   - Sparkline (tiny line chart, ~100px wide)
   - Card count and ownership % (small text)
   - Priced/unpriced indicator (e.g., "45/60 priced")
3. **Empty state**: "No decks yet" message with link to import
4. **Loading state**: skeleton rows

Controls:
- Sort dropdown: "Value" | "Value Change %" | "Cards" (maps to
  `sort_by` param)
- Period pills: 7d | 30d | 90d
- URL param persistence for sort + period

Pagination: "Load more" button (offset-based).

### New file: `frontend/src/components/DeckSparkline.tsx`

Minimal Recharts `LineChart`:
- No axes, no grid, no tooltip, no legend
- Single `Line` with `stroke` color based on trend (green if last >
  first, red if last < first, gray if equal)
- Fixed height ~32px, width ~100px
- Props: `data: number[]`, `width?: number`, `height?: number`

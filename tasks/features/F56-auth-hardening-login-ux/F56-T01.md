## User Story

As the project owner, I want the seed user password to be `mudar@123` and
unauthenticated visitors to land on the login page, so that the app is
secure by default and credentials are predictable for development.

## Dev Notes

### Backend — Seed Password

**File:** `src/cli/main.py` (lines 528-531)

Current behavior: password comes from `TCG_SEED_PASSWORD` env var, or a
random 16-char token if not set.

Change: hardcode default password to `mudar@123` when `TCG_SEED_PASSWORD`
is not set (replace the random token fallback).

```python
password = os.environ.get("TCG_SEED_PASSWORD", "mudar@123")
```

### Frontend — Default Redirect to Login

**File:** `frontend/src/App.tsx`

Current behavior: `/` renders Dashboard (public). ProtectedRoute only
wraps `/collection`, `/decks`, etc.

Change: wrap the Dashboard route (`/`) with `<ProtectedRoute>` so
unauthenticated users are redirected to `/login`. The `returnTo` param
already works in ProtectedRoute (line 15 of ProtectedRoute.tsx).

All public routes that should remain public:

# F188-T06: Update DeckEvaluationPanel with Synergy Score + Role Breakdown

- **Wave:** 2
- **Type:** frontend
- **Depends on:** T04, T05
- **Status:** planned

## User Story

As a user viewing my deck's evaluation, I want to see the overall synergy
score, a role coverage breakdown (removal, draw, ramp), and tribal density,
so that I understand the deck's strategic strengths and weaknesses at a
glance.

## Objective

Update `DeckEvaluationPanel.tsx` to display the new synergy metrics from
the evaluation API response. Add i18n keys for all new labels.

### DeckEvaluationPanel changes

Add three new sections to the evaluation panel, below the existing
mana curve and type distribution charts:

#### 1. Synergy Score Gauge

A circular progress indicator or a horizontal bar showing the overall
synergy score as a percentage:

```tsx
{evaluation.synergy_score !== null && (
  <div className="...">
    <h3>{t("deck.evaluation.synergyScore")}</h3>
    <div className="flex items-center gap-3">
      <div className={`text-2xl font-bold ${synergyColor}`}>
        {(evaluation.synergy_score * 100).toFixed(0)}%
      </div>
      <div className="flex-1 bg-gray-200 dark:bg-gray-700 rounded-full h-3">
        <div
          className={`h-3 rounded-full ${synergyBarColor}`}
          style={{ width: `${evaluation.synergy_score * 100}%` }}
        />
      </div>
      <span className="text-sm text-gray-500">{synergyLabel}</span>
    </div>
  </div>
)}
```

Color mapping:
- 0.0-0.19: red ("Low")
- 0.20-0.39: orange ("Moderate")
- 0.40-0.59: yellow ("Good")
- 0.60+: green ("Excellent")

#### 2. Role Coverage Chart

A horizontal bar chart (Recharts BarChart) showing counts per role:

```tsx
{evaluation.role_coverage.length > 0 && (
  <div className="...">
    <h3>{t("deck.evaluation.roleCoverage")}</h3>
    <ResponsiveContainer width="100%" height={200}>
      <BarChart data={roleCoverageData} layout="vertical">
        <XAxis type="number" />
        <YAxis type="category" dataKey="role" width={80} />
        <Tooltip />
        <Bar dataKey="count" fill="#3b82f6" radius={[0, 4, 4, 0]} />
      </BarChart>
    </ResponsiveContainer>
  </div>
)}
```

Translate role names: `t("deck.roles.removal")`, `t("deck.roles.draw")`,
etc.

#### 3. Tribal Density

A simple stat line (only shown for commander format):

```tsx
{evaluation.tribal_density !== null && (
  <div className="flex items-center gap-2">
    <span>{t("deck.evaluation.tribalDensity")}</span>
    <span className="font-bold">
      {(evaluation.tribal_density * 100).toFixed(0)}%
    </span>
  </div>
)}
```

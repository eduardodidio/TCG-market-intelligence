# F188-T02: Create Synergy Scoring Engine (src/decks/synergy.py)

- **Wave:** 0
- **Type:** backend
- **Depends on:** none
- **Status:** planned

## User Story

As a deck builder engine, I need a pure-function module that can analyze
card text for synergy with a commander's keywords, so that I can score
and rank cards by how well they support the deck's strategy.

## Objective

Create `src/decks/synergy.py` -- a pure-function module (zero DB imports,
zero framework imports) that provides keyword extraction, card role
classification, and synergy scoring. This module follows the F10/F03
pattern of pure functions that receive data as arguments and return
domain objects.

## Dev Notes

### Module structure

```
src/decks/synergy.py
```

Three public functions:

#### 1. `extract_commander_keywords(oracle_text, type_line) -> CommanderKeywords`

Extracts keyword categories from the commander's oracle text and type line:

```python
@dataclass(frozen=True)
class CommanderKeywords:
    tribal_types: list[str]      # creature types from type_line
    mechanic_keywords: list[str] # mechanical themes from oracle_text
    referenced_types: list[str]  # card types referenced in oracle_text
```

**Tribal extraction** from type_line:
- Split type_line on " -- " or " \u2014 " (em-dash) to get subtypes
- Strip supertypes ("Legendary", "Basic", "Snow") and card types ("Creature", "Enchantment", etc.)
- Remaining words are creature types: e.g. "Legendary Creature \u2014 Elf Warrior" -> ["Elf", "Warrior"]

**Mechanic keyword extraction** from oracle_text (case-insensitive regex patterns):

| Category     | Regex patterns |
|-------------|----------------|
| **draw**    | `r"draw[s]?\s+(?:a\s+)?card"`, `r"draw[s]?\s+\w+\s+cards?"` |
| **ramp**    | `r"add\s*\{"`, `r"search your library for a? ?(?:basic )?land"`, `r"add \w+ mana"` |
| **removal** | `r"destroy target"`, `r"exile target"`, `r"deals?\s+\d+\s+damage"`, `r"-\d+/-\d+"`, `r"destroy all"` |
| **token**   | `r"create[s]?\s+(?:a\s+)?[\w/]+"` followed by `r"token"`, `r"populate"` |
| **counter** | `r"\+1/\+1 counter"`, `r"counter on"`, `r"counters on"` |
| **sacrifice** | `r"sacrifice a"`, `r"sacrifice an?"`, `r"when\s+.{1,30}\s+dies"`, `r"whenever\s+.{1,30}\s+dies"` |
| **flicker** | `r"exile\s+.{1,40}\s+return"`, `r"blink"`, `r"flicker"` |
| **lifegain** | `r"gain[s]?\s+\d+\s+life"`, `r"you gain life"`, `r"lifelink"` |
| **graveyard** | `r"from your graveyard"`, `r"return .{1,30} from .{0,10}graveyard"`, `r"mill"` |
| **protection** | `r"hexproof"`, `r"indestructible"`, `r"protection from"`, `r"shroud"`, `r"ward"` |
| **equipment** | `r"equip"`, `r"equipped creature"`, `r"attach"` |
| **enchantress** | `r"whenever .{0,20} enchantment"`, `r"constellation"`, `r"enchant "` |

Return a deduplicated list of matching category names (e.g. `["draw", "sacrifice", "token"]`).

**Referenced types** from oracle_text:
- Scan for card type references: "creature", "artifact", "enchantment", "instant", "sorcery", "planeswalker", "land"
- Exclude generic mentions like "target creature" which is just removal
- Focus on "whenever a creature" / "each creature you control" / "creature spells" patterns

#### 2. `classify_card_role(oracle_text) -> list[str]`

Classify a card into one or more roles using the SAME keyword patterns:

| Role        | Patterns (same as above) |
|------------|--------------------------|
| `removal`  | destroy target, exile target, deals N damage, -X/-X, destroy all |
| `draw`     | draw a card, draws a card, draw X cards |
| `ramp`     | add {, search your library for a land, add X mana |
| `protection` | hexproof, indestructible, protection from, ward |
| `token`    | create token, populate |
| `finisher` | "you win the game", "each opponent loses", trample + power >= 6 (requires type_line context) |
| `utility`  | fallback -- cards that match none of the above |

A card can have multiple roles (e.g. a card that draws and removes).
Return sorted list of role strings.

#### 3. `score_synergy(card_oracle_text, card_type_line, commander_keywords) -> float`

Return a 0.0 to 1.0 synergy score:

```
score = 0.0

# Tribal match: does the card share a creature type with the commander?
card_subtypes = extract_subtypes(card_type_line)
tribal_overlap = len(set(card_subtypes) & set(commander_keywords.tribal_types))
if tribal_overlap > 0:
    score += 0.3 * min(tribal_overlap, 2)  # max 0.6 from tribal

# Mechanic match: do the card's roles overlap the commander's themes?
card_roles = classify_card_role(card_oracle_text)
mechanic_overlap = len(set(card_roles) & set(commander_keywords.mechanic_keywords))
if mechanic_overlap > 0:
    score += 0.2 * min(mechanic_overlap, 3)  # max 0.6 from mechanics

# Cap at 1.0
return min(score, 1.0)
```

The scoring weights are intentionally simple and can be tuned later.
The key property is: a card matching both tribal AND mechanic themes
scores higher than one matching only one dimension.

#### Helper: `extract_subtypes(type_line) -> list[str]`

Same logic as tribal extraction from `extract_commander_keywords` --
split on em-dash, strip supertypes and card types, return creature
subtypes. Reused internally.

### Design decisions

- **Pure functions only** -- no DB, no framework, no side effects.
  This mirrors `src/analytics/` (F03) and `src/collection/matcher.py` (F10).
- **Regex-based** -- no NLP dependencies. The patterns are specific
  enough for MTG's templated oracle text.
- **Extensible** -- new keyword categories can be added by extending
  the pattern dicts without changing function signatures.
- **Frozen dataclass** for CommanderKeywords -- immutable, hashable.

## Acceptance Criteria

1. `src/decks/synergy.py` exists and exports `extract_commander_keywords`, `classify_card_role`, `score_synergy`.
2. `extract_commander_keywords("Whenever a creature you control dies, draw a card.", "Legendary Creature \u2014 Elf Shaman")` returns `CommanderKeywords(tribal_types=["Elf", "Shaman"], mechanic_keywords=["draw", "sacrifice"], referenced_types=["creature"])`.
3. `classify_card_role("Destroy target creature or planeswalker.")` returns `["removal"]`.
4. `classify_card_role("Draw two cards.")` returns `["draw"]`.
5. `classify_card_role("Search your library for a basic land card, put it onto the battlefield tapped, then shuffle.")` returns `["ramp"]`.
6. `classify_card_role("")` returns `["utility"]`.
7. `score_synergy("...", "Creature \u2014 Elf Druid", commander_kw)` where commander_kw has tribal_types=["Elf"] returns >= 0.3 (tribal match).
8. `score_synergy(removal_text, "Instant", commander_kw)` where commander_kw has mechanic_keywords=["removal"] returns >= 0.2 (mechanic match).
9. `score_synergy("", "Artifact", commander_kw)` returns 0.0 (no match).
10. All return values of `score_synergy` are in range [0.0, 1.0].
11. Module has zero imports from `src.database`, `src.api`, `src.providers`, or any framework.

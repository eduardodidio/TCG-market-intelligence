# F188-T04: Update Evaluator + Suggestions with Role Validation and Synergy Metrics

- **Wave:** 1
- **Type:** backend
- **Depends on:** T02
- **Status:** planned

## User Story

As a user evaluating my deck, I want to see a synergy score, role
coverage breakdown (how many removal, draw, ramp cards), and tribal
density, so that I can understand how well my deck supports its strategy
and where it has gaps.

## Objective

1. Update `evaluator.py` to compute and return synergy metrics in the
   `DeckEvaluation` result.
2. Update `suggestions.py` to validate `removal_min`, `card_draw_min`,
   `ramp_min` from archetype templates using `classify_card_role()` --
   making the dead code live.
3. Update `DeckEvaluation` dataclass and `DeckEvaluationResponse` schema
   to include the new fields.

### Evaluator changes (`evaluate_deck()`)

The `evaluate_deck()` function currently receives `cards: list[dict]`.
Each card dict has `name_en`, `mana_cost`, `type_line`, `quantity`, etc.

After T01, card dicts in the deck may include `oracle_text` (fetched from
the DB by the endpoint). The evaluate endpoint in `decks.py` already
enriches card dicts with data from CardRow -- it needs to also include
`oracle_text`. This is a small change to the endpoint, not the evaluator.

Add to `evaluate_deck()`:

```python
# F188: Synergy metrics
role_counts: dict[str, int] = defaultdict(int)
synergy_scores: list[float] = []
commander_types: list[str] = []
creature_tribal_match = 0
creature_total = 0

# Extract commander info (first card in commander format, or None)
commander_oracle = None
commander_type_line = None
if format_name and format_name.lower() in _SINGLETON_FORMATS and cards:
    # Convention: first card in list is the commander
    commander_oracle = cards[0].get("oracle_text")
    commander_type_line = cards[0].get("type_line")

if commander_oracle or commander_type_line:
    from src.decks.synergy import (
        extract_commander_keywords,
        classify_card_role,
        score_synergy,
        extract_subtypes,
    )

    cmd_kw = extract_commander_keywords(
        commander_oracle or "", commander_type_line or ""
    )
    commander_types = cmd_kw.tribal_types

    for card in cards:
        oracle = card.get("oracle_text", "")
        tl = card.get("type_line", "")
        qty = card.get("quantity", 1)

        # Role classification
        if oracle:
            roles = classify_card_role(oracle)
        else:
            roles = ["utility"]
        for role in roles:
            role_counts[role] += qty

        # Synergy scoring
        if oracle or tl:
            syn = score_synergy(oracle or "", tl or "", cmd_kw)
            for _ in range(qty):
                synergy_scores.append(syn)

        # Tribal density (creatures only)
        if tl and "Creature" in tl:
            creature_total += qty
            card_subtypes = extract_subtypes(tl)
            if set(card_subtypes) & set(commander_types):
                creature_tribal_match += qty
else:
    # Non-commander or no oracle data: classify roles only
    from src.decks.synergy import classify_card_role

    for card in cards:
        oracle = card.get("oracle_text", "")
        qty = card.get("quantity", 1)
        if oracle:
            roles = classify_card_role(oracle)
        else:
            roles = ["utility"]
        for role in roles:
            role_counts[role] += qty
```

Set the new fields on the returned `DeckEvaluation`:
```python
avg_synergy = (sum(synergy_scores) / len(synergy_scores)) if synergy_scores else None
tribal_pct = (creature_tribal_match / creature_total) if creature_total > 0 else None
```

```python
# N. Role coverage checks (F188)
if template and evaluation.role_coverage:
    role_map = evaluation.role_coverage  # dict[str, int]

    removal_count = role_map.get("removal", 0)
    removal_min = template.get("removal_min", 0)
    if removal_count < removal_min:
        warnings.append(
            f"Only {removal_count} removal cards found. "
            f"{arch_label.capitalize()} {fmt} decks recommend at least {removal_min}."

    draw_count = role_map.get("draw", 0)
    draw_min = template.get("card_draw_min", 0)

        warnings.append(
            f"Only {draw_count} card draw sources found. "
            f"Recommend at least {draw_min} for {arch_label} {fmt}."
        )

    ramp_count = role_map.get("ramp", 0)
    ramp_min = template.get("ramp_min", 0)
    if ramp_count < ramp_min:
        warnings.append(
            f"Only {ramp_count} ramp sources found. "
            f"Recommend at least {ramp_min} for {arch_label} {fmt}."
        )
```

## Acceptance Criteria

1. `DeckEvaluation` dataclass has `synergy_score: float | None`, `role_coverage: dict[str, int] | None`, `tribal_density: float | None`.
2. `evaluate_deck()` computes and returns synergy_score as the average synergy across all non-land cards (when oracle_text is available).
3. `evaluate_deck()` computes and returns role_coverage as a count dict (removal, draw, ramp, etc.).
4. `evaluate_deck()` computes and returns tribal_density as the fraction of creatures sharing a type with the commander.
5. `generate_suggestions()` produces warnings when removal/draw/ramp counts are below archetype template minimums.
6. `generate_suggestions()` produces an info suggestion when synergy_score < 0.15.
7. `DeckEvaluationResponse` includes `synergy_score`, `role_coverage`, `tribal_density`.
8. The evaluation endpoint passes `oracle_text` to the card dicts used by evaluate_deck.
9. Existing tests in `test_evaluator.py` and `test_suggestions.py` still pass.

### Test scenarios

**Evaluator synergy metrics:**
1. **Elf tribal deck -- tribal density** -- given 20 creatures of which 15 are Elves and commander is "Legendary Creature \u2014 Elf Druid", tribal_density should be 0.75.
2. **Average synergy score** -- given 10 cards with known synergy scores, verify synergy_score is the mean.
3. **Role coverage counts** -- given cards with known oracle texts covering removal, draw, ramp, verify role_coverage dict has correct counts.
4. **No oracle_text available** -- all cards have oracle_text=None, synergy_score should be None, role_coverage should still classify as "utility".
5. **Non-commander format** -- format is "standard", no commander, synergy_score is None, but role_coverage is still computed.
6. **Empty deck** -- cards=[], synergy_score=None, role_coverage={}, tribal_density=None.
7. **Quantity weighting** -- a card with quantity=4 contributes 4 times to role coverage and synergy average.

**Suggestions role validation:**
8. **Removal deficit warning** -- template says removal_min=8, deck has 3 removal cards, warning generated.
9. **Draw deficit warning** -- template says card_draw_min=10, deck has 5 draw cards, warning generated.
10. **Ramp deficit warning** -- template says ramp_min=8, deck has 4 ramp cards, warning generated.
11. **All minimums met** -- no role-based warnings generated.
12. **Low synergy score info** -- synergy_score=0.08, info suggestion about low synergy generated.
13. **Good synergy score** -- synergy_score=0.45, no synergy info suggestion.
14. **No template (unknown archetype)** -- no role warnings generated (template is None).
15. **No role_coverage** -- evaluation.role_coverage is None, no role warnings generated.
16. **Backward compatibility** -- existing suggestion tests still pass with evaluation.synergy_score=None and evaluation.role_coverage=None.

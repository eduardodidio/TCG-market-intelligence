# F188-T07: Add Synergy Badges per Card in DeckBuildWizard Review Step

- **Wave:** 2
- **Type:** frontend
- **Depends on:** T03, T05
- **Status:** planned

## User Story

As a user reviewing a generated deck in the DeckBuildWizard (step 4),
I want to see a visual synergy badge on each card (high/medium/low),
so that I can quickly identify which cards were chosen for synergy
versus which were fillers.

## Objective

Add synergy score badges to each card in the DeckBuildWizard review step.
Cards with high synergy get a green badge, medium gets yellow, low gets
gray. Also display the `avg_synergy_score` from the generate response
as a summary stat.

## Dev Notes

### DeckBuildWizard step 4 (review step)

The review step renders the generated cards list. Each card in the
`DeckGenerateResult.cards` array now includes `synergy_score` (from T03)
and the response includes `avg_synergy_score` (from T05).

#### Synergy Badge Component

Create a small inline component (can be defined within DeckBuildWizard
or extracted if reusable):

```tsx
function SynergyBadge({ score }: { score: number | null | undefined }) {
  if (score === null || score === undefined) return null;

  const pct = Math.round(score * 100);
  let colorClass: string;
  let label: string;

  if (score >= 0.6) {
    colorClass = "bg-green-100 text-green-800 dark:bg-green-900 dark:text-green-200";
    label = t("deck.synergy.high");
  } else if (score >= 0.3) {
    colorClass = "bg-yellow-100 text-yellow-800 dark:bg-yellow-900 dark:text-yellow-200";
    label = t("deck.synergy.medium");
  } else if (score > 0) {
    colorClass = "bg-gray-100 text-gray-600 dark:bg-gray-700 dark:text-gray-300";
    label = t("deck.synergy.low");
  } else {
    return null; // score is 0, no badge
  }

  return (
    <span className={`inline-flex items-center px-1.5 py-0.5 rounded text-xs font-medium ${colorClass}`}>
      {pct}% {label}
    </span>
  );
}
```

#### Summary stat

At the top of the review step, alongside existing stats (total cards,
land count, total value), add average synergy:

```tsx
{result.avg_synergy_score !== null && result.avg_synergy_score !== undefined && (
  <div className="text-sm">
    <span className="text-gray-500">{t("deck.synergy.average")}:</span>{" "}
    <span className="font-semibold">
      {(result.avg_synergy_score * 100).toFixed(0)}%
    </span>
  </div>
)}
```

#### Synergy weight control (step 3 -- options)

In the wizard's step 3 (deck options), add a synergy weight slider:

```tsx
<div className="space-y-2">
  <label className="text-sm font-medium">
    {t("deck.synergy.weightLabel")}
  </label>
  <input
    type="range"
    min="0"
    max="100"
    value={Math.round(synergyWeight * 100)}
    onChange={(e) => setSynergyWeight(parseInt(e.target.value) / 100)}
    className="w-full"
  />
  <div className="flex justify-between text-xs text-gray-500">
    <span>{t("deck.synergy.pureRarity")}</span>
    <span>{t("deck.synergy.pureSynergy")}</span>
  </div>
</div>
```

Wire `synergyWeight` into the generate request:

```tsx
const params: DeckGenerateParams = {
  ...existingParams,
  synergy_weight: synergyWeight,
};
```

## Acceptance Criteria

1. Each card in the review step (step 4) displays a SynergyBadge when synergy_score > 0.
2. Badge colors: green (>=0.6), yellow (>=0.3), gray (>0), hidden (0 or null).
3. Badge shows percentage value + translated label (High/Med/Low).
4. The review step summary shows avg_synergy_score as a percentage.
5. Step 3 has a synergy weight slider (0 to 100) that maps to synergy_weight (0.0 to 1.0).
6. The slider's value is passed to the generate API call.
7. All text uses i18n (`t()` calls) -- no hardcoded strings.
8. Dark mode styling for badges and slider.
9. `npm run build` passes.
10. Existing DeckBuildWizard tests still pass.

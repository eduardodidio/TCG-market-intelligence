# F188-T01: Add oracle_text Column to CardRow + Migration + Update Seeder

- **Wave:** 0
- **Type:** backend
- **Depends on:** none
- **Status:** planned

## User Story

As a deck builder engine, I need access to each card's oracle text (rules
text) so that I can analyze card abilities for synergy scoring.

## Objective

Add a nullable `oracle_text` TEXT column to the `cards` table, update the
Scryfall catalog pipeline to populate it during seed, and provide a CLI
command to backfill oracle_text for cards already in the database.

## Dev Notes

### Schema change

Add to `CardRow` in `src/database/models.py`:

```python
oracle_text: Mapped[str | None] = mapped_column(Text)
```

Place it after `image_uri` to maintain column ordering convention.

### Migration (ALTER TABLE pattern)

In `src/database/repository.py`, inside the `if "cards" in
insp.get_table_names():` block (around line 125-147), extend the
`new_card_columns` dict:

```python
new_card_columns = {
    "rarity": "VARCHAR(5)",
    "color_identity": "VARCHAR(20)",
    "mana_cost": "VARCHAR(50)",
    "type_line": "VARCHAR(200)",
    "image_uri": "VARCHAR(500)",
    "oracle_text": "TEXT",  # F188
}
```

This follows the existing migration pattern -- no Alembic needed.

### Scryfall parser update

In `src/catalog/scryfall.py`:

1. Add `oracle_text: str` field to `CatalogCard` dataclass (default `""`).

2. In `_parse_card()`, extract oracle_text from the Scryfall JSON:
   ```python
   oracle_text = raw.get("oracle_text", "")
   # For double-faced cards, concatenate front + back face text
   if not oracle_text:
       card_faces = raw.get("card_faces") or []
       texts = [f.get("oracle_text", "") for f in card_faces if f.get("oracle_text")]
       oracle_text = "\n".join(texts)
   ```

3. Include `oracle_text=oracle_text` in the CatalogCard constructor call.

### Seeder update

In `src/catalog/seeder.py`, `_process_card_batch()`:

1. Add `oracle_text=card.oracle_text` to the `dialect_insert(...).values(...)` call.

2. Add `oracle_text` to the `on_conflict_do_update` `set_` dict:
   ```python
   "oracle_text": func.coalesce(CardRow.oracle_text, excluded.oracle_text),
   ```

### CLI backfill command

Add `catalog update-oracle` to `src/cli/main.py`:
- Download fresh Scryfall bulk data (reuse existing `download_bulk_data`)
- Stream parse with `parse_bulk_cards`
- For each card, UPDATE `cards SET oracle_text = ? WHERE game = 'magic' AND set_code = ? AND collector_number = ?` where oracle_text IS NULL
- Batch in groups of 500, report progress
- This is a non-destructive backfill (only fills NULL oracle_text)

1. `CardRow` model has an `oracle_text: Mapped[str | None]` column of type `Text`.
2. Repository startup adds `oracle_text TEXT` column to existing `cards` tables via ALTER TABLE.
3. `CatalogCard` dataclass has an `oracle_text: str` field.
4. `_parse_card()` extracts `oracle_text` from Scryfall JSON, including double-faced card concatenation.
5. `_process_card_batch()` includes `oracle_text` in the INSERT and ON CONFLICT UPDATE.
6. `catalog update-oracle` CLI command backfills oracle_text for existing cards where it is NULL.
7. Running `catalog seed` on a fresh DB populates oracle_text for all cards.

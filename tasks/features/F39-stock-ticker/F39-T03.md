# F39-T03 — TickerItem + MarketTicker Components

**Wave:** 2
**Depends on:** T01 (CSS animation), T02 (useTickerData hook + types)
**Creates:** `frontend/src/components/TickerItem.tsx`, `frontend/src/components/MarketTicker.tsx`

## Objective

Build the two React components that render the stock-style ticker bar:
`TickerItem` (a single card entry) and `MarketTicker` (the scrolling
container).

## Deliverables

### 1. `frontend/src/components/TickerItem.tsx`

A small inline component rendering a single ticker entry.

**Props:**
```typescript
interface TickerItemProps {
  item: TickerItemData;
  onClick: (cardId: number) => void;
}
```

**Rendered structure:**
```
[SET] Card Name  $42.50  +12.3%
```

- **Set code** (optional): 3-letter code in `text-slate-500 text-xs
  font-mono`, shown only if `set_code` is not null.
- **Card name**: language-aware using `getCardName()` from `useCardName`
  utilities. Truncated with `truncate` class, `max-w-[120px]` inline.
- **Price**: formatted using currency symbol. `text-slate-200`.
- **Change %**: formatted to 1 decimal place with sign.
  - Positive (direction "up"): `text-emerald-400` with up arrow character
    (Unicode `\u25B2` or SVG).
  - Negative (direction "down"): `text-red-400` with down arrow character
    (Unicode `\u25BC` or SVG).
- **Separator**: a subtle `border-r border-slate-600` on the right side,
  with padding `px-4`.
- **Clickable**: entire item is a `<button>` with
  `onClick={() => onClick(item.card_id)}`. `cursor-pointer`,
  `hover:bg-slate-700/50` transition.
- **Accessibility**: `aria-label` describing the card, price, and change
  (e.g., "Sol Ring, 42 dollars 50 cents, up 12.3 percent").

### 2. `frontend/src/components/MarketTicker.tsx`

The scrolling container bar.

**Implementation:**

```typescript
export function MarketTicker() {
  const { items, loading } = useTickerData();
  const navigate = useNavigate();

  // Return null if loading or no items
  if (loading || items.length === 0) return null;

  // Calculate animation duration for consistent speed
  // ~80px per item, 60px/s scroll speed
  const duration = Math.max(20, items.length * 80 / 60);

  const handleClick = (cardId: number) => {
    navigate(`/cards/${cardId}`);
  };

  return (
    <div
      className="hidden md:block w-full bg-slate-800/80 border-b border-slate-700 overflow-hidden"
      role="marquee"
      aria-label={t("ticker.ariaLabel")}
      aria-live="off"
      data-testid="market-ticker"
    >
      <div
        className="animate-ticker flex whitespace-nowrap motion-reduce:animate-none motion-reduce:overflow-x-auto"
        style={{ '--ticker-duration': `${duration}s` } as React.CSSProperties}
      >
        {/* Render items twice for seamless loop */}
        {[...items, ...items].map((item, index) => (
          <TickerItem
            key={`${item.card_id}-${index}`}
            item={item}
            onClick={handleClick}
          />
        ))}
      </div>
    </div>
  );
}
```

**Key behaviors:**

1. **Hidden when empty/loading**: returns `null` to avoid layout shift.
   No skeleton or placeholder.
2. **Duplicated content**: items array is rendered twice (`[...items,
   ...items]`) so the `-50%` translateX creates seamless looping.
3. **Dynamic duration**: CSS variable `--ticker-duration` scales with item
   count for consistent reading speed.
4. **Responsive**: outer div has `hidden md:block` -- invisible on small
   screens.
5. **Reduced motion**: `motion-reduce:animate-none` stops scrolling.
   `motion-reduce:overflow-x-auto` allows manual horizontal scroll.
6. **Hover pause**: handled by CSS (T01) via `.animate-ticker:hover`.
7. **Semantic HTML**: `role="marquee"` with `aria-live="off"` (screen
   readers should not announce every scroll update).
8. **Background**: `bg-slate-800/80` with bottom border, consistent with
   the ExchangeRateBanner style but slightly distinct.

## Key Details

- The component must not throw or show errors if the trending API is
  unavailable. It simply returns null.
- Navigation uses `useNavigate` from react-router-dom, not `<Link>`,
  because items are rendered inside a scrolling animation and `<Link>`
  would add unnecessary DOM overhead for each duplicated item.
- `data-testid="market-ticker"` on the outer container for testing.
- Each `TickerItem` should have `data-testid="ticker-item"` for test
  queries.

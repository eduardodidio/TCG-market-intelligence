## Objective

Write comprehensive tests for all new code introduced in F39. All tests
use Vitest + React Testing Library, consistent with the existing frontend
test suite.

## Deliverables

### 1. `frontend/tests/components/TickerItem.test.tsx`

Test cases:
- Renders card name, set code, price, and change percentage
- Shows green color + up arrow for `direction: "up"`
- Shows red color + down arrow for `direction: "down"`
- Calls `onClick` with correct `card_id` when clicked
- Truncates long card names without overflow
- Omits set code badge when `set_code` is null
- Has correct `aria-label` with interpolated values
- Has `data-testid="ticker-item"` attribute
- Formats price with correct currency symbol
- Formats change percentage to 1 decimal place with sign

### 2. `frontend/tests/components/MarketTicker.test.tsx`

Test cases:
- Returns null when `loading` is true (no DOM rendered)
- Returns null when `items` is empty array
- Renders ticker bar when items are provided
- Renders items twice (duplicated for seamless loop)
- Has `role="marquee"` on container
- Has `aria-live="off"` on container
- Has `data-testid="market-ticker"` on container
- Has `hidden md:block` classes for responsive behavior
- Sets `--ticker-duration` CSS variable based on item count
- Calls `navigate` when a TickerItem is clicked
- Duplicate items (second half) have `tabIndex={-1}`
- Has `motion-reduce:animate-none` class for reduced motion

Mock `useTickerData` hook to control test data.
Mock `useNavigate` from react-router-dom.

### 3. `frontend/tests/hooks/useTickerData.test.ts`

Test cases:
- Returns `loading: true` and empty items on initial render
- Returns items after successful fetch
- Interleaves gainers and losers correctly
- Returns empty items on fetch error (no throw)
- Re-fetches when currency changes
- Sets up 5-minute interval for auto-refresh
- Cleans up interval and AbortController on unmount
- Keeps previous items during interval refresh (no loading flash)
- Handles partial failures (one endpoint fails, other succeeds) --
  returns empty array

Mock `fetchTickerData` and `useCurrency`.
Use `vi.useFakeTimers()` for interval testing.

### 4. Integration verification

- Verify MarketTicker appears in Layout between ExchangeRateBanner and
  main content (can be tested by rendering Layout with mocked router and
  checking DOM order).

## Key Details

- Follow existing test patterns in the project (see
  `frontend/tests/components/` for examples).

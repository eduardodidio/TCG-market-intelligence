# F39-T01 — CSS Keyframes + Tailwind Animation Utilities

**Wave:** 1 (parallel with T02)
**Depends on:** nothing
**Modifies:** `frontend/src/index.css`

## Objective

Define the CSS `@keyframes` animation and utility classes needed for the
continuous horizontal ticker scroll effect, including reduced-motion
support.

## Deliverables

### 1. Add keyframes to `frontend/src/index.css`

Add within the existing Tailwind layers (after `@tailwind utilities`):

```css
@layer utilities {
  @keyframes ticker-scroll {
    0% {
      transform: translateX(0);
    }
    100% {
      transform: translateX(-50%);
    }
  }

  .animate-ticker {
    animation: ticker-scroll var(--ticker-duration, 30s) linear infinite;
  }

  .animate-ticker:hover {
    animation-play-state: paused;
  }
}
```

### 2. Reduced-motion support

Add within the same `@layer utilities` block:

```css
@media (prefers-reduced-motion: reduce) {
  .animate-ticker {
    animation: none;
  }
}
```

When animation is disabled, the ticker container should fall back to a
horizontally scrollable overflow (`overflow-x-auto`) which is handled in
the component (T03), not in CSS.

## Key Details

- The `-50%` translation works because the content is rendered twice
  (duplicated) inside the scrolling container. When the first copy exits
  left, the second copy is exactly in its starting position, creating a
  seamless loop.
- `--ticker-duration` CSS custom property is set inline by the component
  (T03) based on item count to maintain consistent scroll speed.
- `linear` timing ensures constant speed (no ease-in/out).
- `infinite` ensures continuous loop.
- Hover pauses via `animation-play-state: paused`.

## Acceptance Criteria

- [ ] `@keyframes ticker-scroll` defined with 0%->100% translateX(0 -> -50%)
- [ ] `.animate-ticker` class applies the animation with CSS variable duration
- [ ] Hover pauses animation
- [ ] `prefers-reduced-motion: reduce` disables animation entirely
- [ ] No new npm dependencies
- [ ] CSS is added within Tailwind's `@layer utilities` for proper ordering

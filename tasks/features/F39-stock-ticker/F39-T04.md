# F39-T04 — Layout Integration + i18n + Responsive/A11y

**Wave:** 3
**Depends on:** T03 (MarketTicker component)
**Modifies:** `frontend/src/components/Layout.tsx`, `frontend/src/i18n/locales/en.json`, `frontend/src/i18n/locales/pt-BR.json`

## Objective

Wire the MarketTicker into the application layout and add all
internationalization keys for the ticker feature.

## Deliverables

### 1. Integrate MarketTicker into Layout.tsx

Add `<MarketTicker />` in the main content column, directly below
`<ExchangeRateBanner />` and above `<main>`.

```tsx
import { MarketTicker } from "./MarketTicker";

// Inside the JSX, in the "Main content area" div:
<ExchangeRateBanner />
<MarketTicker />
<main className="flex-1 overflow-y-auto p-6" data-testid="main-content">
  <Outlet />
</main>
```

The ticker sits in the document flow (not `position: fixed` or `sticky`).
It occupies a thin horizontal band (~36-40px height). On screens below
`md`, it renders as `null` (via its own `hidden md:block`), so no layout
impact on mobile.

### 2. Add i18n keys

**`frontend/src/i18n/locales/en.json`** -- add a `"ticker"` section:

```json
{
  "ticker": {
    "ariaLabel": "Market price ticker showing trending cards",
    "itemAriaLabel": "{{name}}, {{price}}, {{direction}} {{change}}%",
    "up": "up",
    "down": "down"
  }
}
```

**`frontend/src/i18n/locales/pt-BR.json`** -- add matching section:

```json
{
  "ticker": {
    "ariaLabel": "Ticker de precos de mercado com cards em alta e baixa",
    "itemAriaLabel": "{{name}}, {{price}}, {{direction}} {{change}}%",
    "up": "alta",
    "down": "baixa"
  }
}
```

### 3. Verify responsive behavior

Confirm the following behaviors (no code changes needed if T03 was
implemented correctly, but verify):

- **Below md (< 768px)**: ticker is `display: none`. No DOM space taken.
- **md and above**: ticker is visible as a thin bar.
- **Reduced motion**: animation stops. Content is static but scrollable
  via touch/mouse drag (overflow-x-auto).

### 4. Verify accessibility

- Container has `role="marquee"` and `aria-live="off"`.
- Each TickerItem has an `aria-label` using the i18n `itemAriaLabel`
  template with interpolated card name, price, direction, and change.
- Focus is possible on each item (they are `<button>` elements).
- Tab order makes sense (ticker items are focusable but not disruptive).
  Consider adding `tabIndex={-1}` to duplicate items (the second copy
  rendered for seamless looping) to avoid double-tabbing through the same
  content.

## Key Details

- The MarketTicker import should be at the top of Layout.tsx alongside
  other component imports.
- The ticker must not interfere with the existing sidebar or mobile
  hamburger menu behavior.
- The i18n `itemAriaLabel` uses react-i18next interpolation syntax
  (`{{variable}}`).

## Acceptance Criteria

- [ ] `<MarketTicker />` rendered in Layout.tsx below ExchangeRateBanner
- [ ] Ticker does not affect layout on mobile (hidden)
- [ ] i18n keys added for EN and PT-BR (4 keys each)
- [ ] ARIA labels use translated strings with interpolated values
- [ ] Duplicate items (second loop copy) have `tabIndex={-1}` to avoid
      redundant tab stops
- [ ] No visual regression on existing layout elements

# F32-T05 -- Refactor useCollectionRefresh to Use SSE

**Wave:** 2
**Depends on:** T04 (useScanStream hook exists)
**Estimated effort:** small

## Objective

Replace the `setInterval` polling loop in `useCollectionRefresh` with the
new `useScanStream` hook. The public API of the hook remains identical so
that consuming components (`MyCollection.tsx`) need zero changes.

## Changes

### File: `frontend/src/hooks/useCollectionRefresh.ts`

#### Current behavior (polling)

1. `startRefresh()` triggers `POST /scans` to create scan
2. `setInterval` polls `GET /scans/{id}` every 3 seconds
3. Updates `progress` state on each poll response
4. Clears interval on completion/failure

#### New behavior (SSE with fallback)

1. `startRefresh()` still triggers `POST /scans` to create scan
2. Instead of `setInterval`, pass `scanId` + JWT token to `useScanStream`
3. `useScanStream.onEvent` updates `progress` state on every event
4. `useScanStream.onComplete` sets `isDone`, calls `onComplete` callback
5. `useScanStream.onError` sets error state
6. `cancelRefresh()` calls `useScanStream.disconnect()` instead of
   `clearInterval`

#### Public API (unchanged)

```typescript
export interface UseCollectionRefreshReturn {
  isRefreshing: boolean;
  progress: RefreshProgress | null;
  error: string | null;
  isDone: boolean;
  startRefresh: () => Promise<void>;
  cancelRefresh: () => void;
}
```

#### New addition to return value

Add an optional `lastEvent` field for consumers that want per-card details:

```typescript
export interface UseCollectionRefreshReturn {
  // ... existing fields ...
  lastScannedCard: {
    name: string;
    priceFound: boolean;
    price?: number;
  } | null;
}
```

#### JWT token

Get the token from `useAuth()` context (already available in the app).
Pass it to `useScanStream`.

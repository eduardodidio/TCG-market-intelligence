# F32-T04 -- Frontend: useScanStream Hook (EventSource + Fallback)

**Wave:** 2
**Depends on:** T03 (SSE endpoint exists)
**Estimated effort:** medium

## Objective

Create a React hook that connects to the SSE endpoint and provides a stream
of scan events. Falls back to polling if SSE is unavailable.

## Deliverables

### File: `frontend/src/hooks/useScanStream.ts`

```typescript
export interface ScanStreamEvent {
  event_type: "scan_started" | "card_scanned" | "scan_complete";
  scan_id: number;
  timestamp: string;
  external_id?: string;
  card_name?: string;
  price_found?: boolean;
  price?: number;
  currency?: string;
  error?: string;
  cards_processed: number;
  cards_total: number;
  cards_failed: number;
  observations_saved: number;
}

export interface UseScanStreamOptions {
  scanId: number | null;
  token: string;               // JWT for auth
  onEvent?: (event: ScanStreamEvent) => void;
  onComplete?: (event: ScanStreamEvent) => void;
  onError?: (error: string) => void;
  fallbackToPolling?: boolean;  // default: true
}

export interface UseScanStreamReturn {
  isConnected: boolean;
  lastEvent: ScanStreamEvent | null;
  progress: { processed: number; total: number } | null;
  error: string | null;
  disconnect: () => void;
}
```

#### Implementation

1. When `scanId` is non-null, create an `EventSource` pointing to
   `${API_BASE_URL}/api/v1/scans/${scanId}/stream?token=${token}`.

2. Listen for `scan_started`, `card_scanned`, `scan_complete` event types.
   Parse the `data` field as JSON into `ScanStreamEvent`.

3. Call `onEvent` for every event. Update `lastEvent` and `progress` state.

4. On `scan_complete`, call `onComplete` and close the EventSource.

5. On EventSource `onerror`:
   - If `fallbackToPolling` is true, close EventSource and fall back to
     the existing 3-second polling logic (reuse `getScanStatusAuth`).
   - If false, set `error` state and stop.

6. On `disconnect()` call or component unmount, close the EventSource.

7. Cleanup: close EventSource in `useEffect` cleanup function.

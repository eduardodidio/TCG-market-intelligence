# F32-T03 -- SSE Endpoint: `GET /scans/{scan_id}/stream`

**Wave:** 1
**Depends on:** T01 (event bus exists)
**Estimated effort:** medium

## Objective

Add an SSE (Server-Sent Events) endpoint to the scans router that streams
scan progress events to the browser in real time.

## Changes

### File: `src/api/routers/scans.py`

Add a new endpoint:

```python
@router.get("/{scan_id}/stream")
async def stream_scan(scan_id: int, token: str | None = None):
    ...
```

#### Authentication

`EventSource` does not support custom headers. Auth options:

- Accept JWT via `?token=<jwt>` query parameter
- Validate the token using the same logic as `require_auth_or_api_key`
- Return 401 JSON response if token is invalid or missing
- Also accept API key via `?api_key=<key>` query parameter

Create a helper `validate_stream_token(token, api_key)` that reuses the
existing auth validation logic from `src/api/deps.py`.

#### SSE Implementation

1. Validate the scan exists (`repo.get_scan_run(scan_id)`). Return 404 if
   not found.

2. If scan is already `completed` or `failed`, return the final status as a
   single SSE event and close.

3. Subscribe to the event bus for `scan_id`.

4. Return a `StreamingResponse` with `media_type="text/event-stream"` and
   headers: `Cache-Control: no-cache`, `Connection: keep-alive`,
   `X-Accel-Buffering: no` (for nginx).

5. The generator function:
   - Yields SSE-formatted events: `event: <type>\ndata: <json>\n\n`
   - On `scan_complete` event, yield it and break
   - On client disconnect (detected via `asyncio.CancelledError` or
     checking `request.is_disconnected()`), clean up
   - Timeout: if no event arrives in 30 seconds, send a `:keepalive\n\n`
     comment to prevent proxy timeouts
   - In the `finally` block, unsubscribe from the event bus

6. Late joiners: if a client connects after the scan has already started,
   they receive events from that point forward (not replayed). The first
   event they get will have the current `cards_processed` count so they
   can set up the progress bar correctly.

### File: `src/api/schemas/scans.py`

No schema changes needed -- SSE events are raw JSON, not Pydantic-validated
responses.

## Tests

- Test SSE endpoint returns final event for completed scan
- Test SSE endpoint streams events from event bus (mock bus, publish 3

- Test keepalive comment is sent on timeout

reading.

# F32-T07 -- Frontend: Enhanced Progress Bar (Card Name, ETA, Ratio)

**Wave:** 3
**Depends on:** T05 (useCollectionRefresh v2 with SSE events)
**Estimated effort:** small

## Objective

Replace the basic "Refreshing... 42/120" progress bar with a richer display
that shows the currently-scanned card name, a price-found success ratio,
and an estimated time remaining.

## Changes

### File: `frontend/src/components/ScanProgressBar.tsx` (new component)

Props:
```typescript
interface ScanProgressBarProps {
  processed: number;
  total: number;
  currentCardName?: string;
  priceFoundCount: number;
  startTime: number;            // Date.now() when scan started
  isRefreshing: boolean;
  isDone: boolean;
  error: string | null;
}
```

Layout (within the existing collection header area):

```
[==============================          ] 42/120 (35%)
Scanning: "Lightning Bolt"    Prices found: 38/42    ETA: ~1m 20s
```

1. **Progress bar**: Tailwind-based, same style as current. Width =
   `(processed / total) * 100%`. Color: cyan-400 (matches theme).

2. **Current card name**: show `currentCardName` below the progress bar.
   Truncate with ellipsis if too long. Fade transition between names.

3. **Price-found ratio**: `priceFoundCount / processed` shown as
   "Prices found: 38/42". Small success indicator.

4. **ETA calculation**: `((Date.now() - startTime) / processed) *
   (total - processed)`. Format as "~Xm Ys" or "< 1m". Hide when
   processed < 3 (not enough data for estimate).

5. **Completion state**: when `isDone`, show a green checkmark and summary
   "Scan complete: 120 cards, 98 prices updated". Auto-dismiss after 3s.

6. **Error state**: when `error`, show red alert with error message.

### File: `frontend/src/pages/MyCollection.tsx`

Replace the inline progress rendering with `<ScanProgressBar />`.
Pass `lastScannedCard` data from `useCollectionRefresh` to the component.

Track `priceFoundCount` and `startTime` in MyCollection state:
- Increment `priceFoundCount` on each `card_scanned` event with
  `price_found: true`
- Set `startTime` when `startRefresh()` is called

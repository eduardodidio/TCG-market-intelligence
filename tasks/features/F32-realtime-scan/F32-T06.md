# F32-T06 -- Frontend: Live Card Updates + Highlight Animation

**Wave:** 3
**Depends on:** T05 (useCollectionRefresh v2 with SSE events)
**Estimated effort:** medium

## Objective

As scan events arrive, update individual card prices in the collection grid
without waiting for a full re-fetch. Cards that just got scanned receive a
brief visual highlight.

## Changes

### File: `frontend/src/pages/MyCollection.tsx`

1. **Live price updates**: subscribe to `lastScannedCard` (or a new
   `onCardScanned` callback from `useCollectionRefresh`). When a
   `card_scanned` event arrives with `price_found: true`:
   - Find the matching card in the local `cards` state array by
     `external_id` (need to match via source card data or a new field)
   - Update its `latest_price` in local state (optimistic update)
   - This avoids a full collection re-fetch until the scan completes

2. **Highlight animation**: track a set of recently-scanned card IDs in
   state. When a card is scanned:
   - Add its ID to `recentlyScanned` set with a timestamp
   - After 2 seconds, remove it from the set
   - Use `useEffect` with cleanup timeouts

3. **CollectionCardTile highlight**: if the card's ID is in the
   `recentlyScanned` set, apply a CSS class:
   - Price found: green border glow (`ring-2 ring-emerald-400/60`) with
     fade-out transition
   - No price / error: amber border glow (`ring-2 ring-amber-400/40`)

4. **Scroll to scanned card** (optional, nice-to-have): if the scanned
   card is off-screen, do NOT auto-scroll (disruptive). Instead, show a
   small floating indicator "Scanning card 42/120: {name}" at the top of
   the grid area.

### File: `frontend/src/components/CollectionCardTile.tsx` (or inline in MyCollection)

Add a `highlighted` prop (or `highlightColor`) that applies the ring class.
Use Tailwind `transition-all duration-500` for smooth fade.

## Mapping external_id to collection cards

The `CollectionCard` type from the API includes `external_id` (or we can
derive it from the source card link). Check the API response shape:
- If `external_id` is not in `CollectionCard`, add it to the API response
  in this task (small backend change to `collection.py` router)
- Or match by card name (less reliable)

Preferred: add `external_id` to `CollectionCard` API response if not
already present.

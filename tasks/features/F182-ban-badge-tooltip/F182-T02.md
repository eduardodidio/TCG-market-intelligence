## User Story

As a user viewing my collection, I want the ban data for each card to
include the list of formats where it is banned or restricted, so that the
BanBadge component can display this information in a tooltip.

## Dev Notes

### Current implementation (MyCollection.tsx, lines 525-540)

```typescript
const bannedCardMap = useMemo(() => {
  const map = new Map<number, { status: "banned" | "restricted"; recentlyChanged: boolean }>();
  for (const bc of bannedCards) {
    const existing = map.get(bc.card_id);
    if (!existing || (bc.status === "banned" && existing.status !== "banned")) {
      map.set(bc.card_id, {
        status: bc.status as "banned" | "restricted",
        recentlyChanged: bc.recently_changed || (existing?.recentlyChanged ?? false),
      });
    } else if (bc.recently_changed && existing) {
      map.set(bc.card_id, { ...existing, recentlyChanged: true });
    }
  }
  return map;
}, [bannedCards]);
```

### Required changes

1. **Extend the map value type** to include a `formats` array:

```typescript
const map = new Map<number, {
  status: "banned" | "restricted";
  recentlyChanged: boolean;
  formats: Array<{ format: string; status: string }>;
}>();
```

2. **Accumulate formats** during the loop. Each `BannedCollectionCard` has
   `format` and `status` fields. Push `{ format: bc.format, status: bc.status }`
   into the array for every row. The worst-status logic stays unchanged.

```typescript
for (const bc of bannedCards) {
  const existing = map.get(bc.card_id);
  const formatEntry = { format: bc.format, status: bc.status };

  if (!existing) {
    map.set(bc.card_id, {
      status: bc.status as "banned" | "restricted",
      recentlyChanged: bc.recently_changed,
      formats: [formatEntry],
    });
  } else {
    existing.formats.push(formatEntry);
    if (bc.status === "banned" && existing.status !== "banned") {
      existing.status = "banned";
    }
    if (bc.recently_changed) {
      existing.recentlyChanged = true;
    }
  }
}
```

3. **Pass formats to CollectionCardTile.** The `CollectionCardTile`
   function (line 71) already receives `banStatus` and `banRecentlyChanged`.
   Add a `banFormats` prop:

```typescript
// In CollectionCardTile props
banFormats?: Array<{ format: string; status: string }>;
```

4. **Forward to BanBadge** (line 110):

```tsx
<BanBadge
  status={banStatus}
  recentlyChanged={banRecentlyChanged}
  formats={banFormats}
/>
```

5. **At the call site** (around line 1134), extract and pass `banInfo?.formats`:

```tsx
banFormats={banInfo?.formats}
```

# F158-T01: Card detail cross-links to Market/Trending

**Feature:** F158 — Journey P3 Polish
**Wave:** 0
**Status:** planned

## User Story

As a user viewing a card's detail page, I want links to see this card
on Market Movers and Trending pages, so I can quickly check its market
position without navigating manually.

## Dev Notes

### Current State

`CardDetail.tsx` has no links to `/market` or `/market/trending`.
These pages exist at routes `/market/movers` and `/market/trending`.

### Implementation

Add a small "Market Links" section below the price info in CardDetail:

```tsx
<div className="flex gap-3 mt-3">
  <Link to="/market/movers" className="text-xs text-indigo-400 hover:text-indigo-300">
    {t("cardDetail.seeOnMarket")}
  </Link>
  <Link to="/market/trending" className="text-xs text-indigo-400 hover:text-indigo-300">
    {t("cardDetail.seeTrending")}
  </Link>
</div>
```

### i18n keys
- `cardDetail.seeOnMarket`: "Market Movers" / "Movimentacao de Mercado"
- `cardDetail.seeTrending`: "Price Trends" / "Tendencias de Preco"

### Files
- `frontend/src/pages/CardDetail.tsx` — add market links
- `frontend/src/i18n/locales/en.json` — new keys
- `frontend/src/i18n/locales/pt-BR.json` — new keys

## Testing

- Unit: market links render on card detail page
- Unit: links point to correct routes

## Acceptance Criteria

- [ ] "Market Movers" link visible on CardDetail
- [ ] "Price Trends" link visible on CardDetail

# F90-T03: Trending Collection-Only

**Status:** planned
**Wave:** 1

## User Story

As a collector, I want the trending gainers and losers to show only
cards in my collection, so that I see price movements relevant to cards
I actually own.

## Acceptance Criteria

1. Authenticated users see trending data scoped to their collection only.
2. Unauthenticated users continue to see trending data for all cards
   (existing behavior preserved).
3. The API endpoints accept an optional `collection_only=true` query
   parameter. When present with a valid auth token, trending is filtered
   to the user's collection cards.
4. The TrendingService cache keys include the user scope so that
   collection-scoped and global results do not collide.
5. Dashboard TrendingSection and Trending page both default to
   collection-only when the user is authenticated.
6. Performance: the collection-scoped query should not be significantly
   slower than the global query (use a single JOIN, not N+1).

## Dev Notes

### Backend Changes

**Repository** (`src/database/repository.py`):
- Add `get_trending_price_data_for_user(user_id: int, period_days: int)`
  method that JOINs `SourceCardRow` + `PriceObservationRow` with
  `UserCollectionRow` on `card_id`. Same return type as
  `get_trending_price_data`: `dict[int, list[tuple[date, Decimal]]]`.
- The JOIN: `UserCollectionRow.card_id == SourceCardRow.card_id` plus
  `UserCollectionRow.user_id == user_id`.

**TrendingService** (`src/services/trending.py`):
- Add `user_id: int | None = None` parameter to `get_trending()`.
- When `user_id` is set, call `get_trending_price_data_for_user` instead
  of `get_trending_price_data`.
- Cache key becomes `f"{direction}:{period_days}:user_{user_id}"` for
  scoped queries and `f"{direction}:{period_days}:all"` for global.

**API** (`src/api/routers/market.py`):
- Add `collection_only: bool = False` query param to
  `/market/trending/gainers` and `/market/trending/losers`.
- When `collection_only=True` and user is authenticated, pass `user_id`
  to `TrendingService.get_trending()`.
- When `collection_only=True` but no auth token, ignore the flag (return
  global data).

### Frontend Changes

**Trending page** (`frontend/src/pages/Trending.tsx`):
- Pass `collection_only=true` query param when user is authenticated.
- Add a toggle/checkbox "My Collection Only" (default: on when authed).

**TrendingSection** (`frontend/src/components/TrendingSection.tsx`):
- Same: pass `collection_only=true` when authenticated.

**API calls** -- update `fetchTrending` (or wherever the API is called)
to accept and forward the `collection_only` param.

# F90-T02: Beta-Test Tab Nav Grouping

**Status:** planned
**Wave:** 0

## User Story

As a user, I want experimental features grouped under a collapsible
"Beta Test" section in the sidebar, so that the navigation is cleaner
and I can easily find the core pages (Dashboard, Collection, Explore).

## Acceptance Criteria

1. The sidebar groups the following items under a collapsible "Beta Test"
   disclosure section: Market, Trending, Ban List, Ban History, My Decks,
   Top Decks, Marketplace.
2. The "Beta Test" section is collapsed by default and expands with a
   click on the header (disclosure arrow rotates).
3. Top-level items remain flat: Dashboard, My Collection, Explore Cards,
   Settings, Admin.
4. The active route highlight still works correctly for items inside the
   Beta Test group.
5. Collapse state persists via localStorage across page refreshes.
6. Mobile sidebar behavior is unchanged (items still visible when
   expanded).
7. i18n key `nav.betaTest` added for EN and PT-BR.

## Dev Notes

### Files to Modify

- `frontend/src/components/Layout.tsx` -- restructure `NAV_ITEMS` into
  two groups (top-level and beta). Add disclosure UI for beta group.
- `frontend/src/i18n/locales/en.json` -- add `nav.betaTest` key
- `frontend/src/i18n/locales/pt-BR.json` -- add `nav.betaTest` key

### Implementation Approach

1. Split `NAV_ITEMS` into `PRIMARY_NAV_ITEMS` and `BETA_NAV_ITEMS`:
   ```
   PRIMARY: /, /collection, /cards, /settings, /admin
   BETA: /market, /market/trending, /banlist, /banlist/history,
         /decks, /decks/ranking, /marketplace
   ```

2. Add a `betaOpen` state with localStorage persistence
   (`tcg_beta_nav_open`).

3. Render primary items as before. Below them, render a disclosure
   header with a chevron icon and "Beta Test" label. When open, render
   beta items indented slightly (pl-6 instead of pl-3).

4. The chevron should rotate 90 degrees when open (transition-transform).

### Key Decision

Keep the grouping purely presentational. No route changes, no new
components beyond what fits in Layout.tsx. If the disclosure logic grows
complex, extract a `NavGroup` component in the same file.

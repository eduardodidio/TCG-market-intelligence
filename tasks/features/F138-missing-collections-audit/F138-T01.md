# F138-T01: `catalog missing` CLI command

**Status:** planned
**Wave:** 0
**Depends on:** none

## User Story

As a user, I want to run `catalog missing` to see which sets in my catalog
don't have Liga prices yet, so I can generate a scan batch to fill gaps.

## Dev Notes

### Implementation

Add a new Click command under the `catalog` group in `src/cli/main.py`:

```python
@catalog.command("missing")

```

### Query Logic

1. Get all catalog sets: `SELECT set_code, COUNT(*) FROM cards GROUP BY set_code`
2. Get priced sets: `SELECT DISTINCT c.set_code, COUNT(DISTINCT c.id) FROM cards c JOIN price_observations po ON po.external_id = 'liga_' || CAST(c.id AS TEXT) GROUP BY c.set_code`
3. Get collection sets (if user_id): `SELECT DISTINCT c.set_code FROM user_collection uc JOIN cards c ON c.id = uc.card_id`
4. Compute: unscanned = catalog - priced, partial = priced where count < 50% total

### Output Modes

**table** (default):
```
=== COLLECTION GAPS ===
  sld: 2726 cards, 0 priced (0%)

=== UNSCANNED (100+ cards) ===
  plst: 5579 cards
  ...

=== PARTIALLY SCANNED ===
  ltr: 107/858 (12%) *COLL*

SUMMARY: 129/994 sets scanned
```

**script**:
```bash
# Generated by: catalog missing --format script
# Sets not yet scanned (50+ cards)
scan_set "plst"   # 5579 cards
scan_set "sld"    # 2726 cards *COLL*
...
```

## User Story

As an operator, I want a CLI command to sweep my entire collection through
LigaMagic with configurable pacing and resume support so that I can do the
initial price population without overwhelming the site.

### Key behaviors

1. **Get eligible cards**: `repo.get_cards_for_liga_scan(filter, max_age_days=max_age_days)`
2. **Batch processing**:
   - Split cards into batches of `batch_size`
   - Process each batch sequentially (concurrency=1 within batch)
   - Between batches: pause `batch_pause` seconds
   - Log progress: `"Batch 3/18 complete: 15/20 prices found, pausing 60s"`
3. **Resume support**: `max_age_days` naturally skips cards with recent Liga prices
4. **Per-card flow**:
   - `provider.search_card(name_en or name_pt)` → extract price
   - Save as `source="liga"`, `external_id="liga_{card_id}"`
   - Delay `delay` seconds before next card
5. **Single browser**: open `LigaMagicProvider` once, close at end
6. **Progress output**: click.echo progress for each batch
7. **Graceful interruption**: catch KeyboardInterrupt, report partial results

### Estimated time for 349 cards
- 349 cards x 5s delay + ~5.5s fetch = ~10.5s/card = ~61 minutes
- With batch_pause: 18 batches x 60s pause = +18 min = ~79 minutes total
- Acceptable for initial sweep (run overnight)

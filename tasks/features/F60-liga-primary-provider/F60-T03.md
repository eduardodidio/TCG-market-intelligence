**Status:** planned
**Wave:** 0

## User Story

As an operator, I want to clear old MYP price history so that charts start
fresh with Liga data, without losing manual or Liga prices.

## Dev Notes

### New CLI command: `tcg db-clear-prices`

```python
@cli.command("db-clear-prices")
@click.option("--db", default="sqlite:///tcg_market.db")
@click.option("--source", required=True, help="Source to clear (e.g. jsonld_snapshot, myp)")
@click.option("--confirm", is_flag=True, help="Required to actually delete")
@click.option("--skip-backup", is_flag=True, help="Skip pre-delete backup")
def db_clear_prices(db, source, confirm, skip_backup):
```

### Safety rules
- `--confirm` flag required — without it, runs as dry-run showing count
- Automatic backup via `src/database/backup.py` before deletion (unless `--skip-backup`)
- NEVER delete `source="liga"` or `source="manual"` prices (refuse with error)
- Allowed sources: `jsonld_snapshot`, `myp`, or any other non-protected source
- Does NOT touch `scan_runs` table (preserve audit trail)

### Implementation: `clear_prices_by_source()`

New function in `src/database/cleanup.py`:

```python
def clear_prices_by_source(
    db_url: str,
    source: str,
    *,
    dry_run: bool = True,
    skip_backup: bool = False,
) -> ClearPricesResult:
```

- Count `price_observations WHERE source = :source`
- If `dry_run`: return count only
- If not: backup → DELETE → VACUUM → return count
- Returns `ClearPricesResult(deleted: int, dry_run: bool, backup_path: str | None)`

### Protected sources
```python
PROTECTED_SOURCES = {"liga", "manual"}
```
If user tries to clear a protected source, raise `ValueError` with clear message.

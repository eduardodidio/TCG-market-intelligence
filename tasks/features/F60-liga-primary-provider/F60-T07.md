## User Story

As an admin, I want a dashboard showing which cards in my collection lack
Liga prices so that I can track the migration progress and trigger scans
for missing cards.

## Dev Notes

### 1. Backend: `GET /collection/liga-status`

New endpoint in `src/api/routers/collection.py`:

```python
@router.get("/liga-status", response_model=ApiResponse[LigaStatusResponse])
def get_liga_status(
    repo: Repository = Depends(get_db),
    user_id: str = Depends(require_auth_or_api_key),
):
```

Response schema:
```python
class LigaStatusResponse(BaseModel):
    total_cards: int           # total unique entries with card_id
    liga_priced: int           # entries with a liga price observation
    liga_stale: int            # liga price older than 7 days
    liga_missing: int          # no liga price at all
    unlinked: int              # entries with card_id IS NULL
    coverage_pct: float        # liga_priced / total_cards * 100
    last_liga_scan: str | None # ISO timestamp of most recent liga scan_run
```

### 3. New repo method: `get_liga_coverage_stats()`

```python
def get_liga_coverage_stats(self, user_id: str, stale_days: int = 7) -> dict:
    """Count cards with/without/stale Liga prices."""
```

SQL approach:
- Subquery: latest `liga` observation per card_id
- LEFT JOIN with user_collection
- Categorize: no observation → missing, observation > N days → stale, else → priced

### 4. Frontend: `/admin/link-status` page

New page `frontend/src/pages/AdminLigaStatus.tsx`:

- **Summary cards** (4 KPIs):
  - Total cards | Liga priced | Missing | Stale
  - Coverage progress bar (% with Liga price)
- **Missing cards table**: paginated list from `/collection/liga-missing`
  - Columns: Name, Set, Collector#, Last MYP Price, Action
  - Action: "Scan" button (triggers single-card Liga refresh via existing endpoint)
- **Bulk action**: "Scan All Missing" button → triggers Liga scan via `/scans` with provider=liga
- **Auto-refresh**: poll `/collection/liga-status` every 30s when scan running

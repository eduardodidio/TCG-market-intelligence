# F60-T01: Refactor scan orchestrator for generic provider

**Status:** planned
**Wave:** 0
**Parallel with:** T02, T03

## User Story

As a developer, I want the scan orchestrator to accept any CardSourceProvider
so that Liga and MYP scans share the same orchestration logic (scan_runs,
SSE events, retry, progress tracking).

## Dev Notes

### Current state
- `src/collectors/scan.py` hardcodes `MypCardsProvider` import and `provider.fetch_current_price(external_id, slug)`
- MYP-specific: expects `external_id` + `slug` from `get_cards_for_scan()`
- Uses `NotFoundError`, `RateLimitError` from `src/providers/myp/exceptions.py`

### Changes needed

1. **Abstract the provider call** in `run_scan()`:
   - Add `provider_name: str = "myp"` parameter (replaces type hint `MypCardsProvider`)
   - Accept `CardSourceProvider | None` as provider arg (keep backward compat)
   - When `provider_name == "liga"`, use `LigaMagicProvider`; get cards via `get_cards_for_liga_scan()`
   - When `provider_name == "myp"`, use current MYP path unchanged

2. **Extract price-fetch into a strategy function**:
   ```python
   async def _fetch_price_liga(provider, entry, card_id) -> HistoricalPrice | None:
       card_name = entry.get("name_en") or entry.get("name_pt", "")
       prices = await provider.search_card(card_name)
       normal = prices.get("normal", {})
       price = normal.get("mid") or normal.get("low") or normal.get("high")
       if price is None:
           return None
       return HistoricalPrice(
           source="liga",
           external_id=f"liga_{card_id}",
           observed_at=date.today(),
           median_price=price,
       )
   ```

3. **Error handling**: catch `LigaError` hierarchy alongside MYP errors
   - Import both error hierarchies
   - Map `LigaNotFoundError` → skip (no retry)
   - Map `LigaRateLimitError` → requeue with longer delay (Liga needs 30s+ cooldown)
   - Map `LigaError` → fail card

4. **Concurrency control**: when Liga, force `concurrency=1` regardless of param
   - Add delay override: Liga default 5s between cards

5. **Preserve backward compat**: all existing MYP scan tests pass unchanged

# F60-T08: Card detail Liga/MYP button priority

**Status:** planned
**Wave:** 2
**Depends on:** T01
**Parallel with:** T07, T09

## User Story

As a collector, I want the card detail page to show Liga as the primary
refresh action and MYP as a secondary fallback so that I default to the
best price source.

## Dev Notes

### Current state
- `CollectionCardDetail.tsx`: has "Refresh" button (MYP via `POST /collection/{id}/refresh`)
- F59 added "Refresh Liga" button (via `POST /collection/{id}/refresh-liga`)
- Both buttons exist but there's no clear hierarchy

### Changes needed

#### 1. `CollectionCardDetail.tsx` — button layout

- **Primary button** (emerald/green, prominent): "Refresh Liga"
  - Calls `POST /collection/{id}/refresh-liga`
  - Shows spinner while loading
- **Secondary button** (gray, smaller, outline): "Refresh MYP"
  - Calls `POST /collection/{id}/refresh`
  - Labeled as fallback

Layout:
```
[  Refresh Liga  ]  (primary, emerald)
[ Refresh MYP ]    (secondary, gray outline, smaller)
```

#### 2. `PriceSourceBadge` update

Current badge shows source. Update colors:
- `liga` → emerald/green badge "Liga"
- `jsonld_snapshot` / `myp` → amber badge "MYP"
- `manual` → blue badge "Manual"

#### 3. `CollectionCardTile.tsx` — hover overlay

Current: single refresh icon on hover.
Change: default refresh action = Liga (change endpoint called on click).
Keep MYP available via long-press or secondary action (or just change the default).

Simplest approach: change the refresh endpoint in `CollectionCardTile` from
`/collection/{id}/refresh` to `/collection/{id}/refresh-liga`.

#### 4. `DeckCardTile.tsx` — same change

Change refresh endpoint from MYP to Liga.

### Files to modify
- `frontend/src/pages/CollectionCardDetail.tsx` — button hierarchy
- `frontend/src/components/PriceSourceBadge.tsx` — liga color
- `frontend/src/components/CollectionCardTile.tsx` — default refresh = liga
- `frontend/src/components/DeckCardTile.tsx` — default refresh = liga

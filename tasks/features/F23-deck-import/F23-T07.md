# F23-T07: API Endpoints (decks router)

- **Wave:** 3
- **Status:** planned
- **Depends on:** F23-T03, F23-T05, F23-T06
- **Type:** backend

## Description

Create `src/api/routers/decks.py` with the deck CRUD endpoints and
register it in `src/api/app.py`.

### Endpoints

**POST /api/v1/decks/import**
- Auth required (F22 dependency -- use `get_current_user` or fallback to
  `FAKE_USER_ID = "eduardo"` pattern until F22 ships).
- Request body: `DeckImportRequest`
- Calls `import_deck_from_text` or `import_deck_from_csv` based on `format`.
- Returns `ApiResponse[DeckImportResult]`.

**GET /api/v1/decks**
- Auth required.
- Returns `ApiResponse[list[DeckSummarySchema]]`.
- Each summary includes ownership stats computed via `get_deck_summary`.

**GET /api/v1/decks/{deck_id}**
- Auth required.
- Returns `ApiResponse[DeckDetailSchema]`.
- Cards include ownership flags from `get_deck_cards_with_ownership`.
- Cards include `image_url` from Scryfall (reuse `_scryfall_image_url` helper
  from collection router, or extract to shared utility).
- Cards include `latest_price` from `get_latest_prices_batch`.
- Returns 404 if deck not found or belongs to another user.

**DELETE /api/v1/decks/{deck_id}**
- Auth required.
- Calls `delete_deck(deck_id, user_id)`.
- Returns 204 No Content on success, 404 if not found.

### Router registration

Add to `src/api/app.py`:
```python
from src.api.routers.decks import router as decks_router
app.include_router(decks_router, prefix="/api/v1")
```

### Auth pattern

Until F22 ships, use the same `FAKE_USER_ID = "eduardo"` pattern from
`src/api/routers/collection.py`. When F22 lands, replace with
`get_current_user` dependency.

Use `TestClient` from FastAPI (same pattern as existing router tests).

3. POST import with empty content -- 422 validation error

5. GET /decks/{id} -- returns detail with ownership flags

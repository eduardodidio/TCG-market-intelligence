## Description

Create `src/decks/importer.py` with the deck import orchestrator. This
function takes parsed card data (from either text parser or CSV parser),
creates a deck, inserts deck cards, and attempts to link each card to the
canonical `cards` table.

### Main function

```python
def import_deck(
    engine,
    user_id: str,
    name: str,
    cards: list[dict],
    description: str | None = None,
) -> dict:
    """Create a deck and insert its cards.

    Args:
        engine: SQLAlchemy engine
        user_id: authenticated user ID
        name: deck name
        cards: list of dicts with keys: name_en, quantity, set_code, collector_number
        description: optional deck description

    Returns:
        dict with keys: deck_id, name, cards_imported, cards_linked
    """
```

### Card linking logic

For each card dict, attempt to find a matching `CardRow` in the `cards` table:
1. If `set_code` and `collector_number` are provided: exact match on
   `(game="magic", set_code, collector_number)`.
2. If only `name_en`: search by `name_en` (case-insensitive). If exactly
   one result, link it. If multiple, leave `card_id` as None.

This reuses the same pattern from `src/collection/importer.py` lines 74-83.

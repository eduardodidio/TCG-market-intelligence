# F23-T09: Frontend Deck List Page + Import Modal

- **Wave:** 4
- **Status:** planned

- **Type:** frontend

## Description

Create the deck list page and import modal.

### DeckList page (`frontend/src/pages/DeckList.tsx`)

- Fetches decks via `fetchDecks()` on mount.
- Displays a grid of deck cards, each showing:
  - Deck name
  - Card count (e.g., "60 cards")
  - Ownership percentage with visual indicator (progress bar or badge)
  - Created date (relative, e.g., "2 days ago")
- Clicking a deck card navigates to `/decks/:id`.
- "Import Deck" button in the top-right opens the import modal.
- Empty state when no decks exist.
- Loading skeleton while fetching.

### DeckImportModal (`frontend/src/components/DeckImportModal.tsx`)

- Modal overlay (same dark theme as the rest of the app).
- Fields:
  - Deck name (text input, required)
  - Format toggle: "Text" / "CSV" (default: Text)
  - Content textarea (placeholder shows example format)
  - Optional description (text input)
- "Import" button calls `importDeck()`.
- On success: close modal, refresh deck list, show success toast/banner.
- On error: show error message inline.
- Loading state on the import button.

### Route registration

Add to `frontend/src/App.tsx`:
```tsx
const DeckList = lazy(() => import("./pages/DeckList").then(m => ({ default: m.DeckList })));
// Route: /decks
```

Add to `frontend/src/components/Layout.tsx` nav items:
```tsx
{ to: "/decks", label: "My Decks" }
```

# F23-T04: Text Format Deck Parser

- **Wave:** 2
- **Status:** planned
- **Depends on:** none
- **Type:** backend

## Description

Create `src/decks/parser.py` with a pure function that parses a simple
text-format deck list into a list of card dicts.

### Supported formats

**Basic:** `{quantity} {card_name}`
```
4 Lightning Bolt
2 Eidolon of the Great Revel
1 Mountain
```

**With set code:** `{quantity} {card_name} [{set_code}]`
```
4 Lightning Bolt [M11]
2 Goblin Guide [ZEN]
```

**With set and collector number:** `{quantity} {card_name} [{set_code}:{number}]`
```
4 Lightning Bolt [M11:137]
```

### Parser rules

- Lines starting with `#` or `//` are comments, skip.
- Empty lines are skipped.
- If quantity is omitted, default to 1.
- Set code and collector number in brackets are optional.
- Whitespace is trimmed.
- Case is preserved for card names (matching is case-insensitive elsewhere).

### Return format

```python
def parse_deck_text(content: str) -> list[dict]:
    """Parse a text deck list.

    Returns list of dicts with keys:
    - name_en: str
    - quantity: int
    - set_code: str | None
    - collector_number: str | None
    """
```

Also create `src/decks/__init__.py` (empty).

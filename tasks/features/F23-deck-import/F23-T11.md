### User journey diagram (`docs/diagrams/F23-journey.mmd`)

BPMN-style flow:
1. User navigates to /decks
2. User clicks "Import Deck"
3. User pastes deck list, enters name
4. User clicks Import
5. System parses, creates deck, links cards
6. User sees deck in list with ownership %
7. User clicks deck -> sees card grid
8. User identifies owned vs missing cards
9. User clicks card -> navigates to detail

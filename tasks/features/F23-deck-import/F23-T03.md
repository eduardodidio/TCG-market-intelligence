# F23-T03: Repository CRUD + Ownership Query

- **Wave:** 1
- **Status:** planned

## Description

Add deck-related methods to `src/database/repository.py`:

### CRUD Methods

1. **`create_deck(user_id, name, description=None) -> DeckRow`**
   Insert a new deck row, return it.

2. **`add_deck_cards(deck_id, cards: list[dict]) -> int`**
   Bulk insert deck_cards rows. Each dict has: `name_en`, `set_code`,
   `collector_number`, `quantity`, `card_id`. Returns count inserted.

3. **`get_deck(deck_id) -> DeckRow | None`**
   Fetch a single deck by ID.

4. **`list_decks(user_id) -> list[DeckRow]`**
   List all decks for a user, ordered by `created_at DESC`.

5. **`delete_deck(deck_id, user_id) -> bool`**
   Delete a deck and its cards (cascade via manual delete of deck_cards
   first, then deck). Returns True if deleted, False if not found or
   wrong user.

6. **`get_deck_cards(deck_id) -> list[DeckCardRow]`**
   Fetch all deck_cards for a given deck.

### Ownership Query

7. **`get_deck_cards_with_ownership(deck_id, user_id) -> list[dict]`**
   For each deck_card, LEFT JOIN against `user_collection` to determine:
   - `in_collection` -- bool (any matching collection entry exists)
   - `owned_quantity` -- sum of collection quantities for matching cards
   - `collection_entry_id` -- first matching collection entry ID

   Matching logic (in priority order):
   a. Match by `card_id` if both deck_card.card_id and collection.card_id are not null
   b. Match by `set_code + collector_number` if both are available
   c. Match by `name_en` (case-insensitive) as fallback

   Returns list of dicts with all DeckCardRow fields plus ownership fields.

8. **`get_deck_summary(deck_id, user_id) -> dict`**
   Returns aggregated counts: total_cards, unique_cards, owned_cards, ownership_pct.

### Card Linking

9. **`link_deck_card(deck_card_id, card_id) -> None`**
   Update a deck_card's card_id field. Used during import to link to
   canonical cards.

# F23-T06: API Schemas (Pydantic models for decks)

- **Wave:** 3
- **Status:** planned
- **Depends on:** F23-T02
- **Type:** backend

## Description

Create `src/api/schemas/decks.py` with Pydantic models for the deck API.

### Request schemas

**DeckImportRequest:**
- `name` -- str, required, min_length=1, max_length=300
- `format` -- Literal["text", "csv"], default "text"
- `content` -- str, required, min_length=1
- `description` -- str | None, default None

### Response schemas

**DeckImportResult:**
- `deck_id` -- int
- `name` -- str
- `cards_imported` -- int
- `cards_linked` -- int

**DeckSummarySchema:**
- `id` -- int
- `name` -- str
- `description` -- str | None
- `total_cards` -- int
- `unique_cards` -- int
- `owned_cards` -- int
- `ownership_pct` -- float
- `created_at` -- datetime
- `updated_at` -- datetime

**DeckCardSchema:**
- `id` -- int
- `name_en` -- str
- `set_code` -- str | None
- `collector_number` -- str | None
- `quantity` -- int
- `card_id` -- int | None
- `in_collection` -- bool
- `owned_quantity` -- int
- `collection_entry_id` -- int | None
- `image_url` -- str | None
- `latest_price` -- float | None

**DeckDetailSchema:**
- `id` -- int
- `name` -- str
- `description` -- str | None
- `cards` -- list[DeckCardSchema]
- `total_cards` -- int
- `unique_cards` -- int
- `owned_cards` -- int
- `ownership_pct` -- float
- `created_at` -- datetime
- `updated_at` -- datetime

All schemas use `model_config = ConfigDict(from_attributes=True)` where applicable.

## Acceptance Criteria

- [ ] All 5 schema classes defined with correct field types
- [ ] `DeckImportRequest` validates `format` is "text" or "csv"
- [ ] `DeckImportRequest` rejects empty name or content
- [ ] Schemas serialize/deserialize correctly
- [ ] All existing tests pass

# F23-T01: Database Models (DeckRow, DeckCardRow)

- **Wave:** 0
- **Status:** planned
- **Depends on:** none
- **Type:** backend

## Description

Add two new SQLAlchemy models to `src/database/models.py`:

**DeckRow** (`decks` table):
- `id` -- INTEGER PK autoincrement
- `user_id` -- VARCHAR(100), NOT NULL, indexed
- `name` -- VARCHAR(300), NOT NULL
- `description` -- TEXT, nullable
- `created_at` -- DATETIME, default now
- `updated_at` -- DATETIME, default now, onupdate now

**DeckCardRow** (`deck_cards` table):
- `id` -- INTEGER PK autoincrement
- `deck_id` -- INTEGER, NOT NULL, indexed (logical FK to decks.id)
- `set_code` -- VARCHAR(20), nullable
- `collector_number` -- VARCHAR(20), nullable
- `name_en` -- VARCHAR(500), NOT NULL
- `quantity` -- INTEGER, default 1
- `card_id` -- INTEGER, nullable (linked to canonical cards table)

Indexes:
- `ix_decks_user` on `(user_id)`
- `ix_deck_cards_deck` on `(deck_id)`
- `ix_deck_cards_card` on `(card_id)`

Follow existing patterns in `models.py` (see `UserCollectionRow`, `ScanRunRow`).

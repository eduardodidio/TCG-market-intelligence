# F125-T04 — TreasureModal: 3D Tilt on Enlarged Image

**Status:** planned
**Wave:** 1
**Parallel:** yes (no deps on T01, T02, T03)

## User Story

> As a user viewing the enlarged Treasure Token modal, I want the treasure
> image to have the same 3D tilt effect as card images, with foil shimmer,
> so it feels like holding a real Magic card.

## Dev Notes

### File: `frontend/src/components/TreasureModal.tsx`

**Current behavior:** The TreasureModal shows an `<img>` with a golden
box-shadow and fly-in/fly-out animation. No 3D tilt.

**Changes:**

1. Import `Card3DTilt`.
2. Wrap the `<img>` (line ~170-181) in `<Card3DTilt>`:
   ```tsx
   <Card3DTilt tiltMaxAngle={18} scale={1.08} foil>
     <img
       src={treasureImage}
       alt={t("credits.balance")}
       className="max-h-[70vh] max-w-[90vw] rounded-lg"
       style={{ boxShadow: ... }}
       data-testid="treasure-modal-image"
     />
   </Card3DTilt>
   ```
3. The `foil` prop enables the glare + shimmer effect, fitting the golden
   treasure aesthetic.
4. The fly-in animation uses CSS `transform` on the parent `contentStyle`.
   `Card3DTilt` (react-parallax-tilt) uses its own internal transforms.
   These should compose correctly since Card3DTilt is a child of the
   animated container. If there's a conflict, wrap Card3DTilt in a `<div>`
   that receives the animation styles instead.

**Potential issue:** `react-parallax-tilt` sets `transform-style: preserve-3d`
which might interact with the parent's transition transform. If the fly-in
animation breaks, apply `contentStyle` to a wrapper `<div>` above Card3DTilt
instead of on the same element.

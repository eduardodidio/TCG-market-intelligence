# F125-T02 — CardDetail: 3D Tilt + Click-to-Zoom Preview

**Status:** planned
**Wave:** 1
**Parallel:** yes (no deps on T01, T03, T04)

## User Story

> As a user viewing a card's detail page, I want the card image to have the
> same 3D tilt effect as the grid tiles, and I want to click the image or the
> card name to open a fullscreen 3D preview modal, so the experience is
> consistent across the app.

## Dev Notes

### File: `frontend/src/pages/CardDetail.tsx`

**1. Wrap CardImage in Card3DTilt**

The local `CardImage` component (line ~433) renders a plain `<img>`. Changes:

- Import `Card3DTilt` and `CardPreviewModal` at the top of the file.
- Add `useState<boolean>` for `previewOpen` in the `CardDetail` component.
- Pass an `onImageClick` callback down to `CardImage`.
- Inside `CardImage`: wrap the `<img>` (or its container `<div>`) in
  `<Card3DTilt tiltMaxAngle={12} scale={1.05}>`.
- Add `cursor-zoom-in` on the image, `onClick` calls `onImageClick`.
- Placeholder (no image) does NOT get clickable behavior.
- Render `CardPreviewModal` in `CardDetail` when `previewOpen` is true.

**2. Card name click**

The `<h1>` (line ~178) showing the card name: add `onClick` →
`setPreviewOpen(true)`, `cursor-pointer`, and a subtle hover style
(`hover:text-cyan-300 transition-colors`).

**3. Image URL for modal**

Track the currently displayed image URL in `CardImage` so we can pass it
to `CardPreviewModal`. Options:
- Lift the resolved URL up via a callback `onResolvedUrl(url)`.
- Or compute the URL in the parent and pass it down (cleaner).

Recommended: compute image URL in parent `CardDetail`, pass to both
`CardImage` and `CardPreviewModal`.

**4. Foil detection**

CardDetail doesn't track foil status. Pass `isFoil={false}` for now.

### Render

```tsx
{previewOpen && resolvedImageUrl && (
  <CardPreviewModal
    imageUrl={resolvedImageUrl}
    cardName={displayName}
    isFoil={false}
    onClose={() => setPreviewOpen(false)}
  />
)}
```

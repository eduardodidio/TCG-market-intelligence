# F125-T03 — CollectionCardDetail: 3D Tilt + Click-to-Zoom Preview

**Status:** planned
**Wave:** 1
**Parallel:** yes (no deps on T01, T02, T04)

## User Story

> As a user viewing a collection entry detail page, I want the card image to
> have the same 3D tilt effect and click-to-zoom modal as the rest of the app,
> including clicking the card name to preview.

## Dev Notes

### File: `frontend/src/pages/CollectionCardDetail.tsx`

**1. Wrap card image in Card3DTilt**

The card image (line ~290-299) is a plain `<img>` inside a `<div>`. Changes:

- Import `Card3DTilt` and `CardPreviewModal`.
- Add `useState<boolean>` for `previewOpen`.
- Wrap the image `<div>` content in `<Card3DTilt foil={entry.is_foil}>`.
- Add `onClick={() => setPreviewOpen(true)}` on the image.
- Add `cursor-zoom-in` class.
- Handle `onError` — keep existing behavior (hide on error), do NOT open
  modal if image failed to load. Track error state to disable click.

**2. Card name click**

The `<h1>` (line ~303) with `displayName`: add `onClick` →
`setPreviewOpen(true)`, `cursor-pointer`, hover style
(`hover:text-cyan-300 transition-colors`).

**3. Foil detection**

CollectionCardDetail already has `entry.is_foil`. Pass it to both
`Card3DTilt` (for shimmer on hover) and `CardPreviewModal`.

**4. Image URL**

Already computed at line ~274:
```tsx
const imageUrl = entry.image_url || scryfallImageUrl(entry.set_code, entry.collector_number);
```

Use this directly for the modal.

### Render

```tsx
{previewOpen && imageUrl && (
  <CardPreviewModal
    imageUrl={imageUrl}
    cardName={displayName}
    isFoil={entry.is_foil}
    onClose={() => setPreviewOpen(false)}
  />
)}
```

## Acceptance Criteria

- [ ] Card image on `/collection/:id` wrapped in `Card3DTilt` (foil shimmer if `is_foil`)
- [ ] Clicking card image opens `CardPreviewModal` with 3D tilt + zoom
- [ ] Clicking card name (h1) also opens `CardPreviewModal`
- [ ] Card name has `cursor-pointer` and hover color change
- [ ] Image has `cursor-zoom-in`
- [ ] `isFoil` passed correctly to both `Card3DTilt` and `CardPreviewModal`
- [ ] Escape/backdrop close the modal
- [ ] If image errored (hidden), clicking does NOT open modal

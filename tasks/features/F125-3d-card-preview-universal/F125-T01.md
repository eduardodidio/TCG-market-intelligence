# F125-T01 — Bugfix: Add Card3DTilt + CardPreviewModal to All Missing Grid Tiles

**Status:** planned
**Wave:** 1
**Parallel:** yes (no deps on T02, T03, T04)

## User Story

> As a user browsing my collection, the marketplace, shared collections,
> wishlist, or duplicates, I want the same 3D tilt on hover and click-to-zoom
> modal that already works on the Cards and Catalog pages, so the experience
> is consistent everywhere.

## Context (the bug)

F116 added `Card3DTilt` to 4 components (`CardTile`, `CatalogCardTile`,
`DeckCardTile`, `CardHoverPreview`) but missed 5 inline tile components
defined locally inside page files. These still use flat `hover:scale-[1.02]`
CSS or no hover effect at all.

## Dev Notes

### 1. `CollectionCardTile` in `MyCollection.tsx` (line ~68)

**Highest priority** — this is the user's main collection grid.

- Import `Card3DTilt` and `CardPreviewModal`
- Add `useState<boolean>` for `previewOpen`
- Wrap the outer `<div>` (or its content) in `<Card3DTilt foil={card.is_foil}>`
- Remove `hover:scale-[1.02]` from the className (Card3DTilt handles scale)
- Add `cursor-zoom-in` and `onClick` on the image `<div>` to open preview
- Render `CardPreviewModal` when `previewOpen && primaryUrl`
- Pass `isFoil={card.is_foil}` to CardPreviewModal

**Note:** The tile is wrapped in a `<Link>` via `SelectableCardTile`. The
`onClick` on the image must call `e.preventDefault(); e.stopPropagation()`
to prevent navigation, same pattern as `CardTile.tsx`.

### 2. `MarketplaceCardTile` in `Marketplace.tsx` (line ~18)

- Import `Card3DTilt` and `CardPreviewModal`
- Add `previewOpen` state
- Wrap outer `<div>` in `<Card3DTilt foil={false}>`
- Remove `hover:scale-[1.02]`
- Image click → preview modal (stopPropagation to not trigger interest button)
- Use `currentUrl` for the modal image

### 3. `SharedCardTile` in `SharedCollectionPage.tsx` (line ~24)

- Same pattern as MarketplaceCardTile

- Remove `hover:scale-[1.02]`
- Image click → preview modal

### 4. `WishlistCard` in `WishlistPage.tsx` (line ~187)

- Import `Card3DTilt` and `CardPreviewModal`

- Wrap outer `<div>` in `<Card3DTilt foil={false}>`

### 5. `DuplicatesList` in `DuplicatesList.tsx` (line ~23)

- Import `Card3DTilt` and `CardPreviewModal`
- Each card in the `.map()` needs `previewOpen` state — extract a
  `DuplicateCard` sub-component (or use a wrapper component) since hooks
  can't be called inside map directly. Simplest: create a local
  `DuplicateCardTile` function component.
- Wrap the `<Link>` content in `<Card3DTilt foil={false}>`
- Image click → preview modal (stopPropagation to prevent Link navigation)

### Pattern to follow (from CardTile.tsx)

```tsx
<Card3DTilt foil={isFoil} className="w-full">
  {/* existing tile content */}
  <div className="aspect-[5/7] ... cursor-zoom-in"
    onClick={(e) => { e.preventDefault(); e.stopPropagation(); setPreviewOpen(true); }}
  >
    {/* image */}
  </div>
  {/* card info */}
  {previewOpen && imageUrl && (
    <CardPreviewModal
      imageUrl={imageUrl}
      cardName={displayName}
      isFoil={isFoil}
      onClose={() => setPreviewOpen(false)}
    />
  )}
</Card3DTilt>
```

# F81-T02: Monthly Admin Grant Logic (10k Tokens)

**Status:** planned
**Wave:** 0

## User Story
As an admin user, I want to receive 10,000 tokens automatically on the 1st of every month, so I have enough tokens for intensive operations without manually requesting grants.

## Dev Notes

### Design
- Add `ADMIN_MONTHLY_GRANT = 10_000` to `src/credits/constants.py`
- Add `last_monthly_grant_at` column to `credit_balances` table (nullable TIMESTAMP)
- On login or on any credit check, auto-claim monthly grant if:
  1. `user.is_admin == True`
  2. `last_monthly_grant_at` is None OR `last_monthly_grant_at.month != current_month` or `last_monthly_grant_at.year != current_year`
- Grant 10k tokens and update `last_monthly_grant_at`

### Files to Modify
- `src/credits/constants.py` — add `ADMIN_MONTHLY_GRANT = 10_000`
- `src/credits/service.py` — add `claim_monthly_admin_grant(user_id, is_admin)` method
- `src/database/models.py` — add `last_monthly_grant_at` to `CreditBalanceRow`
- `src/database/repository.py` — add `update_last_monthly_grant_at` method
- `src/api/routers/credits.py` — call `claim_monthly_admin_grant` on GET /balance if user is admin (auto-claim on check)

### Auto-Claim Flow
```
GET /credits/balance
  → if user.is_admin and monthly grant not yet claimed this month:
    → grant 10k
    → update last_monthly_grant_at
  → return balance (including fresh grant)
```

### Existing Bonus (unchanged)
- 5 tokens every 12h via POST /credits/claim-bonus — stays the same for ALL users (admin and non-admin)

## Testing

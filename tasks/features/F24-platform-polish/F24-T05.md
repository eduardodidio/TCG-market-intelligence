# F24-T05: Fix Explore Cards Missing Prices

- **Wave:** 1
- **Status:** planned
- **Depends on:** none
- **Type:** fullstack

## User Story

As a user browsing Explore Cards, I want to see price information for all
cards, or a clear indication when no price data is available.

## Objective

Ensure all cards in Explore Cards display a price or a meaningful fallback
message when no price data exists.

## Dev Notes

**Current price display logic:**
- `CardTile.tsx` shows `card.latest_price` formatted via `formatBRL/USD/Pila`
- Cards without price observations have `latest_price = null` or `0`
- Need to check what the API returns for cards without prices

**Investigation checklist:**
1. **Backend** — `GET /api/v1/cards` response: does it include a price field?
   Check `src/api/routers/cards.py` list endpoint. It batch-fetches latest
   prices via `get_latest_prices_batch()`. Cards without source_cards or
   without observations will have no price.
2. **Frontend** — How does `CardTile.tsx` render when price is null/undefined/0?
   Does it show blank, "R$ 0,00", or nothing?
3. **Root causes for missing prices:**
   - Card has no `source_cards` linked (no MYP match)
   - Card has source_cards but no `price_observations` yet
   - Price observation exists but `median_price` is 0 or null

**Fix approach:**
- Frontend: Show "No price data" or "Price unavailable" when price is
  null/undefined/0. Use a muted text style.
- Optionally show "Not tracked" if the card has no source_cards at all.
- Ensure `formatBRL(0)` doesn't show "R$ 0,00" for unpriced cards.

**Files to touch:**
- `frontend/src/components/CardTile.tsx` — add price fallback display
- `frontend/src/utils/format.ts` — possibly add `formatPriceOrFallback`
- `frontend/src/types/api.ts` — verify price field type (nullable?)

## Testing

- Framework: Vitest + React Testing Library
- Test file: `frontend/src/__tests__/CardTile.test.tsx`
- Test scenarios:
  1. Card with valid price → displays formatted price
  2. Card with price = null → shows "No price data" text
  3. Card with price = 0 → shows "No price data" (not "R$ 0,00")
  4. Price display respects current currency context

# F24-T02: Lovable Design Tokens & Tailwind Theme

- **Wave:** 0
- **Status:** planned
- **Depends on:** none
- **Type:** frontend

## User Story

As a user, I want a modern, polished visual design so that the platform
feels professional and enjoyable to use.

## Objective

Analyze the Lovable reference app (tcg-market-shine.lovable.app) and
extract design tokens into Tailwind config. This is the foundation for
the style overhaul in T09.

## Dev Notes

- Fetch the Lovable reference page at `https://tcg-market-shine.lovable.app`
  using WebFetch to extract:
  - Color palette (primary, secondary, accent, background, surface, text colors)
  - Typography (font families, sizes, weights, line heights)
  - Spacing scale (padding, margins, gaps)
  - Border radius values
  - Shadow definitions
  - Card styles (elevation, border, hover effects)
  - Button styles (variants, sizes, states)
  - Sidebar/nav design patterns
- Document extracted tokens in `docs/design/lovable-tokens.md`
- Update `frontend/tailwind.config.js` (or `.ts`) to extend theme with:
  - Custom color palette matching Lovable
  - Typography scale
  - Shadow utilities
  - Border-radius presets
- Create `frontend/src/styles/design-tokens.css` with CSS custom properties
  for colors that can be used in both Tailwind and raw CSS
- DO NOT change any component yet (that's T09)
- Preserve all existing Tailwind classes as valid

## Testing

- Framework: Vitest
- Test: build succeeds with new Tailwind config (`npm run build` passes)
- Manual: Tailwind dev server starts without errors

## Acceptance Criteria

- [ ] Design tokens documented in `docs/design/lovable-tokens.md`
- [ ] Tailwind config extended with Lovable color palette
- [ ] CSS custom properties file created
- [ ] Existing build still works (no broken classes)
- [ ] No visual regressions (tokens added but not yet applied)

# F24-T07: Interactive Price Chart with Zoom

- **Wave:** 1
- **Status:** planned
- **Depends on:** none
- **Type:** frontend

## User Story

As a collector, I want to zoom in/out on the price chart and see dynamic
Y-axis scaling so I can analyze price movements at different time scales,
including prices above R$100 (e.g., Aves do Paraiso).

## Objective

Replace the static Recharts line chart with an interactive chart supporting
zoom, pan, dynamic Y-axis, and basic TradingView-like tools.

## Dev Notes

**Current issues:**
- Y-axis appears capped at R$100 — "Aves do Paraiso" price exceeds this
  but can't be seen. Likely a hardcoded domain or auto-scaling bug.
- No zoom/pan capability — user can't focus on specific time ranges.
- No crosshair or interactive tools.

**Solution options (pick one):**

### Option A: Recharts with Brush + ReferenceArea zoom (simpler)
- Add `<Brush>` component for time-range selection at bottom
- Add ReferenceArea-based zoom (click-drag to select region)
- Fix Y-axis: use `domain={["auto", "auto"]}` or `domain={[0, "dataMax + 10%"]}`
- Add crosshair via `<Tooltip cursor={{ strokeDasharray: "3 3" }}>`
- Pros: no new dependency, familiar API
- Cons: limited interactivity vs dedicated charting lib

### Option B: lightweight-charts (TradingView) (richer, new dep)
- Install `lightweight-charts` (MIT, ~45KB)
- TradingView-style candlestick/line chart with built-in:
  - Mouse wheel zoom, click-drag pan
  - Crosshair with price/time labels
  - Auto-scaling Y-axis
  - Time scale controls
- Pros: professional financial chart UX, built-in zoom/pan
- Cons: new dependency, different API

**Recommended: Option A first** (Recharts Brush + zoom). If insufficient,
escalate to Option B in a follow-up.

**Implementation plan (Option A):**
1. Fix Y-axis domain: `domain={[0, (dataMax) => Math.ceil(dataMax * 1.1)]}`
   to always show 10% headroom above max price
2. Add `<Brush>` at bottom for time range selection
3. Add zoom state: `zoomLeft`/`zoomRight` via ReferenceArea mouse events
4. Add reset zoom button
5. Add crosshair cursor to Tooltip
6. Responsive container already in place

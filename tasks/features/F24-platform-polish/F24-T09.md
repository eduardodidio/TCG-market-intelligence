# F24-T09: Visual Style Overhaul (Lovable Design)

- **Wave:** 2
- **Status:** planned
- **Depends on:** F24-T02
- **Type:** frontend

## User Story

As a user, I want a modern, polished visual design that matches the Lovable
reference app so the platform feels premium and professional.

## Objective

Apply the Lovable design tokens (from T02) across all pages and components.
Full visual refresh without changing any functionality.

## Dev Notes

**Reference:** https://tcg-market-shine.lovable.app

**Key design elements to apply (based on T02 tokens):**

### Global:
- Dark theme with rich gradients (dark navy/purple background)
- Card-based layout with subtle glass-morphism (backdrop-blur, semi-transparent bg)
- Consistent border-radius (rounded-xl / rounded-2xl)
- Subtle shadows and borders with low-opacity whites
- Smooth transitions on hover/focus states

### Layout/Sidebar:
- Sleek sidebar with icon + text nav items
- Active state: highlighted background + accent color
- Collapsed mode for mobile
- Logo/brand area at top

### Cards (KPI, Card tiles):
- Glass-morphism background (bg-white/5 backdrop-blur)
- Hover: scale-up slightly + border glow
- Consistent padding and internal spacing
- Subtle gradient overlays

### Buttons:
- Primary: gradient background (purple→blue or per reference)
- Secondary: outlined with hover fill
- Consistent sizing and padding

### Typography:
- Clean sans-serif (Inter or system stack)
- Hierarchy: page title (2xl bold), section (xl semibold), body (sm/base)
- Muted secondary text (text-white/60 or similar)

### Charts:
- Dark chart background matching page
- Grid lines: very subtle (white/10)
- Line colors: vibrant against dark background

### Forms (Login, Import):
- Dark input backgrounds with subtle borders
- Focus ring in accent color
- Clean label placement

**Approach:**
1. Update `frontend/src/index.css` or `globals.css` with base dark theme
2. Update Layout.tsx sidebar styling
3. Update each page component's container and section styling
4. Update shared components (KpiCard, CardTile, SearchBar, etc.)
5. Update form components (Login, DeckImportModal, ScanForm)
6. Ensure responsive design maintained

**Files to touch (ALL frontend components):**
- `frontend/src/index.css` — base styles, dark theme
- `frontend/src/components/Layout.tsx` — sidebar + layout
- `frontend/src/components/KpiCard.tsx` — glass-morphism cards
- `frontend/src/components/CardTile.tsx` — card grid items
- `frontend/src/components/PriceChart.tsx` — chart container
- `frontend/src/components/SearchBar.tsx` — input styling
- `frontend/src/components/SortSelect.tsx` — select styling
- `frontend/src/components/GridSizeToggle.tsx` — toggle styling
- `frontend/src/components/CurrencyToggle.tsx` — toggle styling
- `frontend/src/components/ErrorBanner.tsx` — alert styling
- `frontend/src/components/EmptyState.tsx` — empty state styling
- `frontend/src/components/Skeleton.tsx` — skeleton styling
- `frontend/src/pages/*.tsx` — all page layouts
- Plus any other components with visual styling

**Critical rule: DO NOT remove any feature or functionality.** This is a
purely visual change. All interactive elements, data displays, and
navigation must continue working exactly as before.

# F24-T08: i18n String Extraction (EN + PT-BR)

- **Wave:** 2
- **Status:** planned
- **Depends on:** F24-T01
- **Type:** frontend

## User Story

As a user, I want to see all UI text in my chosen language (English or
Portuguese) so the platform feels natural in either language.

## Objective

Extract all hardcoded UI strings from every page and component into the
i18n translation files (EN + PT-BR). Replace hardcoded text with `t()` calls.

### Translation key structure (in `locales/en.json`):
```json
{
  "common": { "loading", "error", "retry", "save", "cancel", "delete", "back", ... },
  "nav": { "dashboard", "exploreCards", "myCollection", "myDecks", "scans", "marketMovers", ... },
  "dashboard": { "title", "collectionHealth", "totalCards", "coverage", ... },
  "cards": { "title", "searchPlaceholder", "noResults", ... },
  "collection": { "title", "entryNotFound", "notLinked", ... },
  "decks": { "title", "importDeck", "deleteConfirm", ... },
  "auth": { "login", "register", "email", "password", ... },
  "chart": { "period30d", "period90d", "resetZoom", ... },
  "market": { "movers", "gainers", "losers", ... }
}
```

**Important rules:**
- Card names (`name_en`, `name_pt`) are DATA, not UI strings — do NOT translate
- Currency formatting uses locale-aware `Intl.NumberFormat` — already handled
- Date formatting should use locale from i18n context
- Interpolation for dynamic values: `t("dashboard.coverage", { pct: 23 })`

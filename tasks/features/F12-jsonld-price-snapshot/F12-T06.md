# F12-T06 -- Frontend: PriceChart Sparse Data Handling

- **Wave:** 2
- **Type:** frontend
- **Depends on:** (none)
- **Status:** done

## User Story

As a dashboard user, I want the price chart to display a clear, helpful
message when there are very few data points (1-5), and to render single
data points as visible dots instead of invisible zero-length lines, so
that the chart is usable during the first days/weeks of JSON-LD snapshot
collection.

## Objective

Improve `frontend/src/components/PriceChart.tsx` to handle sparse data
gracefully.

## Dev Notes

- Currently, the chart shows "No price history available" when
  observations is empty. When there is 1 data point, Recharts renders a
  line with no visible path (zero-length line segment). This looks broken.
- Fix: when observations.length is between 1 and 5, show dots on the
  Line components (`dot={true}` or `dot={{ r: 4 }}`).
- Also add a subtle info banner below the period selector when data
  points < 7: "Building price history -- {N} data point(s) so far.
  Daily snapshots will fill this chart over time."
- No API changes needed -- the chart already fetches from
  `/api/v1/cards/{id}/history`.

## Implementation Details

1. Open `frontend/src/components/PriceChart.tsx`.
2. Determine if data is sparse: `const isSparse = observations && observations.length > 0 && observations.length < 7;`
3. Add info banner after the period selector div:

```tsx
{isSparse && (
  <p data-testid="sparse-data-notice" className="text-sm text-amber-400/80 mb-3">
    Building price history -- {observations.length} data point{observations.length !== 1 ? 's' : ''} so far.
    Daily snapshots will fill this chart over time.
  </p>
)}
```

4. On each `<Line>` component, conditionally set `dot`:
   - Change `dot={false}` to `dot={isSparse ? { r: 3, fill: "currentColor" } : false}`
   - This makes individual data points visible as dots when sparse.

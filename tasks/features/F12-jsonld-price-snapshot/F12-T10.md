## Implementation Details

### 1. PRD (`docs/prd/F12-jsonld-price-snapshot.md`)

Cover: problem statement (history endpoint gated), solution (JSON-LD
extraction + daily snapshots), scope (parser, provider, collector, CLI,
API, cron, frontend), constraints (collection-only, no schema changes,
idempotent), success metrics (daily observations stored, chart populated
after 7+ days).

### 3. Journey Diagram (`docs/diagrams/F12-journey.mmd`)

BPMN-style flow:
- Trigger: Cron daily at 03:00 / Manual CLI / API POST
- Step 1: Load linked collection entries
- Step 2: For each, check idempotency (skip if today exists)
- Step 3: Fetch product page
- Step 4: Parse JSON-LD price
- Step 5: Store observation
- End: Log summary

### 4. README Update

Add under delivery history:

  (`POST /collection/snapshot-prices`), cron integration. Builds price
  history organically after MYP gated their history endpoint.

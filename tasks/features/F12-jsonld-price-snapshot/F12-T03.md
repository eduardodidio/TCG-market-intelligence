# F12-T03 -- Provider: fetch_current_price() Method

- **Wave:** 1
- **Type:** backend
- **Depends on:** F12-T01, F12-T02
- **Status:** done

## User Story

As a collector module, I need a provider method that fetches a product page
by external_id and slug and returns the parsed JSON-LD price, so that the
snapshot collector can get current prices without depending on the gated
history endpoint.

## Objective

Add `fetch_current_price(product_id: str, slug: str) -> JsonLdPrice | None`
method to `MypCardsProvider` in `src/providers/myp/provider.py`.

## Dev Notes

- The provider already has `get_current_price(card: SourceCard)` which
  fetches the page and calls `parse_price_snapshot()`. The new method is
  simpler: it takes `product_id` and `slug` directly (no need to construct
  a full SourceCard), fetches the page, and calls `parse_jsonld_price()`.
- Reuse the existing `_fetch()` method for HTTP with retry + rate limiting.
- URL pattern: `https://mypcards.com/magic/produto/{product_id}/{slug}`
- Add `parse_jsonld_price` to the imports from `src.parsers.myp`.
- Add `JsonLdPrice` to the imports from `src.domain.models`.

## Implementation Details

1. Open `src/providers/myp/provider.py`.
2. Add `parse_jsonld_price` to the existing import from `src.parsers.myp`.
3. Add `JsonLdPrice` to the existing import from `src.domain.models`.
4. Add the new method to `MypCardsProvider`:

```python
async def fetch_current_price(
    self, product_id: str, slug: str
) -> JsonLdPrice | None:
    """Fetch product page and extract current price from JSON-LD.

    Args:
        product_id: MYP product ID (e.g., "179334").
        slug: URL slug (e.g., "tutor-esclarecido").

    Returns:
        JsonLdPrice with current price data, or None on fetch failure.
    """
    url = f"{BASE_URL}/magic/produto/{product_id}/{slug}"
    try:
        html = await self._fetch(url)
    except (RuntimeError, TimeoutError, OSError):
        log.warning(
            "fetch_current_price_failed",
            product_id=product_id,
            slug=slug,
        )
        return None
    return parse_jsonld_price(html)
```

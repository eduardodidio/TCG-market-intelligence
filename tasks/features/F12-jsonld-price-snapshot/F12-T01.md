# F12-T01 -- Domain Model: JsonLdPrice and SnapshotSummary

- **Wave:** 0
- **Type:** backend
- **Depends on:** (none)
- **Status:** done

## User Story

As a developer, I need domain dataclasses that represent JSON-LD price
extraction results and snapshot run summaries, so that the parser,
collector, and CLI can communicate using well-typed structures.

## Objective

Add `JsonLdPrice` and `SnapshotSummary` dataclasses to
`src/domain/models.py`.

## Dev Notes

- `JsonLdPrice` represents the extraction result from a single product
  page's JSON-LD block. Fields: `price` (Decimal | None), `currency`
  (str), `availability` (str -- "InStock" / "OutOfStock" / "Unknown").
- `SnapshotSummary` summarizes a full snapshot run. Fields:
  `total_entries` (int), `fetched` (int), `stored` (int),
  `skipped_existing` (int), `skipped_zero_price` (int), `errors` (int),
  `started_at` (datetime), `finished_at` (datetime | None).
- Follow existing patterns in `src/domain/models.py` (dataclass, field
  defaults, datetime factory).
- No imports from other project modules -- domain models are leaf nodes.

## Implementation Details

1. Open `src/domain/models.py`.
2. Add after the `MypSearchResult` dataclass (around line 163):

```python
@dataclass
class JsonLdPrice:
    """Price extracted from JSON-LD offers block on a product page."""
    price: Decimal | None
    currency: str = "BRL"
    availability: str = "Unknown"  # "InStock" | "OutOfStock" | "Unknown"
```

3. Add after the `SyncSummary` dataclass (end of file):

```python
@dataclass
class SnapshotSummary:
    """Summary of a price snapshot run."""
    total_entries: int = 0
    fetched: int = 0
    stored: int = 0
    skipped_existing: int = 0
    skipped_zero_price: int = 0
    errors: int = 0
    error_details: list[CollectionError] = field(default_factory=list)
    started_at: datetime = field(default_factory=datetime.now)
    finished_at: datetime | None = None
```

4. Update the import of `JsonLdPrice` in any `__init__.py` if the project
   uses explicit re-exports (check first -- it currently does not).

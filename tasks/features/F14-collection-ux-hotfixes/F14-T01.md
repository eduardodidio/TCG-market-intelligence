# F14-T01 — Collection cards: internal navigation + external links

**Status:** planned
**Wave:** 1
**Depends on:** none

## User Story

As a collector, I want to click any card in My Collection and see its full
detail view (price chart, metadata) inside the platform — the same experience
as Explore Cards — so I don't leave the app.

As a collector, inside the card detail view I want quick links to Scryfall and
LigaMagic so I can cross-reference prices and information on those external
platforms.

## Acceptance Criteria

- [ ] Clicking a collection card with `card_id` navigates to `/cards/{card_id}`
      (already works — verify)
- [ ] Clicking a collection card WITHOUT `card_id` navigates to an internal
      fallback view (e.g. `/collection/{id}` or a modal) instead of opening
      Scryfall externally
- [ ] CardDetail page shows external links section with:
  - Scryfall link (search by card name + set)
  - LigaMagic link (search by card name)
- [ ] External links open in a new tab (`target="_blank"`)
- [ ] All existing tests pass; new tests cover the link rendering

## Dev Notes

### Current behavior (MyCollection.tsx, lines 139-151)
```tsx
// If card_id exists → <Link to={`/cards/${card.card_id}`}>
// If no card_id → <a href="https://scryfall.com/search?q=..."> (external)
```

### Changes needed

**1. `MyCollection.tsx` — CollectionCardTile**
- For unlinked cards (no `card_id`): change the external Scryfall `<a>` to an
  internal `<Link>` pointing to `/cards?name={encodedName}&set={setCode}` or
  a dedicated route. Simplest approach: navigate to the Explore Cards page
  pre-filtered by name, so the user can find and click the card there.
- Alternative: if unlinked cards have no useful detail to show, keep the
  internal link to Explore pre-filtered.

**2. `CardDetail.tsx` — External links section**
- Add a section below card metadata (after source links) with:
  - Scryfall: `https://scryfall.com/search?q=${encodeURIComponent(name)}+set:${setCode}`
  - LigaMagic: `https://www.ligamagic.com.br/?view=cards/card&card=${encodeURIComponent(name)}`
- Style as small icon+text buttons (e.g. "View on Scryfall", "View on LigaMagic")
- Use `target="_blank" rel="noopener noreferrer"`

### Key files
- `frontend/src/pages/MyCollection.tsx` (lines 130-153 — CollectionCardTile)
- `frontend/src/pages/CardDetail.tsx` (external links section — new)
- `frontend/src/components/CardTile.tsx` (reference for internal link pattern)

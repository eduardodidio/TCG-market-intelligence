# F14-T03 — Infinite scroll (Collection + Explore Cards)

**Status:** planned
**Wave:** 1
**Depends on:** none

## User Story

As a user, I want cards to load automatically as I scroll down, so I don't
have to repeatedly click "Load More" — a smoother browsing experience.

## Acceptance Criteria

- [ ] Collection page (`/collection`) loads next page automatically when the
      user scrolls near the bottom
- [ ] Explore Cards page (`/cards`) loads next page automatically when the
      user scrolls near the bottom
- [ ] Loading indicator shown while fetching next page
- [ ] No duplicate cards loaded (cursor-based pagination already prevents this)
- [ ] Scroll position preserved when navigating back from a detail view
- [ ] "Load More" button removed from both pages
- [ ] Works on mobile viewports
- [ ] All existing tests updated; no regressions

## Dev Notes

### Current implementation
Both pages use `<Pagination>` component (`frontend/src/components/Pagination.tsx`)
which renders a "Load more" button. The `handleLoadMore` callback in each page
appends results to the card array and updates the cursor.

### Implementation approach

**Option A (recommended): IntersectionObserver hook**
Create a custom `useInfiniteScroll` hook:

```tsx
// frontend/src/hooks/useInfiniteScroll.ts
import { useEffect, useRef, useCallback } from "react";

export function useInfiniteScroll(
  onLoadMore: () => void,
  options: { enabled: boolean; rootMargin?: string }
) {
  const sentinelRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!options.enabled) return;
    const sentinel = sentinelRef.current;
    if (!sentinel) return;

    const observer = new IntersectionObserver(
      ([entry]) => { if (entry.isIntersecting) onLoadMore(); },
      { rootMargin: options.rootMargin ?? "200px" }
    );
    observer.observe(sentinel);
    return () => observer.disconnect();
  }, [onLoadMore, options.enabled, options.rootMargin]);

  return sentinelRef;
}
```

**Usage in pages:**
```tsx
const sentinelRef = useInfiniteScroll(handleLoadMore, {
  enabled: !!cursor && !loadingMore,
});

// At the end of the card grid:
<div ref={sentinelRef} />
{loadingMore && <LoadingSpinner />}
```

### Edge cases
- `rootMargin: "200px"` triggers prefetch before user reaches bottom
- Guard: don't fire if `loadingMore` is true or `cursor` is null
- When all data is loaded (`cursor === null`), sentinel still renders but
  observer is disabled via `enabled: false`

# F14-T02 — Fix per-card price display in collection

**Status:** planned
**Wave:** 1
**Depends on:** none

## User Story

As a collector, I want to see the current price of each card in my collection
so I can evaluate my holdings at a glance.

## Acceptance Criteria

- [ ] Each collection card tile displays its latest price in BRL (e.g. "R$ 1,50")
- [ ] Cards without price data show a clear indicator (e.g. "---" or "No price")
- [ ] Collection summary KPI "Estimated Value" reflects the sum of per-card prices
- [ ] All existing tests pass; new/updated tests cover price rendering

## Dev Notes

### Investigation checklist

The code path LOOKS correct in the frontend — `CollectionCardTile` already
renders `formatBRL(card.latest_price)`. Possible failure points:

1. **Backend not returning `latest_price`** — Check
   `src/api/routers/collection.py` lines 66-89: `get_latest_prices_batch()`
   may return empty if no observations exist for linked cards. Verify with:
   ```bash
   curl http://localhost:8000/api/v1/collection?limit=5 | python3 -m json.tool
   ```

2. **No observations in DB** — If `snapshot-prices` hasn't run yet, there are
   no `jsonld_snapshot` observations. The old F01 observations may use a
   different source key. Check what sources exist:
   ```sql
   SELECT DISTINCT source FROM observations;
   ```

3. **`get_latest_prices_batch()` filtering by source** — If the repo method
   filters by source and the existing observations use a source the query
   doesn't match, prices won't populate.

4. **`card_id` is NULL for most collection entries** — If collection entries
   aren't linked to cards (card_id is NULL), the price lookup is skipped
   entirely. Check:
   ```sql
   SELECT COUNT(*) as total,
          COUNT(card_id) as linked
   FROM collection_entries;
   ```

5. **Frontend formatting** — `formatBRL(null)` may return empty string or
   render nothing. Check `frontend/src/utils/format.ts`.

### Fix strategy

- Diagnose which of the above is the root cause
- If it's a data issue (no observations): ensure the F12 snapshot pipeline
  populates data correctly; add a "no price data" indicator in the UI
- If it's a query issue: fix the repository method
- If it's a linking issue: surface it clearly in the UI (show "Not linked"
  instead of blank)

### Key files
- `src/api/routers/collection.py` (lines 66-89 — price lookup)
- `src/database/repository.py` (get_latest_prices_batch method)
- `frontend/src/pages/MyCollection.tsx` (CollectionCardTile price rendering)
- `frontend/src/utils/format.ts` (formatBRL function)

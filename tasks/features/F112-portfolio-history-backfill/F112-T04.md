# F112-T04 — Collection Movers Panel (Gainers/Losers)

**Wave:** 1
**Status:** planned

## User Story

As a collector, I want to see which cards in my collection had the biggest price increases and decreases recently, so I can make informed trading decisions.

## Dev Notes

### Backend

#### Location
- `src/api/routers/collection.py` — new endpoint

#### Endpoint: `GET /api/v1/collection/movers`
- Query params: `days` (default 7, max 90), `limit` (default 5, max 20)
- Auth: `require_auth_or_api_key`
- Response schema:
  ```python
  class CollectionMover(BaseModel):
      card_id: int
      card_name: str
      set_code: str | None
      image_uri: str | None
      price_start: float
      price_end: float
      change_abs: float
      change_pct: float

  class CollectionMoversResponse(BaseModel):
      gainers: list[CollectionMover]
      losers: list[CollectionMover]
      period_days: int
  ```

#### Logic
1. Use existing `repo.get_trending_price_data_for_user(user_id, days)`
2. For each card, compute start/end price and % change
3. Sort by % change desc for gainers, asc for losers
4. Return top N of each

### Frontend

#### Location
- `frontend/src/components/CollectionMovers.tsx` (new component)
- Integrate into `PortfolioDashboard.tsx` below the chart

#### UI
- Two columns: "Top Gainers" (green) and "Top Losers" (red)
- Each row: card image thumbnail, card name, price change (abs + %), sparkline (optional via PriceSparkline)
- Compact layout, max 5 items per column
- Empty state: "Not enough price history yet" if no movers

#### API call
- `GET /api/v1/collection/movers?days=7&limit=5`
- Call alongside portfolio summary in PortfolioDashboard useEffect

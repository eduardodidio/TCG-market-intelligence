# F112-T01 — Backfill Acquisition Prices

**Wave:** 0
**Status:** planned

## User Story

As a collector, I want my existing collection entries to have an `acquisition_price` automatically set to the price at the time I added them, so the portfolio dashboard can calculate my P&L.

## Dev Notes

### Location
- `src/collectors/portfolio_backfill.py` (new file)

### Logic: `backfill_acquisition_prices(repo, user_id=None)`
1. Query `user_collection` entries where `acquisition_price IS NULL`
2. For each entry with a `card_id`:
   a. Find the `price_observations` row closest to `entry.created_at` date (or earliest available)
   b. Use `median_price` (fallback: `tcg_price`, then `last_sold_price`)
   c. Update `acquisition_price` and `acquired_at` on the collection entry
3. If no price observation exists for a card, skip it (log a warning)
4. Return a summary: `{updated: N, skipped: N, total: N}`

### Query Strategy
- Join `user_collection` -> `cards` -> `source_cards` -> `price_observations`
- For each card, pick the observation with `observed_at` closest to `created_at` (prefer same day or earlier)
- Use a single batch query with window functions to find nearest observation per card, avoiding N+1

### Constraints
- NEVER overwrite an existing `acquisition_price` (user may have set it manually)
- Idempotent: safe to run multiple times
- Transaction: wrap all updates in a single transaction

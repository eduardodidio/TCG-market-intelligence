# F19-T01: Backend Pila Formatter (Extenso Logic)

- **Wave:** 0
- **Status:** planned
- **Depends on:** F18 (multi-currency infra must exist)

## Description

Create a pure-function Pila formatter in the backend that converts a Decimal/float
BRL value into the extenso format: `230 pilas e 21 centavos`. This formatter will
be used by API responses when the user's preferred currency is PILA, and also serves
as the canonical reference implementation for the frontend formatter.

The formatter should live in `src/currency/pila_formatter.py` (or within whatever
currency module F18 establishes). It must be a pure function with no side effects
or database access.

## Implementation Details

File: `src/currency/pila_formatter.py` (new file, or integrate into F18's currency module)

Function signature:
```
def format_pila(value: Decimal | float | None) -> str
```

Rules:
- `None` -> `"--"`
- Integer part uses pt-BR thousands separator (`.`): `1000` -> `1.000`
- "pila" when integer part == 1, "pilas" otherwise
- "centavo" when fractional part == 1, "centavos" otherwise
- Omit fractional clause when centavos == 0
- Examples: see PRD formatter rules table

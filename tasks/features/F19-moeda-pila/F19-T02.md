# F19-T02: Register PILA Currency in Multi-Currency System

- **Wave:** 0
- **Status:** planned
- **Depends on:** F18 (multi-currency infra must exist)

## Description

Register "PILA" as a currency entry in the F18 multi-currency system. This includes
adding seed data to the currency table/registry with a fixed 1:1 rate to BRL. The
PILA currency must be marked as a custom/novelty currency so it can be distinguished
from real ISO currencies. The exchange rate must never be updated by any automated
rate-fetching process.

## Implementation Details

Add PILA to whatever currency registration mechanism F18 provides. Expected fields:

- `code`: `"PILA"`
- `name`: `"Pila (Rio Grande do Sul)"`
- `symbol`: RS flag reference (emoji or SVG path)
- `rate_to_brl`: `1.0`
- `is_fixed`: `True` (flag to prevent rate updates)
- `formatter`: `"extenso"` or reference to the custom formatter
- `decimal_places`: `2`
- `locale`: `"pt-BR"`

If F18 uses a database table, add a migration or seed script. If F18 uses a
configuration file or enum, add the entry there.

## Acceptance Criteria

- [ ] PILA currency exists in the multi-currency registry after setup
- [ ] PILA has `rate_to_brl = 1.0`
- [ ] PILA is marked as fixed-rate (excluded from automated rate updates)
- [ ] PILA has a `formatter` or `format_type` field indicating custom extenso formatting
- [ ] Listing all currencies via F18's API includes PILA
- [ ] All existing tests pass
- [ ] Unit/integration test verifies PILA seed data is present

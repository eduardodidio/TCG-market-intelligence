# F19-T05: Integrate Currency-Aware Formatting into All Price Display Points

- **Wave:** 2
- **Status:** planned
- **Depends on:** F19-T03 (frontend formatter), F19-T04 (RS flag + CurrencyIndicator)

## Description

Replace all direct calls to `formatBRL()` across the frontend with the new
`formatCurrency()` dispatcher, and add the `CurrencyIndicator` component next to
all price displays. This ensures that when the user selects PILA as their currency,
every price in the app switches to the extenso format with the RS flag.

This task requires auditing every price display point in the frontend and updating
them to be currency-aware.

## Implementation Details

Audit and update all files that call `formatBRL()`:

Known price display points (based on current codebase):
- `frontend/src/pages/Dashboard.tsx` -- collection total value KPI
- `frontend/src/pages/MyCollection.tsx` -- card prices in list, total value
- `frontend/src/pages/CollectionCardDetail.tsx` -- current price, price history chart
- `frontend/src/pages/Cards.tsx` -- card prices in list
- `frontend/src/pages/CardDetail.tsx` -- price display, chart tooltips
- `frontend/src/pages/MarketMovers.tsx` -- mover prices
- `frontend/src/components/KpiCard.tsx` -- if it formats prices internally
- `frontend/src/components/MoversTable.tsx` -- price columns
- `frontend/src/components/MoversPreview.tsx` -- price display
- `frontend/src/components/PriceChart.tsx` -- axis labels, tooltips
- `frontend/src/components/CardTile.tsx` -- card price display

Each update:
1. Import `formatCurrency` instead of (or in addition to) `formatBRL`
2. Get the active currency from the currency context/hook (from F18/F22)
3. Replace `formatBRL(value)` with `formatCurrency(value, activeCurrency)`
4. Add `<CurrencyIndicator currency={activeCurrency} />` where appropriate

## Acceptance Criteria

- [ ] Zero direct calls to `formatBRL()` remain in page/component files
  (only `format.ts` itself may reference it internally)
- [ ] All price displays use `formatCurrency()` with the active currency
- [ ] `CurrencyIndicator` appears next to prices in key locations (collection total,
  card prices, chart labels)
- [ ] Switching currency to PILA shows extenso format everywhere
- [ ] Switching currency to BRL restores R$ format everywhere
- [ ] Price charts (Recharts) correctly format axis/tooltip labels per currency
- [ ] All existing frontend tests pass
- [ ] Updated/new tests verify currency-aware rendering in at least 3 key pages

## Implementation Details

### Architecture Diagram (`docs/diagrams/F19-architecture.mmd`)

Show the currency formatting data flow:
- User preference (stored in DB via F22)
- Loaded into frontend CurrencyContext on login
- `formatCurrency()` dispatcher reads active currency
- Dispatches to `formatBRL()` or `formatPila()` based on code
- `CurrencyIndicator` reads same context for icon rendering
- Backend `format_pila()` used in API responses (if applicable)

### User Journey Diagram (`docs/diagrams/F19-journey.mmd`)

BPMN-style flow:
1. User logs in
2. System loads currency preference from profile
3. User navigates to collection/dashboard
4. Prices display in preferred currency format
5. User opens settings/currency selector
6. User selects "Pila (RS)"
7. System persists preference
8. All price displays switch to extenso format with RS flag
9. User refreshes page -- preference persists

# F19-T03: Frontend Pila Formatter (TypeScript)

- **Wave:** 1
- **Status:** planned
- **Depends on:** F19-T01 (backend formatter defines the canonical rules)

## Description

Create a TypeScript `formatPila()` function in the frontend that mirrors the backend
extenso formatter exactly. Also create a currency-aware dispatcher function
`formatCurrency()` that selects between `formatBRL()` and `formatPila()` based on the
active currency setting.

The dispatcher will be the single entry point for all price formatting across the
frontend -- replacing direct calls to `formatBRL()` in existing components.

## Implementation Details

File: `frontend/src/utils/format.ts` (extend existing file)

```typescript
// New function
export function formatPila(value: number | string | null | undefined): string

// New dispatcher (uses currency from context/preference)
export function formatCurrency(
  value: number | string | null | undefined,
  currencyCode: string  // "BRL" | "PILA" | "USD" | etc.
): string
```

Rules for `formatPila()` -- identical to backend:
- `null`/`undefined`/`NaN` -> `"--"`
- Integer part uses pt-BR thousands separator (`.`)
- "pila" (singular) when integer part == 1; "pilas" otherwise
- "centavo" (singular) when fractional == 1; "centavos" otherwise
- Omit "e N centavo(s)" when fractional == 0

`formatCurrency()` dispatcher:
- `"PILA"` -> `formatPila(value)`
- `"BRL"` -> `formatBRL(value)`
- Other codes -> delegate to F18's generic currency formatter

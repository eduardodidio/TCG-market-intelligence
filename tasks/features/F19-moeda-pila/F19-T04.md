# F19-T04: RS Flag Asset and Currency Indicator

- **Wave:** 1
- **Status:** planned
- **Depends on:** F19-T02 (PILA must be registered so the indicator knows about it)

## Description

Add the Rio Grande do Sul state flag as an SVG asset to the frontend, and update (or
create) a `CurrencyIndicator` component that displays the appropriate icon next to
formatted prices. When the active currency is PILA, it shows the RS flag; for BRL, it
shows "R$" or the Brazilian flag; for others, it delegates to F18's indicator.

## Implementation Details

1. **RS Flag SVG**: source a clean, license-compatible SVG of the RS state flag
   (Bandeira do Rio Grande do Sul). Place it in `frontend/src/assets/rs-flag.svg`.
   The flag should be optimized (small file size, no unnecessary metadata).

2. **CurrencyIndicator component**: a small inline component that renders the
   currency symbol/icon based on the currency code. This may already exist from F18;
   if so, extend it.

```tsx
interface CurrencyIndicatorProps {
  currency: string;  // "BRL" | "PILA" | "USD" | etc.
  size?: number;     // icon size in px, default 16
}
```

For PILA: render the RS flag SVG inline or as an `<img>`.
For BRL: render "R$" text or Brazilian flag (existing behavior).

## Acceptance Criteria

- [ ] `frontend/src/assets/rs-flag.svg` exists and renders correctly

- [ ] Component renders at configurable sizes (16px, 24px, etc.)

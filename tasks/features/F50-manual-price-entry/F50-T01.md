## User Story

As a collector, I want to set a manual price for a card in my collection so that I can track its value even when MYP data is unavailable.

## Dev Notes

### Price Storage Strategy

Reuse `PriceObservationRow` with `source="manual"`:
- `source`: `"manual"`
- `external_id`: `"manual_{collection_entry_id}"` (ties to specific collection entry)
- `median_price`: the user-provided price
- `currency`: `"BRL"` (always store in BRL; convert at display time)
- `observed_at`: current date
- No new tables needed — fits existing multi-source architecture

### API Endpoint (`src/api/routers/collection.py`)

`PATCH /api/v1/collection/{entry_id}/price`

Request body:
```python
class ManualPriceRequest(BaseModel):
    price: float  # in user's selected currency
    currency: str = "BRL"  # BRL/USD/PILA
```

Logic:
1. Validate entry ownership (auth required, IDOR check)
2. Convert price to BRL if currency != BRL (use CurrencyConverter)
3. Upsert `PriceObservationRow` with source="manual", external_id="manual_{entry_id}"
   - Unique constraint on (source, external_id, observed_at) prevents duplicate daily entries
   - If user sets price twice same day, update existing row
4. If entry has no `card_id`, auto-create a minimal CardRow (name/set/number) and link it
   - This ensures manual-priced cards also appear in price history
5. Return updated `CollectionCardDetail`

## User Story

As a collector, I want to see whether a card's price came from MYP or was manually entered, so I can trust the data source.

## Dev Notes

### Schema Changes (`src/api/schemas/collection.py`)

Add to `CollectionCard`:
```python
price_source: str | None = None  # "manual", "myp", "jsonld_snapshot", None
```

### Query Changes (`src/database/repository.py`)

**File collision note:** T01 also modifies this file in Wave 0 but only adds `upsert_manual_price`. This task ONLY modifies `get_latest_prices_batch` — no overlap.

Modify `get_latest_prices_batch()` (or wherever latest price is resolved):
- Return the `source` field alongside `median_price`
- When building `CollectionCard` response, populate `price_source` from the winning observation's `source`

### Priority Logic

When both manual and MYP prices exist for same date:
- Manual price wins (user explicitly set it)
- Implementation: ORDER BY observed_at DESC, CASE WHEN source='manual' THEN 0 ELSE 1 END ASC, LIMIT 1

When manual is older than MYP:
- MYP wins (more recent data)
- Standard: latest observation by date wins regardless of source

### Frontend Type (`frontend/src/types/api.ts`)

Add to `CollectionCard` interface:
```typescript
price_source?: string | null;
```

# F50-T03: Frontend Manual Price Input + Badge

**Status:** done
**Wave:** 1
**Depends on:** F50-T01, F50-T02
**Maps to AC:** AC3

## User Story

As a collector, I want to enter a manual price for a card and see a clear "Manual Price" badge so I know which prices were set by me vs fetched automatically.

## Dev Notes

### Manual Price Badge (`frontend/src/components/PriceSourceBadge.tsx`)

New component:
- `price_source === "manual"` -> amber badge: "Manual Price" / "Preco Manual"
- `price_source === "myp" | "jsonld_snapshot"` -> subtle gray/green badge: "MYP" (optional, can omit for auto)
- `price_source === null` -> no badge

Use in:
- `CollectionCardDetail.tsx` — next to price display
- `CardTile.tsx` — small indicator on tile (optional, only if manual)

### Manual Price Input (`frontend/src/pages/CollectionCardDetail.tsx`)

Add "Set Price" section on card detail page:
- Input field for price (numeric, 2 decimal places)
- Currency selector (reuse CurrencyToggle or respect user preference)
- "Save" button -> `PATCH /collection/{id}/price`
- On success: refresh card detail, show success toast
- Validation: price > 0, max reasonable value (e.g., 99999.99)

### API Client (`frontend/src/api/collection.ts`)

Add `setManualPrice(entryId: number, price: number, currency: string)`:
- `PATCH /api/v1/collection/${entryId}/price`
- Body: `{ price, currency }`

### Card Tile Indicator (`frontend/src/components/CardTile.tsx`)

When `price_source === "manual"`:
- Show small pencil icon or "M" badge next to price
- Tooltip: "Manually set price" / "Preco definido manualmente"

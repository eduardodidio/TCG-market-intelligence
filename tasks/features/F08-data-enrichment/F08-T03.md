# F08-T03: Collection expansion -- backfill popular Magic sets

**Wave:** 1
**Status:** done
**Estimate:** L (runtime-heavy, not code-heavy)

## User Story

As a data analyst, I want price data from multiple popular Magic sets beyond
DMR, so that I have enough data variety to see real market trends, compare
sets, and find meaningful price movements.

## Dev Notes

### Approach

The backfill infrastructure already supports multi-set collection. The
`run_backfill(set_filter=slug)` function in `src/collectors/backfill.py`
discovers all cards in a set, fetches their pages and price history, and
stores everything with INSERT ON CONFLICT DO NOTHING (safe to re-run).

### Sets to Collect

Select 5-8 popular/recent sets that are likely to have active price movement
on MYP Cards. Suggested sets (developer should verify slugs exist on MYP):

1. **foundations** (Foundations -- current Standard set, high activity)
2. **duskmourn-house-of-horror** (Duskmourn -- recent set)
3. **modern-horizons-3** (MH3 -- high-value Modern set)
4. **outlaws-of-thunder-junction** (OTJ -- recent Standard)
5. **murders-at-karlov-manor** (MKM -- recent Standard)
6. **the-lord-of-the-rings-tales-of-middle-earth** (LTR -- popular crossover)
7. **march-of-the-machine** (MOM -- popular set)

The developer should verify these slugs exist by checking MYP's editions page
or running `discover_sets()`.

### Execution

For each set, run the CLI backfill command:

```bash
python -m src.cli.main backfill --set <slug>
```

Or create a small shell script `scripts/expand_collection.sh` that loops
through the selected sets. This script is operational tooling, not
production code.

### Concurrency and Rate Limiting

- Existing concurrency limit (asyncio.Semaphore, default 3) applies
- Existing rate limiting (1 second delay between requests) applies
- Resume capability means interrupted runs can be restarted safely
- Expected runtime: ~10-30 minutes per set depending on card count

### No Code Changes Required

This task is purely operational -- running existing backfill code against new
sets. The only new artifact is the convenience script.

# F08-T02: Change Dashboard movers default period from 7d to 30d

**Wave:** 0
**Status:** done
**Estimate:** S

## User Story

As a dashboard user, I want the Market Movers section to show meaningful price
changes by default, so that I can see which cards are actually moving in price
without manually changing the period selector.

## Dev Notes

### Problem

The Dashboard fetches movers with `period: "7d"`, but price observations in
the database are approximately weekly. With only one data point per week, the
7-day window often compares identical prices, resulting in 0% change for every
card.

### Fix

Change the default period from `"7d"` to `"30d"` in the Dashboard page.

**File:** `frontend/src/pages/Dashboard.tsx` (line ~18)

```typescript
// BEFORE:
fetchMovers({ period: "7d", limit: "5" })

// AFTER:
fetchMovers({ period: "30d", limit: "5" })
```

### Secondary Consideration

The Market Movers full page (`frontend/src/pages/MarketMovers.tsx`) has a
period selector that defaults to `"7d"` as well. Change its default to `"30d"`
for consistency.

### Test Updates

Update any frontend tests that assert on the `period: "7d"` default:
- `frontend/tests/pages/Dashboard.test.tsx` (or similar)
- `frontend/tests/pages/MarketMovers.test.tsx` (or similar)

Search for `"7d"` across frontend test files and update assertions.

# F98-T02 -- Frontend: ScanSummaryCard Component

**Wave:** 1
**Depends on:** T01

## User Story

As a user, after a bulk refresh completes I want to see a summary card
showing how many cards were priced, how many failed, and why -- so I know
whether the scan was successful without checking logs.

## Current State

- `ScanProgressBar` has a `isDone` state that shows a one-line green
  message: "Complete! {total} cards, {prices} prices found" for 2 seconds
  before disappearing.
- The `useCollectionRefresh` hook clears all state after
  `COMPLETE_DISPLAY_MS` (2000ms).

## Dev Notes

### 1. New component `ScanSummaryCard`

File: `frontend/src/components/ScanSummaryCard.tsx`

Props interface:

```typescript
export interface ScanSummary {
  cardsTotal: number;
  cardsProcessed: number;
  cardsFailed: number;
  observationsSaved: number;    // "priced" count
  notFoundCount: number;
  rateLimitedCount: number;
  durationMs: number;           // elapsed time
}

interface ScanSummaryCardProps {
  summary: ScanSummary;
  onDismiss: () => void;
}
```

Layout (dark theme, slate-800 surface):

- Header row: checkmark icon + "Scan Complete" (or warning icon if
  `cardsFailed > 0`)
- Stat grid (2x2 or 3-column):
  - "Priced" (emerald) -- `observationsSaved` / `cardsTotal`
  - "Not Found" (amber) -- `notFoundCount` (only if > 0)
  - "Rate Limited" (red) -- `rateLimitedCount` (only if > 0)
  - "Other Errors" (slate) -- `cardsFailed - notFoundCount - rateLimitedCount`
    (only if > 0)
- Footer: duration ("Completed in 2m 34s") + dismiss button (X icon)
- The card persists until the user clicks dismiss.

### 2. Update `ScanProgressBar`

Replace the `isDone` block in `ScanProgressBar` with a render slot or
callback. The parent (MyCollection page) will render `ScanSummaryCard`
when `isDone` is true, so `ScanProgressBar` should return `null` when
`isDone` and not `isRefreshing`.

Alternatively, keep `ScanProgressBar` focused on the in-progress state and
let the parent conditionally render either `ScanProgressBar` (during scan)
or `ScanSummaryCard` (after scan). This is cleaner separation.

### 3. Wire into MyCollection page

The MyCollection page (or whichever page renders the refresh button and
`ScanProgressBar`) should:

1. Render `ScanSummaryCard` when `isDone && summary !== null`.
2. Pass an `onDismiss` callback that clears the summary state.

## Testing

File: `frontend/tests/components/ScanSummaryCard.test.tsx`

1. `renders all stat counts` -- full summary with all counts > 0 shows
   priced, not found, rate limited, other errors.
2. `hides zero-count categories` -- summary with `notFoundCount=0` does
   not render the "Not Found" stat.
3. `dismiss button clears card` -- clicking X calls `onDismiss`.
4. `shows warning icon when failures exist` -- `cardsFailed > 0` renders
   warning icon instead of checkmark.
5. `shows success icon when no failures` -- `cardsFailed === 0` renders
   checkmark.
6. `formats duration correctly` -- 154000ms displays as "2m 34s".
7. `card persists until dismissed` -- no auto-timeout; card remains in DOM.

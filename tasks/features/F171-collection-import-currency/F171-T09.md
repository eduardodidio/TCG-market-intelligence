## User Story

As a user adding cards by text with a price, I want the price stored in BRL (converted when typed in USD), so that batch-added cards join my P&L correctly.

## Objective

Carry `price`/`price_currency` from the parser through the batch API into `batch_add_entries`, converting to BRL.

## Implementation details

- Dataclass `BatchAddEntry` gets `acquisition_price: Decimal | None = None` and `price_currency: str | None = None`. `BatchAddResult` gets `warnings: list[str] = field(default_factory=list)`.
- `batch_add_entries(..., rate_lookup: RateLookup | None = None, today: date | None = None)`. Convert before creating the `UserCollectionRow`.
- The pydantic `BatchAddEntry` gets `acquisition_price: Decimal | None = Field(default=None, ge=0, le=1_000_000)` and `price_currency: Literal["BRL","USD"] | None = None`.
- `ParsedLineResponse` gets `price: str | None = None` and `price_currency: str | None = None`. `BatchAddResultResponse` gets `warnings: list[str] = []`.
- Router: map the new fields and pass `rate_lookup_from_converter(converter)`.

## Acceptance criteria

- [ ] POST `/collection/batch/parse` with `Sol Ring US$3.10` returns `price "3.10"`, `price_currency "USD"`
- [ ] POST `/collection/batch` with `acquisition_price 3.10 USD`, rate 5.00 → stored `15.50`
- [ ] BRL or None currency → stored unchanged
- [ ] No rate → the row is added, price None, and a warning is returned
- [ ] Old payloads without the new fields behave as before

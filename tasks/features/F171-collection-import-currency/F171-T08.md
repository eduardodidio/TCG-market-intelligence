## User Story

As a user importing purchase history that contains USD prices, I want the preview to show the BRL value applied and the original value, so that the acquisition price saved is in BRL.

## Objective

In `import_preview`, convert every parsed item's `unit_price` to BRL via `to_brl` with the order-date rate, and expose the original currency and value.

## Implementation details

- Helper `_convert_item(item, rate_lookup) -> tuple[str | None, dict]` returning the BRL price string and the extra fields
  `original_unit_price`, `original_currency`, `exchange_rate`.
- When `brl is None` (no rate or unsupported): exclude the item from `matches`, put it in `unmatched` with `reason="currency_conversion_failed"`, and append a warning.
- Tests `tests/api/test_purchases_currency.py`: TestClient + `app.dependency_overrides` as in `tests/api/test_import_purchases.py`. Patch `CurrencyConverter.get_display_rate` to return `Decimal("5.00")` / None.

## Acceptance criteria

- [ ] A USD item `3.10` with rate 5.00 → `unit_price == "15.50"`, `original_currency == "USD"`, `original_unit_price == "3.10"`
- [ ] BRL items are unchanged, with `original_currency == "BRL"` and `exchange_rate` None
- [ ] No rate → the item is not offered for apply, and a warning is present
- [ ] Existing purchase tests pass

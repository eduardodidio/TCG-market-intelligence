## User Story

As a user importing purchase history with USD items, I want to see the original USD value next to the BRL value, so that I trust the conversion before applying it.

## Objective

Render a `US$ x → R$ y` badge for preview rows whose `original_currency` is not BRL.

- `unmatched` rows with `reason === "currency_conversion_failed"` show the reason text.

## User Story

As the operator running local imports on Windows (`bats/*.bat` → `python -m src.cli.main`), I want `import-csv` to detect or accept the file currency, so that CLI imports store BRL correctly.

## Objective

Add a `--currency auto|BRL|USD` option. The dry run uses `import_collection_csv(..., dry_run=True)` and prints the detection. The real run passes the currency and a DB-backed rate lookup.

## Implementation details

- `@click.option("--currency", type=click.Choice(["auto","BRL","USD"], case_sensitive=False), default="auto")`. Upper-case the value before use.
- Dry-run output adds the lines `Currency:`, `Source:`, `Confidence:`, `Priced rows:`.
- Summary output adds `Priced:`, `Converted USD->BRL:`, `Rate:`, and up to 5 warnings.

## Acceptance criteria

- [ ] `import-csv --file tests/fixtures/collection_import/generic_usd_symbol.csv --user-id u --dry-run` prints `Currency: USD`
- [ ] `--currency BRL` is honored in the dry run
- [ ] An invalid `--currency EUR` → click usage error (exit code 2)
- [ ] The real import (with `input="y\n"`) stores converted values (sqlite tmp DB + a seeded exchange rate row, or a patched `CurrencyConverter.get_display_rate`)

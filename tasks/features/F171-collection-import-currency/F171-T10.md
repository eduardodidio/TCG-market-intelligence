## User Story

As a user importing a CSV from the web app, I want to preview the detected currency and choose BRL/USD, so that I confirm the currency before the collection is replaced.

## Objective

Expose the importer's new `currency` and `dry_run` options on the existing endpoint and extend `ImportResult`.

## Implementation details

- Signature adds `currency: str = Query(default="auto", pattern="^(auto|BRL|USD)$")`, `dry_run: bool = Query(default=False)`, `converter: CurrencyConverter = Depends(get_currency_converter_dep)`.
- Pass `currency=`, `dry_run=`, and `rate_lookup=rate_lookup_from_converter(converter)` to `import_collection_csv`.
- Map the new result keys into `ImportResult`. `exchange_rate` is a string.
- Tests `tests/api/test_collection_import_currency.py`: upload the T01 fixtures via TestClient multipart. Override `get_currency_converter_dep` with a stub whose `get_display_rate` returns `Decimal("5.40")`.

## User Story

As a user importing an export from Liga, ManaBox, or a spreadsheet, I want the importer to recognize the columns and the file's currency, so that my BRL prices are not read as USD.

## Objective

Implement `resolve_columns` (alias table + origin + header currency) and `detect_file_currency` (precedence chain) as pure functions.

## Dev Notes

Veja `_brief/00-overview.md`, `_brief/01-money-parsing.md` and `_brief/03-csv-import.md`.

- Current hardcoded Liga headers live in `src/collection/importer.py` (L49–L64). Your alias table must include them verbatim.
- Uses `detect_symbol`, `number_format_hint` from `src/currency/money.py` (T02) and types from `src/currency/types.py` (T01).
- Accent-insensitive compare: `unicodedata.normalize("NFKD", s).encode("ascii","ignore").decode().strip().lower()`.
- Price header detection must **not** match unrelated headers such as `Price source`. Match only the explicit aliases
  plus headers whose normalized form starts with `price`, `purchase price`, `preco`, or `valor`, and that
  are not the currency column.
- Pattern to follow: static table + heuristic fallback (project learning F15).

- Follow CLAUDE.md: no new dependencies, validate input at boundaries, no secrets, stage files one by one
  (never `git add -A`), never commit to `main`.
- `acquisition_price` is **always BRL**. Never store a USD amount as BRL.

## Implementation details

- `src/collection/csv_columns.py`: `FIELD_ALIASES: dict[str, tuple[str, ...]]`, `ColumnMap`, `resolve_columns`, `detect_file_currency`, helper `_header_currency(header) -> SupportedCurrency | None` (`(R$)`, `(BRL)`, `(US$)`, `(USD)`, `[BRL]`).
- `detect_file_currency` samples at most 200 non-empty price cells. It returns `CurrencyDetection` with `evidence` such as `"column: 12 BRL"`, `"symbol: 3 R$"`, `"origin: liga"`.
- `tests/collection/test_csv_columns.py` uses the T01 fixtures (read with `csv.DictReader`; the cp1252 one with `encoding="cp1252"`).

## Test scenarios

- Happy: each of the 7 fixtures → expected (currency, source) (parametrize).
- Edge: headers with BOM `\ufeff` on the first column; extra spaces; upper-case `PREÇO`; the price column exists but all cells are empty → fall through to origin/default.
- Mixed: 3 `R$` + 1 `US$` → BRL, confidence low, evidence mentions "mixed".
- Error: empty header list → `ColumnMap(fields={}, origin="generic")`, no exception. A currency column with only `EUR` → unsupported_symbols has `EUR` and falls through.
- Boundary: 250 price rows → only 200 sampled (assert through evidence counts).

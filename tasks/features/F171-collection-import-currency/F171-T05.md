## User Story

As a user importing Liga/Nerdz purchase history, I want prices parsed in the right format and currency, so that a `US$` or dot-decimal price does not become 0 or 100 times too large.

## Objective

Make `parse_brl_price` a wrapper over `parse_money(hint='BRL')`, add `parse_price_with_currency`, and add `ParsedPurchaseItem.currency`.

## Implementation details

- `parse_brl_price(text) -> Decimal`: `amount, _ = parse_money(text, hint="BRL")`, return `amount if amount is not None else Decimal("0")`.
- `parse_price_with_currency(text) -> tuple[Decimal, str]`: `(amount or 0, symbol or "BRL")`, with `EUR` passed through.
- Replace the 3 call sites so each item gets `currency=`.

## User Story

As a user importing my collection CSV, I want to see which currency was detected and override it, so that a BRL export is never saved as USD by mistake.

## Objective

Add dry-run detection on file selection, an Auto/BRL/USD selector, a low-confidence warning, and priced/converted counts on success. This task is the sole owner of the F171 i18n keys.

## Implementation details

- On file change → `setState("detecting")` → `importCollectionCsv(file, { dryRun: true })` → store `detection` → `setState("detected")`. On error → `idle` with the selector still available.
- `<select data-testid="csv-currency-select">` with options `auto` (label shows the detected value), `BRL`, `USD`.
- `data-testid="csv-currency-detected"` and `csv-currency-warning` (shown when `currency_source==="default"` or `currency_confidence==="low"`).
- Import → `importCollectionCsv(file, { currency })`. The success screen shows `priced`, `converted`, the rate, and the first 5 `price_warnings`.
- Create `frontend/src/components/__tests__/CsvImportModal.test.tsx`.

## Test scenarios

- Happy: dry-run BRL/symbol → shows "BRL", import with `auto` → success with counts.
- Override: select USD → the import mock was called with `{ currency: "USD" }`.
- Edge: `currency_source "default"` → warning visible; the user selects a new file → detection resets.
- Error: dry-run rejects → the selector is still usable and import is still possible; import returns `errors` → error state.
- Boundary: `price_warnings` with 8 items → only 5 rendered; `converted 0` → the rate line is hidden.

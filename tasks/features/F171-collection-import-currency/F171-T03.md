## User Story

As a collector importing a USD-priced export, I want the values converted to BRL with the PTAX rate, so that my portfolio and P&L, which assume BRL storage, are correct.

## Objective

Implement `to_brl` + `ConversionResult` + `rate_lookup_from_converter` in `src/currency/import_conversion.py`.

## Implementation details

- `RateLookup = Callable[[date], Decimal | None]`
- `@dataclass ConversionResult` (fields as in the shard)
- `to_brl(amount, currency, on_date, rate_lookup)`: normalize currency via `.upper().strip()`. BRL → identity.
  USD → `(amount * rate).quantize(Decimal("0.01"), ROUND_HALF_UP)`. USD without rate → `brl=None, warning="no_rate"`.
  Others → `brl=None, warning="unsupported_currency"`. `rate <= 0` is treated as no rate.
- `rate_lookup_from_converter(converter)`
- `tests/currency/test_import_conversion.py`

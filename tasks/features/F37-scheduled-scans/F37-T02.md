
Run `pip install -e .` to verify installation.

## Dev Notes

- APScheduler 3.x is chosen over 4.x (alpha) for stability.
- `croniter` is used for cron expression validation and next-run calculation.
- APScheduler 3.x already depends on `pytz` and `six` -- both lightweight.
- The `SQLAlchemyJobStore` from APScheduler uses SQLAlchemy, already in our deps.

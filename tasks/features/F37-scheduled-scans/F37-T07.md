# F37-T07: FastAPI Lifespan Integration

- **Wave:** 3
- **Type:** backend
- **Depends on:** T04
- **Status:** planned

## Objective

Integrate the `ScanScheduler` with FastAPI's application lifecycle so it
starts on server boot and stops on shutdown. Mount the schedules router.

## Implementation Details

### File: `src/api/app.py`

1. **Add lifespan context manager** using FastAPI's `lifespan` parameter:

```python
from contextlib import asynccontextmanager

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup
    from src.scheduler.service import ScanScheduler
    db_url = os.environ.get("TCG_DATABASE_URL", "sqlite:///tcg_market.db")
    scheduler = ScanScheduler(db_url)
    scheduler.start()
    app.state.scheduler = scheduler
    yield
    # Shutdown
    scheduler.shutdown()
```

2. **Pass lifespan to FastAPI constructor**:

```python
app = FastAPI(
    title="TCG Market Intelligence API",
    version="0.1.0",
    lifespan=lifespan,
    ...
)
```

3. **Mount the schedules router**:

```python
from src.api.routers.schedules import router as schedules_router
app.include_router(schedules_router, prefix="/api/v1")
```

### Dev notes

- The existing `create_app` function uses a factory pattern with
  `uvicorn.run("src.api.app:create_app", factory=True)`. The lifespan
  parameter works seamlessly with this pattern.
- `app.state.scheduler` is accessed by the schedules router via
  `request.app.state.scheduler`.
- If `TCG_SCHEDULER_DISABLED=1` env var is set, skip scheduler startup
  (useful for testing, CI).

### File: `src/scheduler/service.py`

```python
class ScanScheduler:
    """Manages APScheduler lifecycle for automated price scans.

    Uses BackgroundScheduler (threading-based) with SQLAlchemyJobStore
    for persistence. Each schedule maps to an APScheduler CronTrigger job.
    """

    def __init__(self, db_url: str):
        self._db_url = db_url
        self._scheduler: BackgroundScheduler | None = None

    def start(self) -> None:
        """Initialize APScheduler, load active schedules from DB, start."""

    def shutdown(self) -> None:
        """Gracefully stop the scheduler."""

    def add_schedule(self, schedule_id: int) -> None:
        """Read schedule from DB, create APScheduler job with CronTrigger."""

    def remove_schedule(self, schedule_id: int) -> None:
        """Remove APScheduler job for given schedule."""

    def pause_schedule(self, schedule_id: int) -> None:
        """Pause an APScheduler job."""

    def resume_schedule(self, schedule_id: int) -> None:
        """Resume a paused APScheduler job."""

    def trigger_now(self, schedule_id: int) -> int:
        """Manually trigger a schedule immediately. Returns scan_run ID."""

    def _execute_scheduled_scan(self, schedule_id: int) -> None:
        """Callback executed by APScheduler. Runs scan, updates schedule metadata."""
```

### Key behaviors

1. **`start()`**: Creates `BackgroundScheduler`, loads all active schedules
   from `repository.get_active_schedules()`, registers each as a CronTrigger
   job, starts the scheduler.

2. **`_execute_scheduled_scan()`**: The job callback function.
   - Reads the schedule from DB to get filters
   - Checks if a scan is already running for this schedule (skip if so)
   - Creates a `ScanFilter` from `filters_json`
   - Calls `run_scan()` in a new asyncio event loop (same pattern as
     `scans.py` router)
   - On success: updates `last_run_id`, `last_run_at`, resets `error_count`
   - On failure: increments `error_count`, auto-pauses if `error_count >= max_retries`
   - Updates `next_run_at` from the CronTrigger's next fire time

3. **Cron validation**: Use `croniter.is_valid(expr)` to validate expressions.
   Reject sub-hour intervals by checking that the minute field is not `*` or
   `*/N` where N < 60.

4. **Concurrency guard**: Before executing, check if the schedule's `last_run_id`
   points to a still-running scan. If so, skip this execution and log a warning.

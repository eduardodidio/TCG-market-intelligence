# F37-T08: Frontend Schedules Page

- **Wave:** 4
- **Type:** frontend
- **Depends on:** T05
- **Status:** planned

## Objective

Create the frontend schedule management page: API client, schedule list table,
create/edit form, and route integration.

## Implementation Details

### File: `frontend/src/api/schedules.ts`

API client functions using `apiGet`, `apiPost`, `apiPatch`, `apiDelete` from
`client.ts`:

```typescript
fetchSchedules(params?)  -> ScheduleListResponse
fetchSchedule(id)        -> ScheduleResponse
createSchedule(body)     -> ScheduleResponse
updateSchedule(id, body) -> ScheduleResponse
deleteSchedule(id)       -> void
triggerSchedule(id)      -> ScheduleTriggerResponse
```

### File: `frontend/src/types/api.ts` (extend)

Add TypeScript interfaces:

```typescript
interface ScheduleResponse { id, name, description, cron_expression, ... }
interface ScheduleListResponse { schedules, total }
interface ScheduleCreateRequest { name, cron_expression, scan_type, ... }
interface ScheduleTriggerResponse { schedule_id, scan_id, status }
```

### File: `frontend/src/pages/Schedules.tsx`

Main page layout:

1. **Header**: "Scheduled Scans" title + "New Schedule" button
2. **Schedule table** (`ScheduleTable` component):
   - Columns: Name, Cron, Status (badge), Last Run (relative time), Next Run,
     Errors, Actions (pause/resume, trigger, edit, delete)
   - Status badges: green=active, yellow=paused, red=disabled
   - Error count shows `N/max` format, red if at max
3. **Create/Edit modal** (`ScheduleForm` component):
   - Fields: Name, Description, Cron Expression (with helper text showing
     common presets like "Daily 6am", "Every 12h", "Weekly Monday"),
     Scan Type dropdown, Filters JSON textarea, Max Retries
   - Cron presets as clickable chips: `0 6 * * *`, `0 */12 * * *`,
     `0 3 * * 1`, `0 0 1 * *`
   - Validation: name required, cron required + basic format check

### File: `frontend/src/components/ScheduleTable.tsx`

Reusable table component. Actions column has icon buttons:
- Play/Pause toggle (PATCH status)
- Lightning bolt = trigger now (POST trigger)
- Pencil = edit (opens modal)
- Trash = delete (with confirmation)

### File: `frontend/src/components/ScheduleForm.tsx`

Modal form for create/edit. Reuses the project's existing modal patterns
(if any) or uses a simple overlay div.

### File: `frontend/src/App.tsx` (extend)

Add route: `<Route path="/schedules" element={<Schedules />} />`
Wrap in `ProtectedRoute` (auth required).

### Styling

Follow existing Tailwind slate dark theme patterns. Use cyan-400 for active
badges, amber-400 for paused, red-400 for disabled/error states.

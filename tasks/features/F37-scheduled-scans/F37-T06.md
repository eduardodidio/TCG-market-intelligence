# F37-T06: CLI Commands for Schedule Management

- **Wave:** 3
- **Type:** backend
- **Depends on:** T04
- **Status:** planned

## Objective

Add `schedule-list`, `schedule-add`, and `schedule-remove` CLI commands to
`src/cli/main.py` for managing scheduled scans from the command line.

## Implementation Details

### File: `src/cli/main.py`

#### `schedule-list`

```
tcg schedule-list [--db URL] [--status active|paused|disabled]
```

Lists all schedules in a table format:

```
  ID  Name              Cron          Status   Last Run   Next Run    Errors
  1   Daily Collection  0 6 * * *     active   08:00      06:00+1d    0
  2   Weekly Sets       0 3 * * 1     paused   -          -           3/3
```

#### `schedule-add`

```
tcg schedule-add --name "Daily Collection" --cron "0 6 * * *" [--type collection] [--filters '{}'] [--description "..."] [--max-retries 3] [--db URL]
```

Validates cron expression, inserts into DB, prints confirmation.
Does NOT register with APScheduler (that happens on server start).

#### `schedule-remove`

```
tcg schedule-remove SCHEDULE_ID [--db URL]
```

Deletes the schedule from DB. Prints confirmation or error if not found.
Does NOT interact with APScheduler (schedule will be absent on next server start).

### Dev notes

- CLI commands operate directly on the DB, not via the API. This is intentional --
  the CLI works even when the server is not running.
- APScheduler picks up DB changes on next server start. For live changes while
  the server is running, use the API.
- Validate cron expression with `croniter.is_valid()` in `schedule-add`.

## Acceptance Criteria

# F53-T02 — GauchoDialog Component

**Status:** planned
**Wave:** 0
**Estimate:** medium

## User Story

As a user who clicked the chimarrao icon, I want to see a gaucho-themed
dialogue bubble with clickable response options and replies, so I can
enjoy the cultural easter egg interaction.

## Dev Notes

### What to build

**`frontend/src/components/GauchoDialog.tsx`:**

Props:
```typescript
interface GauchoDialogProps {
  message: string;           // Main dialogue text
  options?: GauchoOption[];  // Clickable response options
  autoDismissMs?: number;    // Auto-dismiss timeout (for no-option dialogues)
  onDismiss: () => void;     // Called when interaction completes
}

interface GauchoOption {
  label: string;    // Button text
  reply?: string;   // Response shown after clicking (if any)
}
```

### UI Design

1. **Dialogue bubble**: positioned above the chimarrao icon (bottom-right)
   - Background: `bg-slate-800/95 backdrop-blur` (glass-morphism)
   - Border: `border border-green-600/40 rounded-xl`
   - Shadow: `shadow-xl`
   - Max width: `max-w-sm`
   - Speech bubble tail pointing down-right toward the icon

2. **States**:
   - **Initial**: Shows `message` text + option buttons
   - **After click**: Shows the `reply` text for 2.5 seconds, then calls
     `onDismiss()`
   - **Auto-dismiss**: If no options, show message for `autoDismissMs`
     (default 4000ms), then call `onDismiss()`

3. **Option buttons**:
   - Styled as pill buttons: `px-4 py-2 rounded-full bg-green-700/60
     hover:bg-green-600 text-white text-sm transition-colors`
   - Laid out horizontally if 2 options, centered if 1

4. **Entry/exit animation**:
   - Fade in + slide up on mount
   - Fade out on dismiss

5. **Close button**: small X in top-right corner to dismiss without
   interacting

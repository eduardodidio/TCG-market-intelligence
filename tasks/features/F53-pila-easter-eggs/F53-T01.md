# F53-T01 — ChimarraoIcon Component with Pulse Animation

**Status:** planned
**Wave:** 0
**Estimate:** small

## User Story

As a user with PILA currency selected, I want to see a small pulsing
chimarrao (mate) icon in the bottom-right corner of the screen, so I
discover the gaucho easter egg interaction.

## Dev Notes

### What to build

**`frontend/src/components/ChimarraoIcon.tsx`:**
- Fixed position: `fixed bottom-6 right-6 z-50`
- Size: 48x48px clickable area, icon ~32px
- Icon: inline SVG of a chimarrao/mate cup (simple silhouette)
  - Alternative: use a text emoji (🧉) with custom styling
- Animation: `animate-pulse` from Tailwind (gentle glow effect)
  - Add a subtle green glow: `shadow-lg shadow-green-500/30`
- Only visible when `currency === "PILA"` (from `useCurrency()` hook)
- `onClick` prop: triggers the dialogue opening
- Cursor: `cursor-pointer`
- Hover: slight scale-up (`hover:scale-110 transition-transform`)

### Conditional rendering

The icon should be rendered in `Layout.tsx` (after the main content area),
wrapped in a condition:

```tsx
{currency === "PILA" && !dialogDismissed && (
  <ChimarraoIcon onClick={() => setShowDialog(true)} />
)}
```

The state management (dialogDismissed, showDialog) will be handled in
F53-T03 when integrating into pages.

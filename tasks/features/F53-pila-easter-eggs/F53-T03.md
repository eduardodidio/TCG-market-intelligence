# F53-T03 — Page Integration + Dialogue Data + i18n

**Status:** planned
**Wave:** 1
**Estimate:** medium

## User Story

As a user navigating different pages with PILA currency, I want each page
to have its own gaucho dialogue when I click the chimarrao icon, so the
easter egg feels contextual and fresh on each page.

## Dev Notes

### What to build

**`frontend/src/hooks/useGauchoEasterEgg.ts`:**

Custom hook that manages the easter egg state per page:

```typescript
function useGauchoEasterEgg(pagePath: string, context?: { isEmpty?: boolean }) {
  // Returns: { showIcon, showDialog, dialogData, openDialog, dismissDialog }
  // - Tracks which pages have been dismissed (sessionStorage)
  // - Resets on page navigation (new page = new opportunity)
  // - Returns null dialogData if page has no dialogue configured
}
```

Key behaviors:
- Icon appears after 2-second delay on page load (subtle entrance)
- Once dismissed on a page, stays dismissed for that session
  (use `sessionStorage` key: `gaucho_dismissed_{pagePath}`)
- Reappears on next session or different page
- For `/decks`: checks `context.isEmpty` to pick correct dialogue variant

**Page integration — `frontend/src/components/Layout.tsx`:**

```tsx
const { showIcon, showDialog, dialogData, openDialog, dismissDialog } =
  useGauchoEasterEgg(location.pathname, { isEmpty: /* from context */ });

// At the end of Layout, after </main>:
{showIcon && <ChimarraoIcon onClick={openDialog} />}
{showDialog && dialogData && (
  <GauchoDialog
    message={t(dialogData.message)}
    options={dialogData.options?.map(o => ({
      label: t(o.label),
      reply: o.reply ? t(o.reply) : undefined
    }))}
    autoDismissMs={dialogData.autoDismissMs}
    onDismiss={dismissDialog}
  />
)}
```

**Deck empty/non-empty detection:**
- Layout doesn't know if decks are empty. Options:
  1. Pass via URL search param (bad UX)
  2. Use a lightweight API call in the hook (overkill)
  3. **Best**: Let DeckList page expose a context or render the
     chimarrao/dialog itself with the correct variant
  4. **Simplest**: In Layout, default to "decks with data" variant.
     Override in DeckList by rendering its own GauchoDialog when empty.
     Use a `GauchoOverride` context or simply render in DeckList directly.

→ Go with option 4: Layout handles all pages except decks-empty.
  DeckList renders the empty variant directly when `decks.length === 0`.

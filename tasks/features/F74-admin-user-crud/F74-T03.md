# F74-T03 — Frontend: Create User + Delete + Password Change Flow

**Status:** planned
**Wave:** 1
**Depends on:** F74-T01, F74-T02

## User Story

As an admin, I want a form to create users and a button to delete them in the admin panel. As a user with expired password, I want to see a password change form after login.

## Dev Notes

### Files to modify

1. **`frontend/src/api/admin.ts`** — Add:
   ```typescript
   export async function createUser(email: string, displayName?: string): Promise<ApiResponse<CreateUserResponse>>
   export async function deleteUser(userId: number): Promise<ApiResponse<null>>

   interface CreateUserResponse {
     user_id: number;
     email: string;
     display_name: string | null;
     temporary_password: string;
   }
   ```

2. **`frontend/src/pages/AdminPanel.tsx`** — Add to Users section:
   - **CreateUserForm** (inline component or separate file):
     - Toggle button "Create User" → shows form with email + display_name inputs
     - On submit, calls `createUser()`
     - On success, shows the temporary password in a highlighted box (copy-friendly, monospace)
     - Warning text: "This password will only be shown once. The user must change it on first login."
     - Refresh user list after creation
   - **Delete button** per user row:
     - Red trash icon/button in actions column (next to Adjust Credits)
     - Confirmation dialog before delete
     - Cannot show delete for self (admin's own row)
     - On success, refresh user list

3. **`frontend/src/pages/ChangePassword.tsx`** (NEW):
   - Shown when login returns `password_expired: true`
   - Form: current password (pre-filled conceptually — user just used it), new password, confirm password
   - Calls POST /auth/change-password
   - On success, stores new tokens and redirects to home

4. **`frontend/src/contexts/AuthContext.tsx`** (MODIFY):
   - Handle `password_expired` flag from login response
   - If expired, redirect to /change-password instead of home
   - Store temporary token for the change-password call

5. **`frontend/src/App.tsx`** — Add route `/change-password` → ChangePassword page

### i18n keys needed (~15)
- `admin.createUser`, `admin.createUserBtn`, `admin.emailLabel`, `admin.displayNameLabel`
- `admin.temporaryPassword`, `admin.passwordWarning`, `admin.deleteUser`, `admin.deleteConfirm`
- `admin.cannotDeleteSelf`, `admin.userCreated`, `admin.userDeleted`
- `auth.passwordExpired`, `auth.changePassword`, `auth.newPassword`, `auth.confirmPassword`, `auth.currentPassword`

## Testing

- Create user form renders and submits
- Temporary password displayed after creation
- Delete button hidden for self
- Delete confirmation dialog works
- Password change form validates matching passwords
- Password change redirects to home on success
- Login with expired password redirects to change-password

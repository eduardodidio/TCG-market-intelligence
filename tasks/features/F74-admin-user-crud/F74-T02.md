# F74-T02 — Backend: Login Password Expiration + Force-Change

**Status:** planned
**Wave:** 1
**Depends on:** F74-T01

## User Story

As a user created by admin, when I login with the temporary password, I want to be prompted to set a new password before I can use the platform.

## Dev Notes

### Files to modify

1. **`src/api/routers/auth.py`** — Modify login endpoint:
   ```python
   @router.post("/login")
   def login(body: LoginRequest, ...):
       # ... existing email/password verification ...

       # Check password expiration
       if user.password_expires_at and user.password_expires_at <= datetime.now():
           # Return limited token + password_expired flag
           # The access token should be short-lived (5 min) and marked as "password_change_only"
           temp_token = create_access_token(user.id, user.email, expires_minutes=5)
           return success_response(data={
               "access_token": temp_token,
               "refresh_token": None,
               "password_expired": True,
           })

       # ... existing normal login flow ...
   ```

2. **`src/api/routers/auth.py`** — Add password change endpoint:
   ```python
   @router.post("/change-password")
   def change_password(body: ChangePasswordRequest, user = Depends(get_current_user), repo = Depends(get_db)):
       # Verify current password
       db_user = repo.get_user_by_id(user.id)
       if not verify_password(body.current_password, db_user.password_hash):
           raise HTTPException(400, "Current password is incorrect")
       # Hash new password
       new_hash = hash_password(body.new_password)
       # Update user: clear expiration
       repo.update_user(user.id, password_hash=new_hash, password_expires_at=None)
       # Issue full tokens
       tokens = AuthTokens(
           access_token=create_access_token(user.id, user.email),
           refresh_token=create_refresh_token(user.id),
       )
       return success_response(data=tokens)
   ```

3. **`src/api/schemas/auth.py`** — Add:
   ```python
   class ChangePasswordRequest(BaseModel):
       current_password: str
       new_password: str  # min length 8 via Field(min_length=8)
   ```

4. **`src/auth/jwt.py`** — Modify `create_access_token` to accept optional `expires_minutes` param

### Key decisions
- Expired password login returns tokens BUT with `password_expired: True` flag
- Access token is short-lived (5 min) — just enough to call /change-password
- No refresh token on expired password login
- After password change, full tokens are issued and `password_expires_at` cleared to None

## Testing

- Login with expired password returns password_expired=True
- Login with expired password returns short-lived token
- Login with non-expired password works normally
- /change-password with correct current password succeeds
- /change-password clears password_expires_at
- /change-password with wrong current password fails (400)
- /change-password issues full tokens
- New password min length enforced

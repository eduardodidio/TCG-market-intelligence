**Status:** planned
**Wave:** 1

## User Story

As a deployer, I want CORS and API URL configured for production (same-origin serving), so the frontend works correctly on Render.

## Dev Notes

1. CORS already supports `TCG_CORS_ORIGINS` env var — verify it works with Render URL
2. When serving frontend from same origin, CORS is less critical but still needed for:
   - Dev mode (localhost:5173 → localhost:8000)
   - Any future CDN/subdomain setup
3. Update `.env.example` with production env vars:
   - `TCG_CORS_ORIGINS=https://your-app.onrender.com`
   - `TCG_JWT_SECRET=<generate-strong-secret>`
   - `TCG_ENV=production`
   - `TCG_DATABASE_URL=sqlite:////data/tcg_market.db`
   - `TCG_LIGA_DISABLED=1`
4. Frontend: `VITE_API_BASE_URL` should be empty for same-origin (already default)
5. Verify `TCG_CORS_ORIGINS` parsing handles single value without comma

### Files to modify

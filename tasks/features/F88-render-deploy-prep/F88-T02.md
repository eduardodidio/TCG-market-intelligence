# F88-T02: Production Uvicorn Config

**Status:** planned
**Wave:** 0
**Depends on:** —

## User Story

As a deployer, I want uvicorn to run in production mode (no reload, configurable workers, $PORT from env), so that the API performs well on Render.

## Dev Notes

1. Modify `src/api/app.py:run_server()` to accept a `production` flag:
   - `reload=False` in production
   - Bind to `$PORT` env var (Render sets this dynamically)
   - Optional: `workers` param (default 1 for SQLite, which doesn't support concurrent writers well)
2. Update `src/cli/main.py` serve command:
   - Add `--production` flag (disables reload, uses $PORT if set)
3. Keep backward compat: `python -m src.cli.main serve` still works for local dev

### Files to modify
- `src/api/app.py` — `run_server()` production mode
- `src/cli/main.py` — `--production` flag on serve command

### Acceptance Criteria
- [ ] `serve --production` starts without reload
- [ ] $PORT env var is respected when set
- [ ] Default behavior unchanged for local dev

## Testing

- Unit: test that `run_server(production=True)` passes correct args
- Manual: `PORT=8080 python -m src.cli.main serve --production` binds to 8080

# F88-T04: Frontend Static Serving via FastAPI

**Status:** planned
**Wave:** 1
**Depends on:** —

## User Story

As a deployer, I want FastAPI to serve the Vite-built frontend as static files, so that a single Render service handles both API and SPA.

## Dev Notes

1. Add `StaticFiles` mount in `create_app()` for `frontend/dist/`:
   - Mount at `/assets` for Vite's hashed assets (JS, CSS, images)
   - Catch-all route for SPA: serve `index.html` for any non-API, non-static path
2. Only mount if `frontend/dist/` directory exists (skip in dev/test)
3. SPA catch-all must NOT intercept `/api/*`, `/health`, `/docs`, `/redoc`
4. Update `frontend/vite.config.ts`:
   - Set `base: '/'` explicitly (default but good to be explicit)
5. Frontend `VITE_API_BASE_URL` should be empty string in production (same-origin)

### Implementation approach
```python
import os
from pathlib import Path
from fastapi.staticfiles import StaticFiles
from fastapi.responses import FileResponse

FRONTEND_DIR = Path(__file__).parent.parent.parent / "frontend" / "dist"

# In create_app(), after all routers:
if FRONTEND_DIR.is_dir():
    app.mount("/assets", StaticFiles(directory=FRONTEND_DIR / "assets"), name="static")

    @app.get("/{path:path}")
    async def serve_spa(path: str):
        file_path = FRONTEND_DIR / path
        if file_path.is_file():
            return FileResponse(file_path)
        return FileResponse(FRONTEND_DIR / "index.html")
```

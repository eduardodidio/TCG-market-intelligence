# F88-T07: render.yaml + Build Script

**Status:** planned
**Wave:** 2
**Depends on:** T06

## User Story

As a deployer, I want a render.yaml (Blueprint) so Render auto-configures the web service, persistent disk, and env vars on first deploy.

## Dev Notes

### render.yaml

```yaml
services:
  - type: web
    name: tedhc-market
    runtime: docker
    plan: free  # or starter
    region: oregon
    branch: main
    dockerfilePath: ./Dockerfile
    healthCheckPath: /health
    envVars:
      - key: TCG_ENV
        value: production
      - key: TCG_JWT_SECRET
        generateValue: true
      - key: TCG_DATABASE_URL
        value: sqlite:////data/tcg_market.db
      - key: TCG_LIGA_DISABLED
        value: "1"
      - key: TCG_CORS_ORIGINS
        sync: false  # set manually after first deploy
      - key: TCG_SCHEDULER_DISABLED
        value: "0"
    disk:
      name: tcg-data
      mountPath: /data
      sizeGB: 1
```

### Build script (alternative to Docker for Render native builds)
Create `render-build.sh` as fallback if user prefers native runtime:
```bash
#!/usr/bin/env bash
set -e
pip install .
cd frontend && npm ci && npm run build
```

### Start script for Render
Create `render-start.sh`:
```bash
#!/usr/bin/env bash
set -e
# Seed exchange rates on startup (best-effort)
python -m src.cli.main update-exchange-rate --backfill-days 30 || true
# Seed admin user (best-effort)
python -m src.cli.main seed-users || true
# Start API
exec uvicorn src.api.app:create_app --factory --host 0.0.0.0 --port "${PORT:-8000}"
```

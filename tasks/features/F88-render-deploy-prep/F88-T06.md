# F88-T06: Dockerfile (Multi-Stage)

**Status:** planned
**Wave:** 2
**Depends on:** T02, T03, T04

## User Story

As a deployer, I want a Dockerfile that builds the complete application (Python backend + Node frontend), so Render can build and run the service.

## Dev Notes

### Multi-stage build approach

```dockerfile
# Stage 1: Build frontend
FROM node:20-slim AS frontend-builder
WORKDIR /app/frontend
COPY frontend/package*.json ./
RUN npm ci
COPY frontend/ ./
RUN npm run build

# Stage 2: Python runtime
FROM python:3.12-slim
WORKDIR /app

# System deps for curl_cffi
RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc libcurl4-openssl-dev libssl-dev \
    && rm -rf /var/lib/apt/lists/*

COPY pyproject.toml ./
RUN pip install --no-cache-dir .

COPY src/ ./src/
COPY --from=frontend-builder /app/frontend/dist ./frontend/dist

# Create data directory for SQLite persistent disk
RUN mkdir -p /data

EXPOSE 8000
CMD ["uvicorn", "src.api.app:create_app", "--factory", "--host", "0.0.0.0", "--port", "8000"]
```

### Key decisions
- No Playwright in Docker image (Liga disabled on Render)
- `python:3.12-slim` for smaller image
- `curl_cffi` needs libcurl dev headers
- CMD uses port 8000 but Render overrides via $PORT
- Persistent disk at `/data` for SQLite

# F88-T03: Liga Provider Graceful Degradation

**Status:** planned
**Wave:** 0
**Depends on:** —

## User Story

As a deployer, I want to disable the Liga provider via `TCG_LIGA_DISABLED=1` env var, so that Render deploys don't need Playwright/Chromium installed.

## Dev Notes

1. Add `TCG_LIGA_DISABLED` env var check in `src/api/deps.py:get_provider_registry()`
   - When `1`: skip LigaMagicProvider registration entirely
   - Log warning: "Liga provider disabled via TCG_LIGA_DISABLED"
2. Guard the Playwright import in `src/providers/liga/provider.py`:
   - Wrap `import playwright` in try/except ImportError
   - If missing + provider instantiated, raise clear error
3. Update `src/api/app.py` lifespan:
   - Skip Liga browser open/close when disabled
4. Add `TCG_LIGA_DISABLED` to `src/config.py`:
   ```python
   def is_liga_disabled() -> bool:
       return os.environ.get("TCG_LIGA_DISABLED", "0") == "1"
   ```

### Files to modify
- `src/config.py` — `is_liga_disabled()`
- `src/api/deps.py` — skip Liga in registry when disabled
- `src/api/app.py` — guard Liga browser lifecycle
- `src/providers/liga/provider.py` — guard Playwright import

### Acceptance Criteria
- [ ] `TCG_LIGA_DISABLED=1` starts API without Playwright
- [ ] Liga endpoints return clear error (503 or similar) when disabled
- [ ] No Playwright import errors at startup when disabled
- [ ] Normal behavior when env var not set

## Testing

- Unit: test `is_liga_disabled()` returns True/False correctly
- Unit: test provider registry skips Liga when disabled
- Integration: start API with `TCG_LIGA_DISABLED=1`, verify /health works

## Dev Notes

### What to create

#### 1. PRD: `docs/prd/F10-collection-pivot.md`
Feature requirements document covering:
- Problem statement (generic market scanner vs. personal collection tracker)
- User stories
- Functional requirements (sync pipeline, match report, cleanup, frontend adjustments)
- Non-functional requirements (rate limiting, resumability, error handling)
- Out of scope (multi-user, image caching)
- Success metrics (coverage rate, sync completion rate)

#### 2. Architecture diagram: `docs/diagrams/F10-architecture.mmd`
Mermaid flowchart showing:
- Collection CSV import flow (already exists)
- MYP search + match pipeline
- Sync data flow: UserCollection -> Search API -> Matcher -> Card Page -> History Page -> DB
- DB tables and their relationships (user_collection -> cards -> source_cards -> price_observations)

#### 3. User journey diagram: `docs/diagrams/F10-journey.mmd`
BPMN-style Mermaid flowchart showing:
1. User imports CSV -> collection imported
2. User runs match report -> sees coverage
3. User reviews report -> decides to proceed
4. User runs DB cleanup -> backup created, non-collection data removed
5. User runs sync -> prices fetched for matched cards
6. User opens Dashboard -> sees collection stats
7. User browses cards -> sees price data and images

#### 4. ADR: `docs/adr/0004-collection-centric-pivot.md`
Architecture Decision Record:
- Context: Platform was a generic market scanner; user wants personal collection tracking
- Decision: Pivot to collection-centric model where the DB only tracks the user's cards
- Rationale: Single-user app, no need to track cards user doesn't own
- Consequences: DB cleanup removes non-collection data; sync pipeline is collection-driven; Dashboard shows collection stats

#### 5. README update: `README.md`
Add F10 section covering:
- New CLI commands: `match-report`, `db-backup`, `db-cleanup`, `sync-collection`
- New API endpoint: `POST /api/v1/collection/sync`
- Dashboard now shows collection stats
- CardDetail now shows Scryfall HD images
- Set code normalization (all lowercase)

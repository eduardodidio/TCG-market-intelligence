## User Story
As a collector, I want the system to automatically search MYP for each of my collection cards, fetch their price history, and store it, so that I can see accurate market data for MY cards.

## Dev Notes

### What to implement
An async orchestrator `src/collectors/sync_collection.py` that processes each `user_collection` entry through the full pipeline: search -> match -> fetch card details -> fetch history -> store -> link.

### Files to create

### Sync pipeline (per collection card)
```
For each UserCollectionRow:
  1. Search MYP: provider.search_card(name_en)
  2. Match: matcher.match_collection_card(entry, search_results)
  3. If matched:
     a. Fetch card page: provider.get_card_details(source_card)
        - This gives us: external_id, SKU, JSON-LD (name_en, name_pt, set_code, collector_number)
     b. Upsert CardRow via repo.upsert_card(detailed_source_card)
     c. Upsert SourceCardRow via repo.upsert_source_card(detailed_source_card, card_id)
     d. Fetch history: provider.get_price_history(source_card, days=365)
     e. Store observations: repo.insert_price_observations(history)
     f. Link: repo.link_collection_entry(user_collection_row.id, card_id)
     g. Mark any previous errors as resolved
  4. If not matched or ambiguous:
     - Log the result
     - Include in summary report
```

### Key technical details
- Reuse `asyncio.Semaphore(concurrency)` from `backfill.py` pattern
- Each card requires 2-3 HTTP requests: search + card page + history page
- With 548 cards, ~1100-1650 requests, at ~2s each = ~35-55 minutes
- `skip_matched=True` (default) skips entries where `card_id IS NOT NULL` -- this enables resumable sync
- The sync uses `user_id="eduardo"` (hardcoded, same as the rest of the app)
- For the dry-run mode, log what would happen but don't write to DB
- Progress logging: "Syncing card N of M: {name_en} [{set_code}]"

### Repository addition
```python
def link_collection_entry(self, entry_id: int, card_id: int) -> None:
    """Set card_id on a user_collection entry."""
    with Session(self.engine) as session:
        entry = session.get(UserCollectionRow, entry_id)
        if entry:
            entry.card_id = card_id
            session.commit()
```

### Edge cases
- Collection entry with no `name_en` -- skip, log as "no name for search"
- Search returns results but none match by SKU or name -- log as unmatched
- Provider raises exception during card detail fetch -- catch, log error, continue to next card
- Multiple collection entries for same card (different quality/language) -- they should all link to the same CardRow
- Card already exists in cards table (from previous backfill) -- `upsert_card` handles this
- History fetch returns empty list -- still link the card, just no price data

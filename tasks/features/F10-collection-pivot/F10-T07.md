## User Story
As a collector, I want a CLI command `sync-collection` to trigger the collection sync pipeline from the terminal, so that I can sync my collection with MYP price data on demand.

## Dev Notes

### What to implement
Add a `sync-collection` Click command to the existing CLI group in `src/cli/main.py`.

### Files to modify
- `src/cli/main.py` -- add `sync-collection` command

### CLI interface
```
python -m src.cli.main sync-collection [OPTIONS]

Options:
  --db TEXT          Database URL [default: sqlite:///tcg_market.db]
  --limit INT       Max cards to process (for testing)
  --dry-run         Log what would happen without writing to DB
  --delay FLOAT     Seconds between requests [default: 1.0]
  --history-days INT Days of price history to fetch [default: 365]
  --concurrency INT Max concurrent requests [default: 3]
  --force           Process ALL collection entries, even already-linked ones
```

### Implementation
```python
@cli.command("sync-collection")
@click.option("--db", default="sqlite:///tcg_market.db", help="Database URL")
@click.option("--limit", default=None, type=int, help="Max cards to process")
@click.option("--dry-run", is_flag=True, help="Don't write to database")
@click.option("--delay", default=1.0, type=float, help="Seconds between requests")
@click.option("--history-days", default=365, type=int, help="Days of history to fetch")
@click.option("--concurrency", default=3, type=int, help="Max concurrent requests")
@click.option("--force", is_flag=True, help="Re-process already-linked entries")
def sync_collection(db, limit, dry_run, delay, history_days, concurrency, force):
    """Sync user collection with MYP price data."""
    from src.collectors.sync_collection import run_sync_collection

    summary = asyncio.run(
        run_sync_collection(
            db_url=db,
            limit=limit,
            dry_run=dry_run,
            delay=delay,
            history_days=history_days,
            concurrency=concurrency,
            skip_matched=not force,
        )
    )
    _print_sync_summary(summary, dry_run)
```

### Summary output format
```
============================================================
  COLLECTION SYNC SUMMARY
  Total entries:           548
  Skipped (already linked): 320
  Searched:                 228
  Matched:                  180
  Ambiguous:                 20
  Unmatched:                 28
  Cards created:            180
  Observations saved:     65,700
  Elapsed:                2345.6s (39.1 min)
============================================================
```

### Key technical details
- Reuse the `_print_summary` pattern from existing commands but adapt for `SyncSummary` fields
- The `--force` flag maps to `skip_matched=False` in the orchestrator
- Default history is 365 days (not 1095 as in backfill) since we're doing targeted sync, not full historical backfill

### CardDetail image implementation
The CardDetail page currently shows card info (name, set, price, sources) but no card image. Add the Scryfall image using the existing `scryfallImageUrl()` utility.

```tsx
// In the info panel (left column), above the card name:
{card.set_code && card.collector_number && (
  <div className="mb-6 flex justify-center">
    <img
      src={scryfallImageUrl(card.set_code, card.collector_number, "normal")}
      alt={card.name_en}
      className="rounded-xl shadow-lg max-w-[250px] w-full"
      loading="eager"  // main content, load immediately
      onError={(e) => { e.currentTarget.style.display = 'none' }}
    />
  </div>
)}
```

### Key technical details
- `scryfallImageUrl()` already exists in `frontend/src/utils/scryfall.ts` and already defaults to `version="normal"` (HD quality)
- The CardDetail page already has a two-column layout: info panel (left) + price chart (right)
- The image goes in the info panel, above the card name
- Use `loading="eager"` since this is the main content of the page (not a list item)
- Fallback: hide the image element on error (same pattern as CardTile)
- The set_code in the DB may be uppercase (pre-normalization) or lowercase (post-normalization) -- `scryfallImageUrl` already calls `.toLowerCase()`, so both work

### Empty state review
Review each page and update messaging to reflect the collection-centric paradigm:

| Page | Current empty state | New empty state |
|------|-------------------|-----------------|
| Dashboard | (crashes or shows zeros) | "Import your collection and sync to see your portfolio stats." |
| Cards | "No cards found. Try a different search." | "No cards with price data. Sync your collection to fetch prices." |
| CardDetail | "Card not found" | "Card not found. It may not have been synced yet." (keep existing) |
| Market Movers | (may show empty tables) | "Need more price history to show movers. Check back after a sync." |
| My Collection | "No cards in your collection. Import your CSV to get started." | Keep as-is (already good) |

### Edge cases
- Card without set_code or collector_number -- no image shown (graceful degradation, already handled)
- Scryfall 404 (card not in Scryfall DB) -- hide image via onError handler
- Very wide card images (e.g., split cards) -- `max-w-[250px]` constrains width

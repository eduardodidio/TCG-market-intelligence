# F165-T01: Make MoverRow clickable with Link to card detail

**Status:** completed
**Wave:** 0

## User Story

As a user, when I see a card in the Collection Movers panel (gainers or losers), I want to click on it to navigate to the card detail page, so I can understand why the price changed.

## Dev Notes

### Files to modify
- `frontend/src/components/CollectionMovers.tsx`

### Changes

1. **Import `Link` from `react-router-dom`**

2. **Wrap MoverRow content in a `<Link>`**:
   ```tsx
   <Link
     to={`/cards/${mover.card_id}`}
     className="flex items-center gap-3 py-2 border-b border-slate-700/50 last:border-0
       hover:bg-slate-700/30 rounded px-1 -mx-1 transition-colors no-underline"
   >
   ```

3. **Change the outer `<div>` to just be the `<Link>`** — replace the `<div>` with the Link, keeping all child elements

4. **Add cursor pointer visual cue** — the Link naturally provides this

5. **Preserve `data-testid`** on the Link element

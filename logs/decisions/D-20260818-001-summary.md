## 2. Test Coverage

- **103 tests, all passing** -- good foundation.
- **Two known untested branches:** `past_price == 0` in momentum and invalid `price_field` argument. Both are low-risk but should be covered for completeness.
- **pytest-cov is not installed** -- cannot measure automated coverage. Flagged in both F03 QA and TechLead reports. Trivial to fix.
- **Zero tests for the collector/provider pipeline** -- `backfill.py`, `provider.py`, rate-limiting, error handling, and retry logic are all untested. This is the largest gap.

---

## 3. Architecture Health

**Strengths:**
- Provider abstraction (`CardSourceProvider` ABC) is well-designed for multi-source expansion.
- Analytics module is fully pure -- zero DB imports, pure Decimal arithmetic, 46 unit tests with no mocking.
- Domain model separation (dataclasses in `domain/`, ORM in `database/`) keeps layers clean.

**Concerns:**
- Sequential card processing with `asyncio.sleep(1.0)` per card means ~3 hours for all sets (~10k cards). Needs concurrency and checkpoint/resume before scaling.
- SQLite is adequate now (1889 rows) but should be monitored as data grows toward 1.5M rows. The SQLAlchemy abstraction makes PostgreSQL migration straightforward if needed.
